# 《何以为生》现代指挥版封面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 生成《何以为生》现代指挥版单曲封面，并把现代指挥版与既有三层叙事版统一交付为 1500×1500 PNG。

**Architecture:** 以既有三层叙事版中的泠月 Luna 为唯一人物身份参考，重新生成现代指挥场景；先验证人物动作、观看路线与中文标题，再对两张选定封面做一次最终尺寸归一。生成失败时只修改最早失效的视觉变量，不用增加无关人物或武器数量补救。

**Tech Stack:** OpenAI 内置图像生成、macOS `sips`、`file`、本地图像查看与缩略图检查。

---

### Task 1: 生成现代指挥版候选

**Files:**
- Reference: `作品/何以为生/何以为生_单曲封面_三层叙事.png`
- Create: `作品/何以为生/何以为生_单曲封面_现代指挥.png`

- [x] **Step 1: 用既有封面固定泠月 Luna 的身份**

只继承泠月的面部、发型与人物气质；明确排除轮椅、老人、黑白旧照和旧版构图。

- [x] **Step 2: 生成新的 1:1 电影海报画面**

泠月位于前景右侧并看向中景指挥官；指挥官挥臂下达发射命令；手势、导弹轨迹与火箭发射系统形成连续斜线。锁定唯一可见文字“何以为生”，禁止随机外文、番号、口号、血腥与具体受害者。

- [x] **Step 3: 把候选保存到作品目录**

只保存通过初步画面检查的候选；不把默认生成目录当作最终交付位置。

### Task 2: 检查并返修生成结果

**Files:**
- Inspect: `作品/何以为生/何以为生_单曲封面_现代指挥.png`

- [x] **Step 1: 检查人物与动作**

确认泠月像同一人物；指挥官像在发令，不像敬礼、演讲或挥舞古代武器；手臂与手部结构自然。

- [x] **Step 2: 检查观看路线与画面统一**

确认泠月目光落向指挥官，发令手势接到导弹升空方向，火光同时照亮两人；画面不能像人物贴纸压在武器背景上。

- [x] **Step 3: 检查标题与缩略图**

确认标题逐字为“何以为生”，没有随机文字；生成 256×256 临时缩略图，确认人物、动作与歌名仍可辨。

- [x] **Step 4: 若关键项失败，只返修单一问题**

标题错字只修标题；人物身份漂移只加强人物参考；动作不清只重写发令手势与导弹方向。不同时改色彩、人物、动作与排版。

### Task 3: 统一两张封面的最终尺寸

**Files:**
- Modify: `作品/何以为生/何以为生_单曲封面_三层叙事.png`
- Modify: `作品/何以为生/何以为生_单曲封面_现代指挥.png`

- [x] **Step 1: 将两张方形封面归一到 1500×1500**

先输出到独立临时目录，验证成功后再替换作品目录中的正式文件，避免中途覆盖损坏原图。

Run:

```bash
sips -z 1500 1500 "作品/何以为生/何以为生_单曲封面_三层叙事.png" --out "$TMPDIR/何以为生_单曲封面_三层叙事.png"
sips -z 1500 1500 "作品/何以为生/何以为生_单曲封面_现代指挥.png" --out "$TMPDIR/何以为生_单曲封面_现代指挥.png"
```

Expected: 两条命令均成功生成 1500×1500 PNG。

- [x] **Step 2: 验证尺寸后替换正式文件**

Run:

```bash
sips -g pixelWidth -g pixelHeight "$TMPDIR/何以为生_单曲封面_三层叙事.png" "$TMPDIR/何以为生_单曲封面_现代指挥.png"
```

Expected: 两个文件的 `pixelWidth` 和 `pixelHeight` 均为 `1500`。验证后再移动到作品目录。
