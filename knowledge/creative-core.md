# 创作底层原理

本文件只保存跨题材、跨用户、跨歌词与声音阶段仍成立的上位原理。具体乐段、字词和提示词方法分别进入 `lyrics-craft.md` 与 `sound-prompt.md`。

## 1. 作品调用听众已有经验

### 上位原理

听众不会从零学习一首歌。他会用已有的关系经验、身体记忆、语言习惯、文化联想和音乐类型理解第一耳。作品的任务不是把情绪塞进听众脑中，而是给他一个入口，让他重新调用自己已经拥有却未必正在想起的感受。

### 模型容易犯的错误

- 把情绪名称当成情绪传递。
- 解释人物为什么难过，代替让听众经历变化。
- 为了共鸣使用最常见的公共句，结果任何人都能说、任何歌都能用。
- 为了原创切断公共认知，写成陌生但无法理解的表达。

### 创作判断

成熟作品同时完成：

```text
熟悉经验让听众进入
→ 当前人物赋予私人来处
→ 新关系或新声音改变原有理解
→ 乐段组织期待、压力、释放或悬置
→ 听众既认出自己，又记住这首作品为什么不同
```

### 生效证据

- 听众不需要知道作者全部经历也能进入。
- 抽掉当前人物、关系或声音以后，核心表达会失去一部分身份。
- 第一耳能理解，第二耳能多明白一层。
- 听众知道自己会在什么时刻使用、复唱、转发或回味它。

### 边界

通俗不是失败，陌生也不是价值。熟悉材料只要被当前人物重新组织，就可以成立；生僻材料没有人物因果，同样无效。

## 2. 创作从关系刺激和未解决矛盾开始

### 上位原理

情绪不是孤立标签。人物先遭遇现实刺激，再根据欲望、恐惧、身份、责任和已有经验产生带对象、方向和行动冲动的情绪。真正推动作品的是人物尚未解决的矛盾，而不是作者预先替他总结出的道理。

### 错误机制

模型常从题材直接跳到结论：失恋就写放下，异地就写想念，暗恋就写不敢说。随后再找道具和场景证明这个结论。这样得到的是题材常识，不是当前人物。

### 人类判断

先区分：

```text
发生了什么
人物想要什么
人物害怕什么
人物拥有什么证据
人物不能确认什么
人物的身体和行动准备往哪里去
人物尚未解决的两股力量是什么
```

创作命题必须保留这项未决，不在开头替人物变得成熟、清醒或正确。

### 生效证据

- 人物的选择、躲避、改口、停顿或误读有现实来源。
- Bridge 和 Final 的理解来自新增事实或行动，而不是突然讲人生。
- 结尾可以行动，但不能凭作者权力替未知关系给答案。

### 边界

轻甜、舞曲、喜剧可以依靠共同动作、身体释放和身份态度驱动，不强迫每首歌承担沉重哲理。

## 3. 人物知识边界先于作品结论

### 上位原理

听众会持续判断：是谁在说，他凭什么知道。人物可观察到动作和话语，可以推测动机，但不能知道对方没有表达的内心。

### 错误机制

模型为了让关系显得完整，会把作者分析塞进人物嘴里，把“可能”写成“事实”，把未来理解写进当时现场。作品因此失去悬念和人物真实性。

### 执行方法

关键命题只区分四类来源：

```text
用户确认事实
人物可观察事实
人物推测
作者结论
```

作者结论若没有人物证据，不得作为当前人物已经知道的事实进入歌词。

### 生效证据

- 推测保留语言和声音上的不确定性。
- 对方没有凭空获得台词、和声回应或确认式动作。
- 人物仍能在未知中采取自己的行动。

## 4. 情绪通过选择性知觉进入意象

### 上位原理

外物拥有光、声、温度、材质、运动、数量、距离、聚散和文化联想，但没有唯一固定情绪。人物的状态会改变他先注意哪项真实属性、怎样组织这些属性、调用哪段记忆。听众再从这种观看方式反推人物。

### 错误机制

- 从题材词库检索雨、灯、风、街道、手机等材料。
- 给物件附加孤独、温柔、冰冷等形容词。
- 用物件类别判断高级或低级。
- 让一个中心物象在每段机械证明同一结论。

### 人类判断

```text
当前关系刺激改变了人物怎样的注意
→ 人物会先看见外物哪项真实属性
→ 属性通过动作、空间、声音或时间发生什么
→ 外物变化怎样反过来加深或修正情绪
→ 换成同类材料会损失什么
```

### 生效证据

- 隐藏情绪标签以后，观看方式仍暴露人物状态。
- 换成同类物件会同时损失物性、人物关系或声音价值。
- 同一物件再次出现时，观看或作用发生变化，而不是重复象征。

### 边界

机械物件、生活物件、自然风物和文化物象都可以使用。类别不决定情绪贡献；人物来处、真实物性和当前位置决定。

## 5. 三重境界是继承关系

### 第一重：表达能力

事实、主体、动作、对象、结果、语序和自然中文成立。听众第一耳知道发生了什么或感受到什么。

### 第二重：诗性转化

通过意象、物性、修辞、转义、句法、声韵、留白和陌生化，使经验成为歌词语言，而不是信息说明。

### 第三重：整体统摄

人物、情绪、乐段、音乐和听众决定何时使用白话、诗性、抽象词、客观动作和直接称呼。第三重不抛弃前两重，而是在拥有它们以后做合适取舍。

### 错误机制

- 把第一重的大白话误认为第三重返璞归真。
- 把第二重写成辞藻和意象展示。
- 用诗性补偿病句。
- 每句都追求技巧，整首歌没有地面和轻重。

### 生效证据

- 第一耳自然，第二耳增义。
- 简单句能说明为什么比复杂候选更适合人物和音乐。
- 显性诗性有情绪任务，不只证明会写。
- 不同乐段比例不同，但同一个人和同一套语言规律持续存在。

## 6. 私人关系打开公共情感

### 上位原理

共鸣不是把故事写得模糊，而是让听众从一个人的具体关系进入自己已有的类似经验。私人事实提供可信来处，公共情感来自同一种人类处境、代价、选择或时间变化。

### 错误机制

- 只复述专属情侣互动，听众只能旁观作者。
- 为了格局突然写山河、众生和人生。
- 删除全部私人细节，得到空泛公共文案。

### 执行方法

从当前人物的真实刺激出发，逐步问：这项经历照见了什么更普遍的等待、误判、执念、体面、责任、离散或自我保护；再把普遍处境落回当前人物愿意承担的行动。

### 生效证据

- 陌生听众不需要复制同一剧情，也能认领情绪结构。
- 尺度扩大与开场事实属于同一因果。
- Final 回到人物行动，不用作文结论收尾。

## 7. 听众参与和传播来自可使用性

### 上位原理

传播不是一句像海报的金句，而是作品帮助听众完成某种现实动作：替自己说话、向某人表达、确认身份、参与仪式、共同体验、回味或重新理解关系。

### 执行方法

每首歌选择一个主要参与角色：

```text
好奇见证
情绪代入
代理发言
共同判断
共同体验
仪式参与
故事旁观
```

核心句和声音动作必须把部分表达权交给听众。

### 生效证据

- 能指出谁会在什么时刻使用哪句或哪个声音动作。
- 核心句脱离作品仍可借用，但放回作品会获得更准确含义。
- 传播窗口不损害整首歌复听价值。

## 8. 反模型平均化

模型第一反应来自高概率续写，只能成为内部候选，不能自动胜出。反平均化不是故意写怪，而是检查当前人物、关系、语言和声音是否重新授权了熟悉材料。

高价值位置至少问：

- 同题材最常见的关系结论是什么。
- 当前人物有什么事实让它成立或不成立。
- 候选是否真正改变责任、观察、行动或声音，而非换近义词。
- 第一耳自然是否成立。
- 替换成另一首同题材作品是否几乎无损。

普通连接句不承担反平均化任务。作品需要身份资产，也需要自然呼吸。

## 9. 整体先于局部，反馈返回最早根因

作品是耦合系统。命题影响核心句，核心句影响曲式，曲式影响乐段，乐段影响句词，句词又可能暴露命题错误。

修改遵循：

```text
先判断问题层级
→ 在最早根因处改变决定
→ 向下重新执行必要范围
→ 向上回测完整作品
```

局部问题不重跑全歌；方向问题不靠换词掩盖。没有净改善候选时保留原稿。

## 10. 语言参与发现主题

### 上位原理

人类创作不总是先得到完整结论，再把它翻译成歌词。一个动词会改变谁承担责任，一个结果补语会改变动作是否已经发生，一次停顿会暴露人物是在请求、试探还是嘴硬。真正写出的语言会反过来修正创作者对人物和主题的理解。

### 错误机制

模型容易先把立意、Hook、Bridge结论和Final行动全部规划完，再为每段寻找证明材料。这样规则看似完整，正文却只能解释预设答案；语言没有发现权，人物也不会出现可信的意外。

### 执行方法

先锁定用户事实、人物知识边界和未解决矛盾，再用少量完整歌词样本比较不同的动作、责任、观察和声音形状。样本若暴露了更准确的人物关系，可以修正命题、核心句或结尾；但一句漂亮话只有同时通过人物、自然中文、情绪作用和可生长性，才有权改变上游。

### 生效证据与边界

- 命题能指出哪些实际字词让原先理解发生了变化。
- 开场、核心句和后文共享一种会生长的动作、句法、物性或声音关系，而不只是共享主题说明。
- 这不是无方向即兴。用户事实和人物未决仍是边界，押韵、字数和传播标签不能反过来给失真的语言授权。

## 11. 情绪强度不等于作品尺度

### 上位原理

人物越来越痛，只表示同一种情绪浓度上升；作品后来多看见了什么，才决定它有没有纵深。严肃情感作品可以从一段私人关系逐步看见更广的对象、更长的时间、反复发生的因果、需要承担的价值或真实行动。

### 错误机制

模型常把Verse的想念写得更重、Pre更急、Chorus更舍不得、Bridge更抽象，就误以为作品已经升级。结果只是音量和情绪词变大，听众对人物和世界没有新增理解。

### 执行方法

按题材只选择一条必要的尺度轴：

```text
对象：从当事双方照见同类处境
时间：让当前动作与更长记忆发生回响
因果：看见一种反复发生的人性或责任结构
价值：人物决定相信、拒绝、承担或保护什么
行动：结尾付出代价或改变现实动作
```

扩大必须从开场私人事实长出，并最终回到当前人物。直接换成“人生、命运、世界、时代”，引用名人，或只让人物从等待改成离开，都不能自动证明尺度成立。

### 边界

轻甜、喜剧、舞曲和氛围作品不强求人生议题，可以通过共同动作、身份态度、身体释放、角色权力或声音仪式离开单点重复。所谓扩大不是统一宏大，而是作品后来比开场多看见一层。

## 12. 文化材料必须由当前人物重新发声

历史、神话、文学、公共名句和他人案例能够调用听众已有认知，但不能替人物证明自己正确。文化材料只有同时满足以下条件才进入承重位置：

- 与当前冲突共享欲望、阻力、代价或行动结构。
- 当前人物的身份、语气和知识范围有权想到它。
- 旧材料已经转成当前人物的动作、物性、悖论或语言，不只是报名字和复述典故。
- 不了解出处的听众第一耳仍能进入，了解出处的人第二耳多一层回响。
- 删除后会损失理解、尺度或行动，而不只是少一点文化感。

流行歌词通常只保留一个主要文化系统和最少旁证。例证链只在说唱、摇滚、群体表达或篇幅真正需要时使用，并要靠同一命题和节奏推进；不能写成作文素材清单。直接引用还要核对来源、语境和权利风险。

## 13. 资格下限与继续投资价值分开

自然中文、事实准确、人物成立、基本可唱和没有被押韵改坏，只说明作品没有在下限处失败，不能证明它值得继续精修。继续投资要寻找五项资产：人的新发现、当前人物与语言形成的作品身份、可召回的歌词或声音记忆、听众真实用途，以及缺陷能否在不破坏核心资产时修复。

V3不恢复多候选委员会，但在完整初稿和终稿节点必须作出同样的实质判断：

```text
已有不可替代资产，缺陷可局部修复 → 继续精修
资产成立但根因在命题、核心句或曲式 → 返回上游
规则合格却没有身份、发现或听众用途 → 不靠炼字维持投入
```

流程投入、规则通过数量、解释完整和局部工整都不能制造投资理由。相反，一首已有独特核心资产但带少量可修复弱句的初稿，不应输给更安全却通用的稿子。

## 14. 外部成熟机制校准

### 上位原理

项目内部规则只能说明作品是否按自己的方法工作，不能证明它已经接近成熟专业作品。高上限目标需要一个外部坐标，检查当前作品与长期公开实践之间仍缺什么；外部坐标提供的是可观察机制，不是姓名权威和风格答案。

### 执行方法

核心语言或声音样本出现以后，才选择一个与当前最大难题直接相关、公开可核对的成熟作品或创作者实践。只提取一项机制，例如人物责任怎样进入普通中文、公共词怎样获得私人含义、文化材料怎样完成转译、旋律与节奏怎样形成短记忆、编曲怎样为主词让位。随后必须淘汰或修改一个具体字、句法、乐段理解、主题动机、主唱、groove或编曲决定；只写“参考了某某”不算校准。

### 证据与边界

- 校准记录包含公开范围、提取机制、被改变的决定和反模仿检查。
- 不模拟本人表态，不声称本人会认可，不复制标志性原句、旋律、物件或制作指纹。
- 不组成名人投票池，也不在样本出现前替作品选题。
- 顶尖、发行投资或同等级高上限目标默认执行一次；快速草稿、普通练习或没有外部机制能改变决定时可以跳过，并诚实说明质量仍待真实作品与市场验证。
