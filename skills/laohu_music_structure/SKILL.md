# laohu_music_structure

你负责歌词完成后的谱曲与风格阶段：风格流派、BPM、编曲取舍、纯音乐 style prompt 和演唱空间。

当老胡说“生成曲风 / 曲风提示词 / 谱曲 / 风格提示词”时，默认不是只产出曲式与风格方案，而是一次性交付音乐生成阶段初稿：先完成本 skill 的声音容器判断，再直接串联 `laohu_sing_control_writer` 生成初稿人声版 style prompt、controlled lyrics 和声音评审输入包。内部先后顺序必须保留，对外不再要求老胡二次确认“是否进入演唱控制”。

在正式生产的第三个质量小循环里，本 skill 负责先写入曲式与风格阶段文件，再把曲风、BPM、编曲、纯音乐 style prompt、人声预留空间和歌词注册交给 `laohu_sing_control_writer`。第三循环的评分由 `laohu_sing_control_repair` 对最终 style prompt + controlled lyrics 执行；但如果 repair 发现曲风/BPM/编曲根基错误，必须退回本 skill 重做曲式与风格方案，而不是只让演唱控制标签硬救。

如果第三循环的评审缺点根源属于曲式与风格，而不是单纯演唱控制，例如主风格错、BPM 不适配、编曲容器挡歌词、歌词注册和曲风冲突、国风 / R&B / 摇滚等类型定位错误，诊断官必须先完成曲式结构规则归因与写回证据，再让本 skill 重做。阶段文件要写明：评审缺点、为什么属于 structure 根基问题、旧 structure 规则哪里没拦住、本轮新增 / 修正规则、实际写入文件路径或临时规则位置、不升级原因、重做后哪些曲式 / 风格字段证明规则生效。没有这份证据，不能把第三循环标记为完成自我优化。

本 skill 不负责在副歌确定后、主歌未写前插入“配乐 / BPM / 编曲”判断。曲式结构，也就是 Verse / Pre / Chorus / Bridge / Final Chorus 的排列和乐段功能，应在选题规划阶段基本确定，并由歌词 writer 继承执行。除非老胡明确要求“先做纯音乐 / 先定风格 / 先生成伴奏”，否则完整歌词写完并优化前，不进入本 skill。

当前项目不使用外部 skill、外部结构化规则或前后端运行方式。本 skill 必须独立完成曲式与风格判断，共享规则只用于补充校验、扩展风格词汇和避免泛化。

## 基础曲式与风格能力内核

本 skill 的下限是能独立把已确认题眼放进一个合适的声音容器，而不是套一个 generic pop 模板。即使不读取任何共享资产，也必须自带以下能力：

```text
先判断题眼需要什么声音容器：贴耳倾诉、集体合唱、叙事推进、情绪爆发、轻喜剧律动、冷感循环、国风命运感、摇滚反抗或 Rap 态度。
先定主风格，再定辅助风格；辅助只能服务局部，不许平均硬塞。
曲式必须同时满足重复和对比：重复负责记忆，变化负责推进。
副歌核心句必须被放在最有利于复唱、爆发或认领的位置。
Verse 给人物和现场，Pre 收紧压力，Chorus 释放核心句，Bridge 翻面或暴露代价，Outro 回收余波。
Verse / Pre / Chorus 必须共享同一首歌的语言质感和情绪密度。曲式只能分配功能和能量，不能默认 Verse 像文章、Pre 像说明、Chorus 才像歌。Verse 要给“副歌级凝练叙事”留气口和空间；Pre 要给“副歌级凝练埋情绪”留上行动力；Chorus 才进入宣泄和命名。
纯音乐 style prompt 要给后续人声留空间，不把编曲写满，不在纯音乐阶段写具体人声画像。
如果任务明确是短剧 BGM、纯音乐配乐或 instrumental cue，不能只输出 style prompt。仍需给出可填入歌词框 / Custom Lyrics 的无歌词曲式结构控制，例如 [Instrumental Intro]、[Theme A]、[Build]、[Break]、[Outro]，用来控制音乐段落、断点、留白和收尾。
```

本项目默认声音容器按商业传播型流行歌判断。曲式、BPM、编曲和 style prompt 必须优先服务观众喜欢、复唱、短视频截取、BGM / 转场 / OST / 广告使用和评论区传播。文学余味、实验编曲和复杂段落变化只能作为加分项，不能牺牲副歌复唱、hook space、主唱清晰度、段落重复和剪辑可用性。

商业传播型曲式硬门：

```text
hook 早出现：除非题材必须慢铺，否则副歌核心句或动作 hook 应在第一轮副歌明确交付。
副歌稳定：C1 / C2 / Final Chorus 使用同一主旋律和相近句组，允许少量变体，不鼓励每遍重写。
切片友好：至少预留一个 8-15 秒可独立截取的副歌 / Final Chorus 高点。
BGM 友好：Verse 和 Pre 不要编曲过满，给对白、转场或画面留空间；Chorus 有清楚入点和落点。
OST / 广告友好：情绪 cue 要明确，不能只做私人文学氛围；听众没看剧情也能抓到情绪。
```

基础曲式模板下限：

- 短传播歌：优先 V+C 或循环短句，hook 早出现，重复强。
- 标准流行歌：V1 + Pre1 + C1 + V2 + Pre2 + C2 + Bridge + Final C。Pre 负责蓄力，第二轮 Verse / Pre / Chorus 负责补新证据和加深记忆，Bridge 负责翻面，Final C 负责加重。
- 叙事慢歌 / 民谣：Verse 可以加长，但必须换证据推进，不能流水账。
- Rap / 摇滚 / 电子：按态度、切分、喊感、循环和舞台能量重设段落，不强套抒情慢歌。
- 国风 / 古风：曲式服务命运感和语体统一，不靠古风符号堆砌。

### 风格不是声音标签，也是歌词注册

曲式与风格阶段必须同时决定“声音容器”和“歌词注册”。风格不是只写 `pop ballad / R&B / rap` 标签，而是决定后续歌词应该用什么语体、句长、押韵密度、人物声口和抽象度。

给下游填词前，必须内部确定并在交接字段中保留：

```text
歌词注册：口语 / 书面 / 半诗性 / 街头 / 古典 / 贴耳 / 舞台宣言。
人物声口：克制 / 嘴硬 / 反抗 / 疲惫 / 温柔 / 冷感 / 自嘲 / 失控。
句长与气口倾向：短句循环 / 中短副歌 / 长叙事线 / Rap 切分 / R&B 短尾。
韵脚密度：主歌弱押 / 副歌完美韵 / Rap 连押 / R&B 窄韵 / 民谣自然弱押。
副歌长音尾字建议：哪些尾字适合 open vowel、nasal close 或 short dry ending。
主歌韵脚松紧：哪里弱押，哪里必须稳定回环。
Bridge 抽象度边界：是否允许更书面、更哲学、更概念压缩。
不适合本风格的写词方式：例如 R&B 不写完整剧情说明，摇滚不修得过度礼貌，Rap 不写民谣分行。
```

如果曲式方案只说“适合抒情流行 / 适合电影感”，但没有决定歌词注册和声口，后续 writer 会把所有风格写成同一种白话分行，判为交接不足。

### 创作中枢声音化硬门

曲式和风格不是脱离歌词的音乐百科。选择声音容器前，必须先确认：

```text
已确认方向标题：候选方向已经被一句标题句钉住，不是普通摘要。
已确认主唱 POV / 对话对象 / 主人称：知道谁在唱、唱给谁、用什么人称唱。
已确认人物立场卡 / 声口限制：知道这个人的经历伤口、性格棱角、价值偏见、软肋、责任和不肯退让，以及哪些词不像他说。
已确认整首总情绪曲线：知道 Verse、Pre、Chorus、Bridge、Final Chorus 的情绪如何波动。
已确认各乐段职责和内部曲线概要：知道每段负责什么、内部如何起伏。
这首歌替谁唱？
他在什么场景里痛？
他为什么只能用这个声口、这个偏见、这个姿态说话？
他最想说但说不出口的是哪句话？
副歌能不能让这个人认账？
这句话能不能唱、能不能记、能不能传播？
```

如果上游只给题眼、副歌方向或歌名方向，但没有方向标题、POV / 人称、人物立场卡、整首总情绪曲线和乐段内部曲线，本 skill 必须拒收并退回选题阶段补齐，不能由曲式阶段替上游补洞。

曲式的任务是让这些已确认问题在声音里成立：Verse 让场景被看见，Pre 让痛收紧，Chorus 让说不出口的话可复唱，Bridge 让认账或翻面发生，Outro 让那个人留在听众心里。

如果歌词方向要求主歌、预副歌都接近副歌级的凝练度，曲式不能只把能量留给 Chorus。Verse 需要更清楚的短乐句、可听见的家族韵回路和留白；Pre 需要更窄的和声 / 节奏上行，把埋藏情绪推到副歌；Chorus 再释放更强重复和更大动态。

如果风格判断只能说“适合抒情 / 适合流行 / 适合电影感”，但说不清它如何放大这个人的场景、痛点、说不出口的话和副歌传播句，判为 generic 风格判断，必须重做。

### 曲式方案反向审稿

输出前必须检查并直接修正：

```text
是不是先讲了风格理论，而没有先给可执行声音容器？
主风格是否太宽，像 generic pop ballad？
曲式是否只是模板，不能解释副歌为什么必须出现？
Pre 是否真的把人推向副歌，还是只是流程占位？
Bridge 是否有翻面、认账或代价暴露，还是只是“加一段”？
style prompt 是否给人声和歌词留空间，而不是把编曲写满？
```

共享资产调用边界：

```text
主风格裁决、曲式模板、重复与对比、段落功能、hook space → 本 skill 本体直接执行。
具体流派词汇、BPM 细分、配器组合、国风 / Rap / R&B / 电子等专项差异 → 读取风格流派映射库和曲式结构库。
三幕式、五幕剧、英雄之旅、反转阶梯 → 当题材需要叙事骨架时读取曲式结构库，不把所有歌都套高阶结构。
创作者视角 → 需要补制作判断和避免 generic 时读取，不把人物名写进投喂 prompt。
```

### 规则吸收边界

本 skill 只吸收“曲式与声音容器下限”相关规则：题眼如何进入声音、主风格如何裁决、曲式如何服务副歌核心句、段落功能如何给后续填词留空间。新反馈写入本 skill 前必须通过五项测试，并明确不是某一流派的局部经验。

```text
应该写入本 skill：
防止 generic pop / generic ballad 的硬门。
主风格和辅助风格的裁决顺序。
Verse / Pre / Chorus / Bridge / Outro 的基础功能。
副歌核心句位置、hook space、重复与对比的执行流程。

不应写入本 skill：
某一种流派的配器清单、BPM 细分、唱腔偏好、平台提示词长词库。
国风、Rap、R&B、电子、儿童、广告、晚会等类型化规则的全部细节。
仍在试用的争议审美偏好。
```

类型化声音经验和具体流派规则留在共享资产；本 skill 只写清楚“什么时候读取哪类增强资产”，不把所有风格经验混成基础模板。

曲式结构规则写回证据最低字段：

```text
评审缺点：
为什么属于曲式 / 风格根因：
旧 laohu_music_structure 规则缺口：
本轮新增 / 修正的 structure 规则：
写入位置：laohu_music_structure / 共享资产 / 当前作品临时规则 / 待验证经验。
写回证据：实际文件路径和段落标题，或不升级为稳定规则的原因。
同步检查：是否需要补 laohu_sing_control_repair 检查项。
重做前自检问题：
重做后生效证据：主风格、BPM、编曲、歌词注册、hook space 或段落能量中哪些字段已经改变。
```

## 输入

- 已确认的选题角度。
- 已确认的题眼。
- 已确认的副歌核心句和主韵脚。
- 嘴替对象。
- 题眼判断。
- 副歌核心句候选。
- 情绪锋芒和传播目标。

如果老胡只是确认了方向，但没有明确确认题眼和副歌核心句，不得进入曲式与风格阶段。必须退回 `laohu_music_topic` 继续打磨。

### 阶段状态与确认门

本 skill 只能接收“已确认方向”的下游材料，不能把轻阶段探索内容当正式曲式输入。

进入前必须复核：

```text
创作角度：已确认，而不是方向概览里的候选标签。
题眼：已确认，而不是普通话摘要。
副歌核心句：已确认或至少是可唱优化后的候选，不是意思草稿。
主韵策略：已确认主韵辙、完美韵组优先级和家族韵使用边界。
主角和叙事视角：已确认。
人物立场卡 / 声口限制：已确认，并能限制歌词注册、人物声口和禁用写法。
情绪曲线：已确认 Verse / Pre / Chorus / Bridge / Final Chorus 的心理动作。
歌名方向：已确认或有明确候选。
```

缺任一项时，当前阶段状态只能标为“待补齐”，输出缺失项和返回路径；不得生成正式曲式、BPM 或 style prompt。曲式阶段不是用音乐包装一个未确认题眼，而是把已确认副歌核心句放进正确声音容器。

给下游填词的交接字段必须保留：

```text
已确认题眼：
已确认副歌核心句 / 当前候选状态：
主韵辙与完美韵组：
家族韵使用位置：
主角和叙事视角：
人物立场卡 / 声口限制：
Verse / Pre / Chorus / Bridge / Final Chorus 的心理动作：
主风格与辅助风格边界：
歌词注册：
人物声口：
句长与气口倾向：
副歌长音尾字建议：
主歌韵脚松紧：
Bridge 抽象度边界：
不适合本风格的写词方式：
禁用写法：
阶段状态：待补齐 / 曲式候选 / 已确认曲式 / 待老胡确认。
```

## 必做判断

- 主风格是什么，辅助风格只在哪些局部起作用。
- 为什么这个题眼适合这种声音容器。
- 为什么不选常见替代风格。
- 歌词文本风格三要素是什么：题材、意象体系、语言语感。
- 旋律唱腔倾向是什么：慢唱、念唱、转音、嘶吼、慵懒、贴耳、合唱还是循环。
- 编曲配器倾向是什么：钢琴弦乐、木吉他、中式器乐、鼓组贝斯、电子合成器、电吉他、复古音色等。
- 曲式只是如何辅助情绪释放，不能把曲式当风格判断依据。
- 本轮使用哪一种基础曲式模板：V+C、标准流行、无 Pre 简约流行、循环短句、抒情慢歌 / 民谣加长铺陈，或自定义结构。
- 如果选择标准流行 / 标准抒情结构，必须明确是否使用 V1 + Pre1 + C1 + V2 + Pre2 + C2 + Bridge + Final C。不能只写 Verse / Pre / Chorus / Verse 2 / Bridge / Final Chorus 这种省略结构，导致第二次 Pre + Chorus 被漏掉。
- 本轮使用哪一种叙事结构骨架：标准三幕、四幕式、五幕剧、八序列 / 英雄之旅、反转阶梯、嵌套三幕，还是不需要明显叙事结构。选择必须服务题眼和乐段功能，不能为了显得高级而硬套。
- 本轮曲式如何同时满足重复和对比：哪里负责记忆，哪里负责变化。
- 副歌核心句应该在哪个乐段、哪个能量位置出现。
- Verse 如何进入人物和场景。
- Pre-Chorus 如何收紧情绪并逼出副歌。
- Chorus 如何释放核心句，而不是喊口号。
- Bridge 是否需要翻面、反问、停顿或情绪转向。
- Outro 如何留下余波。
- 哪里需要 hook space，哪里给 lead vocal 留出空间。

## 类型与使用场景判断

曲式阶段必须先判断歌词类型和使用场景，不同类型不能套同一套 generic pop 结构：

```text
通俗 / 艺术民族 / 影视 / 晚会主题 / 行业企业校歌 / 广告 / 儿童 / 摇滚 / Rap / 歌手定制 / 现成曲填词
```

判断后必须说明：

```text
使用场景：
目标听众：
演唱主体：
曲式服务点：
传播记忆点：
不适合的曲式风险：
```

如果是影视 / 晚会 / 行业类，曲式要说明主题服务点和独立传唱点，防止宣传腔。
如果是广告 / 儿童类，曲式优先短结构、重复、问答和强记忆单元。
如果是摇滚 / Rap 类，曲式要给态度爆点、喊感位置、口语节奏和段落释放点。
如果是现成曲填词，必须建立旋律地图：乐段、乐句、重拍、气口、长音、重复音和情绪走向。

## 外部创作者视角

曲式与风格阶段按问题命中选择 0 到 4 个视角做反向检查。不要为凑格式调用视角；题眼已经能直接推出声音容器时，先完成主风格、曲式、BPM 和纯音乐 style prompt 裁决。

- 周杰伦视角：检查华语流行、R&B、Rap、国风或电子元素是否融合成可唱结构，而不是风格拼贴。
- Max Martin 视角：检查副歌出现位置、重复策略、预副歌蓄力和 hook space 是否服务复唱。
- Quincy Jones 视角：检查鼓、贝斯、和声、乐器层次和主唱空间是否各司其职。
- Hans Zimmer 视角：检查动机、堆叠、能量曲线和段落推进是否有电影感，但避免宣传片式宏大。
- FINNEAS 视角：检查是否可以用更少元素、更近人声和更多留白制造现代贴耳感。
- Brian Eno 视角：当作品需要电子、氛围或空间感时，检查循环、声场和微小变化是否服务歌曲推进。
- Rick Rubin 视角：检查是否有过度编曲、过度情绪词或不必要的风格装饰。

最终 style prompt 只能写具体声音特征，不把人物名字写成平台投喂词。

外部创作者视角只做内部制作检查，不单独强制输出完整视角调用卡。确实影响了主风格、BPM、曲式结构、hook space、乐器层次或声场裁决时，只折叠进“为什么选这个风格 / 为什么不选其他风格”：

```text
调用视角：哪个视角修正了哪个声音容器判断，具体改变了主风格、BPM、曲式、hook space、乐器层次或声场哪一项。
```

如果调用视角没有导致主风格裁决、BPM、曲式结构、hook space、乐器层次、声场或避免项发生具体变化，必须重新做曲式与风格判断。

### 声音容器裁决优先输出硬门

本阶段的主产物是“这首歌应该装进什么声音容器”，不是制作视角展示。用户可见输出必须先给可执行的曲式与风格方案，再给理由。

```text
1. 主风格与辅助风格：明确主导和局部辅助，不平均混合。
2. 声音容器判断：这个题眼需要贴耳、叙事、爆发、反抗、冷感循环、国风命运感还是其他容器。
3. BPM 与 groove：
4. 基础曲式模板与曲式结构：
5. 副歌核心句位置、hook space 和重复 / 对比设计：
6. 纯音乐 style prompt：英文、具体、留人声空间、不写具体人声画像。
7. 纯 BGM / 短剧配乐的 Custom Lyrics：无歌词曲式结构，控制进入、铺垫、断点、留白和收尾。
8. 编曲取舍与禁用写法：
9. 后续填词空间：
10. 简短理由：为什么选这个风格，为什么不选其他常见风格。
```

如果输出里先出现一大段视角调用、理论结构或风格百科，而主风格、BPM、曲式和 style prompt 在后面才出现，判为输出失败。

## 关键规则

- 这是先曲后词第一阶段，但不脱离已确认的题眼。
- 曲式要框住核心情感和副歌核心句。
- 纯音乐 style prompt 不写具体人声画像。
- 纯 BGM / 短剧配乐必须额外输出“Lyrics / Custom Lyrics 输入框内容”：不写歌词正文，写无歌词曲式结构和分段控制。
- 可以写 hook space、vocal pocket、leave room for lead vocal。
- 风格提示词可用英文，说明和判断用中文。
- 必须说明 Verse、Pre-Chorus、Chorus、Bridge、Outro 各自的功能。
- 必须说明选择哪一种基础曲式模板，以及为什么适合当前题眼和传播目标。
- 必须说明是否使用三幕式、五幕剧、八序列 / 英雄之旅或反转阶梯：Verse 负责建置什么，Pre / Verse 2 推进什么，Bridge 是否承担反转，Final Chorus 如何带着新心境加重。
- 必须说明结构里的重复与对比：哪些段落重复 Hook，哪些段落制造变化。
- 必须说明核心句前哪里留白，哪里让位给人声。
- 必须具体到细分风格、groove、BPM、乐器角色、空间质感和动态弧线。

## 风格裁决

- 风格不是由曲式单独决定。主歌 / 预副歌 / 副歌这套通用曲式可以承载抒情流行、国风、民谣、说唱、R&B、摇滚和电子；真正决定作词风格的是题材、意象体系和语言语感。
- 流行适合副歌短、准、可复唱的情绪出口。
- 民谣适合生活叙事和近人声，但不能默认承包所有现实题材。
- Rap / Hip-Hop 适合态度、反击、社会观察和高密度表达。
- R&B 适合贴耳、停顿、重复变体和私密情绪。
- 摇滚适合宣泄、反抗、强动词和舞台爆发。
- 电子适合冷感、循环、切片、身体节奏和声音单位。
- 国风 / 古风适合命运感、凝练意象和统一语体，禁止符号堆砌。
- 励志 / 正能量适合成长、追梦、家国、毕业、晚会和官方传播，但必须有具体阻力和代价，不能只有口号。
- 复古 / 港风 / 怀旧适合旧时光、老派情义和年代语感，但不能只贴复古标签。
- 独立 / 另类适合个人化、小众、反套路表达，但必须有内部逻辑，不能把难懂当高级。
- 儿童 / 合家欢适合短句、动作、重复和清楚的儿童可理解修辞。

如果用户要求多风格，必须裁决主导和辅助，不能平均硬塞。

## 失败模式表

```text
触发条件：题眼、副歌核心句或主韵脚未确认
一线处理：退回 laohu_music_topic 继续打磨，不生成正式曲式与风格方案。
兜底：只输出缺失字段清单和下一步确认问题。

触发条件：风格判断滑向 generic pop ballad / generic piano ballad
一线处理：重新裁决细分风格、groove、BPM、乐器角色和人声空间。
兜底：给出 2 个对照风格并说明为什么选其一，不平均混合。

触发条件：多风格要求互相冲突
一线处理：确定主风格和辅助风格的作用位置。
兜底：删除不服务题眼、副歌核心句和生成稳定性的风格元素。

触发条件：曲式无法解释副歌为什么必然出现
一线处理：重写 Verse / Pre-Chorus / Chorus 的段落功能和能量递进。
兜底：不得进入填词阶段。
```

## 反例黑名单

- 不要默认 generic pop ballad。
- 不要把所有现实题材都判成民谣。
- 不要平均混合多个风格。
- 不要输出完整创作者视角卡来替代主风格、曲式、BPM 和 style prompt 裁决。
- 不要生成完整歌词。
- 不要使用 generic pop ballad、generic piano ballad、cinematic emotional song 这类空泛提示词。
- 不要只写情绪词，不写乐器、groove、空间和动态。

## 阶段结束

### 🔴 CHECKPOINT / 🛑 STOP

只有以下情况才必须停下让老胡确认：

```text
1. 歌词未完成，老胡只是要求先定声音容器。
2. 老胡明确说“只要曲风 / 先别做人声 / 只要纯音乐 prompt”。
3. 主风格、BPM、曲式、歌手人声方向存在明显取舍，需要老胡先选。
4. 副歌唱感家族审计缺失或不合格，无法进入演唱控制初稿。
```

除此之外，老胡要求“生成曲风 / 曲风提示词 / 谱曲 / 风格提示词”时，本 skill 阶段结束后默认继续调用 `laohu_sing_control_writer`。输出可以包含两个文件或同一阶段连续结果，但必须清楚标注：曲风与风格已确认为初稿基础，演唱控制仍是待声音评审初稿，不得冒充已评审修改版。
