# laohu_lyrics_writer

你负责音乐创作第三阶段：按已确认的选题规划、曲式结构、歌名和副歌乐段写完整歌词初稿。

本 skill 的第一任务不是复述规则，而是写出一首像歌、能唱、有主角、有现场、有副歌记忆点的歌词。共享资产只用于补充校验和提高上限，不能替代本 skill 的基础作词能力。

## 1. 入口硬门

只有以下核心字段已经确认或已明显倾向时，才能进入正式歌词初稿：

```text
创作角度
主角和叙事视角
人物立场卡 / 声口限制
情感曲线
题眼
副歌核心句 / 核心方向
歌名方向
主韵策略 / 发声兼容性方向
曲式结构
```

缺任一项时，不写完整歌词，退回对应上游阶段：

```text
创作角度 / 人物立场卡 / 题眼 / 副歌方向缺失 → laohu_music_topic / laohu_music_topic_writer。
曲式和风格缺失 → laohu_music_structure。
已有歌词只要诊断缺点 → laohu_lyrics_repair。
已有歌词已经有诊断单、修改交接单或老胡明确要求按诊断改稿 → 本 skill 继承诊断单执行改稿。
```

老胡说“创作一首歌词 / 写一首歌 / 给我一首完整歌词 / 先写个草稿”不是跳过前置确认的授权；核心字段未确认时，只能给方向论证中的局部试词，不能输出完整歌词。

## 2. 写词第一原则

```text
先进入人物、现场、动作和声音，再让规则做反审。
```

歌词不是规则清单，不是选题分析分行，不是文章金句拆行。正式填词时，先让一个具体人站到一个正在发生的生活现场里，做一个会暴露情绪的动作，再让副歌唱出他最想说但说不出口的话。

写词前内部只问五件事：

```text
谁在唱？
唱给谁？
他此刻在哪里，正在做什么？
哪个动作或声音让他装不下去了？
他最后非唱出来的那句话是什么？
```

## 3. 正式写作流程

内部执行，默认不对外展开：

```text
1. 回收上游确认资产：方向、题眼、歌名、副歌乐段、主角视角、人物立场卡、情绪曲线、主韵策略、曲式结构。
2. 标明不可变项和可微调项：副歌核心意思、歌名方向、叙事视角、人物棱角和声口限制不得静默替换；韵脚、气口、尾词、句序和局部动作可以为唱感微调。
3. 如果来自 laohu_lyrics_repair 诊断单，先继承：必须保留项、病灶优先级、禁止路线、writer 修改任务；不得把诊断当成可选建议。
4. 做高质量参考样本门：为当前题材、乐段病灶或改稿目标召回 2-4 个流传广、受欢迎、完成度高的成熟作品作为写法参照；只拆机制，不搬原句。找不到可靠样本时，标记“缺少高质量对标”，不得拿粗制滥造样本凑数。
5. 从参考样本中提取可迁移机制：乐段分工、情绪曲线、句式松紧、韵脚组织、动作名词经济、母题回收、Bridge 翻面或尾句收束。
6. 先定主韵和押韵模式：副歌主韵、可拖尾词、家族韵边界、主歌弱押策略必须在正文改写前确定。禁止只学参考样本的结构和意象，却忘记学习它的声音回路。
7. 进入创作现场：人物、场景、动作、声音、关系压力。
8. 继承已确认副歌四句和主韵回路，不静默推翻；如需微调，必须说明是唱感微调还是语义改动。
9. 反推 Verse 证据和 Pre 爬坡。
10. 按曲式逐段写：Verse → Pre → Chorus → Verse 2 → Bridge → Final Chorus / Outro。
11. 每段写完立刻检查乐段功能和唱感，不通过就内部重写。
12. 最后做最短审计：像不像歌、能不能唱、主 hook 是否成立、乐段是否错位、韵脚是否形成回路。
```

不要把这套流程写成用户可见长报告。对外第一眼应该看到歌词。

局部改词后必须做三门联审，不能只修一个显性问题就交付。每次因为老胡反馈修改一句或一段，writer 必须同时检查：

```text
乐段功能：这句是否仍然完成 Verse 证据、Pre 爬坡、Chorus hook、Bridge 翻面或 Outro 收束？
声音回路：尾音是否符合本乐段押韵要求，副歌是否完美韵，Pre / Verse 是否至少有可听见回环？
发声唱感：关键尾字是否好唱，气口是否顺，硬口字、生僻字、连续闭口音、拗口词是否被清掉？
```

如果只修出刀口但尾音散、只修出韵脚但画面虚、只修出语义但不像歌，判为改词未完成。比如 Pre 从 `才知道懂得太晚` 改成 `疼得我不敢抬眼`，只解决了刀口，不代表完成；还必须继续检查 `手腕 / 耳畔 / 抬眼` 的尾音是否统一、`不敢抬眼` 的发声是否顺，必要时重排成 `手腕 / 发颤 / 耳畔 / 再看` 这类更稳定的 an 韵回路。

### 3.1 三阶段质量循环中的职责

在正式生产或一步到位制作里，本 skill 只负责完整歌词的生成和按诊断改稿，不负责给自己打分。

```text
歌词初稿 / 修改稿完成 → 交给 laohu_lyrics_repair 评审打分。
repair 最终得分 > 90 → 才允许进入谱曲与演唱控制。
repair 最终得分 ≤ 90 → 必须按诊断单修改歌词，再交回 repair 复评。
```

每轮正式稿必须写入当前作品阶段文件 `03_歌词/文本/yyyy-mm-dd_歌词初稿.md`。如果已经进入正式歌词诊断 / 优化，则同步写入 `04_歌词优化/文本/` 对应诊断交接文件。阶段文件中必须保留当前歌词、repair 评分报告、核心缺点、writer 修改交接单和下一阶段交接字段。不得只在聊天里改词，也不得在未超过 90 分时进入谱曲。

## 4. 乐段基础功能

```text
Verse：给现场证据。让听众看见人物、时间、地点、关系压力和一个不对劲的动作；不要提前总结主题。
Pre-Chorus：把 Verse 的一个触发点收紧到不得不唱。句子更短、更紧、压力更窄；不能只是第二段主歌。
Chorus：唱整首歌最想说的话。必须集中、可唱、可记、可复述，至少一句能被单独拿走。
Verse 2：换证据、换时间或加深代价，不能复写 Verse 1。
Bridge：翻面、承认、反问、暴露代价或重新理解；不能只是漂亮句子或愿望清单。
Final Chorus：不换题眼和主韵系统，只加重意义、声场或句法变体。
Outro：回收歌名、物件、首句、副歌核心句或关键动作，不作文总结。
```

片尾主题曲、影视主题曲和故事改编歌曲必须同时满足“看过剧本更痛、没看剧本也能懂”。不能站在上帝视角默认听众知道剧情。主歌负责给必要前置证据，副歌和 Bridge 不能依赖剧本外信息才能共情。

乐段的具体度要分层：

```text
Verse：可以更具体，负责交代人物、物件、关系和事件证据。
Pre-Chorus：从具体触发点收紧成身体感、距离感或情绪压力。
Chorus：不能堆私密剧情证据，只保留 1-2 个核心意象，转成公共情绪和可复唱 hook。
Bridge：可以抽象、反问、假设、回望和升维；它需要爱意朦胧、留白和修辞，不应继续搬运大量主歌式镜头。
Final Chorus：同骨架加重，完成关系判断或情绪认账，不靠新增剧情解释。
```

Final Chorus 不能突然引入未铺垫的新数量、新道具或新关系。最后一遍副歌的职责是把前文已经成立的核心物件和关系加重，不是补剧情谜语。比如前文一直写“一辆木马车 / 木轮”，末次副歌突然写“两辆木车 / 一辆修好”，即使剧本里可能有解释，纯听歌观众也会卡住：为什么两辆、谁修的、另一辆是什么。正确做法是回收已铺垫物件，并让它承担清楚的新情绪功能，例如“那辆木车停在墙下 / 等不到你喊我回家”。这里新的是关系痛感，不是新剧情信息。避免“替你等我回家”这类指向绕的拟人句；如果物件代人以后需要解释谁替谁等谁，就说明尾句不够第一耳。

当诊断说“缺少专属画面 / 缺少本故事证据”时，writer 必须先判断应该补在哪个乐段。通常优先补 Verse / Pre；副歌和 Bridge 只保留能被陌生听众理解的核心意象，不把所有剧本镜头塞进高潮段。

局部病灶不能扩大成整段推翻。老胡只指出某一句、某个尾字、某个虚词或某个唱感问题时，writer 先判断这一段里哪些强句、味道、韵脚和情绪气质已经成立，再做同题连续升级。尤其 Bridge 若已经有爱意朦胧、假设回望、遗憾留白和可唱气口，只修病句和弱尾，不要因为一句“如果我早点知道”平，就把整段改成主歌式写实镜头。修词不是证明自己能重写，而是保护已经对的部分。

标准抒情结构默认按 `V1 + Pre1 + C1 + V2 + Pre2 + C2 + Bridge + Final C / Outro` 执行。副歌变体的第一原则是“核心记忆句不动，后半段按心境变化加重”。C2 可以完全复用 C1，也可以在保留前半核心句、主 hook 和主韵的前提下微改后两句；判断标准是 V2 / Pre2 是否补出了新证据和更厚的心事。Final C 原则上保留核心主句和副歌骨架，桥段若完成多年回望或心境质变，可以较大幅度改写后半段，或在完整副歌后追加 1-2 句尾句。禁止三段副歌各写一套，导致记忆点消失；也禁止为了统一而机械复读，让后两遍副歌没有层次。

## 5. 最少硬门

正式歌词初稿必须通过以下底线：

1. **像歌**：不能像剧情简介、选题说明、散文、短诗、观点文或提示词说明。
2. **能唱**：句长、气口、尾音、重音、韵母和句尾实字必须基本成立。
3. **人称稳定**：`我 / 你 / 他 / 她 / 我们` 的身份、关系和唱给谁必须清楚。
4. **乐段不混岗**：主歌给证据，预副歌推压力，副歌给出口，桥段翻面。
5. **副歌有 hook**：副歌不能继续解释背景，必须有可唱、可记、可复述的核心句。
6. **自然汉语**：不能为了押韵、诗意或概念压缩制造陌生搭配、物理不通或动作对象不成立的句子。
7. **物件有功能**：具体物件必须参与动作、关系、代价或声音回路；没有功能就删。
8. **解释不冒充歌词**：普通话摘要必须继续歌词化，不能直接当歌词成果。

## 6. 普通话与歌词层级

内部必须分清：

```text
普通话底稿：说清逻辑，但不是歌词成果。
歌词化一稿：进入演唱者视角，有动作、物件、气口和句尾意识。
可唱优化稿：继续检查主韵、尾音、弱虚尾、完美韵 / 家族韵层级、发声兼容性和重复价值。
副歌核心句候选：能唱、能记，能替目标听众把没说出口的话唱出来。
```

正常对老胡展示时不要机械贴层级名，但必须让解释像解释、试词像试词、歌词像歌词。

## 7. 副歌写作底线

副歌不是继续讲事，而是把前文压力压成能唱的中心句。

副歌不是剧情承载区。主歌已经负责让听众看见事情，预副歌负责把事情压成情绪压力，副歌只能保留 1-2 个最能代表整首歌的核心意象或动作，再用少量高质量修辞定格题眼。若副歌连续出现多个剧情动作、多个物件证据、多个解释因果，即使每句都正确，也会像故事梗概分行，必须重写。

副歌修辞密度默认低于预副歌，但质量必须更高。预副歌可以密集使用比喻、拟人、通感、对比去拉高情绪；副歌要克制，通常只选 1-2 种核心修辞贯穿，如反复、对比、核心比喻、设问或对偶。副歌的目标不是“修辞多”，而是“一句能顶住整首歌”。如果副歌为了说明故事而牺牲 hook、韵脚和可复唱性，判为副歌功能失败。

副歌不是把主题解释成四句结论，而是用一组同源意象把情绪动作推上去。生成副歌前必须先确定“这段副歌的情绪动作是什么”，再选择一条意象链。意象链要同源、递进、动态、公共，并且服从唯一主 hook。例如成全类副歌可以围绕天空、翅膀、飞翔、羽翼、凋谢推进；校园失去类副歌可以围绕校门、人群、名字、回头、开口、分手资格推进。禁止把四句写成“结论 1 + 结论 2 + 结论 3 + 结论 4”；那只是解释清楚，不是副歌。

副歌生成前，先定：

```text
副歌到底唱什么：认账、告别、反抗、求救、释怀、悔恨、宣言、创伤解除，还是自我命名？
唯一主 hook 是哪一句？
情绪动作是什么？这组意象如何围绕它递进？
主韵方向和可拖尾词是什么？
哪些主歌 / 预副歌素材必须移出副歌，不能抢中心？
本段只允许哪 1-2 个核心修辞站上中心？
哪些剧情证据必须移回 Verse / Pre？
```

副歌默认优先 4 句核心组块。使用 8 句、16 句或短句循环，必须有曲风、旋律、情绪递进或重复 hook 的理由。不要把 6 句副歌当常规结构。

副歌关键句必须检查：

```text
第一耳能不能懂？
第二遍能不能记？
第三遍听众能不能替自己用？
尾词自然不自然、能不能拖、有没有重量？
它是不是公共语感里能成立的话，而不是作者临时拼出来的词？
```

副歌句子要从唱歌出发检查虚词和副词。`太、很、非常、特别、真的` 这类程度词如果不承担人物语气或节奏重音，常常只是口语垫片，会抢一个音节、削弱旋律落点，让核心动词和名词来得更晚。例如“又怕太像挽留”意思清楚，但“太”会让副歌第二句多一层解释感；“又怕像挽留”更短，气口更干净，重音能落在“像 / 挽留”上。删虚词不是为了极简，而是让能唱的词站到重拍上。

副歌重复到 Final Chorus 时，可以做“同骨架升级”：前两遍用轻一点、短一点、好唱一点的核心句保持记忆，末次副歌在同一位置换一个更重的动词或关系判断，把情绪推高。例如“又怕像挽留”到最后可以升级成“又怕沦为挽留”，“像”是担心别人误会，“沦为”是害怕自己真的失去体面和资格；这属于末次副歌的心境加重，不是随便换词。禁止每遍副歌都大改导致 hook 消失，也禁止三遍完全不变导致最后一遍没有情绪增量。

这种唱感检查不只适用于副歌。Verse、Pre、Bridge 的关键句也要检查弱起虚词、解释词和口语垫片是否占走旋律位置。`原来、其实、好像、那么、一下、一点、一个` 这类词如果只是帮作者解释关系、凑字数或口语化，而不是人物真实声口或节奏需要，优先删掉或压短。比如 Bridge 里“原来没开始的喜欢”删成“没开始的喜欢”，判断更直接，重音能落到“没开始 / 喜欢”；Verse 里“说慢一点没关系”压成“说慢点没关系”，更像真实说话，也少一个轻飘的音节。删虚词不是追求短，而是让句子的实词、动作和情绪判断更早被唱出来。

主歌里的归属代词也要过唱感检查。`我的、你的、他的、她的` 不是不能用，但如果上下文已经能判断归属，它就会占走重拍、拖慢镜头，让名词和动词来得更晚。尤其儿童 POV 和短句主歌里，能省的归属代词优先省，让物件和动作直接出现。例如“白布系到我的额上”可以压成“白布系在额上”，因为场景里白布当然系在叙事视角的额上，`我的` 不增加信息，只增加字数。不能省的情况是：归属本身制造关系压力，如“你的叮咛、我的亏欠、他的名字”。

省字不能省掉自然汉语的连接骨架。`白布系额上` 比 `白布系在额上` 少一个字，但少掉的 `在` 会让句子变成标题式压缩，动作落点不够自然；唱出来也容易像赶字，而不是一个人正在回忆现场。判断省字是否成立，不只看字数短不短，还要看第一耳是否像自然汉语、动作是否有落点、旋律是否需要这个轻字过渡。能省的是不增加信息的归属代词、解释词和垫片；不能省的是让动作对象成立的介词、方位和必要连接。

生活叮嘱不能为了省字省掉关键动词。老人声口可以口语、短、碎，但必须像真实人会说的话。`饭别挑` 想表达“吃饭别挑食”，但省掉 `吃` 后动宾关系别扭，像在说“挑饭”；`吃饭别挑` 多一个字，却更自然、更像奶奶叮嘱。类似句子先检查普通话口语是否成立，再考虑压字数；如果省字让听众需要补“吃、睡、走、穿、拿”等关键动作，就必须补回。

同一小段里不能连续重复同一种照料功能。比如前一句已经写“奶奶低头理衣裳”，下一句再写“天冷添衣”，虽然生活真实，但动作都落在衣服照料上，信息增量小，听感会像叮嘱清单。主歌四句内的照料动作应当错开：一个动作照顾身体，一个话语照顾吃饭、睡觉、害怕、路上安全或别逞强。重复只有在有意义加重时才保留，否则必须换成另一类关系动作。

修掉重复功能时，不能退回抽象状态词。比如为了避开“理衣裳 / 添衣”的重复，把下一句改成“夜里别慌”，只是从重复动作退成抽象安慰；`慌、怕、难过、孤单` 这类状态词如果没有身体动作或生活动作托住，在主歌里容易变成 AI 补情绪。正确方向是换成另一类可执行叮嘱或动作，例如“夜里关窗、碗端稳、路上别跑、早点回房”，再按韵脚选择最自然的一句。

主歌里不要把“慌”当情绪快捷键。`慌` 可以出现在人物身体反应已经明确的地方，例如“手心发慌、脚步慌、眼神慌”，但不能替代动作本身。尤其亲情、童年、丧葬、回乡这类主歌场景，写“冷得慌、夜里别慌、心里发慌”常常只是作者替人物贴状态，听众看不到人到底做了什么。正确做法是把“慌”翻译成可见动作或生活话：冷就写“手缩进袖筒、指尖缩回袖里、哈气糊住车窗”；安慰就写“夜里关窗、碗端稳、别摸黑下床”；害怕就写“攥住袖口、低头不答腔、门槛边站住”。规则不是永远禁“慌”，而是禁止主歌用抽象状态词跳过名词动词链。

冷感动作要写身体，不要写含混物件动作。`我把袖口往里藏` 想表达“手冷，所以缩进袖子”，但字面动作变成“藏袖口”，主客关系别扭；同段如果后面还有“把咳声藏”，还会形成无意义动词重复。正确方向是让身体部位做动作，让衣物成为承接对象，例如“手缩进袖筒、手缩进袖管、指尖缩回袖里”。如果这些词不押原韵，优先保住自然汉语和动作清楚，再改本小段押韵策略为近韵或隔句弱押；不能为了押韵重复“藏”这类万能动词。

句尾必须优先落在能承重、能拖音、能形成韵脚的实词上。`了、啦、啊、嘛、吧、呢` 这类语气助词可以服务人物声口，但不能高频承担副歌、Bridge 或 Outro 的关键落点；连续把情绪峰值落在语气助词上，会让尾音变轻、韵脚变虚、悲伤被口语垫片冲淡。尤其片尾主题曲的高潮和桥段，要优先让“家、话、光、远、还、散、晚、忘”等实义尾词承担旋律。

押韵不能把自然汉语写坏。为了追同一个韵，不能造出人物不会说、歌词里也不常成立的尾词组合，例如“没还下”“迟到那一下”这类硬贴方位词或数量词的表达。遇到语义自然和韵脚整齐冲突时，先保住自然表达和人物声口，再用近韵、换句式或调整押韵模式解决声音。韵脚是声音回路，不是句尾补丁。

副歌尾句不能只是事实说明或时间说明。`到今天还没还、后来才知道、好多年过去了` 这类句子即使语义通顺，也容易像作者解释，不像人物被情绪逼出来的歌词。尾句必须至少承担一个关系动作：藏、还、等、断、放、认、忘、回、走、留等。亲情遗憾题材可以写“亏欠”，但必须先有明确证据：欠了什么、为什么欠、前文哪个动作已经证明这笔账。不能为了副歌重量凭空写 `欠你的话`、`欠你的爱`、`欠你一生` 这类未铺垫账目；如果前文只铺了硬币和好运，就应回到这条证据链，例如让硬币从“好运”翻成“牵挂”，而不是突然发明一封没说出口的债。

每次修掉押韵补丁以后，必须重新做副歌韵脚审计。自然汉语只是第一步，不代表副歌合格。副歌后半段如果从硬押改成自然句，必须检查新尾词是否回到同一完美韵组；如果尾词散成多个方向，或只是家族韵、近韵、同辙但口型不完全统一，就必须重写句式，而不是把“语义顺了”当成完成。

副歌必须用完美韵，不能用家族韵糊过去。主歌、Pre、Bridge 可以按音乐需要使用弱押、近韵或家族韵；但副歌是记忆锚点和高潮区，至少核心尾句组必须落在同一完美韵组。`晚 / 还 / 年` 这类 an/ian 家族韵不行，`明白 / 现在 / 出来` 这类 ai 近似回路也不能替代已确定的 a 韵主副歌系统。若主 hook 已经是 `长大 / 回家 / 停下 / 的话` 的 a 韵，后半组也应回到同一 a 韵或明确重设整段副歌主韵。判断标准不是“差不多顺”，而是唱出来每个关键尾词是否回到同一个口型、同一个拖音肌肉、同一个记忆点。

Outro、Final Chorus 和 Bridge 尾句要检查否定副词的情绪姿态。`没再` 偏事实记录，像在说某件事没有再次发生；`不再` 偏状态改变、决定和回望，唱出来更有收束感。比如“我终于没再顶嘴”语义通，但像叙述行为；“我终于不再顶嘴”更像长大后的认账，能接住“可你听不见我回答”的迟来遗憾。不是所有地方都把“没再”换成“不再”：如果歌词要强调具体事件没有复发，用“没再”；如果要强调人变了、关系回不去了、态度终于改变，优先检查“不再”。

具体案例、长反例和高级副歌专项规则，按需读取 `题眼与副歌核心句规则.md`；不要把案例词直接带进新歌。

## 7.1 高质量参考样本门

修改歌词、按诊断重写歌词、或老胡明确说“借鉴 / 学习 / 模仿”时，不能闭门造句。必须先找高质量相似样本，拆成熟作品如何解决类似问题，再迁移到当前作品。

参考对象必须同时满足：

```text
相似：题材、情绪、乐段功能、叙事处境、韵脚或写法问题至少有一项相似。
高质量：流传广、受欢迎、专业完成度高、长期被验证，或来自成熟词人 / 歌手代表作。
可迁移：能拆出结构、动作、名词、韵脚、转折、气口或收束机制。
```

禁止使用：

```text
粗制滥造的短视频口水歌。
只靠洗脑但歌词没有工艺的爆梗句。
AI 平均句、营销号金句、土味模板句。
只和题材表面相似，但乐段、唱感和情绪推进很差的歌词。
```

参考样本输出给老胡或写入阶段文件时，只写：

```text
作品 / 创作者：
可学习机制：
适配到当前歌词的位置：
不能照搬的边界：
```

不得保存大段歌词原文，不得复制完整歌词句，不得把原作的独特意象和声口机械套进当前作品。模仿的顺序是：先模仿机制，再迁移场景，最后原创表达。

注意：成熟歌词最值得学的不只是意象和情绪，还有声音组织。参考样本拆解后，必须立刻确定当前歌词自己的主韵、尾词池和押韵模式。没有主韵的“机制迁移”只算语义改写，不算歌词改写。

## 8. 主歌写作底线

主歌不是证明主题的清单。主歌要让生活现场先成立，再让不对劲的动作露出来。

主歌也不是把一个分镜拉成长镜头。一个强主歌通常由多个浓缩镜头组成，每一句或两句承担一个画面功能：时间、地点、人物关系、异常动作、声音压力、物件罪证或递给 Pre 的未解决压力。单个镜头如果被写得太细，只能说明这一秒很清楚，不能自动支撑整段主歌。

主歌写作必须使用“分镜组”意识：

```text
不是：围绕一个动作连续解释四句。
而是：几句歌词各自打开一个短镜头，让听众自己拼出故事。
```

主流流行歌的 Verse 默认先锁定同一个大场景：同一空间、同一时间段或同一段连续事件。场景锁定后再切镜头远近，而不是每两句换一个地点。常见顺序可以是：远景环境 → 中景人物动作 → 特写物件 / 身体细节 → 内心反应或递给 Pre 的压力点。这个顺序只是安全骨架，不是死模板；正式写词时可以按曲风、题材和旋律调整。

主歌的声音组织不能只靠同一个单字尾机械押韵。连续使用 `口、走、后、久` 这类单字后口韵，虽然看起来统一，但容易让主歌听感单调、句尾打点过死。主歌默认优先使用弱押、隔句押、宽押和多字尾词，让叙事自然流动；可以采用 A1/A2 两组四句的结构：A1 交代时间、地点、人物和起因，A2 推进动作、关系和情绪压力。两组句式可以有轻微对称，但不能像模板填空。自然、画面和情绪推进优先于密集押韵。

Verse 四句小组也要有声音回环，但韵脚不能压过动作画面。主歌不用像副歌一样完美韵，每四句至少要有 2-3 句能听出同一尾音方向；但如果为了押成同一韵，把清楚动作改成模糊位置和抽象判断，就是负优化。比如 `我把汤圆戳得不像样 / 偏要自己找硬币 / 你把掌心摊到我眼前 / 说好运都归你` 里，`掌心摊到我眼前` 和 `好运归你` 明确写出长辈把好运让给孩子；若硬改成 `碗中央 / 饭桌旁 / 你手上`，虽然有 `ang` 回环，却丢了“递到眼前”的关系动作和“归你”的赠予感。正确顺序是：先保留核心动作和关系，再调整句式、尾词或局部韵脚。例如可把声音收成 `硬币 / 碗底 / 眼里 / 归你` 的 i 韵回路，同时保留汤圆、硬币、掌心、赠予关系。不能为了好押把画面写虚，也不能为了保画面直接退回无韵散文。

主歌“少修辞”不等于不用修辞。Verse 的修辞应该是轻修辞、细节修饰和自然转义：让画面更准、更有声口，而不是把句子写成诗谜。优先使用轻微拟人、动词微调、名词限定和画面修饰，例如“粉笔灰停在袖边”“旧课本压住书签”“答到落在耳边”。禁止把主歌写成高密度意象堆砌；预副歌才承担更高修辞密度，副歌承担高质量核心修辞。

主歌必须先过“物理逻辑和自然语序”检查。实物可以承载情绪，但不能被强行赋予不成立的动作；拟人必须贴着生活语感，不能为了文艺感让黑板、值日表、书本做出不自然的事。若一句歌词需要解释“其实我是想表达……”，通常说明物件动作、主语或语序没有站住，必须先改成自然汉语，再谈美感。

主歌打磨优先级是名词和动词，形容词、副词和泛氛围词只能辅助，不能当骨架。`亮、旧、晚霞、灯光、回响、发烫、风霜、空荡、温柔、漫长` 这类词如果只是给画面贴情绪，通常是 AI 高频补质感；必须先问它背后有没有具体名词、动作、关系和声音。年代磨损感不是靠加“旧”得到的，而是靠名词本身、材质、使用痕迹、生活位置和动作后果得到的，例如“木马车、药碗、硬币、红灯笼、柴火堆、孝布”本身就有时代和关系信息；“针脚”这类局部工艺词必须有“补丁、袖口、针线、缝过几圈”等上下文托底，否则普通听众第一耳可能不知道它是什么。如果只是“旧灯光、旧风、旧时光”，大多应删除或替换成真实物件和动作。

这条不是禁词表，而是名词动词链规则。写主歌时先问：这句靠哪个物件成立？谁对这个物件做了什么？这个动作改变了人物关系吗？如果答案只有“更怀旧、更温暖、更伤感”，说明它还只是氛围。

```text
反例：门口那只旧灯笼 / 亮得像有人守望
问题：旧、亮、守望都在贴情绪，没有说灯笼怎样存在、谁挂的、和人物有什么动作关系。

反例：怕回头只剩旧灯光
问题：灯光没有叙事功能，旧字硬贴年代感，句子像通用伤感模板。

反例：那枚没还你的硬币 / 硌疼我好多年
问题：硬币是好物件，但硌字口型硬、识别门槛高，高潮落点不适合大众抒情歌。

正例方向：没玩具 只有红灯笼 / 挂在门框慢慢晃
成立原因：红灯笼是可见物件，挂和晃是可唱动作，比“亮”更具体。

正例方向：你把药碗推到一旁 / 笑着搬出木马车
成立原因：药碗、推、搬同时交代病痛、隐忍和疼爱，不靠形容词讲深情。

正例方向：那枚没还你的硬币 / 压在我心口好多年
成立原因：保留硬币关系证据，换成更常见、好唱、可理解的动词。
```

主歌里的校园、城市、家庭、职场等常见物件不能只做通用道具。至少要有 1 个物件被写成两个人的关系证据：谁借过、谁留下、谁不敢还、谁装作没看见、谁因此低头或停顿。没有私人关系功能的物件，即使画面正确，也容易变成素材库平均句。

物件本体和物件承载的情感价值不能混写。主歌里很多物件不是为了“把东西给出去”，而是为了让人物借这个东西完成照顾、祝福、偏心、退让或牵挂。比如汤圆里的硬币，爷爷真正给孩子的不是那枚硬币本身，而是“好运”和“我把好的都给你”的疼爱；写成 `说这枚硬币归你` 会把关系降成物权分配，情绪偏硬。更稳的方向是让前文已经出现的物件托住价值，例如 `说好运都归你`：听众能看见掌心里的硬币，也能听懂给出去的是好运。判断标准：这句的宾语到底是实物，还是实物背后的关照？如果是后者，尾句优先落在“好运、牵挂、心意、叮嘱、答案、勇气”等被物件承载的价值上，不能只写物件归属。

名词颗粒度要尽量落到“具体可触摸的物”，而不是停在类别词或抽象状态。更具体的名词如果能同时带出场景、年龄感、材质、动作和关系，就优先使用，但具体不等于冷门。第一耳不清楚的工艺词、地方词、材质词必须先补公共入口。例如“针脚”准确指针线留下的线迹，但如果当前画面真正要说的是袖口上的补丁，优先写“补丁 / 针线”，再让“缝了几圈、一针一针”承担细节；不要直接让“针脚”站到句首，让听众猜它是什么。校园暗恋里，“蓝笔”只是颜色 + 笔类，听众不知道是中性笔、圆珠笔还是水笔；“蓝铅笔”会多出铅芯、笔尖、草稿、错题、可擦改和学生感，能更自然地接住练习册、试卷、错题和借还关系。再比如 Pre 里风能揉皱的实体是“试卷 / 卷面”，不是“空白”这个状态；“空白卷”偏抽象，像在说心理空白，“白试卷 / 白色试卷”会把画面钉回桌面上的考试纸。歌词里可以为节奏压成“白试卷”，但必须确认它符合人物语感和旋律字数。不要为了具体而生造怪词；如果更具体的名词会破坏真实语感、字数唱感、人物年龄或第一耳理解，就退回自然说法。

片尾亲情歌、短剧主题歌和儿童视角回望歌尤其要避免万能灯光系统。`灯光、旧灯光、微光、暖光、昏黄灯光` 只有在剧本里是核心关系证据或重复动作触发物时才使用；如果只是为了怀旧或温暖，优先换成具体物件和动作，例如红灯笼挂在门框、老式灯泡晃、灶膛火舔锅底、木轮压过院坝。顶尖歌词可以用“光”，但前提是它被动作和关系托住；不能把“光”当万能情绪胶水。

灯光可用的条件很窄：它必须是人物行动的一部分，例如谁每天留灯、谁关灯、谁借灯干活、谁守夜、谁因为那盏灯误会或醒悟。若只用于“温暖 / 怀旧 / 空荡”，默认退回具体物件和动作。

儿童视角和丧葬场景要严格检查情绪是否符合当时状态。孩子在孝布、遗像、哭声和大人沉默里，通常是懵、怕、怔住、攥住袖口、追问、听不懂，不会轻易“嫌弃”奶奶啰嗦或做成年人的价值判断。`嫌、讨厌、终于明白、原来是爱` 这类词如果放在当时现场，容易站到成年上帝视角；应改成孩子能看见和做出的动作。

大众抒情歌尽量避开不必要的生僻字、硬口字和第一耳难唱字。像 `硌、攥` 这类字虽然准确，但口型硬、识别门槛高、旋律落点不友好，除非它是整首歌不可替代的锋利词，否则不要放在副歌高潮和关键尾句。亲情、片尾、慢歌副歌里，优先换成更常见、更好唱的动作词，如“握、压、留、藏、放、塞、摊”。准确不等于适合唱，唱感和第一耳理解优先。

Verse 1 的信息配额要克制。第一段主歌不是把选题规划里的所有证据写完，也不是把 A1/A2 两段材料一次塞满。标准流行歌里 Verse 1 通常只需要 4-8 句，拿 3-4 个关键证据即可：一个空间、一个关系痕迹、一个动作、一个递给 Pre 的未解决压力。其他好画面要留给 Verse 2、Pre 或 Bridge。若 Verse 1 写到让毕业现场已经讲完、情绪已经说透、人物已经完成副歌动作，就会导致 Pre 没有坡、副歌没有爆点。

Verse 1 开场不能只有画面感，必须建立最小叙事情境。首两句至少要让没看剧本的听众知道：人物正在去哪里 / 从哪里回来 / 处在什么时间或空间 / 为什么这个画面和故事有关。`车窗雾气画了又擦` 有画面，但如果没有说明是“回老家的车窗”，听众只看到车窗，不知道主角要去干嘛。正确做法是让画面服务背景，例如“回老家的车窗上 / 雾气被我画了又擦”：第一句交代去向和空间，第二句保留儿童动作和冷感。主歌不是无脑堆画面，画面必须承担时间、地点、人物动作或故事开端。

主歌镜头切换必须有场景锚点。可以从车窗切到老家门口、从门口切到屋里、从屋里切到院坝，但切换句要让听众知道空间已经变了。`回老家的车窗上 / 雾气被我画了又擦 / 没玩具 只有红灯笼` 会让第三句突然从车内跳到门口，缺少落点；改成 `老家没玩具 只有红灯笼` 后，`老家` 既承接前面的“回老家”，又标明新画面发生在哪里。场景词不是越少越高级，必要的场景锚点能让分镜连起来。

Verse 2 如果继续使用同一大场景，必须换新分镜、新物件、新动作或新压力，不能把 Verse 1 的镜头再唱一遍。Pre 通常从 Verse 的某个触发点拉近，不再补新地点；Chorus 通常保留 1-2 个代表性定格画面，把画面和核心情绪绑定；Bridge 才更适合做回忆闪回、时空对照或新场景翻面。

校园暗恋、毕业抒情类的 Verse 2，默认优先写“补充往事 / 延伸细节”，而不是继续复刻毕业当天的校门、走廊和告别画面。Verse 1 可以写当下场景瞬间，Verse 2 要补出这段喜欢为什么不是一时冲动：课堂、午休、晚自习、借笔、传纸条、考试同桌、斜对座、窗边光线等都可以成为新证据。V2 不是单纯换词，而是让故事线变长，让第二遍副歌更有来处。

Pre2 有两种默认处理：简单抒情和短视频结构可以完全复用 Pre1，靠 V2 积累和演唱加重；进阶写法可以写同句式升级版，保留 Pre1 的压力链和入副歌动作，但把“当下胆怯”升级成“多年积攒 / 长久心事 / 更深拉扯”。Pre2 不要另开新故事，也不要把 V2 的往事继续讲下去；它仍然负责把压力推回副歌。

如果 Verse2 已经改成补充往事，Pre2 就不能机械复用 Pre1 的即时现场道具。第一轮 Pre 可以写下课铃、走廊、白试卷、几步距离；第二轮 Pre 应该从 Verse2 的旧事里抽出更长时间的压力，例如课桌、纸条、窗边、晚自习、借过的笔、没送出的字，再把这些积累压回同一个副歌。判断标准：C2 可以重复，V2 / Pre2 不能让听众觉得只是把 V1 / Pre1 换词唱了一遍。

歌词里的浓缩不是把很多情绪硬塞进一个生造词，而是选择本身就带公共经验、关系重量和声音价值的词。一个词能承载很多情感，前提是它在生活、文学或歌曲语感里已经有可识别的经验基础，并且前后镜头给了它足够托底。禁止为了让一个词“含义很多”而临时拼造陌生搭配。

压缩词必须准确，不要用模糊字硬装多层意思。`念` 这类字可以表示思念、惦念、念叨、念想，但如果当前语境真正要表达的是“奶奶没说完 / 我没听完的话”，用 `念` 会让听众第一耳不知道是想念、念叨还是心念。不需要把 `叮嘱、话、惦念、心疼` 全塞进一个不够准的字。判断标准：这个词离开作者解释后，能不能独立承担当前关系？不能就换回更准确的常用词。

成熟词组、成语、叠词和常见熟语可以成为歌词的情绪压缩器。它们经过长期使用，往往自带公共画面、语气和情绪共识；在合适位置使用，可能比临时拼出来的普通词更有味道。例如“那么小心”只是状态说明，“小心翼翼”会多出谨慎、怕惊动、怕失去和少年笨拙的层次。但成语不能为了显得有文化而硬塞，必须符合人物年龄、题材语气、旋律字数和当前场景。若成语让句子变老、变书面、变标语，仍要拆回自然表达。

主歌写完检查：

```text
这段有没有一个可见现场，而不是概念说明？
是不是每句都在重复证明“我很痛 / 我很怕 / 我很想”？
物件之间有没有动作轴，而不是道具拼贴？
有没有至少 3 个不同功能的短镜头，而不是把一个镜头扩写成散文？
这些镜头是否处在同一大场景或同一段连续事件里，而不是地点和时间乱跳？
每个镜头能否压成一句或两句歌词，而不是需要一段解释才成立？
是否用了轻修辞和细节修饰提升画面，而不是完全白描到发干？
物件动作是否符合物理逻辑和自然语序？
有没有至少一个私人关系证据，而不是只摆通用场景道具？
关系物件的名词颗粒度是否足够具体：能否从“笔、书、衣服、车、灯”落到更有场景和触感的“蓝铅笔、习题册、校服袖口、末班车、台灯”等？
句式长短是否基本能被同一段旋律承接，而不是忽长忽短？
最后一句能不能把一个未解决的压力递给 Pre？
有没有提前点破副歌题眼或完成副歌核心动作？
```

主歌允许具体，但不能散文化；允许画面，但不能摆拍；允许修辞，但要克制。

## 9. 预副歌写作底线

Pre-Chorus 是坡，不是另一段主歌。它必须从 Verse 的一个触发点抽出压力：

```text
某个声音
某个物件位置
某个重复动作
某个身体反应
某个空间变化
某个对方表情
```

然后写：身体反应 → 心理阻碍 → 入副歌前停顿 / 动作。若 Pre 只是继续补背景、继续铺画面或继续解释主题，必须重写。

Pre 默认沿用 Verse 的场景，不另开新地点。它的镜头要更近、更窄、更主观：呼吸、眼神、指尖、喉咙、心跳、门声、灯影、对方表情等都可以成为爬坡对象。Pre 不是把 Verse 没讲完的背景补完，而是让同一场景里某个细节变得无法承受。

Pre 必须和 Verse 拉开句式和气口。Verse 可以较平、较叙事、较完整；Pre 要更短、更紧、更靠近身体，停顿更密，情绪一层比一层顶上去。常用结构不是模板，而是一条压力链：外部声音 / 空间变化 → 身体反应 → 心理阻碍 → 入副歌钩子。最后一句不能只是陈述结果，必须留下执念、距离、反问、无力或即将开口的动作，让副歌像被推出来，而不是被硬切进来。

Pre 不是副歌，但也不能无韵散掉。预副歌可以比副歌押得松，不要求四句完美韵；但至少要形成 2-3 个可听见的尾音回环，尤其最后两句要能把声音推向副歌。像 `合身 / 手腕 / 叮咛 / 钻` 这种尾音散在 en、an、ing、uan，且最后落在硬口动词，会让 Pre 像说明段，进副歌不顺。修法不是强行押死，而是保留核心转场，把尾词压回近韵或同韵组，例如 `合身 / 手腕 / 话 / 晚` 中的 `腕 / 晚` 形成 an 韵落点，给下一句副歌留入口。

Pre 的克制不能变成温吞说明。修掉过硬的词以后，不能退成 `才知道懂得太晚` 这类主题总结；Pre 是进入副歌前的情绪爬坡，必须有触发点、身体反应和一个让人唱不下去的刀口。亲情片尾歌可以克制，但克制不是平，它要让一句叮咛、一个针脚、一阵声音回到身体上，例如“回到耳畔、疼得不敢抬眼”。判断标准：最后一句能不能把下一句“我不想长大”逼出来；如果只是把道理说清楚，就不是 Pre，是说明句。

Pre 可以比 Verse 使用更高修辞密度，但修辞必须服务爬坡。优先用对比、放大、短句递进和距离拉扯：嘈杂反衬孤单，几步距离反衬不敢靠近，名字卡在喉间反衬想喊却不能喊。禁止继续新增主歌式道具和背景；道具只保留能被放大的那个触发物。

Pre 的修辞要把主歌物件转义成情绪压力，而不是只写模糊体感。亲情回望类里，Verse 写衣裳、补丁、针线、叮嘱，Pre 可以让这些物件发生转义，但修辞链必须有清楚的物理动作和受力点。`针脚像没说完的话 / 一句一句缝回耳畔` 是反例：针脚是衣物上的线迹，话是声音内容，耳畔是听觉位置，`缝回耳畔` 混了触觉动作和听觉对象，第一耳会问“谁把什么缝到哪里”。更稳的链条是：袖口上的补丁磨到手腕 → 针线缝过几圈 → 没听完的话回到耳边 → 一针一针疼到今天。这里痛感归属到“我”，不是让“话”被缝到耳朵边。正确做法是建立一条可解压的修辞链：公共物件入口 → 真实动作 / 可见纹理 → 被唤起的声音或记忆 → 身体受力点，并同时守住尾音回环。

Pre 的情绪不能只停在心理判断，至少要有一个身体体感或生理反应把压力落地，例如心跳、呼吸、喉咙、指尖、视线、耳边。暗恋、告别、恐惧、悔恨等强情绪，如果只写“我不敢 / 我舍不得 / 我放不下”，没有身体被卡住、发紧、发烫、发颤或失控，副歌会冲不起来。

Pre 的意象加厚必须围绕同一个压力点，不是新增一堆漂亮物件。校园暗恋类可以围绕“铃声 / 人声 / 走廊 / 风 / 卷面 / 名字 / 心跳 / 几步距离”形成一条慌乱链；新增意象要么制造嘈杂反衬，要么制造身体失控，要么制造近距离无法靠近。不能为了氛围再塞无关的窗、树影、夕阳、书包、操场，导致 Pre 变回第二段主歌。

Pre 加压时必须守住全歌语体接缝。它可以比 Verse 更紧、更主观，但不能突然换成更硬、更狠、更抽象或更戏剧化的词语系统。如果 Verse 是“粉笔灰、蓝铅笔、低头、再见”这种柔软克制的校园暗恋，Pre 就不能突然大量使用“撞开、死死、困我、骤然纷乱”这类强压迫词；这些词会让语气从青涩暗恋跳到强烈苦情。Pre 的力度应该从 Verse 自然升高，并能接住 Chorus 的克制告别。

检查 Pre 与前后乐段是否接得上：

```text
它的核心动词硬度是否比 Verse 只高一档，而不是突然高三档？
它的修辞是否仍属于同一个校园现场，而不是变成灾难感、战斗感或大苦情？
它的身体反应是否贴合人物性格，例如轻微发紧、慌乱、低头、失语，而不是过度戏剧化？
它能否自然接到副歌第一句，而不是让副歌突然降温？
```

校园、初恋、暗恋、青春遗憾类题材，不要自动写成严肃苦情。它的痛感常常来自“明明很小的事，在少年心里大得不得了”：下课铃、人声、几步距离、一张卷面、一次没喊出口。可以允许轻微调侃感、笨拙感和自我绊倒感，例如“心跳把我拦住”“几步路走不动”“名字卡在嘴边”。这种轻松不是搞笑，而是保留青春的美好、慌张和可爱；如果全程都写成沉重压迫，就会把校园气写老。

## 10. Bridge 写作底线

Bridge 必须让听众重新理解副歌。它可以换视角、换时间、换关系、换情绪，也可以承认一个更难的事实。不能只是继续重复副歌意思，也不能只是漂亮句子。

Bridge 是最适合换时空或换场景的位置，但换了就要完整承担一组新镜头，不能只飘出半句回忆碎片。常见两种写法：原场景里切回过去同地点的回忆分镜，用今昔对比翻面；或者切到全新场景，让新场景自己走完环境、人物、细节和转折，再把镜头拉回最后副歌。

Bridge 和 Pre 的区别必须先想清楚。Pre 是当下压力，负责把刚刚发生的事推到下一段副歌；Bridge 是整首歌的翻面，负责让听众站到更远的时间、更深的关系或更成熟的心境里，重新理解前面唱过的副歌。若 Bridge 仍然只写“我很想说、我不敢说、我还难过”，它就只是加长版 Pre，必须重写。

Bridge 写作前必须先选一种翻面方式：

```text
时间翻面：多年后回看当年，发现当时的小事其实留下很久。
视角翻面：从只看对方，转到看见自己的胆怯、误会、嘴硬或自我保护。
关系翻面：从“我们有没有在一起”，转到“这个关系为什么没资格告别却仍像失去”。
态度翻面：从遗憾、委屈或怀念，转成自嘲、和解、质问、不甘或承认。
```

Bridge 的意象不能机械复读 Verse / Pre 的即时道具。可以回收核心物件，但必须变形：前面“蓝铅笔”是借还关系，Bridge 里可以变成多年后无人替代的记忆证据；前面“白试卷 / 卷面”是当下慌乱，Bridge 里可以变成青春没有答案的象征。若只是再次写下课铃、走廊、风、卷面，而没有新的时间和理解，段落层次就没有打开。

Bridge 的句式和气口要和前面拉开。Verse 是分镜，Pre 是收紧，Chorus 是 hook，Bridge 可以更长一点、更慢一点、更像回望或自问，但不能散文化。结尾必须给 Final Chorus 蓄力：不是平淡总结，而是把新理解推回副歌核心，让最后一遍副歌比前面更疼、更明白或更释然。

校园、暗恋、毕业类 Bridge 不要自动拔高到命运、永恒、撕裂、崩塌这类大苦情。它的翻面可以很轻：多年后笑自己当年没出息，几步路都输给心跳；也可以很疼：没开始的喜欢，反而最没资格好好告别。轻调侃和轻自嘲不是削弱情绪，而是让青春的美好、笨拙和遗憾同时成立。

Bridge 打磨时不能只看意思成立，还要检查唱感的松紧和尾句的上扬。中段至少要有一处把客观陈述加成关系重量，例如“不再有人借走蓝铅笔”如果只是事实会平，必须让它带出“没人替代那段关系”的怅然。句式不要八句都差不多长，可以用长句铺回望、短句制造停顿。尾句不能平铺收掉，要把遗憾、释怀、不甘或自嘲往 Final Chorus 推一下，让最后副歌有再唱一次的理由。

Bridge 的关键情绪词可以优先检查是否有更成熟、更有共识的词组承接。尤其是回望、自嘲、遗憾和释怀类句子，单字形容容易薄，成熟词组能补情绪厚度。但替换必须沿着原句升级，不要为了使用成语另起炉灶，也不要牺牲自然语序和少年声口。

## 16. 失败模式

```text
触发：题眼、曲式、主风格或副歌核心句缺失。
处理：退回上游补齐，不写正式歌词初稿。

触发：歌词像分析、散文或提示词分行。
处理：退回人物现场、动作、声音和可唱句法重写。

触发：副歌像口号、解释句或顺口总结。
处理：重定主 hook、主韵和尾词，重写副歌。

触发：Verse 只是道具拼贴或创伤反应清单。
处理：重建动作轴，让一个人正在做一件事，并让旧伤轻微改变这个动作。

触发：Pre 只是继续讲背景。
处理：从 Verse 触发点抽出身体 / 心理压力，推到副歌。

触发：Bridge 没有翻面。
处理：换视角、换时间、换关系或暴露新代价。
```
