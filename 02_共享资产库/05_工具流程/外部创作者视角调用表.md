# 外部创作者视角调用表

本文件用于把外部音乐创作者、作词人、制作人和歌手的公开创作方法，提炼成老胡音乐项目可调用的阶段视角。

使用这些名字时，不是模仿其具体作品、语气、旋律、歌词或人声，也不要求输出“某某风格”。只提取他们对当前阶段有帮助的判断方式：看什么、删什么、放大什么、避免什么。

## 0. 使用边界

- 只能调用“视角”和“检查动作”，不能复刻作品表达。
- 不保存或生成可还原原作的大段歌词。
- 不把名人名字直接写进最终投喂平台的 style prompt，除非老胡明确要求且平台规则允许。
- 普通阶段视角调用最多选 2 到 4 个，避免参照过多导致结果平均。
- 正式“选题角度评审官”例外：从候选池中选 3 到 7 位，必须由执行官汇总取舍，不能平均化合并。
- 如果人物视角互相冲突，以当前作品的题眼、副歌核心句、目标听众和生成可用性为最高裁决。
- 人物视角不是装饰性引用。每次调用后，必须至少改变一个实际产出：方向取舍、题眼表达、副歌句、曲式结构、style prompt、歌词句子、修改卡、演唱控制或复盘结论。

## 0.1 强制调用卡

所有阶段文件必须包含一张简短的“视角调用卡”。如果当前阶段没有这张卡，视为没有真正调用外部创作者视角。

```text
本阶段主任务：
调用视角：
每个视角负责检查什么：
因此改动了什么：
没有采用的视角及原因：
最终裁决：
```

“因此改动了什么”必须写具体，例如：

```text
删掉了一个普通方向。
把副歌核心句从解释句改成可复唱短句。
把 generic ballad 改成带 groove、空间和 hook space 的细分风格。
把关键行演唱从全程爆发改成前近后远。
```

禁止写成：

```text
参考了某某的风格。
整体提升了质感。
更有高级感。
更像大师。
```

## 1.1 选题角度评审官池

选题角度评审官不是普通名人视角。它们专门用来评审 `laohu_music_topic_writer` 给出的三个初稿方向，判断哪个方向更值得进入后续曲式和歌词阶段，以及有没有更刁钻、更精准、更少被看见的角度。

使用原则：

```text
不是随机全请。
每次从池子里选 3-7 位。
至少覆盖：歌词 / 音乐角度、人群洞察、传播钩子、故事 / 文学角度。
评审官只能评方向、题眼、人群、场景、情绪债务和传播入口，不写完整歌词。
```

### 1.1.0 选题角度拆解视角

选题不是一句题眼，也不是一句情绪总结。选题是“用什么角度看待同一件事、同一种关系或同一种情绪”。进入选题候选阶段时，必须优先调用擅长洞察人性、人的具体处境、传播角度、关系本质和社会情绪的人，而不只调用作词人。

选题候选必须先回答：

```text
什么人：
在什么场景：
发生了什么事：
他和谁的关系发生了变化：
他遇到的阻碍是什么：
他做了什么动作：
这首歌替这类人说哪一句话：
这个角度怎么看待这件事：
```

选题角度拆解优先视角：

| 视角 | 更擅长拆什么角度 | 适合生成什么选题候选 |
|---|---|---|
| 梁宁 | 人的具体处境、真实需求、隐性痛点、一个人没说出口的需要 | “这个人表面经历的是一件事，真正难受的是这件事拿走了他习惯的日子” |
| 马东 | 大众表达场景、可讨论性、社交传播、情绪命名 | “这件事为什么值得被很多人拿来讨论、转发、认账” |
| 李诞 | 反常识、自嘲、嘴硬、现代人的荒诞处境 | “看似开心的事为什么让人难受，看似自由的事为什么像被抛下” |
| 张爱玲 | 关系里的冷、狠、细微权力感和人性褶皱 | “关系不是断在大事里，而是断在一个没说出口的小动作里” |
| 蔡康永 | 关系沟通、体面、未说出口的话、迟到的表达 | “这个人不是没有话说，是错过了可以自然说话的身份” |
| 罗大佑 | 时代情绪、群体记忆、个人命运背后的公共经验 | “这不是一个人的毕业，是一代人共同经历的分流仪式” |
| 韩寒 | 青年反叛、失意、嘴硬和轻讽 | “曾经最想逃走的人，真的自由后反而没地方去” |
| 余华 | 普通人命运里的荒诞和钝痛 | “没有戏剧性悲剧，但命运已经轻轻把人分开” |
| MrBeast | 开头钩子、继续听的理由、注意力承诺 | “这个故事开头能不能一句话让人想听下去” |
| 叶茂中 / 华杉 | 冲突定位、超级符号、记忆锚点 | “这个选题有没有一个简单到能被记住的核心冲突或符号” |

使用要求：

```text
每个选题候选必须标明调用了哪个角度拆解视角。
不同候选必须是不同看法，不只是同一故事换人称。
不能平均化合并多个视角；一个候选先让一个主视角成立。
作词人视角可以补题眼和可唱性，但不能替代选题角度拆解。
角度拆解视角是内部找角度用的，不是对外语言。输出给老胡的候选不能保留“用户场景、价值主张、稳定使用场景、心理位置、系统解散”等分析词，必须翻译成老胡文稿里那种具体人、具体事、具体动作和能读出来的口吻。
```

## 3. 阶段执行模板

每次正式进入阶段前，先选本阶段 2 到 4 个视角，写入内部判断，不必全部展示给老胡。

```text
本阶段主任务：
本阶段调用视角：
每个视角负责检查什么：
因此改动了什么：
没有采用的视角及原因：
最终裁决：
```

如果调用视角后发现当前阶段方向错误，必须回到上游修正，不要用名人参照给错误方向润色。

## 4. 阶段硬门

### 4.1 选题题眼

- 没有李宗盛或罗大佑类视角时，必须额外检查“是否只有个人小情绪，没有人群入口”。
- 没有黄伟文或林夕类视角时，必须额外检查“是否只有温柔正确，没有心理锋芒”。
- 没有 Max Martin 类视角时，副歌核心句不得确认，除非另有明确的复唱性检查。

### 4.2 曲式与风格

- 没有 Max Martin 类视角时，必须单独说明副歌 hook space 和重复策略。
- 没有 Quincy Jones / FINNEAS / Rick Rubin 类视角时，必须单独检查编曲是否过满、主唱是否有空间。
- 没有 Hans Zimmer 类视角时，电影感、史诗感、能量堆叠类 prompt 不得直接通过。

### 4.3 填词

- 没有李宗盛类视角时，必须单独检查人味和真实代价。
- 没有林夕 / 黄伟文类视角时，必须单独检查心理矛盾和说话姿态。
- 国风题材没有方文山 / 黄霑 / 许嵩类视角时，不得通过语体和意象检查。

### 4.4 歌词优化

- 没有 Rick Rubin 类视角时，必须先删句再润色。
- 没有 Max Martin 类视角时，副歌优化不能只做文采修饰，必须检查复唱性。
- 没有李宗盛类视角时，不能把“更文雅”当成“更好”。

### 4.5 演唱控制

- 没有陈奕迅 / Billie Eilish / FINNEAS 类视角时，必须单独检查人声距离、咬字、气口和贴耳细节。
- 没有张惠妹 / Adele / 邓紫棋类视角时，释放型作品必须单独检查副歌爆发和长线情绪。
- 没有 Rick Rubin 类视角时，必须检查是否过度加标签、和声或弦乐。

### 4.6 审查复盘

- 复盘必须写清哪些视角真的提升了结果，哪些只是看起来高级但没有改变作品。
- 如果某个视角连续两次误导当前项目，要写入待验证假设，不得继续默认调用。
