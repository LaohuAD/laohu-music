# 新音乐作品创建与归位流程

## 触发条件

当老胡提供一个新灵感，并且明确想写成一首歌，或对话中已经进入正式创作时，创建新作品目录。

## 创建位置

```text
01_作品项目/进行中/yyyy-mm-dd_作品名/
```

作品名不明确时，用灵感核心词命名，后续可重命名。

## 标准目录

```text

00_阶段确认记录.md
```

## 阶段确认

每完成一个阶段，都要在 `00_阶段确认记录.md` 记录：

- 阶段名称。
- 产物文件。
- 老胡是否确认。
- 老胡修改意见。
- 下一步动作。

未确认阶段不能默认推进下一阶段，除非老胡明确说“一步到位”。

“一步到位”只跳过老胡中途确认，不跳过智能体评审。凡是选题评审诊断、歌词优化、演唱控制等要求真实独立 Agent / sub-agent 的阶段，必须开智能体并等待返回，才能进入下一步。

## 作品完成后的飞书归档

当一个作品完成、定稿、最终投喂版确认、发布包装完成，或老胡说“做完一个作品”时，默认把作品归档到固定飞书 Wiki：

```text
https://yau2chbtefp.feishu.cn/wiki/AaAkwdJZAiFff9kd6h7c3QFQnyb?from=from_copylink
```

飞书归档不替代本地作品目录。本地仍是源文件和生成素材主仓库，飞书负责给老胡集中查看、复用和交付。

归档内容至少包括：

- 最终歌词。
- 最终 style prompt。
- controlled lyrics。
- 封面图 / 歌词海报。
- 三阶段最终评分与评审摘要。
- 作品目录路径和关键生成素材路径。
- 归档复盘摘要。

写入飞书多维表格时，`纯歌词（只有歌词）` 字段必须做清洗：

```text
删除所有演唱控制标签。
删除所有段落标签。
所有中文标点、英文标点、括号、引号、顿号、省略号、破折号等标点统一替换为空格。
保留原歌词分行。
同一行连续多个空格压成一个空格。
```

这个字段不是排版欣赏稿，而是后续复制、投喂、分词、字幕和二次处理用的干净歌词文本。带标点会干扰后续处理，因此不能把正式歌词里的逗号、句号、引号原样带入。

除非老胡明确说先别上传，否则作品进入已完成 / 已发布前必须检查飞书归档状态。

## 三阶段文件与评分记录

正式生产或一步到位制作时，每个阶段都必须有作品目录内的结果文件，不能只保存最后的演唱控制文件。

```text
选题规划阶段：
01_选题题眼/文本/yyyy-mm-dd_选题题眼方案.md

作词阶段：
03_歌词/文本/yyyy-mm-dd_歌词初稿.md
如进入正式歌词诊断 / 优化，再写入：
04_歌词优化/文本/yyyy-mm-dd_歌词诊断与writer交接单.md

谱曲与演唱控制阶段：
02_曲式与风格/文本/yyyy-mm-dd_曲式与风格方案.md
05_演唱控制/文本/yyyy-mm-dd_最终style_prompt与演唱控制.md
```

每个阶段文件至少记录：

- 当前 writer 结果。
- repair 评分报告和最终得分。
- 核心缺点诊断。
- writer 修改交接单。
- 是否超过 90 分。
- 是否允许进入下一阶段。
- 下一阶段继承字段。

每次进入 repair 评分节点，评分报告必须同步展示给老胡；文件归档不能替代对话可见。
