## 规则 1：模糊输入不能直接当歌

### 初始问题

当用户只给星座、题材、情绪、关键词、故事片段或抽象观点时，AI 很容易直接写完整歌词，导致“题材像歌，实际没人、没现场、没非唱不可的话”。

### 独立评审结论

这条规则应成立，但不能写成“六项字段表硬填”。硬门拦的是跳过人物化和现场化，不是要求每次外显填表。

### 建议规则

```text
当输入还停留在星座、题材、情绪、关键词、故事片段或抽象观点时，topic writer 不得直接进入完整歌词、不得确认题眼、不得输出正式副歌核心句。

必须先把输入转成可唱的创作现场。内部至少判断六项：
1. 人：这首歌替谁唱。
2. 关系：他和谁之间出了问题，或他在和什么东西对抗。
3. 现场：事情发生在什么时间、地点、生活状态里。
4. 触发动作：哪一个动作、事件、沉默或细节点燃情绪。
5. 代价：这个人因此失去、暴露、承认或再也回不去什么。
6. 不可说出口的话：他最想说但不能直接说出的那句话。

进入方向池前，至少补齐其中四项；但“人”必须存在，“关系或现场”至少存在一项，“触发动作或不可说出口的话”至少存在一项。

如果不足四项，writer 只能输出探索问题或 2-3 个候选假设，不能写完整歌词，不能确认题眼。
```

### 关键边界

- 允许轻量自动假设：输入很轻但方向明显时，writer 可以先补候选假设，并标明“这是先补的创作现场，不是最终确认”。
- 允许灵感瞬间优先：如果输入本身已有强画面、强动作、强声口或一句非唱不可的话，可以先抓瞬间，再反向补人物、关系和代价。
- 六项是内部校验，不是必须展示给老胡的表格。

### 反例

```text
输入：水瓶座女生，独立，自由。
错误输出：她是风一样的人，不为谁停留。
失败点：只有标签和气氛，没有谁在唱、唱给谁、为什么非唱不可。
```

### 正确方向

```text
先补现场：她在朋友局替人善后，恋人却把手机推来追问她的行程。
成立点：水瓶座自由感被转成“亲密关系审批化”的生活冲突。
```

### 待老胡选择

1. 强度 A：拦截级硬门，完整歌词前必须过此门。
2. 强度 B：方向池阶段可自动假设，完整歌词前必须过此门。推荐。
3. 强度 C：仅作为 writer 内部自检，不拦截。

## 规则 2：方向池要给不同的歌，不是同一情绪换标题

### 初始问题

AI 常给多个方向，但只是换标题、换物件、换情绪强度；实际 POV、关系、情绪出口完全一样。

### 独立评审结论

规则成立，但不能只数“差异项”。真正决定是不是另一首歌的，是这首歌最终替谁、把哪种情绪、用什么姿态唱出去。

### 建议规则

```text
选题 writer 输出多个候选方向时，候选之间必须形成真正不同的“歌”，而不是同一情绪的标题变体。

一级差异包括：
主唱 POV、对话对象、核心关系、情绪出口、题材路由。

辅助差异包括：
固定现场、Bridge 翻面、曲风声口。

每个候选方向至少要与其他方向存在两项实质差异，并且其中至少一项必须来自一级差异。只更换标题、物件、形容词、场景装饰、情绪强度或曲风包装，不算不同方向。

同一场景下允许给多个方向，但必须改变 POV、关系判断或情绪出口。
```

### 候选数量建议

- 默认 3 条。
- 原始素材很窄时可给 2 条。
- 素材复杂且确有分叉时最多 4 条。
- 不得为了凑数量输出弱方向。

### 反例

```text
方向 A：雨夜里等一个人。
方向 B：车站里等一个人。
方向 C：旧街里等一个人。
失败点：场景换了，但主唱、关系和情绪出口都还是“等不到的人很难过”。
```

### 正确方向

```text
同一婚礼现场：
A 新娘唱：我终于不是为了被爱才留下。
B 前任唱：我输给的不是别人，是你终于清醒。
C 父亲唱：我把你送出去，才发现你早就长大。
成立点：同一场景，但 POV、关系和情绪出口不同。
```

### 待老胡选择

1. 强度 A：方向池硬门；同质候选直接重做。推荐。
2. 强度 B：同质候选允许保留 1 条，其余要求改写。
3. 强度 C：仅用于评分扣分，不强制重做。

## 规则 3：方向标题、歌名、题眼、副歌核心句可以重合，但不能混岗

### 初始问题

AI 常把一句看似有道理的话同时当方向标题、歌名、题眼、副歌核心句，导致每个位置都没真正过关。

### 独立评审结论

硬门不是“禁止重合”，而是“禁止混岗”。顶尖作品允许歌名、题眼和副歌 hook 高度重合，但那是逐项验证后的结果，不是选题阶段偷懒。

### 建议规则

```text
选题阶段必须分清四种句子：

方向标题句：服务方向比较，负责让不同候选一眼可区分；可以有判断感，但不得直接冒充歌名或副歌终稿。

歌名候选：服务整首歌命名，必须能承接题眼和副歌记忆点；不得只是故事文件名、作文题或漂亮短语。

题眼判断：服务创作总纲，必须回答这首歌替谁唱、卡在什么关系里、最终要唱出什么情绪判断；它不一定原样进入歌词。

副歌核心句候选：服务可唱、可记、可传播，必须接受唱感、尾音、韵脚、复唱和情绪爆发检验；意思正确不等于副歌成立。

同一句可以暂时兼任多个角色，但必须标明主职责，并逐项说明待验证风险。
```

### 顺序建议

```text
方向池阶段：先用方向标题筛方向。
方向选中后：先定题眼判断。
题眼稳定后：再打磨副歌核心句候选。
歌名标题阶段：从题眼和副歌 hook 的共同高压点里提炼歌名。
```

### 反例

```text
一句“她不是舍不得走，是每次道歉都太像真的”
同时被标成方向标题、歌名、题眼和副歌核心句。
失败点：它可以是方向标题或题眼胚胎，但未经过歌名音感、整首命名和副歌唱感验证。
```

### 正确方向

```text
方向标题：她不是舍不得走，是每次道歉都太像真的。
题眼判断：她要看清道歉不是悔改，而是让她留下来的手段。
歌名候选：太像真的 / 别再像真的 / 那次道歉。
副歌核心句候选：另行过唱感、尾音、韵脚和主 hook 检查。
```

### 待老胡选择

1. 强度 A：输出格式硬门，四类句子必须分区。推荐。
2. 强度 B：轻阶段可混合，但立项阶段必须分区。
3. 强度 C：只在评审时检查，不限制 writer 输出。

## 规则 4：先确认情绪触发机制，再建立意象工具库

### 初始问题

AI 常先列雨、灯、车票、月亮、巷口等意象，而不是先拆这个画面为什么让情绪发生。

### 独立评审结论

规则成立，但应从“强现实场景机制”改成“情绪触发机制”。硬门拦的不是没有现实故事，而是只有意象、没有情绪因果。

### 建议规则

```text
选题规划必须先确认情绪触发机制，再建立意象工具库。

情绪触发机制要说明：
这个画面、场景或概念为什么会让情绪发生；
人物被什么关系、身份、承诺、损失、误判、禁忌或现实条件卡住；
哪个动作、物件、声音、时间点或一句话触发情绪转折。

意象可以先作为灵感出现，但不能直接成为主歌证据。只有当它能证明人物处境、关系变化、情绪转折或副歌核心句时，才允许进入主歌证据库。
```

### 特殊题材边界

- 氛围民谣：可弱现实剧情，但必须有心理 / 感官触发链。
- 国风概念曲：可用历史处境、神话秩序、身份伦理、仪式动作作为内部因果。
- 意识流：可画面跳跃，但必须有心理联想链。
- 一瞬间画面可以先于机制成为灵感入口，不能先于机制成为选题结论。

### 反例

```text
方向：旧路灯下，她想起过去。
失败点：路灯只是氛围物件，不知道为什么想起、想起谁、关系如何变化。
```

### 正确方向

```text
方向：路灯每晚自动亮起，只有他再也不会从那条路回来。
成立点：路灯不是氛围，它触发“等待机制失效”的关系证据。
```

### 待老胡选择

1. 强度 A：稳定硬门；没有情绪触发机制不得进入选题规划。推荐。
2. 强度 B：强叙事 / 商业流行硬门，氛围曲放宽。
3. 强度 C：仅作为意象质量评分项。

## 规则 5：歌名要成为整首歌的入口，不一定概括整首歌

### 初始问题

AI 歌名常像故事文件名、作文题或情绪标签。

### 独立评审结论

规则方向正确，但“装下整首歌”不能当硬门。更准确说法是：歌名必须能牵出整首歌，不一定概括整首歌。

### 建议规则

```text
歌名必须从题眼动作中生长出来，不能只命名事件、剧情或情绪标签。

立项阶段生成歌名时，先判断命名重心：
情绪、关系、态度、命运、物件意象，还是副歌核心声音。

再给少量分型候选，并说明每个候选为什么能成为整首歌的入口，以及为什么其他候选不如它。
```

### 执行边界

- 轻阶段只需给 1-3 个方向感歌名。
- 立项阶段执行“题眼动作 → 命名重心 → 分型候选 → 淘汰理由”。
- 每轮默认 3-6 个候选。
- 至少覆盖三类中的两类：情绪命名、关系定性、副歌核心句截取 / 变体。
- 短歌、概念歌、强 hook 歌可以只取小物件、短词或副歌碎片，但必须证明它是全歌入口，不是装饰名词。

### 反例

```text
《她终于离开了那个人》：故事文件名。
《关于成长的代价》：作文题。
《孤独》：裸情绪标签，除非全歌已经给它独特声音。
```

### 正确方向

```text
《不肯变成别人》：关系定性 + 人物态度，能牵出整首歌。
《晴天没修伞》：物件隐喻 + 责任判断，能打开核心情绪。
```

### 待老胡选择

1. 强度 A：立项阶段必须执行完整四步。推荐。
2. 强度 B：只要求命名重心 + 淘汰理由，不强制三类候选。
3. 强度 C：只作为歌名评审标准。

## 规则 6：“继续”不是直接写完整歌词的授权

### 初始问题

用户选择一个方向后，AI 容易静默补齐 POV、题眼、歌名、副歌核心句、曲式、风格，直接写完整歌词。

### 独立评审结论

规则应进入阶段路由拦截级硬门，但不能把真正不可缺的创作核心和方便管理的工具字段混在一起。硬门检查的是“没有它会不会写偏”，不是字段是否漂亮。

### 建议规则

```text
用户选择一个方向，只表示方向确认，不等于授权系统直接进入完整作词。

进入作词前，系统必须先做一次作词前确认门，区分四类内容：

1. 已确认项：用户已经明确选择或上下文已经稳定成立的方向、人物、关系、场景、情绪目标。
2. 系统可默认补齐项：临时歌名、暂定题眼表达、常规曲式、主韵策略、风格范围、主歌证据顺序等执行层方案。
3. 必须显式确认项：会改变主唱 POV、核心关系、价值立场、场景机制、副歌情绪方向的关键判断。
4. 暂不可作词项：缺少主角 / POV / 场景机制 / 核心情绪压力 / 副歌功能方向中任一项，且系统无法从上下文稳定推断。
```

### 真正不可缺的五项

```text
谁唱。
对谁唱。
为什么非唱不可。
主歌证明什么。
副歌爆开什么。
```

歌名、最终题眼句、最终副歌歌词句、具体 BPM 和编曲细节，不作为作词前绝对硬门；它们可以暂定或后置。

### 自动补齐边界

```text
系统可以补“怎么写”，不能私自改“替谁唱、为什么唱、唱到哪里去”。
```

### 反例

```text
用户：就这个方向，继续。
错误：AI 直接写完整歌词，并静默把 POV 从女生自述改成旁观者叙述。
失败点：用户只确认方向，未授权系统替换主唱视角。
```

### 正确方向

```text
我理解你确认的是这个方向。
已确认：主角、核心处境、情绪方向。
我将默认补齐：临时歌名、曲式骨架、主韵方向。
需要你确认：副歌是告别还是反击？POV 是她自己唱还是旁观者替她唱？
```

### 待老胡选择

1. 强度 A：拦截级硬门；缺五项核心不得作词。推荐。
2. 强度 B：一步到位时可自动补齐并进入评审，但必须明示关键假设。
3. 强度 C：只在阶段文件中记录，不阻止作词。

## 规则 7：高频道具不是词库问题，而是选题角度病灶

### 初始问题

AI 经常反复写站台、车牌、账单、旧票、路灯、雨夜、消息框，不只是因为词库俗，而是选题阶段没有找到人物自己的生活逻辑，只能滑回通用伤感模板。

### 独立评审结论

规则成立，但不能写成禁词表。真正要禁的是：通用伤感道具先于人物关系机制出现，并替代人物、关系和压力做主证据。

### 建议规则

```text
选题阶段不得让通用伤感道具先于人物关系机制出现。

任何道具进入主歌证据库前，必须先说明：
1. 它在人物生活系统中的位置；
2. 它触发情绪的具体原因；
3. 它证明的关系压力；
4. 换成普通同类物件后，题眼是否会变弱。

探索阶段可以暂存道具灵感，但方向确认前必须完成证据功能校验。

如果道具只负责制造氛围、伤感感、城市感、离别感，而不能证明人物处境和关系压力，必须删除、降级为背景，或重找场景。
```

### 关键边界

- 不是禁用站台、车牌、账单，而是禁止它们替代人物关系。
- “不可替换”不能理解成数学唯一；更准确是：换掉后关系压力会明显变弱。
- 不能为了避开高频词，硬造冷门道具。低频不等于高级，贴人物、能动作、能证明关系才高级。

### 反例

```text
她站在雨夜站台，看着远去的车牌，手里攥着旧票。
失败点：所有物件都服务离别氛围，没有说明她为什么在这里、车牌为什么刺她、旧票证明什么关系压力。
```

### 正确方向

```text
她每次被伤害后都会买好长途票，对方每次道歉又把她骗回去；这一次她没有退票。
成立点：站台和车票不再是离别氛围，而是反复逃离失败的证据。
```

### 待老胡选择

1. 强度 A：重写级硬门；道具先于关系机制出现，方向必须打回。推荐。
2. 强度 B：允许探索阶段暂存，立项前必须完成证据功能校验。
3. 强度 C：只作为证据库质量评分项。

## 规则 8：选题阶段必须先确认生活压力系统，不能默认都市漂泊系统

### 初始问题

AI 一写遗憾就站台，一写成年就账单，一写离开就车牌，一写孤独就便利店，本质是没先判断人物活在哪套生活里。

### 独立评审结论

规则成立，建议作为硬门。但“生活系统”不能变成题材下拉菜单，核心不是分类，而是人物被哪套现实关系困住。

### 建议规则

```text
选题阶段建立主歌证据库前，必须先确认人物的主要生活压力系统。

生活压力系统不是题材标签，而是人物被现实关系困住的证据来源。

确认时至少回答四个问题：
1. 这个人主要被哪套现实关系困住？
2. 这套关系里，哪些动作、物件、地点、制度或日常细节能证明他的处境？
3. 如果换成站台、账单、车牌、便利店、消息框，是否还能成立？如果能，说明当前证据不够专属。
4. 如果确实使用都市漂泊道具，为什么它是人物命运的一部分，而不是 AI 默认氛围素材？

未确认生活压力系统时，不得默认调用都市离别 / 都市漂泊道具库。
允许主系统 + 副系统叠加，但主歌证据必须优先来自主系统。
```

### 生活系统示例

```text
校园、家庭、职场、病房 / 照护、亲密关系、县城 / 乡镇、漂泊城市、创作职业、女性友谊、亲子、社会结构、国风身份秩序。
```

### 反例

```text
写成年崩溃：默认账单、出租屋、便利店、凌晨两点。
失败点：这些只是成年人的通用背景，没有证明这个人为什么崩溃。
```

### 正确方向

```text
职场系统：他不是怕加班，是发现自己越努力，越像一个可以被替换的名字。
证据库：工牌、群通知、绩效表、撤回的请假申请、深夜会议纪要。
```

### 待老胡选择

1. 强度 A：硬门；未确认生活压力系统，不进入主歌证据库。推荐。
2. 强度 B：强叙事 / 现实题材硬门，氛围曲放宽为自检。
3. 强度 C：作为方向池差异辅助项，不拦截。

## 规则 9：题材证据必须分层，不能用通用氛围物冒充生活证据

### 初始问题

AI 常把离别、贫穷、失恋、漂泊、家庭、婚姻、创伤都写成雨夜、站台、消息框、路灯、旧票。结果不是题材在说话，是素材库在说话。

### 独立评审结论

规则成立，但不能做成道具等级表。不是“站台低级、工牌高级”，而是“没有被题材机制重新解释的常见道具，才低级”。

### 建议规则

```text
选题阶段建立证据库时，必须先区分三类证据：

1. 题材机制证据：没有它，这个题材或处境就不成立。
2. 人物私有证据：只有这个人物会这样处理、保留、逃避或反复触碰。
3. 通用氛围证据：很多伤感题材都能共用的环境、天气、交通、消息、灯光等素材。

方向核心和主歌主证据，优先从前两类产生。

通用氛围证据只有在被题材、人物关系或关键动作重新定义后，才允许升级为核心证据。
如果没有新功能，只能做背景，不能做题眼支撑、主歌主证据或副歌核心来源。
```

### 关键边界

- 站台可以因春运返乡、逃离控制关系、异地最后一次见面而升级为核心证据。
- 过度追求题材专属会让歌变成社会观察笔记；人物私有证据同样重要。
- 列出三栏不等于会写，必须判断哪一个证据能推动情绪和副歌压力。

### 反例

```text
写中年失业，却用雨夜站台开场。
失败点：它没有证明“失业”。听众只知道这个人难过，不知道他为什么难过。
```

### 正确方向

```text
中年失业：他每天照常出门，只是不敢让家里人知道自己已经没班可上。
证据：工牌、打卡记录、楼下长椅、招聘表年龄栏、下班时间才回家的习惯。
```

### 待老胡选择

1. 强度 A：重写级规则；通用氛围证据冒充方向核心，必须重构证据库。推荐。
2. 强度 B：只要求主证据来自前两类，背景可自由使用。
3. 强度 C：作为评审扣分项，不强制重写。

## 规则 10：先定关系 / 处境压力，再决定证据形态

### 初始问题

AI 常先列物件，再硬配情绪。站台、车牌、账单不是从人物关系长出来，而是像短视频封面素材一样被摆在那里。

### 独立评审结论

规则成立，但“压力类型表”只能当判断工具，不能成为固定模板。真正优先级应是：具体人物 > 具体关系 / 处境 > 压力机制 > 证据形态 > 具体物件。

### 建议规则

```text
选题阶段禁止先从物件清单堆氛围。

必须先确定人物处境、关系 / 处境压力和情绪触发机制，再选择能证明这种压力的证据形态。

证据不只包括物件，也包括：
动作、身体痕迹、时间安排、空间距离、金钱流向、语言习惯、被检查的细节、未完成的承诺、反复发生的循环。

一个物件能进入选题，必须通过三问：
1. 没有它，这段关系 / 处境压力还成不成立？
2. 它是在证明人物处境，还是只是在制造氛围？
3. 它能不能换成任意热门道具？如果能随便换，说明它还没长进故事里。
```

### 压力类型只作参考

```text
错过型、亏欠型、消耗型、照护型、阶层 / 现实压迫型、自我背叛型、身份秩序型、成长断裂型、友谊失衡型、亲密审批型。
```

这些类型只能帮助判断证据方向，不能替代具体人物和关系。

### 反例

```text
亏欠题材：先写账单、欠条、未接电话，然后说“我欠你太多”。
失败点：亏欠没有具体行为来源，读者不知道欠的是钱、时间、陪伴、承诺，还是人生选择。
```

### 正确方向

```text
亲密审批型：爱被变成审查，解释成了日常义务。
证据方向：行程截图、定位、聊天记录、被追问的沉默、每次出门前的预先报备。
成立点：重点不是手机，而是亲密关系里出现了审讯结构。
```

### 待老胡选择

1. 强度 A：硬执行顺序；不得先列物件清单。推荐。
2. 强度 B：方向池允许先给画面，立项前必须补压力机制。
3. 强度 C：作为 writer 内部参考工具。

## 规则 11：高频公共意象触发举证门，不做简单禁词表

### 初始问题

如果只说“不要写站台、账单、车牌”，AI 会换成电梯、冰箱、工牌、收据，病还在；但如果不设置检查，高频公共意象又会继续冒充私人生活。

### 独立评审结论

规则成立，适合作为举证门。公共意象可以用，但必须有“人物所有权”：它从这个人的职业、生活半径、关系习惯或冲突机制里自然长出来。

### 建议规则

```text
当选题规划、证据库、主歌证据或副歌支撑中出现以下高频公共意象时，不直接禁用，但必须完成举证检查：

站台、车牌、账单、旧票、路灯、雨夜、便利店、消息框、空杯、烟火、月亮等。

举证四问：
1. 来源必然性：它是不是从人物职业、生活半径、关系习惯、冲突机制里自然长出来的？
2. 人物占有度：把这个意象换到另一首歌、另一段关系里，它还一样成立吗？
3. 动作承载力：它能不能在 Verse 里发生动作，证明关系和压力，而不是只负责“看起来有画面”？
4. 替代竞争力：有没有更贴这个人物生活系统、更能证明关系的证据？如果有，高频意象必须让位，或降级为背景。
```

### 处理方式

```text
四问通过：可以保留，并要求后续歌词把它写成动作证据。
部分通过：只能作为背景，不允许当题眼、主证据或副歌核心支撑。
明显不过：替换为人物生活系统里的具体证据。
```

### 反例

```text
便利店的灯还亮着，消息框却没人回。
失败点：便利店、灯、消息框都是 AI 高频安全牌，情绪成立，但人物不成立。
```

### 正确方向

```text
外卖骑手的爱情：他每次路过她小区都故意少接一单，后来系统派单记录反而成了他还爱过的证据。
成立点：道具不是冷门，而是从人物职业机制里长出来。
```

### 待老胡选择

1. 强度 A：高频意象无人物所有权时，必须重写或降级。推荐。
2. 强度 B：高频意象可保留，但不得做题眼或主证据。
3. 强度 C：只作为歌词阶段修辞 / 意象提醒。

## 规则 12：选题角度必须逼出专属证据，否则方向不够锋利

### 初始问题

有些方向看起来有情绪，但只能自然导出站台、车牌、账单、旧票、路灯、雨夜、消息框等公共道具，说明角度还停在泛情绪层。

### 独立评审结论

规则成立，接近硬门。但要防止误伤公共意象，也要防止 AI 为了“专属”乱造奇怪细节。专属不是冷门，而是这个证据一出现，别人替不了。

### 建议规则

```text
选题方向进入立项前，必须通过“专属证据压力测试”。

测试重点不是禁用通用道具，而是判断这个方向能否自然逼出不可替换的关系证据。

如果一个方向只能导出任何题材都能套用的公共道具，却导不出人物独有动作、关系专属物、题材专属场景、冲突触发细节或带代价的选择，说明选题角度仍停在泛情绪层，不能直接进入作词。

公共道具可以保留，但必须被人物关系改写。

判断标准：
1. 删掉这个证据，方向是否塌掉？
2. 换成另一个人物，细节是否还能原样使用？
3. 它能不能转成可唱句法、情绪动作或副歌核心压力？
```

### 处理方式

```text
泛方向不直接作词。
先重拆人物、关系、职业 / 处境、关键动作、触发事件。
如果仍只能产出通用证据，降级为弱方向或素材池。
方向至少需要逼出 2-4 个专属证据，并且其中至少 1 个能转化为副歌核心压力，才允许进入立项。
```

### 反例

```text
分手后他在站台等她回来。
失败点：站台、等待、错过都是失恋通用模板，看不出两个人有什么不可替换的关系。
```

### 正确方向

```text
她是婚礼跟拍摄影师，拍了太多别人拥抱，自己的离婚证却一直夹在相机包最底层。
成立点：职业场景逼出专属证据；相机包、婚礼现场、离婚证之间有反差和人物命运。
```

### 待老胡选择

1. 强度 A：重写级，接近硬门；只剩通用证据还强行立项，必须打回。推荐。
2. 强度 B：方向池可保留，但不得进入作词，必须先补 2-4 个专属证据。
3. 强度 C：作为方向质量加分项。
