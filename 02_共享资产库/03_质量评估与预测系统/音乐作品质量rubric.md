# 音乐作品质量 Rubric

本 rubric 融合 `cheat-on-content` 的“维度打分 + composite + 预测 + 复盘 + bump”思想，但维度改成老胡音乐项目自己的音乐创作质量维度。

它可以用于：

```text
选题题眼打分
副歌核心句打分
完整歌词打分
style prompt 打分
controlled lyrics 打分
生成结果复盘
发布包装复盘
课程化内容判断
```

## 1. 当前版本

```text
当前版本：v0.1
状态：冷启动先验，尚未经过足够作品校准。
使用方式：先作为质量门，不作为最终绝对公式。
```

## 2. 综合分公式

```text
composite = (TA×1.5 + CH×1.5 + RH×1.5 + IM + LY + ST + VC + GE + PV) / 10.5 × 2.0
```

每个维度 0-5 分，综合分 0-10。

权重说明：

```text
TA 题眼准确度、CH 副歌传播力、RH 韵脚唱感 ×1.5。
因为当前项目多次暴露的问题集中在：方向没压准、副歌弱、韵脚和可唱性不足。
其他维度先等权，后续根据生成和发布复盘再 bump。
```

## 3. 维度定义

### TA — Topic Accuracy / 题眼准确度（权重 ×1.5）

```text
这首歌是否真正抓住老胡想表达的核心，而不是只复述表面题材？
```

评分：

```text
0：只复述主题词，没有明确人群、场景、关系和情绪债务。
3：方向基本对，但题眼还像标题或观点句，不能强力指导整首歌。
5：题眼能决定人群、叙事入口、副歌落点、曲式走向和最终回收。
```

### CH — Chorus Hook / 副歌传播力（权重 ×1.5）

```text
副歌是否短、准、可唱、可记、可复述、可剪成短视频片段？
```

评分：

```text
0：副歌像作文总结、口号或普通 AI 情绪句。
3：有核心意思，但画面、韵脚、重复或传播句不够集中。
5：副歌有明确画面资产、稳定韵脚、可重复 hook，听一次能留下句子。
```

补充硬扣：歌名感 hook 不能冒充副歌核心 hook。若一句只是漂亮、顺口、能当标题或尾声回声，例如“某个意象偏向你 / 照向你 / 等着你”，但没有偏执、认账、质问、宣告、公开立场、不可逆选择或关系判词，CH 最高 3 分。若评审发现旧主 hook 不成立，旧通过分数、旧认可句和已投入修改成本不得作为保留理由，必须按当前规则重评。

### RH — Rhyme & Singability / 韵脚与唱感（权重 ×1.5）

```text
歌词尤其副歌是否先建立主韵辙、押韵模式、句尾词池和气口？
```

评分：

```text
0：韵脚散乱，副歌出辙，句尾不可拖音，AI 生成很容易吞字或断错。
3：局部押韵，但副歌第二组、Final Chorus 或 Bridge 有明显断裂。
5：副歌主韵辙清楚，押韵模式稳定，句尾实字可唱，附带韵脚审计表。
```

### IM — Image System / 画面系统

```text
歌词是否有贯穿全歌的核心画面资产，而不是每段随手换意象？
```

评分：

```text
0：全是概念词，看不见人物、动作、物件。
3：有局部画面，但没有形成贯穿系统。
5：3-7 个核心画面资产反复变形，Verse、Chorus、Bridge、Outro 都能调用。
```

### LY — Lyric Human Trace / 真人痕迹

```text
歌词是否像真实人会唱出来的话，而不是 AI 平均句？
```

评分：

```text
0：正确、顺滑、空泛，像宣传文案。
3：有生活细节，但部分句子仍像说明。
5：有具体处境、动作、犹豫、亏欠、嘴硬、迟疑和真实代价。
```

### ST — Structure & Tension / 结构与张力

```text
Verse、Pre、Chorus、Bridge、Outro 是否互相推进？
```

评分：

```text
0：段落只是同一主题的重复分行。
3：段落功能基本存在，但副歌不是被逼出来的。
5：每段都有心理动作，Pre 必然推向副歌，Bridge 有翻面，Outro 有回收。
```

### VC — Vocal Control Readiness / 演唱控制可用性

```text
歌词和控制标签是否足以指导 AI 音乐平台生成一个稳定版本？
```

评分：

```text
0：只有泛风格词，演唱控制堆标签，核心句没有让位。
3：有 section-level 控制，但关键句声音策略不够清楚。
5：style prompt 具体，controlled lyrics 清楚，hook 前有空间，关键行控制克制有效。
```

### GE — Generation Feasibility / 生成可行性

```text
这套歌词、曲式、style prompt 投喂 AI 音乐平台时，是否容易生成可用结果？
```

评分：

```text
0：过长、韵脚乱、标签冲突、风格泛，生成大概率失败。
3：基本可生成，但可能出现晚会腔、吞字、段落错位或副歌不突出。
5：长度、气口、结构、提示词、人声空间都清楚，失败风险有预案。
```

### PV — Publishing Value / 发布与课程化价值

```text
这首歌是否有发布、切片、评论区引用、课程化复盘和长期样本价值？
```

评分：

```text
0：只能作为一次内部练习，没有可传播句或复盘价值。
3：有发布潜力，但切片句、标题、封面、课程点还不明确。
5：副歌可剪、标题可写、评论区有引用句，失败或成功都能转成案例。
```

## 4. 观点类内容维度的融合方式

`cheat-on-content` 的观点视频 rubric 中，ER、SR、HP、QL、NA、AB、SAT 对老胡音乐仍有价值，但不能原样套用。

映射如下：

```text
ER 情感共鸣 → 老胡音乐 LY / CH / TA
SR 社会议题共振 → 老胡音乐 TA / PV，用于判断观点是否有结构性共鸣
HP 钩子强度 → 老胡音乐 CH / 选题题眼入口
QL 金句密度 → 老胡音乐 CH / PV，但必须转成可唱句，不是文案金句
NA 叙事性 → 老胡音乐 ST
AB 受众广度 → 老胡音乐 PV，但“广”不等于“愿意传播”
SAT 讽刺深度 → 只在讽刺、反讽、观点型歌曲或口播里启用
```

歌词、长文、短视频口播都可能包含观点。遇到观点型歌词或课程化内容时，可以临时追加观点维度：

```text
PO — Point Originality / 观点独特性
SR — Social Resonance / 社会议题共振
QL — Quotable / 可引用句
TS — Topic Shareability / 转发安全性与分享冲动
```

但这些维度是附加诊断，不替代音乐作品主 rubric。

## 6. 阶段门槛

### 6.0 三阶段 90 分自动流转门

以下门槛用于正式生产和一步到位制作的小循环，不替代本文件其他专项评分细则：

```text
选题规划阶段：使用 6.3 歌词选题规划专项量化评分。
作词阶段：使用 6.1 歌词修改专项融合平衡版量化评分。
谱曲与演唱控制阶段：使用 6.2 AI谱曲提示词与分段演唱控制专项量化评分。
```

判定规则：

```text
最终得分 > 90：允许自动进入下一阶段。
最终得分 ≤ 90：不得进入下一阶段，必须带 repair 诊断单打回对应 writer 修改。
同一阶段连续 3 轮仍未 > 90：停止循环，报告最高分、剩余硬伤和需要老胡取舍的问题。
```

可见性规则：

```text
每次评分都必须对老胡展示评分报告、核心缺点、writer 交接单和是否允许进入下一阶段。
评分报告同时写入当前作品阶段文件。
```

注意：下面 0-5 综合分门槛是通用质量判断和复盘预测；三阶段生产循环以本节 100 分专项评分为自动流转门。

```text
选题题眼进入曲式：
TA ≥ 4，CH ≥ 3，IM ≥ 3。

歌词进入演唱控制：
CH ≥ 4，RH ≥ 4，LY ≥ 3，ST ≥ 3。

演唱控制进入生成测试：
VC ≥ 4，GE ≥ 4，RH 不得低于 4。

发布包装进入正式发布：
PV ≥ 4，CH ≥ 4，且至少有 1 个明确切片句。
```

低于门槛时，不要用“后面再修”推进。

## 6.1 歌词修改专项融合平衡版量化评分

本专项用于 `laohu_lyrics_repair` 在歌词诊断、修改前后对比、版本质量判断时打分。它只评歌词文本本身，并且采用“双核心判定”：

```text
1. 顶尖成熟词人普遍存在的写法，不因为简单、直白、通俗、常见而扣分。
2. 只扣 AI 独有的机械化、模板化、缝合式缺陷。
```

底层区别：

```text
风格选择：作者主动直白、主动用普通物象、主动少留白，有场景、私人细节或人物声口支撑。0 扣分。
能力缺陷：AI 被动堆高频意象、全程无私人细节、不会留白也不会侧面烘托、句式强行工整、为押韵扭曲语义。按梯度扣分。
```

因此，晚风、月亮、人海、看、走、想、等、忘、短句、直白抒情都不是原罪。它们只有在大面积模板堆砌、无自主设计、无私人生活证据时才扣分。

打分顺序固定，不能凭整体观感先给总分：

```text
基础分：篇章结构与段落功能 28 + 韵脚与演唱唱感 26 + 情绪表达与叙事逻辑 22 + 意象体系与修辞 14 + 动词名词字词精度 10 = 100
最终得分：基础总分 - AI拟人真实度专项倒扣（0-10）
```

### A. 篇章结构与段落功能（28 分）

```text
乐段职能清晰度 8：主歌补新细节，预副歌过渡爬坡，副歌提炼核心，桥段有反思/反转。V1/V2 只替换物象无叙事增量扣 3-7；修辞配比颠倒或均匀无层次扣 5；桥段复刻副歌无新视角扣 4；副歌脱离主题扣 6。
承上启下过渡 8：段落有意象或情绪缓冲。AI 机械硬切、只靠“但是/可惜”等连接词换场景扣 3-8。
叙事推进逻辑 7：人物行为和情绪符合普通人逻辑。AI 单一模板情绪、无矛盾层次扣 4；现实逻辑硬伤每处扣 2。
收尾设计 5：含蓄留白或直白点题都可满分。只有结尾无设计、循环复制副歌拖沓时扣 3-5。
不扣分：主歌简单、副歌直白、段落简短、主动直白收尾。
硬扣：副歌没有从叙事升成判词、质问、宣告、愿望、认账或公开立场，只是在继续讲动作和画面，乐段职能清晰度最多 5/8，且总分原则上不超过 92。
```

### B. 韵脚与演唱唱感（26 分）

本项在歌词质量里仅次于句义精准、情绪刀口和字词搭配准确性，高于画面修辞和文学余味。判断顺序是：先看这句话该唱的情绪和词义是否准确，再看它能不能自然发声、换气、押韵、落重音，最后才看画面是否漂亮。为了押韵牺牲词义，扣字词和叙事；为了画面牺牲唱感，扣本项。

```text
韵脚规整度 9：语义优先于押韵，段落韵部稳定。为凑韵颠倒语序、扭曲语义每处扣 1，大面积硬凑扣 5；一段内无逻辑频繁跳韵扣 3-9。
咬字声调适配 7：口型、声调和常见词组顺。大量生僻字、书面倒装、文言拼接导致难唱扣 4-7。
句式换气律动 6：有自然气口、语段切分和松紧。每句能按语义拆成 2/3/4 字为主的发声单元，主 hook、韵脚和关系判词落在语段尾或可拖长位置，Verse / Pre / Chorus 气口密度有分层。全篇强制等长、刻意对仗、无真人松弛感扣 2-6；超长无停顿、5 字以上语段连续堆叠、韵脚藏中间、轻字落尾、单字孤立气口、词组被气口切断、连续闭口音或仄声堆无缓冲扣 3-6。
记忆句重复设计 4：副歌有专属核心记忆钩子。重复句照搬网络通用模板扣 2-4。
不扣分：大众宽韵、简单韵字、口语短句、整齐但自然的流行歌句式。
硬扣：歌词结构、情绪和字词均合格，但声韵气口没有稳定呼吸，副歌不能自然复唱，韵脚与演唱唱感最多 20/26，总分原则上不超过 92；多处超长无气口、重音落空、闭口堵嗓、轻字落尾并存时，总分原则上不超过 90。若副歌核心位只靠家族韵 / 宽韵冒充完美韵，且没有旋律回环补偿，韵脚规整度最多 6/9。
```

### C. 情绪表达与叙事逻辑（22 分）

```text
情绪递进曲线 8：有起伏即可，可克制可直白。AI 开篇拉满、全程无落差、流水线伤感扣 4-8。
情绪落地共情 7：两条路线都可满分：物象侧面烘托，或专属私人小事支撑直白倾诉。全篇只有通用意象+抽象“遗憾/难过”扣 3-7。
故事逻辑自洽 7：场景、行为、时空和因果成立。AI 拼接导致时空跳转、行为失真、多处逻辑漏洞扣 2-7。
不扣分：情绪纯粹、故事简单、直白抒情，只要有生活证据。
硬扣：全篇有生活证据但没有情绪刀口，听众只知道发生了什么，却听不到羞耻、不甘、亏欠、被绕过、被困住、被降格、公开偏爱或不可逆决定，情绪表达与叙事逻辑最多 16/22。
```

### D. 意象体系与修辞（14 分）

```text
意象统一与精准 6：意象体系自洽，高频物象少量点缀并搭配专属细节可满分；通用意象占一半但有差异化细节得 4-5；70% 以上依靠晚风/月亮/人海等模板物象得 2-3；全篇模板物象无专属设计得 0-1。风格割裂物象强行同段混搭，每组扣 1.5。
修辞密度与适配 5：修辞随乐段功能分层，主歌少、预副歌上升、副歌集中。修辞均匀平铺、模板比喻每处扣 1；不因为修辞简单或白描叙事扣分。
意象原创陌生化 3：有专属原创物象得 3；少量原创、多数通用得 1-2；完全复用模板得 0。
不扣分：少量使用基础意象、真实小众物件、直白白描。
加分判断：抽象词、虚词和大词不是天然扣分项；宿命、轮回、因果、奈何、为何、偏偏、只求、两清、失格、赤诚、热烈等词，只要有题材和主歌证据托底，可以提升修辞与情绪强度。扣分对象是低负荷抽象词和无证据硬塞大词。
```

### E. 动词名词字词精度（10 分）

```text
动词张力 4：动词不仅要有动作区分，还要有情绪方向。通篇只用“看/走/想”等万能中性动词且无动作分层得 0-1；连续依赖托、递、扶、低头、侧身、让出、藏起等温和生活动作承重，却没有关系判词或不可逆变化，最多 2；少量中性动词但有强情绪词和关系证据支撑得 3-4。
名词与词语承载 3：有具体小载体和私人细节，同时关键名词 / 抽象词有情绪方向。全篇只有公共抽象名词扣 1-3；全篇只有灯、影、笔、袖、伞、桥等中性小物件而没有公共强词点亮，最多 1-2；生造无共识拼接词每个扣 1，3 个以上本项 0 分。
搭配与公共语感 3：常规通俗搭配不扣分，但高潮句必须有成熟词组、强虚词、公共熟语或准确关系判词支撑。AI 强行拼接动宾、重复模板词汇每处扣 1；用语义相近的轻、低、亮、满、白、远等单字替代准确词，或把托住、拿走、长出等转义动词泛化，每处扣 1。
```

### F. AI拟人真实度专项倒扣（最高 -10）

```text
全网高频模板意象大面积堆砌：最多 -4。全篇 70% 以上依靠晚风/月亮/人海等通用模板物象，无自主专属细节。
安全叙事 / 中性词过载：最多 -5。结构完整、画面具体、句子顺，但全篇主要由中性物件和温和动作推进，缺少公共强词、关系判词、情绪虚词和副歌升维。
完全缺失留白烘托能力：最多 -3。全篇无一处景物托情或侧面暗示，只会直白喊情绪；若已有一处有效烘托，视为风格选择，不扣。
无私人专属差异化生活细节：最多 -2。只有公共通用画面，没有独属于故事的记忆载体。
句式机械强制工整对称：最多 -1。全文字数统一、刻意对仗，无自然长短错落。
```

质量等级：

```text
90-100 顶级真人质感词作：无 AI 机器缺陷，私人细节、传唱性和文学性兼顾。
80-89 优质商用成熟词作：轻微 AI 痕迹，无致命模板硬伤，微调即可。
```

## 6.2 AI谱曲提示词与分段演唱控制专项量化评分

本专项用于 `laohu_sing_control_repair` 评审 style prompt、曲风提示词和 controlled lyrics。它只负责找缺点、打分和交接修改任务，不负责输出修改后提示词。

底层判定和歌词评分一致，采用双标尺：

```text
正向标尺：对标职业制作人如何为这首歌词设计曲风、BPM、配器、人声、空间和段落控制。
反向标尺：只惩罚 AI 流水线模板、无脑大众化、无适配、无分段控制、无定制化。
```

关键区分：

```text
不扣分：流行通用曲风、钢琴吉他、基础鼓组、克制编曲、简单和声、动态平缓。
必扣分：完全不结合歌词叙事，提示词空洞，所有乐段复制同一套控制，配器无增减，人声无气口/尾音/hook让位，曲风或速度破坏歌词意境。
```

最终得分：

```text
基础分：模块A 全局风格&编曲提示词 60 + 模块B 分乐段演唱控制文本 40 = 100
最终得分：基础总分 - AI流水线模板专项倒扣（0-10）
```

### A. 全局风格&编曲提示词（60 分）

```text
A1 曲风、BPM、律动、情绪氛围适配 18：
满分要求曲风、速度、拍号、律动和核心氛围贴合歌词内核。基础匹配但细节笼统得 13-17；曲风/速度轻微违和得 6-12；人曲完全割裂得 0-5。无脑套通用 ballad / 固定 72BPM、不按歌词调整，最多扣 6；只有 sad / emotional 等空洞情绪词，每处扣 2。

A2 配器编排、乐器音色精准度 16：
满分要求乐器分层清晰，旋律、节奏、低频、氛围织体各有角色，段落有增减，懂留白。合理但缺少段落增减得 12-15；堆砌或主次不分得 5-11；只写 piano+guitar 无音色、无低频、无织体得 0-4。乐器只写大类不写音色，每项扣 1.5；全曲一套乐器无变化扣 5；冲突混搭每组扣 3。

A3 人声全局参数 14：

A4 混音空间、动态、声场规划 12：
满分要求主歌近、人声前置、副歌声场拓宽、hook 留空间、混响干湿和动态有收有放。完整但缺少段落声场变化得 9-11；只写 reverb 得 3-8；无混音/动态/声场描述得 0-2。全程单一混响、不给 hook 预留空间扣 3。
```

### B. 分乐段演唱控制文本（40 分）

```text

B2 分段人声、呼吸、张力控制 12：

B3 旋律钩子、和声、尾句特殊处理 10：

B4 段落衔接、过渡细节 6：

```

## 6.3 歌词选题规划专项量化评分

本专项用于 `laohu_music_topic_repair` 评审选题方向、选题规划、题眼规划、歌名方向和副歌核心规划。它只负责找缺点、打分和交接修改任务，不负责输出修改后选题规划。

底层判定和歌词、演唱控制评分一致，采用双标尺：

```text
正向标尺：对标成熟词人的选题策划逻辑，判断人物、视角、故事、场景、情绪、乐段、标题和副歌规划是否能支撑一首歌。
反向标尺：只惩罚 AI 流水线批量策划高频出现的模板化、空洞化、同质化、逻辑缺陷。
```

关键区分：

```text
不扣分：选题通俗、场景简单、情绪平缓、故事小、风格克制。
必扣分：策划空洞无落地细节，角度高度同质化，情绪无分层，段落规划功能重叠，视角混乱，标题/副歌核心规划失效。
```

最终得分：

```text
基础分：五大正向模块 100分
最终得分：基础总分 - AI选题模板专项倒扣（0-10）
```

### A. 五大正向模块（100 分）

```text

核心故事逻辑完整度 8：起因-发展-核心矛盾闭环完整且有差异化得 6-8；框架存在但细节缺失得 3-5；只有宽泛情绪无故事线得 0-2。仅笼统写青春暗恋/遗憾，无专属冲突事件，扣 5。

2. 场景与意象体系规划 20：

意象功能规划精准度 7：意象绑定动作、情绪、矛盾且有贯穿逻辑得 5-7；半数无功能得 2-4；只罗列通用物象得 0-1。批量罗列晚风、月亮、人海、路灯等无剧情绑定，扣 4。
画面可视化落地性 6：画面细节充足得 4-6；模糊抽象得 1-3；只有抽象情绪词得 0。全篇无具象画面规划，扣 3。

3. 情绪曲线与乐段结构规划 25：
完整情绪梯度曲线 9：平淡铺垫→压抑积蓄→高潮释放→反思回落完整，且有隐忍、纠结等复合情绪得 7-9；有起伏但单薄得 4-6；全程单一情绪得 0-3。只有纯悲伤/欢喜，无复杂拉扯，扣 5。

歌名/标题规划质量 10：标题凝练承载核心矛盾得 7-10；普通无记忆点得 4-6；冗长宽泛得 0-3。标题只有青春、遗憾等通用情绪词，无专属故事标识，扣 4。
副歌核心钩子规划质量 10：副歌锚定核心冲突、适合重复传唱、区别于主歌叙事得 7-10；钩子模糊得 4-6；副歌和主歌无区分得 0-3。副歌规划为空泛道理总结，无具象痛点，扣 5。
```

以下情况允许提议升级 rubric：

```text
同一类错误连续出现 3 次。
一次生成失败暴露了当前 rubric 完全没有覆盖的维度。
老胡明确指出某个维度是长期规则而不是单次偏好。
发布或评论数据反复证明某个维度被低估或高估。
```

升级前必须写清：

```text
旧公式：
新公式：
变化点：
触发证据：
哪些旧样本需要重评：
可能引入的新风险：
```

不允许：

```text
为了让当前作品看起来合格而临时调低门槛。
只凭一次普通失败就改权重。
把老胡一次审美偏好直接升成全局规则。
```
