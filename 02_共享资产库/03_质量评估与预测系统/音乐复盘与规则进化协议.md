# 音乐复盘与规则进化协议

本文件借鉴 `cheat-on-content` 的 Retro、Observation Lifecycle 和 Bump Validation Protocol，改写为老胡音乐项目的复盘与规则进化机制。

## 1. 复盘不是总结，是清算

复盘必须对照预测或阶段判断，不能只写“效果不错 / 不好”。

```text
预测了什么？
实际发生了什么？
哪些判断被验证？
哪些判断被推翻？
是单次现象，还是跨作品规律？
应该写回哪里？
```

复盘不能把观察直接升级成永久规则。每条观察必须先过五项测试：

```text
真实目标测试：这条反馈真正要解决什么？
事实与逻辑测试：判断是否成立，有无反例，是否过度概括。
适用边界测试：判断适用于所有作品、某类题材 / 曲风 / 平台，还是当前个案。
冲突测试：判断和已有规则是否冲突，是否需要覆盖、降级、迁移或并存标边界。
写入层级测试：判断进入 writer、repair、review、共享资产、质量系统、案例库、当前作品复盘，还是规则进化备忘录。
```

## 2. 复盘对象

```text
AI 生成音频

style prompt 投喂结果
发布数据
评论区反馈

```

## 4. 观察生命周期

```text
单次观察
→ 待验证假设
→ 跨作品观察
→ 规律沉淀
→ 正式规则 / 维度 / skill
```

### 单次观察

只由一次作品、一次生成或一次老胡反馈支持。

处理：

```text
写入当前作品阶段确认记录或 09_归档复盘。
如果可能跨作品复用，进入待验证假设。
不要立刻写成强规则，除非五项测试确认它是明确执行错误或硬质量门缺失。
如果五项测试确认是明确执行错误或硬质量门缺失，当轮写回对应 skill 或流程文件；如果只是上限增强、类型偏好或证据不足，进入共享资产、当前作品复盘或规则进化备忘录。
```

### 待验证假设

有可能跨作品成立，但证据不足。

处理：

```text
写入 02_共享资产库/03_质量评估与预测系统/规则进化备忘录.md。
后续作品主动验证。
```

### 临时执行规则

已经有较强理由，但仍需要 1-3 次创作试用。

处理：

```text
写入规则进化备忘录的临时执行区。
可写入对应流程或 skill 的试用说明，但必须标注验证场景、失败条件和回滚方式。
试用期内不得作为永久硬门压制其他风格。
```

### 跨作品观察

至少两个作品或两个生成样本出现同一模式。

处理：

```text
进入案例经验库。
可以补充到共享资产 md 的方法解释。
暂不一定改正式规则或 skill。
```

### 规律沉淀

多次验证或一次强反例足够明确。

处理：

```text
写入对应共享资产、skill 或核心规则。
从待验证假设里移除。
```

### 争议规则

有用但边界明显，或和其他题材 / 曲风存在冲突。

处理：

```text
放共享资产、类型化经验或案例库。
标清适用场景和不适用场景。
不得进入 writer 基础能力内核。
```

### 淘汰规则

被复盘证明误导创作、造成 AI 味、报告味、唱感失败或风格冲突。

处理：

```text
从当前 skill 硬门或流程文件移除、降级或迁出。
在规则进化备忘录记录淘汰理由和替代规则。
必要时回测受影响旧作品。
```

## 5. Bump 触发条件

允许提议升级 rubric 或规则：

```text
同一类失败连续出现 3 次。
某个评分维度长期高估或低估。
某个缺失维度导致严重误判。
生成结果反复证明某类 style prompt 写法失败。
发布反馈反复证明某类副歌句传播弱。
老胡明确指出某条是长期执行规则，不是单次偏好。
```

不允许：

```text
为了当前作品过关，降低门槛。
只凭一次普通失败改权重。
把单次审美偏好升成通用规则。
为了保留历史，把被推翻的观察继续放在当前规则里。
```

## 6. Bump 必须写清楚

```text
旧规则：
新规则：
变化类型：边际细化 / 结构升级 / 公式调整 / 阶段门新增 / 禁用项新增
触发证据：
适用范围：
不适用范围：
可能副作用：
需要回测的旧作品：
```

## 7. 清算原则

每次规则升级后必须清理：

```text
被新规则吸收的观察，从待验证区删除。
被推翻的观察，从当前规则删除，必要时写入失败案例。
仍未解决的观察，保留为待验证假设。
历史过程写进复盘，不堆在当前规则里。
```

## 8. Blind 信息隔离

如果以后建立盲评分子流程，必须注意：

```text
盲评分只能读当前 rubric 和待评分文本。
不能读生成结果、发布数据、评论反馈、复盘结论。
包含真实表现的数据只放进复盘或 memo，不放进盲评分读取的当前 rubric。
```

当前项目暂不强制实现 hook，但执行时要遵守这个信息隔离原则。
