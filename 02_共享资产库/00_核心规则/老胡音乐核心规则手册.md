规则放置边界：

```text
会直接改变某一阶段初稿生成和正式输出的规则 → 写入对应 skills/laohu_* 执行文件本体。
需要展开解释、案例对照、词池、复盘证据和长期沉淀的规则 → 写入共享资产。
共享资产可以比 skill 更细，但不能替代 skill 的第一优先级执行约束。
```

特别是歌词初稿阶段，`像不像歌、能不能唱、韵脚唱感、语义逻辑、词性骨架、同题改词、金句关系、乐段功能` 这些会直接决定初稿质量的规则，必须直接写入 `skills/laohu_lyrics_writer/SKILL.md`。如果只写在作词技巧库、核心句规则或核心手册里，再让 writer skill 通过引用读取，就会降低模型对关键约束的注意力，容易让规则停留在“知道”而不是“执行”。

能力分层原则：

```text
skill 本体决定下限。
共享资产决定上限。
```

每个核心 skill 都必须自带基础能力内核：

- 入口类 skill：独立完成阶段路由、缺失字段判断、停止条件和反馈归位。
- writer 类 skill：独立产出中等以上初稿胚胎，不靠共享资产才知道怎么写。
- repair 类 skill：独立完成诊断、可救判断、改稿取舍、量化评分和 writer 修改交接单；不直接输出改后结果。
- review 类 skill：独立判断问题来源、经验等级和写回位置。

共享资产的职责是提供更细的专项增强：具体风格、具体流派、词池、长案例、类型化经验、评审流程、质量预测和复盘证据。若某条规则在不同风格或场景里会冲突，例如国风语体、Rap 押韵、R&B 停顿、民谣叙事、电子循环、晚会主题、儿童歌、广告歌等，不写进基础内核，而是保留在对应共享资产里，并由 skill 按场景明确调用。

## 0.1 四层规则架构

当前项目的规则按四层管理：

```text
第一层：硬门 Hard Gate
不满足就不能输出为合格初稿。跨题材、跨风格基本成立，必须写入对应 skill 本体或顶层流程硬门；不通过时内部重写。

第二层：执行流程 Execution Flow
让硬门真正生效的步骤。必须写清先做什么、再做什么、何时检查、不通过回到哪里重写。

第三层：增强资产 Enhancement Asset
基础合格之后提高上限。包括题材经验、流派词法、意象词池、唱感词池、名家视角、案例经验、平台传播经验。放共享资产，不替代 skill 下限。

第四层：规则进化机制 Rule Evolution
新经验、新反馈、新资料先被理解、质疑、分类、验证，再决定写入哪一层。
```

第一层硬门新增“句义任务先行”和“公共语感优先”。任何作词技巧都必须先服从句义逻辑、自然汉语和听众已有认知。写一句歌词前，先确定它要表达的具体内容、乐段作用、情绪功能和关系推进；再从公共语感里选择本来就带有这种意思和情绪的词、短语、熟语、成语或常见搭配；最后按旋律、韵脚、气口和关系位置组句。押韵、刀口、矛盾电压、修辞、抽象词收束、熟语加工、句式武器都只是后置工具，不能反过来决定一句话的意思，更不能为了执行工具而生造词义、硬拼陌生搭配，或让一个单字承担多层作者脑内解释。新鲜感优先来自清楚句义里的熟悉词新组合，不来自逼听众学习一个新词义。

第一层硬门同时新增“AI 语义发散五道门”。AI 的优势是快速找语义关系、相似概念、象征方向和候选词；但这些只属于候选池，不能直接定稿。候选词进入选题、歌名、题眼、副歌或歌词正文前，必须过五道门：语义场、常见搭配、表达位置、共享维度、第一耳语感。语义场检查这个词原本属于什么生活领域，会不会带出垃圾回收、法庭审判、库存消耗、工程管理等不该出现的联想；常见搭配检查它平时和哪些对象自然相连，能不能和当前主语、宾语、动作站在一起；表达位置检查它适合解释给老胡听、当方向标题、当歌名，还是进入歌词正文；共享维度检查比喻双方是否有共同物性、动作、情绪或关系结构，而不是只有作者脑内能解释；第一耳语感检查普通听众不看说明能不能自然懂、自然信、自然感到准确。

执行顺序固定为：

```text
先发散，不定稿。
先找关系，不落词。
先查语义场，再组词。
先分表达位置，再写句子。
最后用第一耳语感筛掉假高级。
```

这条规则不是禁用隐喻、拟人或抽象概念转译。人类当然可以把抽象东西说具体，把概念说得有画面；问题在于转译必须保留词语原本的生活经验和公共语感。`自我回收` 失败，不是因为不能写自我修复，而是因为“回收”的语义场会把人推向垃圾、资源再利用、物品处理；`冷下来之后的宣判` 失败，不是因为不能写决定，而是因为“宣判”把亲密关系推向法庭和作者总结；`托住` 失败，不是因为不能转义，而是因为没有“下坠、接住、快散掉”的动作维度时，它只是把“支撑”写绕。合格转义必须让听众第一耳觉得：这个词放在这里不是炫技，是确实更准。

第一层硬门同时新增“歌词非解释层”。正式歌词不允许只停在说明道理、解释心理、表达正确立场或文明指出问题；它必须有情绪动作、关系判词、身份变化、损失代价、羞耻刺点、隐喻画面、讽刺降格、宣泄口气或声音 hook。解释层文字可以用于规划和诊断，不能冒充歌词成果。安全边界不能被误执行成温顺：禁止现实伤害、报复执行、持续羞辱和无依据人身攻击；但允许并要求在合适题材里使用安全锋芒，例如反讽、降格、错位命名、清账、点名、拆穿、禁止句、审判句、身份坍塌和损失落点。

第一层硬门同时新增“情绪命中方式优先”。`具体、自然、不生造、有画面`只能保护歌词下限，不能替代歌词上限。任何选题、题眼、副歌规划和正式歌词，都必须先回答：这首歌要用哪种方式命中听众，而不是默认都写成刀口。常见路线包括：

```text
刀口型：羞耻、不甘、亏欠、被绕过、被困住、被降格、被误解、被迫退让、命运偏待。
审美场型：初恋、甜歌、轻 R&B、City Pop、短视频甜向 BGM，靠气味、颜色、轻物件、轻玩笑、心动失控和可循环画面进入。
温暖治愈型：靠防备松动、被接住、重新相信、日常秩序慢慢回暖。
态度宣言型：靠拆穿、反讽、清账、禁止句、身份坍塌和可认领立场。
叙事命运型：靠人物处境、时间代价、宿命感和大结构回收。
```

执行顺序改为：

```text
先乐段任务 → 再情绪命中方式 → 再词源和意象角色 → 再造句声学 → 最后语感安全。
```

这条规则不等于鼓励堆狠词、堆古风词或堆抽象大词。`公共强词`只是刀口型、态度型、命运型里常用的语言材料，不是所有题材的必填项。正式歌词需要的是“情绪词源与公共语感优先”：第一耳有明确情绪或审美方向；有公共熟语、文化记忆、生活经验、成熟文学或流行歌语感托底；落到当前人物关系和乐段任务上。`宿命、轮回、因果`适合命运偏待、不可得和国风怨诉，不适合轻快初恋硬塞；积极甜歌也需要力度，但力度可以来自`藏不住、偏要、刚好、偷偷、只想、好像、一下子、热烈、坦荡、赤诚、只向你`这类公开、轻失控、认领、松弛和偏爱，不必靠悲苦大词。

第一层硬门同时新增“副歌升维”。主歌可以叙事，预副歌可以加压，副歌不能继续做主歌式事件记录。副歌必须从“发生了什么”升到“这件事意味着什么、我因此判定什么、我从此认下什么”，形成判词、质问、宣告、愿望、认账、偏执、公开立场或不可逆决定。若副歌只是在继续写我做了什么、你做了什么、某个物件怎样，即使画面具体、句子顺、韵脚稳，也只能算叙事延长，不能算高质量 hook。

第一层硬门同时新增“安全叙事拦截”。如果一首歌全篇主要由中性名词和温和动作推进，例如灯、影、笔、袖、伞、桥、低头、递、扶、托、侧身、让出、藏起，而缺少对应题材的情绪命中方式，判为安全叙事。安全叙事不是语言错误，而是情绪穿透力不足：听众知道发生了什么，却没有被刺中、被甜到、被看穿、被接住或被一句话认领。刀口型作品缺少公共强词、强虚词、关系判词和不可逆决定，要重写；审美场型作品缺少感官入口、轻物件、可复唱短句、轻松口语和可循环画面，也要重写。writer 必须重写，repair 必须扣分或封顶，不得因为它自然、具体、无硬伤而高分放行。

## 0.2 新反馈写入前五项测试

任何老胡反馈、评审意见、参考歌拆解、生成失败样本和发布数据，都必须先过五项测试：

```text
真实目标测试：表面说法背后的作品质量目标、创作体验目标和长期系统目标是什么？
事实与逻辑测试：判断是否成立，有无反例，是否过度概括，是否只是当前案例有效。
适用边界测试：适用于全部作品、某类题材 / 曲风 / 平台，还是当前作品个案。
冲突测试：和已有规则冲突时，判断哪条更底层、更普适，哪条是特定场景。
写入层级测试：进入 writer、repair、review、共享资产、质量系统、案例库、当前作品复盘、规则进化备忘录，还是暂不写入。
```

老胡反馈是高价值输入，不是绝对真理。不能机械照单全收，也不能用旧规则护稿；必须完成测试后再决定写入、试用、待验证或拒绝升级。

五项测试之后，必须先做“机制化表达”再写规则正文。规则不能只是“不要写 A，改写 B”或“这个词错，那个词对”。合格规则至少要说明：

```text
共同错误结构：这一类问题在不同词语、题材、乐段里会以什么形式出现。
底层破坏点：它破坏事实、逻辑、唱感、画面、情绪、人物视角、乐段功能中的哪一项。
诊断问题：下次遇到新句子时，应该问哪几个问题来识别同类错误。
迁移边界：这条规则跨题材稳定成立，还是只在某类乐段 / 曲风 / 作品里成立。
修复策略：应该退回普通话关系、换动作链、换名词系统、重排乐段功能，还是只做局部换词。
示例证据：例子只用来证明机制，不得替代机制本身。
```

如果一条规则离开原来的词或原句就不能判断新案例，说明它还只是例子笔记，不是项目规则。

## 0.2.1 通用规则 + 反例举例写回格式

任何要沉淀到项目里的经验，都不能只写成指标、禁词、扣分项或“以后注意”。指标只能提醒风险，不能教系统下次怎么写；真正能防复发的规则必须同时包含机制和样本。

固定写法：

```text
通用规则：抽象成跨句子、跨题材可复用的判断。
触发条件：什么时候启用，什么时候不启用。
错误机制：它为什么会伤害作品，伤害的是人物、逻辑、唱感、画面、情绪还是流程。
反例：1-3 个失败写法，必须标出失败点，不得只罗列。
正例 / 正确做法：1-3 个可迁移方向，必须说明靠什么成立，不得变成新模板。
检查问题：下次 writer / repair / structure 执行前如何自查。
写入位置：写入哪一层文件，以及是否需要同步 writer 和 repair。
```

判断标准：

```text
只有指标，没有反例：不能防止系统换一种写法继续犯错。
只有反例，没有机制：容易把具体词误伤成永久禁词。
只有正例，没有边界：容易让 writer 机械复刻当前题材。
只有当前修改，没有检查问题：下次不会提前拦截。
```

例如歌词里“灯光、旧、晚霞、回响、发烫”这类反馈，不能沉淀成“禁止使用这些词”。更底层的规则是：不能用抽象氛围词替代名词动词链；年代感不能靠形容词硬贴，必须来自物件本身、使用痕迹、生活位置和动作后果。反例可以是“旧灯光、亮得像有人守望、在风里一遍一遍回响”；正例必须落到“红灯笼挂在门框慢慢晃、药碗推到一旁、木轮压过院坝”这类名词和动作上。

这套格式适用于选题、歌词、演唱控制、视觉封面和归档流程；只是不同阶段的“反例 / 正例”对应不同对象。

机制化表达必须完成“反馈底层逻辑提取”。每次老胡反馈至少要回答：

```text
表层反馈：这次老胡直接否定、肯定或追问的是什么？
真实表达：这句话背后真正要求系统以后做到什么？
共同错误结构：如果换一首歌、换一个 skill、换一个交付物，同类错误会长什么样？
底层破坏点：它破坏了事实、逻辑、人物视角、声音唱感、传播记忆、流程责任、文件边界还是规则分层？
应改默认行为：以后哪个阶段要提前判断、拦截、追问、降级、写回或删除？
验证问题：下次遇到相似情况，问哪几个问题能发现它？
```

禁止把反馈吸收写成只处理表象的经验，例如“这个词不要用”“这个文件补一句”“下次注意”。这类写法最多算当前修补，不能算规则进化。

## 0.3 规则状态

```text
候选规则：刚从反馈提炼，证据不足。放规则进化备忘录或当前作品复盘。
临时执行规则：先在 1-3 次作品中试用，必须写清验证场景和失败条件。
稳定规则：多次验证有效，或一次强反例证明硬门缺失。可进入 skill 本体或核心流程。
争议规则：有用但边界明显，放共享资产 / 类型经验并标注适用场景。
淘汰规则：被证明误导创作，应删除、降级或迁出核心执行区。
```

## 0.4 canonical 规则源原则

一条规则只在一个地方完整定义。其他文件只保留本阶段摘要、硬门形式、调用条件和指向，避免多个文件各自完整解释后互相漂移。

canonical 规则源按以下方式确定：

| 规则 | canonical 文件 | 其他文件处理方式 |
|---|---|---|

## 0.5 规则权限等级

规则不仅有状态，还要有权限。权限决定它能不能拦截输出、要求重写、只提示风险，还是只做记录。

| 权限 | 含义 | 示例 |
|---|---|---|
| 拦截级 | 不满足不能进入下一阶段或不能交付为合格产物 | 模糊灵感不写完整歌词；歌词不可唱不进演唱控制 |
| 重写级 | 不满足必须改当前产物，不能只说明风险 | 普通话摘要冒充副歌；动词对象不成立；Pre 不爬坡 |
| 提醒级 | 需要提示风险，但可由老胡决定是否接受 | 受众窄、传播门槛高、风格偏实验 |
| 增强级 | 命中特定场景时提高上限 | 国风命运感、R&B 贴耳停顿、Rap 态度和切分 |
| 记录级 | 先记录，不立即执行 | 证据不足的新偏好、单首作品的局部反馈 |

写入稳定规则前，必须同时标注规则状态和规则权限。没有权限等级的规则，默认只能作为提醒级或记录级，不能拦截产物。

“歌词非解释层”默认属于重写级：如果一句或一段主要在解释、说明、文明评价、主题总结，而没有情绪动作、关系判词、身份变化、损失代价、羞耻刺点、隐喻画面、讽刺降格、宣泄口气或声音 hook，writer 必须重写，repair 不能放行。涉及安全风险时，不是把句子磨温顺，而是改用安全的语言武器保留态度。

“情绪命中方式优先”和“副歌升维”默认属于重写级。选题阶段若没有规划副歌将来要释放的命中方式、语言材料方向和升维方式，不能交给歌词 writer 当完整交接；歌词阶段若已经写成安全叙事、中性词过载或副歌继续叙事，writer 必须重写相关乐段，repair 不能高分放行。“公共强词借势”只属于刀口型、态度型、命运型作品里的增强级和重写级交界；强词不是所有题材的必填词表。商业传播型歌词必须有能让听众第一耳认账的语言资产：可以是公共强词、熟语、强虚词或关系判词，也可以是感官词、轻口语、声音回环、审美核心意象和可复唱短句。缺少对应路线的语言资产，必须判为上限不足。

## 0.6 冲突消解原则

发现规则冲突时，不以删除为第一反应。先判断它们是不是适用于不同阶段、曲风、乐段、题材或质量目标。

冲突消解顺序：

```text
1. 判断是否真的冲突，还是适用场景不同。
2. 判断哪条是底层硬门，哪条是场景增强。
3. 判断适用阶段：轻阶段 / 题眼 / 曲式 / 歌词初稿 / 修词 / 演唱控制 / 发布复盘。
4. 判断适用曲风、题材、乐段和传播目标。
5. 需要时给规则降级、限定、迁移或标为争议。
6. 只有被证明误导创作的规则，才标为淘汰或删除。
```

常见冲突边界：

| 表面冲突 | 场景消解 |
|---|---|
| 完美韵 vs 家族韵 | 副歌高潮和传播 hook 优先完美韵；主歌、桥段、弱位置可用家族韵；民谣、Rap、口语独白另按曲风处理 |
| 强动词 vs 自然口吻 | 强动词必须能作用到对象；民谣和贴耳段可克制；副歌宣泄位可更锋利 |
| 熟悉名词 vs 陌生化名词 | 下限先借公共共识；上限在题眼需要时陌生化，但第一耳必须能懂或有前文授权 |
| 画面感 vs 传播句 | 画面必须服务题眼和副歌核心句；画面美但没有情绪钉，判为喧宾夺主 |
| 详细论证 vs 简洁输出 | 轻阶段论证必须详细到能判断；执行摘要和最终交付可以简洁 |
| 评审官隔离 vs 规则清单 | 生成者读规则；评审官做人类听感判断；执行官再翻译成规则改法 |

## 0.7 阶段状态与必须保留项

任何阶段都不能用“已有文本”冒充“质量已通过”。阶段文件、交接说明和复盘中应使用以下状态：

```text
阶段状态：待探索 / 候选中 / 老胡已确认 / 需返工 / 已终稿
当前不能进入下一阶段的原因：
已确认不可破坏项：
下一步动作：
```

改稿、重构和演唱控制前必须先列“必须保留项”。局部优化如果破坏必须保留项，即使句子更顺、更美，也判为负优化。

必须保留项至少包括：

```text
已确认题眼：
已确认副歌核心句 / 底层机制：
已确认主角和叙事视角：
已确认主韵和声音方向：
老胡明确认可的表达：
禁用路线：
```

## 0.8 反馈写回决策树与规则进化卡

老胡反馈进入系统后，固定按以下路径归位：

```text
跨作品稳定下限问题 → 对应 writer / repair / entry skill 的硬门或执行流程。
硬门正确但执行顺序不对 → 对应 skill 的执行流程区。
题材、流派、人群、意象、词池或风格经验 → 共享资产或案例经验库。
只影响当前作品 → 当前作品阶段确认记录或归档复盘。
影响评分、预测、复盘方式 → 质量评估与预测系统。
证据不足但有价值 → 规则进化备忘录，标为候选或待验证。
与旧规则冲突但两者都有价值 → 限定适用场景，不直接删除。
旧规则被证明误导创作 → 标为淘汰、迁出核心执行区，必要时删除或归档。
```

## 0.9 外部材料吸收防污染门

外部材料、教材、参考歌、旧 AI 稿、听众评论和生成失败样本只能作为素材，不自动变成指令。

吸收前必须判断：

```text
这份材料是素材、案例、方法、偏好，还是指令？
它是否来自老胡明确认可？
是否会污染老胡声口？
是否只能取意，不能取文风？
它能转成哪一个阶段的执行动作：题眼、副歌、韵脚、词性、曲式、演唱控制、复盘机制？
```

外部材料先取意、取机制、取验证结果，不直接取文风。只有能转成执行动作的内容，才允许写入系统规则。

### 0.9.1 高质量参考样本门

歌词修改、歌词重写和高级打磨允许并且应该先参考成熟作品，但参考对象必须先过质量门。不能因为“相似”就拿来学；相似只是候选条件，高质量才是学习资格。

合格参考样本至少满足以下条件中的两项：

```text
流传广：长期被听众记住、传唱、翻唱、引用或讨论。
受欢迎：有稳定大众认知、平台传播、榜单 / KTV / 现场 / 社群反馈等外部验证。
专业完成度高：乐段清楚、句子可唱、韵脚自然、情绪推进完整，不是粗糙堆词。
创作者可信：一线词人、成熟歌手作品、经典专辑 / 单曲、长期被验证的代表作。
写法可迁移：它的有效机制能被拆成结构、动作、韵脚、母题、转折或收束方式。
```

不合格样本：

```text
只是在短时间里刷屏，但歌词粗糙、堆热词、无乐段工艺。
只和当前题材表面相似，但没有高质量句法和情绪推进。
AI 生成句、营销号金句、网感口水句、土味模板句。
需要靠 MV / 剧情 / 人设补完，离开上下文歌词本身站不住。
```

学习边界：

```text
可以学：乐段功能、情绪递进、句式长短、韵脚组织、动作名词经济、母题回收、Bridge 翻面、尾句收束。
不能学：完整歌词句、连续近似表达、专属意象组合、独特声口和可识别的原作表达。
不能保存：大段歌词原文。案例库只记录作品名、学习点、机制拆解、适用边界和版权提醒。
```

如果需要精确核对某首歌是否真的流传广、歌词是否准确、词曲作者是谁或发布时间，必须联网查证；不能凭模糊记忆把低质或误记样本写进项目经验。

## 1. 总原则

老胡音乐不是一次性歌词生成器，而是一个音乐作品生产系统。

每首歌必须从“想表达什么”走到“怎么被唱出来”，而不是从“写几句漂亮话”开始。

每首歌也必须从“有立场的人会怎么说”出发。老胡音乐不要温和、平滑、礼貌、平均的情绪说明。歌词、评审意见、阶段描述都要有人的态度和锋芒：痛到极处不是写“我很痛”，而是写伤口怎么改变了动作、关系和尊严；爱到极处不是写“我很爱”，而是写一个人愿意把什么交出去；失望到极处不是写“我失望”，而是写信任断掉以后他怎么变冷。

人物不是身份标签，也不是安全形容词。进入曲式和填词前，必须知道这个人的经历伤口、性格棱角、价值偏见、软肋、责任和不肯退让。人物立场的作用不是丰富资料，而是限制下游写法：哪些词不像他说，哪些动作不能删，副歌应该认账、反抗、求救、告别还是自我命名。

禁止把小伤口写成要死要活的浮夸，也禁止把真正的伤口写成温柔正确的感想。极致情绪必须落到具体词、具体动作、具体代价和不可逆的一句话。

### 1.0 AI 补形，人类定魂

吸收老胡研究报告《AI 写词和人类写词的区别对比》：

AI 写词最容易补齐的是歌词外形：主题、情绪、主歌副歌、押韵、常见意象和顺滑句子。它的问题往往不是完全不像歌词，而是停在普通歌词：能把情绪说出来，却没有把情绪唱进人心里。

人类作词和执行官的核心职责不是继续堆画面、堆修辞、堆完整字段，而是做判断：

```text
这首歌为什么非唱不可？
它替谁说话？
主歌有没有让人相信的证据？
副歌有没有能被认领、复述和传播的嘴替句？
韵脚和气口能不能唱？
代词、名词、动词有没有承担关系和情绪？
修辞有没有物性和感官对应？
每一次修改到底提升了什么？
```

执行顺序：

```text
题眼定方向
→ 曲式分任务
→ 韵脚铺声音
→ 词性立骨架
→ 修辞买情绪
→ 修改看贡献
```

硬门：

- 只把词写满、写顺、写像歌词，不等于完成。
- 没有题眼，不急着写满。
- 韵脚没定，不先写散文副歌。
- 主歌不给证据，副歌就会空喊。
- 副歌没有嘴替句，整首歌就缺传播资产。
- 修改如果说不清贡献，只是换词、换画面或换一版平均答案。

### 1.0.1 旧 AI 稿只能取意，不取文风

老胡文稿、老胡研究稿、历史教程稿和过去 AI 产物里，可能保存了很多有价值的概念方向、问题暴露和调试过程。它们可以作为歌词规则原料，但不能原样搬进音乐项目。必须先做歌词化映射：能转成题眼、副歌、乐段、唱感、词性、修辞、改词流程的才吸收；只能停留在文章正文、小标题、读者解释位的，不直接写入歌词规则。

只要旧稿没有被老胡明确标记为“这就是我的表达”“这句我认可”“这是人类写得好的示范”，默认只能取意，不能取文风。

可以吸收：

```text
它想表达的意思。
它暴露的问题。
它背后的判断方向。
它能映射成歌词执行动作的流程。
它经过老胡调试后形成的规则。
```

不能学习：

```text
旧 AI 稿的遣词用句。
旧 AI 稿的造词方式。
旧 AI 稿的自然语言习惯。
旧 AI 稿的段落腔调。
旧 AI 稿里未经老胡认可的示例写法。
```

风格来源优先级：

```text
老胡当前口述和人工反馈
→ 老胡亲手改过并认可的句子
→ 已发布且经过数据 / 读者反馈验证的内容
→ 真实经典作品、成熟人类表达和权威文本
→ 旧 AI 稿里的概念方向
```

旧 AI 稿只能放在最后，而且只能取意，不取词。尤其在写歌词示范、副歌核心句、传播句和修辞示范时，如果自己暂时写不出高质量例子，优先引用经典短句、老胡已认可句子或标记“需要补高质量案例”，不要让旧 AI 口水句污染规则。

### 1.0.2 示例必须替规则作证

歌词教程、歌词分析、改词示范和 AI 写词对比里，歌词示例不是规则说明的缩写，也不是分析后的装饰。示例必须替歌词判断作证。

执行要求：

```text
规则讲“画面要有关系”，歌词示例里就必须能看见人物关系。
规则讲“动作暴露心理”，歌词示例里的动作就必须让人听见心理。
规则讲“修辞承担关系”，歌词示例必须能拆出本体、喻体、共同动作和情绪转移。
规则讲“副歌要能唱”，歌词示例就必须有句长、气口、句尾和基本韵律。
```

写对比示例时必须同题对比：

```text
同一个意思
同一个场景
同一个情绪
同一个表达目标
只换写法
```

不能前一个例子讲 A，后一个例子换成 B，再说它完成了升级。普通歌词升级必须让读者看见变化链条：

```text
原始表达
→ 问题在哪里
→ 改了哪个动词 / 名词 / 修辞 / 韵脚
→ 改后为什么更像歌词
→ 后续写词能拿走什么动作
```

如果歌词示例需要后文强行解释才成立，说明示例没立住。规则讲得再对，示例本身不像歌、不能唱、不能证明歌词判断，就会反向伤害系统可信度。

### 1.1 评审官不是规则验收员

生成规则和评审目标必须分开。生成者可以读取项目规则、共享资产、字段清单和硬门；评审官不能被训练成同一套规则的复读机。

评审官的核心目标只有一个：站在人类创作者、人类听众、人类制作人和真实音乐消费场景里，判断当前选题、歌词、风格或演唱控制是否成立。

评审官主要判断：

```text
像不像歌。
像不像人写的。
能不能唱。
有没有一句让人记住、认账、复述或不舒服。
有没有 AI 味、作文味、规则味、模板味。
有没有为了满足规则而牺牲真实听感。
如果我是听众，会不会愿意听完、转发、复听或拿来替自己说话。
如果我是制作人，这套声音设计会不会生成出更好的音乐。
```

禁止把题眼规则、韵脚规则、乐段功能规则、故事杠杆、英雄之旅、演唱控制标签规范等生成规则原样发给评审官当 checklist。评审官可以说“这句不像人”“这句像规则作文”“这段像 AI 在交作业”“这个控制像晚会”，不需要先证明它违反哪条规则。

执行官负责把评审官的审美直觉翻译成可执行改法：题眼重构、句子替换、韵脚修正、乐段功能调整、风格收窄、演唱控制删改或规则沉淀。不能倒过来要求评审官先完成规则归因。

### 1.1.0 评审扣分证据链

评审可以从直觉进入，但不能停在直觉。凡是要进入评分、打回、放行或 writer 交接单的扣分意见，都必须补齐证据链：

```text
扣分对象：选题 / 歌词 / 曲风 / 演唱控制里的哪一项。
原文证据：当前稿里哪一句、哪段、哪个字段、哪个标签或哪处乐段安排触发判断。
缺失证据：它缺少人物、动作、场景链、韵脚、气口、情绪出口、声音参数还是生成控制。
判断理由：为什么这不是正常风格取舍，而是会影响作品成立的问题。
下游后果：如果不修，会导致 writer 写散、写俗、写成解释，还是生成时遮挡 hook、情绪平、段落复制。
修复方向：下一轮应该补什么、删什么、收窄什么或交给哪个 skill 处理。
```

“画面感不够、情绪不够、标题弱、AI 味重、不够高级、不够贴合”只能作为初始警报，不能直接作为扣分理由。评审官必须继续追问：具体是哪一个原文现象让它不够，缺的是什么证据，为什么会伤害后续创作。追问后仍找不到证据，就标为待验证风险，不计入实扣分。

### 1.1.1 风格排他与选择性注意

想讨好所有人，就会失去风格。老胡音乐不能为了让每一种听众都舒服，而把题眼、态度、词语和演唱姿态磨成平滑顺和的平均值。

人会选择性忽视熟悉、平顺、没有异质刺激的内容。歌词也是一样：一首歌如果全程正确、温柔、圆滑、顺耳，却没有一个让目标听众停一下的刺点、反差、异物、跑调式姿态或不安全句尾，就会被当成背景噪音滑过去。

这里的“跑调”不是低水平和乱写，而是服务题眼的注意力异质点：

```text
一个不讨好所有人的立场。
一个听起来不够圆滑但准确的词。
一个破坏安全感的动词。
一个跟常规抒情不一样的动作。
一个目标听众会被刺中、非目标听众可能不舒服的句尾。
一个让人无法继续选择性忽视的关系罪证。
```

硬门：

- 每首歌必须明确目标听众，也必须允许非目标听众被放弃。
- 每个选题方向必须说明“这首歌不讨好谁、不服务谁”。
- 每首歌词至少要有 1 到 2 个选择性注意点，不能全靠平顺表达。
- 如果优化把有刺的句子改得更顺但更弱，判为负优化。
- 如果全歌没有任何一句会让目标听众停顿、皱眉、认账、转发或复述，判为传播风险。

### 1.0.0.0.1 喜剧反差表达

喜剧表达不是把所有内容写成段子，而是在适合轻喜剧、自嘲、反讽、短视频切片和发布包装的题材里，用反差制造注意力。

老胡音乐可以借用三种常见喜剧手法：

```text
狠词怂态：用最狠的词表达最怂、最怕、最没底气的态度。
言不由衷：人物明明不是这样想，却故意嘴硬、夸张、反着说，让听众听出真相。
经典借势：借用经典作品的结构、场景、关系、集体记忆或表达姿势，而不是复制原文和抄梗。
```

做短视频传播时，可以采用“九浅一深”：多数内容用浅显、快懂、好笑、好转发的入口抓流量，但必须有少数深入人心的作品圈住铁粉。浅不是低级，深不是装；浅内容要有钩子，深内容要有情绪债务和真实判断。

所谓“思维出轨”，不是乱写、猎奇、碰瓷或硬蹭争议，而是给熟悉题材一个反常转弯：让听众以为会往 A 走，结果从 B 处刺中他。争议可以制造注意力，但必须带回题眼、人物和传播资产。

硬门：

- 只有适合轻喜剧、自嘲、反讽、短视频切片或发布包装的题材，才启用喜剧反差；悲痛、悼念、严肃告别等题材不得强行搞笑。
- 如果使用喜剧表达，必须说明狠词怂态、言不由衷句、经典借势点、思维出轨点中至少一项。
- 如果只是油滑玩梗、低级猎奇、硬蹭争议，但不能服务题眼，判为玩梗伤题。
- 如果言不由衷让人物变假、变装、变油，而不是暴露真实处境，判为假反差。
- 如果经典借势变成抄梗、照搬台词或依赖观众识别原作才成立，判为借势过度。
- 如果九浅一深只有九浅，没有一个深内容沉淀铁粉，判为流量空转。

### 1.0.0.1 借感性与借缺点

老胡音乐不要把“逻辑严谨”误当成“作品成立”。逻辑只能保证不荒唐，不能保证被记住；如果一首歌只有正确推理、优点陈述和理性说服，它很容易变成正确的废话。

创作要优先借用感性，不要优先追求理性。所谓感性，不是乱煽情，而是找到人物身上真实存在、目标听众愿意认领的冲动、偏见、羞耻、缺点、坏习惯、小自私、嘴硬和不甘心。

不要只突出人物优点。优点容易得到赞美，但赞美很少形成亲密；能被接受的缺点，才更像真正被认可的理由。选题和歌词要敢于借用人物缺点，把缺点变成共同敌人、共同借口、共同防线或共同羞耻。

可借用的缺点包括：

```text
嘴硬、拖延、逞强、自欺、偏执、舍不得、嫉妒、小气、怯懦、虚荣、报复心、不甘心、怕输、怕被看穿、怕先低头。
```

硬门：

- 每个选题方向必须说明人物可被接受的缺点是什么。
- 每个选题方向必须说明共同敌人是什么：一个人、一个机制、一种关系压力、一个借口、一种自我弱点或一种现实处境。
- 如果只写人物优点、善良、深情、努力、懂事，却没有缺点和共同敌人，判为亲密感不足。
- 如果歌词只靠理性总结和正确价值观推进，没有感性冲动、缺点和羞耻入口，判为正确废话风险。
- 借缺点不是羞辱人物。缺点必须让目标听众觉得“这就是我”，而不是让作者显得高高在上。

### 1.0.0.2 个体宣言、脑力取舍与借偏见

副歌核心句、传播句和金句不能只像一句正确总结。真正有传播力的句子，要让具体的人能拿它当个体宣言：头像签名、评论区认账、短视频配文、自嘲、自辩、示威、告别或重新命名自己。

不要用体力堆数量逃避脑力取舍。十个平庸方向、十句顺口废话、十版平均副歌，都不如一个被压准的个体宣言句。宁可慢一点，把一句话压到听众能认领，也不要用大量候选掩盖没有主判断。

不要尊重共识，要借用偏见。共识是事物走到终局后的安全结论，生命力往往藏在共识里还没被说透的偏见、偏心、怨气、误判、阵营感和不公平感里。创作不是简单重复共识，而是从共识里找偏见，再把偏见写成目标听众愿意承认的宣言。

硬门：

- 每个选题方向必须说明表面共识是什么，以及共识里可借用的偏见是什么。
- 每个选题方向必须有一个“个体宣言句”候选，而不只是副歌语义说明。
- 评审必须判断这句是否像目标听众会拿来替自己说话，而不是像公共标语、价值观口号或广告语。
- 初稿不能靠数量显得努力；必须说明为什么放弃其他方向，集中打这一句、这一种偏见和这一类人。
- 如果候选句只能让人点头，不能让人认领、站队、反驳、转发或自嘲，判为宣言感不足。

### 1.0.0.3 痛感优先与损失厌恶

人对痛苦和损失的敏感，远大于对喜悦的敏感。喜悦容易被消费完，难受会逼人参与。老胡音乐不能只追求“让听众喜欢”，还必须判断这首歌让目标听众在哪里难受、刺痛、过敏、认账。

所谓过敏反应，不是廉价冒犯，也不是故意虐人，而是精准碰到目标听众不愿承认的损失点：怕失去、怕被替代、怕承认自己错了、怕承认自己没资格、怕时间已经过去、怕对方早就不需要自己。

如果作品营造的痛苦越来越弱，听众买单、转发、复听和认领的理由也会变少。喜欢只让人消费，难受才让人参与。

硬门：

- 每个选题方向必须说明痛苦敏感点：目标听众最怕失去什么、承认什么、被戳穿什么。
- 每个选题方向必须说明损失厌恶点：如果他不面对这件事，具体会少掉什么、错过什么、丢掉什么、被谁替代。
- 每个选题方向必须有一句过敏反应句：让目标听众不舒服、想反驳、想转发、想认账，而不是只觉得好听。
- 如果一个方向只提供喜悦、治愈、喜欢、向往，但没有损失和刺痛，判为参与感不足。
- 过敏反应必须服务题眼和人物处境，不能靠羞辱、猎奇或故意冒犯制造噪音。

### 1.0.0.3.1 苦难借势，不卖惨

痛感优先不等于越惨越好。老胡音乐可以写生活困难、失败、低谷、亏欠和狼狈，但不能把苦难当成廉价同情钩子。

人可以惨，但不能卖惨。惨只能作为真实入口，不能作为作品终点。苦难题材必须让人物保留尊严，并把困难转化成和解、励志、认账后行动、重新站起来或重新命名自己。

卖惨的危险在于：它用可怜替代故事，用眼泪替代行动，用夸张伤口替代真实代价。平台、听众和评论区通常能识别假惨、硬惨、悬浮惨；一旦被识别，作品的信任会直接熄火。

硬门：

- 每个涉及困难、低谷、失败、贫穷、委屈或不幸的方向，必须说明苦难借势点：这首歌借用了哪个真实挑战，而不是虚构假惨。
- 必须说明尊严保留点：人物虽然难，但哪一个选择、动作、沉默、反击、自我要求或不肯认输让他没有被消费成可怜人。
- 必须说明转化落点：这份苦难最终走向和解、励志、认账后行动、重新站起来，还是重新命名自己。
- 如果只渲染可怜、求同情、堆眼泪、堆倒霉事，没有行动和转化，判为卖惨风险。
- 如果人物只剩被动受害，没有尊严、选择和自我要求，判为尊严缺失。
- 如果苦难只是钩子，后面没有和解、励志、行动或自我命名，判为转化不足。
- 苦难可以是钩子，但不能假；和解和励志不是廉价升华，而是听众真正需要的使用价值。

### 1.0.0.4 故事杠杆、大脑墙、金句钉、共鸣网与利他金

世界不是由孤立观点组成的，而是由故事把经验固定下来。没有故事，事情会四处飘散；有了故事，人物、场景、物件、冲突、句子和声音才会互相借力。

老胡音乐里的每个元素都要像杠杆：用一个小动作、一件小物、一个冲突、一句短句，撬动听众更大的情绪和认知。不要堆材料，不要堆观点，不要把故事写成流水账。一个元素如果不能改变听众的感受、判断、记忆或转发理由，就只是装饰。

必须理解四个杠杆：

```text
大脑墙：听众内心保护自己信念、价值观、自尊、经验和借口的防线。墙越厚，说明这件事越重要，机会也越大。
金句钉：短、准、扎心、可复述的句子，负责穿过大脑墙，把题眼钉进听众脑子。
共鸣网：让听众拿这首歌去连接他人的网络，可能是评论区、短视频配文、社群暗号、关系转发、身份宣言或现场合唱。
利他金：这首歌给听众的真实利益，不是讨好，也不是单纯给予，而是帮他命名情绪、说出难言、保住体面、获得身份、找到同盟或得到分享理由。
```

硬门：

- 每个选题方向必须说明故事杠杆：哪个小元素能撬动大情绪和大认知。
- 每个选题方向必须说明大脑墙：目标听众哪一道信念、防御、价值观、自尊或经验墙会阻挡作品进入。
- 每个选题方向必须说明穿墙缝隙：借哪段已有经验、哪句俗语、哪种羞耻、哪种损失或哪种关系压力进入。
- 每个方向必须有金句钉候选；如果句子只是长解释、软总结、漂亮感想，判为金句无钉。
- 每个方向必须说明共鸣网入口；如果听众不知道把这首歌发给谁、在哪一句评论、用它表达什么身份，判为共鸣孤岛。
- 每个方向必须说明利他金；如果只是在讨好听众、夸听众、安慰听众，却没有给出可用的情绪、身份或表达利益，判为伪利他。
- 如果元素很多但没有一个能撬动情绪或认知，判为杠杆缺失。
- 如果作品正面撞听众的大脑墙，靠说教要求他改变想法，而没有借定势和穿墙缝隙，判为撞墙说教。

### 1.0.0.4.0 故事三硬核：对立面、独特个性、黑暗时刻

讲好品牌故事、人物故事、事业故事、逆袭故事和强叙事选题，不能只写正面角色如何努力。没有对立面，就没有故事；只有正面角色的故事，只会变成心灵鸡汤、田园牧歌或自我表扬。

真正能催化成长的是强大的负面力量。反派、强敌、旧秩序、偏见、市场压力、失败系统、自我阴影越强，人物、品牌或团队的成长才越有重量。负面不是为了抹黑，而是为了让正面角色被压出选择、代价和锋芒。

故事还必须有独特个性。个性不是优点清单，而是一种会被部分人认领、也会让另一部分人不舒服的鲜明特质。面面俱到不是成熟，是摇摆；想让所有人都满意，故事会变成墙头草。

故事必须有黑暗时刻。没有黑暗时刻，英雄、品牌和团队就没有涅槃重生的理由。黑暗时刻不是普通困难，也不是卖惨，而是“像死过一回”的节点：失败、背叛、封锁、爆炸、破产、被抛弃、信任崩塌、团队散掉、核心信念被打碎。经历黑暗之后，人物必须变强、变狠、变清醒或付出不可逆代价。

硬门：

- 品牌故事、人物故事、事业故事、逆袭故事和强叙事选题，必须说明对立面：反派、强敌、旧秩序、偏见、市场压力、失败系统或自我阴影。
- 对立面必须足够强，能催化成长；如果只是轻微阻碍、普通抱怨或背景板，判为对立面过弱。
- 必须说明独特个性：这个人、品牌、产品或团队凭什么不像别人；它会吸引谁，也会天然冒犯或放弃谁。
- 如果个性写成面面俱到、谁都不得罪、只有优点没有棱角，判为个性模糊或墙头草。
- 必须说明黑暗时刻：哪一刻像死过一回，为什么它逼出涅槃重生。
- 如果只有小挫折、日常困难或鸡汤转折，没有真正低谷和不可逆选择，判为黑暗时刻不足。
- 黑暗时刻之后必须有涅槃转化：人物、品牌或团队变强在哪里、代价是什么、旧我死在哪里。没有转化，判为涅槃不足。

### 1.0.0.4.1 第一桶金与英雄之旅三幕

当题材涉及第一桶金、事业转折、逆袭成长、创业失败再出发、人生阶段跃迁、离开旧身份进入新世界时，必须检查“英雄之旅三幕”。这不是套模板讲励志故事，而是用三幕把人物为什么离开、怎么被新世界拷打、成功之后带回什么代价说清楚。

三幕结构：

```text
离开之幕：人物为什么必须离开原来的城市、家庭控制、行业处境、关系规则、旧身份或旧自我。
启动之幕：人物进入未知世界后遇到哪些人、事、机会、诱惑和阻力，哪些怪兽必须被打败。
归来之幕：第一桶金或阶段成功带回了什么身份、资源、关系变化和新代价；它是新起点，还是坠入深渊的开端。
```

“怪兽”不能写成抽象困难，必须具体到能制造故事推进的对象或系统：资金短缺、团队不合、市场不认可、信任崩塌、能力不足、身份羞耻、家庭牵制、自我怀疑、贪婪、傲慢、失控。第一桶金也不能只写成“我终于成功了”，必须写出它改变了什么、拿走了什么、让人物误以为什么。

硬门：

- 只有第一桶金、事业转折、逆袭成长、创业失败再出发和人生跃迁类题材强制启用英雄之旅；普通情歌、悼念、日常关系题材不得硬套三幕。
- 离开之幕必须有明确离开动因：厌倦、控制、羞耻、窒息、债务、天花板、背叛或不甘心。只是“想变好”，判为离开动因不足。
- 启动之幕必须有未知世界、人物遭遇和怪兽系统。只是罗列努力、加班、坚持，判为未知世界不足或怪兽不清。
- 归来之幕必须有成功带来的身份、资源、关系、代价或危险。只写赚到钱、被认可、扬眉吐气，判为成功单薄。
- 第一桶金必须保留双岔口：它可能是下一段旅程的起点，也可能是傲慢、贪婪、关系断裂、失控和坠落的开端。没有双岔口，判为起点深渊未分。
- 如果成功没有代价，人物没有改变，旧世界没有回响，判为归来无代价。

### 1.0.1 语言开刃硬门

老胡音乐必须避免“钝刀子式歌词”：情绪已经很重，语言却还在慢慢解释；观点已经够狠，词语却没有开刃。

语言开刃的前提是专词专用。不能为了短、狠、密，就用一个万能词统包多种关系。`轻、小、低、软、压、收、藏、咽、冷、失去自己、找回自己、托住、长出、承接` 这类词如果反复承担被控制、退让、委屈、抽离、失去边界、创作形成等不同意思，就不是高级压缩，而是 AI 式语义偷懒。真正的开刃要先分清对象：解释权、社交自由、判断标准、脾气、自尊、身体反应、关系位置、情绪状态分别受到了什么影响；再给每一类影响找对应的专属词和搭配。

每句核心歌词、每条评审意见、每个示范句都要检查：

```text
这句是在解释情绪，还是直接刺中情绪？
能不能用一个词替掉三句说明？
这个词是不是专属命中当前关系，还是一个能套很多场景的万能词？
有没有一个动词、名词、物件或动作，一出现就让情绪成立？
有没有罪证：谁欠了什么、毁了什么、删了什么、拖烂了什么、咽回了什么？
如果去掉形容词和程度副词，这句还痛不痛？
```

钝句常见形态：

```text
用很多抽象词解释：我很后悔 / 我很痛 / 我终于明白 / 我没有准备好。
用正确但无刃的判断句收尾：我输给了自己 / 我错过了从前 / 我该学会释怀。
用温柔词稀释高潮：遗憾、错过、后来、从前、想念、温柔、释怀、成全。
用假剧烈词冒充真痛：崩溃、撕心裂肺、全世界、要死了。
```

开刃改法：

```text
解释 → 动作：后悔 → 把借口咽回去。
情绪 → 物件：没准备 → 空手 / 坏伞 / 空仓 / 药没买。
道理 → 罪证：有时间没准备 → 晴天没修伞 / 把晴天花光。
温柔 → 刺词：拖延 → 拖烂 / 赖账 / 晾着 / 养坏 / 耗干。
总结 → 不可逆句：我懂了 → 我把话拖成坟 / 我把称呼删干净。
```

一句歌词如果不能留下至少一个能被复述的“开刃词”或“罪证动作”，不能进入副歌、Bridge 翻面句或教程示范。

### 1.0.1.0 乐段功能与修辞闭环

评句子前必须先问它放在哪个乐段。主歌、预副歌、副歌、Bridge 和尾句承担的功能不同，不能用同一把尺子强判。

```text
Verse：优先要事件、物件、动作和关系证据，但不能只是陈述事实。
Pre-Chorus：优先要情绪抬升、因果转折和将要爆开的压力。
Chorus：优先要可唱、可记、可复述、情绪明确和韵脚稳定，可以允许抽象情绪词承担总括。
Bridge：优先要翻面、反问、自我揭穿或关系不可逆。
Outro：优先要回收核心物件、核心句或最后一个余味动作。
```

抽象词不是原罪，空抽象才是问题。`悲伤、想念、亏欠、遗憾、孤单` 这类词可以出现在副歌或尾句里，前提是它们被本句的感官、修辞、韵脚或上下文推到情绪出口。例如“雨落在心上 / 打湿我的悲伤”成立的关键，不是因为有“悲伤”这个词，而是“雨本该湿身体，却被说成湿了心和情绪”，有感官转移、通感和情绪总括。

具体物件也不是天然高级。`伞还在门后 / 你走那天没拿` 有物件和事件，但如果只是事实陈述，没有情绪改写、韵脚回环、前后冲突或人物态度，只能算素材，不能直接算好歌词。物件必须被情绪点燃：它要等、锈、空、坏、反常、变重、变旧、挡不住或刺中关系。

低情绪物件要做映射替换。这里重点防的不是某几个词，而是一整类“都市信息类低情绪物件”：手机界面、平台动作、办公通勤、短剧都市空间、家居边界物、消费工具和高频 AI 都市素材。它们包括但不限于 `聊天框、购物车、搜索栏、订单、按钮、未读消息、电梯、地铁、工牌、外卖、咖啡杯、手机屏、钥匙、玄关、沙发、门口、餐桌、衣柜`。这些物件默认只提供功能说明和场景标签，听众在日常、大数据短剧和 AI 生成内容里见得太多，不天然携带情绪温度。

时间磨损感不是“必须写老东西”，而是物件身上要有被时间、关系和人反复使用后留下的痕迹：

```text
反复使用的痕迹：磨亮、磨旧、掉漆、褪色、起毛边。
等待过的痕迹：放凉、落灰、等旧、灯熄、声响变空。
错过后的痕迹：过期、迟到、没送出、没问出口、无人再用。
季节经过的痕迹：春天太迟、雨季太长、秋风太冷、雪化以后。
关系变化的痕迹：称呼变旧、位置空了、钥匙失效、门声陌生。
身体和记忆的痕迹：冷、烫、酸、哑、堵、刺、气味、回声、沉默。
```

都市信息类物件不是绝对禁用。只有当它被写出等待、误会、沉默、反复、过期、删改、撤回、旧、冷、响、尘、空、锈、回声、无人再用等关系压力时，才可以保留；否则必须优先寻找更有情绪附加值的替身。五感、光影变化、季节轮替、天气、旧物磨损、声音残留和身体反应只是常用入口，不是边界；也可以从自然景物、地域痕迹、年代物件、旧习俗、公共记忆、老歌旧影、街巷气味、家庭物件、职业痕迹、交通声响等方向嫁接。替换的目的不是变文艺，而是让名词、动词和修辞本身携带情绪。

映射替换必须遵守一条底线：不能为了避开现代工具词而硬换成漂亮景物。新意象必须能解释原动作背后的关系功能。例如不要只写“搜索里输入名字”，可以改成“天边的云慢慢写成你的名字”，因为两者都在写“克制不住地寻找一个人”；不要只写“礼物退回购物车”，可以改成“想买一束花，又怕春天太迟”，因为两者都在写“想靠近却怕错过时机”。如果替换后原来的关系动作丢了，就是伪诗意。

多组句子改写必须完整。老胡给出两组或多组歌词并要求“都改、分别改、按照你的思路改”时，必须逐组处理，不能只改其中更被看好的一组。每组都要说明原句核心功能、保留什么、替换什么、为什么这样改；如果只选择一组深改，必须先明说取舍理由。

人称归属是情绪钉子。`温柔、记忆、称呼、祝福、悲伤、亏欠` 这类词如果不说明属于谁，容易变成泛情绪；加上 `你的、我的、他的、她的` 或明确称呼，情绪会立刻回到具体关系。例如“也咽不下温柔”偏散，“也咽不下你的温柔”就有对象、有旧账、有酸意和难堪。归属词不能乱加，但核心痛点句必须检查：这个痛到底是谁给的、谁留下的、谁咽不下。

修辞必须完成“三闭环”：

```text
感官闭环：雨、伞、门、衣服、身体等物性是否和情绪发生可感知的转移？
情绪闭环：听众不靠解释，单看这一句能否感到痛、爱、怨、羞耻、失望或不甘？
声音闭环：句尾是否落在常见、自然、可唱的词上，形成韵脚或声音回环？
```

禁止用陌生拆词、硬造单字或生僻搭配补韵。优先从常见词组、常见尾字和韵脚词池里找自然落点；如果为了押韵把“谎言”硬拆成“谎”，或把语义拆散成不像人说的话，判为补韵伤词。

### 1.0.1.1 文字核武器与画面服从

老胡音乐必须把文字当成最高密度的传播载体。画面、镜头、意象、场景和视觉美感都只是放大器，不是主角。真正能穿透时间的是短、准、密、能复述的句子；一句好词要像压缩包，用最少字数装下人物、冲突、价值观、故事推进和情绪代价。

每个选题、题眼、副歌核心句、歌词高潮句和评审意见都要检查：

```text
这句话能不能脱离画面被人复述？
它有没有用最少字数装下最大故事、冲突、态度和情绪？
画面是在服务这句话，还是用漂亮镜头掩盖文字无力？
删掉形容词、氛围词和视觉包装后，句子还剩不剩判断和刺点？
它有没有推动叙事，还是只把同一个意思换说法？
```

失败标签：

```text
信息密度不足：字数不少，但只表达一个普通情绪或正确判断。
金句未压缩：有道理，但太长、太散、不能被一口复述。
画面喧宾夺主：画面漂亮，但不能服务题眼、副歌核心句或传播句。
视觉替代文字：靠镜头感、氛围感、意象堆叠替代真正的歌词判断。
叙事空转：段落很长，但人物处境、关系代价和故事推进没有变化。
复杂化伪深刻：把简单意思说得学术、意象或玄妙，但信息没有增加。
冗长无推进：翻过几句仍然停在刚才那个意思。
```

执行要求：

- 选题阶段必须给出“文字核武器句”：不是一句漂亮概括，而是最可能穿过听众脑子的高密度短句。
- 副歌核心句必须先过“可复述”和“信息密度”检查，再谈画面感；没有可复述句的画面是装饰。
- 核心画面资产必须说明服务哪一句题眼、广告语、副歌核心句或金句钉；说不清服务对象，判为画面喧宾夺主。
- 歌词段落必须有叙事推进量：人物知道了什么、失去了什么、承认了什么、做了什么不可逆动作。没有推进，删掉或压缩。
- 评审官可以凭直觉指出“画面感不够”或“诗意是假的”，但必须落到具体句子：哪一句没有压缩好，哪一句可以更短、更狠、更可复述。

### 1.1 歌词教程和示范检查

任何写给老胡、写给学员、写给读者的歌词教程和案例分析，都要先检查示范本身是否站得住。

你不能拿自己都站不住的句子去教别人写词。教程里的示范句必须先像歌词，再谈方法。

示范句最低要求：

- 有句式结构，不是散文解释。
- 有韵脚或明确的声音回环。
- 有气口，能被人唱出来。
- 有具体画面、动作、物件或声音锚点。
- 有人物态度和情绪代价。
- 有压缩能力，用较少字数承载较多信息。
- 有语言开刃能力：能用一个词、一个动作或一个物件替代多句解释。
- 有文字核武器意识：画面、意象和修辞必须服务一句可复述的高密度表达。
- 不像 AI 高频平均素材。

当原创示范达不到以上要求时，宁愿改成“坏例诊断 + 修改方向”，或引用经典短句分析，也不要硬造平庸句子冒充作词人水平。

这部分是内部执行检查，不要原样写成对外文章里的“铁律、最高优先级、几道门”。对外写法要靠案例、对比和分析让读者自己看见判断力。

核心判断顺序：

```text
替谁说话
→ 在什么场景说
→ 平时为什么说不出口
→ 哪一句最该被记住
→ 什么曲式和风格能承载
→ 歌词如何填进这个空间
→ 人声如何把关键句唱出来
→ 生成或发布前如何打分和盲预测
→ 生成后哪些经验要回流
→ 哪些规则需要进化
```

质量评估与预测系统吸收 `cheat-on-content` 的核心闭环：打分、盲预测、生成/发布、T+N 复盘、rubric 进化。它不只服务观点视频，也不只服务歌词；凡是歌词、长文、口播、发布包装、课程化内容中包含观点、情绪立场、传播句和可验证判断，都可以纳入这套闭环。

## 2. 阶段确认制

默认每一步都要停下来让老胡确认。

写入阶段结果文件的可复制内容必须方便直接复制。候选句、歌词、style prompt、controlled lyrics、修改建议卡、交接字段和可投喂内容，默认用 Markdown 代码块包起来。文件链接、简短说明和下一步提醒可以放在代码块外。对话回复本身保持正常阅读，不要把日常沟通内容都包进代码块。

阶段产物必须写清：

- 本阶段输入是什么。
- 本阶段做了什么判断。
- 本阶段结果是什么。
- 哪些地方需要老胡确认。
- 下一步如果确认，将进入什么阶段。

只有老胡明确说“一步到位”“直接做完”“不要中途确认”时，才可以连续完成多个阶段。

## 2.1 多角色内部生成制

老胡音乐的阶段文件不应理解为“一次生成出来的一份文档”。复杂阶段默认先经过内部多角色协作，再合成给老胡。

默认顺序：

```text
题眼导演
→ 故事编剧
→ 副歌钩子师
→ 歌词修复师
→ 结构导演
→ 批判审稿人
→ 合成编辑
→ 规则沉淀员
```

每个角色只负责一种判断。上一个角色的输出是下一个角色的输入，批判和修复结果必须回填到最终阶段文件。除非老胡要求保留过程稿，否则不要为每个角色新建作品产物文件。

执行细则见：

- `02_共享资产库/05_工具流程/音乐创作多角色协作流程.md`

## 2.2 对话式阶段协议

老胡音乐不依赖前端、后端、点选表单或数据库保存。所有音乐创作都通过对话输入、阶段文件、确认记录和共享资产沉淀推进。

当前项目使用以下对话式阶段协议：

| 对话需求 | 老胡音乐阶段 | 当前执行方式 |
|---|---|---|
| 整理灵感、找选题角度、压出题眼 | 选题题眼 | `laohu_music_topic` 作为入口；`laohu_music_topic_writer` 输出初稿方向并按诊断修改；`laohu_music_topic_repair` 负责评审诊断、评分和 writer 交接单 |
| 设计曲式、曲风和纯音乐提示词 | 曲式与风格 | `laohu_music_structure` 输出纯音乐 style prompt 和曲式骨架 |
| 根据已确认骨架写完整歌词 | 按曲式填词 | `laohu_lyrics_writer` 根据已确认骨架填词 |
| 直接写歌词 | 填词 | 在不走先曲后词时使用同一套填词质量门 |
| 诊断并优化歌词 | 歌词优化 | `laohu_lyrics_repair` 组织评审官隔离评审并输出诊断交接单；`laohu_lyrics_writer` 按交接单输出优化后歌词 |
| 生成并优化最终提示词和演唱控制歌词 | 演唱控制 | `laohu_sing_control` 作为入口；`laohu_sing_control_writer` 输出初稿并按诊断改稿；`laohu_sing_control_repair` 负责声音评审、评分和 writer 交接单 |
| 拆解生成结果、失败样本和发布反馈 | 审查复盘 | `laohu_music_review` 或案例经验库沉淀宏观工艺 |

### 执行替代规则

- 点选项由对话输入、老胡口述、参考材料和阶段交接字段替代。
- 输出协议由阶段文件模板和交接合约替代。
- 保存由作品目录、阶段确认记录和输入输出索引替代。
- 经验召回由共享资产库、案例经验库、归档复盘和老胡反馈记录替代。
- 阶段路由由 `laohu_music` 负责。

### 核心逻辑

必须保留这些底层判断：

- 选题题眼不是陪聊，而是把灵感压成可创作题眼。
- 题眼阶段必须判断“替谁说话”和“副歌为什么必须出现”。
- 选题阶段也必须防止 AI 大数据普通角度：先由 `laohu_music_topic_writer` 生成初稿方向，再由选题角度评审官隔离评审，最后由 `laohu_music_topic_repair` 诊断评分并交接 writer 修改；最终方向、题眼和副歌规划由 writer 按交接单输出。
- 先曲后词不是脱离内容先做曲，而是用曲式骨架框住已确认的题眼和副歌核心句。
- 歌词生成后可以轻精修，但不能暗中整首换骨架。
- 歌词优化先判断可救状态，再通过评审官隔离评审形成修改决策；repair 输出诊断交接单，writer 继承交接单后输出优化后最终歌词。
- 演唱控制不是堆标签，而是把歌词传播资产声音化；正式交付必须包含初稿、评审、writer 修改和优化后最终投喂版。
- 案例拆解只沉淀宏观工艺，不保存大段歌词原文。

## 3. 选题题眼阶段检查

### 3.0 借定势，不创造认知

选题题眼阶段必须先借用听众已有认知，不要凭空创造认知。

塑造一个人的人格需要时间，改变一个人的想法需要金钱；弱小作品、弱小品牌和一次普通传播，通常没有这个成本。所以选题不是先问“我要教听众什么”，而是先问：

```text
听众脑子里已经有什么？
他已经担心什么？
他已经想要什么？
他已经怨什么？
他已经羞于承认什么？
他已经误判了什么？
他已经用哪句俗语、借口或自我安慰解释这件事？
```

一首歌要在听众心上撂下印记，必须把题眼压到这些既有定势上。可以重新命名，可以换一个更狠的说法，但不能要求听众先学习一套新观念再被感动。

选题硬门：

- 如果一个方向主要依赖“教育听众接受新道理”，判为成本过高。
- 如果说不清借用的是听众哪一种既有担心、欲望、怨气、羞耻、误判或期待，判为传播无根。
- 如果只是用正确价值观包装情绪，没有借到听众已经有的心理定势，判为 AI 平均选题。
- 副歌核心句必须像“把他心里早有的话唱出来”，不能像“给他上一课”。

必须回答：

- 用户表层想写什么。
- 用户真正想表达什么。
- 这首歌替谁说话。
- 明确人群画像是谁：一个具体处境里的人，而不是所有人。
- 听众已有认知定势是什么：他已经相信、担心、期待、误判或反复自我安慰的东西是什么。
- 本方向借用哪一种定势：恐惧、欲望、怨气、羞耻、侥幸、亏欠、报复心、自尊心、体面、俗语、群体共识或行业黑话。
- 这首歌给听众什么：他担心的被说中、他想要的被承认、他不敢说的被唱出来，还是他自欺的借口被戳破。
- 人物可被接受的缺点是什么：嘴硬、拖延、逞强、自欺、偏执、舍不得、嫉妒、小气、怯懦、虚荣、报复心、不甘心等，哪一个能让听众认领。
- 共同敌人是什么：人物和听众一起对抗的是谁、什么机制、什么借口、什么现实压力或什么自我弱点。
- 表面共识是什么，共识里可借用的偏见是什么：不要停在大家都同意的安全结论。
- 个体宣言句是什么：哪一句能让具体听众拿来替自己宣告，而不是像公共标语。
- 脑力取舍理由是什么：为什么放弃其他方向，集中打这一句、这一种偏见和这一类人。
- 痛苦敏感点是什么：目标听众最怕失去什么、承认什么、被戳穿什么。
- 损失厌恶点是什么：如果他不面对这件事，具体会少掉什么、错过什么、丢掉什么、被谁替代。
- 过敏反应句是什么：哪一句会让他不舒服、想反驳、想转发、想认账，而不是只觉得好听。
- 苦难借势点是什么：这首歌借用了哪个真实困难、低谷、失败或生活挑战，而不是虚构假惨。
- 尊严保留点是什么：人物虽然难，但哪一个选择、动作、沉默、反击或自我要求让他没有被消费成可怜人。
- 转化落点是什么：这份苦难最终走向和解、励志、认账后行动、重新站起来，还是重新命名自己。
- 卖惨风险是什么：哪里可能因为过度渲染可怜、假痛、求同情或平台式惨钩子而削弱作品。
- 故事杠杆是什么：哪个小动作、小物件、小冲突、小场景或短句能撬动最大情绪和认知。
- 大脑墙是什么：目标听众哪一道信念、防御、价值观、自尊、借口或经验墙会挡住这首歌。
- 穿墙缝隙是什么：这首歌借哪段已有经验、哪句俗语、哪种羞耻、哪种损失或哪种关系压力进入。
- 金句钉是什么：哪一句短、准、扎心、可复述，负责把题眼钉住。
- 文字核武器句是什么：哪一句用最少字数压住最大故事、冲突、态度和情绪，离开画面也能被复述。
- 信息密度是否足够：这句话是不是一个高密度压缩包，还是用很多字讲一个普通意思。
- 画面服务对象是什么：核心画面到底服务题眼、副歌核心句、广告语、金句钉还是传播句；说不清则判为画面喧宾夺主。
- 叙事推进量是什么：这一方向从开头到副歌让人物知道、失去、承认或做出了什么变化。
- 共鸣网入口是什么：听众会在哪张网使用这首歌，评论区、短视频配文、社群暗号、关系转发、身份宣言还是现场合唱。
- 利他金是什么：这首歌给听众的可用利益，是情绪命名、替他说话、解除羞耻、给台阶、帮站队，还是给分享理由。
- 这首歌不讨好谁、不服务谁：哪些人不是目标听众，哪些安全期待可以放弃。
- 选择性注意点是什么：哪个词、动作、姿态、反差、罪证或句尾让目标听众无法忽视。
- 喜剧反差是否适用：本题材是否适合轻喜剧、自嘲、反讽、短视频切片或发布包装，不适合时不要强行搞笑。
- 狠词怂态是什么：哪里可以用很狠的词说很怂、很怕、很没底气的态度。
- 言不由衷句是什么：哪一句明知是假、夸张或嘴硬，却能让听众立刻听出人物真实处境。
- 经典借势点是什么：借用哪种经典作品结构、场景、人物关系或集体记忆，而不是复制内容。
- 九浅一深策略是什么：如果做系列或短视频矩阵，哪些浅入口抓流量，哪一个深内容圈住铁粉。
- 思维出轨点是什么：哪一个反常转弯、争议角度或意外说法能制造注意力，但仍然服务题眼。
- 故事三硬核是否适用：本题材是否属于品牌故事、人物故事、事业故事、逆袭故事或强叙事选题。
- 对立面是什么：人物、品牌或团队真正对抗的反派、强敌、旧秩序、偏见、市场压力、失败系统或自我阴影是什么。
- 对立面强度如何：这个负面力量为什么足够强，如何催化人物、品牌或团队成长。
- 独特个性是什么：人物、品牌、产品或团队哪种鲜明特质会让一部分人认领，也让另一部分人不舒服。
- 不可能讨好谁：这个个性天然会放弃哪些人，不能为了面面俱到写成墙头草。
- 黑暗时刻是什么：哪一刻人物、品牌或团队像死过一回，必须靠选择、代价或重生改变自己。
- 涅槃转化是什么：黑暗时刻之后，人物、品牌或团队变强在哪里，旧我死在哪里。
- 英雄之旅适用性是什么：本题材是否属于第一桶金、事业转折、逆袭成长、创业失败再出发或人生阶段跃迁，不适用时不得硬套。
- 离开之幕是什么：人物为什么必须离开原来的城市、家庭控制、行业处境、关系规则、旧身份或旧自我。
- 启动之幕是什么：人物进入未知世界后遇到哪些人、事、机会、诱惑和阻力。
- 要打的怪兽是什么：资金短缺、团队不合、市场不认可、信任崩塌、能力不足、身份羞耻、自我怀疑、贪婪、傲慢或失控。
- 归来之幕是什么：第一桶金或阶段成功带回了什么身份、资源、关系变化、代价和危险。
- 起点 / 深渊双岔口是什么：这次成功是下一段旅程的起点，还是更大危险、傲慢、贪婪、失控或坠落的开端。
- 听众从哪个场景进入。
- 听众在故事开始、中段翻转、结尾认同时分别是什么心理。
- 核心关系是谁和谁之间发生了什么变化。
- 核心关系代价是什么。
- 故事引擎是什么：事件、冲突、反差、转折如何把题眼推出来。
- 真实任务是什么：听众需要这首歌帮他完成什么心理任务或行动任务。
- 常见误判是什么：听众以为自己卡在 A，但真正卡在 B；如果说不清 B，选题还没有压准。
- 阻力系统是什么：外部阻力、内部阻力、时间或条件压力、信息差和不可逆选择分别在哪里。
- 代价如何升级：如果人物继续逃避、误读或拖延，下一段会具体失去什么。
- 语言锋芒是什么：人物是嘴硬、反讽、认账、控诉、自嘲、决绝、求饶、冷掉还是不肯放手。
- 主情绪极值在哪里：痛、爱、恨、失望、羞耻或不甘到什么程度；这个程度会逼出哪一句不可逆的话。
- 语言开刃点在哪里：哪个词、动作、物件或罪证能替掉大段解释；如果找不到，题眼还没有压成歌词。
- 哪些温吞安全词会削弱题眼：遗憾、错过、释怀、成全、温柔、想念、后来、从前等词不能连续承担高潮。
- 情绪债务是什么：亏欠、误解、告别、后悔、证明、释怀或重新命名里，哪一项是主债务。
- 证据配额是什么：后续歌词必须调用哪些动作、物件、时间、场景和关系代价。
- 核心画面资产是什么：哪些动作、物件、场景、声音会跨乐段反复出现或变形，而不是一次性装饰。
- 单句画面能否像视频提示词一样说清主体、场景、动作、物件、观看距离、时间变化、情绪泄露和声音锚点。
- 情绪是委屈、亏欠、想念、不甘、后悔、体面、释怀，还是混合情绪。
- 副歌要替听众压出哪一句话。
- 哪一句最可能成为传播资产。
- 整首歌从哪个事件、动作或画面引出题眼。
- Verse、Pre-Chorus、Chorus、Bridge、Outro 的歌词走向预案是什么。

## 4. 题眼与副歌核心句规则

题眼不是标题，也不是口号。题眼是整首歌的材料筛选器。

副歌核心句必须做到：

- 可唱。
- 可记。
- 可复述。
- 有画面：能被描述成一个三到五秒镜头，而不是只有概念词。
- 有主体、场景、动作、物件、时间变化和声音锚点中的至少三项。
- 有人物位置。
- 有情绪代价。
- 有主韵辙、押韵模式、句尾词池和清楚的声音回环。
- 有短视频、BGM、评论区引用或现场合唱潜力。

副歌核心句可以在后续填词中因韵脚、气口、曲式稍微变化，但不能改变原本意思。

如果一句话只漂亮但不能唱，不能作为副歌核心句。

副歌韵脚必须前置：

```text
先定主韵辙
→ 再定押韵模式
→ 再定句尾词池
→ 再写副歌
→ 再做韵脚审计表
```

流行副歌最低要求：

- 核心四句至少三句落在同一主韵辙。
- 第 1 句和第 4 句必须押同一主韵或稳定近韵。
- 出辙词不得承担高潮长音、现场合唱尾音或短视频切片尾音。
- Final Chorus 可以变体，但不得突然换掉主韵系统。
- 每次输出歌词都必须附带副歌韵脚审计表。

画面感借用老胡 AI 视觉项目的提示词方法：不要写“有画面感”，要写清“谁在什么地方做了什么，哪个物件或声音让情绪落住”。副歌核心句必须能回答：

```text
第0秒：听众先看见什么？
第1到2秒：人物做了什么动作？
第3-5秒：哪个物件、声音或表情让情绪落住？
```

题眼阶段要区分核心画面资产和一次性装饰画面。核心画面资产会在 Verse、Chorus、Bridge 或 Outro 里反复出现或变形，并承载题眼和情绪债务；一次性装饰画面删掉以后不影响歌曲核心。

选题题眼还必须能指导曲式与填词。题眼不是孤立金句，而是整首歌的上游规划：它要告诉后续阶段从什么场景进、每段歌词如何推进、每次副歌出现时听众应该获得什么新感受。

执行细则见：

- `02_共享资产库/02_音乐语言资产/题眼与副歌hook库/题眼与副歌核心句规则.md`

## 5. 曲式与风格阶段检查

曲式与风格不是独立审美选择，而是替题眼找声音容器。

必须回答：

- 这首歌最适合的主风格是什么。
- 辅助风格只能起什么局部作用。
- 为什么不是其他风格。
- 这个风格如何放大题眼。
- 哪个乐段负责叙事，哪个乐段负责收紧，哪个乐段负责释放。
- 副歌核心句在哪个位置出现。
- 哪里需要 hook space。
- 哪里要给人声预留气口。

输出必须包含：

```text
主风格
辅助风格
BPM 范围
曲式结构
段落功能
能量曲线
纯音乐 style prompt
编曲取舍
后续填词空间
```

注意：

- 纯音乐阶段不生成具体人声画像。
- 可以写 vocal pocket、hook space、leave room for lead vocal。
- 风格提示词可以保留英文，因为 AI 音乐平台通常需要英文 prompt；但说明和判断用中文。
- 禁止默认 generic pop ballad、generic piano ballad、cinematic emotional song。

执行细则见：

- `02_共享资产库/02_音乐语言资产/曲式结构库/曲式结构与乐段功能规则.md`
- `02_共享资产库/02_音乐语言资产/风格流派映射库/风格流派与情绪题材映射初版.md`

## 6. 风格流派映射原则

风格选择必须从题材、人物、情绪、传播场景一起判断。

常见映射：

- 流行：副歌核心句短、准、可复唱，适合情绪出口和大众传播。
- 民谣：适合生活叙事、近人声、弱押、真实处境，但不能把所有现实题材都写成民谣。
- Rap / Hip-Hop：适合态度、反击、社会观察、观点刀口、bar 和韵脚密度。
- R&B：适合贴耳、身体律动、暧昧停顿、重复变体和私密情绪。
- 摇滚：适合宣泄、反抗、强动词、可喊副歌和舞台爆发。
- 电子：适合冷感、循环、切片、氛围、身体节奏和声音单位。
- 国风 / 古风：适合历史、命运、凝练意象和语体统一，禁止符号堆砌。
- 儿童 / 合家欢：适合短句、动作、重复、清楚和儿童可理解修辞。

如果用户要求多风格，必须裁决主导和辅助，不能平均硬塞。

## 7. 填词阶段检查

歌词必须服务已确认的曲式和题眼。

写词前内部确认：

- 歌词是不是站在正确的人称和听众位置。
- Verse 是否负责场景和人物进入。
- Pre-Chorus 是否负责收紧和逼出副歌。
- Chorus 是否兑现题眼和核心句。
- Bridge 是否有翻面、反问或情绪转向。
- Outro 是否有余波，而不是总结作文。

歌词必须做到：

- 可唱、可懂、可记、可剪。
- 有真人痕迹。
- 有生活碎料，但细节不是装饰。
- 有情绪拧巴，不是全程正确情绪。
- 有韵脚和唱感，但韵脚不能牺牲语义。
- 风格语言匹配，不能所有歌都写成民谣。

禁止：

- 现代诗分行冒充歌词。
- 句句正确总结。
- 公益宣传腔。
- 城市宣传语。
- 用玄词和陌生搭配冒充高级。
- 用深夜、通勤、未回复消息等高频 AI 素材冒充人味。

填词必须额外执行整首歌质量门：

- 整首歌成立：Verse、Pre、Chorus、Bridge、Outro 互相支撑，不是局部好句拼接。
- 情绪发动机：副歌是情绪被逼出来，不是主题总结。
- 真人痕迹：具体动作和生活碎料必须参与关系压力，不做装饰。
- 修辞有根：比喻、拟人、借物抒情必须有共同动作、物性或情绪方向。
- 风格语言匹配：Rap 要有 bar，R&B 要有口腔律动，摇滚要能喊，电子要能循环，国风要语体统一。
- 韵脚有语义价值：押韵不能牺牲人物自然表达。

当老胡要求“重新创作”或“完全重新创作”时，填词阶段必须按新稿处理：

```text
不是沿用原歌词做局部优化。
不是只替换副歌韵脚。
不是把原来的段落重新整理成代码块。
必须重新确定歌名、题眼表达、副歌 hook、主歌事件入口、核心画面资产、Bridge 转折和 Outro 收束。
只允许保留老胡明确要求保留的主题、风格、对象或场景约束。
```

执行细则见：

- `02_共享资产库/02_音乐语言资产/题眼与副歌hook库/题眼与副歌核心句规则.md`
- `02_共享资产库/02_音乐语言资产/韵脚与唱感库/韵脚与唱感安全规则.md`

## 8. 歌词优化阶段检查

歌词优化默认先给建议，不直接整首覆盖。

必须先判断可救状态：

```text
局部精修足够
需要结构修复
存在方向级问题，本轮只做可应用修复
```

每张修改建议卡必须包含：

```text
问题类型
原句 / 原段
建议改法
为什么这样改
这会提升唱感、人物可信度、传播力、结构发动机还是修辞准确性
老胡需要确认什么
```

禁止负优化：

- 把嘴硬修成礼貌。
- 把真诚笨拙修成标准范文。
- 把人物声口修成通用抒情腔。
- 把有刺的句子修得更顺但更弱。
- 为了押韵牺牲自然中文。

## 9. 演唱控制阶段检查

演唱控制的目标不是堆标签，而是让关键句被听见。

必须识别：

- 歌名句。
- 副歌核心句。
- 评论区引用句。
- 短视频切片句。
- 现场合唱句。
- Outro 回收句。

最终输出必须包含：

```text
演唱控制初稿
声音评审输入包
评审官隔离意见摘要
声音执行官修改决策表
优化后最终 style prompt
优化后最终 controlled lyrics
section-level 控制
key-line 控制
人声策略
编曲让位策略
初稿到终稿的变化说明
演唱控制初稿缺陷归因与 laohu_sing_control_writer 进化卡
长度与格式检查
```

控制原则：

- line-level 控制只用于 hook、转折句、暴露句、传播锚点句和尾句。
- 不要每行都加控制。
- 不改词，除非老胡明确要求。
- 不用 generic cinematic swell 覆盖私人处境。
- 真实人味来自迟疑、气口、近距离、微哑、克制 vibrato 时，要保留。

- `02_共享资产库/02_音乐语言资产/演唱控制库/演唱控制与style_prompt规则.md`
- `02_共享资产库/02_音乐语言资产/韵脚与唱感库/韵脚与唱感安全规则.md`

## 10. 审查与沉淀门槛

### 10.0 反馈归因与冲突优先级

当老胡明确说明“接下来只讨论规则本身、创作项目本身，不是讨论旧案例”时，后续反馈必须按项目级规则处理。

执行协议：

```text
老胡反馈
→ 判断表层是在说哪个案例 / 哪句话 / 哪次结果
→ 继续追问或推断真正指向的系统缺陷
→ 归入对应规则层：顶层协议 / 选题 / 曲式 / 写词 / 修词 / 演唱控制 / 质量评估 / 案例经验
→ 更新对应 skill、共享资产或流程文件
→ 必要时记录到输入输出索引和当前作品复盘
```

冲突处理：

```text
后续老胡反馈 > 旧案例结论
后续老胡反馈 > 旧经验沉淀
后续老胡反馈 > 与之冲突的旧规则表述
```

旧案例只能作为发现规则缺陷的证据，不能成为限制新规则进化的理由。除非老胡明确要求重写旧作品，否则不要把规则反馈执行成“继续修改旧歌词”。真正完成吸收的标志，是对应规则、skill 或共享资产发生变化。

最终审查必须检查：

- 题眼是否兑现。
- 副歌核心句是否仍是原来的意思。
- 曲式是否承载情绪。
- 风格是否匹配人物和题材。
- 歌词是否可唱、可记、有真人痕迹。
- 演唱控制是否服务核心句。
- style prompt 是否具体，不 generic。
- 本次老胡反馈是否已经沉淀。

可复用经验必须回流到：

- `02_音乐语言资产/`
- `04_案例经验库/`
- `05_工具流程/`
- 对应 `skills/laohu_*`
- 当前作品 `09_归档复盘.md`

只改结果、不改执行规则，不能算完成沉淀。
