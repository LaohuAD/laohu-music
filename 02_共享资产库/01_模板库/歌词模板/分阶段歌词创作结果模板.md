# 分阶段歌词创作结果模板

本模板用于记录一首歌从选题、曲式、歌词、优化到演唱控制的关键交接。模板字段不是为了堆表格，而是防止题眼、声口、韵脚、气口和演唱控制在阶段之间丢失。

- 角度类型：具体故事 / 概念悖论 / 伦理边界 / 身份翻面 / 语言姿态 / 流派角度

- 创作显影层摘要：这首歌会写成什么姿态；关键画面或声音；副歌爆发方向；不该写成什么
- 选择层：相对其他方向的差异；适合保留的理由；适合淘汰的风险
- 抽象概念如何落地：

- 题眼动作 / 关系动作：

- 命名重心：情绪 / 关系 / 命运 / 态度 / 声音
- 歌名候选 A/B/C：
- 歌名类型：情绪命名 / 关系定性 / 副歌核心句 / 意象压缩 / 悖论反常识
- 歌名成立理由：命名了什么情绪状态；能否装下整首歌；能否进入副歌；声音是否好念好唱
- 歌名淘汰风险：太具体像故事文件名 / 太抽象像主题词 / 太像短视频标题 / 与曲风声口不一致 / 像口号 / 像半句诗

- 整首总情绪曲线：开头 / Verse / Pre / Chorus / Bridge / Final Chorus
