# 类型化评审经验库

本文件保存不适合直接写进主 skill 的类型化评审经验。

它解决的问题是：评审反馈不能全部堆进 `laohu_lyrics_writer` 或 `laohu_sing_control_writer`，否则初稿会越来越平均、越来越正确、但越来越没有风格。主 skill 只吸收跨风格通用硬门；类型、风格、题材、词性、平台或人声场景专属经验，放在这里，按需读取。

## 1. 经验分层规则

```text
通用硬门：
不管什么风格、题材、词性都成立的问题。
写入对应主 skill。

类型化经验：
只在某类歌词、曲风、演唱方式、题材或平台场景里成立的问题。
写入本文件。

单次偏好：
只服务当前作品、当前老胡反馈或当前审美选择。
写入作品 09_归档复盘，不写入主 skill。
```

## 2. 写入判断

评审后写回前，必须先问：

```text
这条经验是否对所有歌词都成立？
如果用于 Rap、儿歌、国风、摇滚、R&B、民谣、都市情歌，会不会破坏其中某一类的特色？
它是防止低级错误，还是偏向某一种审美？
它应该成为硬门，还是只在某个标签命中时读取？
```

判断方式：

| 经验类型 | 写回位置 | 例子 |
|---|---|---|
| 通用硬门 | `skills/laohu_music_topic_writer/SKILL.md`、`skills/laohu_lyrics_writer/SKILL.md` 或 `skills/laohu_sing_control_writer/SKILL.md` | 选题必须有明确人群；不要让没有承诺的人承担亏欠；初稿 controlled lyrics 必须已有 `[]` 和必要 `[()]` |
| 选题类型经验 | 本文件 | 都市关系、普通人处境、女性关系、反常识角度、小众人群等选题经验 |
| 歌词类型经验 | 本文件 | Rap 要提前设计韵脚密度和 bar 推进；儿歌要控制词汇年龄和旋律重复 |
| 曲风制作经验 | 本文件或演唱控制共享规则 | R&B 要保留口腔律动；摇滚副歌需要可喊句尾 |
| 题材经验 | 本文件 | 国风意象必须参与动作，不堆符号 |
| 单次偏好 | 当前作品复盘 | 这首歌不要弦乐；这一次不想要释怀 |

`laohu_music_topic_writer`、`laohu_lyrics_writer` 和 `laohu_sing_control_writer` 在出初稿前，只读取与本轮命中标签相关的经验。

## 5. 当前类型经验

### 副歌单句刀口密度 / 强传播流行副歌

适用范围：
流行歌副歌、短视频情绪切片、强情绪传播、三角关系、被替代、被冷落、先爱者低姿态、备选感、背叛、分手控诉、苦情宣泄、评论区共鸣型副歌。核心目标是让副歌每一句都具备单独分享、单独刺中、单独被听众认领的能力。

不适用范围：
完整叙事慢歌、亲情片尾主题曲、校园暗恋克制型副歌、民谣故事歌、国风意境歌、需要长线铺垫和留白的作品。

常见初稿缺陷：

- 只设计一句 hook，其余句子只是解释、铺垫、重复情绪或凑韵。
- 每一句意思都通，但单独拿出来没有态度、没有关系刺点、不能被听众分享。
- 用完整叙事歌标准写这类副歌，过度要求铺垫、意象统一和克制，导致每句刀口不够快、不够狠、不适合传播。
- 把强情绪误解为乱喊，连续堆“死掉、性命、氧气、凌迟、乞讨、卑微”等极端词，但没有独特关系证据。
- 只有作者控诉，没有听众可认领的位置；听众知道你难过，但不知道这句怎么替自己发声。
- 句子像小作文分行，没有句首锤击、尾韵回环、切分停顿或关键词反复。
- 三角关系里“我、你、她 / 他”的位置不清，导致控诉对象和受伤点漂移。
- 每句都很满，没有一句短稳 hook，短视频截取时找不到最有力的一刀。

为什么会被喜欢：

- 它不是只有一行金句，而是每一句都有独立刀口。听众可以截第一句、第三句或最后一句，每一句都能表达一种委屈。
- 它给听众一个很快能站进去的角色：被替代的人、先爱的人、懂事的人、备选的人、被当笑柄的人。
- 它不是先讲故事，而是先宣判关系，把听众心里的“凭什么”直接说出来。
- 它常用第二人称对峙，让听众产生“这句话就是我想骂他的”的代入感。
- 它把复杂关系压成社交货币句，适合评论、配文、转发和短视频字幕。
- 它用排比、反问、禁止句和重复句式制造锤击感，旋律上容易形成一口气的情绪爆发。

单句刀口组成：

```text
对象明确：这句是对你、对我、对她 / 他，还是对这段关系说。
关系错位：这句揭开被替代、被消费、被亏欠、先爱低姿态、懂事换不来爱等不公平。
情绪动作：这句在质问、判决、认账、告别、自嘲、反击或求救，不只是描述难过。
声音落点：这句有尾韵、重音、停顿、重复词或可唱的结束词。
```

四句副歌的理想状态：

```text
第 1 句：立场刀，让听众立刻知道我受了什么伤。
第 2 句：关系刀，指出你和我之间最不公平的地方。
第 3 句：尊严刀，写我如何被迫低头、懂事、退让或自我羞辱。
第 4 句：判决刀，把这段关系压成一句能传播的结论。
```

四句不一定都按这个顺序，但必须每句承担不同角度，不能四句都在说“我很难过”。

常见有效结构：

```text
句首反复：别把 / 别用 / 凭什么 / 难道 / 是不是 / 就承认。
三角替代：你把我和她比较、替代、炫耀、消费。
身份认领：我很合适、我太懂事、我出现太迟、我只是备选。
账单控诉：你的一时兴起，换我长期消耗。
自我羞辱：先爱的人放低姿态，像乞讨、像笑柄、像消遣。
结尾判决：承认你没爱过我 / 把你还给人海 / 我们角色不对等。
```

评审官常抓的问题：

- Max Martin 评审官会抓有没有可截取的 8-15 秒情绪句，以及句首 / 句尾重复是否形成旋律锤点。
- 李宗盛评审官会抓控诉是否像真实关系里的委屈，而不是短视频苦情模板。
- Rick Rubin 评审官会抓极端词是否太多，能不能删到只剩最痛的一两刀。
- 平台传播评审会抓这句能不能被评论区复用，听众拿它表达什么。

初稿前预防动作：

- 先定“关系判决句”，例如：我是备选、你拿我的痛哄她、先爱的人失去质问资格、她一句话就能代替我。
- 再拆 3-4 个不同刀口：身份刀、亏欠刀、替代刀、尊严刀、记忆刀、告别刀。
- 再选句式武器：反问、禁止、排比、重复、审判或自嘲，不要同时乱用所有武器。
- 三角关系必须写清：谁伤害谁，谁替代谁，谁消费谁的回忆。
- 至少设计两句短稳社交句，能单独拿出来发评论或短视频字幕；目标是每句都尽量有分享价值。
- 强词只保留最必要的 1-2 个，不要全段都死、命、氧气、凌迟、乞讨。
- 允许副歌更直白，但必须做声音回路：尾韵、切分、句首反复或关键词回钩至少有一种。

不能过度修正成：
所有流行副歌都变成控诉模板。完整作品仍需要 Verse 证据、Pre 爬坡和 Bridge 翻面；这类写法只适合强情绪传播目标，不适合所有题材。

不能把“每句可分享”误解成“每句都像文案”。强传播副歌仍然必须能唱：主韵、切分、尾音、口型、停顿和重复策略要成立。若一句离开旋律只适合发朋友圈，但唱出来气口散、尾词虚、韵脚乱，不能通过。

不能把所有抽象词和高频词都禁掉。高传播副歌经常使用想念、以后、人海、温柔、资格、位置、名字、心事等公共词，关键是它们有没有被关系重新加工。裸用扣分，加工后可以成为社交货币句。

不能机械套“身份刀、亏欠刀、替代刀、尊严刀”。这些是诊断和构思工具，不是四句填空模板。每段副歌只选最适合当前关系的一两种刀口，其他句子围绕同一伤口加压；如果四句分别展示四套机制，听众会觉得聪明但不真。

关联 skill：
`laohu_lyrics_writer`、`laohu_lyrics_repair`、`laohu_music_topic_writer`

来源作品 / 证据：
老胡 2026-06-27 提供的大量受欢迎流行副歌片段观察。样本呈现高频共性：每句都有独立刀口、第二人称对峙、三角替代、句首反复、强控诉、社交货币句和短视频切片友好。

状态：
待验证，作为类型化经验使用；不升级为所有副歌通用硬门。

### 选题角度 / 模糊灵感拆解

适用范围：
用户只给一句灵感、一个模糊主题、一段情绪或一个大方向，需要先拆成歌曲选题。

不适用范围：
老胡已经明确指定人物、场景、故事线和题眼，只需要进入曲式或填词。

常见初稿缺陷：

- 三个方向只是标题不同，实际都是同一种遗憾、怀念或苦情。
- 只写“误了多年、放不下、错过一眼”这类情绪结果，没有追问结果背后的隐性需求：想被选中、怕承认自作多情、逃避后来的人，或把普通善意误读成命运。
- 嘴替对象太宽，只写所有人、年轻人、中年人、打工人。
- 场景滑向 AI 高频素材：站台、地铁、深夜、未读消息、空房间、旧照片。
- 情绪债务太泛，只写错过、遗憾、释怀，没有具体代价。
- 只找大众都懂的角度，没有找到“小部分人终于被看见”的角度。

评审官常抓的问题：

- 黄伟文会抓角度是否有刺、姿态是否够新。
- 梁宁会抓人群是否精准、需求是否真实。
- 李诞会抓是否太端、太正、太像作文。
- 张爱玲会抓关系里的权力和冷感有没有被看见。
- MrBeast 会抓听众为什么要继续听。

初稿前预防动作：

- 三个方向必须至少有一个不是大众抒情，而是“少数人被看见”的角度。
- 至少一个方向必须回答“为什么会误多年”，不能只回答“误了多年以后多难过”。
- 每个方向必须写明一个具体处境里的人。
- 每个方向必须有冲突、反差或被忽视的日常遭遇。
- 主动标记并替换 AI 高频场景。

不能过度修正成：
为了刁钻而猎奇、为了小众而听不懂、为了传播而像营销标题。

关联 skill：
`laohu_music_topic_writer`

来源作品 / 证据：
`2026-06-10_往后许多年`、`2026-06-10_错把一眼当一生` 和老胡关于选题角度普通化的反馈。

状态：
待验证。

### 都市流行情歌 / 复杂关系

适用范围：
都市情歌、错过、误会、暗恋、遗憾、成年人关系。

不适用范围：
宣言型摇滚、儿歌、强叙事民谣、Rap battle。

常见初稿缺陷：

- 把“我误读了关系”写成“你欠我解释”。
- 用命运、时间、人生等大词替代具体场景和动作。
- 副歌核心句只像金句，没有重复策略和回钩。
- “后来的人”只作为论点出现，没有动作、台词或离开瞬间，导致亏欠感不成立。

评审官常抓的问题：

- 李宗盛评审官会抓“这不像一个真实的人会说的话”。
- 林夕评审官会抓“心理矛盾有没有入口，是否只是漂亮玄句”。
- Max Martin 评审官会抓“hook 是否短、稳、可复唱”。
- Rick Rubin 评审官会抓“是否有装饰性聪明句”。

初稿前预防动作：

- 先确认对方是否真的有承诺；没有承诺就写自我误读，不写对方亏欠。
- 每个大词前必须有具体动作或物件支撑。
- 副歌核心句至少设计一次重复、一次变体或一次回钩。
- 如果主题涉及后来的人或现实关系，至少给对方一个轻动作或轻台词，让主角的亏欠有证据。

不能过度修正成：
所有都市情歌都变成自我检讨、低能量、无锋芒。

关联 skill：
`laohu_lyrics_writer`

来源作品 / 证据：
`2026-06-10_往后许多年`、`2026-06-10_错把一眼当一生` 歌词评审。

状态：
待验证。

### 贴耳叙事型演唱控制

适用范围：
近距离男声 / 女声叙事、遗憾、错过、私密倾诉、耳机循环。

不适用范围：
舞台释放型、摇滚大合唱、国风大开大合、儿童合唱、热血 Rap。

常见初稿缺陷：

- 第一遍副歌过早打开，和声或弦乐遮住核心句。
- 环境声太具象，变成音效展示。
- style prompt 有声音方向，但 controlled lyrics 没有把关键句标出来。
- style prompt 只写 lead vocal 或 close vocal，没有明确性别 / 年龄感、音区、音色、唱法和咬字。
- 行级 `[()]` 控制过密，连续控制同一组中文尾音，导致贴耳叙事变成技巧展示。

评审官常抓的问题：

- 陈奕迅评审官会抓咬字、停顿、尾音是否可信。
- FINNEAS 评审官会抓距离、留白和现代制作。
- Rick Rubin 评审官会抓过度标签、过度弦乐和过度和声。

初稿前预防动作：

- 初稿 controlled lyrics 就要标出核心 hook 前后的留白。
- 第一遍副歌默认先保护主唱前景，再判断是否需要和声。
- 环境声默认低存在感、不可辨词、在人声下 duck。
- style prompt 必须先写清人声身份，例如成熟男声 / 女声、年龄感、音区、音色、近麦距离、咬字和唱法。
- 贴耳叙事型作品的 `[()]` 优先控制停顿、短尾音和最终和声尾巴，不要连续要求 hold / rise / fall / rhyme handoff。

不能过度修正成：
所有歌曲都变成 whisper、极简、无副歌抬升。

关联 skill：
`laohu_sing_control_writer`

来源作品 / 证据：
`2026-06-10_往后许多年`、`2026-06-10_错把一眼当一生` 声音评审。

状态：
待验证。

### 亲情片尾主题曲 / 迟懂亏欠

适用范围：
亲情、代际、爷爷奶奶 / 父母、短剧片尾主题曲、儿童视角回望、长大后才听懂照顾的歌曲。

不适用范围：
轻喜剧亲子歌、儿童儿歌、家庭宣传片、热血励志、纯氛围 BGM。

常见初稿缺陷：

- 把“不想长大”写成泛青春、泛怀旧，没有具体亲情误读。
- 主歌只堆旧物和老家氛围，缺少“当年误读照顾”的关系动作。
- 预副歌继续讲剧情，没有把主歌物件转成身体压力。
- 副歌解释主题，不唱心声；或者为了具体，把剧本信息塞进副歌。
- 只靠“旧、灯光、发烫、回响、风霜”等高频 AI 氛围词制造年代感。
- 短剧主题曲默认听众看过剧本，导致纯听歌时白布、纸钱、木车等意象空降。
- 曲风被做成宣传片弦乐、晚会大合唱或过度 cinematic，而不是近麦迟懂。
- 封面按“多年后回望”生成年纪偏大的主角，和年轻声线不匹配。

评审官常抓的问题：

- 李宗盛评审官会抓这是不是一个真实家庭关系里会发生的误读。
- Rick Rubin 评审官会抓哪些旧物只是摆拍，哪些可以删。
- Max Martin 评审官会抓副歌是否能被普通听众复唱，而不是剧情说明。
- 陈奕迅 / FINNEAS 评审官会抓亲情迟懂是否被唱得过满、过戏剧化。

初稿前预防动作：

- 先写清：当年误读了哪一种照顾。
- 选 1 个核心物件做发动机，最多 2-3 个辅助物件，不堆满老家道具。
- Verse 交代必要前置，让没看剧本的人也能懂。
- Pre 必须有身体受力点：听见、磨到、扎到、答不上、抬不起眼，而不是总结“懂得太晚”。
- Chorus 必须有完美韵和可复唱心声，不能家族韵糊过去。
- 曲风优先 close-mic、folk-pop warmth、music-box / object motif、dry intimate room、restrained final lift。
- 合唱版只做轮唱、轻合和尾句和声，不做晚会合唱。
- 封面人物年龄跟最终声音走，年轻声线优先 18-25 岁青年感。

不能过度修正成：
所有亲情歌都必须用老物件、都必须悲伤、都必须低声克制；如果题材是亲子轻喜剧、春节团圆、母亲节传播或儿童视角儿歌，应该重开风格和语言注册。

关联 skill：
`laohu_music_topic_writer`、`laohu_lyrics_writer`、`laohu_lyrics_repair`、`laohu_music_structure`、`laohu_sing_control_writer`、`laohu_image_writer`

来源作品 / 证据：
`2026-06-18_不想长大` 发布链路；成功案例文件 `02_共享资产库/04_案例经验库/成功案例/2026-06-18_亲情片尾主题曲_不想长大案例.md`。

状态：

### 老胡式内容判断迁移 / 故事线与证据链

适用范围：
模糊灵感、现实感题材、自我清算、普通人处境、关系误读、个人成长类歌曲。

不适用范围：
极简氛围歌、纯口号型应援歌、强类型舞曲 hook、只追求声音循环的电子作品。

常见初稿缺陷：

- 把老胡文稿里的“系统化”误写成规则宣讲，像在讲道理，不像人在唱。
- 只罗列素材：体检、工作、关系、父母、机会、时间，却没有一条因果线把它们推到副歌。
- 评审意见只说“更具体、更有画面、更克制”，没有说明证据、失败后果和具体改法。
- 选题只说“想表达什么”，没有说听众以为自己卡在 A、真正卡在 B。

评审官常抓的问题：

- 梁宁会抓具体人群、具体场景和真实任务是否清楚。
- 李宗盛会抓人生账本是否有真实动作和代价。
- Rick Rubin会抓是不是为了显得完整而堆了不服务作品的素材。
- 黄伟文会抓角度是否只是正确，缺少戏剧姿态和被忽视的人。

初稿前预防动作：

- 先写一句故事推进线：诱发事件 → 误判或逃避 → 阻力加重 → 代价出现 → 不可逆选择 → 副歌认账 / 命名。
- 每个关键判断后面必须能找到一个动作、物件、场景、时间或关系后果。
- Verse 2 和 Bridge 必须让代价升级，不只是换一组素材重复 Verse 1。
- 评审意见按“问题 / 证据 / 后果 / 改法 / 提升项”写，不写空泛命令。

不能过度修正成：
歌曲变成案例分析、观点口播、教程金句或完整答案腔。

关联 skill：
`laohu_music_topic_writer`、`laohu_lyrics_writer`、`laohu_lyrics_repair`

来源作品 / 证据：
老胡文稿项目“具体问题 → 为什么重要 → 动作与证据”的结构偏好，老胡 AI 视觉项目“目标 / 阻力 / 时间压力 / 代价升级 / 不可逆选择”的故事引擎规则，以及老胡关于歌词概念碎片化的反馈。

状态：

### 歌词语言锋芒 / 情绪极值

适用范围：
所有需要表达强烈爱、痛、恨、羞耻、失望、不甘、决绝、自责或控诉的歌词。

不适用范围：
轻喜剧、儿童歌、功能性广告歌、纯氛围电子 hook，以及老胡明确要求温柔治愈的作品。

常见初稿缺陷：

- 语言太软、太平、太温和，只是在礼貌描述情绪。
- 语言太钝：一个情绪要用很多个词解释，但没有一个词、动作或物件能直接把情绪刺出来。
- 句子意思正确，却像复盘、检讨、观点文或自我安慰，不像歌词里的人被逼到出口。
- 用“遗憾、错过、释怀、成全、温柔、想念、后来、从前”等安全词连续承担高潮，听起来正确但没伤口。
- 把一点点伤口写成“要死了”的浮夸，没有真正的动作、代价和关系后果。
- 评审意见也很软，只说“更有画面、更有力量”，没有指出哪句软、为什么软、该换成什么带刺的词。
- 评审意见也很钝，只说“不够锋利”，却没有给出可替换的动词、名词、物件或罪证动作。
- 副歌没有不可逆句，说完以后关系还能原样退回去。

评审官常抓的问题：

- 黄伟文会抓姿态是否有戏，句子有没有刺。
- 林夕会抓痛感是不是有心理入口，而不是空泛大词。
- 李宗盛会抓这句是否像一个真的人会唱出口。
- Rick Rubin会抓狠词是不是服务作品，还是为了显得高级而装狠。

初稿前预防动作：

- 先为主情绪建立“极值词场”：这个人痛、爱、恨、失望或羞耻到顶点时，会说哪些词，绝不会说哪些词。
- 再建立“语言开刃表”：每个抽象情绪至少配 3 个可唱的动词、名词、物件或罪证动作。
- 高潮句至少要有一处动词或名词带伤口，例如删、锁、还、撕、吞、欠、烂、冷、空、脏、旧、赌、赔、认。
- 每首歌至少检查一句“说出口以后回不去”的不可逆句。
- 如果必须使用安全词，前后必须有更硬的动作、物件或关系代价托住。

评审执行动作：

- 必须列出“钝句替换表”：原句、钝在哪里、开刃词是什么、替换句是什么、替换后提升什么。
- 如果一个情绪需要三句解释，优先压缩成一个词、一个动作或一个物件，而不是继续加说明。
- 评审官不能只给“更有画面、更锋利”的抽象建议，必须给出至少 1 个可直接替换的句子。

不能过度修正成：
粗暴、猎奇、脏话堆砌、无意义伤害、为狠而狠，或把所有歌都写成控诉。

关联 skill：
`laohu_music_topic_writer`、`laohu_lyrics_writer`、`laohu_lyrics_repair`

来源作品 / 证据：
老胡关于当前歌词“太软弱、太柔弱、太平和、不够锋利，不像一把刀捅进心口”的反馈。

状态：
待验证。

### 教材吸收 / 歌词类型路由

适用范围：
每次从题眼进入曲式、填词或演唱控制前，都需要判断歌词类型、使用场景和演唱主体。

不适用范围：
老胡只要求单句 hook、标题候选或局部改句，尚未进入完整歌曲阶段。

常见初稿缺陷：

- 只写“流行、摇滚、儿童、影视、行业”等标签，没有把类型转成写法约束。
- 通俗歌写成大道理，儿童歌写成成人腔，行业歌写成口号，摇滚写得太礼貌，广告歌写得太啰嗦。
- 为特定歌手或虚拟主唱写歌时，没有先判断声音、年龄感、音区、形象和市场定位。
- 现成曲填词时先写散文式歌词，再硬塞旋律，导致倒字、气口错、长音尾字不可拖。

评审官常抓的问题：

- 类型适配老师抓“这是不是这类歌该有的语言和结构”。
- 歌手适配老师抓“这句话是不是这个歌手 / 虚拟主唱能唱出口”。
- 词曲贴合老师抓重拍、气口、长音、倒字、句式疏密和旋律情绪是否匹配。

初稿前预防动作：

- 先写类型路由卡：歌词类型、使用场景、目标听众、演唱主体、语言颗粒度、篇幅约束、传播目标。
- 对定制歌手作品，先写歌手画像：性别、年龄感、音区、音色、形象、过往作品、市场定位和可接受突破范围。
- 对现成曲填词，先做旋律地图：乐段、乐句、重拍、气口、长音、重复音、情绪走向。
- 每首歌都要提前找“一句话工程”：最能被唱、记、传播、复述的核心句。

不能过度修正成：
把所有歌都写成类型教科书，或为了适配类型牺牲老胡真正要表达的题眼和人物。

关联 skill：
`laohu_music_topic_writer`、`laohu_music_structure`、`laohu_lyrics_writer`、`laohu_lyrics_repair`、`laohu_sing_control_writer`

来源作品 / 证据：
《歌词写作十八讲》第十一至十四讲关于不同类型歌词、歌手定制、现成曲填词和歌词修改的作词工艺。

状态：

### 自我清算 / 准备不足题材

适用范围：
关于拖延、准备不足、长期透支、人生还账、错过窗口期的现实题材。

不适用范围：
热血励志歌、明确宣言型摇滚、校园考试单一场景、纯职场爽文。

常见初稿缺陷：

- 选题滑向时间管理、自律鸡汤或“从今天开始努力”。
- 歌词把体检、工作、父母、关系、机会并列成清单，像复盘报告，不像歌。
- 副歌把道理一次性讲完，缺少短稳可复唱 hook。
- Bridge 变成“命运挑时间”的控诉，削弱自我认账。
- 演唱控制把 alternative rock 副歌做成励志摇滚大合唱。

评审官常抓的问题：

- 李宗盛评审官会抓是否有普通人真实代价，是否像人夜里认账。
- 黄伟文评审官会抓是否太正确、太鸡汤、太像公众号标题。
- 罗大佑评审官会抓个人失约背后有没有群体透支感。
- Max Martin 评审官会抓副歌是否太解释、句尾是否可复唱。
- Rick Rubin 评审官会抓是否过度励志、过度编曲、过度表演。

初稿前预防动作：

- 先定一个可传播的账本型或透支型 hook，不要用“要准备、别拖延”当题眼。
- 每一类亏欠只保留最有代价的一笔；必须写动作或后果，例如“她后来不问了”“父母少打给我”。
- 副歌后半只承担回钩和认账，不承担完整说理。
- Bridge 优先写“账到期 / 认账 / 躲过的晴天回来认名字”，不要写命运控诉。
- 声音上采用成熟近麦男声、克制鼓和吉他推进，禁用 anthem belting、choir、major-key catharsis 和 guitar wall。

不能过度修正成：
低能量自责、失败者独白、时间管理教程、热血翻身歌。

关联 skill：
`laohu_music_topic_writer`、`laohu_lyrics_writer`、`laohu_sing_control_writer`

来源作品 / 证据：
`2026-06-10_早该准备的人` 选题评审、歌词评审和声音评审。

状态：
待验证。

### 流行国风 ballad / 自欺遗憾题材

适用范围：
流行国风、国风情歌、宿命感意象、错过、遗憾、自我误认、把胆小包装成缘分的题材。

不适用范围：
纯古风大叙事、戏曲腔作品、家国国风、江湖豪气歌、古装影视主题曲。

常见初稿缺陷：

- 把国风理解为增加灯、檐、桥、红尘、天意、流年等布景词，器物没有参与人物动作。
- 核心器物很多，但没有一个持续承担遮掩、揭穿、递还、阻拦、催促或见证功能。
- 遗憾自责型歌词只写氛围，不写自欺证据。
- 演唱控制把古筝、琵琶、二胡、笛子等乐器一起塞入 prompt，导致生成成古装配乐。
- 中文前鼻音尾字被直接写成 hold，导致尾音扁、硬、像口号。
- Bridge 认罪段被写成 near-spoken / dry / no vibrato，唱成朗读，缺少半唱式羞耻感。

评审官常抓的问题：

- 国风语体评审会抓器物是否只是布景，是否真的暴露人物真相。
- 普通人代价评审会抓有没有“没寄出的信、没拨出的电话、没走上前的一步、听到消息时假装平静”的自欺证据。
- 制作评审会抓 style prompt 是否过满、国风乐器是否过多。
- 中文咬字评审会抓前鼻音、气口和 Bridge 是否唱成朗读。

初稿前预防动作：

- 先选一个核心器物，并规定它至少完成 3 个动作，例如藏签、改签、拆签、还签。
- 每出现一次缘分、天意、命、流年等词，都要配一个人物逃责任的动作证据。
- 主国风音色最多 2 个，默认一个核心音色即可，例如 guzheng + warm electric piano。
- style prompt 不靠乐器堆砌防 generic，而靠成熟人声、现代流行骨架、hook 让位和克制空间。
- 对“眼、言、签、前”等前鼻音尾字，不写 hold 字；写 sustain vowel before 字 + quick nasal close。
- Bridge 承担认罪、后悔、羞愧时，用 half-sung confession、close breath、slight pitch lean，不用全干念白。

不能过度修正成：
完全去掉国风质感、只剩都市流行情歌；或为了克制把 Bridge 唱成无旋律朗读。

关联 skill：
`laohu_lyrics_writer`、`laohu_lyrics_repair`、`laohu_sing_control_writer`、`laohu_sing_control_repair`

来源作品 / 证据：
`2026-06-11_人海那一眼` 选题评审、歌词评审和声音评审。

状态：
待验证。

### 国风宿命怨诉慢歌 / 不可得对象质问

适用范围：
古风 / 国风情爱、孤寂、求而不得、被命运绕过、明月 / 天命 / 轮回 / 江水 / 长夜等不可触及对象承载情绪的慢板抒情歌。核心不是两个人当面对峙，而是主唱把怨、孤独和求爱投向一个高处、远处或不可更改的对象。

不适用范围：
积极热恋、轻甜国风、少年意气、家国群像、江湖快歌、都市写实情歌、需要强现实对话的作品。

常见初稿缺陷：

- 只堆月、江、寒、孤、宿命、轮回、千年、万劫等古风词，人物没有自己的动作和处境。
- 副歌只写“我很孤独 / 我很痛 / 命运不公”，没有把情绪压成可传播的质问或祈求句。
- 主歌和副歌都在写同一种孤寂，没有从隐忍、怨怼、质问、求告到认命 / 余光的情绪转向。
- 把不可得对象写成装饰性意象，没有让它真的参与关系：照见别人、绕过我、沉默不答、只留余光等。
- 桥段只是继续加大痛苦，没有完成“恨到求 / 怨到乞 / 控诉到认账”的翻面。
- 曲风提示词只写古风、悲伤、电影感，缺少 BPM、小调、段落动态、民乐和弦乐分工、人声声线和混响空间。

为什么会被喜欢：

- 它给了听众一个可代入的外部承受对象。人不一定愿意直接怪某个人，但可以怪月、天命、宿命、轮回，这样情绪更安全、更戏剧化，也更适合国风传播。
- 副歌核心通常是“为什么偏偏不是我”的结构，既通俗，又有古风高度；听众不用懂复杂故事，也能认出被错过、被冷落、求而不得的心情。
- 主副歌用同一核心意象反复追问，记忆点集中；Bridge 再把质问改成低声祈求，情绪层次会明显变深。
- 音乐上慢板小调、清冷民乐、弦乐渐强和清冷烟嗓女声很容易形成短视频 BGM 画面：孤影、寒江、月夜、宿命、回眸、诀别。

初稿前预防动作：

- 先确定一个“不可得对象”：明月、天命、轮回、江水、长夜、神佛、旧梦等。它必须能承担动作，不只是氛围名词。
- 给这个对象安排 2-3 个可唱动作：照见 / 绕过 / 不答 / 高悬 / 沉落 / 隔岸 / 误我 / 留我。动作必须符合对象物性和公共语感。
- 主歌先写低处动作：独坐、凭栏、独酌、听风、看江、守夜、梦醒、无人共话；不要一开头就把副歌核心判词唱完。
- 预副歌负责把低处孤影推到命运压力：不羡繁华、偏守一处、曲有情而人无情、被宿命反复碾过。尾句要悬到副歌质问。
- 副歌用同一核心句式反复追问或判给自己，句法可对称、可反复，但每句要推进一层：对象高悬 → 照别人不照我 → 若有因果为何独受 → 终局落到我。
- Bridge 必须翻面：从恨、怪、怨，转成求、愿、只要一点余光、只求被看见。Final 或尾句再回收这个新姿态。
- 古风词密度可以上浮，但每 4 句至少要有 1 个清楚动作；连续宏大词不得超过 2 句。

曲风与演唱预防动作：

- 曲式默认慢板大动态：Verse 轻、Pre 推、Chorus 强、Bridge 最强或最痛、Outro 渐弱留白。
- BPM 默认 72-76，小调，清冷、孤寂、幽怨、宿命感，适合古风流行 / Mandopop ballad。
- 编曲用少量核心民乐建立世界，常用古筝 / 竹笛 / 琵琶择 1-2 个，配钢琴单音、大提琴长线和弦乐渐强；不要把所有民乐都堆上。
- 人声可选成熟女声、清冷烟嗓 / 轻沙哑、中低音、气声与胸声渐变；主歌低吟，预副歌咬字变实，副歌强混爆发，Bridge 带哭腔但不乱转音，尾句回到气声留白。
- 混音强调宽声场、长混响、大动态和人声前置；人声必须清楚，不能被弦乐和大鼓盖住核心质问句。

不能过度修正成：
所有古风歌都写月亮、宿命和轮回；所有国风慢歌都用怨诉质问。若题材是积极初恋、少年热血、家国群像或轻甜国风，必须换成更明亮的动作和声音容器。

### 高考毕业 / 散场失重题材

适用范围：
高考结束、毕业散场、同班关系走散、校园共同生活秩序消失、青春失重感题材。

不适用范围：
热血励志毕业歌、校庆晚会歌、官方毕业主题曲、纯同学情合唱。

常见初稿缺陷：

- 只堆准考证、上课铃、操场、试卷、晚自习、同桌、校服等公共素材，缺少一个具体人物和具体亏欠。
- 把高考结束写成“青春不散场、未来可期、奔赴远方、梦想启航”等毕业套话。
- 只写“我们分开了”，没有写失去什么具体照顾：没人占座、没人等晚归、没人催早读、没人替你留灯。
- 副歌连续使用“不是 A，是 B”的观点句，像毕业文案，不像人物在唱。
- Bridge 只写“想再听铃声、想再抱怨作业”，没有没回头、没还东西、没问志愿、没好好告别等罪证。
- 演唱控制用校铃、合唱、弦乐和青春仪式感证明毕业，导致生成成毕业晚会歌或校园宣传片。

评审官常抓的问题：

- 普通人代价评审会抓是否写出被共同秩序接住的生活突然撤场。
- 公共记忆评审会抓铃声、座位、灯光是否是共同记忆，而不是素材堆叠。
- Hook 评审会抓“一场考试把我们考散”这类钉子是否短、准、可唱。
- 声音评审会抓副歌是不是大喊、合唱是不是晚会化、尾音是不是有留白。

初稿前预防动作：

- 先找一个具体人物和一笔具体亏欠：没回头、没还橡皮、没问志愿、没说再见。
- 公共素材只能服务这个亏欠，不能自己当主角。
- 副歌前四句可以承担题眼，后四句必须落到具体代价，不再继续解释观点。
- “考散 / 同班 / 留灯 / 转身”等尾字要检查咬字、收口和留白。
- 演唱控制默认近麦叙事、低声共鸣、Final Chorus 轻合而不喊。
- 谨慎使用 school bell、choir、cinematic strings、anthem lift 等会触发晚会模板的提示。

不能过度修正成：
只写私人暗恋而失去毕业公共记忆；或完全去掉副歌合唱感，导致毕业季传播弱。

来源作品 / 证据：
`2026-06-11_散场以后` 选题评审、歌词评审和声音评审。

### 差点伤害别人 / 主动方自我刹车题材

适用范围：
差点伤害别人、差点复制暴力、关系里主动伤害者自我刹车、成年后发现自己正在变成曾经最恨的人、亲密关系冲突里主动方必须停止侵入的题材。

不适用范围：
普通误会后的双向和解、双方都安全且愿意靠近的亲密修复、纯受害者逃离视角、没有主动伤害风险的自责歌。

常见初稿缺陷：

- 对方已经说“别靠近”、退缩、挡脸或沉默，主动方却立刻上前拥抱、捧脸、擦泪、安慰，把继续靠近误写成温柔。
- 副歌太快证明“我长大了 / 我变好了 / 我知道错了”，让主动方的悔意抢走受害方的恐惧。
- 只写自责程度，例如“我有多差、我多后悔”，没有写危险临界点：那只手、那句话、那声门响、那一步逼近是怎么停住的。
- 把上代暴力写成玄句，例如拳头躲进骨架、影子住进身体，但没有转成当前可感的手势、嗓门、眼神、摔门声或桌沿声。
- 把“伤害不传递”写成概念句，没有落到收手、闭嘴、后退、退出现场、不求原谅这些动作。
- 只把边界动作列成“我不摔门 / 不靠近 / 不辩解 / 不求原谅”，伦理正确但像承诺清单，缺少当场被自己吓到的恐惧、羞耻、自我厌恶和记忆刺点。
- 把普通话心理机制分行，例如“像把他摁回去 / 我也怕我自己 / 冒出他的语气”，关系能解释通，但像文章叙事，缺少副歌的韵脚回环、文学遮蔽、可复唱主句和情绪出口。

评审官常抓的问题：

- 动作伦理评审会抓：对方已经害怕时，主动方靠近是不是继续侵入。
- 关系视角评审会抓：忏悔有没有抢走受害者空间。
- 副歌功能评审会抓：核心是在阻断伤害，还是在给主动方做自我感动。
- 语言评审会抓：旧伤、父亲影子、暴力继承有没有被转成第一耳能懂的动作和声音。

初稿前预防动作：

- 先写普通话动线：危险动作出现 → 对方防御 → 主动方被照醒 → 收手 → 后退 / 闭嘴 / 不辩解 → 不求原谅 → 伤害停在自己这里。
- 副歌动作优先使用：收手、放下、停住、咽下、后退、带门、让开、退出、别求原谅。
- 不要把“看见眼泪”自动修成拥抱或捧脸；只有双方已经安全且对方允许靠近时，贴近动作才成立。
- 副歌至少有一句写“危险地接近自己最恨的人”，但要通过手、嗓子、门声、桌沿声、眼神等具体对象表达。
- 结尾落点优先是“我没有让伤害继续”，不是“我证明自己变好了”。
- 边界动作必须歌词化：否定句最多作为骨架，副歌要补足惊觉、羞耻、罪证动作和阻断落点；每段至少压出一句能被记住的刺点。
- 写副歌前先定一个可复唱主句和韵脚回环，再放少量罪证动作；不要先写心理分析，再把分析切成八行。

不能过度修正成：
主动方完全消失、只剩口号式道歉；或把所有亲密修复都禁止靠近。边界规则只在对方已经恐惧、防御或要求距离，且主动方刚刚造成危险或差点造成危险时触发。

来源作品 / 证据：
`2026-06-15_把手放下` 副歌评审与老胡关于“捧住你的脸”动作伦理的反馈。
