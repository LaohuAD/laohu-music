# 曲式结构与乐段功能规则

本文件是老胡音乐关于先曲后词、曲式骨架、段落功能和编曲空间的专项规则库。

它比 `laohu_music_structure` skill 更细，负责补充曲式裁决、段落功能、hook space、人声预留空间和纯音乐 style prompt 的质量校验。

本文件属于增强资产，不承担曲式 writer 的基础下限能力。主风格裁决、曲式模板、段落基础功能、hook space 和停止条件必须写在 `skills/laohu_music_structure/SKILL.md`；本文件只提供更细的结构模型、乐段解释和类型化增强。

老胡音乐当前流程不是完全先词后曲，也不是完全先曲后词，而是：

```text
先确认方向标题、主唱 POV、题眼、副歌核心句和选题阶段结构草图
→ 再用曲式和风格框住情绪
→ 再按这个骨架填词
```

填词时也不是从第一句开始平铺直叙。默认写作顺序是：

```text
先确定副歌核心主句
→ 再设计主歌故事和证据
→ 再写预副歌情绪推进
→ 最后写桥段转折和最终副歌加重
```

原因：副歌是整首歌的记忆点和情绪出口。主歌、预副歌和桥段都必须反过来服务它：主歌证明它，预副歌把人推向它，桥段改变听众对它的理解，Final Chorus 让它更重。

## 0.0 选题阶段结构草图：先让老胡看清整首歌怎么走

选题阶段的结构草图不是曲式阶段的正式 BPM、段落长度或风格容器，但它必须先回答“这首歌的情绪和故事如何从头走到尾”。没有结构草图就进入副歌、曲式或歌词，后续很容易主歌、副歌、桥段都重复同一种情绪。

选题阶段至少给三层曲线：

```text
整首总情绪曲线：从哪里起、怎么升、在哪里爆、哪里翻面、最后落到什么态度。
乐段职责曲线：先确认歌曲类型和基础曲式，再按曲式说明 V1 / Pre1 / C1 / V2 / Pre2 / C2 / Bridge / Final C 等乐段各自承担什么任务。
乐段内部微曲线：每段内部从什么情绪起，经由什么动作 / 声音变化，落到什么态度或未完成感。
乐段意象曲线：每段建议使用哪些物件、身体、声音、位置或动作，它们如何随情绪变紧、变重或翻面。
```

选题阶段不能先写乐段任务再倒推曲式。正确顺序是：

```text
歌曲类型
→ 基础曲式模板
→ 乐段标签
→ 每个乐段的故事、情绪、分镜和修辞密度
```

如果歌曲类型没有确认，必须先给老胡 2-3 个类型和曲式选择，并说明推荐哪一个。不能直接猜一个曲式当成已定结果。

标准大众抒情曲的完整骨架默认是：

```text
V1 + Pre1 + C1 + V2 + Pre2 + C2 + Bridge + Final C
```

不能简写成 `Verse / Pre / Chorus / Verse 2 / Bridge / Final Chorus` 后就把第二轮 Pre + Chorus 漏掉。第二轮的作用不是凑段落，而是用新证据加深人物处境，再让副歌重复一次，形成记忆和情绪加压。

Pre 必须特别说明：从 Verse 哪个画面、动作、声音或身体反应抽出触发点；这个触发点如何让人物心理升级；歌词里准备用什么停顿、句长、尾音、韵脚或动作把压力推到 Chorus。Bridge 必须说明翻面方式；Final Chorus 必须说明比第一次 Chorus 多出的意义层。

曲式乐段规划必须体现关系推进。曲式不是只给段落排队，而是让关系一步一步变化：Verse 说明当前关系如何卡住，Pre 说明哪个动作让人物误判松动，Chorus 说明关系判断如何爆出来，Verse 2 说明现实条件如何加压，Bridge 说明关系如何被重新命名，Final Chorus 说明人物如何退出、承担、和解或反击。没有关系状态和关系变化的乐段表，只是格式，不是创作规划。

每个乐段还要说明“意象使用策略”。意象不是装饰词，也不是越多越好，而是让听众看见关系和情绪的证据。Verse 可以多放具体物件和动作；Pre 要收紧到触发点、身体反应和声音；Chorus 只留最核心的 1-2 个动作或词；Bridge 让旧意象翻面或叠加；Final Chorus 用更少、更硬的意象收束。没有情绪功能、场景功能或关系功能的意象，不进入乐段规划。

乐段意象必须先过“同一现场”检查：同一时间、同一地点或连续空间、同一人物在场状态、同一动作链。一个物件如果要求人物已经离开现场，另一个物件却要求施暴者正在面前下跪，这不是意象丰富，而是场景冲突。远程消息、事后通话、后来搬走后的物件、过去几次发生的旧画面，都可以写，但必须明确放在回忆、Bridge、Verse 2 的连续空间或另一个选题版本里。没有标明时空关系的混搭，会让歌词像素材拼贴，观众不知道自己站在哪个房间、哪一分钟、看见谁。

乐段意象还必须先过“题材机制”检查。先判断这个场景为什么会发生、靠什么关系机制推进、人物真正被什么卡住，再选择物件。所谓典型意象，不是这个题材里常见的装饰物，而是缺了它故事就不成立、情绪就没有触发点、关系就无法被证明的关键证据；它不是因为场景存在才被摆进去，而是反过来搭建场景、证明关系、烘托情绪、把人物推过心理阈值的支柱。它可以是物件、动作、声音、称呼、身体反应、空间位置或时间节点。没有机制支撑的物件，即使具体，也只是摆拍。强情绪题材必须检查阈值递进：多个证据不是平铺堆惨，而是一个比一个更接近情绪崩口，直到副歌不得不发生。家暴题材不能只写“喝酒、抽烟、摔杯子”这些表象；它们可以出现，但必须服务控制、威胁、羞辱、阻断离开、事后道歉循环、孩子和证件带来的现实牵绊。

强叙事主歌还要检查“证据链推进”，不能只检查单个意象是否具体。高质量意象组要有空间、时间和身份跨度：外部世界如何闯入家庭，家庭残留如何落到身体，身体痕迹如何延伸到校服、鞋底、工作服、证件、病历、工资表等社会身份物。比如雪、车队、轰鸣声、摔断的腿、床底玻璃瓶、母亲淤青、校服袖口、鞋底烟灰这一组，厉害处不在词新，而在它把外部事故、家庭暴力、长期堆积和孩子被卷入连成一条证据链。后续写类似题材时，不得只抄“瓶子 / 淤青 / 烟灰”，要先复制这种推进逻辑。

曲式乐段规划要继承选题阶段的“场景生态链”：外部压力如何进入场景，内部关系如何变化，时间痕迹如何堆积，身份物如何被改变，最终哪个证据触发副歌。换成校园爱情、家园、社会关系等题材时，不能套家暴物件，而要按同一生态链寻找对应题材里缺了就不成立的证据。

当老胡明确是在训练完整创作流程、要求“一个一个来”或只打磨某个乐段时，不使用一次性交完整歌词的方式。副歌核心句确定后，必须进入单乐段工作台：

```text
1. Verse 1 工作台：
只确定产生副歌情绪的第一现场。回答时间、地点、人物位置、关系压力、谁做了什么、主角看见 / 听见 / 身体反应了什么。Verse 1 的任务是给副歌提供证据，不解释副歌。

Verse 1 的歌词化不能只把普通话场景分行。它要把“第一现场”拍成几组可唱镜头：核心名词负责让听众认出空间和生活痕迹，核心动词负责让这些名词带出压迫、退让、后悔或危险。名词优先选择公共认知里能成立的物件、身体、声音和位置；动词必须让场景推进或让关系变紧。主歌可以叙事，但必须先是歌词，至少有家族韵、尾音回环或明确换韵设计。

Verse 1 的最后一句必须是交给 Pre-Chorus 的压力点，不是收尾镜头。它可以留下一个未解决动作、声音、位置或身体反应：手悬着、灯影晃着、碗沿颤着、对方后退、半句话卡着、门外声音逼近。不要用天亮、热气散尽、夜过去、门关上这类结束感镜头把主歌收掉；否则 Pre 会失去爬坡对象。

如果副歌核心句依赖某个不可逆动作，Verse 1 末尾只能逼近这个动作，不能完成这个动作。比如副歌要唱“我把手放下”，Verse 末句就不能写手已经落下、影子已经矮下去、危险已经解除；它必须停在手悬着、影子压着墙、对方挡着脸这一类未解决瞬间，给 Pre 留出认出问题和情绪爬坡的空间。

2. Pre-Chorus 工作台：
只从 Verse 1 里挑一个压力点或触发点，把它拧紧。回答是什么原因把人物推到副歌，哪里卡住，入副歌前的停顿是什么。Pre 不是第二段主歌。

3. Chorus 回看：
确认已打磨副歌是否仍适配 Verse + Pre。只做极小幅适配，不推翻已确认 hook。

4. Verse 2 工作台：
换时间、换证据、换关系压力或加深误判，不能重复 Verse 1。

5. Pre 2 / Bridge / Final Chorus 工作台：
Pre 2 继续爬坡或变体；Bridge 负责翻面；Final Chorus 负责加重或回收。
```

每个工作台都必须先确认“乐段功能和普通话场景”，再写歌词化版本。当前乐段未确认时，不主动铺完整首歌。

## 0. 使用边界：曲式必须服从创作中枢

曲式、三幕式、五幕剧、英雄之旅和反转阶梯都是内部骨架，不是对老胡展示的主产物。每次使用前必须先确认：

```text
这首歌替谁唱？
他在什么场景里痛？
他最想说但说不出口的是哪句话？
副歌能不能替这个人把没说出口的话说出来？
这句话能不能唱、能不能记、能不能传播？
```

对外说明时，优先说“Verse 怎么让人进场、Pre 怎么把话憋到副歌、Chorus 怎么让他唱出来、Bridge 怎么翻面”，不要先展示结构术语。结构术语只服务写歌，不负责证明方案专业。

## 1. 曲式与风格阶段的任务

曲式不是格式，风格不是审美标签。

这一阶段要回答：

- 什么声音容器最能放大题眼？
- 什么曲式能逼出副歌核心句？
- 哪个乐段负责叙事，哪个乐段负责收紧，哪个乐段负责释放？
- 哪里要留出 hook space？
- 哪里要给人声预留气口？
- 编曲要在哪些地方让位给歌词？

## 1.1 曲式底层原则：重复 + 对比

流行歌的基本记忆机制是：

```text
重复：副歌、Hook、关键词、旋律回钩，让听众记住。
对比：Verse 与 Chorus、Pre 与 Chorus、Bridge 与前文，让情绪有变化。
```

只有重复没有对比，会变成口水循环；只有对比没有重复，会变成散文段落，听众记不住。

曲式阶段必须先判断这首歌的核心策略：

```text
叙事优先：Verse 需要更多空间，副歌负责总结和释放。
Hook 优先：Chorus 需要更早、更短、更重复。
情绪爬坡优先：必须加 Pre-Chorus，让副歌不是突然喊出来。
转折优先：Bridge 必须承担翻面或关系重估。
短视频优先：副歌和 Hook 要可截取，结构可以更短、更循环。
```

## 1.2 基础段落标签

项目默认使用这些乐段标签：

```text
Intro：前奏，建立空间和听觉入口，通常不写正文歌词。
Verse / V：主歌，讲故事、铺画面、给证据。
Pre-Chorus / Pre：预副歌，收紧情绪、制造爬坡、把主歌推向副歌。
Chorus / C：副歌，情绪高潮、核心主题、Hook 和传播资产。
Bridge / B：桥段，打破重复、视角翻面、关系重估、最后加压。
Outro：尾奏 / 尾段，回收题眼，留余波，通常不做作文总结。
Hook：记忆点，通常藏在 Chorus，也可以出现在 Intro、Post-Chorus 或 Outro。
```

Hook 不是一个固定段落名，而是听众最容易记住的短句、旋律或节奏单位。副歌没有 Hook，结构再完整也会弱。

## 1.3 叙事结构到歌曲乐段的转换

三幕式、四幕式、五幕剧、八序列、嵌套三幕、平行三幕、倒叙 / 插叙、英雄之旅和反转阶梯，本项目不把它们当成死模板，而是当成安排“信息、情绪、反转和回收”的底层骨架。

歌词篇幅短，不能照搬小说或长文结构。执行时只做转换：

```text
冲突 / 钩子 → 情绪矛盾、关系卡点、场景对立、人物嘴硬。
递进 / 对抗 → 主歌证据增加、预副歌压力收紧、Verse 2 代价升级。
阐述 / 铺垫 → 物件、动作、旧习惯、声音、时间磨损证据。
反转 → 心境变了、口吻变了、意象翻面、关系被重新理解。
解决 / 收尾 → 副歌认账、Bridge 翻面、Final Chorus 加重、Outro 回收。
```

### 1.3.1 标准三幕式对应乐段

```text
第一幕 建置：Verse 1
任务：让人物进场，给出具体处境、关系压力和情绪缺口。

第二幕 对抗：Pre-Chorus + Verse 2
任务：把处境推深，增加阻碍、误判、逃避、身体反应或损失。

第三幕 解决：Chorus + Final Chorus + Outro
任务：把前面的证据压成可唱、可记、可复述的情绪宣言，并在尾段留余味。
```

注意：这不是说所有歌都要先写 Verse 再写 Pre 再写 Chorus。它只说明每个乐段应该承担的心理动作。短歌可以压缩三幕，叙事歌可以扩展三幕，但不能让每段都只重复同一种情绪。

### 1.3.2 四幕式和五幕剧对应乐段

四幕式适合解决“第二段主歌没推进”的问题：

```text
建置：Verse 1，交代人物和现场。
上升行动：Pre / Verse 2，人物开始行动或误判加深。
下降行动：Bridge，局势翻面，代价暴露，人物跌到不能再装。
结局：Final Chorus / Outro，带着新认知重唱核心句。
```

五幕剧适合叙事型歌词、古风 / 国风叙事歌、民谣故事歌和说唱故事歌：

```text
开端：Verse 1，时间、地点、人物、基础冲突。
发展：Verse 2 / Pre，故事推进，线索和情绪升温。
第一高潮：Chorus 1，第一次情绪爆发或核心心声出现。
回落与二次反转：Bridge，推翻前面一层理解，暴露更深代价。
结局：Final Chorus / Outro，新心境下重唱或回收题眼。
```

### 1.3.3 八序列和英雄之旅对应成长类歌曲

八序列和英雄之旅只在成长、治愈、励志、事业转折、第一桶金、离家、毕业、重新开始等题材里使用，不要强行套进所有情歌。

歌词执行时压缩成：

```text
常态世界：他原来怎么活，原来的秩序是什么。
召唤 / 激励事件：哪件事打破原来的日子。
拒绝 / 逃避：他为什么不敢面对，怎么嘴硬、拖延或假装。
试炼 / 怪兽：现实压力、关系压力、钱、病、距离、身份羞耻或自我怀疑具体出现。
逼近内核：他终于看见自己真正怕什么、缺什么、想要什么。
终极考验：一个不可逆动作或承认。
回归 / 新平衡：副歌或尾段给出新身份、新代价或新名字。
```

### 1.3.4 反转阶梯对应 Bridge

歌词里的反转不等于复杂剧情，优先是三种：

```text
意象反转：同一个物件前后意义变了。
心境反转：从想走、恨、躲、装没事，翻到承认、舍不得、认输或放手。
认知反转：原来不是爱、不是恨、不是自由、不是结束，而是更深的缺口。
```

Bridge 是最常见的反转位。桥段必须让最后副歌变重；如果 Bridge 只换漂亮画面，没有推翻、承认、暴露或转向，就不算反转。

### 1.3.5 嵌套三幕对应段落内部

嵌套三幕用于检查每个乐段内部有没有推进：

```text
单句：画面引入 → 动作推进 → 情绪或关系落点。
主歌：现场证据 → 关系压力 → 小转折。
副歌：核心句 → 加重 / 变体 → 回钩。
整首歌：建置 → 对抗 → 翻面 / 认账 / 回收。
系列作品：单歌独立成立，多首歌再组成更大的情绪起落。
```

它的目的不是把歌词写复杂，而是防止每一句都在同一个平面上说明情绪。

## 1.4 五种基础流行曲式模板

曲式选择不是越复杂越好，必须服务题眼、风格和传播目标。

### 模板 1：最简主歌 + 副歌

```text
V1 → C
```

适合：

- 短歌。
- 短视频 BGM。
- 儿歌。
- 极简民谣。
- 只需要一个情绪入口和一个记忆点的作品。

风险：

- 故事不够完整。
- 情绪层次较少。
- 副歌弱时整首歌会立刻塌。

### 模板 2：经典标准流行结构

```text
V1 → Pre → C → V2 → Pre → C → B → C → C
```

适合：

- 大多数华语流行、情歌、国风流行、R&B、流行摇滚和旋律说唱。
- 需要完整叙事、情绪爬坡、重复强化和 Bridge 翻面的作品。

硬门：

- V1 建立人物和故事开端。
- Pre 把压力推到不得不唱。
- C 释放核心句并承担 Hook。
- V2 必须推进，不得复述 V1。
- B 必须翻面，不得只是换一组漂亮句子。
- 最后 C / C 必须更重、更多层或更确定，不能机械复制。

### 模板 3：无预副歌简约流行

```text
V1 → C → V2 → C → B → C
```

适合：

- 摇滚。
- 快歌。
- 部分古风。
- 情绪进入很直接、不需要长爬坡的作品。

风险：

- 主歌到副歌容易突兀。
- Verse 必须自带足够张力，否则 Chorus 像突然喊口号。

### 模板 4：循环短句 / 舞曲 / 神曲结构

```text
V → C → C → V → C → C
```

适合：

- 口水歌。
- 舞曲 / 电子流行。
- 广场舞。
- 强短视频传播。

硬门：

- 副歌短语必须可循环、可卡拍、可复唱。
- 弱化叙事可以，但不能没有记忆点。
- 词不要写成长句和复杂故事。

### 模板 5：抒情慢歌 / 民谣加长铺陈

```text
V1 → V2 → C → V1' → V2' → C → B → C
```

适合：

- 伤感慢歌。
- 走心民谣。
- 需要慢慢铺场景和关系的作品。

硬门：

- 两段 Verse 必须分工：一个铺场景，一个加关系压力或时间变化。
- 情绪慢不等于内容空。
- 进入 Chorus 前必须已经压出足够情绪债务。

## 2. 常见曲式功能

### Intro

作用：

- 建立空间、情绪和听觉入口。
- 不抢副歌核心句。
- 可以留下一个可截取的短视频入点。

### Verse

作用：

- 让人物进入。
- 给出具体处境、动作和关系压力。
- 不负责解释完整背景。

判断：

```text
Verse 是否让副歌更必然？
如果删掉 Verse，副歌是否会变成空喊？
```

### Pre-Chorus

作用：

- 收紧情绪。
- 把主歌里的生活压力推到副歌前。
- 让副歌不是突然喊出来。

常见做法：

- 句长变短。
- 和声或节奏逐步抬升。
- 留出入副歌前的停顿。
- 把问题逼到“不得不唱”的位置。

### Chorus

作用：

- 兑现副歌核心句。
- 释放情绪峰值。
- 承担传播资产。

硬门槛：

- 短、准、可复唱。
- 至少有一句能被记住。
- 不要只是把主歌意思说大声。

### Bridge

作用：

- 翻面、反问、视角移动、代价暴露或关系重估。
- 不是换一组漂亮句子。

可用方向：

- 从“我以为”翻到“我后来发现”。
- 从对别人说，翻到对自己说。
- 从个人情绪，翻到更大的命运或时代。
- 从不甘，翻到接受，但不能鸡汤。

### Outro

作用：

- 回收题眼。
- 给余波。
- 留下可以循环的尾句。

禁区：

- 不要作文总结。
- 不要突然升华。
- 不要把副歌解释一遍。

## 2.1 乐段功能硬门：画面、宣言、收紧和翻面

乐段功能不能只停留在标签。主歌、预副歌、副歌和桥段必须各自承担不同心理动作。

### Verse 硬门

主歌不是负责漂亮画面，也不是负责堆具体物件。主歌负责给副歌提供证据，让听众相信副歌不是空喊。

合格主歌必须至少满足两项：

```text
具体人物位置：谁在场，谁缺席，谁没说出口。
时间磨损证据：反复使用、等待、错过、旧习惯、身体记忆、关系变化或动作过期。
情绪动作：删、藏、躲、假装、没回头、没还、没问、咽回去、放回去等。
关系代价：这件事以后，谁失去了自然出现在明天里的资格。
```

不合格主歌：

```text
只有场景，没有关系代价。
只有物件，没有动作。
只有怀旧氛围，没有人物缺点。
只有作者旁白，没有当事人口气。
把“有画面”误当成“有歌词价值”。
```

主歌的画面必须是“可唱画面”，不是剧情说明。可唱画面要同时具备：

```text
能看见：人物、位置、动作、物件清楚。
能听见：句长、气口、尾音有基本韵律，不像散文分行。
有关系：画面里能看出谁和谁的关系、压力或距离变化。
有铺垫：它能解释后面为什么会进入 Pre 和 Chorus。
```

如果主歌只是“考场外有人尖叫 / 有人红着眼合照 / 电话打来 / 我站在人潮”这种事件记录，虽然有画面，但仍然偏素描。它需要继续用动词、名词和韵脚做歌词化：让画面更有声音、关系和情绪入口。

高质量主歌的底层方法不是直接解释事件，而是用分镜思维让事件进入歌词。每一句尽量成为一个独立镜头，多句组成一个有情绪推进的场景：

```text
镜头里有什么人物位置。
镜头里有什么动作。
镜头里有什么物件、声音、光线、空间或身体反应。
这一镜比上一镜多了什么压力、关系变化或情绪。
这一镜如何把人物推向 Pre 或 Chorus。
```

外部环境靠近、声音打开空间、人物进入、物件累积和身体痕迹留下，是家暴、创伤、强叙事题材里常用的一种分镜方式，只能作为参考，不是所有主歌的固定模板。其他题材也可以用反向分镜、静物分镜、身体分镜、时间跳切、对比蒙太奇或单一空间推进。硬门不是“必须有雪、车、瓶子、淤青”，而是每句要像镜头，多句要成场景，场景要有情绪，情绪要能把副歌逼出来。

主流流行歌的默认安全策略是：Verse 先锁定一个大场景，在同一时间 / 地点 / 连续事件里切远景、中景、特写和内心反应；Pre 沿用这个场景，把镜头拉近到触发点、身体反应和心理压力；Chorus 不继续堆新场景，而是把全歌最有代表性的 1-2 个画面压成可复唱的情绪出口；Verse 2 可以沿用同一大场景，但必须换新镜头；Bridge 是最适合回忆闪回、今昔对比或新场景翻面的乐段。

这不是绝对铁律。多地点叙事、Rap、音乐剧、史诗结构、旅行歌和电影感蒙太奇可以跨场景。判断标准不是“有没有换地点”，而是换场景是否带来新的关系压力、时间推进、人物认知或副歌意义。如果只是为了显得丰富而乱切地点，判为画面破碎；如果换场景能让最后副歌变重，则允许。

这类主歌的文学性来自克制和间接：少说“我害怕 / 我后悔 / 他很暴力”，多让镜头里的动作、物件、声音、光线、身体反应和位置变化替情绪说话。若 Verse 只有“发生了什么”的剧情说明，没有镜头推进、情绪画面和关系代价，判为主歌诗化不足。

主歌素材归位提醒：

有些句子已经有场景、前后关系和人物处境，但仍然不该直接判为副歌。它们更适合放在 Verse 或 Pre，用来给副歌提供证据。

例如：

```text
他们的夏天，在校门口开场
我的暑假，装进门卫室的行囊
准考证还在手心发烫
我连再见都没敢讲
```

这类句子的价值在于让听众看见事情发生的顺序和人物处境。它的问题不是没有画面，而是主要还在交代“发生了什么”。如果它没有进一步压成可复唱、可传播、可认领的情绪句，就优先归入主歌或预副歌素材。

使用方式：

```text
Verse：保留场景、物件、动作链，让听众相信这个人为什么走到副歌。
Pre：从这类素材里挑一个压力点收紧，让人物快要说出口。
Chorus：不要照搬这类叙事句，必须另写能承载 Hook 的情绪核心句。
```

### Pre-Chorus 硬门

预副歌不是更短的主歌。预副歌负责收紧，让副歌变成不得不唱。

合格预副歌必须出现：

```text
句长或气口收紧。
心理压力上升。
入副歌前的卡住点。
最后一行把人物逼到副歌出口。
```

如果 Pre 继续交代背景、继续堆画面、只是换一组漂亮句子，判为预副歌失效。

预副歌必须有“放大招前的提示感”。它要让听众感到情绪正在抬头，马上要进入副歌。合格 Pre 至少出现一种明显爬坡：

```text
声音爬坡：句子更短、更密，尾音更集中，气口更紧。
心理爬坡：人物快要说出口、快要忍不住、快要承认。
关系爬坡：别人一句话、一个动作、一个电话，把人物推到不能再装。
旋律爬坡：为副歌主韵或核心词提前铺声音。
```

如果 Pre 只是“他们说 / 我说 / 那句卡住”这类平铺对话，没有把情绪抬起来，听众不会感觉“注意听，副歌要来了”。

预副歌必须回答“是什么把副歌情绪逼出来”。悲伤歌要写清触发悲伤的阻碍、代价或错位；开心歌要写清触发开心的原因、松绑或兑现。Pre 不是继续铺背景，而是把主歌里已经出现的压力点拧紧：一个电话、一句邀约、一张车票、一个家里等着的人，都必须把人物推向副歌的核心宣言。

预副歌写作顺序：

```text
从主歌证据中选一个压力点
→ 缩短句长和气口
→ 提前铺副歌主韵或相邻唱感家族
→ 最后一行制造不得不唱的出口
```

### Chorus 硬门

副歌不是负责讲完整道理。副歌负责把主歌里的证据压缩成可复唱的情绪宣言。

合格副歌必须同时满足：

```text
稳定唱感家族：不是只同韵辙，而是发音动作接近。
句子短，重音清楚。
至少一句可被评论、签名、短视频配文、关系转发或现场合唱使用。
可以保留一个公共意象，但不能继续交代大量事实。
重复要加重认账、损失、姿态或记忆，而不是水词复唱。
```

如果副歌观点正确但唱不稳，或韵脚只是粗押、口型频繁换挡，判为副歌声音失败。

副歌内部也要有省略式三幕。它不需要像主歌一样交代完整前因后果，但必须有一个小的心理推进：

```text
第一小幕：抛出核心反差或损失。
第二小幕：加重这个反差，让人物被逼到不能再装。
第三小幕：落到一句可复唱、可传播、可认账的情绪结果。
```

如果副歌只有一句好句，后面只是重复解释，判为后劲不足。
如果副歌只有叙事推进，最后没有情绪结果，判为主歌化。
如果副歌最后一句没有比前面更重、更痛或更可记，判为收束失败。

副歌的综合门槛高于主歌和 Pre。它必须同时过：

```text
唱感：句长、气口、重音、尾音、口型适合唱。
韵脚：主韵明确，至少核心句尾稳定，不靠虚词凑。
画面：可以有画面，但画面必须服务核心情绪，不继续解释剧情。
词性：动词有情绪姿态，名词有关系归属。
修辞：不是大白话平铺，也不是假高级；修辞必须帮助听众更快理解情绪。
递进：副歌内部要有情绪从铺垫到爆发再到落点的推进。
传播：至少一句能成为评论句、转发句、短视频字幕或现场合唱句。
```

只满足“普通人能听懂”的副歌不够。副歌可以用大白话，但不能只有大白话；它必须在普通表达的基础上，用韵脚、动词、名词、修辞和重复机制把情绪再递进一层。

悲伤、严肃、遗憾类副歌的底线更高。轻喜剧和开心题材可以靠直白、口语和反差制造趣味；悲伤题材如果只把事实说清楚，没有画面、动作、时间煎熬、修辞遮蔽和声音爆发，就很容易变成小学生式叙述草稿。悲伤副歌必须让听众看见一个可认领的痛点，而不是听作者解释“我很难过”。

### Bridge 硬门

桥段不是备用漂亮句，也不是“想再……”遗憾清单。桥段负责翻面、认账、暴露代价或让人物终于说出前面没敢说的话。

合格 Bridge 必须至少满足一项：

```text
视角变化：从当时的我，翻到后来的我。
不可逆承认：承认逃避、胆小、错过、亏欠或假装。
代价暴露：这件事后来怎样改变了我。
能让最后副歌唱得更重。
```

如果 Bridge 只是再列几个想念的物件、重复副歌意思或为了显得文艺，判为桥段失效。

## 3. 能量曲线

曲式输出必须说明能量曲线：

```text
Intro：低能量，建立空间
Verse：信息清楚，近景
Pre：收紧，压迫感上升
Chorus：打开，核心句释放
Verse 2：补新证据，不重复
Bridge：情绪翻面或关系重估
Final Chorus：重复但更重
Outro：回收，留白
```

不能全程同一种强度。情绪没有起伏，听众很难记住副歌。

### 3.1 亲情回望 / 迟懂类片尾歌结构

亲情片尾歌的结构重点不是“把旧物排满”，而是让同一个照顾动作从当年误读，走到多年后听懂。

推荐骨架：

```text
Verse 1：现在回到旧现场，建立老家 / 长辈 / 孩子当年的误读。
Pre 1：一个声音、动作或物件把误读推到副歌前。
Chorus 1：第一次唱出核心心声，通常是“不是怕长大，是怕听懂太晚”。
Verse 2：补新证据，加入失去、另一位家人或更重的生活物件，不能复述 Verse 1。
Pre 2：把 Verse 2 的物件转成身体压力，准备第二次副歌。
Chorus 2：同骨架重复，情绪更厚，不能大改核心 hook。
Bridge：从当年如果早一点 / 慢一点 / 懂一点翻到现在来不及。
Final Chorus：同一句心声在不可回应中变重。
Outro：回收核心声音或物件，留下听不见回答的余波。
```

乐段分工：

```text
Verse 只能证明，不要替副歌解释。
Pre 只能收紧，不要继续讲新剧情。
Chorus 只能唱心声，不要塞剧本信息。
Bridge 必须让最后副歌更重，不要只列漂亮物件。
Outro 回收一件最核心的声音或动作，不做作文总结。
```

核心物件声音化：

如果某个物件是全歌发动机，曲式阶段要判断它是否能成为听觉母题：

```text
木轮 → music-box wooden-wheel motif
饭桌 / 碗 → low wooden knock 或 soft table pulse
针线 / 补丁 → light plucked texture 或 close dry detail
门框 / 老屋 → old room air 或 dry intimate room
```

声音化不是加音效。它必须服务 hook 记忆、段落回收或情绪翻面；否则宁可不用。

## 4. 纯音乐 style prompt 原则

曲式阶段输出的是纯音乐骨架提示词，不是最终人声版本。

可以写：

- subgenre。
- groove。
- BPM。
- drums / bass / guitar / piano / synth。
- arrangement density。
- hook space。
- vocal pocket。
- leave room for lead vocal。
- dynamic arc。
- space / texture。

不要写：

- 具体男声 / 女声画像。
- 具体唱法。
- 每句歌词的演唱控制。
- generic pop ballad。
- cinematic emotional song。
- piano ballad 这种中心值套话。

## 5. 主风格与辅助风格

必须裁决主风格。辅助风格只能服务局部，不允许平均混合。

错误：

```text
流行 + 民谣 + R&B + 电子 + 国风，全部都要。
```

正确：

```text
主风格：华语流行 R&B。
辅助质感：Verse 用 close-mic acoustic guitar 增加亲近感，Chorus 保持 R&B groove 和宽声场。
```

## 6. 风格不 generic 检查

最终曲式风格输出必须具体到：

- 细分音乐风格。
- groove / BPM。
- 风格内乐器。
- 编曲密度。
- 空间质感。
- 情绪弧线。
- 后续填词空间。

如果只写：

```text
抒情流行，钢琴，温暖，感人
```

视为失败。

## 8. 输出前自检

- 曲式有没有服务题眼？

- Verse / Pre / Chorus / Bridge / Outro 是否各有任务？

- 是否避免 generic 中心值？
- 是否给后续填词留了气口和句长空间？
