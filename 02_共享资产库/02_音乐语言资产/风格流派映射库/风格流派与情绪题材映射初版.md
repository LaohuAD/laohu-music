# 风格流派与情绪题材映射初版

本文件用于帮助 `laohu_music_structure` 判断：一个题眼、副歌核心句和人物场景，适合被什么风格承载。

本文件属于增强资产，不承担曲式与风格 skill 的基础下限能力。主风格 / 辅助风格裁决、generic 风格拦截、段落功能和 hook space 的硬门必须写在 `skills/laohu_music_structure/SKILL.md`；本文件只提供不同流派、题材和情绪的映射增强。

## 0. 风格判定总纲

风格不是单靠曲式结构划分。歌曲整体风格由四个维度共同决定：

```text
歌词文本：题材、意象体系、语言语感、修辞手法、叙事方式、押韵规则。
旋律唱腔：音域、语速、咬字、转音、真假声、嘶吼、慵懒、念唱。
编曲配器：乐器、鼓组、贝斯、合成器、传统器乐、空间和音色。
曲式结构：Verse / Pre-Chorus / Chorus / Bridge / Outro 的排布和能量。
```

作词阶段第一判断标准是歌词文本，尤其是：

```text
题材 + 意象 + 语言语感
```

曲式不能单独区分风格。同一套“主歌 → 预副歌 → 副歌 → 主歌 2 → 副歌 → Bridge → Final Chorus”的流行曲式，可以承载抒情流行、国风、民谣、说唱、R&B、摇滚或电子。曲式只决定段落排布和能量释放，不决定歌词流派。

风格裁决必须避免两个错误：

- 把所有现实题材都写成民谣分行。
- 把所有情绪题材都写成 generic pop ballad / generic piano ballad。

每次选择风格必须回答：

```text
主风格：
辅助风格：
歌词文本三要素：题材 / 意象 / 语言语感
旋律唱腔倾向：
编曲配器倾向：
曲式只是如何辅助：
为什么不是其他相邻风格：
禁用文本写法：
```

## 0.1 华语主流风格热度参考

热度不是创作唯一标准，但能帮助判断大众接受度、短视频传播和生成平台稳定性。

```text
1. 抒情流行：最主流、传唱度最高、男女老少通吃。
2. 国风 / 古风：短视频、影视、晚会、年轻审美强势。
3. 说唱 / 嘻哈：年轻群体强，态度、押韵和节奏主导。
4. 民谣：文艺、治愈、城市、旅行、深夜场景稳定。
5. 励志 / 正能量：毕业、晚会、职场、运动、官方传播刚需。
6. R&B / Soul：都市年轻群体、暧昧私密情绪，唱腔门槛较高。
7. 摇滚：固定受众，态度和舞台爆发强。
8. 电子流行：短视频、律动和循环强，歌词深度通常要简化。
9. 复古：港风、80/90 怀旧、旧时光语感，阶段性回潮。
10. 独立 / 另类：高级、小众、个人化，传唱门槛高。
```

如果目标是最容易大众传播，优先考虑抒情流行、国风 / 古风、简单抒情、励志和治愈民谣；如果目标是年轻态度，考虑说唱、国风融合、R&B、摇滚或电子；如果目标是小众质感，考虑独立 / 另类，但必须接受传唱度降低。

## 0.2 歌词注册矩阵使用法

每次确定主风格时，必须同步给出歌词注册，避免所有作品被写成同一种白话民谣分行。注册至少包含：

```text
歌词注册：口语 / 书面 / 半诗性 / 街头 / 古典 / 贴耳 / 舞台宣言。
句法：短句循环 / 中短副歌 / 长叙事线 / 切分 bar / 对偶凝练。
押韵策略：主歌弱押 / 副歌完美韵 / Rap 连押 / R&B 窄韵 / 国风宽韵。
抽象度：Verse、Pre、Chorus、Bridge 各自允许到什么程度。
允许修辞：生活比喻、概念悖论、身份宣言、古典意象、街头 punchline 等。
禁用平均写法：本风格最容易写成什么 AI 味。
典型声口：贴耳、宣泄、克制、反抗、讲述、冷感、自嘲等。
```

## 流行

适合：

- 大众情绪出口。
- 可复唱副歌。
- 短视频 BGM。
- 情绪清楚、关系清楚、核心句清楚的歌。

硬门槛：

- Chorus 短、准、可复述。
- 副歌核心句必须集中。
- Verse 不要塞满资料。

文本风格：

- 题材多为爱情、思念、遗憾、孤独、治愈和日常情绪。
- 语言以现代白话为主，但不是普通聊天；副歌必须有可复唱的概念压缩或关系判断。
- 意象可以使用人海、夜晚、路灯、晚风、回忆、牵手、眼泪等现代公共意象，但必须避免 AI 平均感。
- 修辞宜轻，不要过度玄学和典故化。

注册矩阵：

```text
歌词注册：现代白话 + 副歌凝练金句。
句法：Verse 中短叙事，Pre 收紧，Chorus 短句回环。
押韵策略：副歌完美韵优先，主歌可家族韵。
抽象度：Chorus 可中高抽象，Bridge 可更书面，但必须可唱。
禁用平均写法：时间会证明、终于释怀、人海错过、风吹散回忆等安全句。
典型声口：可认领、可复唱、情绪清楚但不解释过满。
```

## 民谣

适合：

- 生活叙事。
- 近人声。
- 弱押和自然呼吸。
- 具体人物、旧物、账目、路、饭、灯、门这类生活底子。

风险：

- 不要把所有现实人物都写成民谣。
- 不要靠深夜、通勤、未回复消息等高频 AI 素材冒充人味。

文本风格：

- 题材多为故乡、青春、旅途、小人物、平淡生活、淡淡忧愁。
- 语言像说话和讲故事，朴素、松弛、少华丽辞藻。
- 意象偏街道、火车、酒馆、木吉他、老街、路人、饭菜、四季。
- 情绪内敛，重叙事，少嘶吼，少大词。
- 生活碎料必须参与关系压力，不做装饰摆拍。

## 亲情片尾主题曲 / nostalgic family end-credit ballad

适合：

- 短剧片尾主题曲。
- 爷爷奶奶、父母、老家、童年回望和迟来的懂。
- 不是大哭大喊，而是终于低声承认的亲情亏欠。
- 需要“看过剧情更痛，没看剧情也能懂”的歌曲。

硬门槛：

- 风格必须服务人物迟懂，不做晚会合唱、公益宣传片或大电影煽情。
- 亲情物件要能成为声音动机，例如木轮、八音盒、旧玩具、饭桌声、门轴声、针线触感等；不能只做歌词摆设。
- Verse 近，Pre 收，Chorus 宽但克制，Bridge 要减法翻面，Final Chorus 只加厚一点点。
- 主唱年龄感和封面年龄感必须匹配最终声音；“多年后回望”不能自动生成中年声或中年封面。

文本风格：

- 现代白话，生活物件承重，少形容词和万能氛围词。
- Verse 可具体交代老家、饭桌、药碗、旧玩具、衣物；Pre 把物件转成迟痛；Chorus 压成关系判断和可复唱心声。
- 抽象词可以用，但必须被前文证据托住，例如“不想长大”要由具体误读和迟懂证明。

注册矩阵：

```text
歌词注册：近人声叙事 + 副歌公共心声。
句法：Verse 中短句证据链，Pre 触发点收紧，Chorus 短句回环，Bridge 假设 / 迟懂翻面。
押韵策略：主歌可弱押和家族韵，副歌必须完美韵，尾字优先开口实词。
抽象度：Verse 低抽象，Pre 中抽象，Chorus 可抽象但必须可唱，Bridge 可略书面但不能说教。
允许修辞：物件翻面、动作转义、轻反复、迟到假设。
禁用平均写法：旧灯光、晚霞、发烫、回响、风霜、旧旧旧、宏大弦乐、童年滤镜堆砌。
典型声口：贴近、克制、迟懂、低声认账，不煽情喊话。
```

编曲倾向：

```text
warm felt piano
nylon / acoustic guitar
soft brushed drums
subtle upright bass
one recurring object motif
thin low strings only after second chorus or final chorus
dry intimate room
clear hook space
```

不建议：

- `cinematic emotional ballad` 这类中心值词。
- 厚弦乐从第一副歌就进入。
- choir、anthem、gala duet、大合唱。
- 把亲情片尾歌做成励志正能量或公益宣传。

案例参考：

- `02_共享资产库/04_案例经验库/成功案例/2026-06-18_亲情片尾主题曲_不想长大案例.md`

## Rap / Hip-Hop

适合：

- 态度。
- 反击。
- 社会观察。
- 观点刀口。
- 争议和挑衅。

硬门槛：

- bar、flow、韵脚密度、punchline、Hook。
- 不能写成民谣叙事分行。

文本风格：

- 题材多为生活态度、现实叙事、自我表达、反击、身份、爱恨和社会观察。
- 语言口语化、街头化、短句密集，可以更直接、更有攻击性。
- 押韵系统是核心：单押、双押、多押、跳押、句内韵都要服务 flow。
- 主歌可以长，但必须有 bar 推进，不是散文分行。
- 副歌常做旋律化 Hook，负责记忆和传播。

注册矩阵：

```text
歌词注册：街头 / 态度 / 身份宣言。
句法：bar 推进、切分、句内韵、punchline 收束。
押韵策略：连押和多押服务 flow；副歌 hook 可简化成旋律句。
抽象度：可以高概念，但必须落成 punchline 或身份句。
禁用平均写法：把观点拆成散文分行、只喊口号没有 bar、为了押韵牺牲态度。
典型声口：直接、挑衅、反击、自我命名、冷嘲。
```

## R&B

适合：

- 贴耳。
- 身体律动。
- 暧昧、拉扯、私密情绪。
- 重复变体。

硬门槛：

- 口腔顺滑。
- 气声和滑音空间。
- 不要解释太完整。

文本风格：

- 题材多为都市男女、暧昧、纠结、私密心事和情绪拉扯。
- 语言现代、贴耳、细腻、柔软，避免把故事解释到死。
- 句子要给转音、停顿、滑音和切分留下空间。
- 可使用重复变体，但每次重复要有情绪或身体距离变化。

注册矩阵：

```text
歌词注册：贴耳、短气口、半说半唱、留白。
句法：短句、省略、重复变体，不把因果解释完整。
押韵策略：窄韵、短尾、口腔律动；尾音可轻收。
抽象度：可以中高，但要像私语里突然说准，不像论文判断。
禁用平均写法：完整剧情说明、民谣长句、过度格言化、强行大副歌宣言。
典型声口：靠近、克制、拉扯、冷掉、滑开。
```

## 摇滚

适合：

- 宣泄。
- 反抗。
- 强动词。
- 可喊副歌。
- 舞台爆发。

硬门槛：

- Chorus 要能喊。
- 句尾能落住。
- 不要修得过度礼貌。

文本风格：

- 题材多为理想、自由、反抗、挣扎、热血、尊严和不服。
- 语言直接、有态度、有强动词，避免礼貌抒情。
- 副歌要能喊，句尾要能砸住舞台。
- 可以少一点精致，多一点粗粝和不可退让。

注册矩阵：

```text
歌词注册：舞台宣言 / 反抗 / 强动作。
句法：中短句、强重音、句尾砸实字。
押韵策略：副歌开口韵或强实字尾，主歌可弱押但节奏清楚。
抽象度：可以写尊严、自由、命运，但必须被动词和喊感买回来。
禁用平均写法：修得过度礼貌、委婉、疗愈、像抒情流行。
典型声口：不服、宣泄、硬、粗粝、不可退让。
```

## 电子

适合：

- 冷感。
- 循环。
- 切片。
- 身体节奏。
- 氛围和声音单位。

硬门槛：

- 短语可循环。
- 不要长篇完整叙事。
- 句子要能卡拍。

文本风格：

- 题材偏冷感、夜色、身体律动、循环、失控、城市空间或短视频切片。
- 语言短、重复、洗脑，适合做声音单位。
- 副歌可极简，但必须有可循环的关键词或短语。
- 不适合承载复杂叙事和长句解释。

## 国风 / 古风

适合：

- 历史。
- 命运。
- 人物抉择。
- 凝练意象。

硬门槛：

- 语体统一。
- 意象少而准。
- 不要符号堆砌。
- 现代白话和古典语体不能乱切。

文本风格：

- 题材多为江湖、山水、历史、仙侠、家国、古典情爱、离愁和命运。
- 语言可半文言、诗词化、四字短语、对仗，但必须可唱、可懂。
- 意象可用月、烟雨、江南、亭台、剑、酒、舟、鸿雁、青丝、山河等古典系统。
- 国风流行可以现代旋律 + 中式元素，但歌词语体必须统一。
- 古风唯美偏诗意和意象，家国国风偏山河、血脉、时代、集体宣言。

### 国风宿命怨诉慢歌

适合：

- 孤寂、怨怼、求而不得、被命运绕过。
- 明月、长夜、寒江、轮回、宿命等不可触及对象承载情绪。
- 副歌核心是质问、轻自审或求告，而不是两个人当面对骂。

文本注册：

```text
歌词注册：半诗性古风 + 可复唱质问句。
句法：主歌四字 / 六字短组铺孤影，预副歌收紧，副歌对称反问和自判，Bridge 从恨转求。
押韵策略：宽韵或近韵回环，副歌核心句尾音要稳定，尾句可用单词式情绪落点。
抽象度：允许宿命、因果、轮回、万劫等高抽象词，但必须绑定人物低处动作或核心对象动作。
禁用平均写法：月色、孤独、宿命、千年等古风词横向堆砌；现代口水句突然插入；副歌只解释命运不公。
典型声口：清冷、怨、问、求、最后低声认命。
```

编曲注册：

```text
主风格：Chinese ancient style Mandopop ballad / 新国风慢板抒情。
BPM：72-76。
调性：minor key。
Intro / Verse：guzheng harmonics 或 light arpeggio + breathy bamboo flute + sparse piano single notes + cello long lines，空旷、清冷、鼓弱或无鼓。
Pre-Chorus：strings gradual swell，pipa light tremolo 或 guzheng pattern 加密，气息开始上推。
Chorus：string ensemble full but not crowded，Chinese bass drum accents only after hook，guzheng strum / pipa support，保留人声前景。
Bridge：最大动态，弦乐全奏、古筝刮奏或强扫、笛子强吹、钢琴柱式和弦；功能是“恨到求”的翻面。
Outro：回到古筝 / 笛子 / 钢琴 / 大提琴，渐弱、长混响、留白。
```

风险：

- 民乐数量不是越多越好。主歌最多 2 个核心民乐音色，副歌再加厚；否则会变成古风素材堆叠。
- `cinematic` 只能服务空间和动态，不得把歌曲推成宣传片弦乐、晚会大歌或影视预告片。
- 大鼓只做副歌 / Bridge 点睛，不要把孤寂慢歌做成战歌。

## 励志 / 正能量

适合：

- 成长。
- 追梦。
- 不服输。
- 家国。
- 毕业、晚会、运动、职场和官方传播。

硬门槛：

- 副歌要昂扬、可合唱、可喊。
- 不能写成空口号。
- 必须有具体阻力、代价或人物处境。

文本风格：

- 题材多为逆风、少年、奔跑、理想、征途、希望和重新站起来。
- 语言大气、铿锵、积极，但不能全是“光、远方、翅膀、梦想”。
- 修辞可用反复、排比、夸张，但必须层层递进。
- 最怕宣传腔和正确废话，必须给人物真实低谷和行动。

## 复古 / 港风 / 怀旧

适合：

- 旧时光。
- 港风温柔。
- 80/90 年代语感。
- 怀旧情歌、老街、旧情爱。

硬门槛：

- 语感要有年代感，但不能装腔。
- 意象要有旧生活痕迹。
- 不能只贴“复古”标签。

文本风格：

- 语言可稍老派、含蓄、重情义和旧称呼。
- 意象偏晚风、旧街、霓虹、唱片、旧照片、电话亭、旧影院、旧情书等。
- 句子要比现代流行更有余味，但仍要可唱。

## 独立 / 另类

适合：

- 小众审美。
- 个人化表达。
- 反套路。
- 卧室流行、独立流行、文艺另类。

硬门槛：

- 可以抽象，但不能故作高深。
- 可以不讨好大众，但必须有内部逻辑。
- 不能把难懂当高级。

文本风格：

- 题材和意象可以个人化、怪异、碎片化。
- 语言可以打破常规抒情逻辑，但必须有真实气味和独特视角。
- 传播面通常小于主流风格，除非有极强 hook 或鲜明人设。

## 儿童 / 合家欢

适合：

- 清楚动作。
- 短句。
- 重复。
