# 韵脚与唱感安全规则

本文件是老胡音乐关于押韵、句尾、气口、唱感和风格语言路由的专项规则库。

它比 `laohu_lyrics_writer` 和 `laohu_lyrics_repair` skill 更细，负责补充韵脚风险、句尾可唱性、气口、风格语言硬门槛和负优化判断。

本文件属于增强资产，不承担歌词 writer 的基础下限能力。副歌先定主韵、完美韵组、弱虚尾硬门、写完不合格必须内部重写等跨风格硬门，必须写在 `skills/laohu_lyrics_writer/SKILL.md`；本文件只提供更细的韵脚、发声、词池和专项审计增强。

押韵不是装饰，也不是越密越好。押韵必须被语义买回来。

## 0. 使用边界：声音服务作品，不服务表格

韵脚、唱感、拼音、口型和审计表都是内部修歌工具，不是对外主表达。任何韵脚判断都必须回到同一个创作中枢：

```text
这首歌替谁唱？
他在什么场景里痛？
他最想说但说不出口的是哪句话？
副歌能不能让这个人认账？
这句话能不能唱、能不能记、能不能传播？
```

对老胡展示时，先给能唱的句子，再给短唱感说明。除非老胡要求看完整审计，不要把拼音表、韵辙表和发声表放在歌词前面。

如果审计表显示“合格”，但句子不像人会唱、语义不通、动作链断裂或只是文章金句，仍然判为失败。唱感通过只是副歌成立的底线，不是作品成立的证明。

示范句也受本规则约束。任何用来证明“规则已生效”“能力已提升”的副歌示例，必须至少说明主韵、押韵模式、完美韵组和发声兼容性；如果没有押韵、句尾不能拖、口型跳得厉害，只能标记为语义草稿或方向草稿，不得作为合格副歌展示。

尤其禁止把“语义更准但不押韵”的句子当成副歌成果。它可以进入题眼说明、主歌素材或下一轮改写方向，但不能证明作词能力已经过关。

轻阶段也不能完全放弃声音。老胡要“先看感觉”时，可以不展开完整拼音表，但副歌核心句候选至少要有内部主韵意识：

```text
先定一个主韵方向。
句尾优先落实字，不落吧、啊、呢、了这类弱尾。
相邻句长度尽量接近。
尾音能拖，不能只靠语义硬撑。
读一遍如果像文章标题，不像人会唱，退回重写。
```

轻创作对外只需要短说明，例如“这组先走 i 韵，句尾落在 里 / 起 / 己 / 性 一组，方便副歌回环”。不要把完整拼音审计放在歌词前面。

### 0.1 弱虚尾硬门

除非明确是民谣、口语独白、轻唱段落或反讽自嘲，主歌、预副歌、副歌、桥段的关键句尾默认不落：

```text
了 / 啊 / 呢 / 吧 / 嘛
```

这些字不是绝对禁用，而是不能承担情绪上升和高潮落点。它们普通话顺，但发声弱、拖音弱、爆发弱，容易让副歌和预副歌塌下去。

处理顺序：

```text
普通话底稿可以保留弱虚尾来讲清逻辑。
歌词化一稿必须检查弱虚尾是否削弱唱感。
可唱优化稿要优先换成实字尾、动作尾、关系尾或可拖长的韵脚。
```

例：

```text
普通话底稿：
床头柜上的药盒空了，学费还没凑齐。

歌词化一稿：
床头药盒见了底
学费还差一截没齐

可唱优化方向：
床头药盒剩空格
学费压在开学前
```

这些例子不代表终稿，只说明普通话顺句必须继续过尾音、韵脚、动词、名词和唱感。

## 0.2 元音开放度、气口、重音与乐段位置

歌词的锋芒必须进入声音结构。一个句子如果只能在纸面上解释通，唱出来气口别扭、尾音垮、重音落虚词或韵母不适合拖唱，就不能当副歌核心句。

常用声学取向：

```text
a / ai / ang / ao：开口度高，适合爆发、拖长、合唱、宣言和副歌高潮。
i / ü / in：口腔更窄，适合贴耳、内收、冷感、R&B、克制句和短尾处理。
an / en / ang / eng：可承载长尾和回环，但 n / ng 收束必须稳定，不可混乱。
ou / o：适合口语、回望、停留、认账和较短落点。
弱虚尾：可用于低能量口语句，但不承担 hook 长音、Pre 上扬或副歌高潮。
```

按乐段裁决：

```text
Verse：允许弱押和自然尾音，但叙事钉、罪证物件和关键动作要咬清楚。
Pre：气口更短，句尾更窄或更紧，制造入副歌的压力。
Chorus：核心 4 句优先稳定主韵，长音尾字要能被重复、拖唱和记住。
Bridge：可允许更书面、更抽象的尾字，但必须有翻面和可唱余味。
Final Chorus：不重做韵脚系统，只加重、变体或拉开声场。
```

按风格裁决：

```text
Rap：重音、切分和 punchline 优先，尾韵服务 flow，不用流行副歌标准硬卡每行。
R&B：口腔律动、短尾、滑音、重复变体和贴耳气口优先。
摇滚：句尾要能喊，强动词和开口实字优先，不能修得过度礼貌。
国风：鼻音韵、宽韵和对偶可成立，但语体统一优先。
民谣：弱押可以成立，但弱不是散，句尾仍要自然落地。
```

声学审计短表：

```text
句尾词：
拼音：
韵母：
开闭口：
鼻音收束：
可拖音：
重音词：
气口：
乐段位置：
风险：
```

## 1. 韵脚的基本原则

```text
先确定风格
→ 再确定韵脚密度
→ 再确定主韵辙
→ 再写句尾
```

不要写完歌词以后再随手补韵。补出来的韵很容易变成：

- 轻声助词押韵。
- 玄词押韵。
- 无意义尾巴。
- 句子自然重音和语义重音冲突。

## 1.0 十三辙与词池使用规则

《歌词写作十八讲》附录二提供的是传统十三辙下的押韵常用字词原料。老胡项目使用时不原样套清单，而是按以下顺序筛选：

```text
确认主韵辙
→ 从附录2韵脚词池中选候选尾字 / 尾词
→ 按词性分组
→ 按语义类型分组
→ 按情绪强度筛选
→ 检查可唱性和长音承载
→ 检查人物声口
→ 放入副歌句尾词池
```

每个候选尾词必须标记：

```text
所属韵部
词性
语义类型
歌词功能
可唱性等级
风险标签
```

风险标签包括：虚词、口水、生僻、古风、俗套、多音字、OCR 存疑。

附录词池只提供候选，不替代判断。能押韵但不属于人物、不服务题眼、不适合拖音的词，不能进入副歌高潮。

## 1.1 副歌核心句确认前定韵

副歌核心句不是普通歌词句，它是整首歌的声音锚点。题眼阶段或曲式阶段一旦确认副歌核心句，就必须同步确认：

- 主韵辙。
- 句尾实字。
- 气口位置。
- 是否适合重复和合唱。
- 是否能成为短视频 / 评论区传播句。

方向备选时，可以先给语义候选句帮助老胡选择方向。方向确认后，禁止把副歌核心句写成不押韵的散文句，再期待填词、歌词优化或最终审查阶段“顺手改韵”。如果确认副歌核心句不押韵、不顺口、不像歌词，必须在进入曲式与风格前重写并等待老胡确认。

两句式确认副歌核心句要求：

- A 句尾和 B 句尾押同一主韵，或非常稳定的近韵。
- 两句长度尽量接近，方便旋律重复或呼应。
- 句尾不要落虚词。
- 韵脚要服务语义，不得为了韵脚把老师、学生、相遇等核心关系写假。

常用适配：

- ang 韵：光、方、长、望、上、场、堂。适合开阔、感恩、回望。
- eng 韵：声、生、灯、程、风。适合温暖、行路、师生关系。
- ai 韵：来、开、怀、在。适合告别、重逢、释怀。
- ou 韵：走、守、候、口、手。适合口语、陪伴、行动。
- ao 韵：道、笑、桥、早、老。适合人生、路、时间感。

### 1.1.1 普通句升级时不随手动尾音

吸收老胡研究报告《AI 写词和人类写词的区别对比》：

歌词修改不是文章润色。句尾一变，唱感、韵脚、重音和旋律预期都会跟着变。

当一段歌词基础门成立但不够高级时，修改顺序必须先判断本轮目标：

```text
动词太弱 → 优先改动词，不动句尾。
名词太泛 → 优先换名词，不破坏既有尾音。
修辞太旧 → 在原有发声结构里重做物性和情绪对应。
题眼不清 → 回到题眼阶段，不用押韵补丁硬救。
韵脚本身错误 → 明确进入韵脚专项重写。
```

硬门：

- 除非本轮目标是重做韵脚，否则不要因为想让意思更准而随手改句尾。
- 如果修改后语义更好但唱感更差，判为负优化。
- 副歌核心句不能先写漂亮意思，再临时补韵；必须先有声音路线。
- 押韵不是装饰，而是情绪回到同一个地方的声音路。
- 不要用同一个功能字反复充当韵脚。`上、里、中、边、旁、下` 这类方位词可以押韵，但连续出现且没有语义增量时，会变成韵脚补丁。主歌弱押也要换尾词、换句式或换意象，让声音回环自然发生。
- 同一意象短距离重复必须有功能变化。第一次出现是空间，第二次必须改变为动作、压力、影子、回声或关系后果；如果只是为了回环重复 `灯影、碗沿、桌角`，判为机械复读。

## 1.2 韵脚层级硬门：副歌完美韵优先，家族韵分场景使用

韵脚层级和唱感顺不是同一个概念。

```text
唱感顺：
气口、句长、重音、声母启动、韵母走向、口型开闭、舌位、鼻音收束、长音承载和前后句衔接都自然。

韵脚对齐：
句尾声音落在同一或相近韵区。

关系：
唱感顺通常必须包含韵脚稳定，但韵脚稳定不必然带来唱感顺。
```

以后副歌和关键 hook 的韵脚审计，不能只写“属于某某韵辙”。必须先判断韵脚层级，再检查发声兼容性：

```text
完美韵：
韵母、收尾、口型和长音位置高度一致，适合副歌高潮、核心 hook、句尾长音和重复传播。

家族韵：
同属相近韵区，发声方向接近但不是完全一致。适合主歌、桥段、过渡句、副歌弱位置，能增加自然度和灵活度。

宽韵 / 粗押：
只在大韵辙或听感上有松散关联。只适合语义优先的弱位置、Rap 局部、民谣口语或草稿；不能承担流行副歌高潮主韵。

出韵：
声音关系不成立。除非是明确设计的断裂、反讽或转折，否则重写。
```

审计字段：

```text
尾词：
拼音：
韵辙：
韵母：
声母启动：
口型开闭：
舌位 / 鼻音收束：
是否适合长音：
韵脚层级：完美韵 / 家族韵 / 宽韵 / 出韵
发声兼容性：
风险判断：
```

不要把“唱感家族”当成正式韵脚类型。真正用于创作判断的是完美韵、家族韵、宽韵和出韵；唱感只负责检查这些尾词能不能被同一条旋律、同一种嘴型和同一种尾音处理自然唱过去。

判断顺序：

```text
先看韵母是否接近
→ 再看声母启动是否造成明显换挡
→ 再看口型开闭是否突变
→ 再看 n / ng / m 等鼻音收束是否一致
→ 再判断能否放在同一长音位置
→ 最后标注完美韵 / 家族韵 / 宽韵 / 出韵
```

典型反例：

```text
夏天：xia tian，尾词 tian，韵母 ian，舌尖爆破后打开，前鼻音轻收。
从前：cong qian，尾词 qian，韵母 ian，舌面前部启动，前鼻音轻收。
考散：kao san，尾词 san，韵母 an，齿龈摩擦启动，没有 i 介音缓冲。
同班：tong ban，尾词 ban，韵母 an，双唇闭合爆破后打开。

判断：
天 / 前可初步归为完美韵候选。
散 / 班属于较松的 an 家族韵，且 s / b 启动差异大。
夏天 / 从前 / 考散 / 同班不能因为同属言前辙就判为同一副歌完美韵组。
```

副歌通过标准：

```text
核心 4 句至少 3 句落在同一完美韵组。
第 1 句和第 4 句必须押完美韵，或形成非常明确的声音回环。
如果只是家族韵或同韵辙，只能标记为副歌弱押，不得作为副歌高潮主韵通过。
如果主 hook 本身是强传播句但完美韵不稳，必须在进入填词或演唱控制前重写 hook 或重新定韵。
```

## 2. 句尾安全门

句尾词必须承担至少一项功能：

- 语义功能。
- 动作功能。
- 情绪功能。
- 人物语气。
- 声音承载。
- 韵脚回环。

如果把句尾词换掉，意思几乎不变，它大概率是押韵补丁。

## 3. 轻声虚尾风险

高风险尾字：

```text
了、啊、吧、吗、呢、呀、啦、着、的
```

这些词可以存在，但不要承担：

- 副歌核心长音。
- 高潮落点。
- 现场合唱句尾。
- Rap punchline 尾音。

如果核心句需要拖音，优先把声音重心放到前一个实字。

预副歌和副歌属于情绪上升乐段，句尾更不能随便落在弱语气助词或虚词上。`吧、啊、呢、呀、啦、了` 可以在民谣、口语主歌或衬句里制造真实说话感，但如果放在 Pre / Chorus 的主句尾，会削弱发声、拖音、爆发和合唱承载。

执行规则：

- Pre / Chorus 的核心句尾优先使用可发声、可拖音、有语义重量的实词：名词、动词结果、关系词、地点词、时间词、物件词。
- 如果句尾必须有语气助词，必须说明它服务哪一种唱腔、停顿或人物口吻，并把真正长音落在前一个实字。
- 情绪上升段不得用弱虚尾凑韵。为了押韵把句尾写成 `去吧 / 想啊 / 算了`，但前一个实字没有声音重心，判为唱感失败。

## 4. 不同风格的韵脚策略

### 流行

- 副歌核心句优先实韵。
- 句尾要可拖、可重复、可合唱。
- Verse 可以弱押，Chorus 要更集中。
- 不要让副歌落在解释性长句。
- 两句式 hook 要在早期确定主韵，不要进入填词后再大换。

### 民谣

- 可以弱押、隔句押。
- 允许自然呼吸和轻尾，但核心句仍要落在实字。
- 生活细节比押韵密度更重要。
- 不要为了韵牺牲人话。

### Rap / Hip-Hop

- 需要 bar、flow、内韵、连押或多押。
- 句尾要配合鼓点和切分。
- punchline 不能落在虚尾。
- 押韵密度要服务态度推进，不要只是炫技。

### R&B

- 重视口腔律动。
- 可用重复变体、滑音、窄韵和尾音轻处理。
- 句子要顺口，不要解释过满。
- 核心句仍要能被听清。

### 摇滚

- 句尾要能喊。
- 强动词和实字更适合作为高潮落点。
- 不要把愤怒修成礼貌。

### 电子

- 短句、循环、卡拍。
- 适合利落实韵和声音单位。
- 不适合长句慢解释。

### 国风 / 古风

- 韵尾要配合旋律线。
- 鼻音韵、宽韵和留白可以成立，但语体必须统一。
- 不要为了押韵堆古风符号。

## 5. 唱感检查

每行歌词输出前默读：

- 是否能自然断气？
- 是否能落在一个可唱的词上？
- 副歌尾词是否属于同一完美韵组，而不只是同一大韵辙或家族韵？
- 声母启动是否让口型突然换挡，例如从开口长音跳到闭唇爆破？
- 韵母是否能被同一条旋律拖住，还是每句都要换一种发音肌肉？
- n / ng / m 的收束是否稳定，尾音是否会被 AI 作曲吞掉或拖错？
- 有没有过长从句？
- 句子是不是散文，只是被分行？
- 副歌是不是比主歌更集中？
- Rap 是否有 bar 和重音？
- R&B 是否有口腔律动？

唱不动的长句，要拆成节拍单元。

## 6. 韵脚修改时的负优化

禁止：

- 为了押韵把人物说话修假。
- 为了顺滑磨掉嘴硬和刺感。
- 为了高级感换成陌生搭配。
- 为了工整让所有句子同一种长度。

修改时要说明：

```text
这个改法提升的是唱感、语义、人物可信度、传播力，还是风格硬门槛？
```

## 7. 输出前自检

- 主风格对应的韵脚策略是否明确？
- 副歌是否完成“拼音 / 韵母 / 声母启动 / 口型 / 舌位 / 鼻音 / 长音 / 完美韵组 / 发声兼容性”审计？
- 是否存在只同韵辙、只家族韵却被误判为副歌完美韵的句组？
- 副歌核心句是否落在可承载句尾？
- 是否存在押韵补丁？
- 是否有轻声虚尾承担高潮？
- 句长、气口和停顿是否适合演唱？
- 韵脚是否服务人物，而不是服务规则？

## 8. 韵脚工程化流程

韵脚不是最后修饰，而是副歌与旋律生成前置工程。尤其是流行歌、副歌 hook 和需要短视频传播的歌曲，必须先定韵再写句尾。

执行顺序：

```text
先定主风格
→ 再定主韵辙
→ 再定完美韵组
→ 再定押韵模式
→ 再列可用韵脚词池
→ 再写副歌核心句
→ 再写 Verse / Pre / Bridge 的弱押或换韵
→ 最后做韵脚审计表
```

禁止顺序：

- 先写完整副歌再临时找韵脚。
- 先写漂亮概念句再把句尾替换成押韵词。
- 把副歌出辙问题留到歌词优化或演唱控制。
- 把同音字、近义词或字形相似误当押韵。

## 9. 常用韵辙参考

创作时不要求复刻曲艺十三辙，但必须先声明主韵区。副歌优先纯用一韵，部内近押次之，部间通押最次。

```text
发花 a / ia / ua：啊、花、家、话、下
怀来 ai / uai：来、开、白、海、改
灰堆 ei / ui：回、飞、泪、谁、归
遥条 ao / iao：高、笑、桥、遥、照
由求 ou / iu：走、手、秋、留、旧
言前 an / ian / uan：完、衫、答案、人间、窗帘、看见、多年
人辰 en / in / un：人、门、心、稳、认真
江阳 ang / iang / uang：光、上、方向、肩膀、成长
中东 eng / ing / ong / iong：风、声、先生、姓名、清醒
衣期 i / ü / er：你、里、起、去、记
姑苏 u：路、书、住、苦、归途
梭波 o / e：说、过、河、舍、沉默
乜斜 ie / üe：谢、夜、月、别、世界
```

## 10. 副歌韵脚硬门槛

流行副歌最低要求：

- 默认优先 4 句结构。4 句不是死板格式，而是为了降低听觉和记忆负担；如果使用 8 句或短句循环，必须说明曲风、旋律或传播理由。
- 单句优先 7 到 10 字，四句字数尽量接近。特殊曲风可以放宽，但必须保留自然气口和可复唱性。
- 核心四句至少三句落在同一完美韵组；只同韵辙、只家族韵或不同发声肌肉，不能当作副歌高潮主韵通过。
- 第 1 句和第 4 句必须押完美韵或有明确声音回环。
- 第 2 句如果变韵，必须是明确设计的 ABAB 或 AABA，不得随手出辙。
- 副歌第二组重复句不得突然换到无关韵辙。
- 现场合唱句和短视频切片句必须落在可拖音的实字。
- 同一副歌内不得把 an / ian、eng / ing、ang 等无设计地混用。

强推荐押韵模式：

```text
AAAA：四句同韵，适合传播 hook 和大众流行。
AABA：前三句或第 1/2/4 句同韵，第 3 句可转折，但第 4 句必须回主韵。
ABAB：第 1/3 句同韵，第 2/4 句同韵，适合旋律问答。
AA_BB：前两句同韵，后两句同韵，适合副歌分成两个乐句组。两个韵组必须在听感上有设计。
```

副歌内部必须设计至少一种重复机制：

```text
句首重复：让听众快速抓住入口。
句尾重复：形成尾音预判和记忆回环。
核心词重复：把歌名、题眼或关键词打成全曲标签。
旋律回钩：歌词轻微变化，但声音位置和韵脚保持稳定。
```

重复不是水词。重复句必须每次增加情绪、姿态、损失、认账或传播记忆；如果只是把普通句唱两遍，判为重复无效。

禁用押韵模式：

- A B C D 四句各押各的。
- 前四句主韵稳定，后四句突然换到无关韵辙。
- 为了语义把高潮尾句落在非主韵，但没有旋律或重复设计补偿。
- 把轻声虚词当作押韵落点。

## 11. 韵脚连续性审计

每次输出完整歌词、确认副歌核心句或修复副歌，都必须附带副歌韵脚审计表。审计不是装饰，而是判断歌词是否可投喂、可唱、可复唱的必要证据。

审计表字段：

```text
乐段 | 行号 | 句尾词 | 韵母 | 韵辙 | 模式 | 长音落点 | 语义功能 | 判断
```

每行至少检查：

- 副歌每行句尾词。
- 句尾拼音或韵母。
- 所属韵辙。
- 押韵模式标记 A / B / C。
- 是否承担长音或高潮落点。
- 是否出辙。
- 如果出辙，是否有明确设计理由。

失败判定：

- 副歌核心句没有审计表。
- 审计表显示出辙但文件仍标记为可投喂。
- 主韵辙声明和实际句尾不一致。
- 副歌核心句与 Final Chorus 变体押韵系统不一致。

## 12. 句长与气口规则

中文流行歌词建议：

- 副歌单行优先 6 到 12 字，特别长的句子必须拆成两个乐句。
- Verse 单行可以 7 到 15 字，但不能像散文换行。
- 每个副歌乐句最好有一个自然气口。
- 连续三行以上不能全部同长度，除非为了口号式合唱。
- 副歌关键词优先短词、实词、可重复词。

AI 音乐平台额外注意：

- 一行太长容易赶拍、吞字或自动断错。
- 副歌押韵越稳定，AI 越容易生成自然旋律。
- 生僻字、多音字、连续卷舌音和爆破音不要放在高潮句尾。
