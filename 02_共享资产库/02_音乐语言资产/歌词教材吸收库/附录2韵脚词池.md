# 附录2韵脚词池

本文件承接《歌词写作十八讲》附录二“歌词押韵常用字词一览表”（书内页码 232-250）。

使用原则：

```text
韵脚词池只能作为候选，不是自动押韵答案。
每个候选尾词必须同时通过语义、人物声口、句法词性、可唱性和情绪强度检查。
高潮句不允许为了押韵使用软词、空词或不属于人物的词。
```

## 1. 使用流程

```text
确定副歌主韵辙
→ 选择 8-20 个候选尾词
→ 按词性分组
→ 按情绪强度分组
→ 检查句尾可拖音
→ 写入副歌句尾词池
→ 进行副歌韵脚审计
```

## 2. 附录二词池

附录二按传统十三辙组织，另附儿化韵。它适合作为“原料库”，不适合原样成为“规则库”。

## 5. 代表性候选词示例

这里只放少量代表性示例，完整词池后续必须经 OCR 校正、拼音校验和项目案例回流后再扩展。

### 中东

```text
风 / 梦 / 声 / 情 / 空 / 中 / 痛 / 醒
适合：厚重叙事、群体记忆、人生回望、低中频副歌。
风险：容易滑向宏大空词，如“天空、梦中、心声”必须有具体场景支撑。
```

### 发花

```text
花 / 家 / 话 / 下 / 啊 / 他 / 她 / 疤
适合：开口副歌、民歌感、喊唱、直白告白。
风险：啊、呀、吗、吧等虚尾不能承担高潮；“花、家”容易陈词化。
```

### 江阳

```text
光 / 望 / 长 / 场 / 伤 / 亮 / 墙 / 霜
适合：大情绪、摇滚、合唱、人生题材。
风险：光、远方、梦想等词容易 AI 平均化，必须落到动作和代价。
```

### 言前

```text
年 / 眼 / 见 / 前 / 远 / 欠 / 还 / 难
适合：关系、时间、遗憾、回望，是流行副歌高可用韵部。
风险：多年、从前、永远容易软，要用更硬的动作或关系后果托住。
```

### 人辰

```text
人 / 门 / 身 / 真 / 沉 / 问 / 忍 / 冷
适合：贴耳自白、都市关系、内收情绪。
风险：闭口感较强，高音大副歌要确认长音承载。
```

### 由求

```text
走 / 留 / 旧 / 手 / 口 / 后 / 愁 / 求
适合：告别、挽留、回望、流动感副歌。
风险：温柔、以后、回头等词容易变软，需加人物态度。
```

## 6. OCR 风险

附录二来自扫描 PDF，OCR 不能直接入库。常见风险：

```text
韵母误识别
繁简字混杂
页眉页码插入正文
字头错位
分词粘连
多音字误归韵
旧词、生僻词、成语密度过高
```

校验流程：

```text
对照 PDF 图片校正韵部标题和韵母
→ 统一繁简和标点
→ 用拼音工具计算尾字韵母
→ 标记尾字韵母与所属韵部不一致的词
→ 多音字人工确认
→ 只把高价值实字升级为可用词池
→ 用真实副歌韵脚审计表反向测试
```
