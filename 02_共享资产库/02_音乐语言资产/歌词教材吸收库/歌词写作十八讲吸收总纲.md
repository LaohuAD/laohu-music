# 歌词写作十八讲吸收总纲

本文件用于把《歌词写作十八讲》转化为老胡音乐项目可执行的作词规则。

本项目不保存书中大段原文，不把教材 OCR 文本当作可调用素材库。吸收方式是：

```text
逐页阅读
→ 提炼作词工艺
→ 判断对应音乐创作阶段
→ 写成老胡音乐项目自己的规则
→ 回填 skill / 共享资产 / 类型经验
→ 后续创作和评审时调用
```

## 2. 对当前项目的总判断

这本书最适合补强老胡音乐项目的四类能力：

```text
歌词认识：
把歌词定义成“音乐文学”，既不是文章，也不是现代诗，更不是提示词文案。歌词必须同时满足文学表达、可唱结构、音乐节奏和听众记忆。

作词工艺：
把押韵、修辞、建构组织、创作流程、歌名、类型写法、填词、修改，转成每个阶段的硬检查。

评审带教：
评审官不能只说好坏，要能指出病灶、证据、原理、改法，并反推给上游 skill 下一次怎么训练。

韵脚资料：
附录二适合沉淀为韵脚词池，但不能机械堆词。词池只服务主韵辙、句尾长音、唱感和语义准确。
```

## 2.1 歌词的项目定义

老胡音乐项目采用以下定义：

```text
歌词是准备被唱出来的音乐文学。
它不是分行短文，不是现代诗，不是观点文章，也不是情绪提示词。
它必须同时服务旋律、歌手、听众即时理解和传播记忆。
```

歌词可以有诗意，但不能照搬诗的阅读逻辑。诗可以让读者停下来反复想；歌词多数时候是在旋律中一遍通过。听众第一遍听不懂的句子，通常不能承担副歌、hook 或高潮落点。

歌词可以讲故事，但叙事不是目标本身。歌词里的故事要为情绪服务：主歌给场景、人物和证据，副歌把情绪压成能唱、能记、能复述的一句话。

全流程语言底线：普通话摘要不能冒充歌词化金句。意思正确、能解释主题，只能算语义草稿；必须继续经过动作、对象、身体、声音、尾音、韵脚和唱感处理，才有资格成为副歌核心句、歌词亮点或发布传播句。展开规则见 `作词技巧规则库.md` 的“0.1.1 普通话摘要不能冒充歌词化金句”。

### 2.1.1 创作现场先于规则讲解

本项目吸收教材不是为了把作词变成表格，而是为了让初稿更像人写、更像歌、更能唱。任何教程、示范、初稿和改稿都必须先把一个具体人放进具体现场：

```text
一个人。
一个场景。
一个动作。
一个现实阻碍。
一句他最想说但说不出口的话。
```

之后才使用题眼、韵脚、乐段、修辞、评审和复盘规则。规则是修刀，不是替人物说话的喇叭。

如果示范只剩“这个人很难过、现实很残酷、他必须成长”这类解释，即使逻辑正确，也不能算歌词示范。必须继续落成 Verse / Pre / Chorus 里的可唱句子，并检查主韵、气口、句尾实字和第一耳理解。

## 2.2 歌词写作的四个基本问题

每首歌动笔前必须回答：

```text
这首歌由谁唱？
唱给谁听？
为什么必须用歌来唱，而不是写成文章或诗？
听众第一遍能记住哪一句？
```

如果这四个问题答不出来，说明题眼还没压稳，不应直接进入填词。

## 2.3 体裁前置判断

歌词体裁不是标签，而是写法约束。

写词前至少判断：

```text
演唱形式：独唱 / 对唱 / 合唱 / 群唱
演唱对象：男声 / 女声 / 童声 / 特定歌手 / AI 生成声线
叙述人称：第一人称 / 第二人称 / 第三人称
写作体式：民歌体 / 古诗体 / 自由体 / 散文体 / 新词体
用途场景：流行单曲 / 短视频切片 / 影视插曲 / 儿歌 / 行业歌 / 宣传歌 / AI 音乐发布
```

第一人称适合贴近内心和代言；第二人称适合倾诉、交流和对唱；第三人称适合距离感、故事感、历史感或群体题材。

体式错了，后面修词很难救。例如本来是贴耳都市自白，却写成古诗体；本来是传播 hook 歌，却写成散文体说明；本来是对唱关系，却只有单向独白。

## 3. 吸收后必须改变的执行方式

### 3.1 选题题眼阶段

选题不是找一个抽象主题，而是为歌词建立：

```text
题材来源
明确对象
演唱视角
体裁类型
结构方法
主情绪
主韵辙
记忆闪光点
```

如果选题阶段没有决定体裁、视角、主韵和记忆点，后续歌词容易变成“东一点西一点”的素材拼贴。

### 3.2 歌词初稿阶段

歌词初稿不是把意思分行。出稿前必须同时过四道门：

```text
文学门：主题、题材、人物、画面、情绪是否成立。
音乐门：句式、顿歇、韵脚、长短句、可唱性是否成立。
结构门：起承转合、递进、问答、回环、并列等组织方式是否清楚。
记忆门：歌名、hook、重复句、结尾句是否能被听众记住。
```

### 3.3 歌词优化阶段

修改不是润色，而是重新检查：

```text
主题是否更准
结构是否更完整
语言是否更像歌词
韵脚是否更稳
句尾是否更可唱
体裁是否更统一
是否适合谱曲 / 生成
```

### 3.4 韵脚与唱感阶段

附录二的词池不能当押韵捷径。每个候选尾词必须同时检查：

```text
韵母是否同辙
声调是否适合旋律走向
词性是否能承接句法
语义是否服务人物
是否适合拖音
是否会把高潮写软
```
