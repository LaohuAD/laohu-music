# 题眼与副歌核心句规则

本文件是老胡音乐关于创作题眼、嘴替承载、传播锚点和副歌核心句的专项规则库。

它比 `laohu_music_topic` skill 更细，负责给选题阶段提供更强的质量校验、失败识别和副歌核心句判断；skill 负责执行流程，本文件负责把判断标准压得更深。

它不是标题库，也不是金句库。它负责判断一首歌到底替谁说话、从哪里进入、哪一句必须被记住。

本文件属于增强资产，不承担选题 writer 的基础下限能力。凡是影响选题初稿是否成立的跨题材硬门和执行顺序，必须写入 `skills/laohu_music_topic_writer/SKILL.md`；本文件只保留更细的副歌、题眼、传播和案例增强。

## 0. 使用边界：内部暗线，不是对外字段

本文件里的术语用于执行官内部判断，不是给老胡看的展示模板。

默认顺序必须是：

```text
先写人能感受到的东西：一个人、一个场景、一个动作、一个情绪代价。
再压题眼和副歌方向。
最后才整理内部字段和交接材料。
```

`故事杠杆、金句钉、损失厌恶、共鸣网、利他金、大脑墙、英雄之旅、九浅一深` 等词，默认不得直接出现在对老胡展示的候选正文、选题说明和副歌方向里。需要说明时，必须翻译成具体表达：

```text
故事杠杆 → 哪个小动作撬动了大情绪。
金句钉 → 哪一句能被听众记住并拿走。
损失厌恶 → 这个人具体怕少掉什么。
共鸣网 → 听众会把这首歌发给谁、用在哪。
利他金 → 这首歌帮听众说出什么、保住什么体面。
大脑墙 → 听众原本不愿承认什么。
英雄之旅 → 这个人从哪里被迫离开，遇到什么现实阻力，回来时变成什么。
```

如果输出一开始就是字段、术语和判断，说明顺序错了。必须退回创作现场，先让人看见这个人正在经历什么。

## 0.0.1 方向标题句规则：标题不是正文摘要

方向标题句服务候选比较，不服务完整解释；它像标题，但不是歌名；像判断钉子，但还不是副歌核心句。它的任务是用一句压缩判断钉住该方向独有的关系误差、情绪刺点或认知差异，让老胡一眼区分不同候选。

四种句子分位：

```text
方向标题句：服务候选比较，钉住方向刺点。
解释句：服务老胡理解，负责讲清人物、关系、因果和风险。
试词 / 金句候选：服务歌词可能性，必须单独放候选区，接受唱感和位置检查。
歌名候选：服务整首歌命名，必须经过命名转译。
题眼判断：服务创作总纲，回答这首歌替谁唱、卡在什么关系里、最终要唱出什么情绪判断。
副歌核心句候选：服务可唱、可记、可传播，必须接受尾音、韵脚、复唱和情绪爆发检验。
```

方向标题、歌名、题眼、副歌核心句可以最终重合，但选题阶段不能混岗。同一句可以暂时兼任多个角色，但必须标明主职责，并逐项说明待验证风险。顶尖作品里歌名、题眼和副歌 hook 的合一，是逐项通过后的高压缩结果，不是选题阶段偷懒。

合格方向标题必须：

```text
先搭关系，再压缩。
有关系判断、情绪刺点或认知反转。
能一眼区分该方向和其他方向。
能被正文解释解压。
不冒充歌名、副歌核心句或最终传播句。
```

方向标题可以借公众号标题的钩子逻辑，但要收束到音乐选题。公众号标题常用“目标读者 + 具体损失 + 刺痛判断 + 隐含承诺”；音乐方向标题则要转译成“主角位置 + 关系误判 + 情绪损失 + 歌曲出口”。它不是把故事讲完，而是先钩住一个判断。

可用标题结构：

```text
不是 A，是 B：打掉常见误判，露出真正关系。
你以为 A，其实 B：制造认知反差。
A 不是结束，是 B 的开始：把动作重新定性。
最可怕的不是 A，是 B：把痛点往深处推。
A 越像 B，越说明 C：用悖论制造记忆点。
```

标题必须短、准、能解压。若一句标题需要正文解释半天才知道主角是谁、误判是什么、痛点在哪里，说明它只是伪金句。

方向标题不能用长解释句、分析句或不自然搭配冒充金句。`她不是不爱了，是不想再被爱改造成另一个人` 能说明方向，但太像选题解释；`她不是冷，是已经把最后一次心软用完了` 有反差，但“心软用完了”把抽象情绪当库存，第一耳不够自然；`我不能为了被你爱，连我自己都不剩` 语义能懂，但不像成熟标题或自然唱词。更稳的方向是先压成短准判断，例如 `水瓶女爱得深，醒得快`、`她不是冷，是不再陪你重来`，再由正文解释关系机制。标题负责比较候选，不负责把所有意思一次讲完。

判废清单：

```text
只复述主题，如“受害者逃离暴力关系”。
只是解释句删短，如“她不再替他圆场”。
像课程标题、作文题、短视频标题、时间管理或人生感悟文案。
只有抽象词，没有关系抓手、动作抓手或情绪刺点。
借歌名或副歌位置偷跑，导致标题、歌名、副歌三者混岗。
```

标题写法可借老胡文稿的方法，但不能照搬文章腔：标题不是总结全文，而是钉住全文；压缩不是省略，而是先把“谁和谁 / 哪个误判 / 哪个代价 / 哪个动作”搭清楚，再压成能被记住的判断。

## 0.1 普通话摘要不能冒充副歌核心句

本规则适用于题眼、副歌核心句、歌名方向、歌词主句和发布传播句。意思正确，不等于歌词成立；能解释主题，不等于能当副歌。

### 0.1.1 对话对象与句子位置

同一句压缩表达在不同位置有不同标准。选题解释、内部判断、歌词试词和最终成品不能互相冒充。

```text
给老胡看的选题解释：必须清楚、展开、可判断。它负责让老胡明白方向、风险和选择差异，不追求金句感。
给创作者 / 执行系统看的内部判断：可以记录题眼、证据链、风险和禁用路线，但不得直接端到对外说明里。
给歌词角色唱的试词：可以压缩、有情绪、有声学设计，但必须单独放在候选区，接受动作对象、第一耳理解、尾音、韵脚和乐段位置检查。
给最终听众听的金句 / 副歌 / 歌名：必须有前文托底、公共认知、关系解压和声音成立，不能在选题解释阶段直接宣布为成果。
```

高风险错位：用一句伪金句替代解释。例如 `我不能再把他的下跪听成回家` 试图一次压入下跪、悔改误判、回家幻想和控制循环，但如果没有先说明人物为什么会这样误读，它既不像清楚解释，也不像成熟歌词。此类句子必须先拆成普通话关系说明，再决定是否降级为试词方向。

正确顺序：

```text
普通话解释：她以前看到他下跪，会以为他真的想改、想把这个家过下去；后来她明白，那不是结束暴力，而是把她重新留下来的动作。
创作显影：他跪在门口，地上有碎杯子，她这次没有扶他，也没有收拾，而是把钥匙收起来。
试词方向：他跪在门口 / 我把钥匙收好。
后续检查：这还不是终稿，必须继续检查声口、主韵、尾音、气口和乐段位置。
```


三层句子判断：

```text
普通话摘要：
只负责说清意思。作者 / 分析者视角明显，像解释主题；不一定能唱，不一定有动作对象，不一定有尾音和韵脚。内部只能归为语义层，不能写成歌词成果。

歌词化一稿：
把摘要推进到角色、动作、物件、身体反应和关系现场里。有明确说话人，有动作或物件，有对象，像歌曲里的“我”在唱，不像作者在总结主题。

副歌核心句 / 歌词化金句：
作为整首歌的记忆点、传播句或情绪爆发点。必须能唱、能记，有尾音和韵脚意识，有身体 / 动作 / 声音 / 关系落点，能压住整首歌题眼。不是文章标题句，不是普通话总结句。
```

硬门：

```text
凡是还停在普通话摘要的句子，不得作为副歌核心句、题眼金句、歌词亮点、优化后成果、最终歌词主句或发布传播句交付。
如果一句话意思正确但不像歌，要在内部降级为语义层，继续歌词化；对外不必贴标签，但不能放在歌词成果的位置。
```

通用生成流程：

```text
普通话因果
→ 核心动作 / 物件
→ 谁唱给谁
→ 歌词化一稿
→ 主韵辙 / 尾音检查
→ 副歌核心句候选
```

高风险语义草稿：

```text
我差点把伤害传下去。
过去差点借我的手继续活下去。
我不是受害者，我要阻断暴力。
我把自己带回光下。
```

这些句子能解释主题，但不能直接作为确认副歌核心句。继续追问：

```text
谁在伤害？
伤害通过什么动作继续？
谁看见了？
哪一秒被停住？
尾音、韵脚和唱感能不能承载副歌？
```

示范路径：

```text
普通话摘要：我差点把伤害传下去。
歌词化一稿：我抬起的手，停在你眼前。
副歌候选方向：我把手放下，才算真的长大。
```

最后一句仍需继续审韵、唱感和情绪力度，但它已经比普通话摘要更接近歌词。

## 0.3 精英题眼与高概念压缩

题眼不只来自具体故事，也可以来自概念悖论、伦理边界、身份翻面、语言姿态或流派角度。但高概念不能直接当副歌口号，也不能直接拿来跟老胡沟通选题。它必须能被解压成一个人、一段关系、一条声音路线和一个可唱位置；对老胡展示时先讲清解压关系，再给可能的压缩句。

高概念题眼成立条件：

```text
可解压：能说清谁在什么时刻需要这句话，不靠作者解释补意义。
有证据：至少有一个关系、动作、声音、物件或身体后果能证明它。
有声学路：主韵方向、尾字、气口和句长有初步判断。
有乐段位：它适合 Verse 证据、Pre 收紧、Chorus 主句、Bridge 翻面还是 Outro 余味。
有例子：抽象规则必须配一个歌词化示例；长例子归入 抽象概念歌词化示例库。
```

具体场景是证明层，不是审美上限。若一个方向很具体但只能写成普通故事，不能压出可唱题眼；另一个方向较抽象但能补足证据链、声学入口和副歌回环，可以优先选择后者。

副歌核心句候选必须补充声学简版：

```text
候选句：
乐段位置：Chorus / Bridge / Outro / Pre 入副歌。
主韵方向：
尾字：
气口：
句长：
当前层级：普通话底稿 / 歌词化一稿 / 可唱优化稿 / 可确认核心句。
```

## 0.4 身份标签型 hook：标签只是入口，不是情绪证明

星座、人群、职业、MBTI、地域、年龄层、人格标签和价值观歌曲，可以用身份大词点人群、召唤同类和建立副歌认领感。`水瓶座、爱自由、需要空间、清醒、独立、反传统、倔强` 这类词不是天然低级；真正的问题是把它们反复当成情绪证据，让副歌变成性格说明书。

身份标签型 hook 的正确路径：

```text
身份标签 → 关系悖论 → 具体代价 → 公共困境。
```

四层职责：

```text
身份标签：让目标听众知道“这首歌和我有关”。
关系悖论：让情绪从标签进入关系，例如对方先爱她的不一样，后来又怕她不一样。
具体代价：让主歌证明这个性格在关系里被欣赏、误读、规训或消耗。
公共困境：让非同类听众也能代入，例如“被爱的人想改造成更好控制的样子”。
```

高风险写法：

```text
我是水瓶座 / 我爱自由 / 我需要空间。
我清醒我独立 / 我不接受被改变。
爱得深也爱得倔强 / 你别替我规定形状。
```

这些句子可以作为身份入口或局部态度句，但不能整首歌反复承重。若 C1、C2、Final Chorus 都靠同一组标签换顺序，副歌会变成网感口号，缺少乐段递进和人性厚度。

更强的 hook 方向不是“删掉标签”，而是把标签翻成关系刀口：

```text
弱方向：我爱自由，我需要空间。
强方向：你当初爱我不一样，后来又怕我不一样。

弱方向：我不接受被驯服。
强方向：你说爱我的棱角，又一寸一寸替我磨平。
```

上面只是机制示例，不是固定模板。判断重点不是句子是否照这个写，而是副歌有没有从“我是谁”推进到“你如何对待这样的我”。

检查问题：

```text
删掉身份标签后，这句 hook 是否仍然有关系刀口？
主歌能不能证明这个标签为什么会痛？
副歌有没有把标签转成对方行为、关系误判或人物代价？
Bridge 是否补出人物自我怀疑、私心、贪恋或误判？
Final Chorus 是否带着新理解回来，而不是继续重复身份宣言？
```

硬门：身份标签可以成为歌名、副歌词或尾句，但不能独自成为题眼。真正的题眼必须能回答：这个身份在这段关系里被怎样误读、怎样消耗、怎样反击或怎样重新认领。

## 0.2 副歌爆发位的词性与比喻边界

规则状态：稳定规则。适用于所有副歌核心句、hook、传播句和歌词优化，不属于单一题材经验。

副歌爆发位必须让听众第一耳知道人物在压住什么、停住什么、反抗什么或保护谁。不能用“虚名词 + 私人比喻”假装情绪浓度。

高风险结构：

```text
虚名词：狠话、伤害、过去、阴影、创伤、痛苦、命运、黑暗。
私人比喻：咽成一口沙、吞成一片海、碎成一场雨、熬成一道疤。
```

这些词不是绝对禁用，但必须有前文授权：

```text
虚名词要有具体台词、动作、物件或罪证支撑。
比喻要有共同物性、共同动作或共同感官，第一耳不用解释也能懂。
动作对象要成立：咽可以咽话、咽哭声、咽血腥味；沙如果没有口腔干涩、说不出话或现场灰尘等前文授权，就容易像作者硬接的漂亮词。
```

副歌高潮优先使用：

```text
强动词：停、砸、锁、撕、摔、逼、断、拦、吞、咬、退、护。
具象对象：手、门、碗、眼睛、声音、脚步、墙、孩子、血、钥匙、灯。
关系后果：吓到谁、学会什么、把谁推回哪里、让谁再也不敢说话。
```

判断句：

```text
如果一句副歌需要解释“这里的沙象征什么”，它就不该站在高潮位。
如果一个名词删掉前文就不知道具体指什么，它只能做语义草稿，不能做 hook。
如果动词和对象不是日常可发生关系，也没有前文授权，必须换成第一耳能懂的动作后果。
```

题眼不是歌名，不是宣传语，也不一定原样进入歌词。

### 1.0 歌名命名硬门：歌名不是故事文件名

歌名不是故事标题、作文题、小说章节名或某一幕动作记录。歌名要把整首歌的情绪、关系、命运、态度或核心声音压成一个可记、可唱、可传播的名字。

歌名和副歌 hook 默认同源，但命名顺序必须从情感往外推。正确顺序是：先确定核心情感，再把情感写成副歌核心句组，再从副歌里的核心词、核心动作、核心关系或最强 hook 中提炼歌名。不是因为先有歌名才写副歌，而是因为副歌把情感唱准了，歌名才有来源。歌名至少要进入副歌记忆系统；强传播歌曲可以让歌名完整进入主 hook。歌名不必每次逐字出现，但听众唱完副歌后，应该能自然想起歌名；否则标题和记忆点断开。禁止先定一个漂亮歌名，再倒逼副歌牺牲自然句法和情绪推进去露题。

歌名也不能只是题眼解释。`醒得快 / 不再重来 / 爱得深，醒得快` 能做内部判断或方向标题，但作为歌名偏说明、偏直接，缺少文学性和可感入口。合格歌名可以点人群、主题、情绪、特质或现象，但必须让听众先感到一种关系状态、画面气质或声音钩子，而不是像作者解释“这首歌讲什么”。同一方向至少要同时给出关系命名、意象命名和悖论命名三类候选，再判断哪类最能进入副歌记忆。

老胡当前歌名偏好校准：同一题材里，`到此为止`、`风有边界`、`清醒的痛` 这类名字优于 `醒得快 / 不再重来 / 爱得深，醒得快`。原因不是它们更冷门，而是它们完成了命名转译：

```text
到此为止：关系边界命名。它不是解释“我不回去了”，而是给这段关系下一个结束判词，短、硬、能进副歌，也有情绪体面。
风有边界：意象化性格命名。它把水瓶座女生的自由、不可控制、需要边界压进“风”这个可感入口里，比直接说“她爱自由”更有美感。
清醒的痛：悖论情绪命名。它同时保留“清醒”和“还痛”，避免把女主写成冷血，也避免退回哭诉。
```

这类歌名的共同标准：

```text
不是解释主题，而是命名关系状态、人物气质或矛盾情绪。
短，能复述，能进入副歌或封面大字。
有情绪，但不把情绪讲满。
有文学性，但第一耳不用解码。
能让听众先感到一种气质，再由歌词补完整故事。
```

歌名还要做“凝缩度”校验。解释性连接词、补足动作和口语化修饰不一定越完整越好；很多时候，删掉解释以后更像歌名。`空出来的海` 能解释“海空了”，但“出来的”把状态说明得太白，语感普通；压成 `空海` 后，词更短、更像命名，也同时打开“空掉的海 / 空旷的海 / 空性与海”的多层感。`没回头的风` 是口语叙述，能懂但偏普通；`永不回头的风` 更像文学命名，因为“永不”增加了性格和命运感，语体也更像歌名。

凝缩不是随便砍字。合格凝缩要满足三点：

```text
删掉的是解释性、口语性、连接性的字，不删核心情绪和核心意象。
压缩后第一耳仍能感到情绪方向，不需要作者解释半天。
压缩后比原句更有命名感、画面感或文学性，而不是变成生硬谜语。
```

可参考对照：

```text
空出来的海 → 空海：去掉解释，保留空与海的气质张力。
没回头的风 → 永不回头的风：从口语描述升级成性格 / 命运命名。
爱得深，醒得快 → 清醒的痛：从解释人物反应，转成悖论情绪命名。
```

歌名还可以沿“意象人格化 → 性格命名 → 抽象大词”继续升级。`永不回头的风` 已经比 `没回头的风` 更像文学命名，但它仍然在描述风的行为；如果本题材核心是水瓶座女生的性格和态度，可以进一步人格化为 `倔强的风`，让风带上人的脾气、边界和不肯回头的性格。再继续凝缩，可以压成 `倔强`，直接命名人物精神和副歌态度。

抽象大词不是天然空。`倔强` 这类歌名成立的条件是：

```text
它本身有公共情绪和性格重量，听众第一耳能懂。
它能准确命中主角特质，不只是普通形容词。
副歌里必须把它唱成态度，而不是只把它挂在标题上。
主歌要证明她为什么倔强：不是任性，而是不再被改变、不再解释、不再回头。
```

抽象大词歌名适合人群、特质、态度、现象很强的作品。它比意象歌名更直接，也更容易传播；风险是空泛和撞题。因此生成时要同时比较三层：

```text
意象层：风有边界 / 倔强的风。
性格层：倔强。
悖论层：清醒的痛。
```

若抽象大词能被副歌反复唱出态度，并且主歌证据能证明它不是口号，可以优先于意象歌名。

高风险歌名：

```text
那晚我没敲门
我在楼下站了三小时
你把杯子放回桌上
下雨那天我没带伞
```

这些名字不是绝对禁用，但默认只停在“事件片段”。它们像要讲故事，却没有把故事提炼成情绪命名、关系状态或副歌钩子。除非歌曲本身就是强叙事民谣、歌名能成为反复出现的 hook，并且副歌给它足够回声，否则不能作为首选歌名。

歌名优先从 5 类里选：

```text
情绪命名型：命名一种状态，如 体面、后来、成全、阴天。
关系定性型：给关系下判断，如 一门之隔、说谎、演员、不将就。
副歌核心句型：直接取副歌里最能复唱的一截，如 可惜没如果、你不是真正的快乐。
意象压缩型：用一个意象承载整首歌，如 红豆、白月光、门外、一声响。
悖论 / 反常识型：用矛盾感制造记忆，如 近到不能靠近、没响的告别。
```

合格歌名至少命中 3 项：

```text
能命名整首歌的情绪状态，而不是只记录一件事。
能被解压成故事、人物和关系，不是空泛主题词。
能进入副歌或成为副歌核心句的缩写。
有声音感：好念、好记、尾音能落，必要时能被唱出来。
能牵出整首歌，而不是只装下一个镜头；不要求概括全部剧情，但必须打开核心情绪、关系或声音。
有独特性，但不像作文题、小说章节或短视频标题。
和曲风、人物声口、歌词注册一致。
```

抽象度规则：歌名通常要比歌词里的具体细节更抽象一点，但不能空。最佳状态是“半具体，半抽象”：有一个能看见或听见的入口，也有一个能扩散到多人经验的关系意义。例如 `一门之隔` 具体是门，抽象是关系距离；`没响的门铃` 具体是门铃，抽象是缺席的回应；`近到不能靠近` 具体是距离，抽象是关系悖论。注意：例子只说明颗粒度，不代表某一题材的专属流程。

### 1.1 歌名命名转译链：题眼动作不是最终歌名

任何题材都不能从故事动作直接跳到最终歌名。先把题眼动作当作内部锚点，再判断它应该被转译成情绪、关系、命运、态度还是声音。

```text
原始题材
→ 人物关系 / 心理痛点 / 社会处境
→ 题眼动作 / 关系动作
→ 命名重心：情绪 / 关系 / 命运 / 态度 / 声音
→ 歌名候选类型：情绪命名 / 关系定性 / 副歌核心句 / 意象压缩 / 悖论反常识
→ 候选淘汰理由
→ 当前推荐歌名
```

分层判断：

```text
事件名：记录发生过什么，如“那晚我没敲门”。通常只适合做故事锚点。
题眼动作：人物做了什么 / 没做什么 / 差点做什么，如“没敲门”“按灭手机”“放下手”。可以进入副歌，但不默认等于歌名。
核心意象：承载题眼动作的物件或声音，如“门铃”“回音”“旧工牌”“绕远路”。
关系命名：把动作上升成关系状态，如“一门之隔”“没有回音”“近到不能靠近”。
最终歌名：能同时装下动作、关系、情绪和声音，离开单个镜头也成立。
```

决策流程：

```text
先问：这首歌最该命名的是事件、关系、情绪、命运、态度还是声音？
如果只是事件，默认降级为题眼动作或故事杠杆，不作为首选歌名。
如果事件句已经能在副歌里反复复唱，并且能装下整首歌的关系和情绪，才允许保留为歌名。
每个确认方向至少生成 3 个跨类型歌名候选，不能只罗列同一类名字。
每个候选必须说明：命名了什么；来自哪个题眼动作 / 关系动作；能否进入副歌；最大风险是什么。
最终必须给当前推荐、备用候选和淘汰理由，不能只给一串名字。
```

歌名还必须和选题逻辑同向。比如一首歌真正讲的是“不回头、不再回到循环”，如果歌名叫《回头》，就会和核心态度相反。除非歌词在副歌里明确把“回头”反讽化、否定化或重新定义成“不再回头”，否则不能推荐这种反向歌名。歌名可以有悖论，但悖论必须被作品托住；不能因为一个词好听、短、像歌名，就忽略它和故事逻辑的方向冲突。

如果老胡指出“这个词好听但逻辑反了”，必须先承认它只是在声音或气质上有吸引力，不等于命名成立。下一步不是硬保留这个词，而是判断能否通过副歌把它重新定义；如果副歌没有承担这个重新定义，歌名必须转向同向表达。例如故事核心是“不回头”，可以考虑《不回头》《下一次之前》《门口的花》这类同向命名；《回头》只能作为反讽命名方案，不能默认推荐。

歌名工作台最小格式：

```text
题眼动作 / 关系动作：
命名重心：情绪 / 关系 / 命运 / 态度 / 声音
候选 A：
  类型：
  命名了什么：
  来自哪里：
  能否进入副歌：
  风险：
候选 B：
候选 C：
当前推荐：
淘汰理由：哪些像故事文件名 / 主题词 / 短视频标题 / 口号 / 半句诗。
```

歌名候选必须做反向审稿：

```text
它是在命名情绪，还是只在讲事件？
它能不能被副歌唱出来？
它有没有声音感、尾音和复述性？
它能不能装下整首歌？
它是不是太泛，如 遗憾 / 孤独 / 成长 / 错过 / 释怀？
它是不是太像故事文件名，如 那晚我没敲门？
它和本曲风、本人物声口是否一致？
```

题眼是整首歌的材料筛选器：

```text
替谁说话
→ 在什么具体场景里说
→ 平时为什么说不出口
→ 情绪里最大的代价是什么
→ 副歌为什么非得唱出来
```

如果一个灵感只有主题，没有题眼，下游填词会变成散文、文案、作文或 AI 平均答案。

## 2. 题眼阶段内部必须回答

以下问题是内部暗线和交接证据，不是对老胡展示的字段清单。正式输出要先给短故事、题眼雏形、副歌方向和必要取舍，再按需要折叠这些判断。

- 用户表层想写什么。
- 用户真正想表达什么。
- 这首歌替谁说话。
- 明确人群画像是谁：必须具体到一个处境中的人，不要只写“毕业生、中年人、所有人”。
- 听众脑子里已经存在的认知定势是什么：他已经相信、担心、期待、误判、羞于承认或反复自我安慰的东西是什么。
- 本题眼借用哪一种既有定势：恐惧、欲望、怨气、羞耻、侥幸、亏欠、报复心、自尊心、体面、俗语、群体共识或行业黑话。
- 这首歌给听众什么：他担心的被说中、他想要的被承认、他不敢说的被唱出来，还是他自欺的借口被戳破。
- 人物可被接受的缺点是什么：嘴硬、拖延、逞强、自欺、偏执、舍不得、嫉妒、小气、怯懦、虚荣、报复心、不甘心等，哪一个能让听众认领。
- 共同敌人是什么：人物和听众一起对抗的是谁、什么机制、什么借口、什么现实压力或什么自我弱点。
- 表面共识是什么，共识里可借用的偏见是什么：不要停在大家都同意的安全结论里。
- 个体宣言句是什么：哪一句能让具体听众拿来替自己宣告，而不是像公共标语。
- 脑力取舍理由是什么：为什么放弃其他方向，集中打这一句、这一种偏见和这一类人。
- 痛苦敏感点是什么：目标听众最怕失去什么、承认什么、被戳穿什么。
- 损失厌恶点是什么：如果他不面对这件事，具体会少掉什么、错过什么、丢掉什么、被谁替代。
- 过敏反应句是什么：哪一句会让他不舒服、想反驳、想转发、想认账，而不是只觉得好听。
- 苦难借势点是什么：如果涉及困难、失败、低谷或委屈，它借用的真实生活挑战是什么，而不是虚构假惨。
- 尊严保留点是什么：人物虽然难，但哪一个选择、动作、沉默、反击或自我要求让他没有被消费成可怜人。
- 转化落点是什么：这份苦难最终走向和解、励志、认账后行动、重新站起来，还是重新命名自己。
- 卖惨风险是什么：哪里可能因为过度渲染可怜、假痛、求同情或平台式惨钩子而削弱作品。
- 故事杠杆是什么：哪个小动作、小物件、小冲突、小场景或短句能用最小力量撬动最大情绪和认知。
- 大脑墙是什么：目标听众哪一道信念、防御、价值观、自尊、借口或经验墙会挡住这首歌。
- 穿墙缝隙是什么：这首歌借哪段已有经验、哪句俗语、哪种羞耻、哪种损失或哪种关系压力进入。
- 金句钉是什么：哪一句短、准、扎心、可复述，负责把题眼钉进听众脑子。
- 文字核武器句是什么：哪一句用最少字数压住最大故事、冲突、态度和情绪，离开画面也能被复述。
- 信息密度是否足够：这句话是不是高密度压缩包，还是用很多字讲一个普通意思。
- 画面服务对象是什么：核心画面服务题眼、副歌核心句、广告语、金句钉还是传播句；说不清就不是资产。
- 叙事推进量是什么：这一方向从开头到副歌让人物知道、失去、承认或做出了什么变化。
- 共鸣网入口是什么：听众会在哪张网使用这首歌，评论区、短视频配文、社群暗号、关系转发、身份宣言还是现场合唱。
- 利他金是什么：这首歌具体给听众什么可用利益，情绪命名、替他说话、解除羞耻、给台阶、帮站队，还是给分享理由。
- 这首歌不讨好谁、不服务谁：哪些安全期待、宽泛人群或温和审美可以被放弃。
- 选择性注意点是什么：哪个词、动作、姿态、反差、罪证或句尾会让目标听众停一下。
- 喜剧反差是否适用：本题材是否适合轻喜剧、自嘲、反讽、短视频切片或发布包装，不适合时不要强行搞笑。
- 狠词怂态是什么：哪里可以用很狠的词说很怂、很怕、很没底气的态度。
- 言不由衷句是什么：哪一句明知是假、夸张或嘴硬，却能让听众立刻听出人物真实处境。
- 经典借势点是什么：借用哪种经典作品结构、场景、人物关系或集体记忆，而不是复制内容。
- 九浅一深策略是什么：如果做系列或短视频矩阵，哪些浅入口抓流量，哪一个深内容圈住铁粉。
- 思维出轨点是什么：哪一个反常转弯、争议角度或意外说法能制造注意力，但仍然服务题眼。
- 故事三硬核是否适用：本题材是否属于品牌故事、人物故事、事业故事、逆袭故事或强叙事选题。
- 对立面是什么：人物、品牌或团队真正对抗的反派、强敌、旧秩序、偏见、市场压力、失败系统或自我阴影是什么。
- 对立面强度如何：这个负面力量为什么足够强，如何催化人物、品牌或团队成长。
- 独特个性是什么：人物、品牌、产品或团队哪种鲜明特质会让一部分人认领，也让另一部分人不舒服。
- 不可能讨好谁：这个个性天然会放弃哪些人，不能为了面面俱到写成墙头草。
- 黑暗时刻是什么：哪一刻人物、品牌或团队像死过一回，必须靠选择、代价或重生改变自己。
- 涅槃转化是什么：黑暗时刻之后，人物、品牌或团队变强在哪里，旧我死在哪里。
- 英雄之旅适用性是什么：本题材是否属于第一桶金、事业转折、逆袭成长、创业失败再出发或人生阶段跃迁，不适用时不得硬套。
- 离开之幕是什么：人物为什么必须离开原来的城市、家庭控制、行业处境、关系规则、旧身份或旧自我。
- 启动之幕是什么：人物进入未知世界后遇到哪些人、事、机会、诱惑和阻力。
- 要打的怪兽是什么：资金短缺、团队不合、市场不认可、信任崩塌、能力不足、身份羞耻、自我怀疑、贪婪、傲慢或失控。
- 归来之幕是什么：第一桶金或阶段成功带回了什么身份、资源、关系变化、代价和危险。
- 起点 / 深渊双岔口是什么：这次成功是下一段旅程的起点，还是更大危险、傲慢、贪婪、失控或坠落的开端。
- 说话人面对谁。
- 听众从哪个场景进入。
- 听众故事开始时的心理是什么，中段被什么现实翻转，结尾为什么愿意认同副歌。
- 核心关系是谁和谁之间发生了变化。
- 平时为什么不能、不敢、不会表达。
- 故事引擎是什么：事件、冲突、反差和转折如何把题眼推出来。
- 情绪债务是什么：亏欠、误解、告别、后悔、证明、释怀或重新命名里，哪一项是主债务。
- 证据配额是什么：后续歌词至少能调用哪些动作、物件、时间、场景和关系代价。
- 情绪发动机是什么：委屈、亏欠、想念、不甘、后悔、体面、释怀，还是混合情绪。
- 关系代价是什么：失去、欠下、错过、忍住、没说完、不得不放手。
- 哪一句最可能成为副歌核心句、BGM 切片句、评论区引用句或现场合唱句。

## 2.0.1 副歌核心句的金句化硬门

副歌不是主歌画面的压缩版。主歌可以负责铺场景、交代动作、慢慢让情绪浮出来；副歌必须把前面所有画面压成一句听众能认领、能复述、能转发、能反复唱的情绪判断。

如果副歌只是把几个画面排在一起，例如“有人做什么，有人去哪里，夏天怎样，我们怎样”，但没有反差、认知转折、情绪代价或个体宣言，它最多只能算主歌素材，不能算合格副歌。

副歌升维是硬门。升维不是突然变宏大、变玄、变大道理，而是从“发生了什么”抬到“这件事意味着什么、我因此判定什么、我从此认下什么”。Verse 可以写场景和动作，Pre 可以写压力和临界，Chorus 必须写判词、质问、宣告、愿望、认账、偏执、公开立场或不可逆决定。若副歌仍然主要由“我做了什么 / 你做了什么 / 某个物件怎样”构成，即使句子顺、画面美、押韵稳，也只能算叙事延长，不能算高质量 hook。

副歌核心句优先借公共强词和强虚词。公共强词不是冷僻词，而是听众已经懂、第一耳有情绪方向的字词和短语，例如困、锁、恨、绕、碾、怪、求、偏偏、为何、奈何、只求、两清、失格、折损、委曲求全、低声下气、坦荡、赤诚、热烈。强虚词的作用不是填字，而是制造质问、偏执、求告或反差。判断标准：这个词是否让副歌从“解释故事”变成“释放情绪”；它是否有主歌证据支撑；它是否适合当前题材强度。

歌名感不等于副歌核心钩子成立。漂亮、顺口、能做标题的意象句，例如“灯火偏向你、春风先替我说、月色落向你”，可以作为歌名、尾句回声或副歌辅助 hook，但不能自动承担主副歌核心。副歌核心钩子必须比标题多一层情绪动作：偏执、认账、质问、宣告、不可逆选择、公开立场、关系判词或听众能认领的嘴替。若一句只是“某个美好意象偏向你”，听起来安全、平均、温柔，没有让人物承担态度或代价，判为标题感 hook，不判为核心 hook。

旧 hook 降级必须同时降级“位置权”。如果一个曾经的主 hook 被判定为歌名感、太安全或不再承担副歌核心，不能只在说明里说它降级，却继续把它放在副歌尾句、Final Chorus 最后一拍、Outro 最后一行或全歌最高重复位置。听众记忆由位置和重复决定；旧句只要占据尾钩，就会实际夺回主 hook。正确做法是：新主 hook 放在副歌第 1 句和第 8 句或同等强位回环；旧 hook 只在歌名、段内轻回声、Outro 倒数位置或画面收束中出现，且最终落点必须回到人物态度、关系判词或新主 hook。

商业歌名必须和主 hook 资产统一。若改稿后真正的商业主 hook 已经从旧歌名句转移到另一句，必须重新评估歌名。旧歌名可以保留为意象别名、作品目录名、Outro 回声或视觉封面元素，但正式歌名默认应优先使用最能被副歌复唱、短视频截取、评论区引用和听众认领的主 hook。否则会出现标题入口和副歌记忆点分裂：听众看到一个标题，唱走另一句。判断标准：听众第一次听完副歌，最可能搜索、转发、打在字幕上的到底是哪一句；那一句通常更适合成为商业歌名。

评审时必须区分三种句子：

```text
歌名 / 标题句：好记、好看、可回声，但情绪未必够重。
辅助 hook：能强化主意象、主韵或尾钩，但不承担全曲最大情绪出口。
核心钩子：唱出来以后人物站到明处，关系回不到原位，听众能拿去表达自己。
```

积极甜歌也不能把核心钩子写成“安全表白”。`我喜欢你、灯火偏向你、我也偏向你、想和你一起走` 这类句子可以甜、可以顺，但若没有“我偏要、我认下、我不再藏、满街看见也不退、众人笑我也承认”等公开姿态，就只是平均甜句。甜歌核心钩子要让听众听见一个人从试探走到明处，而不是只听见一个漂亮意象照向对方。

具体意象在副歌里只能保留最能代表全歌的 1-2 个。副歌可以有明月、转盘、灯笺、伞、门、酒杯、长街，但这些意象必须被情绪判词点亮。若副歌塞进多个物件和动作，只是在重复 Verse 的实景叙事，会稀释主 hook。副歌里的物件要么成为判词的证据，要么成为主 hook 的声音锚点；否则移回 Verse / Pre。

积极甜歌的副歌也必须有升维句。它不一定要写苦、恨、命运，但要把心动从“你靠近我”升成“我认下偏爱 / 我藏不住 / 我偏要热烈 / 我只向你坦荡 / 满城灯火都替我露馅”这类公开、失控、偏爱或认领。若甜歌副歌只有牵手、撑伞、并肩、靠近、微笑，缺少公开立场和可传播心声，会显得温和安全、不够打动人。

前置硬门：

副歌首先是歌词，不是观点句。任何副歌核心句必须先满足唱感：发声顺、发音顺、韵脚稳、句尾能拖、气口自然。只有在这个基础上，才谈金句、美感、画面、动词名词和情绪刀口。

如果一个句子语义更准，但破坏声韵结构，不能进入副歌。它可以作为题眼说明、主歌素材或改写方向，不能作为 Chorus 核心句。

副歌候选不能停在“正确”。正确的伦理、正确的态度、正确的行为边界，只能保证不翻车，不能保证像歌。尤其是关系伤害、忏悔、离开、创伤循环类题材，副歌不能写成“我不做 A / 我不做 B / 我不再 C”的承诺清单。正确做法是把“不做”背后的情绪压成可唱的动作、物件和关系判断：哪一秒醒了，哪个物件变成证据，哪句话再也不信，哪扇门不再打开。

副歌四句或八句内部必须有推进。推进不是换几个近义词，而是每一句让人物多看懂一层、多失去一层、多切断一层或多承认一层。例如“看见道歉重复 → 识破下跪功能 → 放下原谅冲动 → 离开循环”，这四层可以形成副歌；如果四句都只是“我不再原谅你”，就是原地打转。

副歌四句推进本质是情绪曲线嵌套。整首歌有大情绪曲线，决定 Verse / Pre / Chorus / Bridge / Final Chorus 分别负责什么主情绪；每个乐段内部还要有小情绪曲线，决定本段每一句怎样推进。副歌的小曲线不能脱离全曲大曲线：第一次副歌不要提前唱完 Final Chorus 的终局，Bridge 不要重复副歌已经完成的情绪结论，尾副歌要在前面基础上升级或回收。写副歌前先问：这段副歌的主情绪是什么，它要把听众推到哪个 hook 落点，四句分别增加了哪一层情绪、关系、代价或认知。

副歌不应被拆成固定句位岗位。更稳的判断是“核心句组稳定 + 变体位开放”。核心句组通常是前 1-2 句，也可能是副歌里最强的 1-2 句；它负责主 hook、核心心声、歌名种子、核心关系判词或最强嘴替价值。C1、C2、Final Chorus 应优先保留核心句组、主韵和关系骨架。后半句、扩展句、追加尾句和 Final Chorus 的局部改写是主要变体位，用来根据情绪曲线做加重、翻面、回收、反转、留白、身份变化、身体后果或主 hook 复唱。第一句开门、尾句收束只作为检查项，不是写作模板；每一句具体承担什么功能，要由本段小情绪曲线决定。

核心句组按功能判定，但副歌高潮默认前置交付。功能上，核心句组是最值得被听众记住、复唱、转发、提歌名的 1-2 句；它要集中承担主情绪、主关系、主韵、传播记忆和题眼 / 歌名生长点。位置上，Pre-Chorus 已经给出“高潮要来了”的听觉承诺，所以 Chorus 前 1-2 句应优先交出核心句组。若核心句组在第三、四句才出现，必须证明前两句属于同一个核心句组的必要上半句、发令动作、悬念张力或不可省铺垫；否则就是高潮开门失约。不是绝对禁止三四句成为核心，而是要求它不能让听众在副歌开头等两句才等到真正的 hook。

Pre-Chorus 到 Chorus 的关键不是两段都强，而是两段能接力。Pre 负责蓄力、对准、悬住：把主歌证据压成身体压力或关系压力，让最后 1-2 句朝向副歌核心句组、主韵或关键词，并留下一个非唱不可的缺口。Chorus 负责接住、爆开、交主 hook：第一句接住同一个情绪方向，前 1-2 句把压力唱成核心心声或关系判词。Pre 不是小副歌；如果它已经把核心心声完整唱完，副歌就会变重复。Pre 也不能像句号一样收平；如果它把情绪解决掉，副歌开口就像硬切。可用方式包括身体临界、话到嘴边、动作失控、关系逼近、对方一句话、沉默加压、旧证据回闪、主 hook 关键词预埋、主韵预埋、半句悬停和反问前摇。它们只是开放工具库，真正标准是：Pre 有没有把副歌逼出来，Chorus 有没有接住同一口气。

C1 / C2 / Final Chorus 的变化要有梯度。C1 建立主 hook 和主情绪；C2 保留核心句组，在变体位里吸收 Verse2 / Pre2 的新证据、新代价或新心境；Final Chorus 保留核心记忆，再选择最需要的方式推到最重、最完整，或回收 Bridge 的新理解。可用方式包括动作升级、身份变化、关系判词升级、身体后果落地、Bridge 视角回收、歌名 / 题眼回收、主 hook 复唱、尾句追加、声场扩大、留白余震、反转、认账、集体合唱等。它们仍是开放工具库，不是固定顺序。判断标准：变化有没有保住 hook，新增重量是否来自已成立情绪，是否让后段比前段承担更多东西。

Bridge 到 Final Chorus 要做“翻面回收”。Bridge 不只是全曲里写得更诗意的一段，它必须让听众重新理解副歌；Final Chorus 也不是简单再唱一次，而是带着 Bridge 的新理解回到主 hook。默认最稳的是理解翻面：时间翻面、视角翻面、关系翻面、态度翻面、代价暴露、自我认账或轻升维。格局升维只在题材需要时使用，例如人生叙事、亲情离世、长久遗憾、史诗感作品；即使用人海、命运、岁月、世界，也必须回到人物关系和副歌核心句。判断标准：Bridge 能不能回答“最后副歌为什么值得再唱一次”；Final Chorus 能不能让同一句 hook 变重、变明白或变不可逆。

副歌第一句是乐段换挡句。它不一定要最大声、最狠、最满，但必须第一耳完成三件事：切换乐段能量、亮出本段主情绪、给后面几句打开冲突方向。开门方式包括反问、宣言、判词、身份变化、核心心声、强画面、动作触发、关系反差、荒唐现象、旧伤承认等；这些是开放工具库，不是题材绑定模板。强传播求留 / 控诉型可以用反问、判词、对方态度或强画面开门，亲情、成长、幽默、治愈等题材也各有常见开门方式，但不能机械规定某题材只能这么开。真正的判断标准是：它是否接住 Pre 推来的压力，是否立刻亮出本段主情绪，是否给后面几句打开冲突方向。若第一句只是状态、回忆、解释或泛泛抒情，听众要等到第二句、第三句才知道副歌要唱什么，就判为开门过软。

副歌尾句是收束与回钩句。它不是第四句补一句，也不是越狠、越痛、越复杂越好；它要把前三句推起的主情绪落到一个可记、可唱、可转述的位置。尾句可用方式包括：判词、身体后果、关系结论、身份变化、歌名 / 题眼回收、主 hook 复唱、反转、认账、动作落地、留白余震等。注意：这些是开放工具库，不是题材绑定模板。苦情控诉可以用判词 + 身体后果，也可以用身份塌陷、关系结论、歌名回收或反转回钩；亲情、成长、幽默、治愈等题材同理。真正的判断标准是：它是否收住本段主情绪，是否回钩核心记忆点，唱完是否停得住，是否给后续 C2 / Bridge / Final Chorus 留出合理升级空间。

副歌候选的文学性不是堆陌生词，也不是强造比喻。它来自三件事：公共认知里的物件、准确的动作关系、可唱的声音落点。像“下跪、门口、旧花、卡片、钥匙、手机亮起、门没有开”这类物件和动作能被第一耳理解；再通过韵脚、句式和转折压缩，才可能变成歌词。不要把语义草稿直接拆行当副歌，也不要用口水话冒充真诚。

副歌也不是总纲摘要。总纲负责把人物关系、事件因果和情绪发动机讲清楚；副歌负责把这些关系转译成音乐文学。像“差点让你替我挨完那一下”这种句子，能解释清楚“我差点把童年的暴力传给你”，但它仍像案情复述。进入副歌时必须继续转译：

```text
普通话总纲：我差点让你替我挨完童年的那一下。
副歌目标：保留“我差点复制暴力”和“我要在这里停下”，但换成身体动作、声音回环、韵脚和情绪宣泄。
检查：这句没有上下文时像不像歌；有上下文时会不会更痛；它是不是能被唱、被记、被复述。
```

强意象必须来自本歌物性系统。不要为了文学性硬塞不属于当前世界的意象。每首歌都会先建立自己的物性系统：身体动作、家庭物件、城市空间、自然天象、职业工具、宗教符号、童年物件或时代物件。强意象进入副歌前，必须和本歌已有系统有共同声音、共同触感、共同形态或共同变化逻辑；否则不是“意象高级”，而是风格跳脱。

重复必须有增量。副歌可以重复核心动作或歌名，但第二次必须改变身份、代价、语气或情绪层级。重复“我把手放下”时，第一次可以是停住动作，第二次必须变成切断遗传、保护对方或自我命名；如果两次都是同一层说明，就会呆板。

副歌要有乐段内部情绪曲线，不能只有一个情绪从头喊到尾。尤其是强叙事、关系冲突、心理转折、代际伤害、亲密关系和忏悔类副歌，必须先判断四句内部的情绪顺序：它可以从疼爱进入保护，从保护转成愤恨，从愤恨转成后悔，再落到阻断；也可以从不甘进入承认，从承认进入告别，再落到自我命名。情绪曲线不是把“疼爱、愤恨、后悔、决绝”这些词写进歌词，而是让每一句发生一个新的动作或关系变化。常见求留控诉副歌可以走“冲突打开 → 关系加压 → 我方代价 → 判词 / 后果落锤”，但这只是当前题材的一种曲线，不是所有副歌模板。亲情亏欠、积极成长、幽默讽刺、治愈释怀都要重定自己的小曲线。

副歌的动词要形成递进链。强动词不是越暴力越好，而是要让人物处境发生变化。先分清每句动作功能：对谁保护、对谁切割、对自己克制、对过去改写、对未来立誓、对关系补救。再选动词。若一段副歌只有名词、形容词和情绪标签，即使押韵，也会像散文总结；若每个动词都只重复同一个意思，也会像口号。

副歌核心句还必须过呼吸句法和动作完整性。歌词的短不是把长句切开，气口也不是逗号。断句要落在自然呼吸点、语义小完成点或旋律停顿处；不能把一个判断关系、谓宾关系或因果关系强行拆成两行。动作句可以省字，但不能省掉第一耳必需的主语、宾语、归属、方向和来源。听众必须一听就知道谁做动作、动作落向谁、从哪里来、为什么现在发生。

副歌核心句在唱感之前先过读感。主语、谓语、宾语、心理动作和指代对象必须先通顺；如果读出来都别扭，就不能靠押韵、情绪或诗性通过。尤其不能让前半句的对象是身体部位，后半句却突然让整个人承担心理动作，造成主体滑移。先用普通话确认“谁对谁做了什么、谁产生什么心理变化”，再压成歌词。

副歌微修时要优先删掉生硬代词、重复水位和力度不匹配的动词。人体部位、关键物件和关系对象如果是情绪承载点，尽量直接写出来，不用 `它 / 这个 / 那个` 代指。重复 hook 可以保留，但第二次要有轻微变体，改变节奏、语气、功能或情绪层级。阻断、切断、夺回、压回、撕下这类动作要和人物内心挣扎匹配；如果动词听起来只是普通日常动作，无法承载副歌爆发，就不能留在高潮位。

亲密关系副歌要区分防御动作和补救动作。`护住、挡住、拦住` 适合危险发生前的保护；`抱紧、搂住、捧住、扶住` 更适合事后愧疚、安抚和靠近。动作对象必须自然：抱住人、抱紧肩膀、搂住身体、捧住脸通常成立；“抱住脸”容易物理别扭。看见对方眼泪以后，动作通常要从防御转向安抚，情绪才会更浓。

副歌里跨时间的伤害要先转译，不能直接搬运。过去发生过的动作、伤害、旧声、旧称呼或旧物件，如果要进入现在副歌，必须变成当前的身体反应、模仿动作、声音复发、影子、习惯或“我差点正在做出的这一动作”。否则过去动作和现在动作会在一句里物理打架。首尾 hook 重复也要检查功能差异：第一次让动作发生或停住，最后一次让人物完成命名、决心、代价或意义加重；如果没有意义加重，就做变体。

副歌动作链必须先分功能，再选动词。动词递进不是把同一个动作写成 `放下 / 压下 / 截下 / 按住 / 拦下` 的近义词清单。每个动作要分别承担清楚功能：对内克制自己、对外保护对方、对过去切断来源、对未来立誓收束。若所有动作都在写“我没有打下去”，听众会觉得原地绕圈；若一行同时写保护对方和压住自己，动作边界会糊。功能分层清楚以后，动词少一点反而更有力。

合格副歌核心句至少命中一项：

- 反差：同一场景里两种命运、两种动作、两种身份互相撞上。
- 反转：听众以为是 A，副歌唱出其实是 B，例如“他们以为考完就放假，我从那天开始没夏天”。
- 损失：明确说出人物少掉了什么、来不及什么、被什么提前叫走。
- 宣言：目标听众能拿这句替自己说话，而不是只点头觉得对。
- 动作钉：用一个强动词或强名词把情绪钉住，例如“攥到发烫”“叫我走”“分成两半”。

硬门：

- 副歌候选不能只靠画面白描通过。画面必须服务一句高密度态度或认知转折。
- 句子不通顺、不像真实人会唱，哪怕概念狠、韵脚稳，也直接淘汰。
- 如果一句副歌离开上下文后不能单独站住，不能成为评论区、封面大字、短视频字幕或现场合唱入口，判为传播锚点不足。
- 可分享不是孤立金句。句子离开上下文后可以被转发，但仍要保留最小主题锚点、人物关系和自然句法。为了分享而删掉爱情、分手、哀求、回头、偏爱、沉默、放不下等主题信息，会变成“看似高级但不知道说什么”的伪金句。
- “有人……有人……”结构只能作为对比工具，不能连续堆成流水账；必须在最后落到一句反差判断或情绪宣言。
- 金句化不等于口号化。副歌可以狠，但必须像一个人唱出来的话，不能像标题党、作文总结或分析报告。

### 2.0.1.1 副歌声音中心与矛盾电压

副歌不是主题总结，而是声音中心。它要把主歌和预副歌积累出的压力，压成一组能被唱、被记、被听众拿走的短语系统。判断副歌候选时，不先问“意思对不对”，而先问：

```text
这句像歌词吗？
它有没有声音回路？
它的大词有没有收束？
它的小动作有没有扎到关系？
它有没有让听众单独拿走的现实用途？
```

副歌的有效金句通常来自“刀词 + 矛盾电压”，不是来自关系标签，也不是来自堆狠词。刀口不是因为句子加入了“关系判断”才成立，而是因为某些词、短语、动词或名词本身有击穿力，能快速命名一种让听众破防的心理状态；关系判断只是把这个词落到具体伤口上。

有效刀词通常具备：

```text
短：第一耳能抓住，不需要解释。
准：能命名一种痛感、羞耻、低姿态、亏欠、替代、误判或认账。
狠：不是大喊，而是让听众觉得“这说的就是我”。
熟：有公共认知基础，或者由熟悉短语重新加工而来。
能唱：尾音、重音、气口能进入旋律。
```

强传播副歌里的刀词要优先从“人类状态词”和“关系代价词”里找，而不是只从关系标签里找。对标成熟流行苦情副歌，常见有效词感包括：

```text
羞耻词：笑柄、乞讨、下跪、奢求、卑微、资格。
耗损词：耗尽、稀碎、凌迟、酷刑、烂命、氧气。
身份词：替身、备选、陌生人、甲乙丙丁、过客。
审判词：凭什么、难道、就承认、别把、别用、活该。
关系代价词：炫耀、证据、怜悯、恩赐、消遣、圈套。
```

这些词只是爱情失败类样本，不是通用词库。积极、亲情、成长、校园题材也需要好词，只是情绪颜色不同：赤诚、坦荡、通透、热烈、有骨、回甘、松弛、清醒、开阔、笃定、欲说还休、痛而不嚎、言浅情深等都可能成为好词方向。判断标准不是“负面还是正面”，而是它是否有情绪颜色、概括力、公共语感、个人取舍、关系落点和声音价值。

这些词不能机械堆砌。它们之所以有效，是因为背后有听众熟悉的人类状态：先爱的人放低姿态，真心被拿去讨好别人，回忆被对方消费，尊严被换成怜悯，身份从爱人坍塌成备选；或者一个人把输赢放下仍然热烈，把伤口带着仍然清醒，把普通日子唱得有回甘。好的副歌不是“用了狠词”，而是让词落在清楚的人物处境和情绪取舍上。

好词还要放在正确情绪时态里。第一次副歌通常更需要“当场爆发”：反问、控诉、低姿态、还在求、还在疼、还在失控。Bridge、Final Chorus 或二次变体更适合“事后总结”：看清、放下、难堪、污点、懂事、和解。若把第一次副歌过早写成漂亮总结，会失去冲出来的情绪。

强传播苦情副歌的变体幅度可以偏高。C2 / Final Chorus 不必只做轻微换词，后段可以把低姿态动作升级成尊严代价、关系判决或身体后果。但高变体不是乱写新句：主 hook、主韵、关系骨架要保住，新增内容必须来自前面已经成立的情绪，而不是突然补剧情或发明陌生词义。`把尊严递给你看` 这类方向能成立，是因为它把跪着求留升级成尊严被交出去；`碎到不敢还` 不成立，因为“不敢还”没有清楚对象和公共表达基础。

Final Chorus 的高变体要按缺口选择加重方式，不能把某一种升级绝对化。可选方向包括：动作升级成尊严代价、身份升级、关系判决升级、身体后果落地、Bridge 视角回收、尾句追加、声场扩大，或把转述判词升级成对方原话。`你却把我的挽留说成纠缠` 升级成 `你一句别再纠缠...` 只适合前文确实建立了“对方一句话如何伤我”的歌曲；如果核心痛点不是话语伤害，硬往“原话砸下”靠会错配。所有加重都必须保留主 hook、主韵和关系骨架，新增重量来自已成立情绪，不能临时补新剧情或硬造怪搭配。

强传播苦情副歌的核心不是“伤心描述”，而是“关系刺点”。好词要刺到一个具体的不公平：我求你别走，你嫌我纠缠；我哭到失态，你说我活该；我把回忆当命，你拿它哄别人；我还在认错，你已经把我判出局。没有这个刺点，词再顺也只是无病呻吟。判断时不要问“这句是不是悲伤”，要问“这句让人想哭的具体原因是什么”。

副歌刀口要能被旋律切开。很多高传播副歌不是靠长句一次讲完，而是靠短词组连续推进：认知、判断、痛点、判词一拍一拍落下。`我明白 爱一旦泛滥 就逃不开 心被肆意破坏` 这类写法的价值在于，空格标出的每个小段都有停顿和重音，听众能跟着唱，也能截出其中一段传播。长句如果没有切分，容易像小作文，即使内容很痛，也不容易形成副歌。但切分必须服从自然句法：去掉空格后是一句顺口的话，加上空格后更好唱；如果去掉空格就不通顺，说明底层句子没成立。

切分还要服从主韵。副歌整段句尾优先同一完美韵，句内气口尾音尽量靠近主韵或同一韵族。空格不是只标意思，也是标发声位置；如果每个小段尾音都跳到不同口腔位置，旋律会很难顺下去。先定主韵，再检查每行末尾和每个气口尾音是否服务这个主韵。

主韵不是格子。副歌情绪抒发需要松紧变化，不能为了完美韵把四句写成完全同字数、同停顿、同语法模板。完美韵只负责让声音回环，不能允许生造词、硬搭配或听众第一耳不懂的短句。`回还、半句不看` 这类词如果需要解释才懂，就算押韵也不能用；应换成真实存在、公共认知明确、唱出来顺的说法。

留白和难懂不是一回事。副歌核心句可以让听众第一遍感觉有余味，但第二遍必须能明白基本意思；如果想两三遍还不知道短句在说什么，就是表达失败。高传播副歌尤其不能依赖谜语式压缩，因为听众没有义务替作者补逻辑。

副歌词语还要有承受感。这里的“第一人称承受感”不是语法人称，不等于必须写“我”。它指听众的位置：听到这句时，他能不能把它带回自己身上，感觉这唱的是我。第一人称、第二人称、第三人称、集体视角都可以成立；失败的是旁观者判断。`孤单、纠缠、审判` 这类抽象状态词如果没有动作和声口支撑，容易变成作者看见一个人很孤单，而不是让听众自己感到孤单。好的副歌词要能被听众内部化：它应当来自喉咙、眼泪、手、沉默、回头和请求这类身体与关系压力，而不是像分析者贴上的标签。

副歌的词和词之间必须有逻辑桥。刁钻不是硬接，双关不是作者脑内补完。若一个词想承担两层意思，至少要有公共用法、前文授权或句内动作桥。`分手还寒` 这种搭配没有天然关系；`沉默推翻从前` 也把状态词强行接到大动作上。正确方向是把中间关系写出来：他没有解释、没有挽留、没有回头，所以从前像被否认；他把狠心说得体面，所以比争吵更伤。

比较句必须有维度。`比 X 还 Y` 不是万能加重器，X 和 Y 之间要有同一条可感的比较线。`比分开还难` 如果没有说明是更没体面、更难收场、更难死心还是更像被嫌弃，就只是空话；`比狠心还寒` 如果没有动作托住，也只是情绪形容词叠加。副歌可以用比较句，但必须让听众第一耳知道它在比什么。

副歌核心句不是心理说明。强传播副歌要让情绪发泄出来，而不是把人物痛苦解释清楚。`我明白、我知道、像在、说穿、负担、为难` 这类词如果没有强动作托住，很容易变成作者站在外面做总结。副歌爆发位要更像当事人直接开口：质问、求留、否认、反击、自责、崩溃。能被解释通不等于能唱；能唱的人必须像正在经历，而不是像在讲解经历。

强审判副歌不能写成绕口逻辑句。强度越高，越不能靠“不是 A 而是 B”这类脑内反转证明自己聪明。`我求你 不是求你 把我看穿` 的问题不是单个词生僻，而是动作关系不成立：分手求留现场里，“求你”天然指向回头、留下、心软、别嫌烦、别把我当纠缠；“看穿”通常指伪装、演戏、识破，除非前文已经建立这个主题，否则它接不上求留动作。强审判要用第一耳成立的动作和判词，比如“我求你回头一眼，你都嫌烦”“我哭到失态，你说我活该”。质问越狠，句法越要直，动作越要清楚。

副歌判词不能让单字超载。单字可以锋利，但前提是公共语感足够稳定，且只承担一个清楚的情绪任务。`我求你 回头一眼 都算贪` 里的 `贪` 同时想表达“我要求太多”“你把我判成贪心”“我低姿态仍被嫌弃”，还要兼顾 an 韵；一个字承载太多，听众第一耳会觉得不明不白。若某个单字需要解释两三层意思才成立，要换成明确词组，或用动作 + 判词写清楚，比如“你都嫌烦”“你说我纠缠”“你嫌我难看”。押韵不能牺牲判词的情绪厚度。

求留句也不能被单字押韵压坏。`别散` 在日常语感里更接近“别散场、别散伙、别走散、别散掉”，不是分手求留里最清楚的第一选择。若作者真正想唱的是“别走、别分开、别不要我、别说再见、别把我丢下”，就不要压成一个 `散` 字让听众补。副歌可以省字，但不能省掉关系动作；如果一个字同时承担求留、分手、结束关系和押韵，它就是压缩超载。

成熟词组可以替代含混单字，但必须沿着原句关系升级。好副歌不一定要发明新词，很多时候是把听众已经懂的词放进新的关系位置。`委曲求全` 放在求留副歌里，价值不在于它是成语，而在于它天然包含“委屈自己、放低姿态、牺牲体面、还想保住关系”；接在 `我喊到破音` 后面，再落到 `你说我纠缠`，就形成“动作证据 → 低姿态压缩 → 对方判词”。这类熟语要服务人物和唱感，不能空降成文化感。

但成熟词组也不能只按意思硬塞。副歌选词要过三关：语义成熟、情绪适配、声学连贯。语义成熟是这个词组本来就有这个意思，不靠作者强行赋义；情绪适配是它的颜色贴当前人物和场景，不是只满足“低姿态 / 刀口 / 押韵”标签；声学连贯是它和前后词的口型、气口、重音、尾音能顺着唱。`委曲求全` 比 `别散` 语义更稳，但如果整句听起来像“动作 + 成语 + 判词”的硬拼，还要继续重排，不算最终合格。

大众副歌不要轻易给单字创造新含义。听众可以接受熟悉词的新关系位置，但很难接受作者临时发明一个字的新用法。除非新搭配第一耳就自然、准确、有美感，否则要回到已有公共认知里的词组和短语。歌词里的新鲜感优先来自组合方式，而不是强迫听众学习新词义。

副歌判词最好由前面的动作或状态托住。好判词不是孤零零的形容词，而是前一句或前半句已经把画面、身体、关系和尊严损耗铺出来，最后一个词负责收束。`哭到失态` 能托住 `难看`，因为听众会自然联想到妆花了、声音乱了、姿态垮了、情绪失控了、尊严掉下来了；所以 `难看` 不只是外貌丑，也包括行为难堪、情绪难堪和关系里的低姿态。正确做法是先给可感动作，再落关系判词；错误做法是直接写 `我好难看 / 我很难堪 / 我太卑微`，那只是说明情绪，没有让听众看见情绪发生。

求留类轻动作不能省掉关键动词。`回头一眼` 为了压字数省掉了 `看 / 望 / 瞥`，第一耳会变成不完整短语：回头以后到底做什么不清楚。副歌可以省字，但不能省掉动作骨架。若要表达“我低到只求你给一个很轻的回应”，可以写 `回头看一眼`；若要带一点冷淡和轻蔑，可以写 `回头瞥一眼`，但要确认唱感和人物姿态是否自然。轻动作越小，动词越要准，因为它决定这句是哀求、轻蔑、敷衍还是最后一点心软。

副歌生僻字 / 硬口字容忍度默认 B 往 C 靠：能不用难认、少见、硬口、难唱的字就不用，除非这个字不可替代地表现情绪。低容忍不是退回最普通词，而是在公共可识别范围里找带情绪的精准动词 / 名词。`看、望、瞥、盯、躲` 都是“看”的相关动作，但情绪姿态不同；选词要根据人物关系和唱感决定。副歌高潮位的字必须第一耳不反感、能唱、能跟、能被听众立刻接住。

留白必须有方向。副歌可以省略细节，但不能省掉听众进入情绪所需的对象、动作和关系指向。若一句只靠作者脑内逻辑成立，普通听众第一耳不知道在说什么，就不是留白，是说不清。

副歌和预副歌的情绪功能不能混用。预副歌是憋住、靠近、发抖、快要问出口；副歌是开口、质问、求留、控诉、认输或崩溃。强传播副歌如果仍在写“我忍着、我不敢、我舍不得喊”，它就还没有进入副歌。副歌可以有脆弱，但脆弱也要唱出来，不是继续压回去。

副歌必须有情绪主线。情绪不是冷静推理，但听众理解情绪需要一条线。求留、副控诉、自责、不甘、告别可以组合，但不能相互拆台。若前面是控诉，后面突然变成克制不敢喊；前面是低姿态求留，后面突然像道德审判，都要检查是否姿态混乱。

副歌情绪姿态必须跟题材、人物处境和表达类型绑定。问卷里的 A/B/C 不是全项目永久偏好，而是当前母题下的选择样本。比如“分手后女方还在求留、男方狠心”的强传播情歌，默认更适合 `求留 + 控诉`，再借少量强审判词增强刀口；如果写亲情遗憾，可能更适合认账和亏欠；如果写校园暗恋，可能更适合克制、自嘲和没资格；如果写摇滚宣言，才更适合反抗和强判词。不要为了显得特立独行，把题材不支持的姿态硬塞进副歌。

句式武器必须服务主姿态。反问、禁止、审判、自嘲、求救、告别、亏欠控诉、宣言都不是孤立技巧，而是决定这段副歌怎么出刀。当前分手求留型副歌默认 B 靠 C：求留 + 控诉为主，借反问、禁止、审判增强刀口；太多求救会软，太多审判会硬。更稳的四句分工是：反问打开不公平，求留暴露低姿态，禁止 / 审判定义伤害，尾句落身体后果或关系判词。换题材时要重选武器：亲情可认账 / 亏欠，校园暗恋可自嘲 / 没资格，摇滚宣言可反抗 / 宣言。

亲情片尾主题曲的副歌边界是 B 靠 C。B 是默认骨架：克制、具体、亏欠、迟来的懂；C 是题材允许时借用的强情绪。若主题是离世、永别、来不及、终身亏欠，副歌可以更痛、更直、更接近哭出来；若主题是家常温暖、成长回望、轻治愈，过度 C 会显得煽情、卖惨或姿态错配。判断重点不是“亲情能不能强情绪”，而是这首歌的事件和人物是否承受得住强情绪。

同一副歌可以借用邻近姿态的好词，但不能换掉主姿态。当前母题里，B 的 `求留 + 控诉` 是主姿态，C 的 `麻烦` 可以借用，因为它比 `嫌烦` 更像对方把“我”当成负担，词组更完整、唱感更顺；但不能因此把整段改成纯反击 / 审判，否则会丢掉“还舍不得、还在求”的拉扯感。选择词时要问：这个词是在增强主姿态，还是把人物推到另一个姿态？

副歌表达有三种常见类型：

```text
主流型：直白内核 + 轻量意象 / 暗喻。情绪直接，1-2 个轻意象增强画面和记忆点。适合主流情歌、全民传唱、强传播苦情。
情绪核弹型：纯直白、口语化、当面拉扯。适合极致崩溃、呐喊、短视频爆发，但后劲可能弱。
文学型：重度借景 / 暗喻。适合慢歌、氛围歌、国风、深度抒情，传唱门槛更高。
```

当前项目默认不机械追求纯直白。若没有特殊流派要求，副歌优先走主流型：直白情绪做骨架，轻量意象做包装。轻意象不是堆景，它必须贴着关系刺点；重意象不能把情绪藏没。

直白不等于未经加工的大白话。副歌可以直接说痛、说求留、说控诉，但仍然要把心理说明翻译成动作、关系判词和可唱句法。`我不是不懂分手 / 只是放不下 / 你一句不爱了` 这类句子意思清楚，却容易像普通口头解释，缺少歌词里的动作压力、关系刺点和声音锤击。正确方向是让直白情绪落到“谁把我怎样看待 / 谁把我的动作说成什么 / 哪一句话让我身体怎样反应”。

含蓄也不能牺牲普通话关系。`风把眼泪吹得很乱` 里 `得 / 很` 增加了口语垫片，却没有增加情绪；`门口的晚` 试图用意象制造余味，但“晚”没有清楚物性和动作关系，听众会问是晚上、晚风还是门口的碗。含蓄型副歌可以用风、门、夜、眼泪等轻意象，但必须第一耳知道谁在做什么、什么被改变、情绪落在哪里。若意象需要解释才懂，就是伪含蓄。

矛盾电压指这些刀词所在的句子里，至少有一个清楚的冲突、转折、反差或判决：

```text
这个关系变了。
这个身份塌了。
这个表面说法是假的。
这个人嘴上体面，实际受了亏。
这个动作很轻，后果却很重。
这个地方还在，人已经回不去了。
```

可用机制：

```text
轻重反差：对方很轻，主唱很重。有效写法不是机械对称，而是让听众听见不公平：你的一句 / 我的多年，你的无意 / 我的半生，你半句判词 / 我身体发颤。当前求留控诉型副歌默认中强度，一段保留 1 个核心轻重爆点即可；太弱会少传播刺点，太满会像技巧展示。轻重反差最好落在尾句或 hook 位，前文用动作和关系证据托住，比如先写失态、嫌弃、低姿态，再让 `你一句...` 把后果砸下来。
身份坍塌：让听众听见“我在你这里的位置塌了”。有效写法不是孤立贴 `陌生人、备选、替身、过期身份` 这类标签，而是让身份变化落在公共语感和当下动作里：从被偏爱的人，变成麻烦、纠缠、难堪、可有可无。当前求留控诉型副歌默认中高强度，可写到 `你给过偏爱 又嫌我太麻烦` 这种程度；更直白的 `从你的偏爱 变成你的麻烦` 虽然身份坍塌更清楚，但容易变成概念总结，必须谨慎使用。
抵达失败：我已经发出去了，但对方那里接不住。可写眼泪、声音、想念、名字、消息、道歉、祝福到不了对方那里。强度不按题材硬分，而按核心痛点决定：如果这首歌最痛的是“对方如何定义我 / 我如何失去身份 / 我如何被判成纠缠”，抵达失败只能低强度点缀或不用；如果最痛的是“说了也到不了 / 发了也收不到 / 想见也见不到”，抵达失败可中高强度甚至做副歌主机制。异地失联、暗恋不敢说、阴阳两隔、亲情来不及等只是常见场景例子，不是限制边界。合格写法要有具体阻隔物，如未回的消息、拨不通的电话、寄不到的信、说不出口的名字；泛写 `想念到不了你身边` 容易模板化。
大词漏斗：以后、人海、命运、半生等大词必须落到小动作或关系判决里。
公共短语加工：一心一意、来日方长、可有可无、两不相干等熟悉词，要被放进新的关系角度。熟语 / 成语不是文采装饰，而是公共认知压缩包；副歌可以偏高密度使用，只要每个熟语都在压缩情绪、制造关系反转或形成声音记忆。比如 `一心一意` 接 `可有可无`，不是堆词，而是把“真心付出被轻贱”压成公共关系痛点。高密度熟语必须有动词和判词串联，如熬成、换成、说成、走成、判成；禁忌不是熟语多，而是空堆、硬插、书面腔和没有句义递进。
```

矛盾电压必须有公共语感托底。它不是把两个相反方向硬拼在一起，而是让听众听懂一条关系链：你先做了 A，才让我变成 B；你现在又拿 B 来怪我。`偏爱` 这类词能进入副歌，是因为它本身就带有被特别对待、被选择、后来又被收回的情绪基础；但 `散` 这种单字如果单独承担分手、别走、别不要我、关系结束和放不下，就会变成押韵硬凑。强矛盾句宁可重排韵脚，也不能让听众替作者学习一个陌生用法。

矛盾电压还要看句间递进。同一个动作功能不能连续重复，只换修饰词不算升级。`跪着挽留` 比 `拼命挽留` 更有身体姿态和羞耻感，但如果两句同时出现，后一句就没有新伤口。四句副歌更稳的分工是：我的失态、你的嫌弃、我的低姿态、你的判词或身体后果。强画面动作用一次就够，后面要转向关系判断、对方回应、身份变化或尾句落刀。

副歌重复策略默认追求“中重复”：有回环、有记忆，但不机械。核心对象、核心判词、核心动作可以在关键句重复，让听众听见控诉对象和情绪重心。例如第二句补一个 `你`，能让前两句形成对象回环；但 `你凭什么` 连续四句如果没有新代价，只会变成单调口号。高重复适合宣言型、摇滚型、极强控诉型副歌，但每一句都必须推进新的伤口、身份或代价；否则应降回关键词回环或句式变体。

强传播不是强苦情的同义词。传播学意义上的分享动机可以来自高唤醒负情绪，也可以来自高唤醒正情绪、幽默、有趣、身份认领、社交货币、实用价值、故事反转和公共记忆。强传播副歌要先判断听众为什么愿意转发这句：是替自己控诉，还是表达热血、好笑、清醒、骄傲、治愈、边界、立场或共同记忆。苦情、被替代、三角关系只是其中一种强传播路径，不能把它升级成所有副歌的默认传播模型。

副歌动作强度要看人物尊严位置如何变化，而不是只看动作够不够低、够不够惨。负面方向可以让人物尊严被压低、受损、崩塌，例如求留被说成纠缠、真心被嫌麻烦、低头被当成活该；正向方向也可以让人物尊严被抬高、托举、守住、找回，例如被看见、被珍视、并肩站起、把对方捧到重要位置、把自己从低谷里认回来。真正的强副歌不是固定写 `跪、哭、求`，而是让听众听见：这个动作改变了人物在关系、自我或群体里的位置。

正向副歌的 hook 可以更口号化。励志、热血、青春、体育、群像、庆典、主题曲类副歌，常见核心不是复杂伤口，而是一个可合唱的信念句：我相信、我们一起、向前走、明天会来、世界等我、把梦唱亮、站上舞台、青春不散。这里的大词不是伪高级，而是公共动员词，目标是让听众立刻拿去给自己打气或和别人一起唱。Verse / Pre 可以写挫折、跌倒、伤口和来时路；Chorus 要把这些压力翻成上扬的信念、身份、方向和群体能量。判断标准：这句能不能被一群人一起唱出来？能不能成为打气句、毕业句、比赛句、出发句或自我鼓励句？如果不能，只是积极观点说明。

正向副歌的大词落地按条件组合，不做固定选项。若目标是合唱、庆典、体育、晚会、品牌或强旋律复唱，主 hook 可以更纯粹、更大、更短；若目标是青春、成长、群像、自我鼓励、逆袭或价值立场，要让大词带出身份认领；若目标是出发、比赛、毕业、奋斗、旅程或进行时动能，要让大词带动作方向。最常见组合是“口号负责记忆，身份 / 动作负责落地”：先给听众一句能喊出来的话，再让他知道自己是谁、要往哪里去。

正向口号要避免说教姿态。`你要勇敢、你要坚强、你要相信自己` 这类句子虽然正面，但容易像外部劝告，不像副歌里的人正在被点燃。更稳的 hook 视角是：个人励志用“我”承诺，群像热血用“我们”认领，对某个人鼓励用“我陪你 / 你不是一个人 / 你值得被看见”这类陪伴和托举，而不是连续命令。正向副歌的核心不是教别人变好，而是让唱的人先把信念唱出来，听众再跟着认领。

正向副歌要追求高唤醒，不追求轻飘开心。`阳光、微笑、美好、希望、温暖、快乐` 这类词可以作为颜色，但不能替代主 hook。更有传播力的正向 hook 通常带热血、笃定、骄傲、不服、赤诚、开阔、胜利感、出发感或归属感，并落到动作、声场、身份或方向上：往前、站上、冲、点亮、唱响、一起、世界等我、名字被喊亮。正向副歌也要爆发，只是爆发出来的是“我要去 / 我们能 / 我偏要 / 我们一起”的上扬情绪。

正向副歌可以借低谷起跳，但不能停在低谷里唱。低谷、跌倒、伤口、黑夜、没人懂、没人鼓掌，是 Verse / Pre 的主要材料；进入 Chorus 后，它们只能作为反弹板，后面必须立刻接站上去、点亮、唱响、往前、自己鼓掌、一起出发等上扬动作。正向 hook 的记忆点应该落在“我怎样站起来 / 我们怎样往前”，不是“我经历过多少黑夜”。Final Chorus 和 Outro 越靠后，越应减少负面材料，回到胜利感、出发感和正向核心口号。

“我们”不是正向副歌的万能扩大器。它必须有共同身份来源：同一段青春、同一个班级 / 操场、同一场比赛、同一个团队、同一座城市、同一个目标、一起扛过的事。写“我们”时至少回答一个身份锚和一个方向锚：我们是谁，我们为什么一起，我们要去哪。若没有这些锚，“我们”会像活动主题曲模板，听众不知道自己是否属于里面。个人自救、单人逆袭、对某个人鼓励和亲密表白，不要强行改成泛泛“我们”。

抽象词比例要按副歌类型判断。强传播撕裂型副歌，也就是当面对峙、求留、控诉、崩溃这类副歌，默认低抽象词：不用 `人海、命运、岁月、世间` 这类宏大词；`想念、温柔、以后、放下` 这类公共词最多 0-1 个，并且必须被动作、关系判词或身体反应托住。事后回望型副歌可以轻用宏大词，但不能让宏大词主导整段。

宏大词最适合的位置通常是 Bridge、Final Chorus 变体或 Outro 回收。Bridge 可以把私人关系推到更远的时间、人群和人生视角里，但仍必须让听众重新理解前面的副歌，而不是只把句子写大。不要把“Bridge 适合升维”机械理解成“Bridge 必须写人海、命运、岁月”；题材克制时，轻升维、轻反问和具体物件变形也可以成立。

Bridge 的升维必须服务 Final Chorus 回收。宏大词不是 Bridge 的目标，翻面才是目标。若 Bridge 用宏大词后，最后副歌没有任何新理解可以回收，说明这只是装饰性升维；应改成更贴人物的时间、视角、关系或态度翻面。相反，如果一个具体物件在 Bridge 里变了功能，例如从现场证据变成多年后仍无法替代的关系证据，也可以完成升维，不必强塞宏大词。

大词收束强度可以高，但大词数量仍要低。当前撕裂求留副歌如果使用一个公共词，应把它强行落到动作、身体状态、对方反应或关系判词里：`想念` 要被 `判成纠缠` 收住，`体面` 要被 `捧着 / 拆穿` 收住。高收束不是堆更多抽象词，而是让一个抽象词承担清楚的关系后果。若大词只是让句子显得开阔，没有把人物推到更疼的位置，就不要用。

具体物件比例要按副歌类型判断。当前撕裂求留副歌可以选高具体密度，但这里的高不是堆剧情道具，也不是写克制小动作，而是让爆发动作、失控后果、身体承受和少量近身证据连续压住情绪：哭到失态、妆花、跪着求、喘不上气、回头看一眼、拼命挽留、疼到发颤。它们必须直接证明一个关系判决：我已经失态、我已经低到尘埃、你还嫌我麻烦、你把我的挽留说成纠缠。`攥袖口、咽回去、忍住、低头不说` 这类动作更像预副歌蓄力，放在当前副歌会把爆发压回去。聊天框、门口、夜晚、咖啡、房间这类剧情物件更适合主歌 / 预副歌；除非它们已经是全歌主 hook，否则不要在副歌里抢情绪爆发的位置。

高风险：

```text
只有氛围：有屋檐、雨、灯、饭香，但没有关系判决。
只有关系：有被替代、亏欠、备选等判断，但没有真正让人破防的刀词。
只有技法：有反差、排比、押韵，但没有人物非唱不可的话。
只有狠词：死、命、凌迟、氧气、乞讨堆满，却没有独特关系证据。
只有解释：把心理机制讲通，但读起来像分析报告分行。
```

执行边界：

- 这些机制是工具，不是每段副歌都必须全用。每段副歌主选 1-2 个机制即可。
- 题眼阶段可以规划“副歌将使用哪种刀口和主韵方向”，但不能把机制说明句冒充正式歌词。
- 示例必须标清层级：机制示范不是成品候选；成品候选必须额外过主韵、气口、尾音和人物声口。

## 2.0.2 副歌名词动词因果硬门

副歌里的强名词、强动词不能靠“看起来有画面”成立，必须来自同一个人物、同一个时间点、同一条动作链。

失败反例：

```text
他们把书扔向天上
我把车票攥到发烫
不是青春忽然散场
是生活点名太响
```

这类写法的问题不只是普通，而是动作逻辑断裂：

- “扔书”发生在考场外或教学楼外的庆祝场景。
- “车票”属于去车站、坐车、离校后的行动链。
- 如果中间没有“我先去门卫室拿行李 / 我已经买好车票 / 我不能留下来庆祝”的叙事桥，两个动作就不是反差，而是硬剪。
- “生活点名”又从学生场景跳到抽象成人处境，人物身份变得飘：一会儿是刚考完的学生，一会儿像被生活拷打过的成年人。

硬门：

- 副歌每个名词必须回答：它在这个场景里为什么出现，谁拿着它，它和人物处境有什么关系。
- 副歌每个动词必须回答：这个动作为什么非做不可，它推动了什么情绪或关系变化。
- 两个对比动作之间必须有同一时间、同一地点、同一人物处境下的逻辑关系；不能只因为画面对称就放在一起。
- 抽象词如“生活、青春、命运、成长、自由”不能突然接管副歌。除非前文已经用具体动作把它们养出来，否则判为概念空降。
- 如果副歌读起来像几个素材拼贴，而不是一个人正在发生的事，必须退回主歌或选题阶段重建动作链。
- 反差不是 A 画面加 B 画面。反差必须是同一个人被迫在 A 和 B 之间做选择，或者同一场景里两个人的命运因为一个具体阻碍分开。

### 2.0.2.1 抽象词拟人和主客关系硬门

副歌可以有意象和多重意思，但必须先满足基本通顺和公共认知。压缩不是让一个词替作者偷懒，拟人也不是让抽象概念随便代替人行动。

高风险句：

```text
生活却先喊了我的名。
生活点名太响。
命运把我推上路。
青春把我留在原地。
```

问题不在于不能写“生活、命运、青春”，而在于这些抽象词突然成了主动施事者。现实里会点名的是老师、名单、班主任、工厂班表、车站广播、招工电话、家里的账单；生活本身不会开口喊人。除非前文已经建立了“点名”这个具体动作系统，否则这类句子会让听众只能意会，不能第一耳理解。

执行规则：

- 抽象词不能突然完成复杂动作。`生活 / 命运 / 青春 / 现实 / 夏天` 可以做背景、结果、比喻对象，但不能无依据地替人发号施令。
- 拟人必须有公共认知托底。铃声能催、名单能叫、雨能藏、门能关，是因为听众有感官经验；抽象词要行动，必须先有具体物件或制度动作托住。
- 主客关系必须清楚。优先写“我被哪件具体事叫走”“我必须对生活做什么”，而不是让“生活”主动对我做一个没有现场依据的动作。
- 如果一句话需要作者解释“生活喊名其实是家庭、账单、打工、责任三层意思”，说明压缩过度。应拆回 Verse / Pre 给证据，再在 Chorus 压成第一耳能懂的句子。

更稳的方向：

```text
他们从今天开始放假
我从今天开始没夏天

他们在校门口告别
我去车站赶明天

别人把书包扔上天
我把工牌别胸前
```

这些句子不一定就是终稿，但主客关系更清楚：谁做了什么，为什么出现这个物件，情绪代价在哪里。

### 2.0.2.2 可发生性和替换动作硬门

副歌核心句和题眼金句不能只看作者能不能解释通，还要看普通听众第一耳能不能相信这个动作真的会发生。

写句子前先把普通话关系说清楚：

```text
谁？
在什么时刻？
被什么现实拦住？
原本要做什么？
后来被什么替换？
谁动手替换？
替换以后少掉了什么？
```

然后再歌词化。普通话解释不能直接当副歌成果。

高风险句：

```text
药钱比我先出发。
账单点了我的名。
车票只到厂门口。
```

问题：

```text
药钱通常是先花掉、先压过来、先摆在眼前，不自然地“出发”。
账单可以催、压、逼人去挣钱，但不会像老师一样点名；除非前文已经建立学校点名和生活点名的隐喻链。
车票通常到车站、城市、县城、镇上，不是到厂门口；除非前文写明厂车、门岗或班车。
```

更稳的处理不是硬解释，而是重建动作链：

```text
他们在群里问谁带相机
我把工服塞进行李
那张毕业旅行的路线图
被我压在准考证底
```

这组句子的优势不是更复杂，而是有替换动作：原本该装旅行和同学，后来装进工服；人物亲手把路线图压下去，愿望被现实替换。

硬门：

- 动词必须能落到对象身上。能解释通但不能发生，判为修辞压弯关系。
- 对比不能只摆两个物件，必须写出替换动作：原本该有什么，后来被什么换掉。
- 转折不能只靠“可是 / 但 / 却”。后半句必须写出现实如何拦住、替换、取消或夺走前半句。
- 如果一句话需要三层作者注释才能懂，先拆回 Verse / Pre 给证据，再让 Chorus 压缩。
- 副歌候选必须同时过“关系通顺”和“声音可唱”两道门；只过任意一道都不能定为核心句。

### 2.0.2.3 物件经济和副歌层级硬门

副歌核心句不是物件清单。物件多不等于画面强，具体不等于有情绪。

每个进入题眼和副歌核心句的物件，都必须有：

```text
动作：谁对它做了什么。
关系：它和人物、家庭、同学、过去或未来有什么关系。
代价：它让人物少掉什么、换掉什么、忍住什么。
情绪功能：它能否替人物说出一句不好意思说的话。
```

如果一个候选同时塞进相机、工服、行李、准考证、铅笔、车票、试卷袋、药盒、学费，却没有动作链，就是道具堆叠。必须删到只剩 1-3 个最能推动情绪的物件。

高风险：

```text
准考证还留着铅笔。
车票夹进试卷袋里。
```

问题：

```text
准考证不会留着铅笔，物件关系不自然。
高考试卷通常不能带走，试卷袋容易让场景失真。
```

更稳：

```text
准考证被汗泡软。
车票压在兜底。
工服塞进行李。
群消息一直亮着。
```

副歌候选必须先在内部分清层级；对外不要机械标注，但要让老胡从文本形态、位置、完成度和唱感上一眼看出它是解释、草稿还是歌词化结果。以下名称只供内部检查和归档使用：

```text
普通话底稿：逻辑清楚，但不是歌词。
歌词化一稿：有可唱句形，但还要修韵脚和弱虚尾。
可唱优化稿：有主韵、句尾实字和基本唱感。
副歌核心句候选：能唱、能记，能被听众拿去表达自己。
```

普通话底稿不能直接作为副歌核心句确认。

## 2.0.3 克制表达与浓烈情绪

克制不是把情绪写淡、写绕、写害羞，而是不用喊叫也能让听众感到刺痛。

副歌必须找到人物真正不敢说的那句痛话，并把它压成可传播句。如果只是“我也想、可是我得、别等我”这类礼貌退让，情绪仍停在解释层，没有进入爆发层。

合格副歌可以隐晦，但听众感受到的不能是隐晦，而必须是浓度、损失和刺。

硬门：

- 副歌要检查人物最想说但不好意思说出口的那句话是什么。
- 克制表达不能削弱损失感；如果听众只感到懂事、礼貌、退让，而没有刺痛，判为浓度不足。
- 传播句必须让目标听众有“这句可以替我说”的冲动，而不只是觉得作者写得对。
- 刀口不能靠大词和哭喊，必须靠具体损失、关系资格、不可逆转或身份变化。

## 2.0.4 压缩句和解释句的边界

高密度题眼、副歌核心句、传播句和金句，不是把很多意思硬塞进一个词，也不是让听众替作者补逻辑。它们的正确位置是：先把关系讲清楚，再把关系压成一句可记、可唱、可传播的话。

执行原则：

```text
先搭关系
→ 再找共同动作
→ 再做物性转移
→ 最后压成题眼句 / 副歌核心句 / 传播句
```

说明句负责让人懂，歌词压缩句负责让人记。二者不能混用：

```text
说明句：
写作还要再往前走一步：别只把经历倒出来，要让读者听得懂、感受得到，还能从里面拿走一点有用的东西。

压缩句：
这才叫被读者接住。
```

这类文章调试句不能原样当歌词规则，但能映射成歌词要求：如果副歌核心句压了很多意思，Verse / Pre 必须先给关系证据；否则听众不知道它唱的是情绪、处境还是判断。先用主歌和预副歌托住，再用副歌压缩，它才成立。

强压缩句的生成方式：

```text
A 是一种情绪 / 问题 / 阻力。
B 是一种工具 / 动作 / 入口。
找到 A 和 B 之间真实可感的共同动作。
让 A 变成 B，或让 B 作用于 A。
用一句话完成关系转移。
```

示例：

```text
关系拆解：
焦虑会抓住人的注意力。
钥匙可以打开锁。
注意力像一扇需要被打开的门。
“拧”同时属于焦虑的拧巴感和钥匙的开锁动作。

压缩句：
把读者的焦虑拧成钥匙，打开注意力的锁。
```

这个句子之所以能作为概念句或歌词化句子成立，是因为它没有只让一个词承担所有意思，而是让 `焦虑 / 钥匙 / 注意力 / 锁 / 拧 / 打开` 形成一条可感的关系链。迁移到歌词时，还必须继续检查句长、气口、尾音和可唱性。

硬门：

- 一个词如果同时想表达“理解、共情、承接价值、行动建议”等多层意思，必须先有前文托底；否则不要直接压缩。
- 压缩句可以玄，但关系不能断。读者可以觉得有余味，不能不知道发生了什么。
- Verse / Pre 的说明和证据必须清楚，题眼句 / 副歌核心句可以更凝练、更锋利、更像歌词。
- 好金句不是省略逻辑，而是让逻辑变成画面和动作。
- 如果一句话只有作者知道它在压什么，判为内部黑话，不是金句。

### 2.0.4.1 金句构成关系审计

金句不是短句、对仗、反差和“不是 A，而是 B”的句式游戏。句式只是外壳，关系才是骨架。

金句至少要压住一种清楚关系：

```text
对立关系：不是 A，而是 B；但 A 和 B 必须同层、同类或同一问题的两种解释。
动作关系：谁对什么做了什么，动作能带出意义。
因果关系：因为 A，所以 B；或 A 才能打开 B。
比喻关系：本体和喻体有共同动作、共同结构或共同情绪。
判断关系：一句话能把前面一段内容钉住，而不是只显得漂亮。
```

失败类型：

```text
有句式，没有关系。
有对仗，没有自然搭配。
有短词，没有公共认知。
有比喻，没有共同动作。
有玄感，没有解压路径。
```

反例：

```text
不是思想深，是词堆厚。
```

问题：

```text
“思想深”是自然说法，“词堆厚”不是自然说法。
“深”和“厚”只有形式对仗，没有清楚关系。
读者不知道“词堆厚”到底指词多、术语多、概念堆叠、表达臃肿，还是故意装深。
这句话把多层意思压成三个字，但三个字没有公共认知托住。
```

更稳的方向：

```text
他不是把问题讲深了，是把读者讲晕了。
```

判断：

```text
“讲深”和“讲晕”都属于表达效果，同层对比。
读者能立刻明白：问题没有变深，是表达把人绕晕。
虽然不如强比喻华丽，但关系清楚。
```

再如：

```text
修辞不是花，是借来的力。
```

问题：

```text
“花”容易被读成花朵，不一定自然等于花哨。
“力”太空，不知道是力量、说服力、理解力、传播力还是情绪力。
花和力不是天然同层，也缺少共同动作。
```

更稳的方向：

```text
修辞不是花哨，是借力。
```

判断：

```text
“花哨”直接指装饰性。
“借力”直接指修辞真正功能：借读者已有认知、感官经验和情绪共识来增强表达。
第一遍能懂，第二遍能品出方法论。
```

生成金句前必须先写关系草稿：

```text
我想反对的 A 是什么？
我真正要立住的 B 是什么？
A 和 B 是否同一层级？
有没有自然词组或生活关系托住？
有没有共同动作或共同结构？
陌生读者第一遍能不能知道我在说什么，第二遍能不能觉得有余味？
```

没有通过这六问，不允许只靠短句、对仗、排比或“不是……而是……”结构冒充金句。

## 2.1 题眼总纲的最低结构

选题题眼不是副歌核心句生成器，而是整首歌的导演稿。它必须能指导曲式、填词和演唱控制。

最低结构：

```text
明确人群：一个具体处境里的人。
已有认知定势：听众心里本来就有的担心、欲望、怨气、羞耻、误判或俗语。
借用定势：本歌借哪一种既有认知发力，而不是创造一个新认知。
给听众什么：说中他的担心，承认他的欲望，戳破他的借口，还是替他说出不敢说的话。
可被接受的缺点：人物哪个不完美能让目标听众认领，而不是被作者羞辱。
共同敌人：人物和听众共同讨厌、共同抵抗或共同甩锅的对象、机制、借口、压力或自我弱点。
表面共识 / 可借用偏见：大家都同意的安全结论是什么，里面哪一种偏见、偏心、怨气、误判或阵营感还活着。
个体宣言句：目标听众能拿来当签名、评论、配文、自嘲、自辩、示威或告别的一句话。
脑力取舍理由：为什么宁可放弃其他方向，也要集中打这一句、这一种偏见和这一类人。
痛苦敏感点：目标听众最怕失去、承认或被戳穿的东西。
损失厌恶点：如果人物继续逃避、误判或拖延，会具体失去什么、错过什么、被谁替代。
过敏反应句：一句让目标听众难受、想反驳、想转发或想认账的话。
苦难借势点：涉及困难、失败、低谷或委屈时，借用哪个真实挑战，而不是虚构假惨。
尊严保留点：人物在困难里保留的选择、动作、沉默、反击、自我要求或不肯认输。
转化落点：苦难最终走向和解、励志、认账后行动、重新站起来或重新命名自己。
卖惨风险：哪里可能因为过度渲染可怜、假痛、求同情或平台式惨钩子而失真。
故事杠杆：一个小元素如何撬动大情绪和大认知，而不是做装饰。
大脑墙：目标听众保护自己信念、价值观、自尊、借口或经验的防线。
穿墙缝隙：借哪段已有经验、俗语、羞耻、损失或关系压力进入大脑墙。
金句钉：短、准、扎心、可复述，能把题眼钉住的一句话。
共鸣网入口：这首歌会进入哪张网，被谁转发、评论、引用、合唱或当身份暗号。
利他金：这首歌给听众的真实利益，不是讨好，而是帮他命名、表达、站队、保住体面或找到同盟。
不讨好对象：这首歌明确不服务谁，哪些人听不懂或不舒服也可以接受。
选择性注意点：哪一个异质词、反常动作、刺耳句尾或关系罪证让目标听众无法滑过去。
喜剧反差适用性：本题材是否适合轻喜剧、自嘲、反讽、短视频切片或发布包装，不适合时不得强行搞笑。
狠词怂态：用最狠的词表达最怂、最怕、最没底气的态度。
言不由衷句：明知是假、夸张或嘴硬，但能暴露人物真实处境的一句话。
经典借势点：借用经典作品结构、场景、人物关系或集体记忆，而不是复制内容。
九浅一深策略：系列或短视频矩阵里，浅入口如何抓流量，深内容如何圈住铁粉。
思维出轨点：反常转弯、争议角度或意外说法如何制造注意力，并带回题眼。
故事三硬核适用性：本题材是否属于品牌故事、人物故事、事业故事、逆袭故事或强叙事选题。
对立面：人物、品牌或团队真正对抗的反派、强敌、旧秩序、偏见、市场压力、失败系统或自我阴影。
对立面强度：这个负面力量为什么足够强，如何催化人物、品牌或团队成长。
独特个性：人物、品牌、产品或团队哪种鲜明特质会让一部分人认领，也让另一部分人不舒服。
不可能讨好谁：这个个性天然会放弃哪些人，不能为了面面俱到写成墙头草。
黑暗时刻：哪一刻人物、品牌或团队像死过一回，必须靠选择、代价或重生改变自己。
涅槃转化：黑暗时刻之后，人物、品牌或团队变强在哪里，旧我死在哪里。
英雄之旅适用性：本题材是否属于第一桶金、事业转折、逆袭成长、创业失败再出发或人生阶段跃迁；不适用时不得硬套三幕。
离开之幕：人物为什么必须离开原来的城市、家庭控制、行业处境、关系规则、旧身份或旧自我。
启动之幕：人物进入未知世界后遇到哪些人、事、机会、诱惑和阻力。
要打的怪兽：资金短缺、团队不合、市场不认可、信任崩塌、能力不足、身份羞耻、自我怀疑、贪婪、傲慢或失控。
归来之幕：第一桶金或阶段成功带回的身份、资源、关系变化、代价和危险。
起点 / 深渊双岔口：成功是下一段旅程的起点，还是更大危险、傲慢、贪婪、失控或坠落的开端。
叙事入口：从哪个事件、动作或画面进入。
受众心理：一开始怎么想，后来被什么翻转，最后为什么认同。
核心关系：谁和谁之间发生了什么变化。
故事引擎：冲突、反差、转折如何推动题眼出现。
情绪债务：哪一笔没还完的情绪让副歌必须出现。
证据配额：后续歌词要调用哪些动作、物件、时间、场景和关系代价。
副歌落点：前面压出的现实阻力如何落成一句可唱、可记、可传播的话。
副歌递进：第一次、第二次、最终副歌分别改变什么意义和听感。
```

这份总纲默认写入文件内部或交接区，不直接压过候选正文。对老胡展示时，只保留能改变判断的几项：这个人是谁、在哪个场景痛、题眼是什么、副歌想唱哪句话、后续不能写偏到哪里。

如果只有副歌句、没有以上总纲，下游会失去上下文，副歌再顺也容易普通。

## 2.2 情绪落地与角度挖掘

传世歌词的起点不是“情绪很浓”，而是把私人情绪变成大众能代入、能复述、能长期携带的情绪载体。选题阶段必须先把情绪落地，再决定题眼和副歌核心句。

每个选题方向都必须拆清两层情绪：

```text
表层感受：用户嘴上说出的难过、开心、遗憾、想念、疲惫、释怀、愤怒等。
底层动因：这份情绪真正来自什么关系变化、时间落差、身份困境、损失恐惧、尊严压力或没有说出口的愿望。
```

只写表层感受，会变成空洞抒情；只写底层道理，会变成正确废话。合格题眼必须把底层动因压进一个能被看见、能被唱出、能被听众认领的角度里。

选题角度默认从 4 类切口里选择主角度：

```text
物象视角：用外物承载情绪，让物不变、人心变。适合思念、遗憾、孤独、怀旧、离别、温暖。
时间视角：用过去 / 现在 / 未来制造落差。适合成长、错过、回望、岁月、理想败给现实、旧我与新我。
反差视角：用表象和内心的冲突制造张力。适合嘴硬、故作洒脱、热闹里的孤独、笑着认输、说谎式自我保护。
身份视角：切换第一人称、第二人称或第三人称，让故事从自白、倾诉或旁观叙事中获得不同格局。
```

执行规则：

- 每首歌必须有 1 个主角度。辅助角度可以有，但只能服务主角度，不能四处跳。
- 物象可以来自日常物件、场景、自然景物、身体感受、声音、季节、年代痕迹或关系证据，但必须有情绪承载力，不能只是都市高频摆件。
- 时间视角必须形成真实落差，不是简单写“从前 / 后来”。要说清曾经失去什么、如今承认什么、未来还怕什么。
- 反差视角必须暴露人物真实处境，不能只是为了显得有梗而反着说。
- 身份视角必须决定“谁在说给谁听”。人称一旦选定，下游歌词不能随意漂移。
- 副歌核心句必须先锁情绪出口。它可以是“我对你唱”，也可以是“我对自己唱”，还可以是“我 / 我们对同类唱”，但不能一段副歌里无理由混用。明确对象关系、求留、控诉、告别、感谢、表白等场景，通常优先让“你”站住，因为关系刀口需要落到对象身上；自我醒悟、释怀、认账、后悔和创伤自愈，允许用自我独白；热血、青春群像、共同记忆、身份认领和合唱型副歌，可以用“我们”或同类视角。判断标准不是某个人称天然更好，而是听众第一耳能否知道这句话从谁的喉咙出来、朝谁打过去、最后由谁承受。
- 角度杂乱时，优先保留最能解释底层动因、最能推出副歌核心句的一个。

优质选题必须同时通过三问：

```text
10 年前有人经历，10 年后依然有人经历吗？
不同年龄、不同身份的人，能不能把自己的故事放进去？
读完这个选题，心里是否留下余味，而不是只得到一个结论？
```

如果答案是否，说明它可能只是热点、梗、私人日记、情绪宣泄或短期话题，不适合进入长期作品链路。

选题提炼公式：

```text
主角度 + 核心情绪 + 情绪载体 = 题眼方向
```

示例判断方式：

```text
不是：写遗憾。
而是：用时间落差写爱而不得的遗憾，载体是多年后仍绕不开的旧称呼。

不是：写孤独。
而是：用物象视角写异乡奔波的孤独，载体是夜路、冷风、故乡声音或无人可说的心事。
```

传世选题优先从三类命题里找：

```text
个人情感类：离别与重逢、错过与遗憾、暗恋与相守、陪伴与失去、释怀与执念、亲情、友情、自我和解。
人生成长类：年少理想与现实、奔波路上的孤独、岁月流逝、跌倒后继续前行、和自己和解、平凡生活的温柔。
人间百态 / 时代共情类：异乡打拼、市井烟火、普通人的坚守、旧时光与时代变迁、陌生人的温暖、某一代人的共同处境。
```

避坑：

- 不要只写极端情绪。嘶吼、崩溃、狂欢可以短期抓耳，但长期耐听通常来自克制、隐忍、怅然、温暖、释然和未说尽。
- 不要让私人细节封死共情。可以有具体证据，但必须能上升为公共情绪容器。
- 副歌个人化细节默认 B：保留 1 个可公共代入的近身细节，其余转成公共情绪、成熟词组和关系判词。近身细节如妆、眼泪、名字、手、门口、手机、外套，只有在能承载失态、亏欠、错过、低姿态或关系判决时才进入副歌。连续堆戒指、玄关、聊天记录等剧情证据，会把副歌写成主歌；完全没有细节又会空。
- 副歌公共化程度必须高。副歌的传播路径是：私人情绪作为钩子，把听众带进公共情绪，再让听众把这句认领成自己的经历。公共化不是抹掉人物，而是把人物的痛压成多数人能唱、能转发、能当嘴替的关系痛点。主歌负责“这是她的故事”，副歌负责“这也是我的情绪”。若副歌只服务私人故事，传播路径窄；若副歌没有私人钩子，只剩观点，也会空。
- 不要依赖网红梗、热点、平台黑话和强时效元素。若必须使用，放在发布包装或主歌局部，不要做题眼和副歌核心。
- 不要炫技。题眼语言要口语化但有意象，通俗但不白，直给但留白。
- 不要把“选题”写成观点标题。选题必须能指导主歌叙事、副歌点题、Bridge 升华和演唱控制。

## 3. 副歌核心句标准

选题阶段可以先给“方向候选句”，用于帮助老胡判断选哪个方向。方向候选句允许是语义雏形，韵脚和唱感可以暂时不完美。

但方向一旦被老胡选中，必须继续打磨“确认副歌核心句”。确认副歌核心句是进入曲式、填词和演唱控制的锁定 hook，必须达到歌词级质量。老胡只说“选这个方向”，不等于确认副歌核心句，也不等于允许进入下一阶段。

副歌核心句必须做到：

- 可唱：句长、气口、句尾能被人声承载。
- 可记：听完后能复述，不只是“感觉很美”。
- 可复述：评论区可以引用。
- 有信息密度：用较少字数装下人物、冲突、态度、故事推进或情绪代价，不能只是顺口的普通总结。
- 有文字核武器感：离开画面、封面和 MV 后，这一句仍然能单独钉住听众。
- 有画面：核心句里至少有一个能被看见、能被拍出来、能被听众立刻想象的动作、物件或场景。
- 有人物位置：知道是谁在说，或者替谁说。
- 有情绪代价：不是正确总结，不是励志口号。
- 能被声音放大：后续可以前置、停顿、重复、拖长或合唱。
- 有主韵脚：至少能说清这句副歌主押什么韵。
- 有声音钩子：读出来要顺口，有自然停顿和重复价值。

### 3.1 副歌默认结构与记忆机制

副歌是整首歌的灵魂、记忆点和情绪高潮。主歌负责讲事、铺垫、给证据；副歌负责把前面积累的情绪集中释放成听众能记住、能跟唱、能引用的一段。

流行副歌默认优先采用 4 句结构。4 句不是死板公式，而是为了符合听众的组块记忆：句数少、结构规整、信息负担低，更容易被大脑打包记住。特殊曲风可以扩展成 8 句或短句循环，但必须能说明为什么不是 4 句。

强传播副歌先锁核心四句，八句只是有新增任务时的扩展。四句应该完成情绪、关系、低姿态和判词；如果四句已经够用，不要为了显得情绪更满扩成八句。八句扩展必须带来第二层递进，例如更重的关系判断、身体后果、身份塌陷或主 hook 复唱；不能把 C2 / Final Chorus 的升级提前塞进 C1。第一次副歌应留出后续变体空间，Final Chorus 才适合把间接判词升级成对方原话、把动作升级成尊严代价或身体后果。

4 句副歌的默认功能：

```text
第 1 句：点题或抛出核心心声。
第 2 句：放大情绪，进入主韵回环。
第 3 句：补一个公共画面、动作或反差，不让副歌空喊。
第 4 句：收束为可复述、可合唱、可剪辑的尾句。
```

副歌必须先确定：

```text
核心主题词：整段副歌只打一个核心情绪或判断。
主韵辙：副歌使用哪一组韵，为什么适合当前情绪。
押韵模式：AAAA / AABA / ABAB / AA_BB 之一，或说明自定义理由。
句长范围：流行副歌单句优先 7-10 字，四句字数尽量接近；特殊曲风可放宽，但必须保留气口。
重复策略：句首重复、句尾重复、关键词重复或旋律回钩，至少有一种。
社交句：哪一句可以被当成评论、签名、短视频配文或现场合唱句。
```

相邻重复特别检查：

```text
如果副歌前两句、后两句或连续 hook 里重复同一个核心名词，必须判断它是不是有意设计的回钩。
有效重复：第二次让意义变重、身份变化、损失加深、语气更狠，或旋律上形成可预期回环。
无效重复：只是把同一个词放两遍，语义上没有推进，听感上显得绕、笨、别扭。
处理方式：把第一次换成同场景词、同韵替代词或动作句，把题眼词留给更重的一句。
```

例：

```text
弱：
他们终于等来夏天
我从今天开始没夏天

更稳：
他们终于等来假期
我从今天开始没夏天
```

原因：`夏天` 是题眼词，连续出现两次会稀释第二句的重量。第一句换成 `假期`，第二句的 `没夏天` 才更像刀口。

副歌不是继续堆剧情。副歌可以保留一个小画面或动作，但它的主要任务是把主歌的事件压成心声、态度、执念、愿望、认账或放手。若副歌仍在交代大量事实、时间、地点和前因后果，判为主副歌分工失败。

### 3.2 副歌公共语感、中心命名与唱感硬门

规则状态：稳定规则。来源：2026-06-16 老胡关于《先找门》副歌反馈。适用于所有流行副歌核心句、hook、传播句和副歌候选，不限于家暴 / 创伤题材。

人类喜欢的副歌，不是最具体、最华丽、最解释完整的副歌，而是：第一耳能唱，第二遍能记，第三遍能替自己用。它必须像一句早就存在于公共语感里的话，只是被这首歌在正确位置唱出来。

副歌核心判断顺序：

```text
自然汉语
→ 公共搭配
→ 声音可唱
→ 中心命名
→ 情绪击中
→ 可复唱 / 可使用
```

任何副歌候选不得只因概念准确、押同一韵或看起来有金句感就通过。尤其要防 AI 式“生造压缩”：为了押韵、对仗或制造锋芒，把一个本身没有公共搭配基础的字硬名词化，强行让它承载多层含义。

反例机制：

```text
我离开那间房
没离开那场慌
```

问题不在于不能写抽象词，而在于 `那场慌` 不是稳定公共搭配。`慌` 更常作为状态 / 形容出现，如“我很慌、发慌、慌了神”，不天然适合被 `一场 / 那场` 承载为核心名词。这里试图把童年恐惧、家暴空间记忆、声音触发和身体反应都压进一个字，但这个字本身没有足够共识基础，唱出来也像为押 `ang` 韵硬凑。

副歌句尾和句内切分落点必须同时满足：

```text
1. 自然：普通汉语里有这个搭配，或歌词传统 / 公共语感能接受。
2. 完整：尾词本身能承担意义，不靠作者解释三层含义。
3. 可拖：元音、鼻音或开口状态适合旋律承载。
4. 有重量：能代表关系、命名、声音、空间、罪证、愿望或情绪后果。
5. 不硬凑：不是因为押韵才被放到高潮位。
```

抽象词可以用，但要有公共经验和歌唱位置。例如：`旧伤、回响、清白、体面、亏欠、自由、原谅、沉默、家、爱、恨`。这些词不是天然高级，只有当它们在副歌里完成命名、判决、悖论、关系定性或情绪总括，并且能被唱出来时，才成立。

更稳的替换方向通常不是找更怪的词，而是找更有公共基础的词：

```text
不稳：那场慌
较稳：旧伤 / 回响 / 害怕 / 那一掌 / 那副嗓 / 肩膀 / 墙
```

但“较稳”不等于直接可用。每个词还要回到本歌物性系统检查：它是否由 Verse / Pre 授权，是否与主角处境有关，是否能落在旋律重拍和长音上。

副歌的人类感来自 6 个同时成立的条件：

```text
1. 中心命名：用一句可唱短句概括整首歌最核心的情绪悖论。
2. 公共语感：词语像人类语言里已经存在的表达，不像作者临场拼接。
3. 声音回环：尾词自然、主韵稳定、气口可承接。
4. 情绪放大：从主歌 / 预副歌的事件上升到可复唱的心声或命名。
5. 关系咬合：四句之间不是并列素材，而是一个人被推到同一句话。
6. 可使用性：听众能拿其中一句表达自己，而不是只理解剧情。
```

四句副歌的推荐推进方式：

```text
第 1 句：中心命名 / 核心矛盾。
第 2 句：加重这个矛盾，形成主韵回环。
第 3 句：引入对象、关系或一个被授权的公共意象。
第 4 句：回钩、判决、复唱句或情绪落点。
```

副歌不能只停在主歌 / 预副歌素材层。像“门声、杯底、低头、退墙”这类动作可以作为触发和证据，但副歌必须把它们压成可唱的中心命名。主歌写事件，预副歌写身体被推到临界点，副歌写这个人终于唱出来的命名、心声或判断。

乐段修辞密度必须分工：

```text
Bridge：最高修辞密度。负责全新视角、叙事翻面和主题升华，可承接复杂隐喻、象征、反问、排比和宏大词，但必须让听众重新理解副歌。
Verse：次高修辞密度。以名词、实义动词、场景、细节和轻中度修辞为主，保证故事线和关系证据清楚；可铺画面，但不能遮住叙事。
Pre-Chorus：中等修辞并逐句递减。承接主歌事实，把客观触发转成主观压力；前半可保留意象，后半逐步换成动词、身体反应和直白情绪，制造入副歌压力。
Chorus：记忆核心，默认低修辞 / 近零修辞。以直白动作、人物称谓、关系判词、成熟词组和可唱短句为主；功能性修辞只允许单点助攻，拒绝每 4 句塞 2-3 个修辞点的旧做法。
Outro / 收尾 hook：全曲最低修辞密度。负责余韵、重复戳痛点和人声收束，剔除多余修饰，只保留核心直白 hook。
```

Outro / 收尾 hook 默认执行减法回声。Final Chorus 把情绪推满以后，Outro 不再继续加剧情、加观点或加新意象，而是把全歌最该留下的东西剥到最少：副歌核心句、歌名词、半句 hook、最痛词组、关键物件、一个动作或一个断开的尾音。完整复唱只适合大合唱、热血、现场感强或强传播复唱明确的歌；残句留白适合氛围歌、遗憾歌、亲情离世和克制慢歌。判断标准不是尾声有没有更狠，而是唱完以后听众脑子里是不是只剩那一句。

执行规则：如果一句写法主要是“叙事画面 + 身体反应 + 触发声音”，优先判断它属于 Verse 或 Pre；只有当它完成了中心命名、声音回环、可复唱和情绪直给，才允许进入 Chorus。副歌不是用修辞定格题眼，而是用能唱、能记、能代入的核心句定格题眼。多重修辞叠加会让句子冗长、记忆点分散、难传唱。

示范判断方式：

```text
普通话核心：我已经离开当年的家暴环境，但身体还被旧伤和旧声音控制。

偏场景 / 更像 Verse 或 Pre：
门声一响，我先找出口。

偏文章 / 不像歌词：
安全没有说服我的身体。

更接近副歌方向：
我离开那间房 / 没离开旧伤。
我离开那间房 / 没离开回响。
```

以上示范只说明机制，不代表终稿。真正交付前还必须继续审：句长、气口、尾音、完美韵、四句推进、对象关系、是否有更好的公共词。

淘汰规则：

```text
如果一个副歌词语需要作者解释“这个字里包含了童年、空间、身体、声音、恐惧、命运”等多层意思，但它本身没有公共搭配和可唱基础，必须淘汰。
如果一个尾词只是押韵，不自然、不好唱、意义轻，不能进副歌高潮位。
如果一句副歌概念很准，但读起来像文章判断，不能直接使用，必须歌词化。
如果一句副歌画面很具体，但没有中心命名和可复唱心声，只能降级为 Verse / Pre 素材。
```

#### 乐段修辞密度与副歌归位总结

用户提供的乐段修辞资料和本轮《先找门》副歌诊断，合并成以下执行规则：

```text
Bridge：最高修辞密度。职责是翻面、升华、新视角和深层隐痛；可用偏思辨的排比、反问、象征、对比和宏大词，但不能脱离可唱性。

Verse：次高修辞密度。职责是交代人物、场景、关系证据和事件线；可用较多意象、细节描写和轻中度修辞，避免三层以上堆叠遮挡剧情。

Pre-Chorus：中等修辞并逐句递减。职责是把 Verse 的客观触发转成主观压力，让副歌变得非唱不可。前半可保留修辞，后半逐步减少隐喻和意象，转向身体反应和直白情绪。

Chorus：记忆核心，低修辞 / 近零修辞优先。职责是把前面所有叙事和情绪压成可唱、可记、可复唱的中心命名 / 心声 / 判断。默认用直白动作、人物称谓、关系判词、成熟词组和可唱短句；功能性修辞只能单点助攻。拒绝画面清单和多重修辞堆叠。

Outro / 收尾 hook：全曲最低修辞密度。负责余韵、反复、回收和烙印；文字越简单，越利于最后一遍被记住。
```

副歌素材归位判断：

```text
叙事画面 + 身体反应 + 触发声音 → 优先归 Verse / Pre。
修辞爬坡 + 逃不掉 / 跑不过 / 被声音追上 → 优先归 Pre。
中心命名 + 可复唱 hook + 公共愿望 / 判断 → 才能归 Chorus。
关系解释 / 边界说明 / 新理解 → 视情况归 Bridge 或副歌后半，但不能抢 hook。
```

以《先找门》类创伤副歌为例：

```text
Verse / Pre 素材：杯底碰桌沿、背先贴住墙、谁一抬手我先缩、别急着抱我。
Pre 爬坡素材：我跑到天亮，跑不过门响；我跑进人海，跑不出走廊。
Chorus 核心素材：门响只是门响。
```

诊断结论：如果一段副歌里同时塞入门响、杯底、墙、走廊、人海、抱我、方向等多个素材，它可能每句都有意思，但会因为中心过多而失去副歌记忆点。成熟副歌要先选主 hook，例如 `跑不过门响` 或 `门响只是门响`，再让其余句子全部服从它。不服从主 hook 的好句，也要移出副歌。

副歌修辞原则：

```text
副歌默认低修辞 / 近零修辞；如果有修辞，只能是功能性单点助攻。
副歌不是继续讲事，而是把事唱成命名。
副歌不是把 Pre 的高密度氛围修辞搬进来，而是把 Pre 推高的情绪压成一句可复唱的核心句。
副歌不是画面越多越好，也不是修辞越巧越好，而是中心命名 / 心声 / 判断能不能定格全曲。
```

#### 副歌改写操作法：先定主 hook，再让所有句子服从它

规则状态：稳定规则。来源：2026-06-16 至 2026-06-17《先找门》副歌改写复盘。适用于所有“素材有情绪但副歌不成形”的二次改写。

副歌改写不是逐字润色，而是先重新判断：这段到底要被听众记住哪一句。若一段副歌同时有创伤反应、关系解释、治愈愿望、声音触发和多个好画面，不能平均保留；必须先选主 hook，再让其他句子为它服务。

执行顺序：

```text
1. 先判断副歌主任务：唱创伤反应、关系误认、情绪宣言，还是创伤解除。
2. 从候选里选唯一主 hook：能第一耳唱、第二遍记、第三遍替自己用。
3. 清理素材：不服从主 hook 的好句，也移到 Verse / Pre / Bridge / Final Chorus。
4. 锁主声音或主意象：一段副歌优先只让一个核心声音 / 意象站上中心，例如门响；杯底、桌沿、墙角等只能做证据，不抢 hook。
5. 把关系解释歌词化：不要写“你明明只是……我却……”，优先压成对比判断，例如“不是你声音太响 / 是那间房还压在我身上”。
6. 用公共悖论开刃：把私人触发翻成公共可认领的关系命题，例如“别人给我温柔，我的身体却想逃”。
7. 审声学：句尾是否自然、可拖、有重量；主韵是否集中；强句之间是否抢主 hook。
8. 分配治愈进度：第一次副歌不要过早写成已经完全好了；“我不再……”类完成句优先留给 Final Chorus，或改成“等有天……”的愿望句。
```

《先找门》改写复盘：

```text
原素材层：
门一响 / 背贴墙 / 你叫我别慌 / 那间房 / 晚安 / 杯底碰桌 / 不再等天亮

问题：
每个素材都有意思，但同时挤在副歌里，导致门响、晚安、杯底、那间房、天亮互相抢中心。

改写选择：
主 hook 选“门响只是门响”，因为它不是继续解释害怕，而是完成创伤解除的中心命名：现在和过去终于分开。

改写逻辑：
- “找门的方向”动作不自然，改成更身体化、更可唱的“先靠墙”。
- “像小时候”是解释，删掉，让“那间房”承担旧伤空间。
- “你明明只是叫我别慌”改成“不是你声音太响 / 是那间房还压在我身上”，保留关系逻辑但去掉说明腔。
- “把晚安听成吵嚷”升级为“一听见温柔就想逃亡”，把具体错听变成公共关系悖论。
- “门响只是门响”放在后半副歌落点，成为可复唱的中心命名。
```

示例结构：

```text
门一响，我还是先靠墙
你一低声，我又退回那间房
不是你声音太响
是那间房还压在我身上

我不要一生都这样
一听见温柔就想逃亡
等有天门响只是门响
我不用再靠墙等天亮
```

以上示例是方法样本，不是固定模板。可复用的是底层操作：定主 hook、删素材、锁主声音、关系对比歌词化、公共悖论开刃、声学收束、Final Chorus 再完成治愈。

#### 副歌意象链：不是解释主题，而是让同一组意象把情绪推上去

规则状态：稳定规则。来源：2026-06-17 校园爱情副歌诊断。适用于所有副歌四句、八句副歌和末次副歌变体。

副歌不能只把主题翻译成几句顺口结论。合格副歌要先确定一个情绪动作，再选择一组同源意象围着这个动作递进。意象之间要像同一棵树上的枝，不是从不同素材库里抓来的漂亮词。

判断方法：

```text
普通解释：我愿意放手成全你。
副歌写法：天空 → 翅膀 → 飞翔 → 羽翼 → 玫瑰 → 凋谢。

普通解释：我们没在一起，所以我没有资格分手。
副歌写法：校门 / 人群 / 名字 / 回头 / 开口 / 分手资格，这些都服务“没有名分的失去”。
```

前者只是说明态度；后者让听众在连续意象里听见人物动作。副歌的情绪不是靠“我很难过 / 我很爱你 / 我放手”说出来，而是靠意象链把人物推到一句非唱不可的话。

合格副歌意象链必须满足：

```text
1. 同源：意象来自同一个情绪系统，不东跳西跳。
2. 递进：每句比上一句更靠近情绪出口，不是并列摆图。
3. 动态：意象最好带动作，如向往、飞、放手、凋谢、站回、喊、回头。
4. 公共：听众第一耳能懂，不需要作者解释私人象征。
5. 服从 hook：意象再美，也必须服务主 hook；抢中心的意象要移出副歌。
```

副歌四句可用的意象链结构：

```text
第 1 句：抛出主愿望 / 主动作 / 主矛盾。
第 2 句：给这个愿望一个身体或空间动作。
第 3 句：用一个被前文授权的核心意象加重关系。
第 4 句：落回 hook、判决或可复唱的情绪命名。
```

淘汰标准：

```text
如果四句只是“结论 1 + 结论 2 + 结论 3 + 结论 4”，即使押韵，也没有副歌资格。
如果四句都有画面，但画面之间没有同一个情绪动作推动，只是素材拼贴。
如果意象很漂亮，但删掉后题眼不受影响，说明它只是装饰。
如果每句都在解释关系，听众只能理解，不能被带着唱，必须重写。
```

副歌末句尤其不能只完成剧情交代。末句要负责回钩、判决或情绪反转，让前面三句的动作在这里落成一句能复唱的话。像“我们不是分手，却被毕业带走”意思成立，但“被毕业带走”偏叙事、偏被动，情绪咬合不够；如果本歌真正刺点是“没有资格分手，却承受了分手一样的失去”，末句应优先落在关系悖论和身体痛感上，而不是只落在毕业事件上。判断标准：末句删掉事件词以后，是否还剩一个能被听众拿去用的关系句；如果只剩剧情说明，就要重写。

### 3.3 副歌虚实与意象比例

副歌最稳的形态不是纯抽象，也不是纯写实，而是“具象意象 + 模糊表意”的中间形态。可以理解为写实为骨、抽象为魂。

```text
纯抽象风险：只剩悲伤、孤独、遗憾、自由、温柔等标签，听过就散。
纯写实风险：私人细节太满，把故事钉死，听众无法把自己代入。
通用具象意象：有画面、有公共经验、可解释空间大，最适合副歌承载共鸣。
```

副歌默认执行虚实交叉：

```text
一句写实：公共意象、动作、身体反应或声音锚点。
一句写虚：心声、执念、态度、遗憾、愿望或情绪判断。
```

公共意象不是“晚风、孤灯、明月”这几个固定词，而是任何目标听众能快速感知、没有过强私人门槛、又能承载情绪的符号。选择意象时必须检查：

- 是否服务本歌题眼，而不是随手套氛围。
- 是否与情绪调性一致，冷意象不乱配欢喜，暖意象不硬配悲痛。
- 是否有动作，动态意象优先于静态摆拍。
- 是否过度堆砌，一句里不塞多个互相抢戏的意象。
- 是否给听众留白，不把故事结局和情绪解释到死。

### 3.3 副歌传播与心理触发

副歌要能被记住，不只靠押韵，还要命中人性里的表达需求。写副歌前必须判断它主要触发哪一种心理：

```text
情绪释放：主歌压住的情绪，副歌终于唱出来。
身份代入：这句像目标听众替自己说的话。
损失厌恶：听众意识到失去、错过、白等、没说出口的代价。
认知代偿：听众现实里不敢说，借副歌替自己说。
矛盾张力：今昔、聚散、拥有和放手、嘴硬和舍不得之间有冲突。
重复满足：听到前半句能预判后半句，形成听觉闭环。
```

每段副歌至少要有一句具备社交货币属性：短、懂、准、有态度，能被转发、引用、合唱或当作关系里的嘴替。如果整段副歌只能让人觉得“好听”，却不知道拿它表达什么，判为传播弱。

副歌传播情绪是全题材硬门。题材只决定情绪颜色和句式武器，不决定副歌能不能偏叙事。苦情歌可以是控诉、刀口和低姿态；亲情歌可以是亏欠、认账和温柔有骨；积极歌可以是热烈、笃定和身份认领；幽默歌可以是反差、荒诞和自嘲。但它们都必须提供嘴替价值，让听众把这句认成自己的心声。若副歌主要继续讲故事、补事实、交代时间地点和前因后果，应移回 Verse / Pre；副歌要做的是把这些故事压成公共情绪、关系判断、态度宣言或可复唱 hook。

克制题材不等于克制副歌。若一首歌的关系本身更委婉，例如暗恋、亲情、治愈、贴耳 R&B 或国风离别，副歌可以选择更贴身份的词、动作和声口，但仍然要让情绪在副歌爆开。这里的爆开不是必须喊、骂、控诉，而是终于把主歌压住的心声唱出来：正在暗恋的人唱没资格和说不出口，过来人唱后来才懂和来不及，亲情唱亏欠和回不去，热血唱不服和认领身份。若副歌只剩氛围、回忆、场景和淡淡遗憾，没有可认领的心声，判为 hook 弱。

副歌爆发还要有分寸。真正强的副歌不一定是最直白、最大声、最像吵架的句子；它可以像一把软刀，词面不脏、不乱、不撒泼，但关系判决很重。判断标准不是“有没有喊出来”，而是“有没有击中心智”。如果一句话能让听众感觉自己被说中、被刺中、被替自己说出来，它就是爆发。若只是把情绪词堆满，像骂街；或只是绕得漂亮，听众不痛，都不合格。

副歌核心句的强度来自四个位置：

```text
词语重量：公共语感里本来有力量的词、短语、熟语或判词。
关系落点：这句话改变了我和你的位置，例如被嫌成麻烦、被说成纠缠、终于两清。
承受证据：身体、动作、尊严、亏欠、身份或时间代价被唱出来。
声音记忆：尾音、停顿、重复和主韵让这句能被跟唱、复述和传播。
```

副歌核心句不能只靠裸情绪词。`难过、遗憾、孤单、不甘、还爱、想念、放不下` 可以作为材料，但不能独自承担 hook。题眼句必须优先转成关系动作链：谁做了什么，谁把这件事说成什么，谁因此承担了什么。动作链让听众看见情绪发生，情绪词只是给情绪命名。若一句副歌删掉情绪词后只剩空壳，说明它还没歌词化；若删掉情绪词后仍有动作、判词和后果，情绪就已经在句子里。

副歌核心句要走“直白内核 + 词句加工”，不能停在大白话，也不能滑向伪高级。直白内核保证第一耳听懂：谁在痛、谁在做、关系怎么变；词句加工保证它像歌：有动作、有判词、有成熟短语、有轻意象、有尾音和气口。若一句只是聊天式心理说明，即使真实也弱；若一句只是漂亮意象，即使文艺也空。题眼句要让听众既不用翻译，又觉得这句话被写过、被唱住。

副歌核心句的文学性不是华丽词汇，而是准确压缩。它的基本公式是：

```text
公共词 + 新关系位置 + 情绪压缩 + 声音落点
```

公共词让听众第一耳接住，新关系位置让常见词变重，情绪压缩让一句话装下动作、身份和代价，声音落点让它能被唱出来、记住、转述。比如 `麻烦、纠缠、偏爱、委曲求全、两清、可有可无` 都是公共词；它们只有被放进“你怎样定义我 / 我怎样承担后果”的关系里，才会从普通词变成副歌刀口。反过来，旧梦、尘寰、荒岸、星河、孤舟、余温这类词，如果没有本歌场景和物性系统支撑，只是在冒充文学性。

检查问题：

```text
这句有动作主体吗？
有关系对象吗？
有对方回应、定义、拒绝、夺走或误读吗？
有身体、尊严、身份、时间或关系后果吗？
尾词是否能唱住这个后果？
它的文学性来自准确关系，还是来自漂亮词堆叠？
这个词是公共认知里本来有重量，还是作者硬给它加重量？
```

副歌落点词是情绪落锤，不是押韵工具。落点词不只是一整句最后的尾词，也包括句内切分词、气口尾词、短语尾词和加速韵落点。凡是旋律、停顿、重拍或重复让听众听见并短暂停住的位置，都必须优先承担一个清楚职责：

```text
情绪结果：难堪、发颤、放不下、回不去。
关系判词：纠缠、麻烦、两清、可有可无。
身体后果：发颤、哽住、喘不上气、红了眼。
身份变化：外人、过客、替身、你的麻烦。
动作完成点：看一眼、说再见、丢下我、回不来。
核心命名：亏欠、体面、旧伤、偏爱、遗憾。
```

押韵只能在落点职责成立之后处理。若为了主韵或加速韵把一个单字放到句尾、气口尾、短语尾或重音位，却需要听众补出分手、别走、关系结束、低姿态等多层意思，就是落点失重。`别散` 的问题正在这里：它靠近 an 韵，但在求留语境里不如 `别走、别分开、别说再见、别把我丢下` 清楚。宁可重排整句，也不要让关键落点只负责押韵。

副歌留白必须保留逻辑骨架。有效留白不是信息少，而是核心关系已经成立，听众只需要填自己的私人记忆。模糊缺信息则是主语、对象、动作和立场缺口太大，听众必须替作者补叙事逻辑。副歌作为情绪锚点，允许舍弃细碎叙事，不允许舍弃关系、施受动作和情绪倾向。

副歌核心句最低骨架：

```text
施动者 / 承受者：我方、对方或关系双方立场清楚。
双向核心动作：谁对谁付出、拒绝、离开、误读、挽留、定义或切断。
单向情绪落点：听众知道该往委屈、不甘、心碎、释怀、遗憾、认账或反抗里代入。
```

可省略项：

```text
哪一天、为什么开始、完整前因后果、具体地点、对方动机、过往琐事、消息 / 电话 / 信件等载体。
```

判断方法：如果删掉载体后关系仍清楚，就是留白；如果删掉载体后不知道发生了什么，就是缺信息。

副歌核心句还要检查叙事距离。不要只问“这句情绪强不强”，要问唱的人离事件有多远：正在现场爆发、事后仍被刺痛，还是多年后复盘。强传播和高唤醒副歌通常需要近距离承受；长期思念和旧伤副歌可用回望仍疼；人生叙事和治愈释怀副歌可用角色自我复盘。远距离不是原罪，作者旁白才是问题。只要它是角色自己的认账、释怀、遗憾或嘴替，并且能被听众拿走，A 型复盘也可以成为副歌 hook。

叙事距离选择规则：

```text
追求瞬时破防、对峙、求留、控诉、反抗：优先 C 当下爆发。
追求长期代入、思念、暗恋、旧伤、亏欠：优先 B 回望仍承受。
追求人生认账、释怀、岁月感、民谣叙事：允许 A 角色自我复盘。
```

无论哪一类，都不能退成主歌剧情或作者总结。检查标准：有没有明确承受者、有没有公共心声、有没有主 hook、有没有可唱主韵、听众能不能用这句表达自己。

### 副歌画面感硬门槛

副歌是整首歌最需要被记住的部分，不能只有概念、价值观或抽象情绪。

人的记忆更容易抓住具体画面、动作和物件，但画面必须服从文字。副歌如果只有漂亮镜头、氛围和意象，却没有一句高密度、可复述、能钉住题眼的句子，仍然失败。画面是广告语、题眼、副歌核心句和金句钉的放大器，不是替代品。

确认副歌核心句必须优先检查：

- 这一句不看画面还能不能被复述？
- 它有没有用最少字数压住最大故事、冲突、态度和情绪？
- 画面服务的是哪一句题眼、广告语、副歌核心句或金句钉？
- 这一句能不能被拍成一个镜头？
- 有没有具体动作，例如回头、递来、擦掉、喊名、收起、站在门口、把伞推回来。
- 有没有具体物件，例如名单、粉笔灰、红笔、错题本、旧课桌、水杯、校门、工牌、工具。
- 画面是否来自本歌故事，而不是随手套“灯、光、星辰、远方、路”。
- 删除画面词以后，副歌是不是只剩概念。如果是，就要重写。
- 如果画面很漂亮，但文字不能复述、不能传播、不能推动人物变化，判为画面喧宾夺主。
- 如果副歌前后只是重复同一种意思，人物处境没有变化，判为叙事空转或冗长无推进。

高风险概念尾：

```text
半生、人生、吾师、学生、远方、星辰、光、灯、方向、成长
```

这些词不是禁用，但不能单独承担记忆点。必须被具体画面买回来，例如“粉笔灰落在袖口”“名单上喊过我的名”“错题本压在抽屉底”等。

### 从 AI 视觉迁移来的画面感写法

老胡 AI 视觉项目里，好的视频提示词不是写“有电影感”，而是写清“谁、在哪里、做什么、镜头怎么拍、光线和物件如何参与”。音乐里的画面感也要用同样的拆法，不要只写“有画面”“有意境”。

副歌核心句和题眼总纲必须至少回答：

```text
主体：这句里谁在画面中？是我、你、老师、母亲、孩子、路人，还是某个背影？
场景：他在哪里？门口、车站、校门、饭桌、工位、楼道、病房、田埂、雨棚，不写泛泛人海。
动作：他做了什么？喊名、折起名单、递工具、擦粉笔灰、把伞推回、低头签字、转身关灯。
物件：画面靠什么被记住？名单、红笔、错题本、袖口、饭盒、工牌、工具、车票、水杯。
观看距离：这是远景、中景、近景，还是一个特写？歌词里至少要能感到观看距离。
时间变化：这一句是否有前后变化？从听见到红眼，从拿着到折起，从递来到账本合上。
情绪泄露：情绪是否从动作、呼吸、眼神、手部小动作里漏出来，而不是直接说“我很感动”。
声音锚点：画面里是否有可听见的东西？点名、铃声、门响、纸页、脚步、风声、工具碰桌。
禁止方向：不能只靠漂亮形容词、抽象概念、万能意象和大词升华。
```

可以把副歌句当成一个三到五秒镜头来检查：

```text
第 0 秒：听众先看见什么？
第 1 到 2 秒：人物做了什么动作？
第 3 到 5 秒：哪个物件、声音或表情让情绪落住？
```

如果无法用一句话描述这个镜头，副歌大概率还是概念句。

### 画面感三层结构

借用 AI 视频提示词的三层结构，音乐题眼也要分三层：

```text
全歌基础设定：人物是谁、关系是什么、主要场景和核心物件是什么。
全歌氛围质感：冷暖、远近、快慢、粗粝还是干净、私人还是公开。
单句画面内容：当前这句具体发生的动作、物件、声音、表情和时间变化。
```

题眼阶段负责前两层，副歌核心句必须兑现第三层。填词阶段每个乐段继续调用这三层，不要每段临时换一套意象。

### 画面资产和一次性画面元素

音乐歌词也要区分“核心画面资产”和“一次性装饰画面”。

核心画面资产：

```text
会在 Verse、Chorus、Bridge 或 Outro 反复出现或变形。
能承载题眼和情绪债务。
能作为听众记住这首歌的画面锚点。
```

一次性装饰画面：

```text
只出现一次。
不改变关系。
不推动副歌。
换掉以后歌曲核心不受影响。
```

题眼阶段必须提前列出 3 到 7 个核心画面资产。填词时优先让这些资产递进，而不是不断新增漂亮但无关的意象。

### 两句式确认副歌核心句硬门槛

如果确认副歌核心句由两句组成，必须在进入曲式与风格前完成韵脚设计。

要求：

- 两句句尾押同一主韵，或形成非常清楚的近韵回环。
- 句尾优先落在实字，例如“光、方、长、望、上、场”这类可承载尾音的字。
- 不能用虚词补韵，尤其不能让“了、的、呢、啊、吧、吗、呀、啦”承担高潮落点。
- 不能把方向候选句的散文化意思直接交给填词阶段，再指望后面大换副歌。
- 两句都要像歌词，不能一句像标题，另一句像解释。
- 读出来要能自然卡进 4/4 或 6/8 的节拍，不要过长从句。

示例判断：

```text
不合格的确认副歌核心句：一声老师，一生都是学生；走过半生，才懂处处皆吾师。
问题：学生 / 吾师不押韵，第二句书面，读感像格言解释。

更合格：一声老师，照我一生的光；走过半生，还向你来的方向。
原因：光 / 方同属 ang 韵，画面和情绪更集中。
```

高风险副歌句：

- 像广告语。
- 像公众号标题。
- 像公益宣传。
- 像热搜话术。
- 只有抽象情绪，没有人物和代价。
- 只有概念词，没有镜头画面。
- 漂亮但不能唱。
- 两句不押韵。
- 句尾是虚词。
- 像散文摘句，不像歌词 hook。

## 4. 三个候选方向的差异

选题题眼阶段默认先由 `laohu_music_topic_writer` 输出 3 个初稿方向，再由 `laohu_music_topic_repair` 组织选题角度评审官评审和裁决。差异不能只体现在人称或标题上，必须有真实创作差异：

三个方向还必须各自借用不同或至少明显不同的既有认知定势。不能三个方向都只是在同一种“遗憾、想念、错过”里换皮，也不能靠向听众解释新道理来冒充深度。

方向 A：更像口述往事

### 4.1 选题角度评审硬门

三个方向生成后，不能直接把其中一个交给曲式与风格。必须先经过选题角度评审。

评审重点：

```text
哪个方向最不普通？
哪个方向的人群最精准？
哪个方向最会借用听众已有认知，而不是试图创造认知？
哪个方向说中了听众已经存在的担心、欲望、怨气、羞耻、侥幸或误判？
哪个方向借用了人物可被接受的缺点，而不是只表扬优点？
哪个方向找到了共同敌人，让听众和人物站到同一边？
哪个方向从共识里挖出了偏见，而不是重复安全共识？
哪个方向的副歌候选更像个体宣言，而不是公共标语？
哪个方向体现了脑力取舍，而不是用数量掩盖主判断缺席？
哪个方向最能诱发目标听众的痛苦敏感和损失厌恶？
哪个方向有真正的过敏反应句，而不是只让人觉得好听？
哪个方向是在借势生活困难，而不是消费苦难、卖惨求同情？
哪个方向保住了人物尊严，而不是把人物写成单纯可怜人？
哪个方向把苦难转化成和解、励志、行动或自我命名，而不是停在惨里？
哪个方向最会用小故事元素撬动大情绪和大认知，而不是堆材料？
哪个方向识别了听众的大脑墙，并找到了穿墙缝隙？
哪个方向的副歌候选像金句钉，短、准、扎心、可复述？
哪个方向有共鸣网入口，能让听众知道发给谁、在哪用、用来表达什么身份？
哪个方向的利他金成立，真正给听众情绪、身份或表达利益，而不是讨好？
哪个方向最敢放弃非目标听众，而不是讨好所有人？
哪个方向有真正的选择性注意点，而不是全程平滑顺和？
哪个方向适合使用喜剧反差，哪个方向不该强行搞笑？
哪个方向能用狠词怂态或言不由衷制造反差，而不是普通讲道理？
哪个方向借用了经典作品的结构、场景或集体记忆，而不是抄梗？
哪个方向的思维出轨能制造注意力，并且最后带回题眼？
如果这是短视频系列，九浅一深里哪一条负责抓流量，哪一条负责圈铁粉？
哪个方向适合英雄之旅三幕，哪个方向不该硬套逆袭模板？
哪个方向说清了人物为什么必须离开旧城市、旧关系、旧行业、旧身份或旧自我？
哪个方向的未知世界和怪兽最具体，而不是只写努力、坚持和熬过去？
哪个方向的第一桶金或阶段成功有代价、有关系变化、有起点 / 深渊双岔口，而不是平铺直叙炫耀成功？
哪个方向说出了某类人经常遭遇但很少被命名的事情？
哪个方向只是 AI 大数据情绪套路？
哪个方向传播成本过高，需要先教育听众才成立？
哪个方向能让后续 Verse / Chorus / Bridge 都有东西可写？
三个方向之外，是否存在更刁钻、更具体、更值得写的第四角度？
```

选题执行官必须输出：

```text
最终选择 / 重构后的最佳方向：
为什么不是另外两个方向：
是否吸收其他方向的局部素材：
确认题眼：
副歌核心句候选：
整首歌总纲：
给曲式与风格阶段的交接字段：
选题初稿缺陷归因与 laohu_music_topic_writer 进化卡：
```

硬门：

- 如果三个方向都普通，必须重构第四方向。
- 如果最终方向只是三个方向的平均值，判失败。
- 如果没有明确人群、故事引擎和情绪债务，不得进入曲式与风格。
- 如果没有说清借用的听众已有认知定势，不得进入曲式与风格。
- 如果没有说清人物可被接受的缺点和共同敌人，不得进入曲式与风格。
- 如果没有说清表面共识、可借用偏见、个体宣言句和脑力取舍理由，不得进入曲式与风格。
- 如果没有说清痛苦敏感点、损失厌恶点和过敏反应句，不得进入曲式与风格。
- 如果涉及困难、失败、低谷或委屈，但没有说清苦难借势点、尊严保留点、转化落点和卖惨风险，不得进入曲式与风格。
- 如果没有说清故事杠杆、大脑墙、穿墙缝隙、金句钉、共鸣网入口和利他金，不得进入曲式与风格。
- 如果没有说清不讨好谁、选择性注意点是什么，不得进入曲式与风格。
- 如果题材适合轻喜剧、自嘲、反讽、短视频切片或发布包装，却没有判断喜剧反差适用性、狠词怂态、言不由衷句、经典借势点或思维出轨点，判为喜剧钩子不足。
- 如果题材不适合搞笑，却强行玩梗、猎奇或蹭争议，判为玩梗伤题。
- 如果题材属于第一桶金、事业转折、逆袭成长、创业失败再出发或人生阶段跃迁，却没有说清英雄之旅适用性、离开之幕、启动之幕、要打的怪兽、归来之幕和起点 / 深渊双岔口，不得进入曲式与风格。
- 如果离开动因只是“想变好、想成功、想赚钱”，没有旧世界压力、羞耻、控制、天花板或不甘心，判为离开动因不足。
- 如果启动之幕只有努力、坚持、加班和吃苦，没有未知世界、人物遭遇和具体怪兽，判为未知世界不足或怪兽不清。
- 如果归来只写赚到钱、被认可、扬眉吐气，没有身份、资源、关系、代价或危险变化，判为成功单薄或归来无代价。
- 如果第一桶金没有起点 / 深渊双岔口，不能看出它会开启新旅程还是诱发傲慢、贪婪、失控和坠落，判为起点深渊未分。
- 如果没有解释为什么淘汰其他方向，不算完成选题执行官裁决。

## 5. 嘴替承载

嘴替不是“面向某类用户”，而是替一个具体处境里的人说一句他说不出口的话。

判断问题：

- 这个人现在卡在哪里？
- 他想说但没说出口的是什么？
- 他为什么不能直接说？
- 这句话唱出来以后，听众会觉得“这就是我”吗？

示例方向：

```text
不是“写给打工人”，而是写给那个明明已经很累，还要在语音里说“我快到了”的人。
不是“写给分手的人”，而是写给那个已经删了联系方式，却还记得对方换季会咳嗽的人。
```

注意：示例只说明方法，不要求以后套用这些高频素材。真正写作时优先取老胡输入、作品真实材料、社群反馈和可靠案例。

## 6. 修辞系统的根

题眼阶段要提前给下游一个修辞根，防止后续乱写意象。

必须判断：

- 核心物象是什么。
- 这个物象为什么能承载人物处境。
- 它在故事里先是什么，后来变成什么。
- 它适合比喻、拟人、借物抒情还是寄情于景。
- 哪些修辞方向不能走，因为会变玄、变假、变不通。

修辞必须服务嘴替承载。不要突然写星河、山海、光、风、梦、宇宙这类没有场景根的漂亮词。

## 7. 副歌核心句允许后续微调

题眼阶段定下的副歌核心句，是语义锚点，不是死字句。

后续填词时可以因为以下原因微调：

- 韵脚。
- 气口。
- 句尾承载。
- 曲式长度。
- 主风格语言。

但不能改变原意。如果从“我终于承认我还没放下”变成“我已经学会祝福”，就是方向跑偏。

更重要的是：微调不等于推翻。方向候选句可以弱一些，但确认副歌核心句必须完成主韵脚、句尾和唱感判断。后续不能因为确认副歌核心句不押韵、不像歌词，就整段替换副歌核心句。

## 8. 选题题眼阶段禁区

- 不提前写完整歌词。
- 不把副歌核心句写成营销口号。
- 不写成抽象分析报告。
- 不把所有题材都推成民谣叙事。
- 不让 AI 临场编造平庸苦情素材冒充人味。
- 不把用户口述原样复写成歌词。
- 不把题眼写成孤立副歌句，缺少明确人群、故事引擎、情绪债务和证据配额。
- 不平铺赞美、怀念或人生道理，必须有冲突、反差或转折。

## 9. 输出前自检

选题题眼产物输出前，内部检查：

- 这首歌替谁说话？
- 明确人群是否具体到一个处境中的人？
- 核心关系是否清楚？
- 故事引擎是否有事件、冲突、反差或转折？
- 情绪债务是否只锁定一项主债务？
- 证据配额是否足够支撑后续主歌？
- 具体场景能不能被看见？
- 情绪代价是不是具体？
- 副歌核心句能不能唱、能不能记？
- 副歌核心句主韵脚是否明确？
- 两句式确认副歌核心句是否押韵？
- 句尾是否落在实字，能不能被拖长或合唱？
- 老胡是否明确确认方向、题眼和副歌核心句三项？
- 三个方向是不是真的不同？
- 哪个方向最适合进入曲式与风格阶段？
- 选题题眼是否提供整首歌总纲，而不只是副歌核心句？
- 是否规划了第一次、第二次和最终副歌的意义递进？

## 10. 阶段确认门

选题题眼阶段必须分清三件事：

```text
已确认方向
已确认题眼
已确认副歌核心句
```

老胡只选择某个方向，不等于确认题眼和副歌核心句；老胡给出修改意见，也不等于允许进入曲式与风格。进入下一阶段前，当前文件必须明确写出：

```text
确认方向：
确认题眼：
确认副歌核心句：
主韵脚：
句尾承载：
核心画面资产：
乐段预案：
副歌递进：
仍需老胡确认：
```

如果“仍需老胡确认”里还有方向、题眼或副歌核心句相关问题，不得推进到曲式与风格阶段。
