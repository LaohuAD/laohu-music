# 灵感关键词到音乐创作维度映射规则

本文件是老胡音乐把灵感、关键词、故事和人物材料映射到音乐创作维度的专项规则库。

它比 `laohu_music_topic` skill 的常规判断更细，负责在灵感模糊、材料较多或方向摇摆时，帮助 agent 进一步判断题材、人称、场景、核心物象、情绪、风格倾向、副歌功能和禁用方向。当前项目只通过对话、口述、文件材料和老胡反馈来判断。

本文件属于增强资产，不承担选题入口或 writer 的基础下限能力。基础路由、候选生成硬门和字段后置顺序必须写在 `skills/laohu_music_topic/SKILL.md` 与 `skills/laohu_music_topic_writer/SKILL.md`；本文件只用于复杂材料和关键词映射加深。

## 1. 映射目标

当老胡给出一句灵感、一段故事、一个人物或一组关键词时，不能只把它整理成“主题”。要把它映射成后续音乐创作真正需要的维度：

```text
题材类型
→ 嘴替对象
→ 说话人称
→ 生活压力系统
→ 场景入口
→ 题材机制证据 / 人物私有证据 / 通用氛围证据
→ 核心物象
→ 核心情绪
→ 表达方式
→ 主风格倾向
→ 副歌功能
→ 禁用方向
```

## 2. 题材类型映射

常见关键词：

- 家人、父母、爷爷、奶奶、老伴、孩子：亲情 / 代际 / 亏欠。
- 分手、暧昧、冷暴力、沉默、错过：亲密关系 / 遗憾 / 没说出口。
- 城市、街头、华强北、视频、走红、帮扶：社会观察 / 当代现实。
- 坚持、命运、苦难、年、人生：人生叙事 / 命运感。
- 权力、规则、防御、拆穿、不服：态度表达 / 说唱 / 摇滚 / 社会观察。

注意：关键词只提供线索，不是最终题材。必须回到“这首歌替谁说话”。

星座、MBTI、人格标签、年龄身份、地域标签等输入，不能直接映射成标签歌。它们只能作为人物气质来源，必须继续落到关系压力、具体选择和审美转译。比如“水瓶座女生”不能写成“独立、自由、冷感、不被束缚”的星座文案；要判断她在爱情里怎样表现这种气质：是否重精神连接、厌恶被审问、爱得深但发现背叛后抽离很快、宁愿失去关系也不愿自证。现实层可能是手机、定位、消息，但歌词层不能默认直出这些高频界面，必须转成更有美感和人物性情的象征动作或故事冲突。

## 2.1 生活压力系统映射

在题材类型之后，必须继续判断人物主要被哪套生活压力系统困住。生活压力系统不是题材标签，而是证据来源；它决定主歌能用哪些动作、物件、地点、制度和日常细节。

常见系统：

```text
校园：课桌、点名、排名、晚自习、校门、毕业照、准考证、空座位。
家庭：饭桌、门锁、旧房间、亲戚称呼、药盒、旧衣柜、母亲圆场、家里沉默。
职场：工牌、群通知、绩效表、撤回的请假申请、会议纪要、下班时间才回家。
病房 / 照护：药盒、缴费单、陪护椅、翻身、铃声、病历袋、等人睡着后崩溃。
亲密关系：报备、定位、共同物、道歉循环、被检查的细节、反复失约。
县城 / 乡镇：熟人社会、街口、婚宴、亲戚转述、门面房、旧同学。
漂泊城市：租房、通勤、站台、车票、外卖、便利店、账单；只有当它确实是人物命运容器时才用。
创作职业：相机包、录音文件、未发稿、演出证、剪辑时间线、被删的素材。
社会结构：合同、欠薪、规则、审批、罚单、名单、排队窗口、被替换的名字。
国风身份秩序：官印、旧信、仪式、城门、家国身份、誓约、不可越界的称谓。
```

未确认生活压力系统时，不得默认调用都市离别 / 都市漂泊道具库。若确实使用站台、车牌、账单、旧票、路灯、雨夜、便利店、消息框等公共意象，必须说明它为什么是人物命运的一部分，而不是通用氛围素材。

## 2.2 证据分层映射

建立证据库时，必须先分三层：

```text
题材机制证据：没有它，这个题材或处境就不成立。
人物私有证据：只有这个人物会这样处理、保留、逃避或反复触碰。
通用氛围证据：很多伤感题材都能共用的环境、天气、交通、消息、灯光等素材。
```

方向核心和主歌主证据，优先从前两类产生。通用氛围证据只有在被题材、人物关系或关键动作重新定义后，才允许升级为核心证据。不是禁用站台、账单、消息框，而是禁止用它们冒充人物生活。

## 3. 人称和说话位置

默认判断：

- 第一人称：适合亲历、独白、心事、没说出口的情绪。
- 第二人称：适合对某个人说、质问、告别、挽留、拆穿。
- 第三人称：适合人物故事、社会观察、历史人物、旁观叙事。

判断问题：

- 谁有资格说这句话？
- 谁能看见这些材料？
- 谁不能越权替别人说内心？
- 听众站在谁的位置听？

如果人称不稳，后续歌词会散。

## 4. 场景入口

场景入口不是背景板，而是第一段歌词从哪里开门。

常见入口：

- 动作入口：删掉、忍住、回头、还钱、等、躲、没说完。
- 空间入口：街头、房间、楼道、车里、摊位、门口。
- 物件入口：票据、灯、饭、药、花、旧衣服、聊天框。
- 时间入口：多年后、凌晨、换季、最后一次、某个节日前。

禁区：

- 不要用“深夜、地铁、没回消息、妈妈问到家了吗”这类高频 AI 素材做默认高级示范。
- 如果这些素材来自老胡真实输入，可以用；否则不要自动套。

## 5. 核心情绪映射

同一灵感可能有多个情绪，不要只抓最表层。

- 不甘：适合 Rap、摇滚、强节奏流行。
- 遗憾：适合流行、民谣、R&B。
- 想念：适合流行、民谣、国风，但要避免泛泛温柔。
- 亏欠：适合民谣、流行、现实叙事。
- 清醒 / 拆穿：适合 Rap、摇滚、冷感电子。
- 治愈：必须有伤口和代价，不要直接写“会好起来”。

## 6. 表达方式映射

- 白描叙事：适合现实人物、亲情、街头观察。
- 口语独白：适合第一人称心事。
- 对话推进：适合第二人称、质问、告别。
- 借物抒情：适合有稳定核心物象的题材。
- Rap bar：适合态度、社会观察、反击、争议。
- 冷感碎片：适合电子、疏离、循环情绪。
- 国风凝练：适合历史、命运、人物抉择。

## 7. 主风格倾向映射

风格不能只看情绪，要同时看：

```text
人物身份
→ 情绪强度
→ 语言密度
→ 传播场景
→ 副歌核心句形态
```

判断示例：

- 副歌核心句短、准、容易传唱：优先流行。
- 需要讲人物和生活处境：民谣可选，但不能默认。
- 态度强、有观点刀口：Rap / 摇滚优先。
- 私密、贴耳、拉扯：R&B 优先。
- 冷感、循环、身体节奏：电子优先。
- 历史、命运、凝练意象：国风 / 古风可选。

## 8. 副歌功能映射

副歌不一定都是“情绪爆发”，它可能承担不同功能：

- 替听众说出口。
- 把主歌细节压成一句判断。
- 把关系代价唱出来。
- 把标题句变成传播句。
- 把人物从忍住推到承认。
- 把不甘推到反击。

副歌核心句不是越狠越好，而是越准越好。

## 9. 禁用方向映射

每次选题题眼阶段都要给“不建议走的方向”。

常见禁用：

- 不要写成营销口号。
- 不要写成公益宣传。
- 不要写成城市宣传片。
- 不要把现实人物写成苦情消费。
- 不要把治愈写成廉价暖词。
- 不要把 Rap 修成民谣。
- 不要把国风写成符号堆砌。
- 不要用 AI 高频苦情素材冒充高级。

## 9.1 亲情 / 代际 / 不想长大类灵感映射

当输入包含家人、爷爷奶奶、父母、童年、回老家、不想长大、短剧片尾、迟来的懂、亏欠等关键词时，不能直接映射成“怀念童年 / 不想长大 / 亲情遗憾”这种泛主题。

先拆三件事：

```text
当年误读了哪一种照顾？
谁把疼藏进了什么生活动作？
多年后哪个物件或声音证明我懂晚了？
```

判断逻辑：

```text
不是所有旧物都能进歌。能进歌的物件必须证明关系。
不是所有具体画面都更好。Verse 可以具体，Pre 要转成身体压力，Chorus 要压成可复唱心声。
不是所有“长大”都写青春迷茫。亲情迟懂类的真正题眼通常是：我不是怕长大，我是怕终于懂事时，没人再听我回答。
```

常见有效入口：

- 误读入口：小时候把叮咛听成啰嗦，把照顾听成管束，把长辈的忍痛听成普通大人话。
- 物件入口：药碗、饭桌、袖口、补丁、硬币、旧玩具、门框、称呼、咳声、碗底、车窗。
- 翻面入口：小时候只顾玩、只顾要、只顾嫌烦；长大后才听懂这些动作是在给我留好运、留退路、留牵挂。
- 禁用入口：只写老家很旧、灯光很暖、风很凉、童年回不去。这些只能做氛围，不能当选题发动机。

选题阶段输出时必须说明：

```text
嘴替对象：长大后才听懂亲情的人，而不是所有怀旧的人。
核心误读：当年把什么爱误解成了什么。
核心物件：哪个物件缺了，这首歌就不成立。
副歌功能：把“迟懂”压成听众能认领的一句心声。
曲风倾向：亲情片尾主题曲优先近麦叙事、克制抒情和物件声音化，不默认大电影弦乐。
```

## 10. 输出前自检

- 是否已经从关键词映射到了音乐创作维度？
- 是否明确嘴替对象和说话位置？
- 是否有场景入口和核心物象？
- 是否判断了主风格倾向，而不是默认流行或民谣？
- 是否给出副歌功能？
- 是否明确禁用方向？
