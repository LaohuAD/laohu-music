# 作品

每部正式立项的作品使用一个独立目录。目录名优先采用正式歌名或当前歌名初稿；尚无合格歌名初稿时，可以暂用能够辨认核心冲突的路线标签，但日志必须明确它不是歌名。

```text
作品/<正式歌名、歌名初稿或路线标签>/
├── 创作日志.md
├── 歌词创作台.md（需要写词时才建立）
├── 创作档案.md（需要保留长篇审议时才建立）
└── 用户明确要求保存的歌词、谱曲方案、歌名、封面提示词或发布材料
```

`创作日志.md`是状态控制台，`歌词创作台.md`是写词输入台，`创作档案.md`是追溯材料，三者不混用。未确认的普通讨论、候选、试写和一次性分析留在聊天中，不提前落盘。作品目录不创建版本副本和临时文件夹。
