# 音乐封面视觉转译与发布验收

这份 reference 吸收老胡 AI 视觉项目的封面设计、图片资产交接和发布复盘规则，专门适配歌曲、单曲、专辑、音乐视频缩略图和发行页面。它固定判断顺序与质量门，不固定综合色、字体、服装、画风和构图模板。

## 封面箴言

```text
封面不是歌曲插图，是听众进入歌曲的门。
先见关系，再见风格。
一个主体守住一条总线，一处异常打开一扇门。
道具不是装饰，必须参与命运。
标题不替画面解释，画面不替标题重复。
悬念不靠遮脸，靠答案尚未抵达。
小图不减情绪，只减细节。
封面、歌名、声音各自入场，最后同归一线。
```

箴言是方向，不是禁词表。古风、雨夜、红色、月亮、戏服、信件、火焰和背影都可以使用；只有当它们来自歌曲的关系、物件、时代或声音，并参与第一眼的观看任务时，才有资格进入画面。

## 一、封面准入

正式封面默认在歌词、正式歌名、声音方向和可用生成结果已经明确后进入发布阶段。封面可以在选题、写词或谱曲阶段做探索稿，但探索稿不得反过来要求歌词、歌名或声音迁就一张漂亮图片。

开始前先建立一张音乐封面简报：

```text
作品与发行用途：专辑封面 / 单曲封面 / MV缩略图 / 短视频封面 / 发行页面主图
目标平台与实际画幅参数：
目标听众与第一眼使用场景：
锁定歌名、演唱者、署名或发行信息：
歌曲总线：人物、关系、命题和不可逆选择
歌词承重物：一个主要物件、动作、空间或自然物
声音中心：主唱身体、核心动机、groove、音色或段落记忆
第一眼承诺：观众看到什么后愿意继续听
观众暂时不知道什么：
不能误导的事实：时代、人物身份、结局、文化和版权边界
现有参考：人物、服装、道具、场景、成片截图、Logo或风格图
```

如果只剩“古风、唯美、伤感、电影感”，准入不通过。那些是检索词，不是封面主张。

## 二、四种封面各司其职

```text
单曲 / 专辑封面：负责长期识别、歌名记忆和作品余味，允许更凝练。
MV缩略图：负责让观众看懂一个现场异常，并与声音开头共同承诺。
短视频封面：负责平台环境中的一秒停留，冲突必须更快可读。
发行页面主图：负责把歌名、歌手、作品身份和视觉世界稳定地放在一起。
```

四者共享同一歌曲总线，但不必选同一个时间点。封面可以前置一处高压现场，不能替歌曲泄露最终选择；短视频可以更直接，长期封面仍要有回听后的余味。

## 三、第一视觉合同

封面只保留一个第一落点、一个主要动作或状态、一个主要悬念。第一落点可以属于歌名、人物或关系证据，先完成归属裁决：

```text
标题主导：歌名本身就是最强问题、判断或记忆中心，背景能够提供一项具体证据。
人物主导：既有人物身份、脸部状态或歌手识别是进入歌曲的最短入口。
关系主导：一个动作或空间异常比歌名和脸更快说明作品独有关系。
```

胜出者至少同时占据面积、明暗或综合色对比、清晰度、周围隔离、构图位置和方向动势中的三项优势。第二层最多在一项上接近它，并且必须证明第一落点；第三层只负责归属、时代或余味。不能让标题、脸和剧情画面分别夺走一项优势后，再用“信息丰富”替注意力平均辩护。

随后回答：

```text
第一眼看见歌名、人物还是关系动作
→ 它正在做什么，而不是摆什么姿势
→ 哪一处关系、欲望或危险不合常理
→ 这项异常来自歌曲总线的哪项事实
→ 观众会提出哪一个主要问题
→ 歌名补足什么，画面不再重复什么
→ 听完以后，这个画面为什么会获得第二层含义
```

人物动作优先于表情，事件压力优先于服装风格。`台下坐满军靴，台上仍有人开口`比“悲伤戏子回眸”更接近一首具体的歌，因为它让身份、秩序和危险同时现身，却没有把结局说完。

### 歌名与背景的证明关系

标题主导型封面中，背景不负责装饰标题，也不负责重演全部歌词。先把歌名还原成听众第一眼会提出的问题、判断或情绪，再选择一项能够改变其读法的可见证据：一个人物动作、一个结果、一个缺席位置或一个跨时空对应。标题提出或命名，背景提供理由；二者合起来仍只打开一个问题。

正式字形设计按以下顺序完成：

```text
歌名语义重音
→ 一行、分行或分组造成的阅读顺序
→ 主次字组的面积差与位置关系
→ 与声音、时代和介质相称的字形骨架
→ 填色、暗边、投影、飞白或材质怎样保证分离
→ 只保留一次有理由的倾斜、越界、断行或局部强调
→ 缩略图核对字义、顺序与第一落点
```

自媒体粗笔刷、黄白强对比和硬阴影证明的是缩略图中文字可以承担第一视觉，不是音乐封面的固定美术风格。迁移时保留宽大字面、明确重音、强分组和背景分离等作用；颜色、笔触、倾斜、描边和质感必须按歌曲重新选择。

### 人物主导画面的单帧因果

人物不是因为出现在画面中央就成为主体。进入构图前，用五个连续问题把她放进正在发生的关系：

```text
前一刻留下了什么可见痕迹
→ 她此刻正在对谁或什么作出反应
→ 哪个动作尚未完成，下一瞬会往哪里去
→ 摄影机站在什么关系位置，观众因此被允许知道什么
→ 环境的光、物件、距离或遮挡怎样接住她的动作
```

静止不等于摆拍。人物可以坐着、站着或沉默，只要手、目光、衣物余势、被移动的物件、空位或环境痕迹共同证明一件事刚发生、正在发生或即将发生。相反，`悲伤回眸、手持旧物、独自站立`若没有明确对象、动作后果和下一趋势，仍是模特姿势。五项不能指向同一关系时，退回主画面，不用更多布景和滤镜补救。

### 方向动作的语义核对

目光、手势、身体、车辆、武器、风、水、烟、飞行物、追逐对象和撞击结果同时出现时，先建立方向账，不能用“整体向右”“线条连贯”代替：

```text
主体或物体是谁
→ 从哪里出发、正朝哪里去
→ 前缘、头部或受力面在哪里
→ 尾迹、烟尘、衣物余势或来路留在哪里
→ 这个方向在人物关系中表示命令、迎接、躲避、阻止、追赶还是离开
→ 下一个物体或结果区是否接住了同一种动作
```

观看路线与事件方向可以相反：一个人在右侧回望左边的人，左边的人仍可以向右发令。关键是分别说明谁在看谁、谁让什么向哪里移动，不能把所有线条压成同一箭头。指挥者的手臂若朝向运动物的尾迹，观众可能读成叫停或拦截；奔跑者身体朝前而衣物、尘土留在身后，才证明前进。反向关系不是禁用项：人物确实在阻止、逆流、回头或追赶时，方向冲突正是内容；但必须由作品事实决定，不能由生成模型偶然造成。

### 双时空与回忆层

一张封面可以同时出现现实人物与旧日影像，也可以使用海报大脸、剪影、照片、倒影和双重曝光。成立条件不是层数少，而是观看路线只有一条：现实层的人物目光、手势、行进方向或空间遮挡必须指向回忆层；回忆层只回答现实层正在承受的一个问题；歌名位于两层之间时，要成为读法转换处，而不是第三张贴纸。

检查时依次遮住现实层、歌名和回忆层。任意两层若仍能独立组成另一张完整海报，说明当前只是三张图叠在一起；退回关系和视线路线。若三层分别承担现在的反应、问题的命名和过去的原因，而且缺一层都会损失同一个悬念，多层构图成立。

### 视觉世界改写时的关系保真

当封面、MV 或短视频把歌曲从原有时代、地域、职业、类型世界迁到另一种现实场景，先建立两列对应；这一步只在世界发生改写时启用：

```text
歌曲原作：表达者 / 表达对象 / 关系种类 / 不可逆选择 / 识别歌词
视觉改写：第一主体 / 关系对象 / 可见动作 / 同级代价 / 对应证据
```

允许更换战争、职场、神话、家庭、舞台或现代生活等外部处境，也允许把字面道具转成同功能的视觉证据；改写后，陌生观众仍应进入同一种人物关系，歌词中的关键称谓、动词和代价仍能由画面解释。以下情况直接判为换题：

- 伴侣、亲属、朋友、师生等既有关系未经作品授权，被改成另一类关系。
- 原本唱给一个人的话变成面向时代、国家或抽象群体的宣言。
- 私人选择被宏大符号遮住，画面只剩题材立场。
- 新背景需要额外旁白才能解释识别歌词，或迫使歌词改义才能成立。

历史、文化和现实苦难只提供人物处境，不自动提供情感分量。涉及真实事件时，核验时代、年龄、服装、器物和纪念空间；无法确认的细节退回不带专名、不冒充史实的虚构视觉，不用真实受难者或可识别史料照片充当装饰。

## 四、视觉通行路线

每张封面都要有一条从进入到离开的视线路线：

```text
进入点：脸、手、歌名、道具、亮区或方向线中的一个。
阻断 / 加速：前景、遮挡、明暗边界、视线、手势或形状怎样改变观看速度。
决定性落点：观众最终必须看见的关系证据或声音象征。
余韵出口：空位、反射、未闭合动作、未抵达的手或歌名关系留下什么问题。
```

标题、人物、道具、背景和装饰不能同时争抢第一落点。若无法说清这条路线，画面仍是名词堆叠。

## 五、歌名与可见文字

歌名、歌手名、词曲作者、厂牌、期数和发行信息拥有不同职责，不能无差别堆上封面。歌名负责作品身份；副标题或宣传短句只有在用户明确提供、或发行任务确实需要时才出现。

```text
用户已确认的歌名 / 署名：逐字锁定，不润色、不缩写、不换同义词。
需要修改的歌名初稿：先完成命名阶段，再回到封面；不让排版替命名补救。
没有原文的文字项：删除，不让图像模型随机编写。
```

最终生图提示词中，所有实际可见的中文文字逐项用中文双引号锁定原文；固定 Logo 使用实际参考，不重新描摹、改字体、改颜色或改比例。文字层级、断行、字重、颜色、前后关系和安全区要写清，但标题不承担歌词或剧情说明书的职务。

## 六、参考图只取职责

参考资产必须在提示词中显性写出职责：

```text
【封面主体参考@...】只固定人物 / 产品 / 道具的身份与必要外形。
【成片截图参考@...】只固定最终音频视觉化内容已经兑现的状态与事实；允许重构封面构图。
【构图参考@...】只提取图文层级、视线、留白或尺度关系。
【风格参考@...】只提取综合色、材质、成像介质或字体气质。
【Logo参考@...】只调用固定 Logo，不把文字替代 Logo 本体。
```

一张参考图不能因为“看起来完整”就同时锁死人物、服装、背景、构图、标题和第三方文字。没有实际引用时不放空占位符；参考职责冲突时，以歌曲已经锁定的身份与总线为准。

## 七、颜色、光线和材质要有出处

颜色从歌词世界、时代材料、人物服装、舞台灯、天气、建筑、纸张、金属、水面或声音联想中的具体物件产生。先写颜色来源和职责，再谈综合色。颗粒、旧纸、柔焦、镜头耀斑、色散和污渍也要有介质或光学来源，不能把“电影感”当作滤镜清单。

国风或文化题材不等于图腾堆叠。文化素材先分为原始 / 传统资料、当代二创、商业案例、版式参考和来源不确定材料；只吸收可观察的结构、比例、材料、颜色、字体、尺度和留白关系。未知经文、宗教核心符号、法器、仪式和不明文字先隔离或核验，商业案例只借方法，不冒充文化事实。

## 八、反模板与概念竞争

内容原生设计时，内部先生成 3–5 个机制不同的概念，至少改变以下两项：观众位置、空间压力、主视觉符号、进入点、落点、歌名与画面的关系、主色来源或余韵出口。不是同一张“大脸 + 背景 + 发光字”换颜色。

逐项审问库存符号：

```text
它是否来自这首歌的人物或声音
→ 它是否参与主要动作或关系
→ 换到同题材另一首歌是否仍然成立
→ 删除它是否损害总线
→ 它会不会把听众误导到另一种歌曲
```

按以下顺序选胜出方案：先看是否兑现歌曲最强承诺，再看一秒识别与缩略图轮廓，再看作品专属符号、生成稳定性、文字安全区和多比例裁切空间。

## 九、画幅与生成正文分层

把画幅分成三层：

```text
参数层：由图片平台设置实际比例；
构图层：内部按目标画幅安排主体占比、留白、标题安全区和视线方向；
模型正文层：只写画幅造成的可见关系，默认不重复堆“横版 / 竖版 / 1:1”等数字。
```

音乐封面按用途记录 `1:1` 专辑 / 单曲封面、`3:4 / 4:3` 发布图和 `16:9` MV缩略图。用户没有要求平台专版时，优先输出一条当次内容的比例自适应提示词；固定坐标、左上 / 右上和像素范围只在平台专版或模板续作中使用。换画幅不能只改数字，必须重审人物裁切、歌名断行、视觉重心和安全边距。

## 十、交付合同

日常默认只交付一条可直接投喂的封面提示词：

```markdown
【封面生图提示词】

【实际参考@...】用于固定……，允许……。
歌曲的第一视觉主体与正在发生的动作……
关系异常、空间压力、摄影机位置、视觉通行路线……
颜色、光线、材质与成像介质来源……
歌名“……”；演唱者“……”；其他确认可见文字“……”
文字层级、断行、前后关系、留白与安全边距……
按当前画幅自动重排，不改变主体、歌名原文和主要关系……
```

内部可以保留简报、概念竞争和淘汰记录，但除非用户明确要求，不把它们混进最终提示词代码块。无字底图与后期排版只在直接带字生成实际出现错字、乱序、残缺字形或排版失控后启用，不作为默认逃生通道。

## 十一、发布前质量门

```text
一秒内能认出主体、歌名和唯一承诺吗
第一落点属于歌名、人物或关系证据中的哪一个，是否至少赢得三项视觉优势
第二层是否给第一落点提供证据，而不是独立争抢注意力
缩到手机缩略图后，轮廓、标题和关系仍成立吗
灰度或剪影状态下，层级仍成立吗
歌名、声音中心、歌词意象和画面是否承诺同一首歌
标题与画面是否互补，而非重复解释
主体是否处在事件或关系压力中，而非站桩摆拍
前一刻的痕迹、当前反应、未完成动作和下一趋势是否属于同一关系
删掉标题后，谁在回应谁或回应什么仍可辨吗
视觉世界若发生改写，表达者、对象、关系种类、代价方向和识别歌词是否保真
现实层、歌名和回忆层是否沿同一视线或动作因果连接
摄影机位置、视线、手势、空间和光线是否可信
方向账是否写清各主体的起点、终点、前缘、尾迹和动作含义；观看路线与事件方向即使相反，也没有产生非预期的阻止、躲避、追赶或误伤语义
颜色、材质、文化元素是否有歌曲或画内来源
参考图是否各司其职，没有污染背景、服装、第三方文字或版式
是否没有提前展示死亡答案、最终选择或全部反转
1:1、发布图和视频缩略图的裁切是否仍可用
真实可见文字是否与锁定原文逐字一致
```

任一关键项失败，按最早责任回流：歌名或作品承诺不成立，回歌名 / 选题；人物、道具或文化依据不干净，回素材准备；主关系、构图、文字层级或比例失败，回封面设计；提示词清楚但模型仍持续错字，才启用无字底图和后期排版。

## 十二、生成后回传

真实封面或发布数据回来后，只记录可观察事实：第一落点、缩略图可读性、标题准确性、承诺兑现、裁切损失、点击变化和评论误读。不能用“更高级、更有氛围”替代定位。数据只说明漏斗在哪一层发生变化，不自动证明应该改颜色；先判断是曝光、点击、开头、歌曲兑现还是内容理解的问题，再把规则回写到正确层级。
