# 旋律入口与跨 Skill 协作

## 什么时候读取

已有旋律、伴奏、节拍、参考音频、哼唱或 topline，或需要跨 Skill 做局部验证时，读取本文件。

本文件只处理音乐限制和 Skill 协作。逐字填词、音节、倒字和完整旋律交给对应 Skill。

## 核心判断

旋律已经携带速度、呼吸、方向、能量、段落和声音角色。不要把歌词命题硬塞进去，先判断题目与这些条件是否相容。

跨 Skill 只回答当前一个明确问题。选题 Skill 保留裁决权。

## 一、先判断创作入口

### 1. 无音乐，自由选题

优先确定人物、关系、主题、用途和运动，再为后续音乐留下重复、呼吸和高潮空间。不要在选题阶段把字数、押韵和曲式全部锁死。

### 2. 已有完整旋律

先听音乐，再筛题。让人物、题材和情绪适应旋律的运动、段落和声音；不要在选题阶段逐音填字。

### 3. 已有伴奏或 beat

重点判断律动、速度、音色、循环长度、能量曲线、留白、重拍和适合的声音姿态。可用无意义哼唱、节奏词或标题句测试，不要先写完整书面歌词。

### 4. 已有 topline 或哼唱

检查旋律重音和元音空间已经暗示什么语言动作：呼喊、倾诉、追问、叙述、切分、咏叹。题目要允许人物自然使用这种声音动作。

### 5. 参考音频

先拆出要借鉴的维度：速度、能量、结构、音色、叙事距离、声线、场景或用途。“照这个风格写”不是分析；不得复制可识别旋律、歌词装置和艺人风格。

## 二、音乐初听的十个变量

不急着命名情绪，连续听三遍：第一遍感受整体，第二遍标段落和变化，第三遍观察声音与语言空间。

1. **速度与律动**：身体是前进、摇摆、悬停、奔跑还是拖曳。
2. **拍感与重音**：哪些位置天然承受关键词、动作词或标题句。
3. **旋律走向**：上行、下沉、盘旋、跳进、级进怎样改变语言姿态。
4. **音域与声区**：适合亲密低语、日常叙述、少年感、厚重叙事还是高位爆发。
5. **句长与气口**：允许短句、长句、密集信息还是元音延展。
6. **和声色彩**：稳定、悬而未决、明暗混合、循环压迫或突然开阔。
7. **段落反差**：主歌、副歌、桥段是否真的改变能量与视角。
8. **音色与编配**：地域、时代、科技、身体或空间联想来自哪些具体声音。
9. **重复方式**：适合中心句回归、问答、递进、咏叹还是动作口号。
10. **表演姿态**：歌者像在对一个人说、对全场喊、讲故事、扮演角色还是与身体共同动作。

把观察与解释分开。例如“副歌旋律持续上行”是观察；“适合胜利”只是解释，还可能适合失控、请求或绝望。至少提出两种人物化解释再选择。

## 三、从音乐反推题目

用下表形成候选：

| 音乐事实 | 可容纳的人物动作 | 可能题目 | 排除什么 |
| --- | --- | --- | --- |
| 长句、低声区、缓慢下行 | 回忆、解释、迟疑 | 私人告白、晚年回望 | 密集口号、快节奏问答 |
| 强重拍、短句、群体回应 | 号召、劳动、对抗 | 现场齐唱、行业动作 | 细碎内心独白 |
| 循环和声、能量渐增 | 等待、执念、不断逼近 | 关系回环、行动升级 | 只靠一次反转的故事 |

表格只是示例。具体判断必须以实际音乐和歌手为准。

每个候选继续核对：人物为什么用这种声势说话，中心句放在音乐高潮是否语义过重或过轻，段落反差能否对应关系变化。

## 四、填词入口的选题边界

选题阶段应确认：

- 音乐与歌词的情感、风格和时代感是否相容。
- 曲式能容纳多少人物、背景与变化。
- 哪个段落适合中心句，哪里需要叙述或留白。
- 重要语义是否有重音与长音空间。
- 多段同曲时，题目是否允许相似句式承载递进内容。
- 旋律是否适合人声、目标歌手与预期时长。
- 音乐来源和使用授权是否清楚。

逐句字数、连音、一字多音、声调走向、倒字、韵脚和试唱修改，交给写词与谱曲 Skill 共同完成。

## 五、局部验证怎样调用其他 Skill

### 调用写词 Skill

适用问题：人物口吻是否可信、中心句是否可唱、两种视角哪种更有生命、某个意象能否落地。

输入必须包含：已锁定的人物和关系、只验证的变量、保持不变的条件、字数或音乐限制、禁止扩写完整成品。

### 调用谱曲 Skill

适用问题：音乐情绪和段落如何理解、题目是否适配已有旋律、中心句是否有高潮空间、演唱形式是否可行。

输入必须包含：音频或乐谱、选题候选、目标歌手、需要比较的音乐维度。谱曲 Skill 给出音乐判断，选题 Skill决定题目。

### 调用歌名 Skill

适用问题：工作标题能否集中主题、归属是否清楚、标题句是否适合返回。正式命名仍待命题确认后完成。

### 调用封面 Skill

只在视觉概念能暴露人物、时代、对象或用途混乱时调用。例如两个命题看似相近，但视觉主体完全不同，可借概念草图帮助用户判断。不得以封面好看证明选题成立。

## 六、一次只验证一个变量

每次调用前写明：

```markdown
- 当前主问题：
- 需要借用的 Skill：
- 只验证：
- 保持不变：
- 候选 A / B：
- 判断标准：
- 输出上限：
```

结果回来后，选题主持人完成：

1. 哪个候选在目标维度更强。
2. 它是否暴露新的命题问题。
3. 需要修改题目、保留假设还是进入下一阶段。
4. 哪些局部结果仅是试验，不得锁定。

## 七、处理词与曲的冲突

### 情感冲突

文字说克制，旋律要求爆发。先判断是否可以把爆发解释为人物终于失守；若人物逻辑不允许，换题或改音乐，不靠表演硬救。

### 信息冲突

旋律句短而题目依赖复杂背景。收窄题目、把背景移到视听或前置剧情；不能在短句中压入说明书。

### 结构冲突

音乐循环强而故事依赖连续反转。改为回环、执念或动作递进题目，或重新设计曲式。

### 声音冲突

题目需要脆弱私语，歌手和编曲只提供宏大外放。重新选择人物位置、歌手或制作方向，不只改形容词。

### 文化与时代冲突

音乐具有明确地域或时代来源，歌词却使用无关符号。先调查来源，判断是尊重、融合还是错置；不靠表面乐器决定题材。

## 八、音乐适配压力测试

1. 不看文字，只听音乐，候选人物会以什么身体和语气开口？
2. 不听音乐，只读命题，它真正需要怎样的能量运动？
3. 两者最强的共同点是什么，最明显的冲突是什么？
4. 核心句放入高潮，是被音乐放大还是显得空泛？
5. 低能量段落是否有真实内容，还是只等副歌出现？
6. 换一段同速度同调性的普通伴奏，题目是否仍成立；若成立，说明适配可能过于泛化。


## 十、失效判定

- 先写完整文字命题，再要求旋律无条件迁就。
- 只用“悲伤、治愈、燃、大气”概括音乐。
- 把一种音乐特征解释成唯一题材。
- 参考音频只剩模仿对象，没有拆解维度。
- 一次试验同时更换人物、题材、视角和中心句。
- 辅助 Skill 的局部结果直接取代用户确认和主 Skill 裁决。
- 音乐来源和授权不清便进入正式交付。
