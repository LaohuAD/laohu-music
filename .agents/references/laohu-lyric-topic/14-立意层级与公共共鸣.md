# 立意层级与公共共鸣

## 什么时候读取

出现以下任一问题，读取本文件：

- 用户知道想写什么题材，却说不清这首歌真正要表达什么。
- 用户希望作品更深、更高级、更有传播力或更接近高水平作品，但“深”和“传播”尚未落到具体判断。
- 需要判断作品主要为一个人、一段关系、一个群体、国家与历史共同体，还是人类共同处境发声。
- 私人经历是否应该扩大成群体表达，或公共题材是否需要收回到具体人物。
- 作品想代表某类人，却不确定创作者、歌者或人物有没有发声资格。
- 需要判断个人经验怎样抵达共同经验，而不是在结尾追加宏大词句。
- 需要解释共鸣、传唱、分享和公共价值分别由什么机制产生。

本文件只负责选题阶段的立意与公共性。意象、修辞、韵律、整首歌词和市场结果交给对应 Skill 与现实验证。

## 一、核心结论

找到真实生活中最值得写出的关系判断。不要用题材名、风格、意象和故事外壳代替它。

立意必须由具体事实推出，并说明人物、群体或个人与现实之间的关系发现：

- “写母爱”是题材。
- “一个从不说辛苦的母亲，晚年第一次允许女儿照顾自己”开始具备关系变化。
- “长期承担照顾的人，最难接受的不是衰老，而是把被需要的位置交还给别人”才形成可以继续验证的立意。

按这条路径推进：

```text
从一个可信的小入口进入
→ 把人物与关系写到足够深
→ 让更多人从中认出自己
```

小入口要有材料；写得深要看见欲望、责任、权力、代价和自我解释的冲突；广回声要给听众留下放入自己经验的位置。

个人、群体、国家、世界只是发声范围，不是作品等级。个人处境可以触及普遍人性，谈世界也可能只有口号。选择材料最真实、最必要、最能承担的范围。

## 二、五个概念分开判断

### 1. 题材

题材回答作品进入哪片生活。爱情、亲情、职业、故乡、成长、时代、家国和公益都只是归类。

题材不能证明作品值得写。同一题材可以承载无数人物、关系和判断。

### 2. 立意

立意回答“作品从这段生活中看见了什么”。它必须包含事实依据、关系判断和价值取舍。

判断句至少能回答其中两项：

- 谁想得到或保住什么。
- 谁在承担什么代价。
- 哪个旧解释被事实推翻。
- 人物终于承认、拒绝、请求或决定什么。
- 作品最终保护什么，又不替什么开脱。

### 3. 发声范围

发声范围回答“这个声音属于谁”。它可能属于一个具体人物、一种关系位置、一个群体、公共共同体或人类共同处境。

范围选择改变人物说话资格、材料要求、语言距离和伦理责任，但不自动改变艺术等级。

### 4. 公共性

公共性回答“这段经验怎样与别人发生关系”。听众不必经历同一事件，只要能认出相似的关系位置、身体感受、价值冲突、身份记忆或现实代价，私人经验就可能具有公共性。

公共性不是去掉私人细节。过度抽象会删除听众进入作品所需的证据，反而减弱连接。

### 5. 传播力

传播力回答“作品为什么会被记住、借用、演唱、分享或反复使用”。它不仅由立意决定，还受歌词表达、旋律、节奏、歌手、制作、媒介、时机、曝光和社交场景影响。

选题阶段只能判断传播条件与潜力，不能保证播放量、热度或历史地位。

## 三、立意从哪里产生

### 1. 从事实开始，不从正确结论开始

先写出不带评价的事实：谁做了什么，谁没有做什么，什么改变了，谁因此付出代价。再问这些事实改变了人物对关系的哪一种理解。

错误顺序：

```text
先决定歌颂母爱
→ 搜索牺牲与奉献的材料
→ 用材料证明预设结论
```

有效顺序：

```text
看见母亲拒绝女儿替她扣纽扣
→ 追问她在保护尊严、习惯还是家庭位置
→ 发现“被照顾”意味着承认自己不再是那个支撑全家的人
→ 形成关于照顾、尊严与角色交还的立意
```

### 2. 找到关系中的真正动词

“爱、想念、成长、时代”是名词，不能发动作品。立意需要动词：留下、隐瞒、归还、承担、拒绝、等待、原谅、保护、背叛、让位、承认。

寻找动词时问：

- 这个人正在对另一个人做什么。
- 他嘴上说的与实际做的是否相反。
- 他想改变谁的决定。
- 他不行动会失去什么。
- 这件事完成以后，关系中的权力、责任或身份会怎样变化。

### 3. 找到不能同时满足的两件事

立意深度常来自真实冲突，不来自情绪数量。至少找出两项不能同时保全的需要：

- 想离开，也想被挽留。
- 想照顾家人，也想拥有自己的生活。
- 想被群体接纳，也不愿放弃个人判断。
- 想纪念共同历史，也不愿删掉其中的代价。
- 想公开表达伤害，也担心再次伤害当事人。

若作品只保留一个正确愿望，没有对立需要和现实代价，立意通常会退化成态度口号。

### 4. 找到作品真正的新发现

“亲情珍贵”“坚持会成功”“要保护环境”属于已有共识。作品仍可写这些题材，但必须找到当前人物让旧共识发生的新变化：

- 哪个事实使常识不够用了。
- 哪类人一直被常见说法遗漏。
- 同一个正确价值在现实中要求谁承担代价。
- 人物原先误解了什么，现在为什么改口。
- 作品命名了哪一种经常发生、却很少被准确说出的关系。

### 5. 做普通话解压

任何“高级立意”都要能改写成普通话，说明人物、事实、关系和取舍。解压后只剩“爱能战胜一切”“平凡造就伟大”“我们生在最好的时代”，判为立意尚未形成。

### 6. 先确定中心问题，再决定是否给答案

不要替生活提前写正确结论。先确定作品追问什么、人物目前相信什么、哪个事实正在反驳他、最后必须确认什么，以及哪些矛盾必须保留。

至少写清四层：

```text
中心问题：这段关系或处境究竟逼我们面对什么问题
人物当前答案：他现在怎样解释自己、对象和结局
反证事实：哪个动作、后果或沉默使这个解释站不住
保留余地：作品最终确认什么，仍允许听众怎样理解
```

“我应该放下”“我们要勇敢”只是答案或口号。中心问题必须逼迫人物选择，例如“长期照顾别人的人，能否在求助时保住尊严”，或“主动离开的人，有没有资格要求被留下”。

答案不必在选题阶段被解释完。若作品把所有矛盾都提前化解，人物就只是在证明作者；若作品连问题都没有，只剩情绪流动，听众又没有需要继续听下去的认识压力。高水平命题要让问题、证据、人物动作和听众参与空间彼此咬合。

### 7. 让立意保留可生长的未决部分

为每个候选立意分别写出“可以确认的判断”和“不能替人物决定的部分”。不能替人物决定的部分不是漏洞，而是作品的开放压力：它可以在写词、旋律、演唱和听众使用中逐步显形。

检查三点：

- 结尾若删除最后一句总结，前文动作是否仍然支持核心判断。
- 人物若没有完全释怀，作品是否仍然完成了真实变化。
- 听众能够带入自己的对象和经历，但是否仍能认出这首歌独有的人物与事实。

如果一个立意只需要把“爱情”换成“亲情”或把“个人”换成“时代”就完全成立，说明它还没有从当前作品中长出来。

## 四、发声范围没有高低

### 1. 具体个人

作品由一个人物唱给一个明确对象，保留私人经历、秘密、称呼和不可替换细节。

**优势**：真实密度高，人物可信，容易形成独特归属。

**风险**：背景过于封闭，听众只能旁观；细节只负责交代信息，没有显出共同关系。

**需要回答**：没有相同经历的人，能从哪一种需要、代价或关系位置进入？

### 2. 关系位置或具体群体

作品由处在相似位置的人发声，例如照护者、迁徙者、夜班劳动者、成年子女、毕业生或失去某种职业的人。

**优势**：听众容易产生“这也是我的话”的身份确认，适合点唱、分享和共同演唱。

**风险**：把群体写成单一人格，用一人的经历代表所有人；外部作者借群体身份制造感动。

**需要回答**：成员真正共同的是什么，哪些差异不能被抹掉，谁有资格使用“我们”？

### 3. 公共、国家与历史共同体

作品处理公共责任、制度生活、历史记忆、共同土地、语言、灾难、战争、城市或国家身份。

**优势**：可以连接共同记忆、公共行动和仪式使用。

**风险**：让抽象共同体代替具体的人；只写荣誉，不写责任和代价；把复杂历史压成单一正确情绪。

**需要回答**：宏观事件怎样进入普通人的生活，哪些事实必须核验，这份归属要求人物承担什么？

#### 时代进入私人命运的五个入口

家国立意不是把私人爱情写小，再在结尾补上国家、民族和牺牲。时代必须进入因果，具体改写人物：

1. **承诺条件**：战争、迁徙、制度或灾难使原本可以兑现的婚约、归期、照护和团聚失去保证。
2. **身份用途**：武生、青衣、医生、教师、船工或普通人的旧职业，在时代压力下获得新的责任和行动可能。
3. **信息边界**：谁能收到信、相信谁、何时知道生死、消息怎样被截断或利用，直接改变误解和选择。
4. **价值冲突**：人物不能同时保住爱人、同胞、职业伦理、安全、尊严和生命，必须公开自己先保护什么。
5. **公共后果**：一个原本只属于两个人的动作，开始影响陌生人的生死、共同记忆或群体行动。

私人入口与公共意义必须形成双向压力：时代逼两个人改变承诺，两个人又用自己的职业、感情和选择回应时代。若国家只负责让恋人分开，删掉时代后换成异地工作仍然同义，时代只是布景；若人物一到结尾突然忘掉爱人，只剩正确口号，公共立意又吞掉了私人生命。

以武生与青衣为例，真正的提升不在`他们的爱情发生在战争中`，而在两人的职业动作被战争改写：武生不愿只在台上扮英雄，选择进入真实战场；青衣先借戏班巡演寻找他，后来可能把戏台变成自己作出公共选择的地方。爱情没有被家国替换，恰恰因为她仍然在等那个人，最后的选择才付出了私人未来。这种代价由行动证明，不需要人物站出来解释大道理。

判断公共立意是否成立，使用这条链：

```text
时代改变了哪项现实条件
→ 这项变化拆散或重写了哪项私人承诺
→ 人物因此不能同时保住什么
→ 他使用原有身份与能力做出什么选择
→ 选择伤害了什么私人愿望，又保护了哪些人或价值
→ 即使删掉结尾口号，听众是否仍能看见公共意义
```

### 4. 人类共同处境

作品触及生老病死、时间、爱、孤独、自由、归属、尊严、失去和代际传递等长期处境。

**优势**：跨越地域与身份，具有长时间理解的可能。

**风险**：把所有差异抹平，人物变成人类概念的传声筒；每句都正确，却没有一件真实发生的事。

**需要回答**：这种共同处境在当前人物身上以什么不可替换的方式发生？

### 5. 范围选择规则

选择范围时比较五项：

1. **材料密度**：现有事实能支撑到哪一层。
2. **人物资格**：歌者知道什么、经历什么、能代表什么。
3. **作品任务**：私人陪伴、群体表达、公共纪念还是仪式共同唱。
4. **差异保护**：扩大范围后是否仍保留群体内部和个人处境的差别。
5. **歌曲容量**：有限时长能否让这个范围通过人物和动作成立。

范围大但材料薄，优先收回；范围小但关系深，不强行扩大。只有作品任务确实需要共同发声，且事实、身份和音乐形式能够承载时，才扩大范围。

## 五、从个人经验抵达共同经验

### 1. 五层纵向推导

```text
具体事实
→ 人物感受与身体反应
→ 关系机制
→ 共同处境
→ 公共意义
```

- **具体事实**：发生了什么，谁做了什么。
- **人物感受**：这件事怎样进入身体、注意和选择，不只贴情绪名。
- **关系机制**：依赖、控制、亏欠、角色倒转、失去许可、身份让位等怎样运作。
- **共同处境**：哪些不同事件中的人也会遇到同一机制。
- **公共意义**：这让听众重新理解什么责任、尊严、权利、归属或共同记忆。

每一层都要由上一层推出。若“公共意义”无法回指具体事实，属于后贴拔高；若只停在事实，没有看见关系机制，作品可能真实但尚未形成立意。

### 2. 双向回指检查

完成推导后反向检查：

```text
公共意义是什么
→ 哪种共同处境支持它
→ 哪个关系机制让处境成立
→ 哪些人物动作证明这个机制
→ 这些动作是否来自真实材料
```

任何一层断开，都不能用更响亮的措辞补上。

### 3. 相同事件不是共鸣的必要条件

听众可以没有照顾过患病父亲，却理解一个长期强大的人第一次承认需要帮助；可以没有离开故乡，却理解回去以后发现自己已经失去原来位置。连接发生在关系机制和人的需要上，不要求所有人拥有同一履历。

### 4. 保留陌生性

公共性不要求把人物改造成平均听众。对听众陌生的职业、地域、年龄和文化细节，只要能看懂其在关系中的作用，就可以保留。作品让人进入另一个人的生活，也是一种公共价值。

## 六、公共共鸣的六种机制

不要只判断“有没有共鸣”。先说明作品依靠哪一种连接发生作用。

### 1. 自我识别

听众从人物的关系位置、动作或一句未说出口的话中认出自己。

**需要**：可识别的处境、准确动作、不过度解释的空间。

**失效**：直接宣布“每个人都经历过”，却没有听众能对照的事实。

### 2. 代入他人

听众没有同样经历，但能进入人物的目标、阻力和代价，理解他为什么这样选择。

**需要**：清楚人物欲望、因果和信息边界。

**失效**：只展示苦难结果，人物没有选择与主体性。

### 3. 关系识别

听众经历不同，却认出相同的关系机制，例如照顾者不敢示弱、离开者希望被挽留、受恩者难以拒绝。

**需要**：作品把情绪落到谁对谁做了什么，以及这改变了什么。

**失效**：只有情绪相似，没有关系和动作。

### 4. 群体身份确认

作品让成员确认“我们是谁、共同承担什么、外界误解了什么”。

**需要**：成员自称、共同劳动、共同风险、内部记忆和愿意公开承担的立场。

**失效**：用人口标签或外部想象制造“我们”。

### 5. 共同记忆与价值情绪

作品调用一群人共享的事件、仪式、地点、语言或历史，同时触发感激、羞耻、骄傲、哀悼、责任、公正等价值判断。

**需要**：记忆来源可核验，价值情绪由人物选择和现实后果产生。

**失效**：符号一出现就默认所有人拥有相同记忆和态度。

### 6. 共同使用与共同演唱

作品在婚礼、毕业、纪念、劳动、集会、比赛、告别或现场中被共同使用，音乐和重复使个体进入同一行动。

**需要**：明确身份、可承担的中心句、适合共同发声的演唱形式与场景。

**失效**：把口号、齐唱和高音误当凝聚；成员自己不愿公开唱这句话。

一首歌可以同时使用两三种机制，但必须有主机制。机制越多不代表越强；互相冲突时按作品任务取舍。

## 七、发声资格与代表性边界

### 1. 先确认说话位置

歌者可能是：

- 亲历者。
- 关系中的另一方。
- 见证者。
- 经充分调查后的叙述者。
- 受委托的代言者。
- 明确虚构的角色。

不同位置知道的事实、能使用的“我”和“我们”、可以作出的判断都不同。不得让见证者冒充亲历者，也不得让作者借角色说出其无从知道的群体真相。

### 2. 使用“我们”前回答六个问题

1. “我们”具体包括谁，不包括谁。
2. 这些人真正共享什么经历、关系、风险或责任。
3. 群体内部有哪些重要差异。
4. 歌者凭什么能代表或召集这个群体。
5. 成员是否愿意公开承担中心句中的立场。
6. 被代表者能否纠正、拒绝或退出这种表述。

答不清时，用具体人物的“我”比虚假的“我们”更诚实，也可能更有力量。

### 3. 写他人痛苦时的伦理检查

- 是否把当事人只写成受害、疾病、贫穷或身份符号。
- 是否为了感动删掉他的愿望、判断和行动能力。
- 是否未经同意使用可识别的私人经历。
- 是否把结构性问题改写成个人不够努力。
- 是否由帮助者、旁观者或品牌抢走主体位置。
- 是否把一种群体经验说成全部成员的唯一经验。

### 4. 公共题材中的复杂性

爱一个共同体不等于只能赞美；批评也不自动等于深刻。作品要说明人物在归属、责任、利益、记忆和现实代价之间怎样选择。删除矛盾，只留下正确态度，会同时损失真实性和公共性。

## 八、传播力的现实构成

### 1. 传播不是立意的单变量结果

选题阶段用下面的关系检查，不把它当精确数学公式：

```text
传播机会取决于
识别度 × 情感重要性 × 表达借用性 × 音乐记忆性 × 场景适用性 × 触达条件
```

其中任一项接近于零，作品即使立意很好，也可能没有广泛传播；传播很广也不能反证立意必然高。

### 2. 六项分别怎样判断

- **识别度**：目标听众能否迅速辨认人物、关系或处境。
- **情感重要性**：这件事是否触及身份、尊严、归属、失去、责任或现实利益。
- **表达借用性**：听众是否愿意借中心句替自己说话，同时句子仍属于本作。
- **音乐记忆性**：旋律、节奏、重复和演唱是否帮助记忆；选题阶段只确认有可承载的中心。
- **场景适用性**：作品在哪个时刻被点唱、转发、合唱、纪念或配合画面使用。
- **触达条件**：歌手、平台、发布时间、预算、制作和分发是否真实存在。

### 3. 不要把所有传播都理解成最大曝光

传播可能是：少量听众长期循环；一类人把歌当作自己的表达；某个仪式反复使用；短时间大范围触达；跨代流传。先确定项目需要哪一种，不用单一热度标准裁决所有作品。

### 4. 传播预测必须可验证

禁止只说“题材大众、容易共鸣”。要写成可验证判断，例如：

```text
目标听众是第一次照顾年迈父母的成年子女；
他们可能借用“第一次替你扣好纽扣”表达角色倒转；
主要使用场景是独处循环、家庭影像和节日分享；
需要用目标听众访谈与两句中心句测试验证，而不是根据题材名称判断。
```

## 九、主持用户完成立意校准

### 第一步：接住原始种子

复述用户真正舍不得丢掉的经历、人物、情绪或判断。只提炼已经存在的内容，不提前给它升华。

### 第二步：找到最值得追问的事实

优先寻找能改变关系理解的事实：一次反常动作、一句没有回答的话、身份倒转、不得不承担的代价、人物一直回避的选择。

不要问“你想表达什么大道理”。先确认用户认定哪件事重要，再追它改变了什么关系。

### 第三步：拆出关系与冲突

明确谁想要什么、谁阻碍什么、人物不能同时保住哪两件事、哪一个决定会改变关系。把“悲伤、治愈、热血”改写成具体压力。

### 第四步：形成普通话立意

用一到两句说明：

```text
这首歌不是泛写【题材】，而是写【人物】在【处境】中发现/承认【关系判断】；
真正难的是他想同时保住【需要 A】与【需要 B】，但【现实事实】迫使他选择。
```

### 第四步半：形成中心问题卡

在形成判断后，不急着把它写成一句漂亮的主题句，先记录：

- 作品真正追问的问题：
- 人物现在相信的答案：
- 支持这个答案的事实：
- 正在反驳它的事实：
- 作品必须确认的部分：
- 必须保留的矛盾或未决部分：

中心问题必须能回指人物、关系和代价；不能只写“如何面对人生”“爱是否永恒”这类任何歌曲都能使用的抽象问题。

### 第五步：选择发声范围

分别提出私人、关系或群体、公共或普遍三个方向。每个方向都说明新增了什么、失去了什么、需要补什么材料、歌者是否有资格承担。

### 第六步：找到共同连接

从六种公共共鸣机制中选择一项主机制，说明听众通过哪个人物动作、关系位置、共同记忆或使用场景进入。

### 第七步：给出明确推荐

推荐现有材料最能支撑、最不失真、最有生长空间的一条。若范围较小但关系更深，要明确说明为什么不扩大；若公共任务要求共同发声，要说明需要补哪些调查、角色或音乐形式。

### 第八步：让用户决定不可替代的取舍

只把真正属于作者的决定交给用户，例如愿不愿保留某段私人事实、是否承担群体立场、作品优先服务谁。事实核验、候选分析和风险说明由管理员承担，不能把专业工作变成问卷。

## 十、三方向候选比较法

对同一材料形成三个纵深不同的候选，保持人物事实不随意变化：

| 比较项 | 私人方向 | 关系或群体方向 | 公共或普遍方向 |
| --- | --- | --- | --- |
| 谁在唱 | 一个具体人物 | 处于共同位置的成员 | 公共角色、共同体成员或具体人物承载普遍处境 |
| 唱给谁 | 明确对象 | 同类关系中的对象或成员 | 公众、后来者、共同体或跨身份听众 |
| 最强资产 | 私人细节与关系真相 | 共同经验与身份确认 | 共同记忆、责任或长期人性问题 |
| 必要材料 | 当事事实、称呼、动作 | 多个成员的共同处境与差异 | 可核验历史、制度、文化与公共后果 |
| 主要风险 | 封闭、自我沉溺 | 以偏概全、虚假“我们” | 口号、拔高、人物消失 |
| 共鸣机制 | 自我识别、关系识别 | 身份确认、共同使用 | 共同记忆、价值情绪、代入他人 |

比较后不要平均折中。可以用私人入口承载公共意义，但必须保持一个主声音；不能第一段写私人信件，副歌突然代表群体，结尾再上升到世界，而没有人物与材料的连续变化。

## 十一、高水平选题的八道门槛

“殿堂级”不能由规则宣布。选题阶段只判断它是否具有进入高水平创作的地基。

### 1. 真实

关键人物、关系和材料经得起当事人或事实核验，不靠类型化想象填空。

### 2. 必要

主人公在此刻非说不可；触发事件已经进入他的需要、身体、行动、防御和关系后果，作品也确实命名了某种未被充分表达的需要。

### 3. 矛盾

人物至少面对两项不能同时满足的真实需要，选择带来代价。

### 4. 发现

作品拥有值得追问的中心问题，人物当前答案受到事实反驳；作品提供新的关系认识、观察位置或准确命名，不只是重复正确常识，也不提前消灭仍需保留的矛盾。

### 5. 可代表而不抹平差异

听众能认出共同机制，但人物没有被改造成平均样本，群体内部差异仍被尊重。

### 6. 有发声资格

歌者掌握的信息、经历和位置足以承担作品立场；不借他人身份获取廉价重量。

### 7. 适合歌曲承载

命题有可反复咏唱的情感中心、声音动作和发展空间，不依赖论文式说明。

### 8. 给听众参与空间

作品没有把意义全部解释完。听众可以把自己的记忆、对象和处境放进去，但不会因此失去作品自身归属。

八项不是平均打分。真实性、发声资格或歌曲适配出现致命问题时，其他项再强也不能进入完整写作。

## 十二、反向验证与外部验证

### 1. 去宏大词检验

删除“时代、国家、世界、人类、命运、伟大、永恒”等词。若公共意义随之消失，说明意义原本只存在于词语标签。

### 2. 换题检验

把立意句换到另一首同题歌。若仍完全成立，说明它是公共常识，尚未从当前人物长出来。

### 3. 事实回指检验

逐句指出立意由哪个动作、选择或后果支持。无法回指的部分降为作者愿望或删除。

### 4. 群体成员检验

涉及群体表达时，找不同位置的成员验证：

- 这是不是你们共同面对的问题。
- 哪个地方把你们写成同一种人。
- 你愿不愿公开唱中心句，为什么。
- 哪个细节只有外部观察者会这样想。

一位成员不能证明整个群体，但可以揭示错误代表和语言失真。

### 5. 陌生听众检验

让没有同类经历的人说明：他理解人物为什么这样做吗，他从中认出了什么关系，他在哪一处失去进入路径。用来验证代入与公共性，不要求他与人物相同。

### 6. 使用场景检验

把中心句放进预期场景：独处、点唱、现场齐唱、纪念、影视或短视频。判断谁会使用、对谁使用、使用后承担什么意义。场景里没有真实动作，传播判断仍是想象。

## 十三、阶段交付模板

```markdown
## 立意与公共性校准卡

- 原始种子：
- 关键事实：
- 人物与主关系：
- 不能同时满足的两项需要：
- 普通话立意：
- 中心问题、人物当前答案与反证事实：
- 作品必须确认与必须保留未决的部分：
- 作品的新发现：
- 主要为谁发声：
- 发声范围：个人 / 关系或群体 / 公共共同体 / 人类共同处境
- 选择该范围的理由：
- 具体事实 → 关系机制 → 共同处境 → 公共意义：
- 主要共鸣机制：
- 目标听众如何进入：
- 歌者的发声资格：
- 代表性边界与伦理风险：
- 私人、群体、公共三个候选的差异：
- 管理员推荐及理由：
- 传播机会的具体机制：
- 尚需补充的材料或验证：
- 用户最终决定：
```

字段按任务删减。没有公共表达需求时，不为完整而强造“公共意义”；只要私人命题已经真实、必要并触及共同关系，就可以保持私人范围。

## 十四、失效判定

出现以下任一情况，返回事实、关系或范围选择继续讨论：

- 立意只是题材词、情绪词、正确价值词或宣传口号。
- 用“更宏大、更高级、更深刻”评价方向，却说不出事实、关系和代价差异。
- 默认一个人低于一群人，一群人低于国家或世界。
- 为扩大传播删除私人细节，结果只剩任何人都能说的句子。
- 把“我”的感受改成“我们”的共识，却没有成员材料和代表资格。
- 公共意义只能在结尾由作者总结，无法从前文人物行动推出。
- 战争、国家和时代只负责制造分别，人物的能力、信息、承诺条件和行动后果与现代私人故事没有区别。
- 为了避免口号化，把已经由人物选择和代价成立的家国冲突全部收回成个人释怀。
- 把牺牲本身当公共意义，没有写清人物原本能选择什么、最终保护什么、私人上失去什么。
- 把群体写成单一人格，删除内部差异与反对声音。
- 写他人创伤、贫困、疾病或身份时，人物只负责提供感动。
- 把同一事件误当共同经验的唯一来源，忽视关系机制可以跨事件连接。
- 把有公共价值误判为一定能传播，或用传播数据倒推艺术价值。
- 只说“引起共鸣”，没有说明听众通过何种机制、在哪个场景、做出什么使用动作。
- 立意很适合文章论述，却没有人物开口必要、反复中心和歌曲容量。
- 管理员只展示多个方向，不给推荐；或以专业名义替用户决定作品立场。

## 十五、理论依据与使用边界

本方法吸收以下理论中与选题直接相关的稳定判断，不把理论名称当作作品答案：

1. **亚里士多德《诗学》第九章**：诗的普遍性并不是抽象谈论所有人，而是呈现某一类人在特定条件下，依照可能性或必然性会怎样行动。这里转化为“从具体人物与因果关系抵达普遍认识”，不要求现代歌词服从古典戏剧结构。来源：[MIT Classics, Poetics](https://classics.mit.edu/Aristotle/poetics.1.1.html)。
2. **叙事沉浸研究**：van Laer、de Ruyter、Visconti 与 Wetzels 对叙事沉浸研究的元分析，将沉浸理解为受众在心理上进入故事所唤起的世界。这里转化为“公共连接需要可进入的人物、处境与因果”，不据此宣称所有叙事都必然说服听众。来源：[Journal of Consumer Research, DOI 10.1086/673383](https://doi.org/10.1086/673383)。
3. **集体记忆研究**：Orianne 与 Eustache 区分个体成员的共享或协作记忆与社会系统中的社会记忆，并指出图式、脚本和社会角色连接个体意识与社会沟通。这里转化为“群体表达必须落到成员、角色、共同经历和反复沟通”，不能把抽象集体当作会自动记忆和发声的人。来源：[Frontiers in Psychology, DOI 10.3389/fpsyg.2023.1238272](https://doi.org/10.3389/fpsyg.2023.1238272)。
4. **共同歌唱与社会联结研究**：Pearce、Launay 与 Dunbar 对新组成成人课程的追踪研究发现，共同歌唱组在早期形成亲近感的速度更快。这里仅支持“共同演唱可能成为群体联结机制之一”，不把单项研究扩大成歌曲必然传播或所有文化场景相同。来源：[Royal Society Open Science, DOI 10.1098/rsos.150221](https://doi.org/10.1098/rsos.150221)。
5. **问题发现研究**：Getzels 将问题发现视为创造活动中区别于直接求解的重要环节。这里转化为“选题先发现真正值得追问的问题，再决定作品确认什么”，不据此要求所有歌词保持含糊或拒绝结论。来源：[Cognition and Instruction, DOI 10.1207/s15516709cog0302_4](https://doi.org/10.1207/s15516709cog0302_4)。

理论负责校准因果和边界，最终判断仍要回到当前人物、材料、歌曲用途、文化处境和用户选择。不得在面向听众的歌词中展示理论名词，也不得因为找到理论支持，就跳过当事人、目标听众和真实使用场景的验证。
