# 情绪动力与心理运动

## 什么时候读取

出现以下任一情况，读取本文件：

- 用户只有“伤感、治愈、热血、遗憾、释怀”等情绪标签，尚未说清人物为何这样感受。
- 人物、事件和立意已经大致明确，但作品缺少真正的内在发动机。
- 需要判断主人公为什么在此刻唱，而不是任何时候都可以唱。
- 需要区分表层情绪、被压住的情绪、相互冲突的需要和人物实际做出的关系动作。
- 需要判断情绪怎样从开头走到结尾，而不是只改变情绪强度。

本文件只负责选题阶段的心理因果与情绪运动。不得把情绪直接写成歌词，不得给题材规定固定情绪，不得用心理学术语替人物作答。

## 核心判断

情绪不是装饰色，也不是预设文风。它是人物解释事件后，在身体、注意、行动冲动和关系选择上的变化。

选题阶段必须完成这一条链路：

```text
具体事件
→ 人物原本期待什么
→ 事件怎样打破或确认了他的判断
→ 它威胁或满足了什么需要、身份和关系
→ 人物出现什么身体感受、注意偏向和行动冲动
→ 他怎样防御、隐瞒、合理化或调节
→ 他不得不对谁做出什么关系动作
→ 这个动作怎样改变作品的情绪、认识或关系
```

只能写“他很难过，所以想念”，情绪链未成立。继续写清他失去什么、怎样解释事件、想靠近还是逃走、想控制还是承认，以及为此付出什么代价。

## 一、先写事实，再写评价

先写旁观者可以核对的事实。暂不用“背叛、辜负、伟大、可怜、成长”等结论：

- 谁做了什么，谁没有做什么。
- 事件发生前，人物以为事情会怎样发展。
- 哪一个事实使原来的理解无法继续维持。
- 谁因此获得、失去、承担或逃避了什么。
- 这件事是已经结束、正在发生，还是仍然可能改变。

同一事实可以产生不同情绪，因为不同人物的目标、知识、责任和解释不同。不要先决定情绪，再为情绪搜集材料。

## 二、拆解事件评价

围绕当前事件逐项判断，只保留会改变人物选择的部分：

### 1. 对目标的影响

这件事让人物更接近还是更远离他想得到的东西？他真正想要的可能不是对象回来，而是被承认、保住尊严、恢复控制、免于亏欠或获得离开的许可。

### 2. 对身份的影响

事件是否迫使人物承认自己已经不是原来那个人，或不再拥有原来的位置？例如照顾者突然需要被照顾，掌控者第一次等不到回应，离开者发现自己仍在等待许可。

### 3. 对关系的影响

事件改变了谁对谁的依赖、权力、责任、距离、信任或称呼？情绪必须回到关系变化，不能只停在人物独自感受。

### 4. 对控制感的影响

人物能否改变结果？他是主动结束、被迫接受、错过时机，还是用“我早就不在乎”掩盖自己没有选择？主动与被动会产生不同的羞耻、愤怒、自责和遗憾。

### 5. 对公平与责任的影响

人物认为谁应该承担什么，现实却由谁承担了？不要默认人物的判断就是事实，要区分事实、人物解释和作者判断。

### 6. 对不可逆性的影响

还有没有补救、撤回、解释或回头的可能？越不可逆，人物越可能在行动前反复犹豫，在行动后继续与结果争辩。

### 7. 对公开形象的影响

人物害怕别人看见什么？有些人不是没有情绪，而是不允许自己在关系中显得需要、失败、软弱或亏欠。这个限制会决定他用直说、绕说、玩笑、行动还是沉默表达。

### 8. 对动机归属和选择归属的影响

先区分三件事：对方当时为什么这样做，主人公后来怎样解释，作者希望观众怎样评价。三者不能合并。没有原话、持续行为或后来证据时，不得把`他怕她不再唱、他想让她活下去`写成真实动机；这至多是人物为了继续相信他而采用的解释，也可能只是观众的一种猜测。

再检查人物后来的选择属于谁。主人公继续等待、停止等待、继续演出、反抗或赴死，必须由她当时面对的压力、能力和价值取舍推出。不能因为另一人物曾留下话语，就把她以后的人生写成执行他的安排。这样会把人物的主动性改成服从，也会把原本的怨、怀疑和冲突提前消解。

完成后，用一句普通话写出：

```text
这个事件对人物最残酷的地方，不是【表面结果】，而是它迫使他承认【身份、关系或需要上的事实】。
```

## 三、区分情绪层次，不堆情绪数量

### 1. 表层反应

人物现在最容易被看见的情绪，例如生气、平静、冷淡、兴奋或若无其事。它是入口，不一定是核心。

### 2. 核心需要受阻后的情绪

人物真正失去或无法获得的东西，例如安全、尊严、归属、回应、选择权、被需要的位置或自我解释的稳定性。

### 3. 被隐藏或不愿承认的情绪

人物不愿让对象看见的部分，例如求助、依赖、嫉妒、羞耻、害怕被替代、希望被挽留或对自己决定的后悔。

### 4. 继发情绪

人物如何评价自己的第一反应，例如因为害怕而愤怒，因为依赖而羞耻，因为舍不得而嘲讽自己。继发情绪往往比单纯悲伤更能形成独特声音。

### 5. 矛盾情绪

至少找出一组不能同时消除的拉扯，例如：

- 想离开，但希望对方追上来。
- 想照顾家人，但怨恨自己没有自己的生活。
- 想道歉，但不愿承认自己错得这么彻底。
- 想被看见，但一旦被看见又想恢复体面。
- 想保留记忆，但继续保留会阻止自己生活。

矛盾不能只写成“又爱又恨”。必须说明两种需要分别是什么、由什么事实触发、人物最后牺牲了哪一边。

不要求每首歌拥有多个情绪层。只保留能改变人物行动、关系和语言的层次，禁止为了显得复杂强行堆叠情绪。

## 四、从情绪推导身体、注意和行动

情绪必须产生可观察后果。至少选择一项身体变化、一项注意偏向和一项行动冲动；如果无法落到人物行为，说明情绪仍是标签。

### 身体变化

呼吸变浅、喉咙发紧、手停在半空、肩膀放松、胃部发沉、反复整理同一件东西、走到门口又折返，都比“心里很痛”更能说明人物处境。身体细节必须属于这个人和这个场景，不能调用通用痛苦动作库。

### 注意偏向

人物反复看向什么、避开什么、记住什么、听见什么？人在害怕失去回应时会注意手机是否亮起；人在维护体面时会注意桌面是否整齐，而不是直接注意自己的脆弱。

### 行动冲动

人物想靠近、逃离、追问、解释、删除、保留、归还、控制、报复、照顾还是假装无事。冲动和实际动作可以相反，反差必须有原因。

### 行动抑制

什么使人物没有按照冲动行动？时间、距离、身份、承诺、金钱、羞耻、法律、对象的沉默或他对后果的预判，都可以成为抑制条件。没有抑制，情绪就没有压力。

## 五、从防御方式推导说话方式

人物通常不会把自己的真实需要完整说出。先判断他怎样保护自己，再决定他在歌里能说到哪一步：

| 防御方式 | 可能的外在语言或动作 | 需要继续追问 |
| --- | --- | --- |
| 解释 | 不断讲道理、交代经过 | 他真正想让谁免于责怪 |
| 控制 | 命令、安排、提前结束 | 他害怕失去哪种控制 |
| 逃避 | 转移话题、只说物件和天气 | 哪句话一旦说出就会改变关系 |
| 玩笑 | 自嘲、夸张、故意轻描淡写 | 玩笑遮住的是求助、羞耻还是愤怒 |
| 体面 | 说“没关系”、主动祝福 | 他是否希望对方反驳这句话 |
| 反击 | 指责、讥讽、冷处理 | 他真正想要的是惩罚对方还是得到回应 |
| 讨好 | 先替对方找理由、承担责任 | 他用什么换取不被抛下 |
| 沉默 | 不解释、不告别、只留下动作 | 沉默是在保护谁，后果由谁承担 |

防御不是人物性格标签，而是他此刻为了保住某种身份或关系采取的策略。一个人可以在主歌里解释，在副歌里反击，在结尾终于承认自己其实想被挽留。

## 六、把情绪落实为关系动作

情绪真正进入歌词，必须改变人物对对象的动作。选择一个主语言动作：

- 承认：终于说出此前回避的事实。
- 请求：要求对象留下、回应、原谅、放手或允许自己离开。
- 质问：逼对象面对某个责任或矛盾。
- 保护：替对象隐瞒、承担或留出体面。
- 归还：把物件、身份、责任或过去的位置交回去。
- 拒绝：不再接受旧规则、旧称呼或旧关系。
- 决定：在知道代价后仍采取行动。
- 命名：替自己或一群人说出此前没有被准确说出的关系。

主语言动作只能有一个。其他情绪和动作围绕它服务，不能让副歌同时承担承认、劝告、升华、安慰和号召。

## 七、建立情绪运动，不只安排起伏

用普通话写出五个节点：

```text
起点：人物怎样解释自己和这段关系
触发：哪个事实让这种解释失效
压力：他想保住什么，却必须面对什么代价
动作：他做了什么，或为什么没有做
余波：事实是否改变；人物对事实的理解、关系位置或自我身份改变了什么
```

结尾不要求人物变得更积极、更成熟或更释怀。真实变化可以是承认无法挽回、停止替对方解释、允许自己继续怨、第一次接受帮助，或发现自己仍然没有答案但不再伪装有答案。

结尾同样不要求人物替另一方找到善意解释。`终于理解他`只有在新证据足以改变判断时成立；若证据仍允许背叛、失联、牺牲或隐瞒并存，就保留未解，并让主人公根据自己的价值作出决定。决定可以发生，真相仍可未知。

如果每个段落只是更换情绪词、景物或强度，情绪没有运动。返回副歌前必须新增事实、关系压力、行动后果或认识变化，才有资格改变中心句的含义。

## 八、情绪动力交付卡

```markdown
## 情绪动力卡

- 触发事件（可核对事实）：
- 人物原本期待：
- 事件对目标、身份、关系、控制、公平或不可逆性的影响：
- 人物的核心需要：
- 表层反应：
- 被隐藏或不愿承认的部分：
- 主要矛盾需要：
- 身体变化：
- 注意偏向：
- 行动冲动与行动抑制：
- 防御方式：
- 主语言动作：
- 起点 → 触发 → 压力 → 动作 → 余波：
- 哪个事实会让情绪判断失效：
- 尚需核实或不可确定的部分：
```

交付卡不要求每一项都填满。只保留会改变人物、关系、中心句、展开或歌手演唱可信度的内容；没有证据的部分标为假设，不用心理学术语掩盖猜测。

## 九、失效判定

- 先选“悲伤、治愈、热血”，再寻找场景替它证明。
- 把情绪数量多误认为情绪复杂。
- 只写人物感受，不写事件评价、需要、身体、行动和关系后果。
- 人物嘴上说一种情绪，行为却没有相反或对应的证据。
- 把防御方式误写成人物固定性格。
- 用“成长、释怀、放下”代替人物真正做出的选择。
- 结尾突然顿悟，前文没有事实、压力或动作积累。
- 用未经证明的善意动机取消主人公的怨、怀疑和责任追问。
- 把主人公后来作出的选择重写成完成另一人物的遗愿或安排。
- 任何人物都能套用同一套心理链，说明情绪没有长在当前人物身上。
- 为了显得深刻，强行增加创伤、秘密和复杂情绪，反而破坏人物可信度。
- 情绪卡写得完整，却不能解释为什么这首歌必须由这个人在此刻唱。

## 十、理论依据与使用边界

1. **事件评价与情绪过程**：Scherer 与 Moors 综述了事件评价如何先引发行动倾向、生理反应和表达，再进入有意识的感受与情绪命名。来源：[Annual Review of Psychology](https://doi.org/10.1146/annurev-psych-122216-011854)。
2. **音乐的心理功能**：Schäfer 等人的研究将音乐聆听功能归纳为情绪与唤醒调节、自我认识和社会联结等维度。来源：[Frontiers in Psychology](https://doi.org/10.3389/fpsyg.2013.00511)。
3. **音乐与自传记忆**：Janata 的研究观察到熟悉音乐能够唤起与自我相关的自传记忆。来源：[Cerebral Cortex](https://doi.org/10.1093/cercor/bhp008)。

这些研究只用于校准创作流程中的因果和提问方式，不能替代人物材料，也不能把任何心理模型当作歌词公式。心理链必须回到当前人物的事实、知识边界、文化环境和关系选择。
