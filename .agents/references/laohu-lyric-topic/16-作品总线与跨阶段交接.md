# 作品总线与跨阶段交接

> **本篇箴言：一线贯通，万象同归。** 总线不是故事摘要，而是让每个下游部门实现同一关系判断的最小充分输入。

## 什么时候读取

当一首歌需要从选题进入写词、谱曲、歌名、封面、MV、短视频或发布，或出现“每个局部都成立但整首歌不像同一件作品”的问题时读取。

本文件只规定作品总线怎样在选题阶段建立、怎样约束后续阶段。它不替写词、作曲、命名或视觉 Skill 处理各自的细节。

## 一、总线是什么

作品总线不是一句宣传语、主题标签、歌名初稿或管理员写给用户看的金句。它是整部作品的核心承诺：目标听众、使用场景、主要体验、文字与声音依据、不能改变的事实及验证条件。可从词或音乐进入。无人物叙事时，不填阻力、牺牲和转折；把呼吸、律动、音色、语言回环或参与方式写到可试验的程度。以下链条专用于人物选择主导的作品：

```text
听众先看见谁处在什么关系里
→ 哪件事实打破原来的秩序
→ 人物主动想保住或夺回什么
→ 哪个现实阻力让他不能用普通办法解决
→ 信息怎样逐段改变人物和听众的判断
→ 人物最后亲手做出什么不可逆选择
→ 这个选择让开头的关系、意象、中心句和歌名怎样重新变义
→ 听众离开歌曲时，比进来时多承受或多看见什么
```

人物选择路线缺少事实、阻力、选择和后果，需要补基础；非戏剧路线缺少具体体验、材料和声音组织，也需补基础。仅有“伤感、宏大、电影感、容易传播”均不算总线。

总线必须用普通话写成一段可以复述的因果，不靠“残留、命运、时差、归属、救赎、善后、身份改写”等宽词把多层意思糊在一起。先把人物、动作、对象、时间和代价说清，再决定是否需要一句更短的命题。

### 总线五层不得折叠

以高压选择或强反转为核心的作品，必须把五层分别写清，任何一层都不能冒充另一层：

```text
现实压力：时代、制度、关系或处境改变了什么生活规则
→ 核心矛盾：人物不能同时保住哪两种价值、关系或身份
→ 阶段任务：人物在中段具体寻找、等待、逃离、求证或完成什么
→ 不可逆选择：最高压力下人物亲手决定什么，并永久失去哪条退路
→ 开放变量：人物作出决定后，哪些真相仍可留给听众竞争解释
```

阶段任务负责推动故事，不自动成为作品命题。`一路寻人、等待来信、寻找答案、继续演出`可以是持续行动；若结尾仍只是继续原动作，没有新代价、身份变化和失去的退路，它不是人物弧光。副歌核心句负责一次主要语言动作，也不自动成为整首作品的最终价值答案；它必须继续接受桥段、结尾和不可逆选择的反证。

开放只允许留在真相、动机、归来、生死或误解等指定变量上。人物可以不知道全部真相，但必须依据当时知道的事实作出清楚选择；`真相不明 + 人物继续原地做同一件事`判为没有结局，不得包装成克制、多义或留白。

## 二、选题阶段必须定下的总线卡

总线卡随探索逐步形成；未知写成假设或待验证，不填假事实。通用记录为目标听者与用途、主要体验、材料及声音依据、展开或持续方式、保护项、状态与验证。下面的扩展卡用于人物选择路线，只填适用字段；已有完整作品可从成品提取，不要求重走审批：

```markdown
## 作品总线卡

- 故事背景与当前场景：人物来自怎样的时代、地点和关系；歌曲开口时具体发生什么
- 故事母体与歌词取材：完整故事怎样发展；哪些事实进入歌词，哪些只供作者理解人物与世界
- 情绪因果：触发事件是什么；人物怎样解释；它威胁什么需要；身体、防御、关系动作和情绪怎样变化
- 作品思考：故事引出什么疑问、认识或价值冲突；这项思考由哪组事实推出
- 核心不可替代变化：人物从什么状态变成什么状态；变化由哪件事实或选择造成
- 主矛盾：人物必须在两种不能同时保住的东西之间选什么
- 歌者与对象：谁在什么时刻唱给谁听；旁听者是谁；谁知道什么
- 主动目标：人物现在主动想完成什么，不做什么会失去什么
- 阶段任务边界：人物中段反复做什么；它为什么只是推进手段而不是作品最终答案
- 现实阻力：制度、距离、身份、时间、责任、身体或他人的选择怎样限制行动
- 关键证据：至少三项会改变人物判断的具体事实、动作、原话或物理变化
- 信息与高潮顺序：听众先知道什么，哪项证据延后，哪些材料必须重复，重复后怎样变义；高潮是否前置，前置发生在歌曲、影像还是两者
- 不可逆选择：人物最后亲手做什么；选择付出什么代价；为何不能被一句感悟抹平
- 开放变量边界：哪项真相允许不说死；人物自己的决定与后果为什么不能一起悬置
- 核心意象：为什么只有这个人物会注意它；它在开头、中段、结尾分别发生什么变化
- 语言动作：副歌主要承认、质问、请求、命名还是决定；对象和后果是什么
- 歌名初稿承诺：听前让人预期什么；听后凭哪项事实获得第二层意思；目前缺什么歌词或声音证据
- 声音承诺：旋律、节奏、音域、配器或演唱怎样让这次变化被听见；当前只锁定哪些声音职务，哪些曲式判断仍需旋律、时长或歌手条件验证
- 视觉与传播承诺：第一眼展示什么异常关系；暂时隐瞒什么；听众为什么继续看、听、转述或跟唱
- 主动舍弃：为了保护总线，明确不写哪条诱人但会分散作品的路线
- 最大风险：最可能在哪个阶段被改成另一首歌；发现什么就必须回流选题
- 现实契约：写实、历史传奇、戏曲传奇、神话、寓言或商业类型；核实标准服从哪一种契约
- 不可降级资产：用户明确要求保留的强冲突、极端行动、高压现场、竞争解释、代价等级和结尾余震
- 冲突强度承诺：作品必须让听众承受什么不能同时满足的价值冲突；不得用什么安全答案替代
- 竞争解释矩阵：每种结局解释由哪些前置事实支持；人物知道什么；听众还能怀疑什么
- 结尾余震：最后一个行动留下的现实后果、关系后果和听众疑问；不能只留下情绪氛围
- 安全化禁令：哪些“合理化、克制化、和解化”会把本作改成另一首歌
- 原始资产损失账：相对用户原始材料，本路线删除、降级或改写了哪些冲突、主动行动、代价、传播画面与结尾余震；谁确认承担这些损失
- 写词前成熟度：歌名初稿、副歌语言动作、hook 候选、演唱视角、曲风、歌词信息结构、暂定音乐曲式、情绪曲线和音乐能量假设分别处于`待探索 / 候选 / 用户确认 / 待声音验证`哪一状态
- 歌词雏形板：已验证的副歌试验、各段职务、段落锚点、连接关系、副歌变体、硬锚、软锚、淘汰句和开放项怎样共同形成初稿输入
- 抒情空间卡：表面命题、承重词、未封口处、人物不说破的原因、两条回收路径、必须排除的解释和结尾回收方式
```

核心不可替代变化只能有一条。可以有多层意义，但不能有两条互不服从的主线。家国、职业、爱情、战争、成长和传播不是并列主题；它们必须说明哪一项改变了人物的选择，其他项怎样服务这次改变。

## 三、总线的建立程序

1. 先从用户材料、对标文本和可靠资料中找出具体事实，不先写抽象结论。
2. 为同一事实列出竞争解释，区分文本已经证明的内容、人物的误读和管理员的创作假设。
3. 生成近距、中距、远距或反向路线；每条路线都必须改变人物事实、现实规则、冲突对象、信息差、结尾选择中的至少两项。
4. 逐条跑完整首歌：如果主歌只能列背景，副歌只能喊主题，桥段只能送来事故，路线淘汰。
5. 比较每条路线的艺术收益、首听成本、制作成本、传播入口、作品寿命、相似风险和失败方式，不用“高级”替代取舍。
6. 选题主持人给出主推荐与改判条件。用户决定真实经历、授权设定和最终审美；用户不负责从一堆未淘汰的普通方案里替管理员找好作品。
7. 用户确认后锁定总线卡；后续阶段只允许翻译、放大、验证或提出回流，不得悄悄换主矛盾。
8. 若用户已经锁定强冲突或结尾，先锁定其戏剧资产，再讨论可信度和实现细节。任何替代方案都必须逐项证明没有降低冲突方向、人物主动性、价值对撞、代价等级、不可逆性、结尾余震和传播画面；证明不了就不能替换。
8a. 用户后来修正某个局部动作、称呼、受话对象或副歌表达时，只改对应层。`她不是逼他回来，而是想知道消息`只能修正寻人阶段的行动目的，不能自动删除时代冲突、最后行动和结尾代价。局部决定若会推翻总线，必须公开写出改变、收益、损失与重做范围，由用户明确确认后才生效。
9. 选题阶段只锁定信息顺序、重复任务、高潮位置和不可降级的结构资产，不默认指定标准流行曲式。需要主歌、预副歌、副歌、桥段或其他形式，由写词与谱曲 Skill 在歌词容量和音乐条件下比较后裁决。
10. 选题交接前区分路线标签、歌名初稿与正式歌名，也区分副歌语言动作与具体核心句、歌词信息结构与音乐曲式、人物情绪曲线与音乐能量曲线。歌名初稿可以在写词前确认，但必须已经像歌名；正式歌名与其他下游锁定结果必须由对应产物反证。

## 四、从构思讨论形成歌词雏形

### 创作记录与歌词输入必须分轨

选题讨论可以使用故事、时间线、因果、历史背景和完整分析，因为这些内容帮助创作者理解作品世界；但它们不能直接成为歌词生成输入。正式作品采用三轨记录：

```text
创作日志：记录当前状态、用户决定、开放变量、阶段门槛和最近变更
歌词创作台：记录能直接约束写词的灵魂、筋骨、血肉和表皮材料
创作档案：保存完整讨论、失败版本、争论和复盘，只供追溯
```

三轨不是把同一段话复制三遍，而是同一轮创作结果的三种不同表示：

| 记录位置 | 记录什么 | 禁止记录什么 | 读取者 |
| --- | --- | --- | --- |
| 创作日志 | 决定、状态、依赖、下一门槛 | 连续故事、歌词解释、长篇争论 | 总监与所有阶段 |
| 歌词创作台 | 四层歌词输入、硬锚、软锚、淘汰项、声音假设 | 作者自辩、完整剧情、未转译的时间线 | 写词 Skill |
| 创作档案 | 对话、失败原因、路线比较、审议证据 | 把历史候选伪装成当前决定 | 复盘与规则进化 |

每轮有效交流只产生一条结构化变更：

```text
本轮主层 → 联动层 → 保护项 → 实际产物 → 对下游的影响 → 下一门槛
```

四层可以在任何阶段被局部触碰，但阶段仍有主层重心：

| 阶段 | 主层 | 联动方式 | 交付禁止 |
| --- | --- | --- | --- |
| 选题与总线 | 灵魂 | 用筋骨确定运动，用血肉和表皮做局部可唱性试验 | 不把故事大纲直接当歌词初稿 |
| 构思与雏形 | 筋骨 | 用核心句、触点和声音句架验证结构 | 不把局部金句扩写成未经确认的整首歌 |
| 完整初稿 | 血肉 + 表皮 | 在已锁定灵魂和筋骨内完成全部正文 | 不重新猜主线，不把解释稿写进歌词 |
| 精修与回填 | 表皮 | 逐句回看血肉、筋骨和灵魂 | 不用换词掩盖上层失配 |

这张表是职责重心，不是阶段隔离。选题阶段可以写一句副歌，写词阶段也可以发现新的总线问题；一旦发现上层问题，必须回流，不得在低层继续修补。

### 从讨论语言转成歌词语言

把任何叙事性讨论交给写词 Skill 前，必须完成一次转译：

```text
“后来发生了什么” → 必要事实边界
“人物因此怎样” → 关系动作或情绪状态变化
“某个场景很有画面” → 抒情触点及其物理动作
“这里要更有韵律” → 声音句架、重音、韵脚或气口假设
```

如果一条记录仍然主要由“后来、然后、于是、最后”连接，说明它仍是创作档案语言，不能直接填入主歌。写词者必须先回答人物向谁开口、完成什么语言动作，以及只保留哪一处触点。

总线确认以后，不立刻让模型从空白一次生成完整歌词。先进入渐进式构思：人物事实、核心句、副歌、主歌场景、预副歌门槛、曲式、歌名和声音假设可以交叉试写，并在讨论中互相反证。灵感出现的先后不固定，但每次新发现都必须回答它改变了哪项总线、哪一段职务和哪项后续选择。

渐进式构思不是把故事拆成很多轮空谈。每轮围绕一个决定性问题形成最小闭环：

```text
提出当前问题
→ 调用对应 Skill 产生真实候选
→ 把候选放回人物、段落和声音中试验
→ 淘汰不能兑现总线的版本
→ 与用户确认保留什么、为什么
→ 更新歌词雏形板和下一项最受影响的问题
```

《歌词雏形板》至少记录：

| 项目 | 必须写清 | 状态 |
| --- | --- | --- |
| 总体 | 总线、歌者、对象、歌名初稿、暂定结构 | 硬约束 / 候选 / 待验证 |
| 副歌 | 一至两行核心单位、短 hook、当前成熟状态；核心确认后才增加四至八行副歌试验和完整声音骨架 | 硬锚 / 软锚 / 淘汰 / 待用户裁决 |
| 回归 | 第一次、第二次、最后一次副歌前新增或改变的情绪、关系、声音、事实及变词位置 | 已确认 / 待试唱 |
| 各乐段 | 进入前已知、情绪或关系压力怎样变化、必要事实、离开时为何必须进入下一段 | 已确认 / 待补材料 |
| 段落锚点 | 能验证人物、场景、转折或声音的一至两句歌词 | 硬锚 / 软锚 / 淘汰 |
| 连接 | 主歌怎样逼出副歌；预副歌为何存在或为何删除 | 已确认 / 待旋律验证 |
| 声音 | 暂定词组、韵脚、重音、气口、节奏密度和能量变化 | 文字侧假设 / 已试唱 |
| 风险 | 哪句正在绑架整体，哪项事实尚会推翻结构 | 必须回流 / 可后补 |

当作品要求留白或国风抒情时，《歌词雏形板》还必须附《抒情空间卡》和关键句的《句级因果账本》。选题阶段交付留白方向与分配，写词阶段交付具体字词如何实现它；不能只在两个阶段重复“含蓄、诗性、有想象空间”。

状态必须有实际含义：

- **硬锚**：用户明确要求保留，或已经成为作品身份；整体冲突时先说明代价，不得静默修改。
- **软锚**：当前最强写法，可以在完整初稿中为人物、声音和整体连贯主动重写。
- **淘汰**：记录母义与失败原因，防止后续换几个近义词重新生成。
- **方向说明**：只供写词者理解，不得直接粘进歌词正文。

局部试写有两个相反风险，必须同时防：一是只分析不创作，讨论没有留下任何可用歌词；二是过早迷恋局部金句，让整首歌为几句尚未经过整体和旋律验证的文字让路。每保留一个锚点，都要做两次检查：删掉它，总线是否仍成立；保留它，其他段落是否被迫凑故事、凑韵或重复解释。前者失败说明总线可能空，后者失败说明锚点正在绑架作品。

以持续发展的人物选择为中心时，副歌核心句再做“终点越权检查”；稳定陪伴或律动以体验持续与回接验收，不要求更大冲突：它最准确地完成了人物哪一次承认、质问、请求或决定；它说完以后，人物是否仍有更大的价值冲突和现实选择没有处理。若全歌只是不断增加证据来证明同一句话，而人物的目标、代价和行动没有改变，核心句已经从记忆中心越权成创作天花板，必须重建桥段、结尾或重新裁决总线，不能让整首歌为局部金句作注释。

进入整稿采用与锁定时，不以“每段都有漂亮句”代替整体。探索初稿允许标签与结构暂定，以实际段落反证；下列为副歌驱动的关系路线整稿检查：标签序列和段落职务已经明确；副歌驱动作品有可评审的核心句、短 hook 和副歌试验；主歌有足够的关系证据和声音压力把副歌逼出来；预副歌有明确保留或删除理由；各次回归有清楚的保持、累积或变化职务；关系变义路线检查新情绪、关系、声音或事实；剩余开放项不会立刻改写人物、主矛盾和结尾。达到门槛后，写词 Skill 必须从雏形板生成整首初稿，不得重新从通用歌词分布起笔。

## 五、下游怎样服从总线

每个阶段交付时都必须回答“我怎样实现总线”，而不是重新写一份自己的主题：

| 阶段 | 只负责把总线转成什么 | 失配时怎样处理 |
| --- | --- | --- |
| 写词 | 必要事实的显露时机、人物口吻、段落职务、中心句、意象变义、重音与气口 | 抒情模式下不得把事实顺序当主歌骨架；句子写不出来时先查关系母句、声音句架和段落，不用换主题救场；主矛盾或结尾变了，回流选题 |
| 谱曲 | 旋律动机、曲式、节奏、和声、音域、配器和演唱的情绪运动 | 音乐只剩气氛、高潮与选择错位，回到总线重新分配段落，不用升调或堆音色遮盖 |
| 歌名 | 把总线压成准确、可记、听后兑现的入口（可变义或保持稳定体验） | 点击感与作品归属冲突时保归属；不能让标题绑架歌词去迎合名字 |
| 封面与 MV | 按用途选择叙事关系、人物识别、字体记忆或声音气质 | 叙事查动作与悬念；肖像、纯字体和抽象查身份、声音对应、文字和规格，不补造情节 |
| 传播 | 选择最早兑现总线承诺的片段、声音动作和使用场景 | 传播句脱离全曲也成立、或提前泄露答案，回查总线和信息差 |

下游可以提出新发现，但新发现如果改变人物关系、主矛盾、不可逆选择或最后判断，就不是局部优化，而是选题变更。必须明确写出：改变什么、换来什么、牺牲什么、哪些已有内容需要重做，并由用户确认。

## 六、总线验收

每次阶段交接先按当前路径与产物状态选适用检查。关系、选择与变义项用于人物戏剧；感知、律动和纯器乐以可感体验、记忆、持续和回接替代；纯字体封面不做删标题见人物测试：

- 删除歌名，歌词、旋律和视觉仍然在讲同一件事；若不能，歌名不是命名，是另起主题。
- 删除某个漂亮意象，主矛盾仍能被事实和动作证明；若不能，意象在替空题遮羞。
- 只听副歌，能听出人物要对谁完成什么语言动作；只看主歌，能看见副歌为什么非这样说不可。
- 旋律最高点、歌词重音、视觉高潮和传播切片没有各自争抢不同的情绪结论。
- 关系改判路线的最后回归须让后果被听见；稳定、循环和律动路线验证保持、累积或释放是否有效，不强制新事实或不可逆选择。
- 听众第一次能进入，复听能回看；深度来自前后关系，不来自必须解释的含混词。
- 总线中的每个主要词都能还原到人物、动作、对象、时间或代价；不能还原的词删除。
- 用户明确锁定的强冲突仍然存在；没有被改写成“理解、释怀、继续生活”或其他默认安全答案。
- 作品的现实契约已经写清；没有用不相称的写实标准削掉传奇性，也没有用传奇性掩盖没有准备的事故。
- 最后结尾保留了原设定要求的危险等级和竞争解释；人物是行动者，不只是收到消息的人。

任一适用项失败，都先判断是总线失效、下游转译失效还是制作执行失效。总线失效回选题；转译失效回对应 Skill；执行失效回写词、谱曲、视觉或传播制作。禁止用“再润色一下”跨过责任归因。

## 七、反向压力测试

至少用一个叙事型强冲突题和一个私人抒情题测试总线。强冲突题必须检查：时代或制度是否真正改变私人选择，人物是否主动行动，反转是否有前置证据，结尾是否留下行动后果。私人抒情题必须检查：没有宏大背景时，单个动作、原话或物件是否足以改变关系。若两类作品最后都只得到“表达痛苦、获得成长、让人共鸣”，总线规则没有执行，回到材料和因果。
