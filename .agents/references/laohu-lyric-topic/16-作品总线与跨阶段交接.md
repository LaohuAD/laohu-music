# 作品总线与跨阶段交接

## 什么时候读取

当一首歌需要从选题进入写词、谱曲、歌名、封面、MV、短视频或发布，或出现“每个局部都成立但整首歌不像同一件作品”的问题时读取。

本文件只规定作品总线怎样在选题阶段建立、怎样约束后续阶段。它不替写词、作曲、命名或视觉 Skill 处理各自的细节。

## 一、总线是什么

作品总线不是一句宣传语、主题标签、工作歌名或管理员写给用户看的金句。它是选题阶段对整部作品作出的唯一核心承诺：

```text
听众先看见谁处在什么关系里
→ 哪件事实打破原来的秩序
→ 人物主动想保住或夺回什么
→ 哪个现实阻力让他不能用普通办法解决
→ 信息怎样逐段改变人物和听众的判断
→ 人物最后亲手做出什么不可逆选择
→ 这个选择让开头的关系、意象、中心句和歌名怎样重新变义
→ 听众离开歌曲时，比进来时多承受或多看见什么
```

没有“谁、什么事实、什么阻力、什么选择、什么后果”，只有“伤感、宏大、电影感、容易传播”，不算总线。

总线必须用普通话写成一段可以复述的因果，不靠“残留、命运、时差、归属、救赎、善后、身份改写”等宽词把多层意思糊在一起。先把人物、动作、对象、时间和代价说清，再决定是否需要一句更短的命题。

## 二、选题阶段必须定下的总线卡

选题主持人必须在路线裁决前建立总线卡。以下字段不是表格装饰，每项都要能改变后续创作：

```markdown
## 作品总线卡

- 故事背景与当前场景：人物来自怎样的时代、地点和关系；歌曲开口时具体发生什么
- 故事母体与歌词取材：完整故事怎样发展；哪些事实进入歌词，哪些只供作者理解人物与世界
- 情绪因果：触发事件是什么；人物怎样解释；它威胁什么需要；身体、防御、关系动作和情绪怎样变化
- 作品思考：故事引出什么疑问、认识或价值冲突；这项思考由哪组事实推出
- 核心不可替代变化：人物从什么状态变成什么状态；变化由哪件事实或选择造成
- 主矛盾：人物必须在两种不能同时保住的东西之间选什么
- 歌者与对象：谁在什么时刻唱给谁听；旁听者是谁；谁知道什么
- 主动目标：人物现在主动想完成什么，不做什么会失去什么
- 现实阻力：制度、距离、身份、时间、责任、身体或他人的选择怎样限制行动
- 关键证据：至少三项会改变人物判断的具体事实、动作、原话或物理变化
- 信息与高潮顺序：听众先知道什么，哪项证据延后，哪些材料必须重复，重复后怎样变义；高潮是否前置，前置发生在歌曲、影像还是两者
- 不可逆选择：人物最后亲手做什么；选择付出什么代价；为何不能被一句感悟抹平
- 核心意象：为什么只有这个人物会注意它；它在开头、中段、结尾分别发生什么变化
- 语言动作：副歌主要承认、质问、请求、命名还是决定；对象和后果是什么
- 工作歌名承诺：听前让人预期什么；听后凭哪项事实获得第二层意思
- 声音承诺：旋律、节奏、音域、配器或演唱怎样让这次变化被听见；当前只锁定哪些声音职务，哪些曲式判断仍需旋律、时长或歌手条件验证
- 视觉与传播承诺：第一眼展示什么异常关系；暂时隐瞒什么；听众为什么继续看、听、转述或跟唱
- 主动舍弃：为了保护总线，明确不写哪条诱人但会分散作品的路线
- 最大风险：最可能在哪个阶段被改成另一首歌；发现什么就必须回流选题
- 现实契约：写实、历史传奇、戏曲传奇、神话、寓言或商业类型；核实标准服从哪一种契约
- 不可降级资产：用户明确要求保留的强冲突、极端行动、高压现场、竞争解释、代价等级和结尾余震
- 冲突强度承诺：作品必须让听众承受什么不能同时满足的价值冲突；不得用什么安全答案替代
- 竞争解释矩阵：每种结局解释由哪些前置事实支持；人物知道什么；听众还能怀疑什么
- 结尾余震：最后一个行动留下的现实后果、关系后果和听众疑问；不能只留下情绪氛围
- 安全化禁令：哪些“合理化、克制化、和解化”会把本作改成另一首歌
- 写词前成熟度：工作歌名、副歌语言动作、hook 候选、演唱视角、曲风、歌词信息结构、暂定音乐曲式、情绪曲线和音乐能量假设分别处于`待探索 / 候选 / 用户确认 / 待声音验证`哪一状态
- 歌词雏形板：已验证的副歌试验、各段职务、段落锚点、连接关系、副歌变体、硬锚、软锚、淘汰句和开放项怎样共同形成初稿输入
```

核心不可替代变化只能有一条。可以有多层意义，但不能有两条互不服从的主线。家国、职业、爱情、战争、成长和传播不是并列主题；它们必须说明哪一项改变了人物的选择，其他项怎样服务这次改变。

## 三、总线的建立程序

1. 先从用户材料、对标文本和可靠资料中找出具体事实，不先写抽象结论。
2. 为同一事实列出竞争解释，区分文本已经证明的内容、人物的误读和管理员的创作假设。
3. 生成近距、中距、远距或反向路线；每条路线都必须改变人物事实、现实规则、冲突对象、信息差、结尾选择中的至少两项。
4. 逐条跑完整首歌：如果主歌只能列背景，副歌只能喊主题，桥段只能送来事故，路线淘汰。
5. 比较每条路线的艺术收益、首听成本、制作成本、传播入口、作品寿命、相似风险和失败方式，不用“高级”替代取舍。
6. 选题主持人给出主推荐与改判条件。用户决定真实经历、授权设定和最终审美；用户不负责从一堆未淘汰的普通方案里替管理员找好作品。
7. 用户确认后锁定总线卡；后续阶段只允许翻译、放大、验证或提出回流，不得悄悄换主矛盾。
8. 若用户已经锁定强冲突或结尾，先锁定其戏剧资产，再讨论可信度和实现细节。任何替代方案都必须逐项证明没有降低冲突方向、人物主动性、价值对撞、代价等级、不可逆性、结尾余震和传播画面；证明不了就不能替换。
9. 选题阶段只锁定信息顺序、重复任务、高潮位置和不可降级的结构资产，不默认指定标准流行曲式。需要主歌、预副歌、副歌、桥段或其他形式，由写词与谱曲 Skill 在歌词容量和音乐条件下比较后裁决。
10. 选题交接前区分工作歌名与正式歌名、副歌语言动作与具体核心句、歌词信息结构与音乐曲式、人物情绪曲线与音乐能量曲线。前者可以在写词前确认，后者必须由对应下游产物反证。

## 四、从构思讨论形成歌词雏形

总线确认以后，不立刻让模型从空白一次生成完整歌词。先进入渐进式构思：人物事实、核心句、副歌、主歌场景、预副歌门槛、曲式、歌名和声音假设可以交叉试写，并在讨论中互相反证。灵感出现的先后不固定，但每次新发现都必须回答它改变了哪项总线、哪一段职务和哪项后续选择。

渐进式构思不是把故事拆成很多轮空谈。每轮围绕一个决定性问题形成最小闭环：

```text
提出当前问题
→ 调用对应 Skill 产生真实候选
→ 把候选放回人物、段落和声音中试验
→ 淘汰不能兑现总线的版本
→ 与用户确认保留什么、为什么
→ 更新歌词雏形板和下一项最受影响的问题
```

《歌词雏形板》至少记录：

| 项目 | 必须写清 | 状态 |
| --- | --- | --- |
| 总体 | 总线、歌者、对象、工作歌名、暂定结构 | 硬约束 / 候选 / 待验证 |
| 副歌 | 一至两行核心单位、短 hook、当前成熟状态；核心确认后才增加四至八行副歌试验和完整声音骨架 | 硬锚 / 软锚 / 淘汰 / 待用户裁决 |
| 回归 | 第一次、第二次、最后一次副歌前新增事实及变词位置 | 已确认 / 待试唱 |
| 各乐段 | 进入前已知、新增事实或压力、离开时为何必须进入下一段 | 已确认 / 待补材料 |
| 段落锚点 | 能验证人物、场景、转折或声音的一至两句歌词 | 硬锚 / 软锚 / 淘汰 |
| 连接 | 主歌怎样逼出副歌；预副歌为何存在或为何删除 | 已确认 / 待旋律验证 |
| 声音 | 暂定词组、韵脚、重音、气口、节奏密度和能量变化 | 文字侧假设 / 已试唱 |
| 风险 | 哪句正在绑架整体，哪项事实尚会推翻结构 | 必须回流 / 可后补 |

状态必须有实际含义：

- **硬锚**：用户明确要求保留，或已经成为作品身份；整体冲突时先说明代价，不得静默修改。
- **软锚**：当前最强写法，可以在完整初稿中为人物、声音和整体连贯主动重写。
- **淘汰**：记录母义与失败原因，防止后续换几个近义词重新生成。
- **方向说明**：只供写词者理解，不得直接粘进歌词正文。

局部试写有两个相反风险，必须同时防：一是只分析不创作，讨论没有留下任何可用歌词；二是过早迷恋局部金句，让整首歌为几句尚未经过整体和旋律验证的文字让路。每保留一个锚点，都要做两次检查：删掉它，总线是否仍成立；保留它，其他段落是否被迫凑故事、凑韵或重复解释。前者失败说明总线可能空，后者失败说明锚点正在绑架作品。

进入完整初稿的最低门槛不是“每段都有漂亮句”，而是：标签序列和段落职务已经明确；副歌驱动作品有可评审的核心句、短 hook 和副歌试验；主歌有足够事实把副歌逼出来；预副歌有明确保留或删除理由；各次回归有新增事实与变义；剩余开放项不会立刻改写人物、主矛盾和结尾。达到门槛后，写词 Skill 必须从雏形板生成整首初稿，不得重新从通用歌词分布起笔。

## 五、下游怎样服从总线

每个阶段交付时都必须回答“我怎样实现总线”，而不是重新写一份自己的主题：

| 阶段 | 只负责把总线转成什么 | 失配时怎样处理 |
| --- | --- | --- |
| 写词 | 事实顺序、人物口吻、段落职务、中心句、意象变义、重音与气口 | 句子写不出来时先查材料和段落，不用换主题救场；主矛盾或结尾变了，回流选题 |
| 谱曲 | 旋律动机、曲式、节奏、和声、音域、配器和演唱的情绪运动 | 音乐只剩气氛、高潮与选择错位，回到总线重新分配段落，不用升调或堆音色遮盖 |
| 歌名 | 把总线压成一个准确、可记、听后增义的入口 | 点击感与作品归属冲突时保归属；不能让标题绑架歌词去迎合名字 |
| 封面与 MV | 把总线的异常关系、人物动作和悬念变成第一眼可见的画面 | 只有古风、悲伤、战争等气氛而看不出人物目的，回到总线，不加装饰补救 |
| 传播 | 选择最早兑现总线承诺的片段、声音动作和使用场景 | 传播句脱离全曲也成立、或提前泄露答案，回查总线和信息差 |

下游可以提出新发现，但新发现如果改变人物关系、主矛盾、不可逆选择或最后判断，就不是局部优化，而是选题变更。必须明确写出：改变什么、换来什么、牺牲什么、哪些已有内容需要重做，并由用户确认。

## 六、总线验收

每次阶段交接前做以下检查：

- 删除歌名，歌词、旋律和视觉仍然在讲同一件事；若不能，歌名不是命名，是另起主题。
- 删除某个漂亮意象，主矛盾仍能被事实和动作证明；若不能，意象在替空题遮羞。
- 只听副歌，能听出人物要对谁完成什么语言动作；只看主歌，能看见副歌为什么非这样说不可。
- 旋律最高点、歌词重音、视觉高潮和传播切片没有各自争抢不同的情绪结论。
- 最后一次副歌不是第一遍的音量放大，而是因新事实或不可逆选择改变了重量。
- 听众第一次能进入，复听能回看；深度来自前后关系，不来自必须解释的含混词。
- 总线中的每个主要词都能还原到人物、动作、对象、时间或代价；不能还原的词删除。
- 用户明确锁定的强冲突仍然存在；没有被改写成“理解、释怀、继续生活”或其他默认安全答案。
- 作品的现实契约已经写清；没有用不相称的写实标准削掉传奇性，也没有用传奇性掩盖没有准备的事故。
- 最后结尾保留了原设定要求的危险等级和竞争解释；人物是行动者，不只是收到消息的人。

任何一项失败，都先判断是总线失效、下游转译失效还是制作执行失效。总线失效回选题；转译失效回对应 Skill；执行失效回写词、谱曲、视觉或传播制作。禁止用“再润色一下”跨过责任归因。

## 七、反向压力测试

至少用一个叙事型强冲突题和一个私人抒情题测试总线。强冲突题必须检查：时代或制度是否真正改变私人选择，人物是否主动行动，反转是否有前置证据，结尾是否留下行动后果。私人抒情题必须检查：没有宏大背景时，单个动作、原话或物件是否足以改变关系。若两类作品最后都只得到“表达痛苦、获得成长、让人共鸣”，总线规则没有执行，回到材料和因果。
