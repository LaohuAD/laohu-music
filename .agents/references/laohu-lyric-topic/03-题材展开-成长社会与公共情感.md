# 题材展开：成长、社会与公共情感

## 核心原则

先找一个人正在承担的现实，再从他的选择中推出公共意义。不得先写正确结论，再找人物证明。

公共性必须让听众从具体处境中认出自己的利益、尊严、责任或共同命运。声音大不构成公共性。

本文件列出的困难、成长节点、职业关系和材料入口既用于设计调查，也用于提出研究型路线，不是可直接领取的故事库。没有当前人物的亲历、可靠讲述或具体个案证据时，可以根据代表作品、行业资料和明确虚构前提比较人物关系、段落结构、修辞与声音方向；必须标明哪些是创作假设。不得把独居老人、孩子学费、父母电话、差评、超时、病人餐、万家灯火等职业高频联想拼成仿真经历。行业常识可以启发问题和路线，不能证明某个骑手真实经历过什么。

## 一、励志豪情

### 先回答“在对抗什么”

- 具体困难：贫穷、疾病、失败、歧视、技能不足、时间限制或外部阻力。
- 内部困难：害怕再次失败、依赖认可、自我怀疑、羞耻或旧习惯。
- 结构性困难：个人努力不能单独解决的制度、资源和机会差异。

先分清人物能改变什么、必须承认什么。不得把所有失败归因于不够努力。

### 可写的成长节点

- 还没成功，但第一次停止自我欺骗。
- 失败后重新定义成功，而不是喊着重来。
- 明知胜算不高，仍决定完成一件有尊严的事。
- 从独自硬撑转为接受帮助。
- 从证明给别人看，转为对自己的承诺负责。
- 得到结果后发现代价，并重新选择。

### 材料入口

训练动作、工作失败、身体反应、账单、时间表、被拒绝的具体场面、一次很小却可验证的进步。

### 常见失效

- 风雨、翅膀、梦想、远方、光芒等词连续出现，却不知道主人公在做什么。
- 把成功者结论塞给尚未走出困境的人。
- 用情绪强度代替困难强度。
- 承诺“只要坚持一定成功”，抹掉现实条件。

### 验收

听众能否说出主人公下一步要做的具体动作，以及他为什么仍可能失败？

## 二、世故人情与人生感悟

人生道理必须由人物付出的代价推出。作者不得直接宣布。

### 可选择的经验来源

- 好心造成了坏结果。
- 讲原则的人在自身利益前改变标准。
- 一个人终于理解父母、朋友或旧对手当年的选择。
- 得到想要的东西后，发现失去的更重要。
- 曾经嘲笑的生活，后来成为自己的处境。
- 一次小便宜暴露长期关系中的不公平。
- 原以为是软弱的行为，后来发现是克制；原以为是善良，后来发现是逃避冲突。

### 判断路径

```text
人物原先相信什么
→ 哪件事实使旧解释失效
→ 他付出了什么代价
→ 新理解解决了什么，又留下什么
```

### 常见失效

- 每句都是可单独转发的道理，人物不存在。
- 用“人心、现实、社会、生活”概括复杂关系。
- 把犬儒、冷漠和算计写成看透人生。
- 结尾把所有矛盾解释圆，没有余味和边界。

### 验收

这条道理是否只能由经历了这件事的人说出？换个案例是否仍然原封不动？

## 三、时代题材

把宏观变化写进普通人的时间、身体、家庭和选择。新闻标题不构成时代题材。

### 选择观察位置

- 亲历变化的人。
- 被新制度或新技术帮助的人。
- 因变化失去旧技能、旧位置或旧关系的人。
- 站在重大事件边缘、承担普通工作的人。
- 事件之后多年回望的人。
- 尚未出生、通过家庭记忆理解时代的人。

### 材料入口

交通时间缩短、职业消失、沟通方式改变、家庭成员迁移、公共空间变化、生活价格、工具更新、旧称谓不再使用、一个普通岗位在重大事件中的具体责任。

### 时效判断

区分即时响应、周年纪念和长期历史表达。即时作品可以依赖当下语境；长期作品必须从事件名称中提炼仍能被后来者理解的人物关系。

### 常见失效

- 按时间顺序罗列成果和事件。
- 用“新时代、新征程、谱华章”替代变化对人的影响。
- 只写胜利者和代表人物，普通人的代价被删除。
- 为追求宏大，主人公没有私人欲望和生活。

### 验收

删掉事件名称后，是否仍能看出这个时代具体改变了人的什么生活？

## 四、爱国题材

爱国可以是归属、责任、保护、批评、守护文化、承担公共风险和普通生活中的职业选择，不只是一种赞美语气。

### 可选择的关系

- 个人与故土、语言、文化和共同记忆。
- 远行者与身份归属。
- 普通岗位与公共责任。
- 家庭命运与国家历史的交叉。
- 面对灾害、战争或危机时的具体选择。
- 对国家有深厚感情，因此不回避现实问题。

### 材料入口

护照与回程、母语、边界、公共服务、家族历史、职业纪律、被保护的日常、需要共同承担的具体后果。

### 常见失效

- 只排列山河、旗帜、辉煌和祝愿。
- 把热爱写成排斥他人或制造群体优越。
- 人物没有行动，只负责高声表态。
- 用未经核验的历史、地域或成就材料支撑情绪。

### 验收

主人公愿意为这份归属承担什么，而不只是从中获得骄傲？

## 五、公益题材

公益作品先明确要改变的是认知、态度、具体行动、资源分配还是公共纪念。

### 角色不能混淆

- 当事人：拥有自己的欲望和尊严，不是被帮助的道具。
- 家属与照护者：有疲惫、边界和复杂情绪，不自动成为圣人。
- 专业工作者：需要准确职业事实，不以奉献口号替代工作。
- 志愿者与捐助者：不能抢走当事人的主体位置。
- 普通公众：作品希望他理解、停止什么或开始什么。

### 材料入口

一个服务流程、一项被忽略的障碍、日常语言中的偏见、照护动作、资源缺口、当事人希望别人如何对待自己。

### 伦理检查

- 是否消费创伤、疾病、灾难和贫困来换取眼泪？
- 是否未经授权代替群体发言？
- 是否把复杂问题简化成一次转发或捐款就能解决？
- 是否核验事实、称谓、数据和行动建议？

### 常见失效

- 只有“让世界有爱、伸出双手”。
- 受助者没有姓名、选择和能力。
- 把专业问题写成善意问题。
- 作品鼓励的行动模糊、无效甚至有害。

### 验收

作品尊重谁的主体性，并希望听众做出哪一个现实中有效的改变？

## 六、行业、职业与组织精神

当题目围绕学校、企业、行业、城市、团队或职业群体时，先区分：

- 对内凝聚：成员共同唱，核心是身份认同与共同责任。
- 对外介绍：公众旁听，核心是理解这个群体解决什么问题。
- 仪式使用：需要稳定、易唱和明确场景功能。
- 人物作品：通过一个具体从业者呈现职业精神。

### 调查内容

真实工作、历史转折、服务对象、行业风险、成员自称、内部笑话、最被误解的地方、最值得骄傲但外人看不见的动作。

先取得至少一个具体从业者或可核验个案的原话、动作、关系与代价，再把现实人物作品锁定为正式命题。只有行业名称、平台规则和大众印象时，先在内部形成因果不同的研究方向并完成淘汰；对外给出主推荐，说明参考了哪些代表作或公开资料、准备写哪种关系、可以迁移什么结构或修辞、哪些人物事实仍是假设、需要向谁核实。只有同等级强备选确实需要委托方决定时才补一个对照。不得为了凑路线，把职业宣传片的常见桥段改写成私人经历；用户明确选择虚构写作时，先把设定写清，再按虚构人物而非行业事实推进。

### 常见失效

- 把名称、成绩、口号和业务范围押韵排列。
- 所有行业都使用“团结、创新、奉献、辉煌”。
- 只满足领导视角，成员自己不愿唱。
- 组织形象正确，但没有音乐和人物空间。

### 验收

换掉单位名称后，这首歌是否仍可原样送给任何组织？如果可以，尚未进入真实行业。

## 七、公共题材的落地流程

```text
确认公共主题想改变什么现实
→ 选择一个有资格承担主题的人物
→ 找到宏观变化进入其生活的具体位置
→ 建立个人愿望与公共责任的冲突
→ 核验事实、称谓和伦理边界
→ 试写一个动作场景与一句中心判断
→ 检查公共意义是否由人物生长，而非后贴口号
```

## 八、公共性验收

同时满足以下条件才可继续：

- 人物不是主题的传声筒。
- 公共问题改变了人物的现实选择。
- 作品没有把复杂问题虚假地化简。
- 即使不使用宏大词，听众仍能感到共同利益与责任。
- 作品允许真实矛盾存在，不用正确结论覆盖代价。
