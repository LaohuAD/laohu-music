# 验证主持与阶段交接

## 什么时候读取

已有候选命题，需要比较、验证、处理分歧、判断能否进入写词，或向下一 Skill 交接时，读取本文件。

## 核心判断

验证只处理最大的未知，并交给真正有资格回答的人。每个验证者只判断自己知道的部分；选题主持人解释证据和冲突，用户作最终决定。

方向未清时不交完整歌词，但必须帮助用户看见方向。只有对标、题材、职业和效果要求时，先补代表作研究，在内部形成并淘汰路线。关键事实足以决定时公开一个主推荐；人物关系、时间节点或私人材料仍会改变作品身份时，公开当前优先级和条件式强分支，再给局部验证和低负担决策入口。路线被用户确认并形成正式命题后，再进入完整歌词。

验证不能替代生成前的创作判断。候选若只是第一反应的高频换皮，不能靠听众投票、歌手喜欢或“看起来现代”把它验证成立。先完成三角对标、全层拆解、迁移表、异常事实或明确假设与因果分叉；如果因果分叉依赖用户尚未提供的事实，先公开分支和材料调查，不得替用户押成唯一命题。验证负责比较路线和命题，不负责给空命题贴认证。

## 专业裁决不是人格表演

“像殿堂级创作者”不能写成语气要求。成熟判断必须留下可检查的选择痕迹：他看见了什么别人容易忽略的关系；拒绝了哪条看似顺滑的路；依据是什么；选择后整首歌会获得什么、失去什么；什么事实会证明他判断错了。只把语气写得笃定、把名人列得更多、把普通结论压成金句，都不能增加专业重量。

[Kahneman 与 Klein 关于专家直觉成立条件的讨论](https://doi.org/10.1037/a0016755)提醒：只有环境中存在可识别规律，并且判断者获得过充分、及时反馈时，经验直觉才值得信任。歌词校准因此不能让一个抽象的“顶尖作词人”替方向盖章；必须选择与当前问题相符的具名作品传统、公开方法或真实从业者，并把直觉拆回作品证据。涉及全新平台、陌生受众或缺少反馈的题材时，降低确定度并设计验证。

[Berg 的创意预测研究](https://doi.org/10.1177/0001839216642211)显示，创作者评价他人的新点子可能比评价自己的点子更准。内部审议必须暂时分开两种身份：创作者负责提出可能性，编辑者把候选当作别人写的，主动寻找它会写俗、写空、写不完和被听众误解的位置。两种身份不能在同一句里互相辩护。

### 具名校准池

每次重要选题只选二至三位与当前缺口直接相关的校准对象。姓名负责指向可核查的作品与判断维度，不负责让系统扮演本人，也不允许凭名气臆造其私人方法。

| 具名校准对象 | 只借用的公开作品判断维度 | 最可能否决什么 |
| --- | --- | --- |
| 李宗盛 | 普通话怎样容纳人物年龄、生活处境和关系代价 | 只有概念，没有一个具体的人会这样唱 |
| 林夕 | 潜台词、关系悖论和一句话没有说尽的余地 | 把人物内心解释完，漂亮但没有第二层意思 |
| 姚若龙 | 情绪心理怎样落到口语、细节和段落递进 | 只列物件或情绪，没有细节之间的心理因果 |
| 唐恬 | 私人经验怎样进入副歌并成为听众愿意借用的公共表达 | 只有个人自怜，或只有正确口号，没有可唱的共同语言 |
| 方文山 | 意象系统、文化材料和声音组织怎样属于同一作品 | 意象只是装饰或资料堆积，没有改变人物关系 |

实际调用前必须核实与当前任务相关的具体作品、句段或公开访谈。没有核实到可用证据时，删掉姓名，改用“具体作品的这一处怎样工作”完成校准；不得用“李宗盛会怎么写”一类人格代入补空。

内部形成最小裁决记录：

```text
本次最难的创作问题
→ 选择哪二至三位校准对象，分别审什么
→ 每个人最可能否决当前候选的哪一处
→ 哪些属于专业硬伤，哪些只是审美分歧
→ 当前实际淘汰什么、修改什么、保留什么
→ 主持人最终推荐及可推翻条件
```

这份记录默认不原样发给用户。对外只保留真正改变判断的证据、分歧和裁决；名人名单、内部会议感和评审表不得泄露成专业表演。

## 一、先写验证命题

每次验证前写清：

```text
当前最不确定的判断是什么
→ 谁最有资格回答
→ 给他看什么材料
→ 问哪一个具体问题
→ 什么结果支持、削弱或否定当前方向
```

一次只解决一个主要未知。把真实、好听、传播和歌手适配混在一起，反馈无法归因。

### 验证前的反高频门槛

提交候选给任何验证者前，主持人必须能写出：

```text
候选不依赖的原作装置是什么
→ 当前候选新增的关系、处境或判断是什么
→ 哪条真实材料、可靠个案或明确采用的虚构设定支撑当前人物
→ 删除表面新元素后还剩下什么
→ 什么结果会让我们停止，而不是继续替它找理由
```

写不出来时，不进入 A/B，不问“哪个更高级”，先回到对标、材料、假设和关系。验证者只能帮助确认可信度、可唱性、受众连接或专业重量，不能把候选生成阶段的懒惰补成创意。

## 二、验证角色矩阵

### 1. 当事人或生活原型

**验证**：行为、语言、关系、处境、代价和行业细节是否真实。

**不要问**：这是不是市场上最好的歌；所有听众会不会喜欢。

**具体问题**：哪一处不像你们会说或会做的；哪个细节外行一听就假；作品遗漏了什么真正困难。

### 2. 歌手

**验证**：人物是否可信，语言是否愿意承担，声音与情绪是否能发挥，现场是否可唱。

**不要问**：所有角色和受众的真相。

**具体问题**：哪句话你能相信地唱，哪句话像作者借你发言；什么位置有声音空间，什么位置需要背景才能进入。

### 3. 作曲者

**验证**：命题是否有旋律空间、段落反差、重复价值、节奏和中心句落点。

**不要问**：人物生活是否真实。

**具体问题**：这个题目最自然的音乐运动是什么；哪些信息超出歌曲容量；中心句返回是否有音乐发展的可能。

### 4. 制作人、导演或项目主创

**验证**：作品与整体项目、角色、声音、画面、曲目位置和制作条件是否相容。

**不要问**：把个人偏好当成全部市场。

### 5. 委托方和审批者

**验证**：唯一任务、硬条件、禁区、交付和品牌或组织事实是否兑现。

**不要问**：公众是否必然喜欢。

### 6. 目标听众

**验证**：能否识别人物与处境，是否感到被准确理解，何时会听、唱、分享或拒绝。

**不要问**：专业结构、版权和全部事实。

### 7. 领域专业者与文化持有者

**验证**：事实、术语、伦理、历史、地域、习俗和文化边界。

**不要问**：要求作品完全服从其个人审美。

### 8. 成熟歌词创作者或歌词编辑

**验证**：命题是否值得进入歌词传统继续写，中心问题是否有艺术重量，人物关系是否有可持续的语言空间，中心句、意象和故事核是否互相需要，选题是否只是高频题材的漂亮改名。

**不要问**：让他替当事人证明生活事实，或把他的个人审美当成所有体裁的唯一标准。

**具体问题**：这个命题相对于同题代表作真正新增了什么；它最可能在哪个位置写成陈词；人物为什么非唱不可；如果删掉某个意象或中心句，作品损失的是核心关系还是表面气质；它适合歌曲的反复、留白和声音记忆吗？

## 三、候选比较必须控制变量

比较 A/B 方向时，先写明保持不变和改变什么：

| 比较目标 | 保持不变 | 只改变 |
| --- | --- | --- |
| 演唱对象 | 人物、事件、用途 | 直接对象与旁听者 |
| 中心句 | 人物、关系、主题 | 语言动作与句式 |
| 核心意象 | 人物、故事、中心句 | 承载物与变义路径 |
| 视角 | 事件、主题、用途 | 观察位置与知识边界 |
| 展开机制 | 人物、中心判断 | 时间、动作、问答等组织 |
| 类型形式 | 核心关系、用途 | 独唱、对唱、群唱等 |

一次改变多个变量，只能比较整体喜好，不能反推原因。

## 四、有效提问

不要问：

- 你觉得怎么样？
- 有没有共鸣？
- 哪个更高级？
- 会不会火？

改问能定位事实、关系、动作、用途和取舍的问题：

- 你觉得谁在唱，他和“你”是什么关系？
- 哪个动作让你相信这段关系，哪个地方像编的？
- 中心句第一次和最后一次分别是什么意思？
- 你会在什么场景用这首歌，为什么？
- 如果只能删掉一项要求，你删什么；如果只能保留一个记忆点，你留什么？
- 哪一个方向更适合这个歌手，依据是声音、经历还是既有听众关系？

## 五、反馈记录四分法

把反馈分为：

1. **事实纠错**：人物、行业、文化、剧本、产品或规则有错误。优先修正。
2. **理解失败**：受众误解了关键人物或关系。判断是信息不足、表达问题还是故意留白。
3. **目标冲突**：作品目标与委托、歌手、听众或平台要求冲突。需要取舍。
4. **个人偏好**：喜欢某种题材、词风、歌手或情绪。记录但不自动上升为规则。

每条反馈保存原问题、原回答、可验证事实和主持人判断，不能只记录结论。

## 六、冲突反馈怎样裁决

### 不同人验证了不同问题

歌手说好唱，生活原型说不真实，两者并不抵消。先修人物真实，再重新验证可唱性。

### 同一目标的判断相反

检查样本是否处于同一受众和场景，是否看了相同材料，问题是否带有诱导。必要时增加一轮控制变量测试。

### 专业判断与用户审美冲突

说明专业风险、适用条件和保留代价。用户知情后仍选择个人审美，记录为明确决定，不用专家身份压制。

### 委托要求与作品真实性冲突

先提出能够同时改善的方案；若根本冲突，明确两条路线各自损失，由有权决策者选择。不要提交看似均衡、实际两边都弱的稿。

## 七、选题成立的最低条件

进入写词前至少确认：

1. 一个具体人物或声音角色。
2. 明确演唱对象、旁听者和知识边界。
3. 可描述的关系与关键处境。
4. 人物此刻开口的必要性，以及触发事件如何进入需要、身体、行动、防御和关系后果。
5. 起点、触发、风险和变化方向。
6. 作品现实用途与目标听众。
7. 至少一组不可替换的真实材料、授权个案、委约设定或用户明确采用的虚构材料。
8. 一项能够统领全歌的主题判断，以及中心问题、人物当前答案、反证事实和必须保留的未决部分。
9. 适合的创作入口、形式与展开机制。
10. 与长期代表作、近年同用途作品和反向成立作品的实质差异，并完成必要的歌词专业校准。
11. 已知硬条件、禁区和最大风险。
12. 用户确认不可替代的决定。

此外，必须完成迁移门槛：已比较主对标、同题异写和同技法异题作品；已列出保留、变形与避让；候选之间是关系因果不同，不是物件、场景和口号不同；至少一项异常事实或明确设定能够推动推荐方向；相似性审查没有发现逐项换词和原结构复刻。未满足时继续研究、补材料或改造，不交完整歌词。

不是每项都要完全精细。若剩余问题可以在写词过程中通过局部创作解决，不必无限讨论；若剩余问题会改变人物、关系、用途或方向，不能带病交接。

## 八、三个阶段状态

### 成立，可进入下一阶段

核心命题和不可替代决定清楚，剩余问题属于写词、谱曲和命名的专业展开。

### 方向有价值，只缺一个关键证据

明确唯一缺口、为什么它会改变作品、由谁用什么方式补。可以做局部试验，不生成完整成品。

### 暂不建议继续

说明是题目不成立、材料不足、人物错位、用途冲突、音乐不适配还是同题无差异。给出能救活的方向和停止投入的理由。

不要把已经判死的方向写成体面告别。若问题是换皮，就直接说换皮；若问题是人物根本不会这样做，就直接说人物是假的；若主歌只能列物件、副歌只能喊口号，就直接说这不是一首尚待润色的歌，而是一条还没有长成作品的想法。批评对象始终是作品和创作动作，具体语气强度交给 `laohu-natural-dialogue`；证据充分时不替弱方向保全面子。

## 九、与用户的收束方式

每轮收束按以下顺序：

1. 说清目前真正成立的部分。
2. 指出本作相对于同题作品最值得继续追的一个发现。
3. 明确淘汰最诱人的普通方向，并说明它会在哪里写俗或写空。
4. 关键事实足够时，讲透主推荐的依据、材料要求、技法选择、主动舍弃、相似风险和可推翻条件。
5. 关键事实不足且会改变作品身份时，给当前优先级和条件式强分支，说明每条需要哪项私人材料、会怎样改写主歌、副歌和结尾；最后把不可替代的问题写成可选择、可纠正的决策入口，用户不需要从零组织答案。

用户正在学习创作方法、明确要求全面比较，或当前输入明显存在跨时代、跨文化、跨体式的潜力时，收束不能只给主对标附近的几个材料入口。先说明原作真正保留的母问题，再给三条审美距离不同且已经淘汰过的路线：最容易接住原意的近距路线、最值得投入的中距路线、最可能建立作者身份但成本最高的远距路线；若反向结构比其中一条更强，用反向路线替换。每条都必须自然讲清：

```text
它为什么成立
→ 会写成什么样的整首歌
→ 学习哪类具体作品、传统或声音方法
→ 新场景改变了人物什么现实规则
→ 针对谁、在什么场景更可能传播
→ 主动放弃什么
→ 最可能怎样失败
```

对外不要使用“保守、进阶、殿堂”给路线排序，也不要把内部十个扫描轴写成知识树。审美距离只说明离用户原始输入多远，不说明质量高低。主持人仍要给明确建议：当前最值得投哪条、为什么，哪项事实或歌手条件会使建议改变。用户拥有最终决定权，不负责替主持人从未淘汰的菜单里找答案。

用户着急时，缩短每轮，不降低判断。可以用两句试写、一张人物卡或两个中心句帮助他感受差异；不得用冷硬拒绝制造对抗，也不得因用户催促交付粗制完整作品。

### 内部裁决卡

路线尚未锁定时，用下列字段完成内部比较。字段按任务删减，不能把整张卡原样发给用户；对外围绕主判断自然展开。

```markdown
### 主方向｜【朴素名称】

- 本作新增的认识：相对于同题作品，听众会多看见什么。
- 保留的母问题：删除原作物件、修辞和标题后，仍必须回答的那一种人性关系。
- 审美距离：近距 / 中距 / 远距 / 反向；这个标签只描述迁移幅度，不描述质量。
- 迁移轴：人物、时代、制度、视角、冲突、意象、语言传统、演唱形式、受众和传播场景中改变了哪些项。
- 新领域改变的规则：谁能决定、谁先知道、谁必须等待、谁承担什么代价或结局为何不同。
- 文化材料依据：原典、历史制度、地域习俗或文化持有者是否已经核实；哪些仍是创作假设。
- 淘汰的普通路线：哪一条最诱人，为什么仍不值得写。
- 会写成什么：谁在什么处境下，对谁做什么，最后改变什么。
- 借鉴依据：主对标、同题异写、同技法异题分别提供哪一种能力；每个样本必须指出具体句子、段落或声音位置。
- 证据证明什么：原文的主语、动词、语序、修辞、重音、押韵、重复或段落动作，具体解决了什么问题。
- 跨行怎样咬合：关键词、语义场、比喻、韵脚和重复如何从一行接到下一行，而不是逐行贴标签。
- 文字与音乐边界：文字自己增加了什么；哪里没有新增信息，必须由旋律、编曲或演唱完成升级。
- 对标的代价：这项有效写法压缩、牺牲或冒险了什么，新作是否愿意承担。
- 迁移理由：当前人物为什么需要这项能力，新作准备保留什么、改变什么、怎样避免成为换词版。
- 保留的方法：可迁移的段落功能、修辞、句式、押韵、重复、高潮或声音动作。
- 必须变形：原作中哪些独特组合仍有固着风险，准备怎样改变对象、顺序、语义、节奏或结论。
- 明确避让：不进入新作的具体词句、细节组合、逐行推进、韵脚排列和旋律记忆。
- 新作自己的东西：新增的人物关系、生活材料、矛盾、观察位置与最终判断。
- 当前依据：哪些来自用户事实、可靠资料、对标启发或创作假设。
- 文本直接证明：不经过人物动机和故事补全，当前材料能够确认什么。
- 竞争解释：同一组证据至少还能支持哪一种因果不同的理解。
- 额外假设：主方向比竞争解释多假设了哪些人物经历、责任、时间或动机；这些假设是否已由用户采用。
- 胜出理由：主方向比竞争解释多说明了哪些文本、少编了什么，以及它怎样持续改变整歌。
- 改判材料：补到哪一项事实时，应切换到另一条路线。
- 主歌如何展开：至少列出两组具体材料、动作及其先后关系。
- 副歌核心问题：人物要追问、承认、请求或决定什么；为什么必须在副歌说。
- 副歌核心句候选：交由 `laohu-lyric-writing` 内部形成并淘汰；本卡只记录胜出句及必要的被淘汰句，不把路线说明或管理员概括冒充成核心句。对外默认只展示胜出句，除非同等级备选必须由用户的声音、经历或作品归属决定。
- 核心句依据：每句由谁对谁说，完成哪一个语言动作，前文哪两组事实把它推到副歌，哪个词承担记忆和声音重心。
- 核心句回归：第一次、第二次和最后一次出现时分别增加什么信息、压力或人物变化。
- 桥段或结尾变化：哪一件事实或动作让人物的理解、关系位置或责任发生变化。
- 传播机会：首听会听懂什么，复听会发现什么，听众可能记住、借用或跟唱什么；没有数据时标明为推测。
- 目标受众入口：具体哪类听众能在第一遍认出人物与处境，哪类听众会因知识或语言成本掉队。
- 使用与媒介场景：独听、合唱、演唱会、影视、短视频、婚礼、公共活动或其他场景为什么需要这条路线。
- 用户成长说明：这条路线示范了保留哪个母问题、改变哪个轴、如何判断迁移不是换皮；只在用户处于学习状态时自然解释，不写成课程总结。
- 质量收益：这条路线在人物、关系、文字或声音上具体提高什么。
- 熟悉度收益：它借用了哪种已经被听众理解过的结构或声音入口。
- 相似风险：哪些重合会让听众误认来源，风险来自词句、细节组合、语义顺序、韵脚、旋律还是结论。
- 当前取舍：为了质量、熟悉度或独立性，当前保留了什么，主动放弃了什么。
- 最大风险：最容易写成哪类旧歌、换皮或失真。
- 管理员建议：推荐 / 备选 / 不建议，并说明理由。
- 可推翻条件：出现什么新事实、歌手条件或听众证据时应改判。
- 选择后还需确认：只保留一个真正会改变作品身份的问题。
```

内部至少比较三条路线，并确认它们没有全部困在同一审美半径。关键事实足够、用户只需立项时，公开只交付胜出的主方向；关键事实仍会改变作品身份时，公开当前优先级和条件式强分支，并提供低负担入口；用户明确要求全景比较或需要学习创作方法时，公开三条不同审美距离的强路线及主推荐。分支必须让用户看见人物、关系、现实规则、结构、技法、受众和整歌结果的真实差异；不能把“更痛、更高级、更有传播力”换成三个标签冒充选择。

只有对标歌词、没有新人物材料时，内部三条路线可以是对同一文本的不同解释，但不能把其中任何一条写成新人物已经发生的事实。此时公开的是“哪种解释目前更值得调查、为什么”和“哪条事实会使另一种解释胜出”，不是替用户宣布故事。若推荐中出现“收尾、善后、替两个人承担、关系还没有结束、分手来得突然”，必须逐项指出文本或人物材料；指出不了，退回竞争解释。

完成淘汰后再做一次语义去重：把主推荐、强分支和被淘汰路线分别改写成最普通的一句话，删除“训练、残留、时差、资格、归属、善后”等包装词。若两条都在说同一人物因果，例如“对方改变了我”，则不能作为不同路线，也不能一条推荐、一条淘汰。重新改变人物事实、演唱对象、冲突或结尾判断，直到整歌确实不同。

只有对标文本时，不对故事结论做胜负排序，先验证材料入口。至少比较：哪条入口最可能得到用户独有材料；哪条不会复述原作已说出的关系；哪条能在第二段继续发展；哪条只会诱导用户填入库存细节。用户选定真实材料或创作前提后，再把材料入口升级为路线并裁决。

当判断已经足够时，主动提醒可以进入下一阶段，并说明下一阶段会解决什么。是否进入由用户决定；用户想继续讨论时继续，不用流程催促。

## 十、交接协议

### 交给写词 Skill

至少交付人物、对象、处境、开口原因、主题、材料、中心句方向、展开机制、用途、形式、必须保留与禁止改变。写词 Skill 不应重新猜作品是什么。

### 交给谱曲 Skill

至少交付人物声音、情绪运动、段落功能、中心句语言动作、歌手能力、用途和参考边界。不得只给“治愈、伤感、大气”。

### 交给歌名 Skill

至少交付核心关系、中心判断、中心句、意象、用途和同题避让。工作标题可以被推翻。

### 交给封面 Skill

至少交付人物或视觉主体、关系、关键时刻、核心意象、时代地域、使用平台和禁止误读。封面不能替正文新增主题。

辅助 Skill 完成局部验证后，结果先回到选题 Skill；用户确认后才成为锁定信息。

## 十二、失效判定

- 用人数投票替代证据和作品目的。
- 找错验证者，让歌手判断生活事实、让委托方代替所有听众。
- 只找当事人、听众和项目方验证，没有人负责审查选题的歌词艺术重量与同题陈旧风险。
- 只问喜欢不喜欢，没有具体问题。
- A/B 版本同时改变多个变量。
- 所有反馈都上升为永久规则。
- 专家意见与用户审美冲突时，直接替用户决定。
- 核心问题未清便交接完整创作，或所有细节都想锁定后才允许进入写词。
- 阶段完成后不说明下一步，或用流程强迫用户停止讨论。
- 把高频候选先交给验证者，再用“有人喜欢”替代新意证据。
- A/B 只改变原作物件、数字设备、地点或情绪口号，却声称已经形成不同命题。
- 没有停止条件，验证从判断工具变成支持既定答案的辩护流程。
- 引用作品名却没有具体原句、段落或文字动作。
- 路线只有气质、题材和正确口号，没有主歌材料、副歌问题与结尾变化。
- 把公共技法因为“像”而一律删除，或把相似风险因为“是二创”而一律忽略。
- 把具名创作者当作人格皮肤、审美权威或虚构评审，未核实具体作品便声称其会认可当前方向。
- 对外展示全部内部候选和评审字段，让用户替主持人完成淘汰。
- 只有对标文本时，把一种人物解释说成事实，或用“收尾、善后、承担后果”等词补出原文没有的责任关系。
- 推荐与淘汰路线只是同一意思的不同包装，导致回复一边否定、一边换词重推。
- 只总结原作有时间词、生活细节和连续问句，没有分析跨行语义、押韵、重复增义及文字与音乐的分工。
- 把对标所有选择都解释成优点，没有指出至少一项使用条件和代价。
