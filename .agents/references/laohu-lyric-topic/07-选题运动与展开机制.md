# 选题运动与展开机制

## 什么时候读取

题材、人物和情绪已经明确，但作品仍是静态感受，不知道各段如何推进、中心句为何重复时，读取本文件。

只确定作品怎样生长。完整结构和歌词交给写词 Skill。

## 核心判断

每一段必须新增事实、关系或人物变化。运动可以很轻，例如从不肯承认到终于承认；不得换着句子重复同一结论。

先判断作品类型。叙事型歌词需要行动、阻力、信息和结果；抒情型、直言型、哲理型、颂歌、号召歌和仪式性歌词可以靠意象、论述、复沓或声音运动成立，不得强塞完整剧情。《歌词写作十八讲》要求构思时先分清叙事型、抒情型、直言型或哲理型，再决定结构；本文件只在作品确实依靠事件和人物变化时启动下面的戏剧推演。

## 叙事裁决的第一条：先保住戏，再核实戏怎样发生

强故事最容易被两种貌似专业的意见毁掉：一种说这个设定不够真实，于是连它承担的冲突一起删掉；另一种说结局太满、不够克制，于是把人物最后的行动改成想通、放下或继续生活。前者把核实写成了材料淘汰，后者把个人审美冒充成创作规律。

收到用户提供的强冲突、反转、悬念、极端行动或结局时，先做戏剧资产登记，不得先润色或降调：

| 层次 | 必须写清 | 可以修改什么 |
| --- | --- | --- |
| 字面设定 | 职位、信件、武器、场所、时代制度和具体行动怎样表述 | 可以核实、替换、缩小或改造 |
| 戏剧功能 | 它制造了什么阻力、信息差、竞争解释、选择或后果 | 未经同功能替代，不得删除 |
| 情感功能 | 它逼人物在爱、尊严、责任、身份、安全和生命之间失去什么 | 不得用更温柔的情绪代替 |
| 传播功能 | 它提供了什么可见现场、悬念问题、回看价值或记忆画面 | 可以换媒介顺序，不能无故抹平 |

正确顺序是：

```text
登记不可删除的戏剧资产
→ 区分事实、用户明确采用的虚构设定和待核实实现
→ 检查每项资产在全剧中的因果位置
→ 字面实现不可信时寻找同功能替代
→ 比较替换前后的冲突、信息差、人物主动性和代价
→ 功能没有损失，才允许采用替代
```

### 冲突保真：不能只保留“有冲突”这个标签

模型最容易犯的错，不是完全删掉冲突，而是保留一个空壳：仍然说有战争、爱情和牺牲，却把人物真正要付出的东西换成成长、理解、继续生活。这类版本表面完整，实际已经把作品的价值判断换了。

收到用户的强设定后，先写一张不可降级清单：

```text
原现场：观众必须亲眼看见什么危险和反常秩序
原欲望：人物此前一直想完成什么
原对撞：哪两种价值不能同时保住
原主动性：人物最后亲手做什么，而不是被什么消息推着走
原代价：他会失去关系、身份、安全、未来还是生命
原悬念：结尾允许哪几种解释继续竞争
原传播画面：哪一个瞬间能让陌生观众停下来追问接下来会发生什么
```

之后每次提出替代，都必须回答：替代前后这七项是否同级。职位从“大将军”改成别的称谓，可以；把他可能因功名不归、也可能已经死去改成他只是离开了，不可以。敌军坐满台下的戏台可以核实人数、场所、演出动机和行动方式；把它改成多年后一个人唱戏，不叫压缩，叫删掉高潮。

### 安全化回退检测

下列变化一律判为创作失真，不得用更克制、更高级、更符合容量解释：

- 人物主动赴死、反抗或复仇，被改成唱完、想通、释怀或继续生活。
- 敌人、制度或时代正在现场施压，被改成背景、回忆或抽象氛围。
- 两种互相冲突的生死、忠诚或背叛解释，被合并成一个温柔答案。
- 爱情与家国、职业、身份或生存的价值冲突，被改成单纯的思念。
- 人物使用自己的职业和能力改变结果，被改成等待、回忆或替别人完成遗愿。
- 用户明确要求的传奇性，被写实修正成没有戏剧压力的普通职业故事。

一旦命中，先恢复原冲突，再检查它是否有欲望、能力、压力和前置证据。若证据不足，补的是前文准备；若实现不可信，换同功能实现；只有当冲突本身没有因果、人物能力或段落价值时，才允许砍掉，并且要说清砍掉的证据。

### 大师级分析的最低落点：现场、权力、动作、后果

“她在寻找他”“他没有回来”“戏台成为战场”都只是分析标签，不能当作已经想透。每个关键判断至少展开四层：

1. **现场**：谁在什么位置，看见谁，谁能发话，谁必须装作没事。
2. **权力**：谁掌握枪、名单、消息、舞台、观众或离开的许可；谁只能用自己的职业换取一点主动权。
3. **动作**：人物具体做了什么，动作怎样改变消息流、关系或危险。
4. **后果**：这个动作让谁失去什么，怎样逼出下一段，最后怎样改变副歌和结尾。

如果一句分析只能靠留住、收手、守望、命运、牵绊、证明、完成解释，说明还停留在精英层的概括，没有到作者层的判断。把青衣用自己唯一会做的事，把一个人留住拆成可观察事实：她为什么继续演；她借演出把什么名字传到哪里；她每次登台有没有付出金钱、暴露身份或接近敌占区；她寻找的是活人、消息还是一个不能承认的答案。不同回答会把这首歌写成不同作品，不能用一个漂亮宽词替它们平均。

例如`报喜信说武生做了大将军`可能在军制、口吻和可信度上站不住。该改的是职位、功绩的说法、写信时间或消息来源，不是把信改成普通报平安。因为这封信真正值钱的部分，是它同时允许两种危险解释：他活着并因处境或身份改变没有回来；他已经牺牲，这封信是提前留下的安慰。删掉竞争解释，只剩温柔的想念，不叫核实，叫把故事阉了。

极端行动也按同一规则处理。`在敌军面前唱完一出戏并与之同归于尽`不能只因惨烈就自动删除。先问它是否完成了这些变化：戏台从谋生和寻人的地方变成战场；等待消息的人变成主动改变结果的人；职业能力进入最后行动；私人承诺在国难中产生公共后果。若这些变化由前文推出，就保留功能，再核实地点、人物能力、时代条件和可行方式。具体实施方法只写到叙事所需的程度，不为追求真实扩写成可操作的伤害步骤。

这条规则也有反向边界。死亡、爆炸、牺牲和反转不是深刻的快捷键。若它们没有改变人物的选择，只负责把观众吓一跳；若前文没有压力升级、人物能力和因果准备；若换成较小代价整首歌仍然同义，就砍掉。那不是高潮，只是烟花。

## 一、先建立四点运动线

1. **起点**：人物起初相信什么，关系处于什么状态，他正在做什么。
2. **触发**：哪件事、哪句话、哪个动作或哪次缺席，使原状态无法继续。
3. **风险**：人物可能失去什么；如果什么都不做，会发生什么。
4. **变化**：事实、关系、认识或行动中，至少哪一项与开头不同。

用一句话压缩：

```text
原本【状态】的人，因为【触发】，不得不面对【风险】，最后【变化】。
```

只能写成“一个悲伤的人经历事情后获得成长”，立即退回人物、触发和风险。

## 叙事型歌词必须完成戏剧推演

叙事不是把人物履历按时间念完，也不是在桥段突然送来死讯。它只保留会改变关系的一连串行动。先用普通话跑完以下程序，再决定哪些节点值得进入歌词：

```text
人物原来的生活秩序是什么
→ 两人因哪项共同生活、技能、承诺或责任发生关系
→ 外部事件具体破坏了什么
→ 主人公现在主动想完成什么
→ 现实规则为什么使他不能直接完成
→ 他采用什么持续行动改变现实或传播消息
→ 每一段新增哪项事实、消息、代价、误解或选择
→ 桥段带来哪项证据
→ 这项证据改变谁的认识、责任或下一步行动
→ 最后一次副歌中，哪句话因此获得新义
→ 结尾留下的是明确事实、人物选择，还是有依据的悬念
```

### 主人公必须行动

主人公可以等待，但不能整首歌只等、想、哭、守。至少有一项持续行动改变现实、信息流或他与他人的关系。行动必须来自人物已经拥有的身份与能力，不由作者临时赐予。

例如青衣随戏班辗转各城演出，若成立，它不只是`继续唱戏`：她可能借每次演出报出戏班和自己的名字，托观众与同行打听武生消息，选择军队可能经过的城镇，或以免费演出换取更广的传播。每一种做法都要核实时代和行业条件。只有`年年穿嫁衣、年年望台口`，人物仍然没有改变任何事，只是在重复姿态。

行动是否有效，按四问检查：

```text
她具体做了什么，而不是作者说她“在行动”
→ 这个动作让谁知道了此前不知道的消息，或让谁不得不回应
→ 阻力怎样因此反击，危险、金钱、名誉、身份或时间代价增加了什么
→ 删除这个动作后，后续剧情和最后副歌是否真的会改变
```

移动不等于行动，忙碌不等于行动，反复演出也不自动等于行动。`她不是站着哭，她是在行动里找人`只是给人物贴了主动标签。若她只是跟戏班从一城到另一城，外界没有收到新消息，她也没有接近答案，故事仍是移动中的苦等。只有巡演被她改造成消息渠道、交换条件、接近危险地区的办法或最后反抗的掩护，职业行为才进入剧情。

职业动作还要与剧情动作分开。青衣登台唱戏是职业动作；她在报幕、唱词、戏单、同行关系或演出地点上做出选择，使武生或知情者可能收到消息，才是寻人动作。`把自己唱出去`没有说明她传播什么、谁能听见、消息怎样回来；`替武生留位`也必须明确是保留角色、不让别人接词、维持婚约还是保存身份。不同答案会改变整首歌，不能压成一句。

### 反转必须产生回看，不靠作者宣布

桥段的新事实至少改变前文中的两处理解，才有资格称为反转。逐项写清：

```text
反转前，人物与听众把哪句话、信件或动作理解成什么
→ 桥段新增哪项可以指认的事实
→ 这项事实排除了什么，又保留了哪些竞争解释
→ 前文哪两处现在获得了不同含义
→ 最后副歌的主语、对象、责任或决定具体改变了什么
```

`那封信把整首歌的意义翻过来`没有提供任何一项判断。若信件日期早于某场战役，听众可能重新怀疑它是提前留下的报喜信；若送信人只能证明武生曾立功，却不知道他后来去向，功成不归与牺牲留信仍然并存。分析必须指出这两条证据怎样改变青衣对失约的判断、怎样让同一句副歌从等人变成追问真相，或怎样逼她作出新的选择。无法回看前文，只是在桥段多出一封信，不叫反转，叫补充信息。

### 高潮必须是不可逆选择，不是作者发来的事故

把人物推到最高压力处，检查他必须在什么之间选择。真正的高潮不是事故最大，而是退路最少：人物知道得更多、能保住的更少，却仍要亲手决定下一步。这个决定一旦做出，就改变关系、身份、现实结果或未来，不允许结尾再用一句感悟把代价抹平。

内部建立代价升级梯：

```text
失去方便或舒适
→ 失去关系与承诺
→ 失去职业、名誉或原有身份
→ 失去安全与返回旧生活的可能
→ 失去生命、未来或让所爱之人回来后仍能团聚的机会
```

不是每首歌都要走到最后一级。只走到哪一级，由人物、题材和歌曲任务决定；但叙事必须知道人物最后拿什么下注。若结尾只是收到死讯、看见遗物或听懂一句话，主人公仍然只是事故的接收者。继续追问：新事实逼他做了什么此前不会做、此后不能撤回的事？

人物的极端选择必须同时通过四项检查：

1. **欲望连续**：它仍在完成或改写人物此前的愿望，不是临时换人格。
2. **能力连续**：它使用人物已经建立的职业、关系、知识或资源，不由作者临时赐予本领。
3. **压力连续**：每次阻力都缩小退路，代价逐步可见，不在结尾突然拔高。
4. **结果连续**：选择改变现实和最后副歌，不只是增加一幅惨烈画面。

### 阻力必须来自现实规则

战争、交通、通信、职业制度、家庭权力、身份差异和生存成本，应真正限制人物能做什么、何时知道、该相信谁。只把现代恋人换成武生青衣，把手机换成书信，把城市换成乱世，而信息传播和人物选择完全不变，仍是换皮。

历史、地域、职业或战争题材进入正式命题前，必须核实：时代、地理、交通、通信、称谓、组织制度、职业运行、服装道具和普通人的信息来源。没有核实的内容标为创作假设或调查问题。`大将军、战报、阵亡名单、戏班巡演、免费演出`等词不能仅因有戏剧性就写进作品。

选题分析中可以提出待查机制，但必须把它们与已知设定分开。不得一边说需要核实，一边把`报号、戏单、番号、军队经过的城镇、名单传回方式`写成当前故事已经采用的事实。先写成研究任务：当时戏班演出是否会公开报出班名和演员名；戏单怎样印发或张贴；民间怎样打听部队与失踪者；一封信可能经过哪些递送渠道。核实后再决定哪一种机制能进入主歌。若本轮没有完成研究，段落推演只写功能，例如`她借巡演扩大寻人消息的传播范围`，不擅自填具体制度。

### 每段都要改变观众掌握的信息

为每个段落写一张最小信息卡：

```text
人物此刻知道什么
→ 听众此刻知道什么
→ 人物相信但尚未证实什么
→ 本段新出现哪项证据
→ 证据使旧话获得什么新意思
```

若一段只增加城市、季节、景物和伤心程度，没有改变行动、知识、责任或选择，删除或合并。歌曲时长有限，背景只保留会逼人物行动的部分；不能把完整电影梗概压成事件清单。

### 桥段必须改写后文，不能只负责发刀

桥段至少改变一项：事实、人物知道的内容、听众的判断、责任归属或下一步选择。删除桥段后最后副歌仍完全同义，说明桥段只是新事故或情绪升级。

如果桥段送来一封信，先判断它的戏剧功能：确认生死、推迟真相、暴露误解、迫使人物选择，还是制造两种都能成立的解释。信中内容不能只靠夸张职位和宏大承诺制造戏剧性；具体战地小事、两人旧称呼、只有双方知道的约定，通常比`我已当上大将军`更可信，也更能证明写信人身份。

一旦开始引用信件原文，就切回写信人当时知道的事。前一句可以由选题分析者说明这封信在结构上承担什么功能；下一句若改写武生的原话，立即改用武生当时的知识、处境、性格和写信目的。武生不能知道青衣后来如何解释这封信，也不能替作者安排“粗听是什么、细听是什么”。“让她别把嫁衣收起来”“若我误了归期，你也要把戏唱完”这类句子，只有在人物平时确实这样说、当时确实有理由这样写、并且没有把多层主题硬塞进一句话时才能保留；否则判为作者分析倒灌。

信件的双重解释应由信内与信外共同完成：信内写角色当时会写的战地近况、称呼、请求、承诺或遮掩；信外用日期、送信人的说法、字迹、缺失的后续、两人旧约和后来的事实制造不安。不要让武生在信里主动宣布自己可能死亡、婚约象征和全歌主题。那不是人物说话，是作者拿角色当讲解器。

### 多义结局必须公平

悬念不是作者不肯交代，反转也不是最后一分钟强塞第二种答案。若结尾允许两种解释，前文必须给两组可回读的证据，并明确谁知道什么：

```text
解释 A 由哪些已出现的事实支持
→ 解释 B 由哪些已出现的事实支持
→ 哪项证据同时允许两种解释
→ 哪项关键事实被有意限制在人物或听众视野之外
→ 两种解释分别怎样改变最后副歌
```

例如一封报喜信若既可能是武生仍活着的承诺，也可能是他早先留下的安慰，前文必须处理投递时间、送信人、字迹或私密称呼、战况与信中时间是否相合。若这些线索只在结尾突然补出，多义是假；若所有线索只支持死亡，所谓开放结局只是故意不说破。

多义不等于作者拒绝选择。先区分三件事：作品必须说死的事实、人物此刻相信的解释、听众仍可保留的竞争解释。人物可以依据有限信息做出不可逆选择，听众却在结尾继续怀疑另一种可能。这样的开放会加重选择的代价；如果人物也不决定、作者也不提供证据、听众只能随便猜，那不是开放，是没写完。

### 结尾必须竞争，不得默认和解胜出

叙事型路线在锁定结局前，至少内部比较三种真正不同的结尾：

| 结尾类型 | 人物完成什么 | 主要收益 | 主要风险 |
| --- | --- | --- | --- |
| 内在完成 | 停止等待、承认事实、改变对往事的解释 | 适合克制、抒情和人物内心转变 | 容易把外部冲突收成自我安慰 |
| 外在行动 | 借已有身份与能力改变现实、救人、反抗、复仇或牺牲 | 人物主体性强，事件与主题合一 | 前文准备不足会像强行发刀 |
| 双重余震 | 人物完成不可逆行动，但另一关键人物的生死、归来或误解仍未封死 | 回看空间大，最后副歌能产生第二层含义 | 线索不公平会沦为故弄玄虚 |

不能把三种结尾平均折中。先看作品要让听众最终承受什么，再判断哪一种完成了主矛盾。`唱完最后一出戏后继续生活`不是天然比牺牲高级；`同归于尽`也不是天然比活下来深刻。高级与否只看因果、人物选择、代价和歌曲容量是否共同成立。

### 时代必须改变私人命运，不能只提供布景

家国、战争和民族存亡不是结尾才出现的正确词。时代必须从开头就改变人物能做什么、能知道什么、何时能收到消息、什么承诺还能兑现、职业身份有什么新用途，以及一个私人决定会伤到或保护哪些陌生人。

武生离开戏台进入战争，不能只理解为`爱情被迫分开`。他的选择至少同时改写三层关系：他不再满足于在台上扮演英雄；他把与青衣的婚约置于无法保证的未来；他开始对戏班之外的人承担风险。青衣最后若把戏台变成战场，也不是在爱情故事末尾贴爱国标签，而是让她最熟悉的职业、最私人的等待和时代要求在同一个行动中相撞。公共意义必须从这种行动与代价里出现，不能靠作者喊出来。

### 歌词顺序、视觉顺序和传播顺序分别设计

歌曲、MV、短视频切片和舞台演出不是同一种时间线。不得把`高潮前置`粗暴理解成歌词第一句交代结局，也不得因歌词采用顺叙，就让视频从童年背景慢慢讲起。

分别回答：

```text
歌词第一句让听众听见什么，暂时不知道什么
→ 副歌第一次先给结果、问题、誓言还是行动
→ MV 或短视频第一镜展示哪个高压现场
→ 该画面隐藏哪个关键目的或结果，避免提前泄底
→ 何时回到过去补足因果
→ 最后一次副歌和结尾画面各自兑现什么
```

青衣在敌军坐满台下时登台，可以作为视觉冷开场：先给危险现场、反常秩序和人物镇定，暂不揭示她准备做什么。歌词可以从这场戏、当年约定或辗转寻人进入；三种入口会形成不同的信息差。副歌前置也只适合先交出整首歌最值得等待的问题或情绪，不等于把信的真相和最后行动一次说完。

传播判断必须保持证据边界。YouTube 的官方留存说明只支持：前 30 秒是否匹配入口承诺并保持兴趣值得单独检查；若高留存时刻出现在后段，可以实验把有吸引力的内容更早引入。它不证明任何作品只要把爆炸、死亡或结局搬到开头就会传播。前置的是承诺和压力，不一定是答案。

### 三幕式、英雄之旅和电影术语只做诊断，不接管作品

用户提到三幕式、英雄之旅、起承转合或电影结构时，先还原它们能帮助检查的实际问题：开头是否建立失衡，中段阻力是否升级，人物是否跨过不能回头的门槛，结尾是否承担选择的后果。不得为了套齐术语，硬给歌词补导师、试炼、最低谷、凯旋和回归，也不得要求所有人物完成成长。

叙事歌词容量有限，优先保留四个功能节点：

```text
旧秩序怎样被打破
→ 人物主动想完成什么
→ 阻力怎样逼他付出更大代价
→ 他最后做出什么不可逆选择，结果怎样改写前文
```

三幕式可帮助检查触发、升级与收束；英雄之旅可帮助检查人物是否离开旧身份、进入陌生规则并为返回付出代价；起承转合可帮助安排信息与语言转折。它们彼此不是质量等级，也不是一首歌必须同时拥有的结构。当前人物若靠等待、仪式、复沓或一个瞬间成立，就不要把电影长结构压进歌曲。

### 理论依据与使用边界

《歌词写作十八讲》要求创作前决定题材、主题、角度、段落、语言与韵律，并强调作者进入规定情境、体会人物内在感情；这里把它落实为先完成世界规则和人物行动，再压缩进歌曲。亚里士多德《诗学》把戏剧人物理解为行动中的人，把情节视为行动的安排，并要求突转与发现从情节内部依可能性或必然性发生；这里吸收的是因果、行动、突转与发现，不要求现代歌词照搬古典戏剧结构，也不把死亡场面本身当成情节。[MIT Classics, Poetics](https://classics.mit.edu/Aristotle/poetics.1.1.html)

YouTube 的官方留存说明把前 30 秒、后段高留存时刻、重复观看高峰和流失点分开观察，并建议在后段出现高留存时实验更早引入有吸引力的内容。这里仅转化为`视觉入口应尽早兑现标题和画面的承诺，并可测试把高压现场前置`，不据此宣称高潮前置必然提高传播，也不把平台留存数据当作文学质量。[YouTube Help, Measure key moments for audience retention](https://support.google.com/youtube/answer/9314415?hl=en)

这些方法只服务叙事型歌词。它们不证明故事越复杂越高级，也不要求每首歌必须反转、悬念或开放结局。真正标准是：所选行动能否逼出人物的关系和情绪，新增信息能否让副歌回归时更重，而不是让创作者有机会讲更多剧情。

## 二、十一种展开机制

### 1. 起承转合

**适合**：主题集中、需要清晰转折与收束的题目。

- 起：以人物、动作或现场定下关系和语气。
- 承：沿同一方向增加证据和压力，不只是同义重复。
- 转：引入会改变听众理解的新事实、视角或人物选择。
- 合：让前文材料共同指向主题，不另起一段大道理。

**失效**：为了形式在桥段突然反转；“合”只负责拔高，没有兑现开头。

### 2. 顺承递进

**适合**：成长、等待、旅程、劳动、关系积累和逐渐失去。

每一层必须提高一种东西：时间压力、现实代价、人物认识、关系距离或行动强度。只增加景物数量不是递进。

**失效**：第二段只是第一段换季节、换地点、换近义词。

### 3. 问答呼应

**适合**：对唱、亲子、恋人、师徒、人与群体之间存在信息差或诉求冲突。

先明确谁问、为什么问、期待什么答案；谁答、愿不愿说真话、回答是否改变下一次提问。可以一问一答、多问后集中回答、问而不答或答非所问，但错位必须服务关系。

**失效**：问题只是给说明文字搭台；双方没有独立欲望，答案早已由提问者说完。

### 4. 分述并列

**适合**：群体、地方、家庭成员、多个侧面共同证明一个中心。

为每一部分分配独立功能，例如第一段写共同来源，第二段写不同代价，第三段写共同选择。并列项之间应有比较、扩大或合流。

**失效**：景点、职业、人物事迹和产品卖点的清单式罗列。

### 5. 一字一词统领

**适合**：某个字、称呼、动作词或物件拥有丰富的生活义、关系义和声音记忆。

先列这个词在人物生活中的不同用法，再安排它从字面义走向关系义。它应能引发动作、人物和变化，不是每行机械重复。

**失效**：只因一个词押韵方便或听起来响亮便把它当主题。

### 6. 时间顺序

**适合**：事件过程、四季周期、人生阶段、关系前后变化。

选择真正会改变意义的时间节点，不必把每年每月都写全。时间标记之后必须回答：人与关系发生了什么新变化。

**失效**：时间完整，人物不动；从春写到冬仍只是想念。

### 7. 空间顺序

**适合**：送别、归乡、迁徙、劳动路线、城市与地域题材。

地点顺序应等于关系推进：越走越远、越接近秘密、从公共空间进入私人空间，或从熟悉走到陌生。每个地点提供新的行动或关系证据。

**失效**：城市宣传式景点巡游，删掉地名后主题毫无变化。

### 8. 情景交融

**适合**：环境真实参与人物处境，景物变化能承载人物变化。

先确定人物感知景物的原因，再选择与动作和关系相关的物候、光线、声音或空间。景不能代替情绪标签，情也不能强迫景物做违背物理规律的表演。

**失效**：先写一段通用风景，下一段突然告诉听众“我很悲伤”。

### 9. 回忆倒叙

**适合**：现在的一个动作、物件或处境重新解释过去。

先给出现时触发物，再选择过去的关键片段；回到现在时必须让人物获得新的认识或决定。过去不是完整履历，只保留解释此刻的部分。

**失效**：主歌全是怀旧清单，现实中的人物为什么回忆没有答案。

### 10. 回旋反复

**适合**：中心句强、情绪需要咏叹、同一对象在不同压力下被重新理解。

每次返回前增加新的事实、代价或对象位置。可让同一句从承诺变成怀疑、从等待变成告别、从对别人说变成对自己说。

**失效**：重复只用于补足曲式，词义和唱法没有变化依据。

### 11. 条例、口诀与号召

**适合**：教学、组织、知识记忆、集体行动和明确公共任务。

先保证事实、顺序和行动准确，再用人物、节奏、问答、场景或幽默提高可唱性。内容本身若不值得记忆，押韵不能救活它。

**失效**：把规章、口号、产品说明逐句押韵，人物与听众完全缺席。

## 三、现代作品常用的四种补充机制

### 1. 动作链

围绕一组相互因果的动作展开，如收拾、寻找、归还、删除、重做。每个动作都暴露人物态度，最后一个动作完成或拒绝完成主题。

### 2. 关系揭示

逐步提供称呼、权力、亏欠、秘密和共同习惯，让听众重新判断两人是什么关系。揭示不是故意藏信息，而是遵守人物何时愿意说。

### 3. 认识翻转

事实不变，人物的解释改变。前文必须放入足够证据，使结尾的认识是被生活逼出来的，不是作者突然总结。

### 4. 对象转换

一句话开始唱给具体个人，后来显出也在唱给自己、家庭、故乡或一群人。转换要由共同处境连接，不能把私人故事生硬拔高成时代宣言。

## 四、选择主机制

按题目的主要压力选择：

| 主要压力 | 优先机制 |
| --- | --- |
| 事件不可逆 | 时间顺序、动作链、起承转合 |
| 两人信息或欲望冲突 | 问答呼应、关系揭示 |
| 多个侧面共同证明主题 | 分述并列、空间顺序 |
| 一句或一物需要反复变义 | 一字一词、回旋反复 |
| 现在重新理解过去 | 回忆倒叙、认识翻转 |
| 环境直接改变人物行为 | 情景交融、空间顺序 |
| 公共知识或行动需要记忆 | 条例口诀、问答、并列 |

一首歌选择一个主机制，最多配一个辅助机制。使用三四种机制通常不是丰富，而是没有决定主线。

## 五、段落功能预演

不写歌词，先用普通话写每段新增什么：

```text
第一段：让听众看见人物与处境，但暂不知道___。
副歌第一次：人物提出___。
第二段：新增事实___，使前一句变成___。
桥段或转折：人物发现/决定___。
副歌最后一次：同一句现在意味着___。
```

如果每段都只能填写“继续表达感情”，回到选题层补触发、风险或关系证据。

叙事型任务再补五项：主人公本段做了什么；阻力怎样反击；谁得到消息；谁仍被蒙在鼓里；这一变化如何改写下一段。缺少主动行动、信息来源或现实规则时，不得只靠意象和情绪词填满段落。

## 六、展开压力测试

1. 删除所有情绪词，动作与关系是否仍在变化。
2. 交换第一段和第二段，若毫无影响，说明没有递进。
3. 删除桥段，若主题完全不受影响，桥段可能只在拔高。
4. 核心句每次返回前，是否新增足以改变它的材料。
5. 结尾变化是否由人物完成，而不是由作者替他总结。
6. 是否能在歌曲篇幅中听懂，不依赖创作者解释设定。
7. 主人公是否至少有一项持续行动，而非只等待和承受。
8. 消息从哪里来、由谁传递、为什么可信或可疑，是否已经写清。
9. 若结尾有两种解释，两边是否都有前置证据，最后副歌是否随之产生不同含义。
10. 历史、职业和战争规则是否经过核实；删掉时代背景后若人物仍做同样的事，说明只是换皮。
11. 用户给出的强冲突被修改前，是否先登记了它的戏剧、情感和传播功能；替代后这些功能是否仍在。
12. 高潮是否由主人公在最高压力下作出不可逆选择，还是作者临时送来事故、死讯或宏大场面。
13. 结尾是否比较过内在完成、外在行动与双重余震，而不是默认把和解、释怀和继续生活当成高级答案。
14. 时代是否改变人物能力、消息来源、承诺条件和行动后果，而非只提供服装、称谓和背景。
15. 歌词、MV 与短视频的开场是否分别设计；高潮前置是否保留悬念，没有把答案提前泄完。

## 八、失效判定

- 只有情绪强弱变化，没有事实、关系、认识或行动变化。
- 用新景物和新意象代替推进。
- 为了转折突然制造事故、秘密或顿悟。
- 结构方法比人物更显眼。
- 并列没有层次，问答没有欲望，回忆没有现实触发。
- 结尾另起大道理，无法由前文推出。
- 主人公只有等待姿态，没有能改变现实或信息流的行动。
- 桥段只送来事故、遗物或死讯，删除后最后副歌仍是原意。
- 开放结局只有含糊，没有两组前置证据。
- 历史与职业只提供服装、称谓和意象，没有改变人物的能力、信息和代价。
- 一见强冲突就先问会不会太大、太惨、太满，没有先写清它保护了什么。
- 字面设定需要核实，系统却把设定承担的悬念、误判和选择一起删除。
- 把人物的极端行动改成唱完、想通、释怀或继续生活，只因系统偏爱克制结尾。
- 结尾只有事故规模，没有人物此前欲望、能力、压力和结果的连续准备。
- 把短视频第一镜、歌词第一句和副歌第一次出现当成同一时间顺序。

## 九、行为回归场景

修改本文件或相关 Skill 后，用以下场景做上下文清零测试。测试只给项目文件与输入，不在提示中解释正确答案。

### 场景 A：字面失真不能连戏一起删

输入包含：一封报喜信声称武生做了大将军；青衣既怀疑他升迁后变心，也怀疑他已经战死、信是提前留下的安慰。

- **失败**：以`大将军太假、太戏文`为由，把信改成普通报平安，并删掉两种解释。
- **通过**：保留两种解释及其前置线索；把职位、功绩、消息来源列为待核实，必要时提供同功能替代。

### 场景 B：极端行动不能自动被温柔化

输入包含：青衣在侵略者坐满台下的戏台上演出，并计划以符合时代和人物能力的方式与敌人同归于尽。

- **失败**：只因太惨、太满或不够克制，改成她唱完戏后停止等待、继续生活。
- **通过**：先判断该行动是否完成`戏台变战场、等待者变行动者、职业能力进入最后选择、私人承诺产生公共后果`；再核实实现条件。若否定，必须提供保留同等功能的替代，不能只降情绪。

### 场景 C：高潮前置不能混成一种顺序

输入包含：短视频第一镜先出现敌军台下看戏，歌曲仍要保留武生生死与青衣目的的悬念。

- **失败**：把歌词第一句、MV 第一镜和副歌开头全部写成结局说明，或因怕泄底完全放弃高压开场。
- **通过**：分别设计视觉冷开场、歌词信息顺序与副歌回归；写清第一镜展示什么、隐藏什么、何时兑现。

### 场景 D：复杂和惨烈不是通行证

输入只说想让故事更高级，所以临时增加死亡、爆炸和三次反转，前文没有人物能力、阻力和证据。

- **失败**：把戏剧强度当质量，继续堆事故。
- **通过**：删除不能由欲望、能力、压力和因果推出的场面；允许小情感成立，但要求人物有真实选择、代价和段落变化。

### 场景 E：继承内核，不得只继承表面

输入已锁定：武生离开戏班去参军；青衣随戏班巡演找他；报喜信同时可能是功名后的背叛，也可能是战死前留下的安慰；敌军坐满台下时青衣登台。

- **失败**：写成“她用戏台寻找他，最后穿嫁衣唱完他的戏，学会继续生活”。它保留了戏班、嫁衣和等待，却删除了功名与爱情的对撞、敌军现场、青衣的反击和双重余震。
- **通过**：明确区分青衣的寻人行动、武生的身份变化、信件的竞争解释和敌军台下的最后行动；结尾至少比较外在反抗与双重余震，不能默认以内在和解收束。

### 场景 F：语言必须落到事实

输入出现“她只是没有拿到一句能让她收手的话”“她是在用自己唯一会做的事，把一个人留住”。

- **失败**：继续用“收手、留住、命运、牵绊、完成”做更漂亮的替换。
- **通过**：说明她具体在何处演出、公开或隐藏什么名字、期待谁把消息带给谁、付出什么代价；确认“收手”到底是停止寻人、停止演出、承认死亡还是不再等候。

### 场景 G：重词不能代替准确关系

输入出现：`她终于明白，他也许不是失约，他可能是把最后一句话留给了她`；`她没有离开自己的命，她把自己的命唱成了寻找他的办法`；`他留下的不是婚期，而是让她活下去的办法`；`她把空了多年的那句词唱完`。

- **失败**：只把`命、留下、办法、唱完`换成更古典、更浓烈或更顺口的近义词，继续保留确定与猜测冲突、不同层级强行对举、一个字承担多项意义和抽象结尾替代人物行动。
- **通过**：分别确认她是在怀疑还是确认；信里实际写了什么；她继续演出究竟为了谋生、寻人、救亡还是履约；多年没有人接唱的是哪一个位置；最终人物是在停止等待、确认死讯、公开反抗还是采取不可逆行动。分析层先把这些事实分开，歌词层再选择其中一项主要情绪和一个准确词，不把所有层次重新压进一句。

这类检查必须在选题阶段完成，不能等写词时才补救。选题总线里的每一句总结都会限制后面的主歌事实、副歌问题、桥段证据和结尾动作；如果总线先写成“她把自己的命唱成寻找他的办法”，下游很容易把一个未经裁决的比喻当成既定主题。正确总线应先写可核对动作：她随戏班巡演，反复演出两人共同演过的折子，并借每一场演出打听武生的消息。等事实、目的和代价确定以后，才决定是否需要一句更凝练的作品概括；概括不能替代总线。

### 场景 H：善意解释夺走人物的选择

输入出现：`最后她明白，他当年不是骗她，是怕她从此不唱了`；`他让她等的不是回来成亲，而是等她有一天能继续活下去`；`她在寻找一个没有地址的人`；`她把一生停在那一折戏里`。

- **失败**：作者先替武生排除欺骗、变心和失约，再补出`怕她不唱、想让她活下去`的善意动机；随后把青衣多年演出、寻找、反抗或赴死解释成执行武生留下的安排。`没有地址`把战争中的失联、通信中断、下落不明和阵亡可能混成现代抒情意象；`一生停在戏里`又用空间动词吞掉年月、行动和代价。最后，原本允许多种解释竞争的故事被收成理解、和解和继续生活。
- **通过**：分别列出武生写过什么、后来发生什么、青衣依据什么怀疑、观众还能怎样解释。没有足够证据时，善意只能是一种竞争解释，不能成为结尾真相。青衣继续演出、借巡演打听、停止等待、在敌军现场采取行动或付出生命代价，必须由她自己的目标、处境和选择推出；不能倒算成武生早已替她安排。战争信息写回通信、部队、信件、名单和消息来源，舞台信息写回哪一折、谁接唱、在哪里停、最后一次演出改变了什么。允许主人公作出决定而真相仍然未知，禁止默认和解。

### 场景 I：完整故事不能只得到元素清单

用户已经补充：武生与青衣从小在戏班长大；战争爆发后武生参军；青衣随戏班跨城巡演并尝试借演出找人；桥段出现一封表面报喜、实际可能另有隐情的信；结尾准备进入敌军在场的高压演出。

- **失败**：回复只把故事压成一句命题，再写`有前史、有冲突、有承诺、有行动、有反转`。随后用`她不是站着哭，她是在行动里找人`、`沿着戏班和巡演的路替武生留位`、`把自己唱出去找他`、`那封信把整首歌的意义翻过来`作结。这些句子没有说明巡演怎样传播消息、谁能听见、消息怎样回流、阻力怎样升级、信件新增什么证据、最后副歌哪一句为何变义，也没有处理敌军台下的高潮与此前寻人行动怎样相连。
- **通过**：先指出新材料使作品从静态等待变成依靠职业能力寻找消息，但只有巡演确实改变信息传播时这项判断才成立。再拆青衣每到一城具体做什么、谁可能把消息带走、她为何选择某些演出地点、免费演出的代价、敌占区如何增加危险。随后比较信件支持的功成不归、失联与牺牲前留信等解释，指出日期、送信人和后续消息分别能证明什么。最后逐段说明主歌怎样建立共同生活，第一次副歌怎样留下未完成的接唱，第二主歌怎样使寻人代价升级，桥段怎样改变前文判断，最后副歌怎样进入青衣自己的不可逆选择；同时交代高潮前置的传播收益、历史与职业核实、最大烂尾风险和改判条件。

这个场景的验收标准不是篇幅，而是用户能否据此决定怎样写整首歌。回复更长却仍只重复`主动、深刻、有画面`，不通过；回复文字简洁，但行动、消息、阻力、证据、段落变义和风险都已经讲清，可以通过。
