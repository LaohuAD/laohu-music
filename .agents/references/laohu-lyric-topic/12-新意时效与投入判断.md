# 新意、时效与投入判断

## 什么时候读取

需要判断题目差异、作品寿命、投入、复用价值，或区分单首机会与长期主攻时，读取本文件。

## 核心判断

新意必须改变对现实关系的认识。检查别人通常从哪边看、本作换到了哪个真实位置、旧问题今天增加了什么条件和代价，以及人物有什么不可替换的证据。

先区分两种借鉴：表面替换沿着参考作品寻找近义物件和近义句，深层迁移先理解原作的关系、结构、修辞和声音为什么有效，再用新的对象、材料和组合完成同等功能。前者会产生“外套换成密码、房间换成账号、痛苦换成自我成长”的换皮；后者允许学习连续追问、复沓、段落爆发和押韵密度，但必须重新建立人物因果和具体表达。

陌生化不是罕见材料竞赛。它的作用是打断听众对熟悉经验的自动理解，使一个原本被看惯的关系重新变得可感、可疑或可思考。新名词只有在改变人物行为、权力、责任、知识差、时间位置或实际代价时才有价值；否则删除它，作品应当仍然成立。

本规则同时吸收“示例会限制”和“比较能促进迁移”两组研究。[Smith、Ward 与 Schumacher](https://doi.org/10.3758/BF03202751)、[Jansson 与 Smith](https://doi.org/10.1016/0142-694X(91)90003-F)说明单一示例容易造成固着；[Gentner、Loewenstein 与 Thompson 的类比编码研究](https://doi.org/10.1037/0022-0663.95.2.393)说明比较多个案例有助于提炼共同关系并迁移知识；[Miall、Kuiken](https://doi.org/10.1016/0304-422X(94)00011-5)支持通过陌生化打断自动知觉。执行结论不是远离前人，而是不要只贴着一个例子换词：比较多个高水平作品，抽取可复用的关系、结构、修辞和声音原则，再回到当前作品重组。

版权边界也要求区分方法与表达。[WIPO](https://www.wipo.int/copyright/en/)明确说明版权保护表达而非思想、程序和方法；[美国版权局 Circular 33](https://www.copyright.gov/circs/circ33.pdf)同样区分思想、方法、格式与具体原创表达。连续追问、排比、复沓、段落格式和一般写作方法可以学习；具体词句、独特细节组合、选择与编排仍可能构成受保护表达。这里只提供创作边界，不替代具体司法辖区的法律意见。

值得写不等于会流行。结果还受作品、歌手、音乐、制作、资源、平台和时机影响；只判断当前能证实的部分。

## 专业判断：先预测，再淘汰

生成候选和判断候选是两种工作。模型能迅速给出多个顺滑方向，只能证明这些方向容易生成，不能证明它们值得投入。[Doshi 与 Hauser 的生成式 AI 创作实验](https://doi.org/10.1126/sciadv.adn5290)发现，AI 帮助可以提高单篇故事的评价，却会使不同作者的作品彼此更相似；这项研究不能直接证明歌词质量，但足以提醒本项目：完成度提高与集体新意下降可以同时发生，不能把“更像成品”误判为“更有作品身份”。

[Simonton 的变异与选择研究](https://doi.org/10.1037/a0023144)把候选生成和选择保留分开；[Berg 关于创意预测的研究](https://doi.org/10.1177/0001839216642211)进一步指出，创作者既要发散，也要预测新点子在真实受众中的结果，而且评价自己的点子比评价别人的点子更容易失准。这些研究只支持流程判断，不提供歌词公式：内部必须把创作者与编辑者暂时分开，先允许候选出现，再像审别人的作品一样淘汰。

每次重要选题按以下顺序裁决：

```text
内部生成至少三条关系因果不同的路线
→ 暂时忘掉是谁提出的，只看材料、歌曲展开和听众结果
→ 为每条路线写出整歌将怎样发展，而不是只看一句说明是否漂亮
→ 排除原作明说内容的摘要和近义改写
→ 用至少两处材料推出本作相对于同题作品新增的唯一认识
→ 淘汰只能列物件、喊态度、借气质或复述题材常识的路线
→ 预测首听能听见什么、复听新增什么、写到第二段最可能在哪里塌掉
→ 判断关键事实是否已经足以押定方向
→ 若足以押定，只公开胜出的主方向；若不足以押定，公开当前优先级最高的方向与由不同事实触发的强分支
```

### 全景扫描不是平铺菜单

用户给出的灵感和主对标只是起点，不是搜索边界。单一例子容易让创作者只在它附近换词；比较不同传统、时代和体式，才更容易看清哪些是可迁移的关系，哪些只是原作的外观。全景扫描因此先问“这首歌真正处理哪一种人性关系”，再沿以下方向内部搜索：

```text
人物与演唱对象
→ 时间、时代与空间
→ 婚姻、职业、家庭、阶层、迁徙等生活制度
→ 古典文本、神话原型、历史处境与文化母题
→ 观察视角、双方知道的信息与误解
→ 人与人、人与自己、人与制度、人与时间的冲突
→ 意象系统与材料来源
→ 口语、民歌、古诗体、新词体、散文体、戏剧独白等语言传统
→ 独唱、对唱、重唱、群唱与声音关系
→ 受众、使用场景与传播动作
```

这张图用于内部发现和淘汰，不要求逐项写给用户。对外展示多少，取决于用户是在尽快立项，还是正在学习和比较创作策略。默认只保留少量会变成不同作品的强路线；用户明确要求看全景时，也不展示十几个排列组合，而是展示三至五条审美距离、作品收益和创作代价真正不同的路线。

### 审美距离不是质量等级

| 距离 | 保留与改变 | 常见收益 | 主要代价 |
| --- | --- | --- | --- |
| 近距 | 保留题材、人物关系和现实语域，改变事实、观察角度或冲突焦点 | 听众第一遍容易进入，较能保留主对标已经验证的情绪效率 | 最容易仍像同类歌，要求材料和语言极准 |
| 中距 | 保留母问题，改变时间、空间、视角、语言传统或演唱形式中的两至三项 | 熟悉感与新意较容易同时成立，常能形成新的段落与声音设计 | 设计变多，任何一项没有落实都会显得拼装 |
| 远距 | 只保留可迁移的人性关系，进入另一时代、制度、文化母题、神话规则、职业或戏剧传统 | 可能建立鲜明作品身份，并让旧经验显出新意义 | 资料、文化、音乐和首听理解成本最高，最容易猎奇或换皮 |
| 反向 | 保留问题，采用与主对标相反的情绪出口、叙事顺序或声音结构 | 能暴露原作方法的边界，找到此前被遮住的另一种成立方式 | 可能损失原作最直接的情绪快感，需要歌手与音乐补足 |

近距不低级，远距也不高级。最好的路线是最适合当前作品任务、歌手、材料、受众和制作条件的那一条。若用户已经明确现代都市发行、特定歌手与旋律，近距往往更负责任；若当前目标是建立作者身份，且有足够文化材料与音乐支持，中距或远距才值得增加投入。

### 跨域迁移五问

把都市失恋迁到古代或神话，不能只把合同换成婚书，把街灯换成月亮，把分别换成断红线。每条跨域路线必须回答：

```text
原作真正可迁移的关系是什么
→ 新领域中哪个具体人物确实承受同一种关系
→ 新领域改变了谁能决定、谁先知道、谁必须等待、谁承担什么代价
→ 新语言与意象为什么属于这个人物，而不是作者从资料库贴上去
→ 不懂原典的听众第一遍能否听懂人物正在失去什么
```

迁移后至少有两项现实规则发生变化，才算另一首歌。只换时代服装、神话角色、古风词汇、色彩和物件，仍是换皮；典故需要长篇注释才能听懂，说明它没有完成歌词的听觉转化；只因为罕见而选，说明新意来自资料库，不来自人物。

### 《歌词写作十八讲》对远距路线的限制

本项目本地资料《歌词写作十八讲》第一讲区分诗与歌词：诗可以让人反复阅读，歌词随音乐向前，一听而过，因此要把深意写进浅显、明朗、自然的语言；第三讲要求作者优先写自己熟悉、感受深的生活，同题作品已经很多时再寻找新角度、新手法和现代处境；书末又要求创作前明确为何用途、为何歌手、为何听众。这里不把教材中的个别结论当成永恒市场规律，只采用四条仍可执行的创作约束：

```text
跨域材料不熟，先调查、访谈或核实，不能靠古风词和资料摘要补生活
→ 新设定第一遍听不懂人物正在做什么、失去什么，就退回改写
→ 新题材必须保留一个集中的抒情问题，不能把历史知识和世界设定塞成说明文
→ 路线不适合当前歌手、旋律、用途和听众时，不因文学上罕见而保留
```

这也解释了为什么“博采众长”和“写熟悉生活”并不矛盾：可以向诗、小说、戏剧、曲艺、历史和神话借观察方法、人物规则与声音形式，但最终必须把借来的能力消化成当前人物听得懂、唱得出、承担得起的生活。跨域是扩大选择，不是逃离生活。

### 全景比较矩阵

进入推荐前，每条强候选至少比较：

| 维度 | 必须回答 |
| --- | --- |
| 与原意距离 | 保留了用户哪一项真实冲动，离开了哪一项预期 |
| 新增认识 | 新场景让听众多看见了什么关系或代价 |
| 迁移轴 | 改变了时代、制度、视角、冲突、意象、语言还是声音中的哪些项 |
| 材料可信度 | 来自用户事实、可靠资料、授权个案还是创作假设 |
| 整歌空间 | 主歌、副歌、桥段和结尾分别有什么可写，第二段会不会枯竭 |
| 语言与意象 | 这套用词、动作和景物为何属于人物，能否寄情于景而非堆景 |
| 歌手与音乐 | 谁唱最可信，曲风与声音形式是否需要这条路线 |
| 首听成本 | 不看说明能否听懂谁对谁做了什么 |
| 记忆与使用 | 听众可能记住、引用、跟唱或在什么场景使用 |
| 相似风险 | 与主对标重合在词句、物件、推进、韵脚、旋律还是结论 |
| 投入与风险 | 调研、写词、谱曲、制作及文化误读成本 |
| 裁决 | 推荐等级、主动放弃和什么新事实会改判 |

全面的价值不在“全说出来”，而在没有错过真正更好的路。内部可以走遍，公开必须选择。

### 解释竞争与最少假设

同一文本常常允许多种成立解释。选题分析不能把最顺滑的一种直接当成作者事实，也不能用一句抽象概括遮住其他可能。每条候选先完成：

```text
直接证据：哪些词句、动作、顺序和重复可以核对
→ 当前解释：这些证据共同支持什么
→ 竞争解释：同一证据还可以怎样理解
→ 新增假设：为了让当前解释成立，额外编入了哪些人物经历、责任、时间或动机
→ 判别材料：补到哪一条事实时，可以在几种解释之间改判
```

路线胜出不是因为它听起来更深，而是它同时做到：解释现有材料较多；额外假设较少；能持续改变主歌、副歌、桥段和结尾；并且相对于对标形成新的作品贡献。若两条解释仍需不同人物事实才能区分，对外给当前优先级和条件式分支，不强押唯一答案。

以下推论没有额外证据时一律不得成立：未完成的动作等于分手突然；留下的物件等于剩下的人必须收尾；歌者还在痛苦等于现实关系没有结束；连续追问等于双方共同决定后由一人承担后果；某人离开等于他把所有责任丢给另一人。这些都可以成为调查方向或用户选择的虚构前提，不能由模型补成当前人物事实。

### 修辞效果不等于故事事实

分析对标时，每项先写两栏：

```text
文字效果：听众从词语、语序、重复、押韵和声音中感到什么
→ 事实边界：这些文字仍不能证明哪项时间、动机、责任和结果
```

`还没、来不及`可能让听众感到事情离得很近，也可能表现歌者主观上迟迟不能适应；不能因此断言分手发生得突然或关系结束得快。连续追问表现歌者怎样说，不能直接证明对方怎样做。债务语义表现人物怎样理解爱，不能把亏欠写成客观裁决。高水平分析不仅看见效果，也知道效果没有证明什么。

### 只有对标文本时，先推荐方法，不替新人物定故事

用户只给对标歌词时，原作可以证明某种写法有效，不能证明新人物应该经历相近故事。此时最高强度的确定结论是：原作哪些文字、结构和声音能力值得迁移；哪些具体组合已经被原作占据；新歌还缺哪种人物事实。人物方向只能按条件提出：

```text
如果新材料证明 X，路线一怎样写
→ 如果新材料证明 Y，路线二为什么会变成另一首歌
→ 当前先保留哪种写法能力，暂不替用户决定哪一种人生
```

不得把原作中的一句扩写成新歌。例如从“你教我勇敢”扩写为“你改变了我的习惯、审美和生活方式”，仍然是在原句周围增殖，不是新作发现。若主推荐与被淘汰路线删掉修饰语后都能还原成同一句普通话，二者属于同一路线，必须重新生成。

只有对标时，优先比较材料入口，不比较哪句抽象总结更漂亮：

```text
动作入口：寻找一个前后用法、对象或结果发生变化的动作
原话入口：寻找一句当时没有听懂、后来意思改变的话
解释分歧入口：寻找两个人对同一件事怎样理解不同
现实处境入口：确认是否确有共同事务、身份或责任继续影响人物
```

这些不是固定四选一，而是防止系统用故事库存补空。每个入口必须说明需要用户提供或允许虚构的具体事实，以及这个事实怎样改变主歌、副歌和结尾。没有事实时，不得把入口写成完成态标题或副歌概括。材料入口也不得自带唯一解释：“一句后来才听懂的话”不等于对方早已告别；它也可能暴露误会、善意、逃避、身份变化或歌者自己的偏见。“一个前后用法改变的动作”不等于人物还在等待。入口只规定找什么，找到材料后再比较解释。

“唯一认识”不是要求作品只能表达一个意思，而是要求它有一个不可替代的发现统领全歌。它必须回答：这份材料让我们看见了哪一种此前被说得太粗、太安全或太习惯的关系；如果删掉这个发现，作品为什么会退回普通同题歌。答案若只是失恋很痛、成长要付代价、爱过就会留下痕迹、告别需要说清，尚未完成选题。

按四级判断分析深度：

| 层级 | 实际完成了什么 | 能否作为主推荐 |
| --- | --- | --- |
| 题材摘要 | 复述这是一首失恋、成长、乡愁或励志歌 | 不能 |
| 写法归纳 | 看出它使用生活细节、连续追问、反复或反转 | 只能说明怎样写，不能决定新歌写什么 |
| 关系重解 | 用两处以上材料推出原作没有直接说出的时间、责任、知识、误解或需要差异，并说明竞争解释为何较弱 | 可以进入候选 |
| 整歌裁决 | 新解释能够同时改变主歌证据、副歌问题、桥段认识和结尾动作 | 才有资格成为主推荐 |

新作不能把主对标已经明说的句子改成抽象主题后，声称发现了更深方向。例如原词写“你教我勇敢”，候选写成“你改变了我、我失去了被你改变的自己”，仍然依附原句，没有改变关系因果。可以调查双方何时意识到关系变化、歌者把什么动作理解成什么、两人的认知是否存在时间差；但这些首先是问题，不是答案。只有推论确有两处以上文本或生活材料支持，才允许成为新方向；不得为了显得深刻凭空补出“对方早已告别、歌者今天才开始失去”之类的故事。

公开推荐必须承担五件事：指出最值得保护的材料；说明主方向为何胜出；点名淘汰一至两条最诱人的普通路线；说明选择后主歌、副歌和结尾将被迫怎样写；写出什么新事实会推翻推荐。若人物关系、时间节点或私人材料尚未确定，再补上“如果出现哪条事实，为什么要改走另一条”。锋利不是故意反常，担当也不是假装必然正确；没有证据的地方准确保留为假设。

## 一、六类有效新意

### 1. 关系新

同题材中少见但真实的关系、权力与责任位置。例如不是泛写母子情，而是成年女儿第一次成为母亲后，才听懂母亲当年的沉默。

检查：关系是否真实存在；双方欲望是否不同；新意是否只靠身份猎奇。

### 2. 处境新

旧关系进入新的技术、经济、迁徙、家庭或社会条件，产生了以前没有的代价。

检查：新条件是否真的改变人物行为，还是只在歌词里出现一个当代名词。

### 3. 材料新

来自具体职业、家庭、地域、世代或亲历的动作、说法和证据。

检查：材料换到另一个人物身上是否仍成立；是否已核实；是否只是生僻知识展示。

### 4. 角度新

改变观察者、演唱对象、时间点、空间位置或知道的信息，使同一事件产生不同意义。

检查：角度改变是否影响主题与关系；只把第一人称改第三人称不算。

### 5. 形式新

对唱、重唱、群唱、互动、角色歌、现场使用或声音结构与内容互相需要。

检查：去掉形式后是否损失核心意义；如果不损失，形式可能只是包装。

### 6. 判断新

作品对常见经验给出更准确、更复杂或更诚实的命名。

检查：是否能由人物和材料证明；是否只是为了反常而反对常识。

## 二、三角对标与全层拆解

至少建立三类样本：用户给出的主对标；同题材、不同表达方法的代表作；使用同一关键技法、但题材不同的代表作。必要时再补近年同用途作品和反向成立作品。三角比较用于区分“这首作品独有的组合”与“高水平创作普遍使用的方法”。

### 样本有效性门槛

每个对标样本必须通过四项检查：

1. **具名可核**：写出作品名与创作者，并能找到可靠歌词文本、录音、正式出版物、创作者访谈或可信专业评论。
2. **问题相同或技法相同**：同题异写真正处理当前作品的核心关系；同技法异题真正使用当前要学的问句、复沓、押韵、段落或声音方法。只有“大概都写普通人、失恋、成长”不算同题。
3. **证据具体**：指出哪一段、哪种排列、哪次重复、哪个视角转换或哪种押韵组织完成了什么。只概括“有力量、很真实、很励志”无效。
4. **适配当前任务**：说明该能力为什么能迁移到当前歌手、用途、听众和音乐条件；名气、奖项、播放量与歌名相似不能单独构成资格。

禁止从记忆里抓三首最有名的歌，再用题材标签为它们补理由。无法核实有效样本时，标明研究缺口和路线的暂定性质；不得编造原句、创作访谈和作者意图。

### 证据不是装饰

每次引用对标作品，都必须完成以下五步：

```text
指出具体句子、段落或声音位置
→ 拆出词语、语序、动词、重音、押韵、重复或段落动作
→ 说明它怎样让听众看见人物关系，并指出它解决了什么创作问题
→ 说明当前路线准备怎样迁移，而不是怎样换几个名词
→ 说明迁移后的收益、代价和相似风险
```

作品名、奖项、播放量和理论名称不能单独证明路线成立。找不到可靠原文或具体位置时，降低结论强度并标为待核实；不要用记忆补写歌词。用户已经提供的歌词可以直接作为主对标材料，但仍要指明具体行句在主歌、副歌或桥段中的功能。

### 看词与词之间怎样咬合

成熟拆解不能只给每行贴“画面、控诉、升华”标签。继续寻找跨行组织：同一时间词怎样反复；同一语义场中的动词和名词怎样互相接力；一个比喻如何从主歌进入副歌；韵脚是否把原本不同的概念拉进同一听觉；重复回来时文字是否新增信息，若没有，升级由旋律、编曲还是演唱承担。

例如一组歌词同时出现“还、保管、两清、赔上”，应检查它们是否共同形成债务、保管和结算的语义场，而不是分别说成四个漂亮词。若副歌后两次逐字重复，应明确：歌词文本没有继续提供新事实，作品把加压任务交给了音乐和声音；新作可以作同样选择，也可以让最后一次回归改词增义，但必须公开代价。

每项分析同时写收益和限制：它为什么有效；它把人物压缩成什么；它是否依赖歌手和音乐才能成立；迁移到新作时保留会得到什么、放弃会损失什么。对标是教材，不是不可批评的答案。

记录：

| 维度 | 对标作品已经占据什么 | 本作准备怎样不同 |
| --- | --- | --- |
| 主关系 | 谁与谁、什么权力位置 | 关系差异 |
| 关键处境 | 在哪个节点开口 | 处境差异 |
| 中心句功能 | 承认、请求、质问等 | 语言动作差异 |
| 意象领域 | 主要物件、地点与文化 | 材料差异 |
| 展开机制 | 时间、回忆、问答等 | 运动差异 |
| 情绪结论 | 最后让人相信什么 | 判断差异 |
| 歌手与用途 | 谁唱、在哪里使用 | 适配差异 |
| 段落功能 | 主歌、副歌、桥段各增加什么 | 功能可留，排列与比例怎样重建 |
| 修辞推进 | 追问、排比、复沓、对照怎样升级 | 保留哪类动作，改变对象与顺序 |
| 句式与韵律 | 句长、停顿、重音、韵脚和元音怎样协作 | 保留听觉原则，改写具体地图 |

对标后做四项决定：保留什么通用方法，变形什么有效组合，避开什么具体表达，补出什么当前作品自己的关系与认识。不得因防相似而丢掉对标最有价值的结构、修辞和声音经验，也不得因“学习方法”保留原作的整套表达顺序。

### 程度判断与权重

相似性不是“像了就删、不像就用”的开关。每项要分别写出五个判断：

```text
文字与情绪质量收益：保留它是否让人物更准确、更有力、更可唱
听众熟悉度收益：保留它是否降低第一次听懂、记住和跟唱的成本
作品独立性：新作是否拥有自己的关系、材料、语义推进和最终判断
相似与版权风险：具体词句、独特细节组合、语义顺序、韵脚、旋律和结论重合到什么程度
当前适配：它是否适合这位歌手、这首歌的用途和目标听众
```

按下面的梯度处理：

| 重合情况 | 默认判断 | 必须做的事 |
| --- | --- | --- |
| 公共技法，人物关系和材料明显不同 | 通常保留 | 说明原作的语言动作，以及新作怎样完成自己的动作 |
| 公共技法，题材相近但关系、顺序或结论不同 | 评估后改造 | 保留听众已经熟悉的入口，同时改动至少两项语义、句法、节奏、对象、段落位置或结尾 |
| 技法、相同物件组合、相同语义顺序、相近韵脚或旋律共同重合 | 高风险 | 先保留质量收益，再重建材料组合、问题链、韵脚地图和结论；必要时放弃整组表达 |

连续问句、复沓、排比、押韵和短句爆发本身属于公共方法。不能因为它们像对标的优点就自动删除，也不能因为它们有效就整套照搬。最终要说明：保留会让听众得到什么，改变会损失什么，当前作品为什么承担得起这项代价。没有听众数据时，传播优势只能写成推测，不得写成事实。

### 对标样本的三层校准

对标不能只找最有名的歌。至少建立三组样本：

1. **长期代表作**：经过时间、反复演唱或跨代使用检验，观察它为什么没有随热点一起失效。
2. **近年同用途作品**：与当前歌手、平台、听众和使用场景接近，观察今天的实际竞争环境。
3. **反向成立作品**：审美、叙述或音乐选择与本作不同，但同样完成人物、关系和听众任务，用来防止把一种风格误当成唯一答案。

每首对标作品分开记录市场结果、专业价值和历史影响。传播广不等于选题深，专业认可也不等于适合当前用途。关系发现、材料组织、段落功能、修辞类别、问句压力、押韵原则和重复策略都可以学习；原句、原细节组合、原比喻群、逐行句法、原韵脚地图和可识别旋律不得照搬。

对标后必须回答：本作学习了哪一层能力；这层能力在原作中怎样工作；新作改变了哪个对象、关系、顺序、节奏和结论；听众为什么不会把它听成换词版。若只能说“保留底层、换掉表面”或“写得更高级、更有画面、更感人”，迁移尚未完成。

### 二创迁移表

| 类别 | 判断 | 交付要求 |
| --- | --- | --- |
| 保留 | 通用方法与新作高度匹配 | 说明它原本完成什么，新作怎样继续完成 |
| 变形 | 有效但组合过于接近主对标 | 至少改变对象、语义推进、段落位置、句法节奏、韵脚和结论中的两项 |
| 避让 | 原作可识别的具体表达 | 列出原句、细节组合、比喻群、逐行对应和旋律风险，不做近义替换 |
| 新增 | 新作必须拥有的独立贡献 | 写清人物关系、新材料、新判断或新的听觉组织 |

连续追问不能被整类列入避让。应拆出每一问的对象与动作，判断它如何从困惑走向控诉、请求、身份危机或自我暴露；新作可以保留问句密度和情绪加压，但必须改变问题链、起手词、信息顺序、句长、韵脚和最终落点。

专业校准可以参考[Amabile 的领域共识评估方法](https://doi.org/10.1037/0022-3514.43.5.997)，但不能把专家人数当成艺术真理。校准者必须真正熟悉当前歌词类型，只判断自己有资格判断的维度；分歧要追溯到体裁、用途、事实和审美取舍。[创造力系统模型](https://doi.org/10.1007/978-94-017-9085-7)可用于提醒作品还处在既有文化领域和专业共同体中，不能只凭作者自称新颖便成立。

## 三、伪新意过滤

以下变化不能单独证明新意：

- 把高频词换成生僻词。
- 把雨、月亮、车站换成另一种景物。
- 用古风、赛博、方言或网络热词换皮。
- 把多个流行题材和音乐类型混在一起。
- 给人物增加极端身份，但生活逻辑没有变化。
- 故意写反常结论，只为了制造争议。
- 与代表作结构一致，只替换名词和语气。

### 首轮联想校准

以下内容一旦在首轮自动联想中出现，先标为类型基线，不得未经比较直接推荐：

- 题材对应的固定场景、固定物件和固定职业。
- 参考作品的表面装置及其语义邻居。
- “现代生活”自动对应的设备、账号、平台和操作。
- “成熟、清醒、治愈、自爱、和解、拿回自己”等现成结论。
- 只靠反差、反转、猎奇和宏大范围制造价值感的命题。

类型基线不是永久禁用表。真实材料、明确虚构设定或对标比较证明某项最准确时可以保留；保留时说明它为何必要、怎样与其他元素形成新组合。刻意绕开所有常见元素也会制造虚假新奇。

### 深层独立与表层迁移双测试

先暂时删掉物件、技术名词、职业、地点、时代标签和修辞风格，只保留人物、关系、处境、关键动作和判断。满足以下三项，说明作品不是只靠换皮：

1. 仍能说出一个旧题材中少见但真实的关系位置。
2. 仍能指出一个由事实推出、不能用正确口号替代的判断。
3. 仍能解释为什么这个人必须在这个时刻对这个对象唱出来。

再把语言与声音放回去，检查四项：修辞是否仍完成当前人物的动作；句式是否根据新语义重新生长；韵脚是否服务新的高潮；表层选择是否形成新作自己的记忆。深层独立不等于表层可以普通，表层精巧也不能替代深层独立；两层都通过才算完成迁移。

## 四、判断作品寿命

### 1. 即时型

依赖具体事件、热点、平台机制、活动和发布窗口。判断：窗口从何时开始，何时结束；过期后还有没有人物与关系价值；制作周期是否赶得上。

### 2. 周期型

在春节、毕业、婚礼、纪念日、赛事、节庆、招新、开学等时刻重复被需要。判断：每个周期重新发生的关系是什么；作品是否只适合某一届具体事件。

### 3. 常青型

依赖长期存在的人性、家庭、爱情、成长、劳动和身份处境。判断：是否以具体人物承载普遍经验；是否因追求普遍而把时代和生活全部擦掉。

寿命没有高低。一次纪念项目可以只活在一个晚上，前提是它准确完成那个晚上。寿命判断用于校准投入和复用，不用于强迫所有作品常青。

## 五、判断投入

### 投入项目

- 人物访谈与田野调查。
- 事实、文化、行业和法律核验。
- 写词、谱曲、编曲、录音、演唱和视觉制作。
- 沟通、修改、审批与版本管理。
- 授权、版权、独家和素材采购。
- 发布时间、团队注意力与错过其他项目的机会成本。

### 必要投入

会改变人物真实性、核心任务、文化准确、演唱适配、法律风险或作品寿命的工作。

### 无效投入

不会提高成功概率，只是因方向未定而反复精修；在未确认选题时制作完整编曲、MV 或多版成品；用更多辞藻掩盖材料不足。

## 六、投入决策矩阵

| 选题价值 | 证据与材料 | 现实机会 | 建议 |
| --- | --- | --- | --- |
| 高 | 足 | 明确 | 进入完整创作，建立里程碑 |
| 高 | 不足 | 明确 | 先做关键调查和局部验证 |
| 高 | 足 | 不明确 | 做可复用样稿或小规模发布验证 |
| 一般 | 足 | 明确 | 判断任务收益，限制投入上限 |
| 一般 | 不足 | 不明确 | 暂停，不用精修制造沉没成本 |

“高价值”必须能说明对谁、解决什么、凭什么成立，不能来自创作者舍不得放弃。

## 七、复用价值

从五层判断：

1. **作品复用**：能否进入其他歌手、现场、影视、短视频或周期场景。
2. **素材复用**：访谈、田野、人物档案能否支持其他命题。
3. **方法复用**：这次建立的判断和流程是否可用于相近任务。
4. **关系复用**：是否建立可靠的歌手、制作、委托与受众合作。
5. **品牌资产**：是否强化创作者长期擅长和听众认知。

复用不能违反独家、隐私和授权边界。能够复用也不代表要把一首歌拆成大量同质内容。

## 八、区分单首机会与长期主攻

### 单首机会

看当前材料成熟度、时间窗口、歌手、用途、收益与风险。一次题目可以因委约、人物或事件特别成熟而值得做。

### 长期主攻

看是否具备：

- 长期生活来源和观察入口。
- 持续兴趣，而非短期热点焦虑。
- 能不断出现新关系和新材料。
- 对应歌手、制作和发布网络。
- 可识别但不自我重复的审美方向。
- 真实听众愿意长期跟随。

长期方向至少列出五个彼此不重复的潜在命题。若只能想出同一首歌的五种换皮，它还不是长期方向。

## 九、最低成本验证

在高成本投入前，根据最大不确定性选择一项：

- **生活不确定**：访谈当事人或领域专业者。
- **受众不确定**：向真实目标听众展示命题和中心句。
- **歌手不确定**：试唱两种口吻或声区。
- **音乐不确定**：用简单伴奏或 topline 测试。
- **任务不确定**：与委托方比较两种方向，锁定唯一任务。
- **传播不确定**：小规模发布片段，但同时检查完整作品空间。

验证必须提前写明什么结果会继续、修改或停止。没有停止条件的验证容易变成不断寻找支持。

## 十一、失效判定

- 用“更高级、更有画面、更年轻”宣称差异。
- 只对标最知名作品，不对标同用途和近年实际作品。
- 把成功作品的传播结果全部归因于歌词。
- 把即时热点误判为长期需求，或以常青为名写得抽象。
- 因已经投入很多而继续投入方向错误的题目。
- 把一次委约机会当作长期定位。
- 复用判断忽略版权、隐私和独家限制。
- 第一轮想到什么就推荐什么，再用规则为高频方案补写理由。
- 以“数字化、当代、现代生活”作为新意本身，而没有证明新条件改变了人物关系。
- 把陌生化误解为生僻化、猎奇化或故意反常。
- 没有真实材料和停止条件，却把候选数量、字数或分析层数当成创作进展。
- 把内部候选全部平铺给用户，用选项数量替代专业淘汰。
- 推荐只写优点和风险，没有说明主动放弃什么、整歌会怎样发展、什么证据会推翻判断。
- 把原作已经明说的内容换成抽象概念，例如从“教我勇敢”直接推成“我被你改变”，再把复述冒充新发现。
- 把未完成、残留、追问和痛苦自动解释成突然分手、替两个人收尾、关系仍未结束、共同决定后由一人承担后果。
- 只给一种顺滑解释，没有列竞争解释、额外假设和能够改判的材料。
- 只有对标歌词时，把一条创作假设包装成主推荐，没有先推荐可迁移方法并给事实触发的强分支。
- 主推荐与被淘汰路线去掉修饰后是同一句话，例如一边推荐“被训练成另一种生活”，一边淘汰“你改变了我”。
- 只有对标时直接给“被改变、解释权、生活习惯、早有预谋”等故事结论，没有先给材料搜索路线。
- 多条路线都从主对标同一句扩写，只是把“你教我勇敢”改成习惯、审美、身份和解释权。
- 把修辞效果写成故事事实，例如由“还没、来不及”断言分手突然或关系结束得快，由连续追问断言对方确有责任。
- 材料入口自带唯一故事，例如把“一句后来才听懂的话”直接写成“对方早已在告别”。
- 所有候选都停留在主对标附近，只在旧话、动作、误会和物件之间换入口，没有扫描时代、制度、冲突、体式、声音与传播场景。
- 把近距、中距、远距当成普通、高级、殿堂级的价值排序，为了显得有想象力强行远离用户目的。
- 把都市合同换成古代婚书、把现代离别换成孟婆红线，人物能做什么、知道什么、承担什么和怎样结束都没有改变。
- 展示十几个分类组合，让用户替系统完成筛选；或只给一条路线，让用户看不见其他真正成立的作品可能性。
- 只写文学新意，不推演目标听众、首听成本、声音形式、传播动作和制作代价。
