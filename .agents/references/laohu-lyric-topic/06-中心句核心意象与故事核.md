# 中心句、核心意象与故事核

## 什么时候读取

人物和方向已经成立，但缺副歌重心、记忆句、核心意象、故事核或工作标题时，读取本文件。已有句子、意象或标题需要验证时，也读取。

如果任务要求真正创作副歌核心句，而不只是说明副歌写什么，调用 `laohu-lyric-writing`，由写词 Skill 读取[副歌核心句与传播记忆](../laohu-lyric-writing/副歌核心句与传播记忆.md)。本文件负责四种锚点的关系，写词 reference 负责核心句的语言动作、记忆条件、候选生成和局部歌词验证。

锚点只负责验证命题，不要求全部具备。所有锚点服从人物、关系和主题；局部漂亮不得绑架作品。

锚点不能替空命题制造“已经是一首歌”的错觉，但可以帮助用户比较路线。人物关系尚未锁定时，允许为不同路线各试一个中心句功能、意象运动或工作标题；必须说明它在验证什么，不把试验当成定稿。进入正式命题前，再完成三角对标、材料核验和相似性审查。

路线讨论中的“副歌问题”默认只说明人物要完成什么语言动作，例如“质问对方为什么说了 X，却做了 Y”；其中 X、Y 必须来自已经确认的材料，不直接拼一条像歌词的问句，也不借示例偷加人物责任。只有人物材料已经成立，并实际调用 `laohu-lyric-writing` 完成候选生成、可唱性和传播记忆检验后，才展示字面核心句。`你改变了我，却把改变后的我交给谁`、`你把哪一部分责任交给了我`一类句子既没有自然口语，也没有足够材料，不能因写成第二人称问句便冒充副歌方向。

## 一、先确定全歌最需要留下什么

寻找句子和意象前，先用普通话回答：

- 人物终于承认、请求、质问、拒绝或决定了什么？
- 听众听完后应该带走哪一种关系认识，而不只是“很感动”？
- 如果整首歌只能留下一个动作、一句话或一幅关系画面，留什么？

答案仍是“珍惜、成长、遗憾、爱与希望”，重心就没有形成。答案必须包含人物位置和关系动作，例如“他舍不得的不是城，是承认这里已经没人等他”。

## 二、中心句的五种功能

### 1. 承认

人物说出此前一直回避的事实。适合内在防御强、关系已无法继续伪装的题目。

### 2. 请求

人物希望对象采取行动、留下回应或给出许可。请求越具体，关系压力越清楚。

### 3. 质问

人物迫使对象面对矛盾。必须知道他真正想得到答案，还是借提问表达控诉。

### 4. 决定

人物从犹豫进入行动。决定要有代价，不能只是“我要勇敢、我要出发”。

### 5. 命名

为许多人经历过却没有准确说出的关系找到一句话。它适合传播，但不能脱离具体人物变成社交媒体格言。

中心句只保留一种主功能。同时承认、劝告、升华、安慰所有人，立即判为过载。

## 三、中心句生成步骤

1. 写下人物此刻最想说却一直没说的话，允许粗糙。
2. 删除情绪标签和解释，只保留对象、关系、动作或判断。
3. 把句子放回人物口中，检查词汇、礼貌、分寸和知识边界。
4. 分别改成承认、请求、质问、决定、命名五种功能，比较哪一种最接近人物需要。
5. 用说和哼两种方式测试，删掉只适合阅读、不适合声音的结构。
6. 放进三个不同段落语境，检查每次返回能否获得新义。

### 六项检验

- **人物检验**：只有这个身份的人会这样说吗？
- **关系检验**：不解释背景，能否听出“我”和“你”之间发生了什么？
- **必要检验**：为什么非在此刻说，早一天或晚一年是否不同？
- **可唱检验**：口腔动作、重音和语序是否适合演唱；具体音符留到写词阶段核对。
- **回归检验**：重复不是复印，第二次和最后一次是否因新增材料变义？
- **借用检验**：目标听众是否愿意借这句话表达自己，同时仍能认出它属于本作？

再做一次反口号检验：把人物、对象和事实背景删掉，这句话是否立刻变成“放下、和解、勇敢、爱自己、拿回自己”的同义表达；若是，恢复产生这句话的具体关系和代价，或淘汰。传播性允许听众借用，作品归属要求这句话不能由任何人物在任何处境下都成立。

## 四、核心意象不是主题的装饰

核心意象必须持续承载人物关系和变化。它不是给主题贴一张好看的图片，而是让听众通过一个具体东西，重新看见人物和对象之间发生过什么。按四层对应筛选具体事物、场所、自然现象或行动系统：

```text
人物为什么熟悉它
→ 它在关系中发生过什么
→ 它的物理属性与主题有什么真实相似
→ 它如何改变人物当下的动作
→ 它如何随段落改变意义
```

“门”可以开、关、反锁、虚掩、隔音，也涉及进入许可和关系边界。人物必须真实生活在这套动作里；只因“门象征隔阂”而选门，仍是概念套物象。

对标创作时，先区分公共物件与原作独特组合。外套、照片、晚餐、门、雨等单个物件不因出现在名作中就永久禁用；但原作的核心物件群、动作顺序、意象变义路径和情绪落点不得成套复刻。若继续使用其中某个公共物件，必须证明它最适合新人物的生活，并让它进入不同的关系动作、段落功能和主题认识。只把原物件换成语义相近或时代更新的物件，关系因果不变，仍属于换皮。

### 意象的理论底座与适用边界

本项目把“借景抒情、借物抒情、寓情于景”落实成一条可检查的因果链，而不是把它们当作景物清单。王国维所谓“一切景语皆情语”，重点不在景物天然带情绪，而在观看者的处境改变了他看见什么、记住什么、怎样解释物的状态。T. S. Eliot 的“客观对应物”提醒我们，情绪不能只由作者宣布，应由一组物件、处境和动作把听众带到那个情绪里；Pound 的意象观强调具体形象必须同时携带感知和情绪认识；Shklovsky 的陌生化不是寻找冷门名词，而是让熟悉事物在新的关系和观看方式中重新变得可感。

这些理论不能替用户补写人生。它们只规定选择和验证方法：景物无情绪标签，物件无现成主题，陌生名词无自动价值。真正进入歌词前，必须能指出人物的私人来处、物的真实属性、关系中的旧动作、现在的变化，以及听众从这些事实中自行感到的东西。缺任一项，降级为调查问题，不写成已成立的意象。

### 意象准入五问

提出任何场景或物件前，逐项回答：

1. 人物为什么偏偏注意到它，而不是旁边的其他东西？
2. 它在两人的关系中曾经发生过哪件具体的事？
3. 它的温度、重量、声音、位置、损坏、使用方式或限制，怎样真实地改变人物动作？
4. 换成同类物件，关系和情绪是否几乎不变？如果不变，它只是库存替换。
5. 主歌、第一次副歌和结尾再次出现时，它各自新增了什么信息？

如果只能回答“它象征孤独、代表遗憾、很有画面”，立即退回材料采集。不能用形容词代替物性，不能用象征意义代替人物经历。沟通层同样不能用“生活替谁作证”“人停在两个人的时间里”“关系往前推一层”之类抽象句代替人物、事实和动作；这类话最多是内部草稿，不能作为给用户的方向说明、标题或核心句。

同一条禁令也适用于关系判断。`关系结束得比生活更快`、`对方提前退场`、`我最后才收到通知`、`我替两个人维持一段只剩一个人的关系`听起来像发现，实际都省略了主语、时间和证据。只有当材料已经写明“谁在何时少做了什么、另一方怎样误读、后来哪件事证明误读”时，才可以把它压缩成一句判断；没有材料时只能写成调查问题，不得当作新歌的中心句或路线结论。

对标中的修辞类别和听觉方法可以继续使用。原作以连续追问推进副歌时，先拆每一问的对象、力度、信息和情绪动作，再为新路线设计不同的追问链；不得因为它醒目便弃用，也不得保持原问句数量、起手词、语义顺序和韵脚地图后只换名词。

### 先研究文字，再决定是否迁移

分析优秀对标时，不能停在“它用了问句、排比或复沓”。至少记录：每句的主语和动词，词语的轻重，语序如何制造逼近，哪个字承担重音，句尾怎样押韵或留白，重复后信息怎样增加。连续问句中的每一问必须写明自己的动作，例如追责、求答、逼近身份、承认无能或把控诉转成请求。

迁移时先判断这些文字选择提高了什么：关系压力、人物口吻、听觉记忆、情绪升级还是副歌回归。再判断它们与新人物是否匹配。可以保留相同的问句密度、复沓方式或短句爆发，只要当前人物、问题对象、语义顺序、重音落点和最终判断重新成立；如果保留后会让听众直接认出原作的词句组合，再改造具体表达，不得只换同义词。

### 有效意象的六种来源

- 共同使用过的物件。
- 反复发生关系的地点。
- 人物职业或劳动中的材料与动作。
- 家庭、地域或时代中真实存在的仪式。
- 事件留下的痕迹或缺口。
- 会随时间发生物理变化的事物。

### 意象属性表

为候选意象列出：可见属性、可听属性、触觉或气味、可执行动作、变化规律、文化含义、人物私人含义。只拥有公共文化含义，没有私人关系证据的意象，不作为核心。

### 变义路径

第一次出现说明处境，第二次出现揭示关系，第三次出现见证人物变化。每次都只是“看见同一件东西并感到伤心”，说明它没有发展能力。

## 五、故事核只保留会改变关系的事

故事核不是完整剧情梗概，而是一条可以在歌曲时长内承载情绪的最小因果链：

```text
某个具体人物
→ 在一个关系节点想完成某件事
→ 遭遇来自他人、现实或自身的阻力
→ 做出一个关键动作或没有做出
→ 因此获得、失去、承认或改变什么
```

### 五项检验

1. 去掉背景介绍，两三句话能否说清发生了什么。
2. 关键动作是否由人物欲望引起，而非作者安排的巧合。
3. 阻力是否真实存在，且人物必须付出代价。
4. 结尾变化是否由前文累积而来。
5. 故事是否给抒情留下空间，而不是把歌词变成事件清单。

故事过大时，截取“改变发生的那一天、那一夜、那一次通话或那个动作”；故事过小时，寻找它背后的关系历史和现实风险，不用增加事故与反转制造戏剧性。

## 六、工作标题用于守方向

选题阶段的标题可以暂定。它应完成四件事：指出重心、便于内部讨论、检验作品归属、提示中心句或意象如何回归。

路线标签、工作标题、标题性句和正式歌名不是同一个东西。路线标签服务比较，写清人物动作或关系处境即可；工作标题服务守方向，可以朴素、暂定、随时推翻；标题性句属于歌词内部，要由人物在具体段落中说出来；正式歌名是成曲后的听众入口，必须由完整作品反推。不要把路线说明压成一句看似精妙的歌词，再让用户误以为方向已经被作品证明。

候选标题可来自中心句、人物动作、关系称呼、关键物件、核心地点、未完成事件或矛盾判断。不要仅靠句式花样生成标题。

### 标题检验

- 准确：听完整首后，标题与真正重心一致。
- 精练：删去一词是否更清楚；短不等于省略关键关系。
- 新鲜：与同题作品相比，差异来自内容而非生僻词。
- 顺口：大声报幕、口头推荐和搜索时不拗口、不歧义。
- 归属：换到另一首同题歌上是否仍然成立。
- 回味：听歌前能进入，听歌后获得第二层意思。
- 人话：大声说出来像一个人会自然说出的词组；如果必须解释其中的比喻，先退回工作标题或路线标签。
- 证据：标题里的关系、动作或判断能在已确认材料和歌词发展中找到依据，不靠标题单独制造深度。

正式命名仍由 `laohu-lyric-title` 主持；这里的标题只用于选题验证。

## 七、四种锚点怎样互相校准

- 中心句说出人物真正要完成的语言动作。
- 核心意象给抽象关系一个可反复感知的载体。
- 故事核提供使句子和意象不断变义的因果。
- 工作标题标记三者共同指向的作品重心。

四者互不相干时，不是“元素丰富”，而是命题分裂。若只能保留一项，保留最能守住人物与关系的一项。

## 八、局部试验法

每次只验证一个变量：

| 试验 | 保持不变 | 比较什么 |
| --- | --- | --- |
| 中心句 A/B | 人物、处境、主题 | 语言动作与可回归性 |
| 意象 A/B | 人物、故事核、中心句 | 私人归属与变义能力 |
| 故事核 A/B | 人物、主题、用途 | 因果、代价与歌曲适配 |
| 标题 A/B | 已有命题 | 准确、归属与记忆 |

试验后回到选题判断。不要因为某版文字更华丽就误判命题更强。

## 十、失效判定

- 中心句是正确道理，没有对象和语言动作。
- 副歌核心句只是“共同生活还没撤场”“生活还在替你留下”一类管理员概括，没有人物、对象、动作和可唱的语言压力。
- 把“你把我变成现在这样，却不负责带我走完”一类作者解释直接当作副歌核心句，句子中的责任对象、动作对象和结尾位置没有说清。
- 把“我最后一个知道我们结束了”“你早就离开，我只是后来才发现”一类未经材料证明的心理推测，当作对标二创的本作发现。
- 只给一个带引号的方向句，却没有说明它怎样从主歌材料推出、重复后怎样变义以及为什么值得用户选择。
- 意象只因古典、唯美、电影感或少见而被选中。
- 故事靠巧合、事故和结尾顿悟成立。
- 标题能套在大量同题歌曲上。
- 四种锚点分别漂亮，却不指向同一个人物变化。
- 试写时一次改变多个变量，无法判断成败原因。
- 为保留一句话或意象，反过来修改人物事实。
- 选题尚未形成新关系与真实材料，便用一句顺口的正确态度冒充创作重心。
- 把对标作品的核心装置替换成更新、更冷门的物件，关系因果和变义路径没有改变。
