# 灵感生成与材料采集

## 什么时候读取

用户只有感受、物件、地点、一句话、模糊概念或完全空白时，读取本文件。题目涉及陌生人物、职业、地域、时代、行业或文化时，也读取本文件。

找到值得追问的生活种子，判断材料能否承担人物和主题。不要随机编题。

## 核心判断

从尚未解释完的生活事实寻找灵感：反常动作，多年后才听懂的话，关系改变后仍留下的物件，始终没有发生的事。不得先定漂亮主题，再让生活作证。

材料必须包含人物、动作和关系。车站、旧照片、雨、酒、月亮只是名词；“父亲每次送人到车站都提前回头，因为他不知道怎样看着别人离开”才是材料。

模型最先给出的通常是题材的高频邻居，不是已经成立的灵感。它会把“分手”接到房间、雨夜和旧物，把“现代”接到账号、密码和屏幕，再用“放下、清醒、和解”收束。把第一批联想记录为类型基线：先与代表作、用户材料和反向案例比较，再决定保留、变形或删除。常见元素若最准确、最必要，可以使用；解释顺滑不能单独证明新意。

### 先分四层，再谈方向

面对一段歌词、一次口述或一个生活细节，先分开记录：

```text
文本或生活事实：材料直接写了、说了或发生了什么
→ 人物解释：当事人怎样理解这件事
→ 作者推论：管理员根据多处证据推出了什么
→ 创作假设：为了发展作品，准备请用户选择哪一种可能
```

四层不能互相冒充。歌词写“衣服还没干、晚餐还没吃完”，只能确认这些动作处于未完成状态，以及歌者正在把注意力放在这些地方；它不能单独证明分手突然、双方共同决定结束、歌者必须替两个人善后，也不能证明关系在现实中仍未结束。上述判断只有得到其他词句、用户材料、可靠个案或用户明确采用的虚构设定支持，才能进入路线。

同一事实至少容纳两种解释。例如“反复看见未完成的家务”既可能说明歌者还不能接受分开，也可能只是原作选择这组细节来制造当下感；若新人物材料尚未出现，不能替新歌锁定其中一种。管理员的专业性不在于把一句话说得笃定，而在于知道哪些已经被文本证明，哪些仍要靠创作选择成立。

还要分开语言效果和故事事实：时间副词制造紧迫感，不自动证明事件突然；问句制造关系压力，不自动证明被问者有责任；债务、道路、战争等比喻说明人物怎样理解关系，不自动证明现实中存在对应事实；某段逐字重复强化记忆，不自动说明人物获得了新认识。分析先说“这组文字让听众怎样感觉”，再说“文本还不能确认什么”。

### 多打几个洞，再收束

《歌词写作十八讲》第九讲记录王健的“碰撞法、收网法、掘进法”：同一题材先从不同切入点形成多个稿或材料方向，再通过比较逐步靠近主题，必要时舍弃前稿继续向深处想。这不是要求把一排普通选项交给用户，而是要求管理员在内部真正改变观察位置、人物解释、结构和声音，避免第一条顺滑解释垄断后续创作。

重要灵感按以下顺序发展：

```text
收集感官、动作、原话和关系事实
→ 为同一组事实提出至少两种因果解释
→ 分别推演人物为何此刻开口、主歌会取什么、副歌要完成什么、结尾会新增什么认识
→ 淘汰证据少、假设多、只能换物件或喊态度的路线
→ 再用最有解释力的一条收束材料
```

[Berklee 的 Object / Destination Writing](https://online.berklee.edu/takenote/songwriting-tips-try-destination-writing/)可用于采集视觉、听觉、嗅觉、触觉、味觉和运动细节；这里吸收的是“由具体感官进入人物经验”，不是“细节越多越高级”。外部细节必须和人物内部反应发生关系：它让人物注意到什么、误解什么、做了什么或停下了什么。中国作家网《[用歌词讲好故事](https://www.chinawriter.com.cn/n1/2022/0815/c404004-32502542.html)》强调好歌词因人因事而写，情感要寄托于事件；这里落实为：物件和景色只有参与人物行动、关系变化或认识变化时，才是材料，不是布景清单。

### 先找灵感成立处，再处理高频风险

用户给出一个对标、物件、句式或路线时，先指出它已经准确捕捉到的生活事实、人物关系、情绪压力或听觉优势。只有确认它为什么成立，才能判断它是否需要改造。随后再检查：它是不是只沿着高频联想补齐了人物、场景和结论；如果是，删掉未经证实的部分，保留用户真正想写的那一处。

不得把“常见”直接等同于“无价值”，也不得把“新奇”直接等同于“高级”。常见材料若最能证明当前关系，可以继续使用；新奇材料若没有改变人物行为、责任、知识差、时间位置或代价，必须删除。分析输出先写“成立在哪里”，再写“风险在哪里”，最后给出保留、变形或放弃的理由。

## 创作者与材料的关系

先确认创作者对材料拥有持续注意、真实入口和接受纠正的意愿。亲身创伤不是必要条件，发声资格必须有现实依据。

至少回答：

- 他为什么反复回到这个人、事件或问题，而不是只因题材流行。
- 他凭什么接近材料：亲历、长期观察、可靠关系、正式委约、研究能力还是与当事人的合作。
- 他最可能在哪个位置替自己辩护、浪漫化经历或误读他人。
- 哪一种事实一旦出现，会推翻他目前最想表达的结论。
- 这次作品相对于他长期关注的母题，新增了什么关系、代价或认识。

亲历不保证好作品，陌生题材也不取消资格。检查创作者是否掌握不可替换的材料、允许现实反驳自己，并愿意为事实、人物和授权承担工作。任何人搜索几篇资料都能获得同样位置，作品就没有作者归属。

## 一、六类灵感入口

### 1. 从人进入

寻找最近让用户反复想起的人，不先问“有什么故事”，先问：

- 他通常怎样对待别人，这一次哪里不同？
- 他最想被谁理解，却最不愿向谁解释？
- 他在家庭、工作或关系中长期承担什么位置？
- 他失去什么以后，仍保留着哪个习惯？
- 哪个看似缺点的行为，其实在保护他？

有效结果不是“写一个坚强的母亲”，而是“一个从不向孩子诉苦的母亲，第一次把药费收据留在桌上”。

### 2. 从事件进入

优先寻找让生活出现前后差异的事件：第一次、最后一次、没有赶上、被迫重来、终于停止、身份转换、秘密暴露、误会解开或永远没解开。

继续追问：事件发生前人物相信什么；发生时他做了什么；事后哪个日常动作变了；这件事的代价由谁承担。

### 3. 从物件进入

物件必须进入关系动作：谁买的、谁使用、谁保管、谁丢掉、谁归还、谁不敢碰。先问它在这段关系里发生过什么，再问它能不能好看。检查它是否同时具备：

- 生活归属：属于这个人物和环境。
- 关系证据：能证明两人发生过什么。
- 状态变化：会磨损、移动、损坏、过期、被替换或重新出现。
- 可唱动作：能拿、放、洗、折、等、寄、拆、关、留。

只有审美属性、没有关系动作的物件，暂不升为核心材料。

### 没有私人材料时，不替人物编物件

门锁、导航、账号、生日提醒、购物清单、两人份餐具和手机记录，都是现代生活中常见的类型材料，不是新意本身。用户没有提供它们的真实来处、明确虚构设定或可靠个案时，不得把它们直接写进路线，不能用“现代”“有共鸣”“容易传播”替它们取得资格。

此时的正确交付不是继续列十个物件，而是给出材料调查方向，并说明每个问题会改变哪一条路线：

```text
这件东西在关系开始前是什么
→ 两个人共同生活时谁改变了它的用法
→ 分开以后哪一个动作仍然照旧
→ 人物在哪一刻意识到这个动作已经没有对象
→ 这个意识让他做了什么，或让他没有做什么
```

至少拿到一条具体原话、一项反复动作和一处前后变化，才可以把物件升级为主歌材料。没有这些材料时，只能写清需要寻找哪一项前后变化，例如“分开后，他哪一个以前为对方做的动作仍然会下意识重复”；不允许先把它解释成替两个人工作、替对方善后或承担共同后果，也不允许直接列门锁、导航、账号等库存物件。

### 4. 从地点进入

地点不是布景，先判断它的功能：相遇、等待、劳动、隐藏、告别、返回、跨越还是困住。再找地点中的具体路线、时间、声音、规矩和人物位置。

同一地点至少比较三个观察点：身处其中的人、离开后回望的人、从未进入却受它影响的人。观察点改变，选题才真正改变。

### 5. 从一句话或一个动作进入

记录原话和动作，不急着文学化。重点寻找：

- 话的字面意思与真实意图是否相反。
- 对方当时为什么没听懂。
- 哪个动作替代了人物不肯说的话。
- 这句话若换个人说，关系是否完全不同。
- 它在后来发生什么以后获得了新意思。

能经受这些追问的话，可能成长为中心句；只能单独截图显得漂亮的话，通常还没有作品根系。

### 6. 从反常与未完成进入

反常不是猎奇，而是正常秩序被轻微打破：总准时的人迟到了，最爱说话的人没有告别，已经搬走的人仍按月交水费。

未完成包括未寄出的信、没兑现的约定、迟到的道歉、没有举行的仪式、没问出口的问题。先确认材料只证明“什么没有完成”；再调查是谁阻止、是否有人必须继续处理、人物是在等待、逃避、误解还是已经放弃。没有证据时，这些都是竞争解释，不是既定故事。

### 入口的使用顺序

先让自动联想短暂暴露，再把它们隔离。随后回到用户的生活材料，寻找以下四类事实：

- 本该发生却没有发生的动作。
- 关系改变后仍能观察到的重复动作、称呼、责任或身体反应；它们分别说明什么，尚需验证什么。
- 人物口头承认、实际行动却拒绝承认的事实。
- 让人物难堪、亏欠、误判或无法用“成长、放下、治愈、爱自己”解释的细节。

优先从这些事实生长命题。若候选只能靠新物件、新技术、新职业或生僻地点制造新鲜感，退回材料；若删掉这些表面装置后仍剩下独特的关系判断，再继续验证。

## 二、从种子长成候选命题

每粒种子依次补齐六项：

```text
人物是谁
→ 他与谁或什么发生关系
→ 关系正处于哪个节点
→ 他想得到、保住、承认或拒绝什么
→ 什么现实阻力让它无法直接完成
→ 这一次变化会留下什么
```

同一粒种子至少发展出两种真正不同的候选。改变关系位置、演唱对象、发生时刻或人物选择，不只替换地点和意象。若这些变量尚未确定，对外按“事实条件 → 路线差异”呈现，不把不同假设压成一个笃定命题。

比较候选时看四点：哪一个更需要歌唱；哪一个拥有真实材料；哪一个能让中心句反复变义；哪一个更属于目标歌手和听众。

## 三、材料采集的五个篮子

### 1. 人说过的话

保留词序、称呼、停顿、避讳、口头误差和没有说完的部分。不要先改成“优美表达”，否则会丢掉身份。

### 2. 人做过的动作

记录动作的对象、力度、先后、犹豫和失败。比“他很舍不得”更有用的是“车已经开了，他还把没拧紧的瓶盖攥在手里”。

### 3. 环境如何参与

记录会改变人物行为的温度、光线、声音、气味、距离、交通、规则和物理限制。环境只负责制造处境或回响，不负责替人物自动抒情。

### 4. 关系证据

共同习惯、债务、承诺、称呼变化、权力差、替代动作、共同秘密和反复冲突，都是关系证据。没有证据的“深爱、亏欠、理解”只是作者结论。

### 5. 变化证据

同一物件、句子、动作或地点，在前后发生了什么不同。变化证据是歌词能够展开而不是原地抒情的基础。

## 四、材料可信度分级

| 等级 | 来源 | 可以承担什么 | 还需要什么 |
| --- | --- | --- | --- |
| A | 亲历并有具体记忆、记录或实物 | 人物核心、关系细节、关键动作 | 核对记忆偏差与他人位置 |
| B | 当事人可靠讲述或多次访谈 | 人物核心与事件过程 | 区分事实、解释和自我保护 |
| C | 公开资料、田野观察、多方证据 | 环境、行业、时代与事实边界 | 转化为具体人物关系 |
| D | 类型常识、二手印象、对标启发和作者假设 | 探索路线、虚构设定、调查问题 | 必须标注，不能冒充真实人物事实 |

陌生题材的主关系若主要依赖 D 级材料，可以提供有依据的路线候选和局部试验，但不得锁定现实人物、行业细节和正式命题；先调查，或由用户明确选择把它作为虚构设定继续创作。

对标作品、题材名称、职业标签和人口标签不属于 A/B/C 级新人物事实。对标可以证明某种关系发现、段落功能、修辞、句式、押韵和传播方法怎样成立，也可以支撑探索路线；它不能证明新人物已经经历过原作中的事情。职业和题材可以指明应访问谁、观察什么，不能单独生成具体经历。C 级材料必须指向具体报道、个案、现场或多方核验结果；“骑手通常赶时间”“离婚的人会保留习惯”仍是 D 级概括，不能据此编出主人公的家庭、服务对象和关键动作。

### 两级候选准入

**路线候选**用于启发和选择，满足以下条件即可提出：

1. 已分析用户种子，并比较至少一项代表作品或可靠创作方法。
2. 每条路线说明借鉴的技法、改变的关系和当前假设。
3. 各路线不是同一高频故事的换物件版本。

**正式命题**用于进入完整写词，还要满足：

1. 至少一条 A/B 级材料能够识别现实人物与关系；或用户明确采用一个已核验个案、委约设定或虚构设定。
2. 至少一条已经确认的变化、矛盾、行动后果或用户明确采用的创作前提能够推动全歌；它不必预先属于“未完成、责任错位”等固定类型。
3. 能说清哪些是事实、当事人解释、专业推论和创作假设。

路线候选未通过时，先补对标研究而不是把空白扔回用户。正式命题未通过时，继续用路线卡、局部试验和材料选项引导；不得把未确认假设写进完整歌词后再倒逼用户接受。

### 材料不是装饰，是差异的证据

每一条进入候选命题的材料都要回答：

```text
它具体证明谁与谁的关系
→ 它改变了人物的哪一个行动、责任或判断
→ 换到另一个人物身上是否仍然成立
→ 删除它后，作品损失的是核心认识还是表面画面
```

只负责“看起来当代”“增加画面”“方便押韵”的材料，不进入核心材料表。材料越新奇，越要证明它改变了关系因果；否则它只是模型为高频情绪寻找的新名词。数字材料也遵守同一门槛：它必须改变人物的权限、责任、行动或知识差，不能只因为属于手机和网络就获得现代感。

## 五、陌生题材调查

调查前先列会改变作品的具体问题：

1. 这类人一天中最真实、最重复的动作是什么？
2. 他们怎样称呼彼此，哪些词外行会用而他们不会用？
3. 什么风险、责任或代价只有身处其中的人知道？
4. 外界最常把他们误解成什么？
5. 他们会在哪个时刻听、唱或拒绝这首歌？
6. 哪些事实、文化符号、隐私与伦理边界必须核准？

优先顺序是当事人访谈、现场观察、原始资料、可靠研究、代表作品和普通网络材料。资料互相冲突时保留冲突，不替现实强行整理成单一答案。

### 访谈与材料使用边界

访谈不是向当事人索取一个能证明主题的故事，而是让现实纠正作者的预设。提问时遵守：

- 先问具体时间、地点、动作、原话和顺序，再问当事人怎样理解；不要一开始问“你是不是很痛苦”“这是不是因为爱”。
- 使用开放问题，避免把答案写进问题。把“你当时是不是觉得被抛弃”改成“那天之后，你做的第一件不同的事是什么”。
- 区分四种材料：发生过的事实、当事人的记忆、当事人的解释、作者从材料推出的判断。它们不能混成同一条证据。
- 对同一事件的不同叙述并列记录。冲突可能来自记忆差异、立场差异、信息差或自我保护，不要未经核实替现实裁成单一版本。
- 当一个细节会改变人物责任、文化准确、公共代表性或隐私风险时，安排二次确认；必要时补现场观察、原始记录或第三方资料。
- 让当事人知道材料将用于歌曲、哪些细节可能被识别、谁会听见以及可以撤回或限制哪些内容。未获授权的可识别私人事实不得作为作品核心。

访谈的目标不是让当事人说出“正确主题”，而是找到外部作者无法凭类型常识编出的生活证据。若访谈结束仍只有观点和情绪词，没有动作、关系和后果，材料尚不能承担高水平命题。

此处的授权与访谈边界参考[美国口述史协会的原则与最佳实践](https://oralhistory.org/principles-and-best-practices-revised-2018/)，只吸收持续知情、权力差异、可识别风险和共同责任等稳定原则。歌曲创作不等同学术口述史，具体授权仍按作品用途、当地法律、平台规则和当事人约定处理。

## 六、从材料中提炼，不把材料全部写进去

采集完成后做三次筛选：

1. 删除不能改变人物、关系、处境或主题的知识。
2. 合并只在证明同一件事的重复材料。
3. 保留一旦删掉就会让作品失去身份的动作、话语和关系证据。

最终材料包不追求多，追求不可替换。若材料换到同题材任何人物身上仍成立，继续调查。

## 八、失效判定

- 只列题材名、情绪词、场景词或意象词。
- 一次生成十几个方向，却没有比较依据。
- 把网上常见故事当成用户或人物的真实经历。
- 调查了大量知识，却找不到一个具体人物为什么要唱。
- 用诱导性问题让当事人替作者证明预设主题。
- 把回忆、解释或作者推论伪装成已经核实的事实。
- 忽略多方叙述的冲突，强行保留最符合预设立意的一版。
- 未确认隐私、匿名化、撤回和改编边界就使用可识别经历。
- 物件和地点只有美感，没有关系动作。
- 为了证明预设主题，只收集支持它的材料。
- 把“灵感不足”误解成辞藻不足，提前进入炼句。
- 把第一批自动联想直接写成候选，再用“现代、真实、有传播力”事后证明它成立。
- 只把原作物件替换成语义邻近物件，关系、心理因果和情绪结论没有变化。
- 用“放下、清醒、和解、拿回自己”等正确态度收束尚未被事实推出的命题。
- 没有代表作研究、迁移依据和明确假设，只把同一个高频故事换物件后包装成三条方向；研究型路线可以提供，但不得冒充已经成立的正式命题。
- 把对标歌词当作新作品的生活材料，换掉人物与物件后继续沿用原作关系。
- 把职业常识和公益宣传中的典型桥段当成具体从业者经历。
