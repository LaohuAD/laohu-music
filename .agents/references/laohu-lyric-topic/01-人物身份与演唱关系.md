# 人物身份与演唱关系

## 什么时候读取

出现以下任一情况，读取本文件：

- 用户只说了“一个男人、一个老人、一个孩子、一个打工人”，人物仍是类型标签。
- 同一题材可以由不同身份的人演唱，身份会改变语言、材料和可信度。
- 不清楚主人公唱给谁、谁在旁听、为什么此刻要开口。
- 歌词口吻虽然顺，却不像这个人物会说的话。
- 需要判断人物何时会主动唱、独自哼、在仪式中使用或转发给别人。

## 核心判断

只保留会改变人物观察、理解、开口、隐瞒或承担后果的身份信息。身份信息至少改变下列一项，才能进入创作命题：

```text
说话资格
词汇来源
观察习惯
情绪分寸
记忆跨度
关系权力
现实代价
演唱可信度
```

“38岁，男性，北方人”仍然很空。“38岁，在外地修路十年，每年只在春节见女儿一次；习惯报喜不报忧，不会直接说想念”已经开始决定歌词。

## 一、身份的十个有效层面

### 1. 年龄与人生阶段

不要只写年龄数字。判断这个人生阶段怎样改变责任、关系和时间感：

- 儿童早期：语言来自身体、游戏、模仿和直接因果；时间尺度短，难以自然使用成人总结。
- 学龄儿童：开始理解规则、比较、输赢、友谊和被评价；仍以具体事件理解抽象价值。
- 青春期：身份正在形成，同伴目光、独立愿望、羞耻和第一次经验会放大；语言可能锋利，也可能故意装作不在乎。
- 初入成年：第一次离家、工作、恋爱、失败和经济独立，使理想与现实发生碰撞。
- 建立家庭或事业阶段：选择伴随责任，爱情常与住房、照护、工作、育儿和父母衰老纠缠。
- 中年阶段：时间开始以“来不来得及”被感知，承担、错过、身体变化和代际位置更突出。
- 老年阶段：记忆跨度更长，失去与幸存同时存在；表达可能克制、重复、朴素，也可能顽皮、激烈，不能自动写成说教。

年龄只提供可能性。用真实经历和当下处境校准，不得直接推导性格。

### 2. 性别经验与身体经验

只在性别、身体或社会期待真实改变事件时使用：

- 他被怎样要求表现坚强、温柔、体面、顺从或成功？
- 哪些感受在他的环境里不方便公开说？
- 身体变化、怀孕、疾病、劳动、年龄或外貌是否改变关系？
- 这是一段具体经验，还是作者拿性别刻板印象替人物作决定？

禁止从性别直接推导词风。女性可以冷峻，男性可以细腻，儿童可以严肃，老人可以俏皮；成立与否取决于人物证据。

### 3. 家庭背景与家庭位置

不要停在“原生家庭不好、普通家庭、单亲家庭”。继续确认：

- 他在家中是照顾者、被照顾者、调停者、替罪者、榜样、缺席者还是秘密保管者？
- 家里如何表达爱：做饭、给钱、责骂、沉默、拥抱、办事还是从不表达？
- 谁拥有决定权，谁习惯让步，谁欠谁一句话？
- 家庭最常回避什么，最重视什么，最怕外人知道什么？
- 当前事件是否使旧家庭角色失效或反转？

家庭背景必须解释人物为何这样爱、这样怕、这样沉默。不能只增加悲惨设定。

### 4. 地域、阶层与生活环境

确认人物长期生活在哪里、怎样移动、能接触什么资源。重点不是贴方言，而是：

- 他熟悉哪些天气、地貌、交通、工作节奏、住房和公共空间？
- 金钱、距离、户籍、教育、职业和照护成本怎样影响选择？
- 他把哪里称作“家”，在不同地方分别像什么人？
- 哪些地方语言或生活习惯只有在真实语境中才自然？

地域细节必须来自调查或可靠经验。几个地名、食物和方言词不能代替生活。

### 5. 职业、劳动与日常动作

职业真正能提供的是观察方式、动作、风险和语言，不是一个制服标签：

- 他每天反复做什么动作，身体哪里会累？
- 他习惯用什么单位、工具、比喻和判断标准？
- 工作中什么算失误，失误会伤害谁？
- 他怎样看待时间、承诺、秩序、危险和体面？
- 职业与私人关系在哪里冲突？

写医生不必罗列医学名词，写司机不必堆道路名称；只保留能改变人物关系和情绪的职业事实。

### 6. 教育、文化与语言环境

判断人物平时从哪里获得语言：家庭口语、学校、行业、网络、宗教、地方文化、书籍、影视或音乐。由此决定：

- 他会不会抽象总结，还是更常借具体事情说话？
- 他使用长句、短句、反问、玩笑、典故还是沉默？
- 哪些词他能理解却不会主动说？
- 哪些表达对作者漂亮，对人物却失真？

文化程度不等于语言高低。没有高学历的人可以表达得极其准确；高学历人物也可能在亲密关系里只会说笨拙的短句。

### 7. 关键生活阅历

只选择改变人物判断方式的经历：第一次离开、长期照护、失业、成功、疾病、迁徙、失去、背叛、养育、退役、退休等。每段经历继续问：

- 当时发生了什么具体选择？
- 他从中学会了什么，也误学了什么？
- 这段经历留下了什么动作、物件、习惯或禁区？
- 今天的事件为什么重新碰到了旧伤或旧承诺？

阅历不是越苦越深刻。真正重要的是经历怎样改变了人物现在的行为。

### 8. 性格、欲望与防御方式

不要只写“内向、善良、坚强”。改写成可观察行为：

- 他最想得到什么，又怕承认什么？
- 遇到冲突会讨好、逃走、控制、解释、开玩笑、装忙还是先发火？
- 他维护的自我形象是什么？
- 哪种事实一旦承认，这个形象就会破裂？

人物口吻来自欲望和防御的碰撞。一个爱开玩笑的人，可能不是轻松，而是不愿让别人看见求助。

### 9. 当前资源、限制与现实代价

确认人物现在能做什么、不能做什么：时间、钱、距离、身体、身份、承诺、法律、家庭和舆论。没有代价的选择不会形成压力。

把“我不能去见你”继续拆成：是不愿、没钱、没资格、来不及、怕打扰、答应过别人，还是见面会推翻他已经建立的生活？原因不同，整首歌不同。

### 10. 秘密、误解与知识边界

分别写清：

- 主人公确定知道什么。
- 他依据什么推测对方。
- 他不知道什么。
- 他误解了什么。
- 他明知却不肯承认什么。
- 听众比主人公多知道什么，或同样被蒙在鼓里。

人物不能替作者拥有全知视角。写“你早就不爱我了”时，要确认这是事实、推测还是自我保护；三种写法的责任和情绪完全不同。

## 二、四个位置必须分开

### 歌者

实际发出声音的人。他可能是故事当事人、旁观者、群体代表、角色扮演者或作者本人。

### 演唱对象

歌者在歌词内部真正对谁说。可以是一个具体的人、一个群体、逝者、故乡、时代、物件、未来的自己或过去的自己。

对象至少分四类，不能混用：

- **具体个人**：对象有共同经历、称呼、秘密和回应能力。歌者可以省略双方都知道的背景，但不能替对方宣布内心。
- **具体群体**：对象共享身份、处境或行动，例如战友、同学、照护者。歌者要说明自己凭什么代表或面对这群人，不能把群体写成一种性格。
- **自我对话**：对象是过去、现在或未来的自己。必须区分两个时间位置各自知道什么，不能让过去的自己提前拥有后来的答案。
- **普遍对象**：表面上的“你”允许不同听众代入。仍要保留一组具体关系和处境作为根基；若为了人人代入删掉所有身份，作品会变成无对象的格言。

对象不在场、已经离世、无法回应或只是想象时，人物的语言动作也要改变：他是在倾诉、排练、追问、纪念、请求原谅，还是借一个不会回答的人把话说给自己听。

### 旁听者

歌词没有直接对他说，但作品希望他听见并被击中。歌者唱给母亲，旁听者可能是所有长期没有回家的人。

### 实际使用者

谁会主动播放、演唱、哼唱、分享、购买或把它放进某个仪式。使用者可能与歌者、对象、目标听众完全不同。

四个位置混淆时，歌词容易一会儿像私信，一会儿像公共演讲。先决定内部关系，再决定外部传播。

## 三、演唱时刻、哼唱时刻与使用时刻

必须分别回答：

1. **故事发生时刻**：关系正在发生什么变化。
2. **人物开口时刻**：为什么偏偏现在说，早一天或晚一天是否还成立。
3. **自然哼唱时刻**：人物在走路、工作、夜晚、酒后、仪式、独处还是人群中会哼起它。
4. **听众使用时刻**：听众在通勤、KTV、婚礼、毕业、告别、纪念、运动、亲子或短视频中怎样使用。
5. **分享动作**：听众会公开转发、私发给一个人、自己收藏，还是现场共同唱。

“适合失恋时听”仍然太宽。要继续具体到：刚删掉联系方式的凌晨、整理共同物品时、朋友问起却装作没事时，还是多年后偶然经过旧地点时。不同时间距离决定语言是滚烫、混乱、克制还是已经能够回望。

## 四、身份怎样改变语言质地

从人物资料推导语言时，逐项检查：

| 变量 | 要做的具体判断 |
| --- | --- |
| 词汇 | 来自人物真实生活，还是作者的文学库存 |
| 句法 | 他会完整解释、断裂停顿、重复、反问还是绕着说 |
| 情绪显露 | 直接承认、借事说情、用玩笑遮挡，还是只说行动 |
| 时间感 | 只看眼前、计算几年、反复回忆，还是担心来不及 |
| 修辞来源 | 来自职业、地域、身体和共同记忆，还是通用月亮晚风 |
| 幽默方式 | 自嘲、讽刺、误会、夸张、冷面陈述还是熟人互损 |
| 禁区 | 哪句话他即使想到也不会这样说 |
| 声音强度 | 私下低声、公开宣告、仪式齐唱、舞台表演还是内心独白 |

风格不能直接从年龄或题材推出。先由人物、关系、目的和场景决定说话动作，再选择成熟、童趣、锋利、诙谐、克制或热烈的语言。

## 五、主持步骤

```text
提取用户已经给出的身份事实
→ 删除不会改变创作的装饰信息
→ 找出最影响口吻与关系的一项缺口
→ 给出两种具体身份解释及其作品后果
→ 让用户确认或修正
→ 建立四个位置与三个时刻
→ 写出人物语言边界
→ 用两句局部试写验证
→ 根据试写反向修正身份判断
```

不要一次盘问十项。优先问会让两首歌彻底不同的问题。

## 六、身份卡交付格式

```markdown
### 主人公身份卡
- 基本位置：
- 人生阶段与当前责任：
- 家庭位置与表达习惯：
- 地域、职业与生活语言：
- 改变他的关键阅历：
- 此刻最想得到与最怕承认的：
- 现实限制与代价：
- 知道、误解与不知道的：
- 演唱对象：
- 旁听者与实际使用者：
- 故事发生、开口、哼唱和使用时刻：
- 应有的语言质地：
- 绝不会自然说出的语言：
```

字段按作品删减，不能为了完整虚构资料。

## 七、失效判定

出现以下任一情况，人物仍未建立：

- 删除年龄、职业和地域标签后，人物说话完全不变。
- 所有背景都只负责制造悲惨或高贵，没有改变行为。
- 人物知道所有人的内心，并替作品总结主题。
- 同一句歌词换给另一个年龄、职业、家庭的人仍完全自然。
- 只说“成熟、童趣、锋利、幽默”，却没有说明由什么处境和说话动作产生。
- 不知道人物为什么现在唱、会在什么时候自然哼起。
