# 用途、市场与委约简报

## 什么时候读取

作品面向明确使用任务，或自由创作需要确定发布载体和用途时，读取本文件。

## 核心判断

把主题词、宣传材料和参考作品拆成目的、限制、偏好与素材。它们不是创作命题。先确认作品要改变谁的认识、情绪或行动，再建立一个有资格开口的人物。

市场只说明作品怎样被发现、选择、使用和付费，不命令作者复制高频内容。所有市场结论必须标明事实、推论或假设。

## 一、简报八层拆解

### 1. 硬条件

逐项核对：时长、语言、结构、歌手、音乐类型、平台、画面、交付格式、版本数量、截止时间、审核、署名、版权、预算与修改轮次。

硬条件必须满足。条件相互冲突时，先裁决再创作。

### 2. 唯一核心任务

把“年轻、感人、大气、传播、品牌感、地域特色”改写成结果：让谁在什么场景记住、感到或做什么。

只设一项最高任务。其余要求按支持、可协商、可放弃排序。

### 3. 偏好

参考歌、音乐风格、时代感、语言气质、禁用套路与审美倾向。继续问偏好背后的原因：喜欢的是速度、角色距离、情绪曲线、声音质感，还是传播结果。不要复制参考作品的表面装置。

### 4. 禁区

包括错误事实、不可承诺的效果、人物形象、文化挪用、隐私、政治与伦理风险、品牌竞品、审核和年龄边界。禁区要写成具体行为与词义风险，不只写“注意合规”。

### 5. 隐含对象

区分出资人、发起人、审批人、演唱者、作品中的对象、目标听众和实际使用者。不同人对“成功”的定义可能冲突。

### 6. 矛盾要求

把互相拉扯的要求成对写出，例如：

- 地方特色 / 全国理解。
- 品牌露出 / 不像广告。
- 庄重 / 年轻。
- 信息完整 / 时长很短。
- 领导满意 / 真实群体愿意唱。
- 服务剧情 / 独立传播。

说明不能同时最大化的部分，给出取舍方案，让用户或委托方确认。

### 7. 必要调查

列出必须核实的人、地点、行业动作、历史、产品事实、组织文化、剧本信息和受众反应。资料越多不代表越好，只收集会改变命题和风险的内容。

### 8. 交付与权利

确认词曲权属、独家与非独家、署名、修改权、改编权、录音和表演使用、地域与期限、素材授权、AI 使用约定、未采用方案能否复用。存在不清楚处时标记待确认，不自行作法律结论。

## 二、把简报压缩成一句任务

```text
为【实际使用者】在【使用场景】创作一首由【歌者/角色】唱给【对象】的【类型】歌曲，
通过【具体关系或行动】让【目标听众】产生【可观察结果】，同时必须满足【最高硬条件】并避开【关键禁区】。
```

这句话若只能复述项目口号，继续寻找人物关系和现实结果。

## 三、不同用途的选题方向

### 1. 影视、剧集、动画与游戏

先确定歌曲位置：主题歌、人物歌、关系歌、插曲、片尾歌、场景歌、世界观歌曲或宣传曲。

必须读取剧本、大纲、人物小传、导演意图和歌曲出现节点。回答：唱歌前发生了什么，唱完后观众应怎样重新理解人物或剧情，角色此刻知道什么，歌曲是否承担伏笔、转折、释放或余韵。

主题歌可以从全局提炼关系；人物歌只能使用角色知识；场景歌必须与动作和节奏相连。脱离剧情是否独立成立，由项目目标决定，不是一律要求。

### 2. 品牌与产品

先找品牌或产品与人的真实关系：解决什么处境、参与什么仪式、减少什么代价、代表什么选择。只保留一个最重要主张，并核实它可被证明。

短广告优先记忆与行动；完整品牌歌还需人物和关系。品牌名、产品利益、声音标识和中心句要协同，不把说明书逐条押韵。

### 3. 城市、地域与文旅

先确定唱的人是当地居民、离乡者、来访者、建设者还是历史旁观者。收集会改变生活的地理、产业、语言、路线、节令、人物和现实变化，不做景点与特产清单。

地方特色必须做到“当地人认得，外地人接得住”。用当地材料和文化持有者验证具体文化。

### 4. 行业、职业与组织

从劳动动作、风险、责任、同伴关系、服务对象和共同记忆中选题。组织精神应由人物在关键选择中的行为显出，不把使命愿景价值观原样搬进副歌。

若成员自己不愿唱、外部听众只听见自我表扬，命题没有成立。

### 5. 教材、儿童与知识内容

先写清年龄、认知目标、使用课堂、演唱能力和必须准确的知识点。知识需要进入问答、动作、顺序、故事、游戏或可观察现象。

教育目标不是由成人站出来总结道理。任何押韵、拟人和简化都不能制造事实错误。

### 6. 舞台、晚会与仪式

确定现场人数、空间、节目位置、前后节目、是否需要互动、齐唱或舞蹈，以及作品在整场中的功能。开场、转场、高潮、纪念、祝福和收束需要不同命题。

### 7. 比赛与公开征歌

逐字拆解章程，核对主题、资格、格式、录音小样、评审、截止时间、提交方式、权利归属与实际使用。研究主办方、活动对象和近年入选作品，只用来理解任务与门槛。

比赛题目通常同质化严重。差异优先来自真实观察位置和关系动作，不靠更大口号取胜。

### 8. 私人定制与纪念

先确认隐私边界、事实授权、实际听众和使用时刻。私人细节要具体到当事人能认出，又筛选到旁听者能够理解。不能为了“感动”虚构对方未授权的秘密或苦难。

## 四、市场调查的最小闭环

需要判断“有没有市场、是否受欢迎、是否容易传播”时，至少完成：

1. 查看近两三年同用途、同受众、同歌手层级的代表作品和实际使用场景。
2. 记录作品由谁发布、在哪里被听见、哪些片段被使用、完整作品是否持续存在。
3. 访谈真实使用者、听众或项目方，确认他们为什么选择或拒绝。
4. 区分作品质量、歌手影响、项目资源、平台分发和事件窗口，不能把结果全归因于歌词。
5. 把结论标为事实、推论或待验证假设，并设计最低成本试验。

旧渠道名称可以提醒用途，不可以直接证明今天的规模和机会。

## 五、委约中的人物化转译

当简报只有抽象词时，按以下方式转译：

```text
口号或概念
→ 它在现实中要求谁承担什么
→ 哪个动作最能证明这种承担
→ 谁因此得到或失去什么
→ 哪个时刻逼得人物必须开口
→ 由这个人物说出，而不是由作者解释
```

“坚守”不能直接写成反复喊坚守；要找到谁在别人离开后仍完成了什么、付出什么，以及他如何看待这件事。

## 六、提案时给出真正不同的方向

每个方向都写清：

- 主人物与关系。
- 核心场景与动作。
- 如何完成简报的唯一任务。
- 对硬条件的处理。
- 最强记忆机会。
- 最大风险和所需调查。
- 为什么推荐或不推荐。

方向之间至少改变人物位置、关系、任务路径或形式，不能只是“温暖版、大气版、年轻版”。

## 七、冲突裁决

当委托方要求互相冲突时：

1. 指出冲突会在作品哪个位置出现。
2. 说明两边都最大化会损失什么。
3. 给出主次方案和可观察结果。
4. 由有权决策者确认。
5. 把确认结果写入创作命题和日志。

未经确认，不擅自选最安全的折中稿。折中往往同时失去两边。

## 八、阶段交付

```markdown
## 用途与委约卡

- 项目与使用场景：
- 唯一核心任务：
- 歌者、对象、目标听众与审批者：
- 硬条件：
- 偏好及其真实原因：
- 禁区：
- 矛盾要求与建议取舍：
- 必须调查和核实的内容：
- 推荐命题及兑现机制：
- 备选命题及主要差异：
- 交付、版权与授权待确认项：
- 成功如何被观察：
```

## 九、失效判定

- 把简报关键词、组织口号或产品卖点直接拼成歌词方向。
- 没有确定唯一核心任务，所有要求同等重要。
- 只考虑出资人，不考虑歌手、听众、使用者和审批者差异。
- 用参考作品的风格外壳代替任务分析。
- 市场判断没有当前证据，却写成确定事实。
- 为了交付安全，把人物写成没有生活的宣传员。
- 未核对版权、署名、授权和复用边界便进入高成本创作。
