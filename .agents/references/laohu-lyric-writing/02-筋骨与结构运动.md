# 筋骨与结构运动

> 主歌显景，副歌命情，桥段换命，尾声留痕。

这不是固定曲式，而是段落之间的意义分工：同一条关系压力先获得形状，再被说出、改写和承担。没有预副歌的歌曲也必须完成同样的收窄，只是把职务交给别的段落或声音。

## 核心判断

段落不是故事章节。它们是同一关系压力的不同发声位置：

    主歌显形 → 预副歌收窄 → 副歌开口 → 第二轮改义 → 桥段换判断 → 最后回声

标准曲式只是可选容器；有预副歌时，它必须制造前进感，而不是补写主歌漏掉的事实。

## 读取边界

各乐段在灵魂、筋骨、血肉和表皮中的必执行偏转，以写词主 Skill 为唯一生成权威。本 reference 不再另存一张基础乐段职务表；下面只展开标签原型、混合角色、多段主歌、副歌回归、桥段容量和理论边界。`主歌显形 → 预副歌收窄 → 副歌开口 → 桥段改判 → 最后回声`只是帮助理解常见运动的简写，不足以直接生成或淘汰歌词。

## 乐段标签是原型，不是封闭目录

主 Skill 已经保存四层内部的乐段偏转，本 reference 只负责解释标签为什么不能被当成硬定义，以及遇到混合与少见乐段时怎样识别。

Trevor de Clercq 的原型研究把 Verse、Chorus、Refrain、Bridge、Solo、Pre-chorus、Intro、Outro 和 Link 视为一组具有加权属性的段落角色，并指出真实歌曲经常出现角色混合；同一片段在旋律、和声、质地、歌词重复和位置上可能给出相互冲突的证据。Jay Summach 对 Pre-chorus 的研究说明，它不是必备标签，而是逐渐从主歌—副歌轨迹中独立出来的前向功能。Drew Nobile 进一步区分：Pre-chorus 属于核心循环的到达轨迹，Bridge 通常处于核心循环之外。Cara Stroud 对 Post-chorus 的研究又说明，副歌后的材料既可能延长收束，也可能成为真正高潮。由此，项目不建立一份“列完所有段落就永久封闭”的目录。

识别未知、混合或命名不一致的乐段时，比较以下证据：

```text
位置：它在什么段落之前和之后
回归：歌词、旋律和声音材料是否重复，怎样变化
完整度：它是完整模块、歌节内部回环，还是短连接
方向：它在发起、积累、到达、收束、对比、回流、释放还是留痕
质地：人声、配器、音区、律动和能量怎样改变
歌词：新事实、固定 hook、关系动作、vocables、无词或采样分别占什么位置
```

证据冲突时使用`主角色 × 次角色`记录，例如`Verse × Refrain blend`、`Bridge × Post-chorus blend`。写词时按对当前文字最有决定力的主角色组装四层，次角色只作为偏转；谱曲时可根据和声、音区、配器和能量重新判定。标签不清楚不等于结构不存在，也不要求为每个行业俗称另建一套永久规则。

Rap 不是固定段落角色。Kyle Adams 的研究把 flow 视为说唱者使用节奏与发音组织歌词的方式；Ben Duinker 对 hip-hop 曲式的研究则把 Verse、Hook 和 Instrumental 作为常见段落类型。因此项目使用`形式角色 × 表达方式`：Rap Verse、Rap Bridge、Spoken Intro、Chant Hook 都分别继承自己的形式职务。

## 多段主歌怎样相关

主歌一与主歌二可以发生在不同地点、不同时间，也可以采用不同景物、感官、物件和韵脚。它们属于同一首歌，优先由三件事证明：歌者与主要对象没有无锚点漂移；它们面对同一条关系压力；后一段交出前一段没有的新事实、认识或代价，使下一次副歌获得新的听法。后一段若只换场景继续表达同一种缺席，或只复制前段句架与意象而没有新增认识，均判为没有推进。

跨乐段换景不等于段内跳接。主歌二可以在新的时间点直接开场，乐段边界本身已经提供一次剪切；开头只需建立足以让听众进入的新坐标，不必先替主歌一收尾。进入新场景以后，人物位置、感官来源和句间因果仍要在本段内成立。不得为了证明两段有关，强行重复前段的风、笑声、回音、物件、尾字或`我听了许久`一类句架。

意象、声音和字句回环是可选收益，只在第二次出现改变对象、责任、距离、含义或情绪压力时采用。各主歌在人物关系和段落作用上相连，具体材料不必重复；全曲语体与人物口吻相容，也不要求表面用词互相复制。若两段主歌预计复用同一旋律，只检查句数、自然词组边界、主要重音、时值容量、发音负荷和情绪力度能否进入相同音乐位置；这种音乐对应不能反过来要求两段写同一场景。

## 段落功能卡不等于声音卡

### 先完成全曲乐段责任图，再写任何一段正文

结构候选胜出以后，先把整个标签序列横向展开。每个乐段填写同一组字段：

```text
前段交来：人物已经知道、正在承受或仍未完成什么
具体情感任务：谁对谁多经历、承认、抗拒或承担哪一件事
进入状态 → 离开状态：人物或听众的认识、愿望、责任或距离具体改变什么
相邻交接：下一段第一项语言动作接过什么，不能靠稿外补入哪一句因果
回归改义：它使下一次 Refrain、Chorus 或核心句与上一次有何不同
越位边界：哪些答案、事实、决定或结尾必须留给别段
开放实现：可在逐段创作时比较的景物、动作、组织方法和声音方案
```

其中`具体情感任务`必须具体到能够区分相邻情绪。例如`写失去爱人的悲痛`无法区分第一次发现缺席、亲手完成诀别和决定怎样度过余生；三者会要求不同的主歌入口、副歌听法和结尾。结构阶段应先把这些差别排定，逐段阶段才决定用听觉、光影、动作、关系物或直接开口来实现。

责任图检验采用“反向候选测试”：为每一格提出一个题材相同、气氛相同但人物责任不同的构思；现有字段若无法立即淘汰它，说明写得过宽。整张图完成以前，不因某个副歌、主歌或桥段已经写得漂亮便先行扩写。后来出现更强材料时可以回流，但修改一格必须连同前后交接和核心回归一起重审。

段落功能卡回答本段在整首歌里完成什么意义运动，并且必须形成一份可淘汰候选的责任约定：前段交来什么压力，本段负责显形、收窄、命名、改判还是留痕，各记忆意群怎样推进这一局部职务，本段结束时把什么新听法交给后段，哪些事实必须留在后台。只有副歌、直接对白和桥段决定句通常要求写清谁对谁完成什么关系动作；主歌先写清谁的处境、感知或事实怎样使压力获得形状。若只能写成`副歌抒情、情绪爆发、表达悲痛、完成升华`，说明职务尚未明确，不能据此生成正文。

若某一版采用“前几句显影或铺陈，随后转入关系，末句落到本段判断”，这只是该段的意义组织方案；它不等于前几句不押韵、后几句押主韵，也不规定句长、气口或韵脚位置。

声音卡另行记录句数、句长走势、重音、气口、主韵、邻韵和有意不押的位置。段落功能需要调整时，不得自动重写韵脚；韵脚需要调整时，也不得自动改变段落职务。

## 副歌内部运动

副歌通常先确定一个主要关系动作，再安排记忆意群。可用的内部变化包括：第一次说出立场，随后暴露这项立场的私人代价；把对象由远处拉到直接称呼；让愿望遭遇不可逆事实；把原来的判断变成请求、拒绝、承认或承担；最后用核心句或声音回响留下未完成处。每首歌只选当前命题需要的变化，不把它套成固定句数模板。

每个新增意群都做“开口连续性”检查：上一意群正在由谁对谁做什么，这一意群是否仍在同一说话现场，它增加了哪一项关系变化。若答案变成`向听众补充经过`、`证明人物为什么这样选择`、`转述旁人评价`或`概括作品主题`，它属于叙事、说明或评论，不因情绪正确而成为副歌。把它移到能承担该信息的主歌、预副歌、桥段，或完全留在故事后台。

这不是禁止叙事副歌。若作品从灵魂层就确定副歌承担叙事性反复，事件每次回归本身会改变关系判断，叙事可以保留；但同一副歌不能在没有设计的情况下，从人物直接开口突然换成作者讲解。

## 副歌回归

先分清副歌的内部单位与整首歌的回归次数。`Chorus A + Chorus B`或`Chorus + Post-Chorus`说明一次副歌内部怎样运动；同一套副歌出现三次，才叫三次回归。不能把一个 A+B 副歌误算成两个回归，也不能因为歌词篇幅较长便机械增加一次副歌。

副歌驱动作品已经确认核心单位时，先完成回归设计，再安排其他乐段：固定什么、变化什么；每次回来前听众新增了哪项事实或人物认识；最后一次怎样偿还前文留下的问题。随后再用主歌、预副歌、桥段的候选结构验证这些变化是否真的能够发生。若其他段落只能解释副歌、不能改变它的听法，反向检查副歌是否过早封死了整首歌；不得让完整度较高的局部句子支配所有段落。

每次回归前必须填写“旧听法 → 新压力 → 新听法”：

    第一次：愿望或自欺
    第二次：新证据迫使防御改形
    最后一次：决定、责任或代价进入同一核心句

只把“有人说”改成“信上说”，或只更换地点、消息和主语，不是改写；前段没有改变副歌的听法，说明铺垫无效。

前两次副歌出现反复问句、否认、愿望或未完成判断时，另列一张收束清单。最后副歌逐项说明：它是得到回答、被人物明确拒绝回答，还是因人物的新决定而改变含义。若最后一次直接换成新的景物、名词或主题判断，前面留下的语言动作仍然悬空，判为没有完成回归。

“人物承担了什么”必须在歌词中听得见。把最后两行还原成普通话，若只能得到“这里出现了某个意象”或“作者再次强调主题”，而不能说清人物现在承认、决定或继续做什么，这个结尾仍停在静态总结，不算最后副歌的新责任。

## 桥段

桥段只保留：

    旧判断 → 触发声音/物件 → 新认知 → 决定与代价

文字容量优先采用四、八或十六句等常见结构容量，但它们指句数或音乐句数，不指每句字数，也不是不可变的格式命令。超过当前容量时，必须说明每一个子单元的不可替代收益；如果超长只是为了交代现场流程，直接删掉。最后副歌必须改变称呼、对象、责任、判断、停顿或唱法，否则桥段没有完成职务。

## 容量与声音

没有旋律时，句数只是结构容量参考，不是字数和小节定律。判断重点是独立语义单位、重复比例、句长走势、气口和可留给旋律的空间。一个段落写得越满，越要证明它为什么不能用一个回声句替代。

预副歌的段落功能是把开放感受收窄成副歌前不得不说的关系压力。它的声音前进感可以另由句长缩短、重复加密、问句收束、尾韵聚合、休止延迟或关系对象变近来实现；这些是声音手段，不应反写成预副歌的固定功能，更不能把“更急、更高”直接写进歌词。

声音卡至少填写：本段句数、长短句走势、重音落点、气口候选、主韵、邻韵、主要韵脚句和有意不押句。无旋律时只标为文字侧假设。四句、八句、十六句不要求每句整齐，气口也不固定为每句两个。

理论边界：

- Jay Summach 的预副歌研究说明预副歌是制造前进感的形式区，不是所有歌曲的必备标签。
- Pat Pattison 的 prosody 说明文字、节奏、旋律和演唱必须共同服务情绪。
- 文字初稿只能提出假设，不能代替试唱和成曲验证。
