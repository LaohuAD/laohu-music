# 筋骨与结构运动

> 主歌显景，副歌命情，桥段换命，尾声留痕。

以下先描述关系戏剧的常见段落分工；陪伴、律动、吟唱等按自身持续与回接验证，不强制收窄、改判或承担代价。关系戏剧也不是固定曲式。未采用预副歌时，检查主歌怎样直接交到副歌、是否由声音连接或有意跳切；不要求每首歌隐藏一个相同的收窄环节。

## 核心判断

段落不是故事章节。它们是同一关系压力的不同发声位置：

    主歌显形 → 预副歌收窄 → 副歌开口 → 第二轮改义 → 桥段换判断 → 最后回声

标准曲式只是可选容器；有预副歌时，它必须制造前进感，而不是补写主歌漏掉的事实。

## 读取边界

各乐段在灵魂、筋骨、血肉和表皮中的必执行偏转，以写词主 Skill 为唯一生成权威。本 reference 不再另存一张基础乐段职务表；下面只展开标签原型、混合角色、多段主歌、副歌回归、桥段容量和理论边界。`主歌显形 → 预副歌收窄 → 副歌开口 → 桥段改判 → 最后回声`只是帮助理解常见运动的简写，不足以直接生成或淘汰歌词。

## 乐段标签是原型，不是封闭目录

主 Skill 已经保存四层内部的乐段偏转，本 reference 只负责解释标签为什么不能被当成硬定义，以及遇到混合与少见乐段时怎样识别。

Trevor de Clercq 的原型研究把 Verse、Chorus、Refrain、Bridge、Solo、Pre-chorus、Intro、Outro 和 Link 视为一组具有加权属性的段落角色，并指出真实歌曲经常出现角色混合；同一片段在旋律、和声、质地、歌词重复和位置上可能给出相互冲突的证据。Jay Summach 对 Pre-chorus 的研究说明，它不是必备标签，而是逐渐从主歌—副歌轨迹中独立出来的前向功能。Drew Nobile 进一步区分：Pre-chorus 属于核心循环的到达轨迹，Bridge 通常处于核心循环之外。Cara Stroud 对 Post-chorus 的研究又说明，副歌后的材料既可能延长收束，也可能成为真正高潮。由此，项目不建立一份“列完所有段落就永久封闭”的目录。

识别未知、混合或命名不一致的乐段时，比较以下证据：

```text
位置：它在什么段落之前和之后
回归：歌词、旋律和声音材料是否重复，怎样变化
完整度：它是完整模块、歌节内部回环，还是短连接
方向：它在发起、积累、到达、收束、对比、回流、释放还是留痕
质地：人声、配器、音区、律动和能量怎样改变
歌词：新事实、固定 hook、关系动作、vocables、无词或采样分别占什么位置
```

证据冲突时使用`主角色 × 次角色`记录，例如`Verse × Refrain blend`、`Bridge × Post-chorus blend`。写词时按对当前文字最有决定力的主角色组装四层，次角色只作为偏转；谱曲时可根据和声、音区、配器和能量重新判定。标签不清楚不等于结构不存在，也不要求为每个行业俗称另建一套永久规则。

Rap 不是固定段落角色。Kyle Adams 的研究把 flow 视为说唱者使用节奏与发音组织歌词的方式；Ben Duinker 对 hip-hop 曲式的研究则把 Verse、Hook 和 Instrumental 作为常见段落类型。因此项目使用`形式角色 × 表达方式`：Rap Verse、Rap Bridge、Spoken Intro、Chant Hook 都分别继承自己的形式职务。

## 多段主歌怎样相关

主歌一与主歌二可以发生在不同地点、不同时间，也可以采用不同景物、感官、物件和韵脚。它们属于同一首歌，优先由三件事证明：歌者与主要对象没有无锚点漂移；它们面对同一条关系压力；后一段交出前一段没有的新事实、认识或代价，使下一次副歌获得新的听法。以上用于推进路线；稳定或仪式路线另查感知丰富、持续与参与收益。只换景或复制句架而既无推进也无持续收益才退回，不统一索取新增认识。

跨乐段换景不等于段内跳接。主歌二可以在新的时间点直接开场，乐段边界本身已经提供一次剪切；开头只需建立足以让听众进入的新坐标，不必先替主歌一收尾。进入新场景以后，人物位置、感官来源和句间因果仍要在本段内成立。不得为了证明两段有关，强行重复前段的风、笑声、回音、物件、尾字或`我听了许久`一类句架。

意象、声音和字句回环可改变对象、责任、距离、含义或情绪压力，也可维持安定、强化记忆与身体参与；按本作职务判断，不按变义一刀切。各主歌在人物关系和段落作用上相连，具体材料不必重复；全曲语体与人物口吻相容，也不要求表面用词互相复制。若两段主歌预计复用同一旋律，只检查句数、自然词组边界、主要重音、时值容量、发音负荷和情绪力度能否进入相同音乐位置；这种音乐对应不能反过来要求两段写同一场景。

## 段落功能卡不等于声音卡

### 用乐段责任图组织与检验试写

结构暂选后展开已知标签，先标当前验证对象及必要前后依赖。完整段落可以验证未定结构，锁定前补齐全图。下列为关系戏剧字段，其他路径记录感知、声音、参与、持续和回接：

```text
前段交来：人物已经知道、正在承受或仍未完成什么
具体情感任务：谁对谁多经历、承认、抗拒或承担哪一件事
进入状态 → 离开状态：人物或听众的认识、愿望、责任或距离具体改变什么
相邻交接：下一段第一项语言动作接过什么，不能靠稿外补入哪一句因果
回归改义：它使下一次 Refrain、Chorus 或核心句与上一次有何不同
越位边界：哪些答案、事实、决定或结尾必须留给别段
开放实现：可在逐段创作时比较的景物、动作、组织方法和声音方案
```

其中`具体情感任务`必须具体到能够区分相邻情绪。例如`写失去爱人的悲痛`无法区分第一次发现缺席、亲手完成诀别和决定怎样度过余生；三者会要求不同的主歌入口、副歌听法和结尾。结构阶段应先把这些差别排定，逐段阶段才决定用听觉、光影、动作、关系物或直接开口来实现。

责任图检验采用“反向候选测试”：为每一格提出一个题材相同、气氛相同但人物责任不同的构思；现有字段若无法立即淘汰它，说明写得过宽。探索时可先完成具体段落来检验未决格；它不能因局部漂亮就锁定全曲。整稿锁定前补齐实际采用结构的交接。后来出现更强材料时可以回流，但修改一格必须连同前后交接和核心回归一起重审。

段落功能卡回答本段在整首歌里完成什么意义运动，并且必须形成一份可淘汰候选的责任约定：前段交来什么压力，本段负责显形、收窄、命名、改判还是留痕，各记忆意群怎样推进这一局部职务，本段结束时把什么新听法交给后段，哪些事实必须留在后台。只有副歌、直接对白和桥段决定句通常要求写清谁对谁完成什么关系动作；主歌先写清谁的处境、感知或事实怎样使压力获得形状。若只能写成`副歌抒情、情绪爆发、表达悲痛、完成升华`，说明职务尚未明确，不能据此生成正文。

若某一版采用“前几句显影或铺陈，随后转入关系，末句落到本段判断”，这只是该段的意义组织方案；它不等于前几句不押韵、后几句押主韵，也不规定句长、气口或韵脚位置。

声音卡另行记录句数、句长走势、重音、气口、主韵、邻韵和有意不押的位置。段落功能需要调整时，不得自动重写韵脚；韵脚需要调整时，也不得自动改变段落职务。

## 副歌内部运动

副歌的表达任务以主 Skill 筋骨分支为准。关系抒情先区分歌者最想说出的感受与使其说不出口的阻力，不用“悲伤、放不下”包办不同人物；可以同时有矛盾感情，但矛盾两端应由词句听出。随后选择立场、呼唤、自问、景语或叙事性反复怎样成为中心，而不是先选一件器物再为每句配寓意。

起笔时比较至少两种能完成同一情感任务的整段实现：一种让人物的愿望或抗拒更近，一种让诗性材料和声音承担同一感受；两者可以融合，不强制最后采用直白版。比较时遮掉功能说明，先写从裸稿实际读出的关系与感受，再指出承重意群及可回归的句架。若必须依次解释多个替身，才能知道这段是在求重逢、舍不得忘或怕被忘，说明材料遮住了中心；具体剧情与复杂余味可以后知，基本的情感方向不能只存在于作者点评。只有声音才能裁决的部分保留音乐验证条件，不据文字宣布感染力已成立。

可用的内部变化包括：说出立场后露出代价，把对象由远处拉近，让愿望遇到事实，以核心句或声音回声停留。只采用本作需要的变化，不套固定句数，也不要求每一行都增加事实或情绪词。已有好句可作为支点；若其余句子只是在解释它或另开意象，则整段仍未成立。

每个新增意群检查是否仍在同一感情现场：它让前一句更近、更矛盾、更坚定，还是仅补经过、证明原因或概括主题。对于当前的直接抒情路线，后者不能因事实准确就加入；叙事、评论作为主动选定的歌曲表达时则检查它怎样承担中心感受。需要移段的材料先重新验证目标段落的任务，不把主歌当作废弃副歌的收纳处；无效或含混的表达应删除或重写，改标签不能改变质量。

这不是禁止叙事副歌。若作品从灵魂层就确定副歌承担叙事性反复，事件反复本身能承载本作的感情、追忆、判断或仪式体验，叙事可以保留；但同一副歌不能在没有设计的情况下，从人物直接开口突然换成作者讲解。

## 副歌回归

先分清副歌的内部单位与整首歌的回归次数。`Chorus A + Chorus B`或`Chorus + Post-Chorus`说明一次副歌内部怎样运动；同一套副歌出现三次，才叫三次回归。不能把一个 A+B 副歌误算成两个回归，也不能因为歌词篇幅较长便机械增加一次副歌。

副歌驱动作品已经确认核心单位时，先完成回归设计，再安排其他乐段：固定什么、变化什么；每次回来如何变义、保持、累积或回接；采用闭合路线时，最后一次怎样处理前文的问题。随后再用主歌、预副歌、桥段的候选结构验证这些变化是否真的能够发生。若其他段落只能解释副歌、不能改变它的听法，反向检查副歌是否过早封死了整首歌；不得让完整度较高的局部句子支配所有段落。

关系变义主导时，每次回归前检查“旧听法 → 新压力 → 新听法”；稳定循环、律动或仪式性重复则检查为何保持、怎样累积或回接，不强加新压力。以下为三次关系回归示例，不规定次数：

    第一次：愿望或自欺
    第二次：新证据迫使防御改形
    最后一次：决定、责任或代价进入同一核心句

只把“有人说”改成“信上说”，或只更换地点、消息和主语，不是改写；前段没有改变副歌的听法，说明铺垫无效。

采用关系闭合路线时，前两次副歌出现反复问句、否认、愿望或未完成判断时，另列一张收束清单。最后副歌逐项说明：它是得到回答、被人物明确拒绝回答，还是因人物的新决定而改变含义。若最后一次直接换成新的景物、名词或主题判断，前面留下的语言动作仍然悬空，判为没有完成回归。

采用新责任收束时，“人物承担了什么”必须在歌词中听得见。把最后两行还原成普通话，若只能得到“这里出现了某个意象”或“作者再次强调主题”，而不能说清人物现在承认、决定或继续做什么，这个结尾仍停在静态总结，不算最后副歌的新责任。

## 桥段

桥段按本作需要形成对比并准备回归。认知转折路线可采用：

    旧判断 → 触发材料 → 歌者如何受其影响 → 新认识或选择

事件不是转折本身；仅新增消息、人物和地点，却没有改变歌者的语气、感受或回归作用，仍须重写。声音对比、情绪暂退或仪式性循环按实际实现验证，不强制补认知反转。

文字容量优先采用四、八或十六句等常见结构容量，但它们指句数或音乐句数，不指每句字数，也不是不可变的格式命令。超过当前容量时，必须说明每一个子单元的不可替代收益；如果超长只是为了交代现场流程，直接删掉。最后副歌依本作决定改变称呼、对象、责任、判断、停顿或唱法，也可维持原句与旋律完成安定或循环。桥段按已选的对比、转换或改判验证，不以词义变化作唯一标准。

## 容量与声音

没有旋律时，句数只是结构容量参考，不是字数和小节定律。判断重点是独立语义单位、重复比例、句长走势、气口和可留给旋律的空间。一个段落写得越满，越要证明它为什么不能用一个回声句替代。

预副歌的段落功能是把开放感受收窄成副歌前不得不说的关系压力。它的声音前进感可以另由句长缩短、重复加密、问句收束、尾韵聚合、休止延迟或关系对象变近来实现；这些是声音手段，不应反写成预副歌的固定功能，更不能把“更急、更高”直接写进歌词。

声音卡至少填写：本段句数、长短句走势、重音落点、气口候选、主韵、邻韵、主要韵脚句和有意不押句。无旋律时只标为文字侧假设。四句、八句、十六句不要求每句整齐，气口也不固定为每句两个。

理论边界：

- Jay Summach 的预副歌研究说明预副歌是制造前进感的形式区，不是所有歌曲的必备标签。
- Pat Pattison 的 prosody 说明文字、节奏、旋律和演唱必须共同服务情绪。
- 文字初稿只能提出假设，不能代替试唱和成曲验证。

### 研究依据与推论边界

[de Clercq（2017）](https://www.mtosmt.org/issues/mto.17.23.3/mto.17.23.3.de_clercq.php)讨论乐段角色的原型与歧义：歌词、旋律、和声和织体等线索可能不一致。因此本项目从裸歌词判断表达任务，并将音乐角色保留为待验证，不用单项语言特征判定副歌。

[Summach（2011）](https://mtosmt.org/issues/mto.11.17.3/mto.11.17.3.summach.php)研究预副歌的前进功能及其多种音乐实现；[Stroud（2022）](https://mtosmt.org/issues/mto.22.28.2/mto.22.28.2.stroud.html)区分不同后副歌功能，高潮也可能位于后副歌。这些流行音乐研究支持条件式判断，不证明所有歌曲都需要预副歌，也不证明副歌必须拥有最高音量。

本项目据此提出的段落功能卡与候选比较是创作方法，不是上述研究已经验证有效的中文歌词评分量表。文字清楚、情绪准确和音乐感染力须分别验收。
