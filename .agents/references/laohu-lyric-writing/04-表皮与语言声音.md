# 表皮与语言声音

> 声为骨，字为肉，韵为回声。

表皮不是给空洞的内容穿一件古风外衣。它要让已经成立的关系，在正常中文的语义、人声和声音回环里落地；若上层没有成立，先回流，不用炼字遮盖。

## 语体、语义与人声同时成立

炼字不是把词改成日常高频搭配，也不是为了保住古雅而放弃自然语义。先判断一个词在当前语体中是否保住了文化重量、身份、命运尺度、关系潜台词或声音记忆，再检查人物是否会这样说、词组的语义角色是否成立、歌唱时是否能自然落下。

“更常见”“更口语”不是优化证据，“更古雅”“更少见”也不是优化证据。一个非日常词若能在语义角色、文化语境、人物资格和声音落点上成立，应保留；一个日常词若只把情绪解释平了，也应删除。判断自然，不是看词频，而是看人物能否在这个处境中这样组织这句话。

## 语体结构

国风抒情散文式咏唱可混合：

- 古典名物和礼俗词，负责文化重量与公共预期。
- 文言式压缩、倒装、叠词、数量尺度和对偶，负责回环、节律和留白。
- 少量浅白关系动词，负责呼告、让步、承认、质问和落锤。

不是每句都古雅，也不是每句都口语。语体切换必须改变人物距离、态度、文化尺度或声音；没有职务的古词和白话都删掉。禁止把“日常”与“低级”、“古雅”与“高级”画等号。

## 先建立本歌的语言底稿

作品已有一句或数句获得用户确认的歌词时，它们比“古风、虐恋、影视感”等题材标签更有权决定后续语言。新写乐段前，先从已确认文字中提取一份作品专属的语言底稿：

```text
当前乐段负责显形、收窄、命名、改写还是留下回声
→ 这一句来自谁的感知、动作、场景或关系判断
这个人正用哪种普通话语序开口
→ 诗意来自哪种句间关系：感官运动、对照、问答、复沓还是关系落锤
→ 哪些古典或文化词已经负责世界、身份、时间与命运尺度
→ 名词、动词、关系词和修饰成分怎样分工
→ 句长、重音、句尾和有意重复形成了什么声音习惯
→ 哪些词已经成为全曲承重词，后文应让它们变义而不是另造一组大词
```

提取必须指回具体文字：哪个名词让听众认出现场，哪个动词让材料自然发生，哪个关系词改变了人物的界线，哪处长短变化真正改变了重音和气口。`浅白中有诗意`、`古雅但好懂`、`悲而不伤`等气质句无法决定候选句胜负，不算语言底稿。

底稿建立后，按下面的正向顺序生成：

```text
先通过乐段局部四层门，确认这项表达完成的是当前段落职务
→ 用自然中文写清一个唯一可恢复的人物、动作、对象或感官关系
→ 只保留能改变人物选择、关系或句势的成分
→ 让诗意从前后句的动作、对照、缺席或回答中产生
→ 最后才选择符合人物身份的文化词、韵脚与压缩方式
```

不得先造一个陌生名词、反常动宾或古雅碎句，再让作者解释它代表什么。好的歌词可以突破日常搭配，但听众必须先认出来源物和它被迁移的主属性；新奇不能代替已经成立的句间关系。

自然中文、对照、押韵和第一遍听懂都只是表皮条件，不能单独证明当前乐段成立。`世界得到明天 / 两人停在今天`这类概念对照可能只是作者概括，也可能在主歌中承担由公共结果转向私人代价的筋骨；要看前文是否建立了可进入的坐标，这组对照是否使材料或压力发生变化，段尾是否把一个尚未完成的情绪交给副歌。不能因句法清楚、结构匀称便自动放行，也不能因它不是直接开口便自动判成解释性散文。

候选完成后做三次连读：第一次按乐段类型遮掉说明，检查主歌是否真的形成情绪入口、预副歌是否收窄、副歌是否完成关系动作、桥段是否改判；第二次检查第一遍能否恢复字面场景和关系；第三次与已确认文字连读，检查是否仍是同一人、同一首歌。中性旁白测试只用于确认材料是否产生本段要求的损失：主歌被压成梗概后应失去观察运动、情绪入口或对下一段的新交接，副歌则应失去人物立场。第一遍听不懂，不用“第二遍有余味”放行；字面清楚却没有完成局部职务，也不用“至少好懂”放行。

## 词类不按数量分配，先看谁在承重

歌词通常依靠名词和动词交出人物、对象、动作、物件与场景，但这不构成“虚词越少越好”的配额。能愿动词、副词、连词和助词负责可能、意愿、否定、转折、时间、范围和语气；形容词与叠词负责准确状态、感官属性或声音节奏。它们只有在改变当前人物的关系判断、可感状态或演唱动作时才保留，不能仅因属于某一词类自动删除或放行。

候选生成后做一次“主干—修饰”检查：

```text
先圈出主体 / 能愿判断 / 主要动词 / 对象 / 结果
→ 再圈条件、时间、范围、程度、否定、方式、状态和语气成分
→ 逐个说明它改变哪一项关系、时间、范围、立场、物性或声音
→ 两个以上修饰成分连续落在同一主干前时，再检查它们是否职务重叠、是否使承重动作来得过晚
→ 删除一个成分后拍读；意义、人物立场和节奏都不变就删除，任一必要项改变则保留
```

单个删除测试不能代替累积检查。`即使 + 此后 + 只能 + 沉默`中的各项分别可以解释为让步、时间与范围，但它们连续出现时，会让一句短歌词先交代三层语法关系，最后才出现主要动作。只有作品确实需要同时锁定让步、未来时段和唯一可能，并且后一句能够完成这条复句时才保留；否则优先用人物本身的能愿判断和主要动作说清。

对照句中的能愿词要比较语义尺度。`可以 / 不能`都判断可能或承受边界，`愿意 / 不肯`都判断主观意愿；交叉使用不是语法错误，但会把“做得到吗”和“愿不愿意”混在同一组反差里。若跨尺度没有人物或段落理由，换回同一尺度再拍读。

形容词和叠词也不只在“情绪强烈”时使用。它们可以让颜色、触感、速度、距离、数量或动作状态变得准确，也可以形成复沓和时值；删去以后物性与声音都不变，只剩“更美、更伤感”的笼统效果，就删除。反过来，`却、只、仍、再、未曾`等关系词即使没有具体物象，只要它们改变人物的转折、范围、持续、重复或时间判断，就属于承重字。使用这些词以前先把前后两项恢复成普通话：`却`的两端必须在同一判断尺度上形成可听见的预期逆转；`仍`必须有正文已经建立的原状态，以及足以威胁这项持续的变化。两件事可以同时成立、只是作者想强调反差，或转折只存在于剧情梗概而没有进入词面时，删除关系词或补回真正缺失的那一端。

## 锁定核心句的语言连续性

核心句一旦锁定，扩写不能只继承它的主题词和人物关系，还要继承它怎样开口。生成前逐项写出：

    主要语气：宣告、呼告、请求、质问、拒绝或解释
    句法力量：主句落锤，还是条件、因果、让步、转折逐层展开
    词语密度：哪些名词、动词和代词同时承担剧情、关系与重音
    语体比例：古雅压缩、浅白关系词和现代日常表达怎样配合
    情绪与身份尺度：私人低语、公开宣言、命运判断或世界性冲突
    句尾力量：每个意群落在人物、关系、动作、代价还是过程说明

新增句与核心句连读时，听众应当仍听见同一个人在同一首歌里继续开口。核心句若用短引领句加高密度主句完成宣告，后文连续使用`若……就……`、`不能……便……`、`纵使……我便……`解释愿望、原因和计划，容易把副歌从宣告写成说明。条件句和浅白词不是禁用项；只有当它们改变人物距离、形成新的声音动作，并且没有降低副歌所需的语势时才保留。

公共共鸣来自听众认出相同的关系选择和代价，不来自把人物语言改成中性的概括。仙魔、战争或古典人物可以说出普通人都懂的感情，但仍要保持人物已经建立的身份、语体和命运尺度；不能为了“人人都懂”，把高压核心句接成现代说明句。

功能卡只能决定新增意群要完成什么，不能提供正文措辞。`不能公开承认爱人，所以只能唱歌缅怀`是结构说明；若歌词只是把它分成`不能在人前……便在歌里……`，说明分析没有经过人物语体、修辞动作和声音重写，退回生成，不做近义词美容。

## 句子检查

每行检查：

    主语、动词、对象、结果是否成立
    关系动作是否可听见
    句尾是否由实词落地
    词组是否能自然朗读
    是否留下有凭据的未封口处
    情绪词、抽象词或意象词是否只有一个明确的主要职务
    是否把抽象情绪转译成了一个准确而非装饰性的具体属性
    与锁定核心句连读时，主要语气、句法力量、词语密度、人物身份和情绪尺度是否仍属同一首歌

连续两个压缩意群还要做“关系展开”：不用诗性省略，把它们恢复成普通话，确认前一句与后一句究竟是问答、因果、转折、包含、并列还是动作与对象。恢复后若存在两种以上会改变人物行动的解释，或两个名词短语之间没有可确定的关系，这不是留白，而是句义没有写完。副歌收束尤其不能用两个看似宏大的名词短语并置，要求听众替作者补出人物的决定。

问答式收束可以使用相同字数和相近句架，因为对称来自真实的发问与回答；验收重点是问题与答案是否属于同一件事、回答是否改变人物选择。不能因为字数整齐便判为机械，也不能因为形成对仗便放过答非所问。

### 正向成品校准

反向审稿不只负责找错，还要保护已经成立的语言力量。对每一个准备重写的句子，先判断它是否已经具备以下四项：

1. 这句话具有与乐段相称的来源：人物会这样开口、感知或行动，或者主歌确实需要这样建立场景。
2. 主语、动词、对象、感官与结果的关系自然成立。
3. 句子有一个明确的局部职务：显形、收窄、关系动作、改判或回声。
4. 句尾、重音和气口能够服务演唱，而不是只服务排版整齐。

四项成立时，禁止仅因为它不够生僻、不够“古风”或不够华丽而替换。新句只有在明确增加了情绪转译、关系变化、声音记忆或文化尺度时才有资格取代原句；近义词替换、宽泛意象替换和作者自造的压缩表达一律不算增益。

整首歌必须保留陌生听众可以直接进入的关系语言，但不要求每个主歌都配置一句直抒。主歌可以由一处清楚的场景、感知或动作完成入口；预副歌和副歌再逐步把关系说近。不要让整首歌只剩文化名物和状态词，也不要为了满足配额把直接关系句硬塞进本应留白的主歌。

以下情况退回重写：

- 只能靠作者解释一个词“同时代表”多种没有被文本建立的情绪。
- 用抽象情绪的近义词互换，或用“空、冷、轻、沉、远、无言”等宽词替代没有写清的关系。
- 把“思念如刀”这种有来源属性的比喻，错误改成无来源的物件拼贴；比喻要迁移一个主属性，不是把两个词并排摆出古风效果。
- 为了对偶而使用人物不会说、语义角色不匹配或只属于作者分析视角的词。
- 句子看似凝练，实际删掉了正常语义角色，只能靠解释恢复人物在做什么。
- 为了押韵、对仗或古雅，把一个已经成立的关系句换成没有新增作用的陌生搭配。

诗性不能替不成立的动宾关系免责；不常见也不能自动判错。反之，解释得很清楚也不能自动成为好歌词。

## 韵律、句数、句长与气口

这些是相互协作、但不能互相替代的声音变量：

```text
句数：本段有多少歌词句或音乐句
句长：每句承载多少语义和旋律时值
重音：听众首先听见哪个字词
气口：在哪里自然停顿、换气或改变句势
韵脚：句尾怎样形成声音回环
发音路径：承重字与相邻音节的声母、韵腹和韵尾怎样衔接
```

四句、八句、十六句指句数或音乐句数，不是每句字数。句长由内容、旋律时值、重音和情绪决定；可以长短交错，也可以在某个段落暂时相近，但不得为了视觉对齐把每句削成同样长度。无旋律时，句长和气口只能记录文字侧假设。

韵辙只说明句尾在听觉上具有怎样的亲缘，不能单独证明两个字的口腔动作相同，也不能证明它们放进同一条旋律就同样顺口。句尾、长音、音高峰值和快速密集处还要逐字检查发音路径：从前一音节进入当前字时，双唇、舌位、下颌和气流发生什么变化；声母需要怎样闭合、摩擦或阻塞；真正被延长的是哪个韵腹；韵尾怎样收束并进入下一字。闭合与阻塞不是自动错误，语言本来就需要辅音；只有它们在当前速度、时值、音高或连唱方式下妨碍清晰、连贯或情绪动作时，才改字、改时值、改旋律或调整咬字。没有旋律和真人试唱时，只能标出发音风险，不能凭韵辙、字数或朗读顺口宣称已经可唱。

气口用普通半角空格标记，不用竖线。一个句子可以没有气口，也可以有一个或多个气口；空格只能落在自然词组边界、意义重音转换或可换气处，不能切开主谓、动宾和固定搭配。先按自然语序朗读，再按空格拍读；若空格只是把普通话切碎，删掉或重排。

## 作词前韵脚规划

韵脚必须在正式作词前单独建立声音卡，顺序如下：

```text
段落功能与情绪落点确定
→ 选择主韵的听觉色彩
→ 规定可接受的邻韵范围
→ 标明主要韵脚落点
→ 标明可以有意不押的句子
→ 在自然语义中选择句尾实词
→ 朗读、拍读和试唱后修正
```

主歌可以较松，副歌通常需要更稳定的声音中心，预副歌可以通过尾韵聚合或休止制造前进感；这描述的是声音组织，不是段落功能。不得把“前两句铺陈、第三句转关系、第四句收住”当成韵脚规则，也不得把“主歌稍松”理解成随意乱韵。

韵脚优先服从关系落点和声音记忆，再在同一段内形成主韵与邻韵的聚合。不得先建立固定词库再硬填，也不得为了凑韵改变对象、责任、语义角色或正常词语搭配。准确的非押实词可以保留；有意破韵必须对应明确的关系、信息或情绪变化。语气词可以出现在句中，但`啊`、`吗`、`了`、`呢`、`吧`等不能作为主要段落韵脚或收束记忆。

逐段圈出所有句尾字，单独检查同字重韵。同一个字再次落在韵脚，只在两种情况下保留：它本身是明确的 hook、复沓或回环；或者每次出现都改变了对象、距离、责任、含义或情绪压力，听众不看解释也能听出递进。若同字只是因为容易押韵而再次收尾，替换或删去后又没有损失新的关系内容，判为无意重韵并重写。正文中的一般同字不因此自动判错，先判断它是否承担有意重复的修辞职务。

两段以上主歌若预期共用或近似复用同一旋律，再做对应位置检查：句数、自然词组节奏、主要重音、发音负荷和情绪力度应能落进同一旋律职务；差异必须来自已经声明的旋律变体或演唱设计。这里的对应是重音位置、时值容量、词组边界和发音难度相容，不是每行字数相等。没有音乐证据时，不用字数强行拉齐，但必须把不一致标为待谱曲验证，不能同时宣称两段已经形成稳定的同一唱感。

先按自然语序朗读，再按声音卡拍读。若改气口或改韵脚后必须补生造词，恢复自然句并重新规划；近韵是否真正成立，最终交给旋律、演唱和听觉验证。

## 关键声音动作

“唱慢、唱轻、唱低”不是歌词动作。要把它写成可听见的控制、拖延、吞咽、停在半句、让声响遮住某个声音，或让一个字迟迟不落。宽泛状态词若不能还原为声音和关系后果，退回重写。

可迁移的技巧包括复沓、排比、对偶、问句、反差、拟人和预期反转；每次使用都必须说明重复改变了什么，以及它如何逼出下一句。修辞名称本身不是成品。

问句还要单独核对关系事实账：它是在求证一个真正未知的答案，在拒绝接受已知事实，还是在完成请求或质问。若四种作用都说不清，问句只是在用语气制造强度；删除以后回到人物已经确认的愿望、选择和代价。
