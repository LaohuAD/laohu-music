# 演唱视角与多角色分配

## 什么时候读取

创作命题已经确定独唱、对唱、多人分唱、群唱、角色歌、影视人物歌或第一、第二、第三人称，但需要把视角真正落实到歌词正文时读取。选题阶段决定采用哪一种演唱形式、由谁唱给谁，仍由 `laohu-lyric-topic` 负责；本文件只管已经选定以后，每句由谁说、知道什么、听见什么和怎样交接。

## 一、人称不是代词，是信息权限

第一人称不能自动等于真诚，第二人称不能自动等于亲密，第三人称不能自动等于客观。视角真正决定四件事：

```text
谁能看见哪些事实
→ 谁只能猜测哪些心理
→ 谁在对谁施加什么语言动作
→ 听众站在现场、对象身边还是旁观位置
```

每句写完都要标记说话者、对象和知识来源。人物只能说自己亲眼看见、亲耳听见、实际经历、合理推断或愿意承认的内容。不能让第一人称突然知道对方未曾说出的完整动机，也不能让第三人称旁白替人物宣布他本人尚未明白的主题。

## 二、第一、第二、第三人称怎样工作

### 第一人称

第一人称适合把听众放进人物内部，直接承受他的欲望、误解和选择。它必须保留人物局限：他可以记错、嘴硬、自欺、犹豫，但歌词要让这些偏差有事实来处。

检查：若把“我”改成“一个人”后整段毫无损失，说明人物没有私人声音；若“我”能准确解释所有人的心理，说明作者越权。

### 第二人称

第二人称必须有明确的言语对象，但对象不必实际在场，也不必有能力回答。每个“你”都要回答：对方此刻在场、缺席、失联、已故、只存在于回忆，还是由歌者在想象中召到面前；歌者是在当面说、隔空呼告、写信、回忆，还是对公众借称呼说；这句话想逼对方回答、留下、承认、听见还是承担。

第二人称连续使用却没有对象动作，只会产生空泛抒情。`你知道吗、你可曾、你是否`不能用来制造亲密感；问句必须改变关系或揭示人物不敢直说的东西。

### 第一人称发声与第二人称呼告可以同时成立

`第一人称歌词`只说明歌者以`我`承担所见、所感和选择，不等于全篇只能使用`我`，也不等于被爱、被问或被责怪的人必须写成`他`。`我对你说`仍然是第一人称人物在发声，同时采用第二人称直接呼告；这是两条不同的轴：

```text
叙述与感知轴：谁看、谁想、谁承担 → 我
称呼与关系轴：这句话直接投向谁 → 你 / 你们 / 他 / 她
```

人物可以对缺席、失联、已故或永远无法回应的人持续使用`你`。这种缺席呼告不是逻辑错误，它让人物暂时拒绝把对方降成一个供旁人议论的对象。合法条件是：`你`有稳定指向；人物有现实或情感理由继续向他开口；歌词不假装对方已经实际回答。

直接呼告与第三人称转述的距离不同：

| 写法 | 实际言语关系 | 常见效果 | 必须防止 |
| --- | --- | --- | --- |
| `我……你……` | 歌者直接把话投向对象，即使对象缺席 | 关系进入特写，请求、质问和思念更直接 | 只有称呼，没有任何想让`你`承受的动作 |
| `我……他……` | 歌者对另一个听众谈论对象 | 适合寻人、作证、讲述、传闻与公共场景，情绪经过旁人中转 | 把距离误写成客观，把第三人称误写成全知 |

`他`不会自动把第一人称歌词改成上帝视角。只要歌者仍是`我`，她就仍受自己的知识限制；`他`只表示此刻武生不是被直接说话的人，而是`我`与另一名听众正在谈论的人。反过来，`你`也不会自动产生真情，它必须完成具体关系动作。

### 第三人称

第三人称适合叙事、传说、群像、历史距离和人物无法亲自说出的处境。旁白必须选择观察距离：只写可见动作，还是允许进入某个人内心。不能一会儿像摄影机，一会儿像全知上帝，再突然替角色唱第一人称感想。

第三人称歌词仍需情感立场。纯粹罗列人物履历、剧情经过和环境说明，只是故事梗概。

### 公开演唱先分清四层对象

独唱不等于只允许一种人称。一个人物可以用第一人称向现场众人说话，同时用第三人称谈论一个不在场的人，并暗中希望那个人最终听见。问题不在于`我、你、他`能否同段出现，而在于每个代词是否有稳定的现实指向。

写这类副歌前必须建立对象表：

| 层次 | 要回答的问题 | 可用人称或句法 |
| --- | --- | --- |
| 歌者 | 谁正在唱，谁承担这句话 | 我、我们或已确认的角色声音 |
| 当面听众 | 此刻谁听见，歌者希望他们做什么 | 你、你们、诸位，或省略但能从请求句恢复 |
| 话中被指称者 | 歌者正在打听、议论或回忆谁 | 他、她、他们或明确称谓 |
| 真正希望听见的人 | 这段话最终想传到谁耳中 | 可以与当面听众相同，也可以是不在场的人 |

`我向台下众人打听他的下落，希望消息传到他耳中`可以使用`我 + 他 + 请告诉我`，这是第一人称公开寻人，不是人称混乱。但副歌必须让听众听出：`请告诉我`在请求现场众人提供消息，`他`指向不在场的武生，歌者不是忽然转头与武生当面对话。

每个代词都要通过现实指向检查：

```text
这个“我”是谁
→ 这个“你/你们”此刻是否在场
→ 这个“他/她”为什么不被直接称作“你”
→ 这句话要求当面听众做什么
→ 真正希望听见的人是谁
```

从`他`切成`你`必须对应可听见的对象变化：现场众人退去，歌者转入想象中的直接呼告；信件、戏中戏或演唱者发生切换；或人物终于不再向旁人打听，而直接把话唱给缺席者。

从`你`切成`他`同样必须有理由：歌者停止向对象说话，转而向公众作证、向旁人求证、向自己复述；关系已经断裂到人物不再承认直接对话；或流言与历史叙述把一个亲近的人推成众人口中的对象。`经历更多消息、情绪更复杂、最后一次副歌要更高级`都不是充分理由。第三人称不会自动产生上帝视角或史诗感，只会先改变言语对象和情感距离。

每次副歌回归都要记录：本轮核心句唱给谁；为何仍用原代词或为何必须改；切换后新增的是亲近、疏离、公开求证、自我保护还是关系断裂；不用这个切换会损失什么。四项说不清，保持原人称，不把换代词当作变体。

切换理由必须写进听众能够接收到的作品证据：称呼对象发生变化、句子要求旁人采取行动、叙述句法由呼告转为转述，或声音与舞台明确换位。删掉作者的分析说明以后，听众若不能判断她已经转向谁，切换就没有成立。禁止先在分析里宣布`她现在转向公众`，再拿这句幕后解释替歌词补足言语对象；作品没有给出可听见的变化，就保持原代词。

## 三、视角切换必须付出理由

人称或说话位置发生变化时，至少满足一项：

- 进入新的段落职务，例如桥段让旁白退场、人物终于开口。
- 时间位置改变，例如现在的“我”转入过去的“你”。
- 演唱者改变，例如对唱由甲转乙、独白转合唱。
- 关系认识改变，例如一直指责“你”的人最后转问自己。
- 现场与内心切换，并有清楚的声音、句法或舞台提示。

没有理由的切换会使听众误判谁在说话。只为押韵把“我、你、他、我们”来回替换，直接淘汰。

### 一旦改成书信、日记或戏中戏，就重新确定谁在说话

歌词里的书信、日记、留言、遗言、戏中戏、录音和人物转述，都不是作者可以继续说话的空白地带。形式一变，必须重新把下面七项列清楚：

| 载体 | 说话者 | 写下或说出这段话的时刻 | 对象 | 当时知道与误会 | 想让对方做什么 | 观众从载体外知道什么 |
| --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |

角色原话只写他在那个时刻有理由知道、相信、隐瞒或承认的内容。作者希望观众听出的死亡预感、背叛、误会、象征和主题，优先交给日期、递送延误、前后矛盾、漏写的消息、他人反应和后来事实。不能把这些解释全部塞回角色嘴里，再把作者的全知冒充人物的深情。

写道具原文前先写普通话目的：他是在报平安、询问近况、请求帮助、遮掩危险、维持承诺，还是交代一件具体事务。目的不清，不准先造遗言和金句。原话若同时替作者解释人物命运、作品象征、观众误解和全歌主题，直接退回重写。

逐句审查时，暂时忘掉作者已经知道的结局，只保留角色当时掌握的信息。这句话他还会不会说；为什么偏偏现在说；收信人是否明白它指什么。任何一项答不出来，说明作者已经越权。

### 引号不能替人物关系

歌词靠声音传递，听众听不见纸面引号。正式歌词正文默认不用引号模拟人物对白。若删掉`“等我”“嫁你”`一类引号后，听众便不知道是谁何时对谁说，说明视角和转述关系没有写进歌词，不能靠排版补救。

人物原话只有三种合法进入方式：歌者此刻直接对明确对象说；歌者用`你那天说、我记得你说`等自然转述建立来源；作品在新乐段或新演唱者中明确切换说话位置。无论哪一种，原话必须像该人物在当时真的会说的话，并服务他的现实目的。作者为了埋死亡预告、主题象征或结尾双解而造出的漂亮遗言，人物本人没有理由说，直接删除。

对唱和戏中戏的角色分配写进演唱方案与角色语言，不把`男：女：旁白：`或中文括号说明塞进可唱正文。目标平台需要标签时只使用已经约定的乐段或演唱标签；标签不能替代角色声音的差异。

## 四、多角色歌曲先分权，再分句

对唱、重唱、表演唱和多人组合不能把一份独唱稿按人数切开。先建立角色表：

| 角色 | 想得到什么 | 怕失去什么 | 只知道什么 | 误会或隐瞒什么 | 语言和节奏特征 |
| --- | --- | --- | --- | --- | --- |
| 甲 |  |  |  |  |  |
| 乙 |  |  |  |  |  |
| 合唱/群体 |  |  |  |  |  |

分配规则：

1. 每个角色必须带来别人无法替代的事实、态度或声音。
2. 回答必须回应上一句真正的问题，可以回避、误答或反问，但这种偏离要暴露关系。
3. 合唱段负责共同事实、共同愿望、冲突交锋或公共记忆，不负责把两人的私密心理平均掉。
4. 同时重唱不同歌词时，关键词、元音、句长和信息密度要允许听众抓住主次；文字不能互相遮蔽。
5. 多成员流行歌曲的分配要结合音域、声线、舞台动作和角色功能，不按人数机械平均行数。

若甲乙台词互换仍然成立，角色没有写出来；若一个角色只提问、另一个只讲道理，关系被写成采访。

## 五、“我”与“我们”的边界

从“我”进入“我们”必须有共同身份、共同经历、共同风险或共同动作。不能因为副歌需要宏大，就把私人经历突然扩大成所有人；也不能让合唱中的“我们”替内部有冲突的人群宣布一致。

群体歌曲先回答：谁被包括，谁不在其中；他们共同做过什么；这句话由所有人唱是否可信。没有共同事实的“我们”只是口号。

## 六、视角验收表

| 句子/段落 | 说话者 | 对象 | 事实来源 | 想让对方做什么 | 是否越权 | 是否可由别人替换 |
| --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |

做一次无标签听辨：去掉“男、女、甲、乙、合”等提示，只听歌词和声音，目标听众是否仍能判断谁在说话。若不能，补角色词汇、事实差异、句法差异或声音提示，不用括号标签替代人物创作。

公开演唱另做一次对象复述：让陌生听众回答谁在唱、当面唱给谁、正在谈论谁、真正希望谁听见。四项中任一项与创作设定冲突，先修句法和代词，不用作者解释补关系。

## 七、依据与边界

本文件吸收《歌词写作十八讲》第五讲关于独唱、对唱、重唱、齐唱、合唱及第一、第二、第三人称的内容，并将“人称分类”改写为信息权限、倾听对象和角色行动规则。教材中按男女气质固定题材和语言的部分不作为规则；性别不能替代人物经历、声线、身份和演唱能力。

[Pat Pattison 的 POV & Verse Development](https://www.patpattison.com/pov)把“谈论她”与“对她说”比作中景与特写：直接称呼不会自动提高质量，但会把关系动作推到听众面前。本项目据此把`他`与`你`理解为言语关系和距离选择，不把它们机械等同于第三人称作品与第二人称作品。抒情传统中的 apostrophe 允许歌者直接呼告缺席、已故、想象或无法回应的对象；本项目只采用这一公开修辞原则，不允许歌外解释替代歌词中的稳定指向和人物目的。

选题 Skill 决定采用何种演唱关系；本文件不重新选人物。旋律、声部、和声、同时重唱与舞台调度由 `laohu-lyric-composing` 负责；本文件只保证文字分配具有角色差异和可听信息。

## 八、失效判定

- 第一人称知道所有人的动机，角色没有认知边界。
- 第二人称有大量问句，却说不清对象是否在场和歌者要什么。
- 因为对象不在现场，就禁止第一人称歌者称其为`你`，强迫所有思念与质问先经过旁人转述。
- 第三人称把剧情从头讲完，没有人物当下的情感选择。
- 把第一人称歌者口中的`他`误判成上帝视角，或把`你`误判成第一人称视角；没有区分发声轴、称呼轴和知识权限。
- `我、你、他`字面都能解释，但说不清歌者、现场听众、话中对象和真正倾听者分别是谁。
- 人称切换只为押韵、方便解释或突然升华。
- 仅因流言更多、故事更复杂或进入最后副歌，便把`你`改成`他`或把`他`改成`你`，没有改变言语对象、现场位置和人物关系。
- 书信、日记、留言、遗言或戏中戏只换了外壳，仍由作者用全知口吻解释结局和主题。
- 道具原文为了制造深意，同时承担人物承诺、作品象征、剧情预告和观众解谜，角色本人却没有说这句话的现实理由。
- 去掉引号或`男：女：`提示后便无法判断谁在说话，纸面排版承担了本应由视角和角色语言完成的工作。
- 对唱只是同一作者声音左右互搏，甲乙台词可以互换。
- 合唱突然用“我们”替没有共同经历的人宣布一致。
- 多成员分词只追求行数平均，没有角色、声线和段落功能。
