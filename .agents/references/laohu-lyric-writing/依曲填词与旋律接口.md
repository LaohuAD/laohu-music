# 依曲填词与旋律接口

## 什么时候读取

已有旋律、伴奏、节拍、哼唱、MIDI、topline、参考音频、逐句音节格，或需要把多段歌词填入同一旋律时读取。没有音乐时，不用本文件假装存在精确音位。

## 一、旋律不是装字的格子

填词先理解音乐正在做什么，再决定文字。至少记录：速度、拍号、小节数、起拍、每句音符数与时值、重拍、切分、长音、高音、休止、重复动机、段落峰值、计划气口和歌手音域。

总字数相等不代表能填。同一组音符对以下内容有不同要求：

- 一个音对应一个字还是允许一字多音。
- 词组边界落在哪里。
- 哪些字占长音、重拍和最高音。
- 哪些位置必须连续，哪些位置可断。
- 同旋律多段歌词的自然重音是否相容。

## 二、先做旋律扫描

按乐句建立表格：

| 乐句 | 小节/拍点 | 音节位 | 长音/高音 | 重拍 | 休止/气口 | 情绪功能 | 文字风险 |
| --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |

旋律资料不完整时明确写缺口。只听见大致哼唱，不能声称逐音填配已经完成。

## 三、填词顺序

1. 先放不可替代的核心词、关系词和关键动词。
2. 把意义重音放到重拍、长音、高音、切分或句尾中的合适位置。
3. 按自然词组填中间音节，不从固定词中间拆开。
4. 安排韵脚和句尾元音，保证副歌回归。
5. 检查声调与旋律是否造成严重误听。
6. 标出气口，确认一口气内的信息和演唱难度。
7. 试唱后回改文字或旋律，不保护任何一方的第一版。

## 四、重音冲突

若音乐最高、最长、最强的位置落在语义弱字上，依次尝试：

```text
调整语序
→ 更换不改变事实的句法
→ 移动关键字到音乐重心
→ 改变个别节奏或旋律
→ 重写整句
```

不能为了保住旋律，把“你没有来”唱成重点落在“有”或“来”以外的无意义位置；也不能为了保住一句漂亮词，破坏整段旋律动机。词曲共同服务中心情绪。

## 五、长音、高音与转音

长音位置优先选择能保持元音、承担情绪和听清语义的字。高音处减少难咬辅音群和复杂信息；转音密集处避免塞入必须逐字听清的新事实。若核心词只能通过扭曲字音唱出，改词或改旋律。

一字多音要确认该字值得延展；多字一音或极密节奏要确认听众仍能分辨词组。装饰音属于演唱设计，不应替歌词补情绪。

## 六、同旋律多段歌词

分节歌和重复主歌不仅要求对应句字数近似，还要求：

- 词组切分相容。
- 意义重音落在相同音乐位置。
- 长音字的元音和咬字难度相容。
- 情绪强度与旋律姿态相容。
- 气口不切断其中某一段的固定关系。

若第二段为了套曲不断倒装、补字、缩词，优先重写第二段；若多段都不自然，旋律模板本身需要调整。

## 七、已有伴奏但无固定旋律

先从伴奏判断稳定条件：速度、律动、段落长度、能量、调式气质、低频密度和空间。再试多个文字节奏，不要只写一版后硬贴。topline 形成后回到本文件逐音核对。

## 八、词曲冲突裁决

出现冲突时按重要性判断：

1. 人物事实和核心意思不能被押韵或音节篡改。
2. 核心旋律动机和副歌识别度不能为无关修饰词牺牲。
3. 语义重音、音乐重音和气口必须找到共同方案。
4. 局部漂亮词、临时转音和非关键音符都可先放弃。

无法同时保留时公开代价，由作品目的决定；不把“词先”或“曲先”写成永久教条。

## 九、依据与边界

本文件吸收《歌词写作十八讲》第十三讲的填词步骤、第四讲的同曲多段对应、第九讲的唱着写和第十四讲的诵唱修改。教材允许用熟悉旋律临时辅助写词，本项目仅把它作为节奏试验；临时旋律不得进入成品，不得无意复制可识别旋律。

已有 beat、track、loop 或伴奏而尚无固定主唱旋律时，参考 Berklee Online 的 [Topline and Vocal Production](https://online.berklee.edu/courses/topline-and-vocal-production)处理 topline：先从制作中提取节奏、段落、hook 和演唱空间，再共同设计旋律与歌词。该来源只支持 topline 是词、旋律、演唱与制作协同工作的判断，不提供中文音节、声调、韵脚和气口的现成答案；这些仍须按实际普通话演唱逐句验证。

具体旋律、和声、编曲、音域和演唱设计由 `laohu-lyric-composing` 负责。本文件只规定歌词怎样读取和回应音乐约束。

## 十、失效判定

- 只报每句字数相同便认定填配完成。
- 关键名词和动词落在弱位，虚词占据最高最长音。
- 为套音符切断固定词、否定、动宾和姓名。
- 同旋律第二段只能靠大量倒装和补字勉强唱。
- 没有音频、MIDI、节拍或音节格却声称逐音验证通过。
- 词曲冲突时只要求另一方让步，没有比较作品损失。
