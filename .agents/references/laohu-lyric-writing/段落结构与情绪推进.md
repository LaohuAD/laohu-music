# 段落结构与情绪推进

## 什么时候读取

需要设计或修改主歌、预副歌、副歌、后副歌、桥段、结尾、分节歌、回旋结构和整首歌词的信息推进时读取。已有旋律时同时读取[依曲填词与旋律接口](./依曲填词与旋律接口.md)。

## 零、先选择结构问题，不先补齐段落名称

结构设计先回答作品怎样被听懂，再决定是否需要主歌、预副歌、副歌、桥段和尾声。禁止看见一段完整故事，就默认套入`主歌 1—预副歌—副歌—主歌 2—预副歌—副歌—桥段—最后副歌`；这只是一个常见容器，不是叙事歌的标准答案。

先把选题总线翻译成五项顺序要求：

```text
听众最早必须看见哪一个异常现场
→ 哪些背景可以后置，哪些事实不先知道就听不懂副歌
→ 哪一句或哪一段值得重复，重复后凭什么改变意思
→ 哪个新证据必须打断原来的结构或声音秩序
→ 最后的不可逆行动需要怎样的回看距离
```

自由写词但尚无旋律时，只能确定**歌词信息结构的暂定方案**。没有速度、拍号、旋律句长、和声循环、目标时长和歌手条件，不得把暂定段落表说成已经完成的音乐曲式；需要真实曲式判断时，交给谱曲 Skill。

叙事大纲回答故事先后，歌词结构回答听众先听见什么、哪句话回来、每次回来为什么更重。两者不能互相冒充。`童年—参军—寻找—来信—登台`只是事件顺序；只有进一步决定哪些事件不唱、哪项证据放进主歌、哪个问题收进预副歌、哪个语言动作进入副歌、哪项新事实改写桥段，才算歌词信息结构。

复杂叙事、强反转、用户明确要求高潮前置，或有人追问“要不要预副歌”时，内部至少比较两个真正不同的结构候选。候选必须改变信息出现顺序、重复位置、高潮到达方式或听众掌握的答案，不能只在同一模板上增删一段。对外给主推荐和必要的强分支，并说明：

- 它保护了总线中的哪项事实、悬念或人物选择。
- 它让听众提前知道什么、延后知道什么。
- 主 hook 第一次何时出现，代价是进入更快还是铺垫更足。
- 哪一段若被删除，作品会具体损失什么。
- 当前结论依赖哪些尚未取得的旋律、时长或制作条件。

### 预副歌准入

预副歌不是故事歌的标配，也不是主歌和副歌之间的装饰过门。只有以下问题中至少两项有明确答案，才保留：

1. 主歌直接进入副歌时，哪项心理压力、语义转折或音乐动势来不及形成。
2. 预副歌准备扣住哪一个尚未说破的问题；它不能只把“舍不得、等待、心痛”提前说一遍。
3. 它将在句长、节奏密度、和声不稳定、音域、韵脚或停顿上造成什么可听见的变化。
4. 第一次与第二次出现时，是否能因新事实而换词、增压或改变唱法；若只能机械复用，收益是否足以抵消拖慢副歌。
5. 删除以后，副歌是否仍能自然且更有冲击地到达。能，则优先删除。

没有旋律时，可以判断歌词是否需要一个“收窄问题的段落”，不能擅自宣布它应当“偏戏腔”“更紧”“往上顶”。这些属于待谱曲验证的声音假设，必须说明依据。

### 高潮前置要分清载体

用户要求把高压画面放在最前面时，先区分三件事：歌曲本身以副歌片段或结局现场冷开；MV、短视频先播放高潮画面而歌曲仍按时间展开；歌词第一段只露出后果，不泄露原因。三种做法改变的是不同作品层，不能用“副歌前置”一词全部概括。选择后必须说明它怎样保护悬念，是否提前泄底，以及后文回到同一画面时新增什么。

## 一、结构不是段落名称，是听众接收信息的顺序

先写出整首歌的运动：人物起初怎样理解当前处境，什么事实使压力增加，副歌必须说出什么，后来又知道了什么，最后决定、承认或留下什么。

每个段落只回答一个问题：

```text
听众进入本段前已经知道什么
→ 本段新增哪一项事实、关系压力或声音变化
→ 本段结束后，下一段为什么非来不可
```

只更换景物、形容词和同义句，没有改变听众知道的事情，不能算新段落。

## 二、可用段落的职务

以下是可选择的部件，不是必须补齐的编制。先由作品运动决定需要什么功能，再给承担该功能的段落命名；不能先拿段落名称占位，再往里面塞故事。

### 主歌 Verse

主歌负责建立人物、场景、动作、时间变化和关系证据。它不负责把主题解释完。

第一主歌至少让听众知道：谁在什么处境里注意到什么，眼前哪一个动作使问题发生。第二主歌必须新增事实或改变同一事实的意义，不能把第一主歌的物件再列一遍。

主歌常用推进：

- 从现场到关系：先写此刻的动作，再让动作暴露过去。
- 从过去到现在：同一件事前后意义改变。
- 从表面到真相：第一段按人物当时理解写，第二段给出后来才知道的证据。
- 从个体到共同经验：先把一个人的生活写真，再让听众自行认出自己；不先喊“所有人都这样”。
- 从秩序到破坏：先建立日常规则，再写哪一处不再成立。

主歌失败信号：开头四句删掉次序仍无影响；每句都能换到另一首同题歌；连续列物件却没有人物动作；一开始便把副歌结论说尽。

### 预副歌 Pre-Chorus

预副歌只在需要收窄、加速、抬高或延迟副歌时存在。它把主歌的多项事实逼成一个即将爆发的问题，并在节奏、句长、韵脚或语气上制造门槛。

预副歌不能成为第二段主歌，也不能提前唱完副歌。若删除后副歌仍自然到达，且没有损失压力或音乐对比，删除预副歌。

### 副歌 Chorus

副歌负责整首歌最主要的语言动作：承认、质问、请求、宣告、决定、命名或反转。它通常承担最高记忆密度和最稳定的重复，但不必每首都写成主题总结。

副歌第一句必须迅速改变听众的位置：从看事情转为进入人物最不能回避的关系。副歌核心句可以第一句直击，也可以在同一压力链完成递进后延后落下；位置由它是直接质问、承认、请求，还是需要前置预期的反转决定。副歌最后一句要么完成落点，要么留下下一轮必须继续的悬念。若前两句与核心句各自建立不同的对象、任务或情绪中心，不得用“都是同一故事”解释连接，必须重建段落关系。核心句的具体规则见[副歌核心句与传播记忆](./副歌核心句与传播记忆.md)。

副歌的句长应当形成层级，而不是把每行裁成相同长度。较长的句子可交代条件、现场或因果，较短的句子应承担判断、请求、反转、重音或 hook 落点；连续短句若没有对象和动作，只会变成口号，连续长句若没有词组和气口，只会变成押韵散文。结构设计时先写清每行的语言职务，再把它交给[声音韵律与可唱性](./声音韵律与可唱性.md)验证。

### 后副歌 Post-Chorus

后副歌负责把副歌剩余能量变成最简短的声音记忆，可以是标题、衬词、短句、音节、重复动作或问答。它不继续解释主题。

没有独立声音功能，只把副歌最后一句多抄两遍，删除。需要依靠旋律或制作才成立时，在歌词稿中标明功能，不假装纯文字已经完成。

### Hook 系统

hook 不是副歌核心句的别名。整首歌可能同时存在：标题或核心词的语言 hook、短旋律与节奏型 hook、衬词或无实义音节 hook、问答 hook、riff/制作 hook、舞台动作 hook。歌词 Skill 只负责文字、音节和段落位置，并与谱曲 Skill 共同检查它们是否互相争抢。

先确定一项主 hook，再安排最多一至两项辅助 hook：

```text
主 hook：听众离开后最应记住什么
→ 辅助 hook：用哪段短语、音节、问答或后副歌帮助回忆
→ 回归位置：每次出现前新增什么
→ 标题关系：歌名是否来自主 hook，还是只与它互相照应
```

核心句可以不是最短 hook，最短 hook 也可以没有完整句意；但它们必须服务同一人物和中心情绪。主歌有一个口号、副歌有另一句格言、后副歌又塞一组拟声词，听众记住的入口互相打架，删到只剩主次。

### 桥段 Bridge

桥段必须带来前文无法提供的东西：新事实、新时间位置、新说话对象、新认识、新代价或新的音乐视角。它不是“再写一段更文艺的话”，也不是规定动作。

桥段常见职务：

- 承认前两遍副歌中一直回避的事实。
- 把质问对象从对方转向自己。
- 让时间跳到多年后，重新解释原句。
- 暂时离开主意象，看到关系的另一面。
- 作出会改变最后一次副歌的决定。

桥段结束后，最后副歌至少有一处文字、语气或听感发生变化。回到副歌却与第一次完全等价，桥段没有完成工作。

桥段必须同时通过两道门：内容门说明哪一项新事实、认识、对象、代价或决定改变了最后副歌；声音门说明它相对于前一副歌和最后副歌，在句长、词组密度、起句方式、韵脚、停顿、气口、音区或演唱姿态中至少改变哪两项。没有旋律时只能提交文字侧声音假设，但仍须给出词组、重音、韵脚地图和意义气口；不能等谱曲替四句说明文制造桥段感。

桥段不必沿用副歌主韵，也不必强押统一韵。它可以破韵、散板、近念白或突然缩短，但必须另有一项可听见的组织，例如固定起句、平行句架、问答、递减、重复关键词、句尾回环或有意留下的断口。连续四句都在交代谁说了什么、信从哪里来、人物知道什么，只通过剧情证据门，没有通过桥段门。

### 结尾 Outro

结尾决定听众离开歌曲时带走什么。允许自然结束、回到开头、让核心句变义、完成动作、留下问题、缩成衬词或反复尾句。禁止没有材料准备的突然升华。

结尾优先选择整歌已经挣来的动作：人物终于说完一句话、停止一个动作、承认一项事实、改变称呼、接受没有答案。若只能再总结一次主题，优先回看副歌是否已完成结论。

## 三、结构确定后才分配正式标签

标签不是中文段名的翻译，也不是平台装饰。它把已经确定的段落职务交给作曲、制作、演唱和生成平台。结构候选尚未裁决时使用临时字母或“段落 A / B / C”；确定后再按[歌词稿格式与乐段标签](歌词稿格式与乐段标签.md)改为 `[verse]`、`[chorus]` 等正式标签。

同一个故事可以有不同标签结构。例如“来信”既可能是第二主歌的新证据，也可能是桥段里推翻旧判断的唯一事实；它放在哪里取决于它是否改变副歌，不取决于故事里发生得晚。不能先认定“信件等于桥段”，再为它补一个桥段作用。

## 四、常见结构只作为候选容器

| 结构 | 适用条件 | 硬要求 |
| --- | --- | --- |
| 分节歌 A1/A2/A3 | 同一旋律承载多个侧面或时间段 | 对应位置的词组、时值、重音和情绪强度可复唱；每段内容必须推进 |
| Verse–Chorus | 需要事实与核心动作形成明显分工 | 主歌提供副歌证据，副歌不重复主歌说明 |
| Verse–Pre–Chorus | 主歌与副歌之间需要压力门槛 | 预副歌必须改变速度、范围、句法或不稳定感 |
| 分节歌加尾句 Refrain | 故事持续推进，但每一节都需回到同一句承诺、称呼或判断 | 尾句必须因新事实增重，不能每节只做情绪盖章 |
| AABA | 核心段反复成立，B 段提供偏离或新视角 | A 每次回归有上下文变化，B 不是随意插段 |
| 回旋/副歌先行 | 核心句本身足够抓人，需要不断回到同一中心 | 每次回归前有新增材料，不能只靠播放次数制造力量 |
| 冷开/高潮片段前置 | 结局现场或核心关系能先制造必要悬念 | 只给异常和危险，不提前交代完整因果；后文回归必须重新解释开头 |
| 通篇连续/through-composed | 故事或意识持续变化，不适合固定副歌 | 仍需声音锚点和局部重复，否则听众抓不住中心 |

结构名称不能替代作品判断。没有预副歌就不要硬添，只有一句副歌也可以成立，主歌和副歌边界模糊也可以成立；前提是听众能听见功能变化。

### 从段落推进表长出歌词雏形

结构讨论不能只留下`主歌写童年、副歌写等待、桥段写来信`。每个关键乐段至少完成一次局部试验，验证它是否真的能承担所分配的职务：

```text
本段从哪个具体现场或事实开口
→ 人物这一段只允许知道什么
→ 哪一两句最能证明本段职务
→ 句尾怎样把压力送向下一段
→ 它与主 hook 使用相同词场还是形成必要对照
→ 暂定词组、韵脚、重音和气口怎样服务这次推进
```

锚点句不是每段必须完成的金句指标。它可以是一个准确场景、一句转折、一项人物请求或一组声音回环；只要它能检验段落能否写成歌词，而不是继续停在故事说明。没有合格句时记录普通话事实与失败候选，不拿低质量诗句填空。

副歌确定以后，必须反向设计进入它的道路：

- 主歌最后留下的是哪项尚未回答的事实，而不是哪个抽象情绪词。
- 若直达副歌太突兀，究竟缺人物改口、对象转移、问题收窄还是声音抬升。
- 预副歌试写后，删除它再读一次；删掉更利落便不保留。
- 第二次进入同一副歌时，主歌必须提供新证据，不能只换场景。
- 桥段必须改变最后一次副歌中的至少一项对象、判断、代价、唱法或关键词。

雏形完成后做“拆件测试”：把锚点句全部拿掉，只读段落事实和连接关系，整首歌仍应成立；再把锚点放回去，它们应提高准确度、声音和作品归属，而不是迫使其他段落解释它。前者不成立说明结构依赖漂亮句遮羞，后者不成立说明局部句子正在绑架整体。

## 六、教材吸收与校准

本文件吸收《歌词写作十八讲》第四讲对句式、分节歌、主歌副歌、二段体与三段体的说明，并吸收第九讲“构思阶段同时考虑段落结构、语言风格与韵律”“从片言只语开始逐渐丰富成初稿”的过程判断。第八讲的材料组织方法由[材料组织与叙事压缩](材料组织与叙事压缩.md)负责。教材把副歌概括为归纳和升华，是常见做法，不是现代流行歌的唯一职务；本项目把它扩展为人物在高潮处完成主要语言动作。

[Gary Burns 对流行录音中 hook 的类型研究](https://doi.org/10.1017/S0261143000006577)用于校准：hook 可以是标题、歌词短语、整行、旋律、节奏或声音，不应被缩成“副歌里的一句金句”。该研究只证明 hook 具有多种形态和重复作用，不证明某种 hook 必然商业成功。

## 七、失效判定

- 用 `A1/A2/B/C` 标了结构，却说不出各段新增什么。
- 收到完整故事后，未经比较便直接给出标准流行曲式。
- 把叙事大纲中的“主歌、副歌、桥段”中文称呼当作用户已经确认的曲式，未展示正式标签序列便进入歌词正文。
- 用户追问预副歌时，只因为“有故事、有场景”就断定应该添加，没有说明直达副歌会损失什么。
