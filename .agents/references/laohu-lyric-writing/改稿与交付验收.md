# 改稿与交付验收

> 先救整歌，再救一句；先看命，再看字。

验收不是把所有句子改成同一种漂亮，而是先判断作品的命题、段落和材料是否仍在发声，再决定哪些字值得动。下面的负面条目只用于发现已发生的错误，不作为生成时的词库禁令。

## 作者退场

任何歌词候选准备向用户展示前，先遮住所有分析和创作说明，只读歌词。核心句、单段试写、替换句和完整初稿使用同一道门，检查深度按交付规模调整，不因篇幅短、标为探索或尚无旋律而免检。不要护稿，也不要先做近义词替换。先判断它是不是歌词，还是把故事梗概分行后加了古词和韵脚。

探索审当前试验及必要依赖，锁定审整稿；没有音乐时声音保持假设。下文关系动作、三次回归与改判只在对应表达职务下执行，不要求未采用的段落或未知主歌先有答案。

## 候选展示准入

生成者必须在内部完成下面七项证据；它们只用于决定候选能否交付，用户没有要求时不展示检查表：

这道门只负责检查正文是否实现了生成前选定的整段构思，不负责在坏稿上寻找创作方向。同一乐段若先后因为视角、材料、逻辑、语体或声音等不同局部问题连续退回，停止增加检查项和逐句修补，回到`03-血肉与材料抒情.md`重新比较整段构思；不得把第七、第八道禁令当成生成能力。

```text
局部四层：先标出`形式角色 × 表达方式`，再写本段的灵魂职务、段内运动与交接、承重材料、声音形态、越位边界和可能的混合角色；不得用副歌的直接开口标准审查所有乐段，也不得把 Rap、念白、齐唱或纯器乐误当成独立形式职务
裸稿拼接：去掉乐段标签和候选说明，把候选接到已确认的相邻乐段或核心句旁边连续朗读；当功能卡要求前段改变后段听法时，另写出前段末尾尚未完成的关系动作、行动责任或问题，以及后段第一意群实际完成、反驳或改写了什么
人物主干：逐行标出实际主语、主要动词、对象和句尾；说明歌者是否真的在看、听、辨认、承认、请求、拒绝或承担
句间接力：逐对写出上一行或记忆意群留下什么可感材料，下一处怎样沿用、改变、遮断或重新辨认；发生时间、地点、感官或主要触点变化时，标出正文中负责转接的词、动作、后果或段落边界
段落损失：把候选压成中性普通话梗概或分镜，记录失去的观察、关系、反讽、人物口气、文化尺度和声音记忆；具体指出哪个词或句法造成损失，仅报代词变化、排版或韵脚数量不算证据。大意相同而独特听法消失，是表达退化，不能因事实齐全放行
声音证据：标出自然词组、主要重音、候选气口、全部句尾和主韵/邻韵/有意不押处；字数只能附在这些证据之后
解释残留：逐项核对作者声称的象征、复沓变义、情绪递进和节奏走势，裸歌词是否让听众在没有说明时仍能直接听出
```

七项证据按下面的顺序裁决：

1. **先判局部四层**：先按主 Skill 四层内部的乐段偏转判断候选。主歌可以使用外部状态、有限叙事和公共场景，只要它们形成可进入的处境、在段内让压力发生变化，并给下一段新的来处；不能因没有直接关系动作便退回。Refrain 看固定回环能否完成本作的记忆、持续或改义，Pre-chorus 看是否形成通向下一段的期待，Chorus 看是否建立本作可重复的感情、立场、感知或声音中心，Post-chorus 看是否收束、回响或形成第二高潮，Bridge 看是否完成本作选择的对比、转换或改判，Link 看是否有效连接，Intro/Outro 看是否建立或回收，Interlude/Solo/Breakdown/Drop 看是否应当无词及其前后职务。Rap、念白、齐唱、对白和 Vocalise 只改变实现验收，不能替形式职务通过。第一遍清楚、与相邻段落题材一致或语言风格统一，都不能补偿局部职务没有完成。
2. **再判人物与段落**：第一人称歌词若只把`我`放在物主、处所或被动位置，而主要动作与意义仍由其他人物、物件和事件完成，检查这是否属于已经确认的叙事体式。当前乐段负责让歌者的压力显形或直接开口，却只能靠代词证明主观性时，退回关系母句或材料选择；不得继续炼字。
3. **再判段内连接**：依靠画面、感官或空间变化抒情的段落，必须让相邻行或相邻记忆意群之间存在正文可听见的材料接力。下一处只是另一个同题画面、时间上可能随后发生、句尾押同一韵，或需要作者补写一项事件以后才合理，都不能算自然发生。普通话展开一旦加入裸稿没有的动作、对象、死亡结果或因果，退回血肉层重选触点；有清楚句法、复沓、音乐位置或段落边界的跳切不受此限。抽象判断转入具体画面时，正文若已用明确对照、因果或关系动作把它和可感后果连在一起，可以成立，不因材料类别变化自动退回。
4. **再判乐段交接**：当段落功能卡声明前段要使后段获得新听法，尤其主歌或预副歌直接进入副歌时，只连读前段最后两个记忆意群与后段最先两个记忆意群。前段末尾必须留下后段第一意群能够完成、反驳或改写的关系动作、行动责任或问题；不能只停在同题画面、人物凝望或一般情绪。相邻乐段若由对象行动转为歌者宣告，前段还要让行动责任为何转到歌者身上能够被第一次听见。若普通话展开必须在两段之间补入正文没有的`于是我不得不……`、`后来我终于……`等动作或因果，判为交接断裂，退回前段出口或后段入口；已经确认的停顿、和声悬置、旋律呼应或戏剧性跳切确实承担这项转折时可以保留，但无音乐材料时不得预支这项证明。
5. **再判全曲同声**：已有确认歌词时，候选必须与最近的同类乐段及核心句连读，比较主要语气、句法推进、古雅与浅白比例、承重词密度、句尾力量和声音动作。先由语言底稿确定本歌真正的不变量，不把所比较的全部指标自动固定。场景、感官、语域、语气和韵脚可以按局部职务改变；仍是同一人物、同一立场且切换可辨时，变化本身不算换歌。用户保护的声口或事实无依据地改变才退回。
6. **再判声音是否真的存在**：句长变化只有在自然语义单位、重音位置、气口或旋律时值随之变化时才算声音设计。把一个完整句拆成时间从句、条件从句或其他依附成分，不能因为后一行变短便称为长短句；只报`8 / 8 / 10 / 6 / 9`一类字数，不得作为节奏通过证据。
7. **最后清除稿外补义**：判断相邻短句的重复是否多余以前，先把各句省略的主语、对象和结果补回，标出它分别承接紧邻前文的哪一项时间、画面、人物、动作或后果。相同句架若分别领取不同的承接项，并让听众第一遍就能从前文补回，属于语义与声音共同推进；不得只因两句接近同一大意便删掉后一拍。两句若补回以后仍指向同一对象、同一结果，后一项只把前一项换词解释，才判为无效重复。固定 Hook、称谓呼号、齐唱和跨乐段回归另按其结构与声音职务验收，不要求每一次都更换省略对象。作者能解释出“第一次是选择，第二次是告别”，不能证明听众已经听见；候选的主要优点若必须依靠说明才能成立，先删除说明重新判断，裸稿不能自证就退回上层重写。

裁决与分层事实必须分开记录。候选在灵魂、筋骨或血肉层退回，整段结论仍是退回；但已经成立的自然词组、句长走势、复沓、韵脚、重音和气口必须按实际保留，不能因为整段失败便改口说它“没有节奏、没有声音”。反过来，声音层成立只是一项可保留资产，不能抵消人物开口、段落职务、寄情关系或语义搭配的失败。返工时先修最早断点，再判断原有声音形式是否仍与新内容相称，不为保住节奏强留错误歌词。

准入结论只有两种：

- **可展示**：裸稿已经完成当前乐段职务，并与全曲人物口吻、语言密度和文字侧声音基准相容。没有旋律时只标为文字侧通过，音乐可唱性仍待验证。
- **退回**：任一主要优点依赖剧情梗概、作者解释、字数统计或局部感官替它成立。按照最早失败位置回到关系开口、段落职务、材料选择或声音卡，不把未通过候选交给用户共同审稿。

这道门不要求所有歌词都由第一人称主语发起，也不禁止叙事歌、对白歌、故意破韵、同字复沓和从高压宣告转入低声细节。它只要求偏离已经由作品体式、人物距离、段落职务或音乐条件证明，并且证据存在于正文或已确认设计中，不能由交付后的解释临时补足。

## 第一轮：抒情是否成立

逐行标记以下主要职务：

    关系发声 / 抒情回声 / 声音记忆 / 必要事实

关系发声还要标出方向和来源：谁在爱、恨、怨、怪、等待、请求、拒绝或原谅谁，材料中的哪项选择、认知或误解允许人物这样开口。疑问句不能免检；`你是否怨我`仍然预设“你可能怨我”是歌者此刻真实担心的事。若问句为了结尾、押韵或增加痛感才临时引入新的关系冲突，推翻该句，回到关系事实账。

一段如果主要由必要事实组成，先看乐段职务。主歌允许叙事，但事实必须建立处境、改变压力或使下一次副歌获得新听法；若只是把剧情摘要分行，仍判为文艺化叙事。副歌通常不承担连续事实报告；桥段中的事实应服务本作选定的对比或转换，不能只因发生在后面就占据桥段。不得只把“后来”换成“既而”，也不得用月、风、灯补装饰。

做三个测试：

1. 梗概测试：改写成谁在何时做了什么，检查损失是否符合本段职务。主歌至少应损失观察运动、情绪入口或对下一段的新交接；副歌检查是否损失本作的情绪或声音中心；桥段检查是否损失本作选定的对比与转换。没有相应损失才推翻。
2. 时间删除测试：删掉后来、临走、收到、有人说等连接词，若只剩顺序断裂，推翻。
3. 触点关闭测试：删掉物件后，若只剩“我很痛苦”，推翻关系回声。

## 第二轮：段落是否运动

按主 Skill 的段落功能卡和 `02-筋骨与结构运动.md` 检查，不在验收层另设一套更窄的乐段定义。先遮住计划，读出裸稿实际带来的感受及其词句证据，再与目标比较；不能先知道作者想写什么，再替每件物品补寓意。

副歌尤其检查整段是否形成可辨认、可重复的中心。关系歌要辨明具体愿望、眷恋、怨怼或犹疑，不能一律解释为“放不下”；混合情绪可成立，但各端应在词句中有根据。意象、叙事、第三人称和含蓄表达都可实现此职务。预副歌的期待、后副歌的回响或高潮、桥段的对比、尾声的停留，同样按实际实现检查，不强制统一为关系改判。

同题、材料有来源、语句通顺和押韵是不同层面的证据，均不能替代段落完成作用。候选若仅能交代事情，先判断本歌是否需要这种讲述及它产生的听众体验；不适合副歌也不代表适合主歌。移动前必须独立证明目标段落需要它，否则重写整段表达，不通过换标签转移问题。

直陈关系的路线另查说话现场和开口连续性；景物、叙事和跳切路线检查统一的感情指向或有根据的变化。稳定陪伴、吟唱和律动查安定、参与与回接，不补造剧情。无音乐材料时，音域、和声与编曲的作用保持假设，不能用想象中的高潮替文字解围。

本作采用三次关系变义副歌时记录（不规定回归次数）：

    第一次的新听法
    第二次的新压力
    最后一次的新责任/新代价

关系改判路线删掉前段后若新听法和声音后果都不受损，检查铺垫是否无效；稳定路线另查安定、记忆和参与收益，不以词义不变作否决。

采用关系闭合路线时，再做一次未完成项清账：圈出前两次副歌反复留下的问句、否认、愿望和未完成判断；最后副歌必须回答、拒答或用新决定改写其中至少一项。若结尾另起意象，或只给一个静态主题判断，原来的问题仍需作者在歌词外解释，判为筋骨未闭合。

再核对曲式中的副歌回归次数与本轮交付次数。曲式已锁定三次回归、用户要求完整创作副歌时，正文必须同时出现三次，并让共同核心句与变化部分都可对照；少交一次即判为交付不完整。用户只要求单段试写或指定一次评审时不触发，但不得把该单段称为整组副歌完成。

## 第三轮：语言和声音

逐句检查主语、动词、对象、文化语境和关系压力。非日常词不能仅因低频被改掉；日常词也不能因顺口被保留。

有锁定核心句时，先把核心句与每个新增意群分别连读，记录主要语气、句法推进、承重词密度、人物身份、命运尺度和句尾力量。新增句若像作者把段落功能解释给听众，或需要靠连续条件词、因果词和过程句才能接续，判为语言断层；不得因为人物、剧情和情绪方向仍然正确而放行。

再检查：

    自然词组
    意义重音
    空格气口
    句尾实词和近韵
    可延长、停顿或留白的位置
    每个情绪词、抽象词或意象词的主要职务
    抽象情绪是否经过准确的比喻、物性、动作、声音或礼俗转译

压缩意群之间另做普通话展开：两个短句是何种关系，省略的主语、动作或对象能否唯一补回。若补法不同会改变人物最后做出的选择，恢复必要关系或重写；不得把句义缺失当作古雅、留白或气势。

声音专项检查必须把以下项目分开验收：

- **句数**：是否符合本段结构容量；四句、八句、十六句检查的是句数或音乐句数，不是每句字数。
- **句长**：是否随内容、重音和旋律假设变化；是否误把整齐分行当成可唱性。
- **气口**：是否只标在自然词组、意义重音和换气处；是否错误地固定成每句两个，或切开主谓、动宾和固定搭配。
- **韵脚**：是否有独立的主韵、邻韵、落韵位置和有意不押位置；是否出现无意乱韵、硬凑韵或语气词承担主韵。
- **层级隔离**：是否把“铺陈、转关系、收住”等段落职务误写成押韵、句长或气口规律。
- **声音验证边界**：无旋律、拍读或试唱时，只能标记文字侧假设，不能宣称最终可唱。
- **换歌测试**：遮住故事背景，只读核心句与新增句；若像不同人物、时代、语体或情绪强度的两段歌词拼接，推翻新增句。确有意降低强度或转入低语时，必须指出前文、关系或音乐提供的转变理由。
连续三行以上同字数且同气口时启动对称来源检查：逐行写出相同句架承受的意义变化，或指出已有的重复旋律、节奏动机与演唱理由。没有其中任何一项时，另做一版长短句拍读；若长短版更能保住自然语义、重音和情绪变化，撤销机械整齐版。这个检查不禁止整齐句，只淘汰没有表达职务的视觉对齐。

按`04-表皮与语言声音.md`的正向成品校准，核对原句、最小修复与差异实现的实际收益和损失；既拦截无效华丽化，也拦截丢掉声口的顺滑化。改稿没有比原稿更能实现当前任务，就不能以已经检查语法、字数和押韵作为通过证据。

出现以下情况，不做近义词美容，直接回到血肉层重写：

- 一个词需要事后解释成多种并列情绪。
- 把“思念如刀”这类有明确来源属性的转译，退化成“空、冷、轻、沉、远”等无来源的氛围词。
- 把抽象词一律删除，误以为抒情必须只剩物件和动作。
- 词语虽然真实存在，但人物不会在这个语境里这样说，或词组的主语、动词、对象关系不成立。
- 句子只是把普通语义删碎，再用陌生字词补成“像诗”的外观；这类问题回到血肉层，不做表面炼字。
- 当前句已经成立，却因为模型偏好更冷、更轻、更沉、更古而被替换；这类改动回退到原句。

无旋律时只能说明文字侧风险；没有拍读、试唱或成曲，不得宣称“最终可唱”。

## 第四轮：反向审查

主动找以下最可能被否决的地方：

- 看似有画面，实际只是新镜头。
- 看似有情绪，实际只是情绪名词。
- 看似古雅，实际是现代梗概换词。
- 看似留白，实际只能靠作者解释。
- 看似押韵，实际改变了人物关系或造成不自然搭配。
- 看似改得更雅，实际丢掉了原句的关系动作、文化重量或人声。
- 看似桥段，实际只是剧情信息。
- 看似有留白，实际只是把情绪拆散后塞进空席、回声、末句、字形等功能符号。
- 看似有韵律，实际只是句数、字数、气口和韵脚被机械套成同一种格式。
- 看似完成了段落功能，实际只是把功能说明分行、押韵或古雅化，核心句的语言力量没有被继承。

发现上层问题后回流上层重写。正式交付必须是审过并修改后的版本，不是初稿加自我辩护。

## 阶段门槛

初稿未整体认可时不宣布锁定或发布；内部审改及用户授权的声音、视觉探索可继续，明确验证对象与未决项。用户指出局部问题时，先判断它是否暴露灵魂、筋骨、血肉或表皮的规则缺失；具有复用价值的反馈先写回 Skill 或作品创作台。
