# 改稿与交付验收

## 什么时候读取

初稿完成后必须读取。诊断、续写、重写、精修、炼字、试唱反馈、对标相似性检查和最终交付也读取。它只负责审稿顺序和验收，不复制各专业 reference 的详细方法。

## 一、不要护稿

把初稿当成别人写的。先问它值不值得救，再问怎样修。局部句子漂亮不能保护错误命题、错误人物和错误结构。

改稿从大到小：

```text
命题与人物
→ 整歌运动
→ 段落职务
→ 材料与意象
→ 核心句与重复
→ 句法、词组和韵脚
→ 单字、声音与标点
```

上层不成立，禁止先炼字。

## 一点五、初稿不是交付稿

歌词初稿、局部试写和逐句修改完成后，执行一次“作者退场”审稿。先不看创作说明，把文字当成陌生作者交来的稿子；再分别从听众、歌手和编辑的位置检查。审稿不是给成品打一个总分，而是找到最早造成失败的节点，并实际返工。

```text
总线与人物是否仍是同一首歌
→ 每段是否完成自己的职务并推动下一段
→ 副歌是否真的完成关系动作，而非总结剧情
→ 每个关键字是否有事实、人物口吻和声音职务
→ 句子是否能在第一次听见时被理解和复唱
→ 哪一处最像库存歌词、作者解释或模型安全答案
→ 回到最早责任层修改，再重新朗读、拍读或试唱
```

以下情况不得交付：只发现问题却不改；只换近义词却保留同一错误关系；用押韵、诗性、旋律或“听众会联想”替不自然搭配辩护；把内部分析句直接放进歌词；把自审结论当成陌生听众、歌手或成曲证据。作者退场审稿必须覆盖命题、事实、人物、结构、段落、语言、声音、传播、相似性和格式，不得因为用户只指出了其中一层，就默认其他层没有问题。上游发生改动后重新扫描全部维度；内部自审通过后，仍须标记哪些内容只经过文字侧验证，哪些已经经过真实声音或外部反馈验证。

## 二、第一轮：作品成立性

检查：

- 谁在唱、唱给谁、为什么现在唱，是否从头到尾一致。
- 歌词是否兑现已确认命题，有没有写成另一个更高频的故事。
- 人物从开头到结尾知道、承认或决定了什么。
- 每个关键事实是否有来源，是否擅自补了动机、责任和经历。
- 作品相对于同题歌新增了什么认识；若没有，是否至少有不可替换的材料和声音。

只剩题材和情绪，没有人物运动，退回选题，不做句子美容。

## 三、第二轮：结构与信息

给每段写一句职务说明，再逐行标出新增事实。删除：

- 重复上一段意思的近义句。
- 只负责营造“像歌词”氛围的物件和景物。
- 提前泄露副歌结论的主歌说明。
- 没有改变最后副歌的桥段。
- 只增加剧情证据、没有形成句长、词组、韵脚、停顿、气口或演唱姿态差异的桥段；内容转折与声音转折必须同时成立。
- 没有声音收益的后副歌和尾句反复。

再给每一行标一项主要接收职务：画面、感官与身体、情绪、关系动作、必要事实、转折、回钩或留白。可以兼任，不得包办。整段若只能标成必要事实、剧情说明和条件分流，说明它是文艺化叙事文，不因分行、押韵或配上旋律自动成为歌词。

把每行脱离上下句单独检查：它是否至少看得见、听得见、感觉得到、像人物说得出口、改变关系或留下声音记忆。单行必须依靠作者补齐剧情才成立时，先恢复准确关系，再用并置、递进、对照、跳切、复沓或回环重组；不能继续删字制造诗意碎片。

把各段顺序打乱仍不影响理解，说明结构没有因果。

## 四、第三轮：核心句与传播记忆

先做零号复查：歌者、当面听众、话中对象和真正倾听者是否稳定；每个代词能否指回具体对象；主语、动词、宾语和修饰关系是否组成正常中文。`见过他的名`一类动宾搭配错误直接退回，不得进入诗性、传播和多义评分。第一人称向现场众人打听第三人称对象可以成立；若后文改成`你`，必须指出对象、时间、载体或演唱者发生了什么变化。

零号复查通过后，对副歌核心句做九项复查：人物能说、关系能见、矛盾有压、文字准确、声音能记、重复会变义、既能借用又属于本作、情绪越过关系门槛、记忆机制明确。详细门槛见[副歌核心句与传播记忆](./副歌核心句与传播记忆.md)。

把核心词另做一次语义职务复查：它是可感意象、行动与关系动词、感官与身体词、时间空间锚点、状态判断词、冲突结构词，还是只负责命名信息类别的功能词。若候选只是`消息、音讯、实话、准信、答案、真相、结果`的近义分级，先全部降回支撑词；不得因为能概括创作任务就进入传播评分。功能词只有在本作中拥有专属载体、行动后果、关系代价、回归变义和声音落点时，才可重新竞争核心位置。

需要宣泄的副歌另做一次“主歌—副歌语言差”验收：

- 能否用一个情绪主色和一个反作用力准确描述人物，而不是罗列多种情绪名词。
- 副歌是否从描述事情转为人物向明确对象完成承认、请求、质问、判断或决定。
- 是否减少了地点、履历和事件说明，增加了称呼、关系动词、否定、条件、让步、选择和代价。
- 是否形成`点名或条件 → 矛盾相撞 → 承担代价 → 核心落点`的文字压力链；顺序可变，四项职务不能全无。
- 逐行是否分配了画面、感受、情绪、关系动作、必要事实、转折、回钩或留白；画面、感受与情绪是否分别有证据，整段是否避免全部写成条件判断和信息处理。
- 句架回归、词组收紧或拉长、重音、韵脚、停顿和短 hook 是否形成声音压力链。
- 去掉`痛、伤、爱、恨、绝望、命运`等情绪名词后，人物的情绪是否仍能从对象、动作和代价中听见。
- 去掉旋律朗读时是否仍有关系压力；放回旋律时是否比主歌更容易被记住和跟唱。

副歌不必总是高声爆发，但必须与主歌形成可听见的情绪转位。低声承认死讯、平静作出决绝选择，也可以比连续高音更重；只提高音量、换开口音或堆强烈词，不算通过。

九项通过以后仍要做传播压力测试：目标听众能否在十秒后复述核心词或句法骨架；换到同题歌曲是否仍完全成立；短 hook、完整核心句和支撑句是否分工；多义是否都能从正文找到来源；真实 demo 中重音、长音和气口是否让记忆词被听见。未做真实听众和成曲测试时，只能说“具备传播条件”，不能宣称已经验证传播。

传播不是单句自己完成的。检查主歌是否提供至少两组事实把它逼出来，桥段是否改写它，最后一次是否值得再唱。需要脱离歌曲解释才能显得深刻的句子，淘汰。

## 五、第四轮：语言与修辞

逐句还原成普通话，检查主语、动词、对象和结果。标出抽象名词拟人、比喻混搭、作者总结、库存意象、形容词堆积、为了押韵倒装和人物不会说的词。

对每项修辞做反向解压。解压后没有具体事实和关系，只剩气氛，删除修辞。详细方法按问题读取[炼字炼词与人物语言](./炼字炼词与人物语言.md)、[意象场景与文化转译](./意象场景与文化转译.md)或[修辞与歌词技巧](./修辞与歌词技巧.md)。

### 简洁与长短句检查

逐行做白话还原和删除测试：

- 删除每个连接词、副词和语气词后，主语、对象、时间、条件、否定、转折、关系压力和人物口吻是否改变。
- 每个保留字是否至少承担事实、关系、情绪差别、声音、韵脚或段落职务；没有职务的字删掉。
- 长句是否只承载一个主要重心，并有清楚词组和气口；短句是否真正落地，而不是删成没有对象的碎片。
- 每行的句长变化是否对应信息输入、压力推进、判断落点、请求、反转或 hook 回归，而不是机械交错。
- 重要句尾和副歌核心落点是否由实词承载；虚词是否只在弱拍、衬腔、过渡或特定曲风中承担明确声音职务。
- 压缩后能否还原成正常白话。若只能靠作者解释补回关系，恢复被删的事实，不用宽词填洞。

## 六、第五轮：声音验收

按以下顺序出声：

1. 自然朗读：检查口语、歧义和人物语气。
2. 拍读：检查词组、重音、密度和韵脚。
3. 哼唱或沿旋律试唱：检查时值、长音、高音、声调和气口。
4. 闭眼听写：不看文字，确认第一耳能否接住。
5. 目标歌手或近似声线试唱：检查真实音域、咬字和呼吸。

没有旋律时做到前三项中的文字侧试验，并明确真实演唱仍待谱曲回查。已有旋律时不能用朗读代替试唱。

副歌驱动作品另查一份声音骨架：每行词组、主要重音、韵脚地图、核心元音、核心句停顿、计划气口、短 hook 回归和支撑句回送。副歌通常应比主歌拥有更稳定、更容易复现的声音组织，但不要求押韵最密、音量最大或句句高音。只有正确意思、没有声音轮廓，仍按功能说明退回。

听不清时按[声音韵律与可唱性](./声音韵律与可唱性.md)区分文字、旋律与节奏、演唱、制作与环境四类原因，再改责任层。至少比较一次不看字幕的干声或低配伴奏听写和一次目标制作环境听写；不能拿创作成员熟悉原句后的理解冒充第一耳可懂。

公共技法不因重合自动删除。具体词句、独特细节组合、逐行语义、韵脚地图和可识别旋律共同重合时，必须重建。只换同义词不算改。

## 八、第七轮：记忆与陌生听众验收

让未参与创作的目标听众只听一遍，不看歌词，随后回答：

1. 谁在唱给谁，发生了什么。
2. 最记得哪一句、哪个词或哪个声音动作。
3. 主歌给了哪项事实，副歌要求或承认了什么。
4. 哪一句听不清、断错、误解或觉得像别的歌。

听众记不住管理员预设的核心句，不代表立刻重写；先判断他实际记住的是否更适合成为主 hook。若每个人记住不同的口号，说明记忆入口分散；若只记住旋律而完全不知道人物和关系，歌词没有完成最低信息任务；若准确复述主题却想不起任何词句，作品有说明，没有语言身份。

测试至少区分三类反馈：第一次听见的理解、第二次听见的增量、目标场景中的使用意愿。不能用熟悉作品的创作成员代替陌生听众，也不能把“好听、感人、不错”当作有效数据。

## 九、修改方法

### 增

只增加会改变理解的事实、动作、对照、后果、气口或声音锚点。不能用增加意象和解释填满空段。

### 删

优先删套话、重复解释、无作用形容词、押韵补丁、作者评语、无职务段落和只在纸面漂亮的句子。

删字不能以“越短越高级”为标准。先保留主语、对象、时间、条件、否定和必要语气，再删除无职务的连接词、副词、助词和重复说明；删后必须重新朗读、拍读，确认没有损失自然句法、人物关系、重音和气口。

### 改

先改关系和动作，再改句法和声音，最后改字。近义词替换不能解决主语错、对象错和比喻框架错。

### 调

调整段落顺序、信息揭示、核心句回归、韵脚地图、句长、重音和气口。顺序改变必须让听众获得更清楚或更有力的接收过程。

### 推翻

若核心命题、人物声音或段落运动根本不成立，保留可用材料，重新构思。不要因已经写了很多而继续修一首不值得救的词。

## 十、冷处理与外部反馈

重要作品初稿后至少进行一次上下文切换或时间间隔，再冷读。时间不足时，也要先处理其他任务、改变显示形式或让文字只以音频进入，打断作者对原句的熟悉。

外部反馈按资格分工：目标听众判断是否听懂和是否愿意再听；歌手判断咬字、气口和可信度；作曲与制作判断词曲空间；作词同行判断人物、结构、语言和相似性。不能把所有人的“喜欢/不喜欢”平均投票。

反馈必须落到可观察位置：哪一句没听懂、哪里需要偷气、哪段觉得重复、哪个词不像人物。抽象评价不直接改稿。

定稿前保留一份内部验收：

## 十二、正式歌词格式验收

最终歌词另做一次不讨论文学质量的机械检查，具体标准见[歌词稿格式与乐段标签](歌词稿格式与乐段标签.md)：

- 乐段使用已确认的英文方括号标签，如 `[verse]`、`[chorus]`、`[bridge]`。
- 不使用 `**主歌 1**`、`尾声 / 最后副歌`等 Markdown 中文段名。
- 可唱正文默认不使用逗号、句号、冒号、分号、引号和括号；停顿靠分行、空行、词组和旋律完成。
- 每行只放一个可唱意群；去掉标点后句法、人物和对象仍然清楚。
- 制作说明、视角说明、故事解释、韵脚备注和试唱风险放在歌词正文之外。
- 书信、对白和戏中戏不能靠引号临时切换人物；无标签听辨仍能认出谁在说。

这一步不把“无标点”冒充普遍文学真理。印刷投稿、曲谱出版或委约方明确要求标点时，另生成编辑稿；用于 AI 音乐平台和本项目默认交付的纯歌词稿按以上格式执行。

## 十三、依据与边界

本文件吸收《歌词写作十八讲》第九讲的构思—初稿—修改流程和第十四讲的主题、结构、语言、风格、诵唱、冷处理、比较优选与推翻重写方法。教材强调“改到不能再改”，本项目将其校准为“再改只会损害已确认目标时停止”，避免无限润色。

## 十四、失效判定

- 初稿完成后只查错别字和押韵。
- 命题错误仍保护已经写出的漂亮句。
- 每条反馈都照单全收，没有按目标和资格裁决。
- 没有出声测试便宣称可唱。
- 没有旋律和歌手便宣称气口、音域已验证。
- 只检查单句原创，忽略意象组合、语义顺序、韵脚地图和旋律共同重合。
- 修改只换近义词，人物、动作、结构和声音问题原封不动。
- 没有陌生听众的一遍听辨，便断言核心句、hook 和人物关系已经被记住。
- 目标听众只记住多个互相竞争的口号，仍把 hook 数量当作传播能力。
- 曲式未确认便套标准模板；正式稿仍用中文 Markdown 段名、大量标点和引号区分人物。
