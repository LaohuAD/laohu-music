# 副歌核心句与传播记忆

## 什么时候读取

用户已经有题材、人物关系或对标作品，但需要确定副歌重心、传播句、中心判断或核心情绪时读取本文件。选题阶段可以试写副歌核心句，但必须标为候选，不把候选直接当成正式歌词或歌名。

本文件只负责核心句的关系动作、文字门槛、记忆机制和回归设计。候选进入正式歌词前，必须继续完成三项联动验证：

- 读取[段落结构与情绪推进](段落结构与情绪推进.md)，证明主歌事实能够把这句话推到副歌，并且后续段落能使它增义。
- 读取[声音韵律与可唱性](声音韵律与可唱性.md)，核对重音、句长、元音、韵脚、停顿和气口；纸面成立不能代替唱出来成立。
- 读取[改稿与交付验收](改稿与交付验收.md)，把核心句放回整首歌审查，淘汰只适合截图、不足以统领作品的句子。

不得让本文件成为独立制造“金句”的捷径。段落推不出来、声音接不住、整歌养不起的核心句，一律退回人物事实和创作命题。

## 核心判断

副歌核心句不是管理员对作品的解释，也不是把路线压缩成一句漂亮话。它是主人公在情绪压力最高、关系最需要回答的地方，真正会对某个对象说出的那句话。它要能被唱、被重复、被听众记住，并且每次回到副歌都因前文变化而获得新意思。

先区分四种文字：

```text
创作命题：管理员用普通话说明这首歌写谁、写什么关系
路线标签：帮助用户比较方向，只负责导航
副歌核心句：人物在副歌中完成一次主要语言动作
传播句：听众愿意记住、转述或借来表达自己的句子
```

四者可以最后重合，不能一开始就混为一谈。“共同生活还没撤场”是对作品的分析标签，不是人物自然会说的核心句；“你把我变成现在这样，却不负责带我走完”有冲突意图，但“负责带我走完”没有明确对象和动作，仍然更像作者解释。

## 零、核心句不是整个副歌的同义改写

副歌通常需要三种不同职务，它们可以由同一句兼任，也可以分开：

1. **核心句**：用一至两行完成副歌最重要的关系动作，提供完整表层意思。
2. **短 hook**：从标题词、称呼、动作、问句或核心句中提取的短声音单位，负责迅速回钩、跟唱和记忆。
3. **副歌支撑句**：负责把压力推到核心句、补充代价、改变对象、回答上一句或把核心句送回短 hook。

副歌其他句子不能只把核心句换几个近义词重说。它们至少分别完成一种功能：

```text
给出触发事实
→ 增加人物付出的代价
→ 把对象从“你”扩大到旁听者或收回自己
→ 回答、反驳或改写核心句
→ 用更短的 hook 让听众能够跟唱
```

若整段每句都在说“我想知道你的下落”，只是换成“谁见过你、谁听过你、谁知道你”，副歌没有展开，只是在排队解释核心句。若短 hook 与核心句各说一个中心，听众记忆也会分裂；必须确定一个主记忆入口。

### 核心句在副歌中的位置不是固定模板

核心句的位置由它完成的语言动作决定，不得因为“副歌要爆发”就机械放在开头，也不得因为“最后一句更像金句”就机械延后。先在下面三种形态中做选择：

| 形态 | 核心句位置 | 适用条件 | 主要风险 |
| --- | --- | --- | --- |
| 直击型 | 第一行或前两行 | 核心句是直接呼告、质问、承认、宣告或请求；预副歌已经把压力推到可以当场开口的程度 | 前置事实太多会把爆发拖成说明 |
| 递进型 | 中段 | 前一两行先给出同一关系链上的事实或代价，核心句随后把它命名、加压或改口 | 支撑句变成另一条故事线，核心句被稀释 |
| 反转型 | 后两行或最后落点 | 前文每一句都在准备同一个预期，核心句用一个可理解的改口、选择或判断把预期翻过来 | 前置材料没有共同指向时，听众只会听见拼接和跳题 |

“核心句在后”只有在前置句删掉以后，反转的必要性会消失时才成立；“核心句在前”只有在后续句仍能增加代价、对象或回钩时才成立。完整副歌必须先写出：第一句让听众进入哪一段关系，核心句改变什么，最后一句把什么压力留下。若前置句和核心句分别属于“寻人”“婚约”“负心”等不同中心，不能用同一首歌的背景替它们自动连线，判为双中心。

没有旋律时，这里决定的是歌词信息位置，不是假装完成音乐位置。预副歌已经把问题收窄，副歌音乐一进入便建立稳定主循环、最高音区或明显重拍时，直击型核心句优先前置；副歌旋律自身仍有可听见的上行、延迟落拍或问答空间时，递进型和反转型可以后置。最终必须由[声音韵律与可唱性](声音韵律与可唱性.md)和谱曲方案共同验证，不能只凭纸面顺序宣布高潮已经成立。

反转型核心单位若由“人物原先的判断”与“人物现在的愿望”构成，前置句必须持续建立原判断、现实代价或迫使人物改口的新事实。只并列一个关系物件和一项寻人请求，不能自动逼出后面的价值反转；若中间还改变了当面听众，必须额外给出可听见的转向，否则同时判为压力链断裂和受话对象跳变。

### 副歌逐行职务：画面、感受、情绪不是同一件事

完整副歌不能只检查核心句，还要给每一行确定一项主要职务：

| 单行职务 | 这一行负责什么 | 典型失败 |
| --- | --- | --- |
| 画面句 | 给出人物位置、空间、物件状态或镜头动作 | 只有景物，没有人物为何看见它 |
| 感官与身体句 | 让听众听到、触到或感到呼吸、声音、姿态和身体反应 | 直接把身体词当作情绪标签 |
| 情绪句 | 让人物的盼、怕、怨、羞、悲、喜或不甘露出明确对象和原因 | 只报`痛、绝望、遗憾` |
| 关系动作句 | 完成请求、质问、承认、拒绝、决定、改口或告别 | 礼貌说明人物想做什么，却没有真的开口 |
| 必要事实句 | 只补一项没有它就听不懂的事实或证据 | 连续交代地点、经历、传闻和剧情先后 |
| 转折句 | 用新证据、回答或改口改变前一句及听众理解 | 用`但、原来、不是而是`制造表面翻转 |
| 回钩句 | 用稳定词组、句架、韵脚、称呼或声音动作形成复唱 | 只重复主题近义词，没有声音轮廓 |
| 留白句 | 停止解释，让前句的事实、声音或关系继续作用 | 因作者没想清楚而写成语义残句 |

画面、感受、情绪必须分开判断。画面回答外部世界有什么可以看见；感受回答人物的感官和身体正在发生什么；情绪回答人物怎样评价这件事、想靠近还是逃开。三者可以在同一句相遇，但不能因一句有景物就同时给它算上画面、感受和情绪三项分数。

每行可以兼任一项辅助职务，但不得包办整段世界观。副歌也不要求八类句子全部出现；它至少要让必要事实、人物内部反应、关系动作和声音回钩形成分工。整段全是事实句、条件分流句或剧情说明句，立即退回，不等旋律替它制造抒情。

### 禁止先锁功能词，再围词造副歌

`消息、音讯、实话、准信、答案、真相、结果`主要命名人物想获得的信息或结论。它们可以是必要宾语、支撑句落点和剧情阶段标记，却不能仅因概括了创作任务就被先验锁成副歌中心。`归期`若只是“何时回来”的信息类别，同样偏功能；若前文已经把它建立成双方约定的具体期限，它属于时间与关系锚点，不能机械归入本类。

错误顺序是：

```text
先决定本段写“求消息”
→ 从消息的近义词里选音讯、实话、准信
→ 给三个词分别安排情绪层级
→ 围绕词语补条件句和剧情说明
```

正确顺序是：

```text
先决定人物此刻最怕哪一种答案
→ 决定她向谁做出什么关系动作
→ 分配画面、感受、情绪、事实、转折与回钩的逐行职务
→ 再从人物材料中选择能完成各项职务的词
→ 最后检查哪个词或句架值得重复
```

功能词要升为核心，必须经过额外证明：它在本作中有专属载体或证据；人物得到或失去它会改变一项行动；它与某个具体对象形成自然搭配；每次回归由新事实改写；声音上有稳定而可复唱的落点。只把`音讯`升级成`实话`再升级成`准信`，改变的是信息确定度，不是人物情绪、关系或画面，判为同义分级。

## 一、核心句必须完成一项主要动作

中心句可以有多种力量来源，不要求每句都制造预期反转。先选择它主要完成哪一项：

1. **承认**：说出人物一直回避的事实，代价是承认自己仍然需要对方、仍然没有走出来或已经无法挽回。
2. **质问**：逼对象面对一个无法轻易解释的矛盾。问题必须有具体对象和追问目标，不用连续问号制造声势。
3. **请求**：要求对方留下、回答、归还、承认或完成一个具体动作。请求越具体，关系压力越真实。
4. **命名**：给很多人经历过却没有准确说出的关系找到新说法。命名必须由人物材料推出，不能脱离作品变成社交媒体格言。
5. **决定**：人物在副歌中作出会付出代价的选择。不能只说“我要勇敢、我要放下、我要重新开始”。
6. **反转**：把听众以为的情绪方向推向另一面，例如把索取改成归还，把挽留改成承认，把受伤改成责任。反转必须由主歌事实准备，不能为了显得聪明硬拐。

一条核心句只设置一个主动作。既要控诉、又要教育听众、又要安慰所有人、又要总结主题，判为过载。副歌可以有前后两句分别承担不同动作，但核心句必须有一个清楚重心。

## 二、先过零号门：对象和搭配正确

核心句进入传播、文学和多义评分以前，先回答：

```text
谁在唱
→ 当面唱给谁
→ 正在谈论谁
→ 真正希望谁听见
→ 这句话要求哪个对象做什么
```

第一人称向现场众人打听第三人称对象可以成立，例如青衣向戏客、路人和兵卒询问武生消息；这不要求全段统一改成`你`。但`他`转成`你`必须对应演唱对象或时间位置改变，不能只为亲密、押韵和情绪升级。

然后还原主语、动词、宾语和修饰关系。动宾搭配、代词指向、事实状态或自然口语有硬伤，候选直接淘汰，不得继续用押韵、旋律、诗性、双关和“听众应该能联想”加分。`见过他的名`不能因画面新奇通过：见过的是人，听过的是名字；除非前文明确名字写在戏单、名册、碑或其他可见载体上。

省略也必须可恢复。`若有人见过 听过`需要分别补出两个不同对象，若前后文和旋律没有先把对象建立清楚，仍是未完成句。先把普通话说对，再决定歌词怎样省。

## 三、殿堂级核心句的九项门槛

### 1. 人物能说

先把句子放回人物身份、年龄、关系位置和当下场景。问：他是对谁说；为什么现在说；他平时会用什么词；这句话需要作者解释还是听众一听就能明白。只有作者能解释的句子，不能进入核心候选。

### 2. 关系能看见

句子必须让人听出谁对谁做了什么，或谁欠谁一个什么动作。`我很痛、我忘不了、我终于成长`没有对象和关系动作，不能承担副歌核心。抽象判断必须由前文的具体事实托住。

### 3. 矛盾有压力

核心句要让人物同时面对两件不能轻松兼得的事：还爱却不能留下，想要答案却不敢听见，感谢对方改变自己却无法接受对方离开。冲突不是堆“痛、伤、遗憾、绝望”，而是让人物在一句话里承担一个具体的两难。

### 4. 文字有落点

主语、动词、宾语和修饰语必须自然搭配。允许歌词比日常语言更凝练，但不能让生活、记忆、时间、系统、身体和关系在一句里同时做人的动作。一个句子优先使用一套比喻框架；陌生搭配必须由人物材料和段落反复证明。

核心句追求的是准，不是绕。句子必须让听众第一遍听懂谁在对谁说什么；深意来自前文事实和重复回归，不来自让听众先猜作者想表达什么。凡是候选句需要管理员解释“这里其实是说对方早有二心、想离开、把我当退路、已经不爱、歌者当时太天真”，先拆回这些具体可能，再根据材料只保留最能被证明的一项。

每个候选都做一次准词检查：

```text
这句话里最重的动词是什么
它的对象是谁
它能不能被更短、更普通、更狠准的词替代
替代后人物关系是否更清楚
删掉修饰后还剩不剩当前作品独有的事实
```

准词检查先保护材料中不可替换的具体名词。合同、车票、诊断书、看房、某句原话等事实若正是关系矛盾的证据，第一轮候选不得为了押韵或诗意把它换成“远方、以后、命运、答案”一类宽词。先用具体对象把人物关系说准，再结合旋律、音节和重音判断是否可以省略；省略后若只剩公共情绪，恢复具体名词。

动作对象不能为了缩短而消失。`签了外地的合同`可以继续炼成`签下外地的合同`，不能炼成`签好了离开`；`答应一起看房`可以压成`叫我等你看房`，不能压成`把我留在未来`。前者仍然是人会做的事，后者只剩作者的解释。事实型副歌宁可多留一个准确名词，也不要用一个漂亮但搭配错误的抽象词换掉它。

同样检查名词前的修饰语。`外地工作合同`中的“外地、工作”来自材料，`离开的合同`中的“离开”来自作者解释；后者即使更短也不准确。副歌可以把两件事实并置，让听众自己感到矛盾，不必先用修饰语替听众宣布结论。

“你在提前离开我”可以表达时间差，但动词仍旧偏虚；若材料是对方已经不准备陪伴，应优先找“你早就不打算陪我”；若材料是对方把人留作退路，应找“你舍不得的不是我，是没人等你”；若材料是歌者当时信错了，应找“我竟然把你的犹豫当成以后”。这些候选不代表定稿，只规定写法：先让动作落地，再谈诗意。

### 5. 声音能记住

核心词应落在旋律重音、句尾或重复位置上。检查句长、停顿、开口音、尾音、押韵和气口；不要只看纸面是否漂亮。好句必须能被人顺口哼出，而不是只能在屏幕上截图。

### 6. 重复会增义

第一次出现让听众知道人物在说什么；第二次出现因为主歌新事实而改变压力；最后一次出现让人物获得新的认识、选择或失败。每次只是重复同一个情绪标签，核心句没有展开能力。

### 7. 既能借用，又属于本作

听众可以把句子借来表达自己，但换到任意失恋、成长或离别歌曲上都成立，说明它仍是公共口号。核心句要保留一个只能由当前人物、当前关系或当前材料解释的词语、动作、判断或语序。

### 8. 情绪必须越过一道门

副歌的爆发不是音量大、词更惨或连续高音，而是人物终于做了主歌里做不到的事：承认不敢承认的愿望，向没有权力追问的人追问，提出可能被拒绝的请求，给关系下一个无法撤回的判断，或作出要付代价的决定。

克制副歌也必须越门。人物可以轻声唱，但他不能只汇报现状。`我想知道你在哪里`说明任务；`没有你的消息，我连该等谁都不知道`才开始触及关系代价。后一句只是机制示范，不是当前作品候选。

#### 需要宣泄的副歌怎样选字、选词、造句

不存在脱离人物、旋律和曲风的“副歌专用词库”。同一个`等、走、回来、忘`可以平淡，也可以刺人；差别在于它是否落在明确对象、不能回避的关系和可听见的声音位置上。需要宣泄的副歌必须相对主歌发生四项变化：叙事减少，人物开口增加；从描述别人做了什么，转为我现在承认、要求、质问或决定什么；从多项场景收窄为一个主矛盾；从散开的语流收紧为能够重复和落拍的句法。

先确定一项**情绪主色**和一项**反作用力**。主色决定人物主要怎样开口，反作用力防止情绪写成单色口号：

| 主色 | 反作用力 | 副歌真正要完成的动作 | 适合优先检查的语言 |
| --- | --- | --- | --- |
| 想念 | 怕再也见不到 | 请求一个回应或到达 | 称呼、回来、等、见、到达动作、双方约定，以及明确时间条件 |
| 哀求 | 仍保留尊严 | 提出最低但不能再退的要求 | 求、请、告诉、给我、至少、照实等，但请求对象和底线必须明确 |
| 愤怒 | 仍然在乎 | 逼对方承认矛盾或责任 | 你、凭什么、为何、不肯、竟然、还、认、欠、负等关系词与否定词 |
| 悲恸 | 仍不敢确认 | 说出最怕听见的事实 | 若、倘若、原来、没有、再也、最后、生死与具体后果 |
| 决绝 | 仍需付出代价 | 作出无法撤回的选择 | 不再、宁可、就算、从今、到此、我认、我走、我还等决定与让步句 |
| 狂喜 | 曾长期匮乏 | 确认终于得到或共同拥有 | 终于、真的、现在、一起、就是，以及可以共同呼喊的称呼和动作 |

表中的词只是检查方向，不是自动填词。`终于、还、只、至少`若没有改变时间、限制或底线，就是副词填充；`痛、伤、爱、恨、绝望、命运`若没有对象、原因和后果，只是在替人物报情绪名称。

需要爆发的副歌优先使用四类有关系压力的词：

1. **称呼与指向词**：`我、你、他、谁`以及人物专属称呼，使情绪有对象。代词必须稳定，不能为了亲密突然把第三人称改成第二人称。
2. **可执行的动词**：`来、走、等、说、认、还、留、问、忘、负、骗`等能够让人物或对象做出动作的词。动词越强，越要说明对象和后果；不能让一个动词包办整段剧情。
3. **冲突与边界词**：否定、条件、让步、选择和时间词，例如`不、别、敢不敢、肯不肯、若、就算、宁可、到底、再也`。它们负责制造压力，不负责凭空制造深度。
4. **代价与作品锚点**：一个来自本作的身份、原话、物件、约定或可见后果，例如婚约、红妆、空位、戏名或无人认领的旧物。副歌不宜继续罗列主歌全部材料，只保留一至两个能代表关系代价的词。信息功能词若没有专属载体和行动后果，不得冒充作品锚点。

句法优先选择能够被唱成动作的形式：呼告、祈使、质问、条件、让步、否定、宣告、对照和递进。副歌不是句式越激烈越好，而是句式必须改变关系。报告“我一直在做什么”通常仍是叙述；只有人物向明确对象提出具体选择、要求对方承担回答，或说出自己将承担的后果，句式才真正越过关系门槛。不得用与当前作品人物、事件和措辞过近的示范句代替候选生成，否则模型会复制例句骨架而跳过人物重新选择。

条件句只是施压工具，不是抒情本身。整段若主要由`若他……就…… / 若他……也…… / 若有人……请……`组成，人物会像在分派信息处理办法：逻辑清楚，情绪却被条件关系接管。条件并列以后必须出现人物当下的身体、关系代价、不可撤回的请求或声音回钩；否则把它降回剧情提纲。

整段常用的宣泄运动不是每句同时大喊，而是形成一条可唱的压力链：

```text
点名对象或提出条件
→ 把两种不能兼得的结果正面摆出
→ 说出人物愿意承担什么
→ 用核心句、短 hook 或实词韵脚落地
```

可以通过重复起句、平行句法、句子逐步缩短、条件升级、否定加深、问答回环和尾韵收紧制造语言加速度。每次重复必须增加对象、代价、答案或决心；只把同一句换成更惨的形容词，不算递进。

副歌的语言密度应当高于主歌的关系密度，低于主歌的剧情密度。听众不应在副歌继续接收人物履历、路线、地点和事件说明；他应当听见人物终于向谁说了什么、把哪项后果摆到了台面、这一句为什么现在非说不可。

爆发也有音量之外的形式。哀求可以因人物已经退到底线而爆发，克制可以因一句不可撤回的判断而爆发，低声也可以因终于说出死讯而爆发。判断标准不是用了多少强烈情绪词，而是人物是否越过了主歌里一直不敢越过的关系门槛，且文字和旋律是否让这一步被听见。

### 9. 必须有明确记忆机制

核心句至少拥有两项能够被听见的记忆条件，其中一项必须来自声音：

- 短而稳定的标题词、称呼或动作词回归。
- 清楚的对照、递进、问答、回环或句法骨架。
- 句尾韵脚、元音、词组节奏、停顿或重音形成可复唱轮廓。
- 一个只有本作才成立的物件、原话、动作或关系判断。
- 第一次听懂、第二次变重、最后一次被桥段改写的上下文反差。
- 听众能借来表达自己，同时仍能认出它来自哪首歌。

一句话只有正确意思，没有任何声音回钩、关系反差和作品专属词，不得因为它位于副歌便称为核心句。

## 四、合法多义来自上下文，不来自强塞

一语双关、一语多关可以成为核心句的力量来源，但不是硬指标。合法多义必须先有一个清楚、自然、人物真的会说的字面意思，其余层次只能来自以下来源：

1. 词语本来就有的公共含义、文化用法或同音关系。
2. 前文已经建立的私人事实、物件和约定。
3. 不同副歌回归前出现的新证据，使同一句话被重新理解。
4. 演唱对象、说话者、时间位置或语气发生有准备的变化。
5. 旋律、停顿和重音改变听众对同一字面意思的关系判断，但没有把字唱成另一句。

多义验收必须逐层回答：字面是什么；第二层由哪项前文事实产生；第三层由桥段或最后行动中的什么变化产生。任何一层只能靠作者在歌外解释，立即删除该层，不把它算成深度。

最稳的三层不是一句话同时含三个谜底，而是同一句在三个位置获得三种关系压力：第一次是愿望，第二次是怀疑，最后一次是人物不得不承认的代价。这样既保留第一耳清楚，也避免用`命、归、戏、等`一个宽字强扛整部剧情。

## 五、预期反转不是唯一答案

预期反转、冲突和破防可以提高记忆，但它们不是质量本身。内部至少比较四种记忆来源：

| 力量来源 | 听众先以为 | 句子最后让他看见 | 适用条件 |
| --- | --- | --- | --- |
| 预期反转 | 人物要挽留 | 人物其实在承认关系已死 | 前文已经积累足够事实 |
| 关系命名 | 只是普通失恋 | 原来双方还存在一个未完成动作 | 有不可替换的关系细节 |
| 直接压力 | 人物只是在抒情 | 人物正在向对象索取回答或承担 | 演唱对象明确 |
| 具体意象 | 只是一个日常物件 | 物件证明了一个无法回避的关系事实 | 意象有私人来源和变化 |

不要为了制造“哇”的反应，强行写成翻案句、鸡汤句或抽象格言。听众被击中，常常因为作者终于把一件熟悉却说不清的事说准了，而不是因为句子故意绕了一圈。

## 六、核心句生成程序

### 第零步：触发以后必须真正创作

用户要求、否决或追问副歌核心句，或上游 Skill 调用本文件验证 hook 时，本轮必须产生可评审的歌词文字。`副歌核心是寻人、围绕空位写、用停顿守婚约、下一步再压成句子`都只是输入说明，不是核心句创作。

阶段未进入完整写词，不影响内部完成候选生成、淘汰、声音假设和三次回归模拟，但它决定本轮可以交付多大的歌词单位。用户当前只要求研究或确定副歌核心句时，对外只交付一至两行组成的完整核心单位，以及能够从中自然提取的短 hook；用普通话说明前后支撑句应完成什么，不写成四至八行副歌，不加`[Chorus]`标签，不顺手补主歌、桥段和结尾。只有用户明确确认核心句，或明确要求进入副歌乐段创作，才进入本程序第四步。阶段边界不是拖延创作的借口：核心句仍必须真正写出来，只是不能拿完整乐段替代本轮唯一要裁决的变量。

只有缺少人物、倾听对象、当前处境或主要语言动作中的关键一项，导致任何句子都会改写作品身份时，才可以暂停候选生成。暂停前必须指出缺哪一项、两种答案会分别写成什么关系，并给不冒充定稿的最小文字试验；不能空手退回方向讨论。

### 第一步：先写人物的粗话

用人物会说的普通话写出三句话：

```text
我现在最想对谁说什么
我真正想让对方承认什么
如果对方不回答，我最怕什么
```

不要一开始押韵，不要一开始追求高级。粗话负责暴露真实关系，修辞负责压缩已经成立的关系。

粗话不能只写一层。遇到“后来才听懂一句话”“当时不懂对方意思”“一句话可能藏着离开、犹豫、不爱或退路”这类材料时，先写成一组细分粗话：

```text
你那句话当时像什么
后来我才发现它可能是什么
我当时为什么信了
我现在最想让你承认哪一件事
如果你不承认，我最怕自己承认什么
```

然后把五句压成一句。压缩不是把五句意思全塞进去，而是选一个最能改变副歌的问题。若五句里同时有“有二心、想离开、没爱了、把我当退路、我太天真”，必须由主歌材料决定主项；材料没决定前，不写核心句，只把它们作为待验证方向。

分析说明可以把这些可能逐项讲透，核心句不可以。核心句一次只承担一个由材料选中的主要伤口：对方早已想走、对方已经不爱、对方把人物留作退路，或人物当时误信了某句话。其他意思可以由主歌事实、语气和后一次回归慢慢显出，不能全挤进一个宽词。这样做不是把歌词写浅，而是把表面意思说清，把深意交给上下文。

候选写出后做一次“解释撤除”测试：隐藏管理员的分析，只读主歌材料和候选句。听众若不能立即知道谁在对谁做什么，或必须补一句“这里其实是说……”才明白，候选直接淘汰。若表面意思清楚，听过前文后又能发现人物当时误会了什么、付出了什么或现在终于承认什么，才进入声音与重复验证。

候选还要标明判断状态：人物是在猜、问、确认、承认还是决定。`终于明白`、`原来`不能和`也许、可能`共同承担主判断；前者表示证据已经让人物确认，后者表示仍有竞争解释。悬念可以保留，但要由人物明确说“我不知道哪一种是真的”，不能把互相冲突的语气词叠在一句里。

凡使用`不是 A，而是 B`，先检查 A、B 是否回答同一个问题并能互相排除。婚期与生存办法、戏服与人生选择、唱词与命运都不属于同一层。不同层级的内容应由主歌事实和桥段变化形成反差，不把逻辑缺口包装成反转句。

核心词若是`命、路、戏、答案、以后、归处`等高负荷字，必须写明本句只让它负责哪一项主要意思。人物事实没有分别建立生命、命运、职业和选择时，不得把这些联想一次算进一个字的深度评分。

### 第二步：确定语言动作

从承认、质问、请求、命名、决定和反转中选一个主动作。删掉无法服务这个动作的升华、安慰和大道理。

### 第三步：跨机制建立候选池，再让编辑者淘汰

候选不能只在一个句式里换词。内部至少经过两轮，覆盖六种不同的记忆机制；每种机制先写两条，形成至少十二条真正不同的候选，再淘汰：

```text
直接动作：人物承认、请求、质问或决定
关系矛盾：两件不能同时成立的愿望或事实正面相撞
具体证据：把本作独有物件、原话、称呼或动作放进关系
问答回环：一句提出不能回避的问题，另一句回应或反噬
标题与短 hook：标题词能够被反复唱，完整核心句负责赋义
上下文多义：字面不变，三次回归因新证据改变关系压力
```

数量只负责防止第一反应垄断创作，不保证质量。十二条都普通，就全部淘汰，回到人物事实；不能从一堆及格句里选最高分，再称它为殿堂级。

每个候选都记录：人物、对象、动作、冲突、具体材料、声音重心、预计回归位置和最大风险。生成结束后切换成编辑者，把这些句子当作别人写的，优先寻找：哪一句只有解释没有人物；哪一句脱离旋律就只剩社交媒体文案；哪一句第一遍漂亮，第二次已经没有新意思；哪一句会逼主歌去凑材料。

编辑者还必须做“准词淘汰”：删掉需要解释才能懂的句子，删掉把多个心理可能压成一个宽词的句子，删掉为了显得高级而把普通动作写弯的句子。保留的候选应当做到：普通人听第一遍知道表面意思，熟悉前文的人第二遍听出伤口在哪里。

内部保留足够候选用于比较，对外先展示胜出的一个；只有第二句使用不同语言动作、同样能被主歌证明，并且会把整首歌带向真正不同的关系结果时，才作为强备选。没有一句通过门槛时，直接说明当前还没有合格核心句，回到人物粗话或主歌材料；不得把最高分的普通句冒充金句交差。

“没有一句通过”只能发生在至少十二条跨机制候选已经实际生成并完成淘汰以后。对外交付最强失败候选及其硬伤，使用户能够判断应当补材料、换语言动作还是重建声音；不得省略创作过程，只用`方向是对的、表达还不够好`代替失败证据。

### 第四步：核心句确认后，才组成完整副歌

只有用户已经确认核心句，或本轮明确要求创作完整副歌乐段，才把胜出候选放入完整副歌，分配核心句、短 hook 和支撑句。先判断核心句属于直击型、递进型还是反转型，再决定它的进入位置；不能用固定顺序替代判断。检查核心句出现以前是否已有同一压力链，出现以后是否还有新动作，以及整段是否在四至八行内形成可复唱的重心。行数服从曲风与旋律，这里只防止副歌被说明句淹没。

仍处在核心句裁决时，只做位置压力测试：用`前置事实、关系动作、回钩或留白`等职务名说明核心句需要怎样的前后文，不把这些职务扩写成歌词。完整副歌写得再好，也不能代替用户先判断核心句本身是否成立。

副歌支撑句可以变化，核心句和短 hook 的声音骨架应保持稳定。第二次副歌若要变词，优先改变一至两处会被新事实改写的词；整段全部换掉会失去回归，整段一字不动又可能失去剧情增量。

核心句落下以后，后续支撑句只能增加代价、改变关系、形成回钩或有意识地留白。若后一句转去解释消息来源、核验字迹、交代物件和补剧情，情绪会从不可回答的关系问题降成办事步骤；这类证据句优先放在核心句以前提供压力，或放入主歌、桥段承担事实职务，不得紧跟核心句泄压。核心句落下以前的支撑句也不能另起一个独立 hook：如果前两句已经要求“寻找消息”，后两句又突然判断“负心”，必须补出两者之间可听见的婚约、身份或关系转折；补不出来，就保留一个中心并删掉另一条线路。

同时读取[声音韵律与可唱性](声音韵律与可唱性.md)，记录每行词组、主要重音、韵脚地图、核心元音、气口、短 hook 回归和支撑句的回送方式。副歌驱动作品若只有句意方案，没有声音骨架，不得进入完整初稿。

### 第五步：放回主歌验证

核心句不是孤立比赛。至少给每个候选配两组主歌材料：第一组让听众理解人物处境，第二组让核心句的压力增加。若核心句脱离主歌仍然只是漂亮格言，淘汰或回到材料。

### 第六步：做三次回归

```text
第一次：核心句第一次出现，听众听懂人物在要求什么
第二次：新增事实改变句子的责任、痛感或对象
第三次：人物的认识或行动变化，句子获得新的意思
```

如果三次都只能解释成“我很难过”，它不是真正的副歌重心。

描述三次回归时只记录新事实、语言动作和人物变化，不临时改写第二条准歌词。比如写“最后一次人物承认自己当时信错了，并停止等待”，不要写成“留下来的不是人，是一个不属于他的以后”。后一句已经是新的歌词候选，必须重新走人物粗话、准词、声音和整歌验证，不能借回归说明绕过候选淘汰。

### 第七步：做传播压力测试

核心句必须依次通过：

1. **第一耳测试**：不看解释，只听一句，目标听众能说出谁在对谁做什么。
2. **十秒复述测试**：听过副歌十秒后，能否复述核心词、句法骨架或短 hook；只记得故事意思不算记住歌词。
3. **换歌测试**：换到三首同题歌仍完全成立，说明没有作品归属。
4. **去旋律测试**：朗读仍有自然中文、关系压力和节奏骨架；不能全靠旋律制造感人。
5. **入旋律测试**：唱出时重音、元音、韵脚、长音和气口能够突出核心词。
6. **三次回归测试**：每次出现前的新事实是否真的改变同一句的压力。
7. **借用测试**：听众是否愿意用它表达自己的关系，而不是只觉得作者写得漂亮。
8. **标题测试**：核心词若成为歌名，听前是否给出入口，听后是否增义；不适合做歌名不等于失败，但必须说明主记忆入口在哪里。

没有真实听众时先做内部模拟，不得宣称已经验证传播。实际 demo 出现后必须重新测试；文字强不等于成曲一定传播。

### 第八步：把普通功能句降级

`我不问你几时归 / 只问谁见过你`能够说明青衣由盼归转向问下落，但它目前只是一条正确的副歌功能句，不是已经成立的核心句：`不问 A 只问 B`是高频句法，`谁见过你`缺少本作专属动作，两个句尾没有形成明显声音回钩，人物得不到回答会付出什么也没有进入句内。

这种句子可以留作副歌支撑句、候选母意或创作提示，不得因为它概括了人物动作就给它加粗并宣布“方向很对”。要升级为核心句，必须继续寻找：本作哪一个词不可替换，青衣问不到消息会失去什么，哪个短 hook 能反复唱，桥段后同一句为什么会变成另一层关系。

## 七、对标研究怎样服务核心句

长期传唱作品只能证明某种写法经过时间和听众反复使用，不能自动证明当前句子适合本作。研究对标时必须抄录必要短句或准确定位段落，并说明它完成了什么。

可作为研究样本的方向：

- 林夕《富士山下》：研究它怎样用“拥有”与“无法拥有”的关系矛盾，把私人爱情写成一句听众容易复述的质问。重点看动词和对象怎样构成冲突，不要只学地名和宏大意象。
- 李宗盛《山丘》：研究核心句怎样把一个具体动作和迟到的认识放在同一句里，使听众先看见画面，再接受人物的失落。重点看句子如何承担时间跨度，不要只学“山丘”这个物件。
- 方文山《青花瓷》：研究景物、等待和演唱对象怎样在简短句法里同时出现。重点看意象为何属于人物关系，不要只把古典名词堆在标题上。
- 陈奕迅《十年》：研究时间词怎样把关系变化压缩成听众能理解、能转述的阶段判断。重点看时间与人物关系的对应，不要只写“多年以后”。

研究传播广的作品时，不只看句意，要按机制分组：

- **标题与核心句重合**：如《月亮代表我的心》《我愿意》，检查标题词怎样在副歌反复并获得明确对象。
- **平行句法制造关系映照**：如《青花瓷》，检查自然或物的条件怎样与人的等待形成一耳可懂的对应。
- **时间或条件制造关系反差**：如《十年》《可惜没如果》，检查普通词怎样因前后条件改变关系判断。
- **动作与认识同句出现**：如《山丘》，检查可见动作怎样承受时间、失败或迟到的认识。
- **极简短语承担群体借用**：研究一句话为何能被不同听众拿来表达自己，同时仍有原作的词场和声音身份。

每次至少选三首不同机制的作品，记录核心句第一次出现的位置、重复次数、是否与歌名重合、主歌提供的两项证据、旋律怎样突出、最后一次是否改词或变义。播放量、榜单、翻唱和长期传唱只能说明整首录音被广泛使用，不能把传播全部归功于某一句歌词；歌手、旋律、制作、媒介与时代曝光必须分开。

这些样本的具体歌词、段落位置和传播结果必须在实际任务中重新核实。[Beaman 与 Williams 关于耳虫现象的研究](https://doi.org/10.1348/000712609X479636)说明，进入持续听觉记忆的曲调通常具有熟悉性；[McGrath 关于音乐与文学重复的研究](https://doi.org/10.4324/9781315607566-3)可用于理解重复怎样与差异共同工作；[Giora 的显著性研究](https://doi.org/10.1515/cogl.1997.8.3.183)可帮助理解熟悉表达为何更快被接住。它们只能支撑“熟悉、重复和显著性影响记忆与理解”的方法判断，不能直接证明一句歌词高级、感人或必然传播。

《歌词写作十八讲》把歌词定义为供唱与听的抒情文字，要求语言通俗、口语化、上口易唱、节奏鲜明，并把副歌概括为主歌之后的感慨、召唤、主题集中和记忆焦点。本项目保留“主歌偏具体、副歌偏情绪和集中”的分工，但不把副歌限定为主题总结；人物的承认、质问、请求和决定同样可以成为高潮。[Jay Summach 对副歌与预副歌的研究](https://doi.org/10.30535/mto.17.3.2)指出，副歌常由不变歌词、较突出的音乐材料以及额外人声和配器获得焦点，预副歌则可通过歌词短语缩短、密度加快等方式制造期待。[Pat Pattison 的 prosody 说明](https://online.berklee.edu/takenote/prosody-in-music-and-songwriting/)用于校准文字、节奏、韵脚、旋律和中心情绪必须同向。三者共同支持“副歌必须在语言、重复和声音上形成相对主歌的变化”，但都不能推出一套固定中文情绪词、开口音或爆发句式；具体选择仍需人物、普通话搭配、旋律和试唱验证。

## 八、交给用户的核心句说明

选题阶段向用户展示胜出的核心句候选时，必须同时交付：

```text
这句话由谁对谁说
→ 它完成承认、质问、请求、命名、决定或反转中的哪一个动作
→ 前文哪两组事实能把它推到副歌
→ 一至两行完整核心单位与可提取的短 hook 分别是什么
→ 歌者、当面听众、话中对象与真正倾听者分别是谁
→ 核心句使用我、你、他中的哪一组关系；缺席对象是否采用直接呼告
→ 哪个词和哪种声音骨架是听众记忆点，为什么不是普通口号
→ 重复时怎样改变意思
→ 多义的每一层分别由哪项正文事实产生
→ 它和对标作品学习了什么，改变了什么
→ 当前是否仍停在核心句裁决；若是，为什么不交完整副歌
→ 目前仍缺什么材料或声音验证
```

不要只说“这句很有传播力”“这句很扎心”“这句适合做副歌”。这些是结论，不是证明。用户需要看见句子为什么值得写、怎样长成副歌，以及选择它以后整首歌会被迫走向哪里。

同时说明至少一个被淘汰候选为什么不够格。淘汰理由必须落到人物、关系、文字、声音、重复或整歌展开中的具体问题，不能只说“不够高级”。这样用户看见的不是系统碰巧写中一句，而是它确实知道什么句子不该进入作品。

## 九、失效判定

- 句子是管理员对作品的概括，不是人物在关系中会说的话。
- 句子靠“不是 A 而是 B”、抽象反转或连续否定制造聪明感，材料没有推出转折。
- 主语、动词、宾语无法组成正常生活场景。
- 代词各自能解释，却没有稳定的歌者、现场听众、话中对象和真正倾听者。
- 动宾搭配错误或省略后对象悬空，却用诗性、通感、双关或古风为病句辩护。
- 确认词与猜测词互相抵消，人物究竟知道什么无法判断。
- `不是 A，而是 B`两端不回答同一个问题，只靠句式制造反转。
- 核心词吸附多项未经正文建立的联想，作者解释越多，字面反而越空。
- 因为创作命题是求消息，就把`音讯、实话、准信`按确定程度排成三层，并宣称它们自然形成情绪递进。
- 完整副歌逐行全是必要事实、条件判断和信息请求，没有画面、感受、关系动作与声音回钩的分工。
- 把一个功能词当作全段世界观的容器，其余句子只是替它解释剧情。
- 一个句子混用多套比喻框架。
- 只有痛苦和正确态度，没有对象、动作、代价和冲突。
- 句子脱离解释就不成立，必须由管理员补一大段说明。
- 句子第一遍、第二遍和最后一遍没有意义变化。
- 句子可以套在大量歌曲上，听众无法认出本作归属。
- 只完成了正确的副歌语言动作，没有短 hook、声音骨架、关系代价和作品专属词，却被宣布为核心句。
- 整段副歌只是核心句的近义改写，支撑句没有增加事实、代价、回答、对象变化或回钩。
- 为追求一语双关、一语三关，把多项未经正文建立的意思强塞进宽词；第一耳反而不知道字面在说什么。
- 把爆发力等同高音、惨词和音量，没有人物越过承认、请求、质问或决定的关系门槛。
- 主歌和副歌使用同一种叙事口气，副歌继续交代人物去了哪里、做了什么、想找谁，只是旋律和音量升高。
- 用`痛、伤、爱、恨、绝望、命运`堆出情绪强度，却没有称呼、对象、关系动词、条件、选择和代价。
- 把`我只是想知道、希望能够、请你捎来一个消息`一类礼貌任务说明直接定为核心句，人物没有逼近底线，也没有可复唱的语言和声音落点。
- 为追求开口音、响亮尾韵或高音，把准确动词和人物口吻换成空泛词；或宣称某种元音天然等于悲伤、愤怒和爆发。
- 没做十秒复述、换歌、去旋律、入旋律和三次回归测试，便宣称句子有传播力。
- 只因对标句子传唱广就照搬其词句、意象组合、语义顺序或韵脚地图。
- 只因害怕相似就删除有效的问句、复沓、重复或押韵，没有比较质量收益与相似风险。
- 生成三句便全部展示，把候选数量当成用户获得感，没有完成专业淘汰。
- 为了必须给出“金句”，在所有候选都未通过时仍选择一条相对较好的普通句。
- 用户本轮只要求裁决核心句，却交出带`[Chorus]`标签的四至八行完整副歌，让支撑句、物件和剧情替核心句本身争取通过。
