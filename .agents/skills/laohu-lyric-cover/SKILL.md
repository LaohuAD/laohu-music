# 老胡歌曲封面与视觉入口

封面是作品的视觉入口，先确定它承担叙事关系、歌手识别、声音气质、文字记忆还是系列识别。人物动作和悬念服务叙事路线；肖像、纯字体、抽象与氛围路线也可以成立，依据具体作品和使用场景裁决。歌曲、歌名、声音中心和封面要让听众感到这是同一件作品，而不是四个互不相干的包装决定。

## 视觉箴言

```text
视觉不替歌曲讲完，视觉先让关系现身。
先见动作，再见气氛。
先定谁承重，再排人物、标题与背景。
一个主体守住一条总线，一处异常打开一扇门。
道具不是装饰，必须参与命运。
悬念不靠遮脸，靠答案尚未抵达。
封面、歌名、声音各自入场，最后同归一线。
小图不减情绪，只减细节。
标题不替画面解释，画面不替标题重复。
```

视觉的方向是第一眼承诺，整体是注意与识别的组织，材料可以是人物、空间、字形、色彩或材质，呈现负责构图、文字准确性与平台规格。上述箴言中的动作、命运与悬念限定于叙事路线；声音气质须落实到具体视觉关系，不能只报风格名称。

开始前必须读取[作品总线与跨阶段交接](../../references/laohu-lyric-topic/16-作品总线与跨阶段交接.md)和[音乐封面视觉转译与发布验收](../../references/laohu-lyric-cover/音乐封面视觉转译与发布验收.md)，并取得本作身份、名称、声音或歌词依据、发布用途、规格及禁止误读。已有完整成品可直接提取简报，不因缺少旧卡片重复立项；缺少关键身份时先做标明假设的探索。

封面探索可以在选题、写词或谱曲阶段提前验证视觉入口；正式封面默认等到发布主音频和正式歌名已经确定。早期草图必须标为探索稿，不能反过来要求歌词、歌名和声音迁就一张先生成的漂亮图。正式封面完成后还要与最终音频、歌词、名称、署名和平台画幅一起进入发布包；单独生成图片不等于作品完成。

## 0. 音乐封面适配

音乐封面先从歌曲总线长出来，再向视觉层落地：

```text
歌曲让听众承认、等待、质问或承担什么
→ 哪个歌词物件、人物动作或声音记忆能替它现身
→ 画面确认什么、隐藏什么
→ 歌名补足什么、声音何时兑现什么
→ 最终把一个关系压缩成可记住的一帧
```

正式单曲 / 专辑封面负责长期识别和歌名记忆；MV 缩略图负责现场异常与点击入口；短视频封面负责一秒停留；发行页面主图负责作品身份与信息稳定。四者共享一条歌曲总线，不强行使用同一张图或同一个时间点。

音乐封面必须建立最小简报：发行用途、目标平台、目标听众、锁定歌名与署名、歌曲总线、歌词承重物、声音中心、第一眼承诺、需保留的悬念（适用时）、不能误导的事实和实际可用参考。只有“古风、唯美、伤感、电影感”时，准入不通过；这些是检索词，不是视觉主张。

## 0.1 Reference 路由

每次音乐封面任务默认读取[音乐封面视觉转译与发布验收](../../references/laohu-lyric-cover/音乐封面视觉转译与发布验收.md)。只有文化、历史、宗教、传统器物或版式来源不明确时，再调用视觉项目中的文化事实方法做局部核验；不把视觉项目的短剧、视频、品牌和资产工作流整体搬入 V4。

封面负责决定这首歌的哪项关系先被看见、哪项答案必须藏住，以及歌名、主体和构图怎样共同成为第一入口；它不负责重新发明人物的完整视觉身份。角色、服装、道具和场景已有确认资产时必须继承，不能为了封面气氛自行换人、换时代或换世界。确实缺少人物设定、服装体系、布景逻辑或跨镜头资产一致性时，形成清楚的视觉开发交接，再用确认结果完成封面；不得把本 Skill 扩成完整角色设计与视觉母项目。

封面或 MV 主动把歌曲迁入另一时代、职业、现实契约或事件背景时，先做关系保真转译：逐项写出原作中谁在表达、表达给谁、两人是什么关系、哪项选择不可逆、哪些歌词承担辨认身份的作用，再为它们寻找新世界中的视觉对应。时代和事件可以更换，人物关系的种类、表达对象、代价方向和歌词解释权不能被背景顺手替换；既有关系被改成另一类关系、个人表达被扩成抽象群体宣言、人物代价被题材符号覆盖，或新画面必须靠额外故事才能让歌词说通，均退回视觉构思，不进入正式封面。

## 1. 先选视觉职责

| 路线 | 实际设计对象 | 验证方式 |
| --- | --- | --- |
| 叙事关系 | 人物、动作、空间、信息差 | 陌生观众能辨认关系，不泄露已锁定的悬念 |
| 歌手肖像 | 身份、表情、距离、造型和留白 | 人物可辨，气质与声音相称，不强加事件 |
| 纯字体 | 名称、署名、字形、字距、分组和色面 | 文字准确、缩小可读、声音气质与系列归属成立 |
| 抽象或氛围 | 色彩、形态、节奏、材质与空间 | 能指出与声音的对应，缩略图仍有区别，非泛化库存 |

先确定本次主职责，再读相应方法。以下动作、危险与信息差检查只适用于叙事路线；其他路线以表中对象替代，不填虚构人物。可以组合，但要明确第一落点。

### 叙事路线准入

先在歌名、人物和关系证据中确定唯一第一落点，再用普通话回答：

```text
第一眼先读到歌名、人物还是关系动作，为什么必须由它先出现
→ 它怎样通过面积、对比、清晰度、隔离、位置或方向形成可辨第一落点，不以数量代替观看
→ 第二眼由什么人物动作或背景证据证明第一落点不是空话
→ 什么地方不对劲
→ 这项异常来自总线中的哪项事实或冲突
→ 观众暂时不知道什么
→ 听完歌以后，同一画面为什么会变义
```

回答只剩“悲伤女子、古风氛围、战争背景、电影光影”，方向未成立。

歌名本身就是作品最强问题、判断或记忆中心，而且背景能为它提供一项可见证据时，采用标题主导；既有人物身份、脸部状态或歌手识别是听众进入作品的最短入口时，采用人物主导；一个动作比名字和脸更快说明异常关系时，采用关系主导。三者都可以成立，但只能有一个第一落点。第二层负责证明，第三层负责归属或余味；不能把标题、脸和剧情画面同时做大、做亮、做清楚。

人物主导不等于排斥海报大脸。大脸必须通过目光、手势、身体方向、遮挡或空间位置与第二层证据发生关系；它若只负责漂亮和悲伤，仍是站桩。标题主导也不等于把背景压成纹理；背景必须让标题获得具体对象或第二层含义，但不能另起一条故事。

## 2. 叙事封面的主画面

封面只保留一个第一视觉主体、一个主要动作和一个主要悬念。时代、职业、关系和危险通过人物正在做的事、环境中不合常理的细节和视觉权力关系出现，不靠道具清单解释剧情。动作必须写清行动者、对象以及被改变的状态；“站立、回望、悲伤、手持某物”若没有对象和后果，仍只是姿势。

人物封面生成前先建立单帧因果：前一刻在人物或环境中留下什么可见痕迹，人物此刻正在对谁或什么作出反应，动作尚未完成哪一步或下一瞬会往哪里去，摄影机站在什么关系位置，环境又怎样接住这次动作。静止场面也可以成立，但必须看得出一个未完成的反应、身体余势或环境回声。若这五项无法收束到同一关系，先重做主画面；不得用表情、服装、天气和光影替代。

画面包含目光、指向、行进、飞行、冲击或追逐时，不能只检查几条斜线是否相接。生成前分别写出每个主体的起点、终点、朝向和动作含义，并核对人物身体、手势、载具、运动物前缘、尾迹与结果区是否共同证明同一件事。几何方向看似统一、语义却会让人物被读成阻止、躲避、追赶或误伤时，退回动作设计；只有作品明确需要这种反向关系时才保留。

现在与回忆、现实与想象或两个时空同时进入封面时，必须沿一条因果视线排列：前景人物正在看、触碰、背向或走近什么，背景旧事回答了哪一个问题，歌名在两者之间怎样改变读法。多层画面只允许共同证明一个悬念；若遮住任一层以后其余部分仍各讲各的，说明它们只是拼贴，退回构图。

主画面必须让主体的动作、空间中的权力关系和一个尚未解决的问题同时可见。删掉歌名以后，陌生观众仍应大致看出谁正在回应谁或回应什么；听完歌曲再看，才补上回应的原因和代价。若画面只有题材身份，没有关系方向，它即使精美也不能进入概念竞争。

## 3. 叙事路线的信息差与不泄底

视觉入口可以前置高潮现场，不能提前解释结局。分别确定：

- 画面现在确认的事实。
- 人物知道而观众不知道的内容。
- 观众会提出的唯一主要问题。
- 歌曲或视频何时兑现答案。
- 听完以后回看封面新增的含义。

多义和悬念必须由作品已有证据支持。不能靠把人物遮脸、放远、加烟雾和故意拍暗制造“高级感”。

## 4. 封面、MV 与短视频不是同一张图

- **封面**负责长期识别、歌名记忆和作品气质，允许更凝练。
- **MV 第一镜**负责建立现场、行动和信息差，可以使用高压冷开场。
- **短视频第一帧**负责在平台环境中让目标听众迅速看懂异常关系，并与标题、声音开头共同承诺后续内容。

三者服从同一总线，但可以选择不同时间点。不得把封面强行裁成短视频，也不得让短视频为了停留泄露歌曲最后的选择。

## 5. 构图与标题字

缩略图中首先保证被选中的第一落点和第二证明可辨。背景细节只保留会改变关系理解的内容。人物、歌名和关键道具可以前后叠压，但不能破坏脸、动作关节、标题字义和视线方向；横版、竖版、方形裁切都要预留安全区域。

标题字不是最后贴上的标签。排版前先确定歌名中哪个字词承担语义重音、标题是一行还是分组、各组的大小差如何表现读法、字形的力度来自歌曲声音还是时代材料、填色与描边怎样从背景中分离。标题主导时，以实际缩略图验证视觉优先级；纯字体作品可由字形、留白和色面共同构成全图，不强求叙事背景；人物或关系主导时，标题仍要保持作品身份，但主动退让面积或对比。粗笔刷、宋体、黑体、书法、手写和几何字都只在与歌曲及发布用途相称时使用，不把任何一套自媒体字形固定成音乐封面的默认模板。

标题字服从正式歌名的声音和含义：字形、大小、位置、颜色、描边和肌理帮助识别，不替歌名补剧情。文字在手机缩略图上必须可读；若歌名需要一大段副标题才能解释，先回命名或选题，不用排版救场。

## 6. 反模板生成

生成提示词前列出当前题材最容易出现的库存符号，并逐项审问：

```text
它是否来自人物生活
→ 它是否参与关键动作
→ 换成同题作品仍然成立吗
→ 删除后是否损害总线
→ 它会不会让观众误读成另一种歌
```

古装、戏服、婚服、雨夜、车站、红绳、战火、废墟、背影、眼泪、信件、月亮都不是禁物；没有人物动作和作品证据时，它们只是库存。禁止用更多装饰弥补主画面没有冲突。

## 6.1 视觉通行路线与文字职责

每张封面都要写清：进入点、阻断或加速、决定性落点和余韵出口。脸、手、歌名、道具、亮区和方向线只能先选一个作为进入点；标题、人物、背景、装饰不能同时争抢第一落点。

歌名、演唱者、词曲作者、厂牌、期数和发行信息各有职责。用户确认的歌名与署名默认逐字锁定，不润色、不缩写、不换同义词；没有明确原文的文字项删除，不让图像模型随机写文案。所有真实可见文字在最终生图提示词中用中文双引号逐项锁定，固定 Logo 通过实际参考调用，不重新描摹或改造。

歌名与画面必须互补：歌名负责把听众引向作品中的一个解释，画面负责让相关人物、动作或异常关系先出现；二者不能重复解释同一事实，也不能各自制造另一条作品总线。若画面离开标题就无法理解，先检查主动作和关系；若标题必须替画面补完整剧情，先回构图或命名。

## 6.2 参考资产与画幅

参考图按职责调用：主体参考只锁人物 / 产品 / 道具身份，构图参考只借图文层级与留白，风格参考只借颜色 / 材质 / 成像介质，成片截图只锁最终视觉事实。没有引用时不放空占位符；一张参考图不能顺手锁死背景、服装、版式和第三方文字。

画幅分成参数层、内部构图层和模型正文层。音乐任务按用途记录 `1:1` 单曲 / 专辑封面、`3:4 / 4:3` 发布图和 `16:9` MV 缩略图；默认输出一条当次内容的比例自适应提示词，不写死坐标。换画幅不能只改数字，必须重审人物裁切、歌名断行、主体重心和安全区。

## 6.3 颜色与材质

颜色、光线、颗粒、旧纸、柔焦、色散和镜头耀斑都要有歌曲世界或画内介质的来源。不要用默认蓝灰、青橙、紫蓝霓虹或“高级低饱和”替代视觉判断。国风不等于图腾堆叠；文化元素要转译成构图、尺度、材料、字体和留白关系，未知经文、宗教核心符号、法器、仪式和不明文字先核验或隔离。

## 7. 交付与验证

```markdown
## 封面与视觉入口方案

- 作品总线：
- 第一视觉主体与动作：
- 异常关系或危险现场：
- 已展示的事实：
- 暂时隐藏的答案：
- 听后变义：
- 歌名位置与标题字逻辑：
- 构图、景别、色彩、光线和材质：
- 封面 / MV 第一镜 / 短视频第一帧的差异：
- 库存符号淘汰记录：
- 平台画幅与缩略图验证：
- 生图提示词与负面约束：
- 最大误读风险与回流条件：
```

交付服从用户目标：要设计则交可评审设计，要图片则完成制作，要提示词才交可直接使用的 `【封面生图提示词】`。按材料比较真正不同的概念，不要求凑满固定数量。纯字体可直接排版，图文组合可生成底图再合成，不以先失败作为选择条件。提示词要写主体动作、关系压力、摄影机位置、视线路线、颜色与材质来源、锁定文字、排版职责、裁切余量和参考职责；不写给用户看的长篇设计说明。

验证实际要求的画幅与目标平台缩略图；跨画幅交付才追加对应验证：主体是否仍能识别，歌名是否可读，人物动作是否清楚，画面是否只剩气氛。生成图还要检查时代、服装、职业动作、空间关系和肢体是否可信。若图像模型无法稳定实现关键动作，简化构图或更换同功能视觉方案，不得把总线删掉迁就模型。

## 7.1 发布前质量门

```text
一秒内能认出主体、歌名和唯一承诺吗
第一落点是否明确属于歌名、人物或关系证据中的一个，且经缩略图验证具有明确优先级
第二层是否正在证明第一落点，而不是另起一条故事
缩到手机缩略图后，轮廓、标题和关系仍成立吗
灰度或剪影状态下，层级仍成立吗
歌名、歌词承重物、声音中心和画面是否承诺同一首歌
标题与画面是否互补，而不是重复解释
主体是否处在事件或关系压力中，而不是站桩摆拍
前一刻的痕迹、当前反应和下一趋势是否落在同一个关系动作中
删掉标题后，仍能看出谁正在回应谁或回应什么吗
改换时代、职业或现实背景后，表达者、对象、关系种类和不可逆代价是否仍与歌曲一致
双时空或回忆结构是否沿同一条目光、动作或空间因果连接，而不是拼贴
摄影机位置、视线、手势、空间和光线是否可信
身体、手势、载具、运动物前缘、尾迹与结果区的方向是否共同证明预定动作，而非产生相反语义
参考图是否各司其职，没有污染背景、服装、第三方文字或版式
是否没有提前展示死亡答案、最终选择或全部反转
实际可见文字是否与锁定原文逐字一致
```

任一关键项失败，按首个断点回流：歌名或歌曲承诺不成立，回歌名 / 选题；素材或文化依据不干净，回素材准备；主关系、构图、文字层级或比例失败，回本 Skill；文字或版式需要精确控制时，直接采用真实字体排版或分层合成；生成式文字适用于可容许字形试验且能逐字校验的路线，不要求先失败。

上述验收只执行当前路线适用项。纯字体不做“删标题后仍见人物”测试，肖像不要求危险现场，抽象图不补造情节；它们仍须通过身份、声音对应、文字与发布规格检验。

## 8. 直接淘汰

- 叙事路线没有可辨关系；其他路线没有作品身份、声音或使用场景依据，只剩通用气氛。
- 用红色、火焰、雨夜、背影、眼泪、古装或电影光影冒充作品身份。
- 为追求点击，展示结局、死亡答案或全部反转。
- 封面、歌名、歌词和声音分别承诺不同作品。
- 小图看不清主体与歌名，却靠高清大图细节自我辩护。
- 生图提示词堆满风格词，没有主体、动作、空间、镜头和禁止误读。
- 关键历史、文化、服装与职业细节未经核实，却用“艺术化”开脱。
- 把专辑封面、MV 缩略图和短视频封面当成同一种传播任务。
- 把用户没有确认的副标题、宣传语、期数或随机文案交给模型自由发挥。
- 把参考图的背景、字体、第三方文字或完整版式一起继承进歌曲封面。
- 只在大图里成立，缩略图、灰度图或其他画幅一裁就失去主体、歌名和关系。
- 为坚持某种生成方式牺牲文字准确性、可编辑性或最终视觉质量；把未经逐字核验的标题交付为成品。
