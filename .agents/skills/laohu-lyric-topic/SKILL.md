# 老胡歌词选题

选题把材料、声音入口与用途变成一项可验证的作品意图：听众要经历什么，冲突时先保护什么。人物关系作品继续追到歌者为何此刻开口；安定陪伴、庆祝、幽默、律动或纯器乐可以通过感知、重复、身体参与和声音秩序成立，不为填写人物字段补造冲突。

## 一、选题箴言

```text
题材是地，命题是命。
先见一人，再见众生。
故事为世界，选择为歌。
新意不在换景，在改关系。
材料不为装饰，事实要能改命。
对标借眼，不借命。
受众不是标签，是需要这首歌的人。
一线贯通，万象同归。
```

这八句用于人物与关系主导的作品。它们不要求每首歌使用固定题材、固定结局或固定曲式；它们要求每一次选择都能回答“这项内容怎样改变人物的关系、判断、行动、代价或听众进入方式”。

执行层级固定为：

```text
公理 → 命题硬骨 → 条件化机制 → 作品总线 → 下游交接 → 反向验收
```

细则与案例是解码器，不是第二套命令。若“更有故事、更有画面、更大众、更古风、更抓人”与人物关系冲突，回到命题硬骨重判；若只是审美分歧，说明保护项、代价和改判条件，不用平均折中。

## 二、这个 Skill 负责什么

负责把以下材料变成一个可写、可唱、可配曲、可命名、可视觉化的作品命题：

```text
灵感、题材、人物、关系、事件、歌词对标、旋律或伴奏、歌手、听众、用途和委约条件
```

输出不是完整故事，也不是歌词正文，而是：

- 一条作品总线：目标听众要经历什么，哪些文字与声音选择共同完成它；人物关系作品说明谁在什么压力下对谁行动。
- 一组关键条件：用途、体验目标、材料来源、声音入口与保护项；戏剧关系作品追加人物、对象、目标、阻力、选择、代价和余波。
- 一份材料边界：哪些是事实，哪些是用户决定，哪些是系统假设，哪些还缺证据。
- 一份条件化路线：当前主推荐、会改变作品的强分支、主动放弃和推翻条件。
- 一张交接卡：写词、谱曲、歌名和封面下一步各自必须实现什么。

先选当前主路径，可组合但不机械填满所有字段：

- 人物选择：事实 → 关系与阻力 → 选择及后果 → 听法变化。
- 感知与陪伴：具体听者及场景 → 注意、距离与感受 → 稳定或渐变的文字声音 → 能否停留和再次返回。
- 律动与共同参与：使用场景 → 可感的节奏、呼应或声音中心 → 进入、持续、释放与回接 → 身体与记忆是否响应。
- 幽默或游戏：可理解的期待 → 语言或声音偏转 → 会意、参与与重复收益，不强制反转结局。

路径由作品证据选择，不按曲风名称贴标签；混合任务公开本轮主目标和牺牲。人物选择路径的完整转译链是：

```text
种子与事实
→ 人物与关系位置
→ 不能同时保住的两样东西
→ 人物选择、代价与余波
→ 听众怎样重新理解同一件事
→ 作品总线与分领域交接
```

题材研究、心理机制、市场资料、对标作品和局部试写只有在改变或确认这条链中的一个决定时才算生效；资料更多、卡片更全和故事更完整，都不能代替这次转译。

本 Skill 不把对标、心理学、市场、题材类别或模板直接变成作品结论。它们只能帮助发现关系、检查边界或选择验证方法。

## 三、先判断材料成熟度

### 1. 已有作品事实

人物、关系节点、演唱对象、事件后果或用户明确的虚构设定已经足够具体。此时直接保护最不可替代的事实，少问重复问题，进入命题裁决。

### 2. 有种子，没有人物命

只有“战争、离别、故乡、古风、治愈、热血、电影感”等题材或效果词。此时不能直接写成歌；先找目标听者、使用场景、材料或声音入口；人物选择路径再追到关系压力。只补会改变作品身份的事实，当前材料支持的局部样稿先做。

### 3. 只有对标作品

先分析对标怎样发现人物、关系、情绪因果、句法、重复和传播入口，再提出待选择的创作机制。没有新人物材料时，不能把对标中的细节、心理动机或故事因果冒充本作事实。

### 4. 已有音乐入口

先听或读取旋律、伴奏、topline 的速度、拍点、音域、句长、重音、悬置和段落记忆，再判断哪种关系命题能被它承受。音乐可以提出核心记忆与新的表达方向，供文字反证；改变用户锁定的身份须回流，不能替人物补经历。

成熟度决定交付深度，不决定艺术标准。材料不足时交探索路线和缺口；材料足够时交明确主推荐，不用完整问卷拖慢创作。

## 四、命题硬骨：先把歌的命定下来

人物选择主导时使用下面这条链。其他路径先明确听者、用途、核心体验、材料和声音依据、展开或持续方式、验证方法；不适用的戏剧字段省略。关键未知允许进入有标记的探索，锁定前必须解决影响身份的缺口：

```text
谁在唱
→ 唱给谁，或唱给谁听
→ 为什么偏偏此刻开口
→ 他想让对方、自己或旁听者发生什么变化
→ 什么现实、关系、身份、时间或知识差阻止他
→ 他能采取什么主动动作
→ 哪个选择不可同时保住两样东西
→ 代价由谁承担，结尾留下什么无法抹平的余波
```

必须分开四个位置：

```text
创作者：为什么我值得写这件事
歌者：为什么这个人必须唱这件事
演唱对象：这句话究竟在对谁施加关系动作
听众：他在什么处境和时刻需要借这首歌完成什么动作
```

创作者的感受不能自动变成歌者的经历；歌者的独白不能自动代表所有听众；听众的公共连接不能反过来抹平人物差异。

### 灵魂：一条关系母句

用普通话先写一条内部母句：

```text
谁在什么压力下，对谁承认、质问、请求、保护、拒绝、归还、告别或承担什么，代价是什么。
```

它不是“爱情、战争、思念、成长”，也不是剧情摘要。它要包含关系对象和选择。若一句话只能说“某人经历了很多事”，灵魂未成立。

### 筋骨：一条认识运动

写清听众怎样逐步改听同一件事：

```text
起点：人物原来相信什么
→ 触发：什么使这种相信动摇
→ 压力：他想保住什么，却必须放弃什么
→ 动作：他亲自做了什么，或为什么没有做
→ 余波：最后一次副歌、尾声或画面让旧词获得什么新责任
```

运动可以是新事实，也可以是对象变近、责任换位、同一句反听、声音回归或人物主动性显形。这条认识运动服务人物路径。其他路径检查感知、律动、声音或参与如何持续和展开；有职务的稳定重复不必每次改义。

### 血肉：承住命题的材料

每项材料进入前都要说明：

```text
它属于谁的生活或作品世界
→ 它有什么准确的物性、动作、声音、制度或文化属性
→ 它改变了哪项关系判断或人物选择
→ 如果删掉，损失的是情绪、身份、声音记忆，还是仅仅剧情完整
```

常见材料可以保留，前提是它最准确地证明当前关系；罕见材料不能因为新奇自动升级。材料不是装饰，也不是道具清单，而是命题的证据和回声。

### 表皮：提前验证能否成为歌

选题阶段可以试写一两句中心句、副歌核心句、歌名初稿或声音句架，但它们只是验证命题的表皮试验。歌名初稿仍须像一个能够报幕、推荐和印在封面上的歌名；若只是说明人物处境，标为路线标签。检查：人物会不会这样开口、关系动作是否明确、是否有可回归的词、是否可唱、是否给后续段落留下增义空间。漂亮句不能反过来替命题做决定。

## 五、从种子到总线的执行顺序

### 第一步：接住种子，不替它下结论

先分出用户提供的是事实、感受、对标、观点、假设、审美偏好还是行动要求。保留最有生命力的冲突，不急着把它命名成爱情、成长或治愈。

### 第二步：找到不可替代的关系

追问或内部判断：

- 谁想得到什么，谁害怕失去什么？
- 两个人、人与时代、人与自我之间哪两样东西不能同时保住？
- 谁知道什么，谁不知道什么？
- 谁拥有主动权，谁承担后果？
- 什么事实会让原来的解释失效？

这些问题用于得到具体结论，不是把问题原样交付给用户。若答案只能写成宽泛情绪词，继续寻找事件、动作、身份或责任来源。

### 第三步：登记现实契约和事实等级

区分写实、历史、戏曲传奇、民间传说、神话、寓言、影视类型和纯抒情。事实核验服从作品契约；用户明确采用的虚构设定按作品事实处理；系统自行补出的内容标为假设。只有对标材料时，不得借作品的世界观给新人物补人生。

事实表至少分为：

```text
用户确认事实 / 外部可核事实 / 作品共同约定 / 系统推论 / 待选择方案 / 尚缺证据
```

### 第四步：把情绪还原成动力

不要先选“悲伤、治愈、热血”。先写：事实发生了什么，人物原本期待什么，事实怎样改变目标、身份、关系、控制感、公平感或不可逆性；再写他的身体、注意、行动冲动、行动抑制和主语言动作。人物路径检查情绪如何促成关系动作；安定、庆祝和律动路径检查情绪如何改变注意、呼吸、节奏或参与，不强加情绪危机。

主语言动作只选一项：承认、请求、质问、保护、归还、拒绝、决定或命名。其他情绪服务于它，不让一首歌同时承担安慰、升华、劝告、控诉和号召。

### 第五步：确定公共连接，不把人物抹平

公共性不是“大词”，而是听众能在人物的具体选择中认出自己的关系位置。依次判断：

```text
个人差异 → 关系位置 → 共同处境 → 听众使用时刻 → 可被传唱的公共判断
```

不凭人口标签推导人格；不因为想让更多人共鸣而删掉陌生性；不把创作者没有资格代表的群体写成自己的代言对象。具体参照[立意层级与公共共鸣](../../references/laohu-lyric-topic/14-立意层级与公共共鸣.md)。

### 第六步：做条件化探索，不做菜单式发散

内部可以发散，但对外只给：

```text
当前主推荐
→ 它保护的事实与新增认识
→ 最容易想到但被淘汰的方向及原因
→ 两个会真正改变关系因果或结尾的强分支
→ 当前主动放弃什么
→ 哪项新证据会推翻推荐
```

分支必须改变人物、材料来源、段落运动、声音入口或结尾判断，不能只是换场景、标题或近义词。材料不够时，不把暂定路线包装成唯一答案。

### 第七步：让对标提供眼睛，不提供命运

重要对标至少分三类：最接近的主对标、同题材异写法、同技法异题材。比较：

```text
灵魂：它看见了哪种人性、关系和生活判断
筋骨：欲望、阻力、认知和代价怎样推进
血肉：哪些事实、物件、文化经验承住情绪
表皮：句法、复沓、留白、韵脚、重音、声音和视觉怎样协作
传播：听众为什么记住、复唱、转述或在某个时刻使用
```

每条迁移结论都要写“原作具体动作 → 听众先听见什么 → 新作保留什么机制 → 新作换掉哪些人物事实、对象、顺序和结论”。学习方法，不复制可识别词句、细节组合、语义推进、韵脚地图、旋律或视觉构图。

### 第八步：建立作品总线并交接

选题成立后，压成一条可供下游执行的总线：

```text
作品要让听众重新听见什么关系判断
→ 谁承担这条判断
→ 哪个触点或声音成为记忆中心
→ 哪个段落第一次显形、哪次回归改义、桥段承担什么新认知
→ 结尾留下哪项选择和代价
```

故事简报留在理解层；歌词输入只接收关系动作、抒情触点、声音句架和最少事实。若选题交接仍按“后来、临走、收到、最后”复述，先转译，不得直接交给写词。

同一总线交给不同领域时，不复制同一份故事简报：写词接关系动作、材料边界和段落认识运动；谱曲接需要被听见的秩序、破坏、回归和选择；歌名接作品重心、记忆线索与听前听后关系；封面接主体动作、异常关系、已有资产和不得泄露的答案。四份交接保护同一首歌，但分别使用下游真正能执行的语言。

## 七、阶段交付：不是问卷，是可执行的作品总线


## 八、反向验收

完成选题后遮住分析，只看总线卡，逐项回答：

### 灵魂门

能否说清本作让谁经历什么、哪项选择值得保护及如何验证？人物路径继续检查关系母句；其他路径以具体体验与声音秩序取证。只有题材、情绪标签或空泛正确道理，退回。

### 筋骨门

各段是否服务同一主要体验？关系戏剧检查变义；循环、吟唱和律动检查持续、累积、释放与回接，不要求新增事实或反转。如果只是不断加事件、场景和消息，退回。

### 血肉门

每个核心材料是否有准确归属和物性？删掉它损失的是关系或声音，而不只是故事完整？如果只是库存意象，退回。

### 表皮门

中心句、歌名初稿或局部句子是否像当前人物会说，能被朗读、试唱、报幕或视觉化？歌名初稿若像剧情说明或管理员备注，退回路线标签；若只能靠作者解释，先回命题或材料层。

### 保真与边界门

用户提出的冲突是否仍在，人物是否仍有主动性，代价是否同级，现实契约是否一致？有没有把牺牲改成释怀、把怨改成善意、把极端选择改成安全结论？发现就回到选题裁决。

### 交接门

写词拿到的是关系动作、抒情触点、声音句架和最少事实，不是故事流水账；谱曲拿到的是情绪与认知的声音问题；歌名拿到的是总线和内部记忆线索；封面拿到的是主体动作、异常关系和未泄底答案。

## 九、与其他 Skill 的边界

- `laohu-song-director` 统筹阶段、状态和回流；本 Skill 负责命题与总线。
- `laohu-lyric-writing` 把总线转成歌词；本 Skill 可以调用它试写中心句或副歌验证，但不把试写自动升级为锁定稿。
- `laohu-lyric-composing` 判断音乐能否承受命题；本 Skill 只提供音乐所需的关系运动和关键落点。
- `laohu-lyric-title` 把总线压成歌名初稿或正式歌名；本 Skill 不用歌名替代作品判断。
- `laohu-lyric-cover` 把总线转成第一视觉；本 Skill 不用视觉气氛冒充题目成立。
- `laohu-quality-supervisor` 独立检查每个中间交付；本 Skill 不用自己的解释替代作品证据。

## 十、直接阻断

- 只有题材、情绪、风格或市场词，无法说明目标听者、具体体验、材料或声音依据；纯器乐不要求虚构歌者。
- 声称以戏剧选择为核心，却只有完整故事，没有主动目标、关系动作、选择或相应代价；不把此门套到非戏剧作品。
- 用对标细节、常见物件或心理动机替用户编造新人物事实。
- 把强冲突安全化，把复杂结尾平均折中，或把人物选择改成另一人的遗愿。
- 用“更有画面、更高级、更电影、更大众”代替具体材料、关系和验收。
- 候选只换场景、标题或近义词，却声称形成不同路线。
- 受众只写年龄、性别、地域和平台标签，不能说明共同处境和使用动作。
- 用市场点击、歌手标签或封面气氛救一个作品归属不成立的题目。
- 交给下游的是按时间顺序的聊天记录，而不是经过转译的作品总线。
- 用户未确认的路线、事实或结尾被写入锁定日志。

## 十一、理论边界

“一切景语皆情语”支持把外部材料当作内在关系的对应物，不等于每个选题都必须写景；“客观对应物”支持用一组可感材料承住情绪，不等于情绪只能由事件链表达；“借他人之境界成我之境界”支持学习传统和对标，不等于借用他人的人物命运。它们只能帮助选择材料与关系，不能代替用户事实、作品契约、试听和听众验证。

选题成立是必要条件，不是商业成功证明。发布效果还受旋律、演唱、制作、歌手、平台、封面、发布时间和受众场景影响；本 Skill 只对作品命题、材料边界和阶段交接负责。
