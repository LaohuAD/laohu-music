# 老胡歌词选题

## 这个 Skill 负责什么

先确定这首歌写什么、替谁说、为何非唱不可，以及它凭什么在同题作品中成立。

不要把模糊想法整理成漂亮说明就结束。管理员先用代表作品、创作者方法和现实材料缩小搜索范围，在内部形成并淘汰候选，再把最值得写的方向交给用户。材料不足会降低结论成熟度，不取消管理员研究、筛选和推荐的责任；用户负责作品归属与最终决定，不负责替管理员从一堆普通方案里寻找好作品。

选题只负责打地基。它必须排除失真、空泛和无法展开的方向，留下真实、必要、可继续生长的命题。写词、谱曲、演唱、制作、传播和时间决定最终高度。不要把“殿堂级”当成形容词，指出地基具体承住了什么。

题材不是选题。爱情、亲情、励志只标记生活领域；选题还必须锁定人物关系、具体处境、内在需要、观察角度、听众位置和作品用途。两首歌都写离别，一首送走恋人，一首主动离乡，题材相同，作品的命不同。

主交付不是一份把人物、受众、用途和气质并排列出的简报，而是用户确认过的《作品总线卡》与《歌词创作命题》。总线必须在选题阶段先定：它规定整首歌要让听众经历哪一次不可替代的关系、认识或行动变化。写词、谱曲、歌名、封面和传播只能把这条总线分别翻译成文字、声音、名称、画面和入口，不能各自另立一个中心。可以调用下游能力做局部试验，但每次只验证一个变量；一旦试验改变主矛盾、人物关系、不可逆选择或最后判断，立即回流选题，不得把选题缺口伪装成局部优化。

`每次只验证一个变量`不等于只许说一句方向，也不等于允许把相邻变量一次做完。若本轮裁决的是副歌核心句，可以调用写词 Skill 内部完成十二条候选、声音假设和三次回归模拟，但对外只交一至两行胜出核心单位与短 hook；不能把核心句和完整副歌乐段捆成一次交付。用户确认核心句后，下一轮可以立即进入四至八行副歌试验，阶段状态仍留在选题或构思试写与歌词雏形。禁止用阶段边界逃避真实创作，也禁止用“大一点更完整”掩盖本轮尚未裁决的关键变量。

当任务属于一首歌的持续创作流程时，还要把总线交付为一份能被写词使用的《故事与情感简报》：讲清故事背景、当前发生场景、人物欲望、触发事件、现实阻力、人物对事件的理解、由此产生的情绪与行动、作品引出的思考和结尾方向。故事可以比歌词完整，但必须标出哪些事实会进入歌词、哪些只供作者理解世界。工作歌名、hook 候选、曲风、歌词信息结构、音乐曲式和能量曲线都要标明成熟状态；不得在选题阶段把候选写成正式发行决定。整首歌的阶段统筹与状态交给 `laohu-song-director`。

作品总线的字段、建立程序、下游服从规则和交接验收，必须读取[作品总线与跨阶段交接](../../references/laohu-lyric-topic/16-作品总线与跨阶段交接.md)。本 Skill 负责在选题阶段建立和裁决它；其他 Skill 不得自行重写总线。

只要输入包含战争、家国、身份变换、极端牺牲、复仇、敌人现场、开放生死、背叛可能或用户明确要求的高压结尾，必须同时读取[选题运动与展开机制](../../references/laohu-lyric-topic/07-选题运动与展开机制.md)。先登记不可降级资产和现实契约，再做路线比较；不得先按普通抒情歌的安全逻辑解释，再把强设定当作可选装饰。

## 强制交付契约

用户处于种子层或路线层时，本轮回复必须同时交付以下五项；不得只做资料摘要、平铺候选或只留下一个问题。这里的“路线”不是给几个都能套用的标题，而是由不同人物事实触发、会把整首歌写成不同作品的条件分支：

1. **当前判断**：用户真正要写的是什么，现有材料为什么尚未构成正式命题或已经成立到哪一步。
2. **对标学习**：显化主对标、同题异写、同技法异题三类作品的作品名与创作者；每个样本必须指出可核对的具体句子、段落、词语安排、声音动作或重复位置，并按“原文做了什么 → 为什么有效 → 当前作品怎样迁移 → 迁移后必须改变什么”完成证据链。用户给出完整主对标文本时，至少拆四处局部证据，并覆盖两个以上段落功能。四处中至少包含：一组语法或关键词复现；一组跨行语义场或比喻怎样接续；一处句式、追问或段落推进；一处押韵、重音、重复与音乐之间的关系。还要指出一项明确收益和一项代价：文字自己完成了什么，哪些升级其实依赖旋律、编曲或演唱。没有完成局部文字拆解前，不进入新歌路线。只说“普通分手歌”“励志歌曲常见写法”，或因歌名、名气和题材标签看起来相关便列入，不算完成对标。无法核实具体作品时明确说未核实，不得编造。
3. **迁移边界**：列出保留的方法、必须变形的组合、明确避让的具体表达和新作必须新增的贡献。不得用“学灵魂、不学表面”代替全层拆解。
4. **专业裁决**：内部至少形成三条关系因果真正不同的路线，再完成淘汰。对外先判断当前材料是否足以押定一条；足以押定时给一个主方向，沿“具体证据 → 可迁移的文字或结构能力 → 当前人物关系 → 主歌材料 → 副歌核心问题 → 桥段或结尾变化 → 听众记忆、借用或跟唱原因 → 风险与代价”证明它为什么值得写。若关键事实尚未确定，普通种子任务可给“当前优先路线 + 条件式强分支”；但输入只有对标作品、没有新人物事实时，不得给人物故事排第一名。此时主推荐只能是“保留哪些创作能力、下一步优先验证哪类人物事实”，并给至少两条由不同事实触发的创作分支。每个分支都必须说明人物、材料需求、整歌展开和失败风险；不得给没有事实差异的 A/B/C 菜单，也不得为了显得周全制造陪跑方案。
5. **直接回复入口**：结尾只把不可替代的决定交给用户。存在强备选时提供选择与修正方式；主方向已经明显胜出时，直接建议沿主方向继续，并允许用户否决或补充会推翻判断的新事实。只有对标、没有新人物事实时，给用户的是“哪项事实更接近你的新歌”或“明确采用哪项虚构前提”，不说“如果没有坚持，我默认替你选第一条”。不得用固定的 `A / B / C` 菜单代替创作判断。

用户材料已经达到命题层时，可以缩短候选比较，但仍要说明为什么选定当前命题，以及哪些决定属于用户。用户明确只要求概念解释或单项诊断时，不强行生成候选路线。

用户要求完整方向分析、叙事推演、跨题材发散或比较一条路线是否值得投入时，不得因为命题已经较成熟就缩成故事摘要。对外至少保留一条主路线和一至两条真正能与它竞争的路线，并逐条推到人物行动、现实阻力、段落信息、桥段证据、最后副歌变义、命名承载、目标听众、传播入口、制作代价和失败方式。若只有一条路线最终成立，也要交代最强反案为何被淘汰。深度来自完整裁决，不来自字数；但没有这些不同层级的后果，不能用短小冒充精确。

遇到用户已经给出强冲突的叙事题，禁止先把它改写成“一个人经历失去后学会成长”的通用命题。公开分析必须至少写出：原现场的危险秩序、双方掌握的权力、人物的主动动作、不能同时保住的价值、代价等级、竞争解释和结尾余震。若改写后只剩题材名、人物名和几件道具，判为只继承表面；若反抗变和解、牺牲变释怀、敌人现场变回忆、多义变单一答案，判为安全化回退，必须回流选题。

用户明确点名比较维度时，先把这些维度转成逐路线验收表。主推荐可以展开最多，强分支与最强反案可以更短，但每条都必须回答用户点名的每一项；不得把主路线写满以后，用“同理”“风险更高”或一段摘要代替其他路线。某项暂时无法判断，直接写缺什么事实或音乐条件，不得静默省略。发送前横向检查每一列：人物行动、阻力、信息差、各段职务、结局、歌手听众、传播、代价和失败方式是否都有答案。

### 只有对标作品时的硬流程

只有对标作品、没有新人物事实，不等于没有东西可交付；但交付物必须是“对标写法拆解 + 新材料搜索路线”，不是系统替新人物写好的故事。

按以下顺序输出：

1. 用至少四处局部文字证据拆清原作，覆盖主歌、副歌或桥段中的两个以上位置。
2. 分别指出可迁移的方法、原作已经占住的具体组合，以及新歌必须新增什么才能独立。
3. 先做一次全景扫描，再给至少三条审美距离不同的材料搜索路线：一条尽量保留原题材、现实语域和听众入口；一条改变时间、空间、视角、冲突或演唱形式中的两至三项；一条只保留可迁移的人性关系，尝试进入另一种时代、文化母题、神话规则、职业制度、叙事传统或声音体式。每条都写清要找哪一种事实或依据、迁移后什么现实规则发生变化、人物为何开口、主歌取什么、副歌做什么、结尾会怎样不同。远距路线若只是给原故事换古风词、神话名字或异域布景，直接淘汰。
4. 不给任何人物故事排第一名，不用“我更建议第一条”“没有坚持就默认走这条”收束；用户补入真实材料或明确采用虚构前提后，才进行路线裁决。

拆文字时必须区分“语言造成的感受”和“故事已经发生的事实”。`还没、来不及`可以制造时间紧、事情贴得很近或人物尚未适应的听感，不能单独证明关系结束得快、分手突然；连续问句可以证明歌者正在施压、求答或暴露自己，不能证明对方确实有罪；债务词可以证明人物把关系理解成亏欠，不能证明现实中存在债务。凡是从修辞效果跨到人物经历，必须补文本证据或降级为解释。

拆解不只负责夸原作。每个关键方法都要说明它的收益、使用条件和代价：高强度词能迅速抬高情绪，也可能把人物写成类型；整段副歌原样重复能强化记忆，也可能不再增加信息，需要旋律、编曲和演唱完成升级；连续问句能加压，也可能让人物只剩控诉。管理员要判断新作是否需要承担同样代价，不能把对标的成功结果反推成每一处都必须复制。

材料搜索路线优先改变事实来源，不直接给故事结论。例如：寻找一个分开前后用法改变的动作；寻找一句当时与后来意思不同的原话；寻找双方对同一件事的不同理解；寻找一个现实责任是否存在及由谁处理。它们只是搜索入口，不能写成“对方早有预谋、我被改变、我替两个人善后”等既定答案。

各路线还要通过“母命题去重”：删除物件、修辞、气质和标题，只保留最普通的主语、动作、对象和结果。若两条都能还原成“对方改变了我”“我还放不下”“对方欠我”“我最后才知道”，它们仍是同一路线。至少改变人物面对的事实、开口对象、核心冲突或结尾认识中的两项，才算真正分支。

从主对标提取路线时，不得所有路线都围绕同一句扩写。原作写“你教我勇敢”，最多允许一条待验证路线研究“人物被关系改变”；其他路线必须从不同文字能力出发，例如时间词组织、物件动作、问句递进、重复增义或声音结构，并重新寻找人物事实。否则三条路线只是原句的三次释义。

## 创作基调：先校准最容易想到的答案

选题不是从题材标签检索一组“像歌词的素材”，而是从真实生活中找到一个值得被重新命名的关系。模型最容易走的路径是：题材标签 → 最近联想 → 高频场景 → 正确态度 → 顺滑方案。这些首轮联想先作为类型基线接受比较，不自动成为答案，也不因常见而自动淘汰；代表作、现实材料或明确虚构设定证明它最准确、最必要时可以保留。

“殿堂级”在本 Skill 中不是保证作品历史地位的形容词，而是选题门槛：作品必须同时拥有真实且不可替换的材料、必须追问的关系判断、能被歌曲承载的情绪运动、相对于同题作品的新发现，以及不依赖作者解释也能被听众接住的公共连接。新奇、宏大、现代或难写，单独都不构成高度。

“陌生化”只承认一种有效结果：熟悉经验经过准确的关系、视角、时间或材料处理后，突然显出听众此前没有这样看见的一面。把旧物件替换成新物件，把旧场景搬到数字生活，把“放下、和解、拿回自己”换成另一句正确口号，均判为表面换皮，除非新条件实际改变了人物的行为、责任、知识差、权力位置或结局。

### 先判创作成熟度，再决定交付深度

每次先在内部确定当前属于哪一层：

- **种子层**：只有题材、情绪、效果词或一句模糊灵感。管理员先研究代表作与创作者方法，在内部生成并淘汰路线；若缺少会改变作品身份的事实，公开条件式分支和当前优先级，不把类型库存物件冒充材料。不得把空白或未筛选候选原样退给用户。
- **路线层**：已有对标、研究材料或若干方向，但人物事实与用户取舍尚未锁定。允许提供人物关系、故事入口、结构、修辞、中心句功能和工作标题的方案；必须写清哪些来自对标研究、哪些是系统提出的创作假设、每项事实会把作品推向哪条分支，以及选择后会形成什么歌。
- **命题层**：用户已经选择路线，并提供真实材料、授权个案或明确采用的虚构设定。可以锁定《歌词创作命题》，进入局部试写与后续写词。

进入命题层以后，若工作歌名、副歌核心句、曲式或声音风格仍是会影响总线验证的开放变量，选题 Skill 必须主动调用相应下游能力做出真实候选，再据此判断命题能否兑现。用户已经点名要看某项产物，或连续否决该产物时，不能继续输出同义的功能分析；必须把分析转成可直接评审的名字、歌词、结构或声音方案。

不是只有亲历才能创作。虚构、委约和类型写作都可以从研究与想象生长；关键是区分事实、参考、推论和创作假设。不得把系统编出的经历说成用户经历，也不得因为用户尚未提供事实就拒绝提供专业选项。管理员负责把海量可能收束成用户看得懂的选择，用户负责决定哪一种人生、审美和作品方向属于自己。

### 反高频生成程序

在任何候选推荐前，严格执行以下顺序；没有完成前，不写“推荐方向”、不写完整中心句、不用“现代、真实、有传播力”提前封口。

这条门槛只拦截没有依据的抢跑，不允许变成永久延迟创作。前置步骤已经在当前线程、作品简报或可靠材料中完成时，直接继承结果并进入候选生成，不重复讲一遍方向。完成前置步骤以后仍只交`核心问题、语言动作、意象方向`，却没有实际中心句或局部成品，判为选题没有调用下游能力。

0. **建立三角对标**：除用户给出的主对标外，补一首同题异写代表作和一首同技法异题代表作。若无法确认具体作品，先搜索；不得只凭模型印象编造歌词或创作方法。
1. **记录首轮联想**：把第一批场景、物件、职业、态度和结论当作类型基线。它们不是永久禁用词，但必须与代表作和现实材料比较；只有最准确、最必要时才保留，不能因容易想到就自动推荐。
2. **完整拆解对标**：同时分析人物关系、生活发现、情绪因果、段落功能、重复策略、修辞动作、句式长度、押韵与声音推进。不得只抽象“原作写了失恋”，也不得只列不能复制的物件。
3. **制作迁移表**：分别写出可以保留的方法、必须变形的组合和不可照搬的具体表达。保留技法时说明它完成什么；变形时至少改变对象、语义推进、段落位置、节奏或结论中的两项。
4. **锁定母问题**：先用普通话写清原输入真正值得保留的关系，不保留原作的具体物件和漂亮说法。例如保留的可以是“一方已经改变决定，另一方仍按原约定等待”，不能只写“失恋后的残留感”。母问题负责保证后面的跨域路线仍在回答同一个人性问题；写不清时继续拆对标，不急着发散。
5. **完成全景扫描**：内部沿十个变形轴寻找候选：人物与演唱对象；时间与时代；空间与生活制度；文化母题、古典文本与神话原型；观察视角与双方知道的信息；人与人、人与自己、人与制度、人与时间等冲突；意象系统；口语、民歌、古诗体、散文体、戏剧独白等语言传统；独唱、对唱、重唱与声音关系；目标受众、使用场景和传播动作。扫描是为了发现此前没看见的作品可能性，不是把十个轴逐项展示给用户。
6. **按审美距离形成路线**：至少形成近距、中距、远距三类内部候选，必要时补一条与主对标情绪出口或结构相反的路线。近距保留题材、人物关系和现实语域，改变观察角度、事实与冲突焦点；中距保留母问题，改变时间、空间、视角、语言传统或演唱形式中的两至三项；远距只保留人性关系，进入古典、神话、历史、寓言、职业、公共生活或另一种戏剧传统。审美距离不是质量等级：近距通常首听成本低，远距可能更有作品身份，也可能只剩猎奇和资料负担。
7. **检查迁移是否改变作品**：古代、神话、异域、赛博、方言和类型流派不能只提供名词与布景。新领域至少要改变人物能做什么、谁先知道、谁有决定权、必须付什么代价、用什么语言才可信或结尾为何不同中的两项。把合同换成婚书、地铁换成驿站、分手换成断红线，但人物的行动、责任和结局没有变化，仍是换皮。涉及原典、历史制度、地域习俗和文化持有者时，先核实；没有依据只能列为待研究路线，不能装成已经成立。
8. **生成有来源的路线**：从全景扫描、对标比较、用户材料、可靠个案和明确标注的创作假设中形成内部候选。每条必须改变关系因果、观察位置、现实规则或声音结构，不得只换物件、地点、职业皮肤和情绪强度。路线标签只负责内部导航和必要比较，优先写人物动作、关系处境或主要冲突；不得把未经歌词证明的金句、中心句或工作歌名放在路线标题中，也不得用“拿回自己、体面离开、收拾残局、学会放下”等可套用结论代替路线。必须先写清人物、动作、阻力和后果，再给路线命名。若没有用户材料支持具体场景，路线只能写“需要调查什么”，不得直接列出门锁、导航、账号、生日提醒、两人份物品等类型库存。
9. **建立竞争解释**：先把文本能直接确认的动作、物件状态、称呼和句式列出来，再为同一组证据提出至少两种因果不同的解释。分别写清每种解释能说明哪些文本、还要额外假设什么、需要哪条人物材料才能成立。反常、未完成、责任变化和人物两难只能作为待检验问题；不得把“东西还在”直接解释成有人必须善后，把“动作没完成”直接解释成分手突然，把“歌者追问”直接解释成双方共同决定后由一人承担后果。
10. **确定本作新增的认识**：不用金句，用普通话写清这首歌相对于同题作品让听众多看见了什么。新认识不能是原作明说内容的摘要或近义改写；原词已经写“你教我勇敢”，新作再写“我被你改变”只完成复述，没有新增。有效发现至少由两处彼此分开的材料共同推出，并改变时间顺序、责任归属、知识差、关系解释或人物下一步行动。若答案只是“分手很痛、要学会放下、被爱改变、没有好好告别”，继续寻找更具体的误解、时间差和人物代价；不得把题材常识冒充发现。没有这些材料时，只能提出待确认的事实分支，不能先替人物补出“他早就知道、他一直在等、他已经开始离开”之类的心理和经历。
11. **做全歌与传播推演**：每条路线都要说明主歌怎样取材、副歌完成什么语言动作、桥段或结尾增加什么，哪套意象与语言只属于这个人物；同时预测目标听众第一遍能否进入、哪一句或声音动作可能被记住、适合独听、合唱、影视、短视频还是现场，以及为了这项传播机会牺牲什么。没有真实数据时只写“更可能”与依据，不把传播潜力说成必然结果。
11a. **叙事型路线追加戏剧推演**：先确认作品确实依靠事件推进，而非抒情、宣告或仪式性复沓。开始核实历史细节或评价结尾以前，必须先列出用户材料中的戏剧资产：主矛盾、人物主动目标、不能同时保住的两种价值、持续行动、信息差、竞争解释、不可逆选择、代价、突转、发现、结尾余震和传播入口。每项再拆成`字面设定 / 戏剧功能 / 情感功能 / 传播功能`。字面设定失真时，只能标为待查并寻找同功能替代；禁止把需要核实误判成应该删除，禁止用释怀、和解、继续生活或温柔告别自动替换强冲突。若用户给出`大将军`，可以核实并改造职位、功绩或转述方式，却不能顺手删除它原本制造的`升迁变心 / 战死留信`竞争解释；若用户给出极端行动，可以核实人物能力、时代条件、因果和伦理，却不能只因结局惨烈就改成人物被动承受。叙事推演必须继续写清人物原有秩序、触发、主动目标、阻力怎样反击、信息怎样流动、每段新增事实、桥段证据、人物在最高压力下亲手做出的不可逆选择、该选择付出的代价、最后副歌怎样变义和结尾留下什么后果。开放结局必须有两组前置证据，不能靠结尾突然藏答案。结尾若出现`他是怕她、他想让她活下去、她替他完成、她终于理解他`，必须另做动机归属和选择归属检查：没有原话、持续行为和后来证据，不得把善意猜测写成真相；主人公后来亲手作出的决定不得改写成执行另一人物早已安排的人生。涉及历史、战争、地域或职业时核实世界规则；未核实的报号、戏单、军制、名单、信件投递、称谓和行动手段只列为研究任务，不得冒充事实，但它们承担的戏剧功能先保留。完整方法读取[选题运动与展开机制](../../references/laohu-lyric-topic/07-选题运动与展开机制.md)。
11b. **用户补全故事后的差量分析**：用户把人物前史、战争或现实背景、持续行动、桥段证据和结尾设想补齐以后，不得只把材料压成一句命题，再列`有前史、有冲突、有承诺、有行动、有反转`。这些标签只能证明故事元素存在，不能证明它们已经咬合。必须逐项说明：新材料推翻或补足了此前哪项判断；主人公的行动具体改变了消息传播、他人反应、危险或代价中的哪一项；外部阻力怎样逐段反击；桥段的新证据支持哪些竞争解释；最后副歌中哪句因何变义；结尾选择怎样回收人物职业、爱情与公共处境；最强传播画面放在何处；仍需核实或补因果的地方是什么。完整故事不是减少分析的理由，而是进入整歌推演的准入证据。
12. **双门淘汰**：新颖但不可信、不动人、不可唱、文化上站不住或无法连接听众，淘汰；成立但任何人物都能套用、只是重复旧结论，也淘汰。再做整歌推演：主歌只能列物件、副歌只能喊态度、桥段没有新事实的路线，即使一句说明听起来漂亮，也淘汰。
13. **反向解压**：把候选压缩成一句中心句后，必须能还原它依赖的关系、事实或选定设定。若只剩“把自己拿回来、学会放下、终于释怀、勇敢向前”“我最后一个知道我们结束”这类可移植结论，或一句解释必须靠作者补充大量背景才能成立，判为路线标签或口号，不得冒充副歌核心句。人物材料未确认时，路线阶段只交付“待验证的语言动作/问题”，不交付看似已经成立的金句。
14. **相似性审查**：并排比较新旧作品的具体词句、细节顺序、比喻组合、问句推进、段落对应、韵脚排列和中心结论。共享一种技法不等于复制，也不构成自动否定；必须分别判断文字和情绪质量收益、听众熟悉度收益、作品独立性、相似风险、歌手与用途适配，再决定保留、改造或放弃。只有多项可识别元素按原作顺序协同重合时，才提高风险等级并继续改造。
15. **承担推荐**：先判断是否存在足以改变作品身份的未知事实。若不存在，公开一个主推荐，写清它保护什么、主动舍弃什么、最可能失败在哪里，以及什么新事实会让管理员改变判断；若存在，普通种子任务公开当前优先级最高的路线和由不同事实触发的强分支。用户正在学习创作方法、比较路线或明确要求全景时，对外优先保留三条真正不同的强路线：最容易接住原意的近距路线、最值得投入的中距路线、最可能建立作者身份但成本最高的远距路线；必要时以反向路线替换其中较弱者。只有对标文本时，公开“方法上的主推荐”和事实触发的强分支，不给某条新人物故事虚构证据优先级。每条都写清人物、材料、主歌、副歌、结尾、受众、传播场景、收益、代价和改判条件。不得把所有内部候选交给用户，也不得只留下一个空泛开放题，让用户从零替管理员完成专业思考。

只有对标歌词、没有新人物材料时，未知事实必然存在。此时可以明确推荐“保留哪种写法能力、下一步先验证什么”，不能把某条新人物故事叫作主推荐。对外至少给两条材料搜索路线，说明各自需要什么事实、会形成什么整歌，以及当前为什么还不能判哪条胜出。若系统推荐“对方把我训练成另一种生活方式”，又淘汰“对方改变了我”，两者关系因果相同，判为语义重复；不得靠换一组抽象词制造已经完成选择的错觉。

### 对外深度句的准入

选题分析中最容易冒充深度的句子，通常把人物、动作和事实压缩成一句抽象判断，例如“关系结束得比生活更快”“他提前退场，我最后才收到通知”“我在替两个人维持一段只剩一个人的关系”。这些句子可以帮助管理员在内部整理问题，但没有材料时不能直接交给用户当作发现、路线标题或副歌方向。

每次准备写出这种判断，先反向展开：

```text
谁在什么时间做了哪一个可观察的动作
→ 另一方当时怎样理解或误解
→ 哪两处材料证明这个理解后来出了问题
→ 这个问题怎样改变主歌材料、副歌追问和结尾动作
```

展开不出来，就改成普通的调查问题，例如“分开前，他具体少做了哪件以前会做的事？你当时把它当成什么？”不要用“撤场、退场、通知、维持、留下、算进以后”等抽象动词替用户补完尚未确认的故事。对外可以有凝练判断，但它必须能被前文已经确认的两处人物事实逐字解压，且大声读出来像当事人或创作者会说的话；否则只能标为待验证的内部假设。

这套程序不是要求每首歌故意生僻，而是阻止模型用最近答案代替作者选择。先指出用户灵感、对标或形式已经成立的部分，再指出风险和需要改造的地方；禁止为了反高频而先否定。具体材料采集、同题占位和验证方法，分别读取[灵感生成与材料采集](../../references/laohu-lyric-topic/05-灵感生成与材料采集.md)、[新意、时效与投入判断](../../references/laohu-lyric-topic/12-新意时效与投入判断.md)和[验证主持与阶段交接](../../references/laohu-lyric-topic/13-验证主持与阶段交接.md)。

## 对标学习：灵魂、骨架、血肉和语言都要拆

用户提供对标作品时，不得只说“学它的底层，不学它的表面”。表面技法同样是作品能力的一部分，只是要拆清后迁移。

| 层次 | 必须回答 | 可以怎样迁移 |
| --- | --- | --- |
| 生活发现 | 它把哪种常见经历说得比别人准确 | 换人物与事实后，继续追求同等命名精度 |
| 人物关系 | 谁想从谁那里得到什么，权力与责任怎样分配 | 改变关系位置、演唱对象或知道的信息 |
| 情绪因果 | 哪件事实先触发什么理解，怎样进入动作、身体和防御 | 保留递进强度，重建触发与结论 |
| 信息与结构 | 听众先知道什么、哪些材料重复、高潮怎样到达 | 保留信息职务，重新比较段落名称、材料顺序、比例与回归方式 |
| 修辞动作 | 追问、排比、复沓、对照、比喻在逼谁做什么 | 可以沿用修辞类别，重写对象、问题层级和语义走向 |
| 句式与声音 | 长短、停顿、重音、韵脚、元音和重复怎样制造可唱性 | 保留听觉原则，不逐行复制字数、句法和押韵地图 |
| 传播设计 | 哪句最易记，为什么重复后意义更重 | 复用“记忆怎样形成”的方法，不改写原句 |

连续追问是典型的可迁移技法。分析时要画出每一问的语言动作：第一问在追责任，第二问在逼对方承认代价，第三问是否从关系升到身份，最后一问是控诉、请求还是自我暴露。新作可以继续连续追问，但必须重建问题对象、递进顺序、句法节奏、韵脚和最终落点；禁止把原作的“怎么—怎么—难道—若”逐行换词。

### 对标证据必须落到文字动作

引用作品名不等于完成研究。每个被拿来支撑路线的作品，至少拆出一处具体文字证据，并回答：

```text
原句或明确段落位置
→ 主语、动词、宾语和关键修饰怎样安排
→ 这组词让人物对谁施加了什么关系压力
→ 停顿、重音、押韵、复沓或音节怎样帮助听众记住
→ 新作保留哪一种语言能力，换掉什么人物事实、对象、顺序和结论
```

不要只写“这首歌很克制”“那首歌很有画面”。例如分析生活细节时，要说明一个动作如何替人物证明关系；分析连续问句时，要逐问说明它是在追责、求答、逼近身份还是暴露软弱。不能只把作品名摆在段首，再用“因此值得参考”结束。

前人的句式、词性、动词力度、语序、重音和韵脚都是学习对象。研究它们不是逐行仿写，而是找出它们在当前人物口中是否仍然完成同一个语言动作。高水平作者的简洁是删掉无功能的字，不是减少信息；对标拆解必须同时检查文字质量和相似风险。

对外分析对标时，优先使用下面的最小证据段，不得只写作品名和评价词。没有可靠原文或具体位置时，不把该作品写成已经证明当前路线的依据；只能明确标为待核实样本，降低判断强度。

```markdown
### 【作品名】｜【创作者】｜【主歌/副歌/桥段/具体位置】

- 具体证据：引用必要短句，或准确描述该段的逐句动作。
- 文字怎么工作：指出主语、动词、词语轻重、语序、停顿、重音、押韵或重复怎样制造关系压力。
- 为什么有效：说明听众因此看见了什么、记住了什么、愿意跟唱或借用什么。
- 当前怎么学：保留哪种语言或结构能力，换掉谁、什么材料、什么顺序和什么结论。
- 代价与风险：保留会得到什么，改变会损失什么，哪些重合会让新作像原作。
```

引用不够可靠时，把“具体证据”改为“待核实位置”，降低结论强度；不得用抽象评价补齐缺失证据。

完成拆解后制作三栏：

```text
保留：通用且适合新作的创作方法
→ 变形：值得学习但组合过于接近原作的部分
→ 避让：具体词句、独特细节组合、标志比喻、逐行结构和可识别旋律
```

“保留”不能只写抽象词，必须说明如何用于当前作品；“避让”不能把整类修辞一刀切。详细方法与理论边界读取[新意、时效与投入判断](../../references/laohu-lyric-topic/12-新意时效与投入判断.md)。

对标二创任务优先读取 `12-新意时效与投入判断.md` 和 `13-验证主持与阶段交接.md`；只要准备提出任何场景、物件、核心意象或故事动作，必须同时读取 `05-灵感生成与材料采集.md` 和 `06-中心句核心意象与故事核.md`。只有具体缺口确实涉及其他题材或展开时，再补对应 reference；不要在路线尚未交付前把所有题材与方法文件一次读完。

重要原创与二创任务在推荐路线前必须核实对标。用户提供的歌词没有作品名时，可以称为“用户提供的主对标文本”，但另外两类样本仍要检索到具名作品及可靠文本、创作者访谈、正式出版物或可信评论依据。检索不到时可以给标明暂定的路线，不得用记忆中最有名、标题最像或题材最宽泛的作品填满三角对标。

## 适用边界

出现以下需要时调用本 Skill：

- 用户只有一句灵感、一个概念、一段经历、一种情绪或几个零散画面。
- 用户想知道某个题材值不值得写、适合写成哪类歌。
- 用户有多个方向，不知道哪个更有作品价值、传播机会或个人优势。
- 用户需要确定歌手、听众、用途、视角、演唱形式、题材或内容切口。
- 用户已有初步命题，但同题作品太多，需要寻找新关系、新材料或新角度。
- 用户接受委约、征集、影视、品牌、行业、教育或舞台任务，需要先弄清限制和真实目的。
- 用户想判断一首歌有没有共鸣、传唱或市场可能，但还没有进入具体歌词评审。

以下任务不由本 Skill 主持：

- 方向已经锁定，用户要求写、续写、重写或修改歌词正文：交给 `laohu-lyric-writing`。
- 主要问题是旋律、曲式、和声、节奏、编曲或演唱设计：交给 `laohu-lyric-composing`。若只问“歌词是否需要预副歌、桥段或其他收窄段落”，先由 `laohu-lyric-writing` 判断信息职务，再调用谱曲 Skill 验证音乐条件；不得把标准曲式直接写进总线。
- 只讨论歌名或封面：分别交给 `laohu-lyric-title`、`laohu-lyric-cover`。
- 用户只询问一个概念时，可以直接解释，不强行把问答升级为作品立项。

## 主持权与辅助能力

选题阶段由本 Skill 主持，意思是最终要回答“这首歌写什么、为什么这样写、哪些选择已经成立”，不是只能使用选题知识。需要验证关键变量时，可以短暂调用：

- `laohu-lyric-writing`：试写人物口吻、局部场景或副歌核心句，检验命题是否能落成歌词；涉及副歌核心句的具体创作、传播记忆和候选淘汰时，由写词 Skill 读取其 `副歌核心句与传播记忆.md`，选题 Skill 不代替写词 Skill 发明或裁定金句。
- `laohu-lyric-composing`：分析已有旋律、伴奏或节奏的情绪、能量、曲式和声线限制，检验题材是否与音乐入口相容。
- `laohu-lyric-title`：生成暂定工作标题或标题句，检验中心思想是否集中、是否具有回归能力。
- `laohu-lyric-cover`：只在视觉概念会反向暴露人物、时代或使用场景不清时做概念试探，不提前制作正式封面。

每次辅助调用前在内部记录正在验证什么，完成后回到本 Skill 比较结果。对外只在结果中说明这项局部试验验证了哪个作品问题、带来了什么取舍，不播报 Skill 名、reference、路由或调用过程。局部试写可能揭示命题有问题，此时修改命题；不得为了保住已经写出的漂亮句子，反过来扭曲人物和主题。

## 核心判断：先找到必须被唱出来的关系判断

按下面的顺序建立命题：

```text
谁在唱
→ 这个人由怎样的年龄、经历、家庭、地域、职业和当前处境构成
→ 唱给谁、谁在旁听、彼此各自知道什么
→ 两者是什么关系
→ 作品以谁的经验为中心，歌者有没有资格替这个人或群体发声
→ 事情发生在什么时间、地点和关系节点
→ 哪个愿望、风险、矛盾或变化逼得这句话非唱不可
→ 人物怎样解释事件，身体、注意、行动冲动和防御因此发生什么变化
→ 从哪个角度切入
→ 作品真正追问什么，人物目前相信什么，什么事实正在反驳他
→ 情绪、认识或关系从哪里走向哪里
→ 哪个故事核、核心意象或中心句能够承载全歌
→ 作品将在什么场景中使用
→ 听完后希望听众记住、感到或做什么
→ 这段具体经验凭什么能连接到目标听众的共同处境
→ 已有旋律、歌手、委约和现实条件允许什么、排除什么
```

“写一首失恋歌”只有题材和情绪，没有命题。“一个总替别人收拾残局的人，第一次承认自己也想被留下；由成熟女声唱给那个从未回头的人听”才开始具备人物、关系、处境、动作和声音归属。

选题同时受六项约束：

```text
生活材料 × 作者真切感受 × 听众现实需要 × 歌手表达能力 × 使用场景 × 同题新意
```

不要让任何一项单独统治选题。只跟市场走，得到热点猜测；只跟感觉走，作品只对作者成立；只看声线，得到适合唱却不值得唱的歌。逐项校准，再决定保留哪条路。

把五个判断分开：

1. **题材**回答作品进入哪片生活领域，例如爱情、亲情、职业、家国或时代。
2. **立意**回答作品从具体事实和关系中发现了什么，它最终保护、质疑、承认或重新命名什么。
3. **发声范围**回答这是谁的声音：一个人、一段关系、某个群体、公共共同体或人类共同处境。
4. **公共性**回答不具有同样经历的人，能否通过人物的处境认出共同的人性、责任、利益或关系机制。
5. **传播力**回答听众是否愿意记住、借用、演唱、分享或在某个场景反复使用；它还受音乐、表达、歌手、媒介、时机和曝光影响。

这五项不能互相冒充。发声范围大，不等于立意深；公共词汇多，不等于公共性强；普遍价值成立，不等于一定传播。沿具体事实推到共同经验，不得从“时代、国家、世界、人类”倒推材料。具体方法见[立意层级与公共共鸣](../../references/laohu-lyric-topic/14-立意层级与公共共鸣.md)。

分清三个目的：

1. **创作者为什么想写**：可能来自亲历、观察、委约、研究兴趣、职业机会或长期母题。这决定投入意愿和材料来源，但不能自动成为歌词内容。
2. **人物为什么此刻要唱**：他遇到了什么，仅靠沉默、说话或行动已经无法完成什么。这决定作品有没有内在发动机。
3. **作品为什么要被做出来**：它要陪伴、表达、纪念、说服、教学、塑造角色、完成仪式、建立品牌记忆，还是进入独立发行。这决定它最终必须兑现什么。

三者可以不同。委托方要城市歌曲，是创作原因；返乡青年面对老站台开口，是人物原因；城市活动要外地游子传唱，是作品任务。不要把委托目的塞进人物嘴里，也不要只顾人物真情而忘记作品任务。

## 选题裁决顺序

所有检查项不能平铺打分。按下面四层依次判断，上一层未成立，不进入下一层精修：

### 1. 致命门槛

事实、授权、发声资格、人物知识边界和歌曲适配是否成立。关键事实失真、材料无权使用、歌者冒充当事人或内容根本依赖长篇说明时，命题直接返回调查或改题。返回调查时必须写清需要更换的是哪个字面实现、它原本保护什么戏剧功能、替代后如何验收功能没有丢失；不得把真实性检查当作删掉冲突、悬念和人物行动的总开关。

### 2. 决定上限的变量

作品是否拥有值得追问的中心问题、真实的情绪发动机、不可替换的材料、不能同时满足的需要，以及相对于同题作品的新发现。这里决定作品有没有继续打磨的价值，不能用歌手、市场和形式优势替代。

### 3. 项目适配变量

检查歌手、听众、用途、形式、旋律入口、传播场景、时间窗口和投入是否相容。适配只能让好题落地，不能把空题包装成项目。

### 4. 后续开放变量

准确措辞、韵律、段落细节、最终标题、旋律发展和制作选择可以在写词、谱曲与制作阶段继续解决。选题阶段只锁定会推翻作品身份的决定，不把尚需创作验证的问题伪装成答案。

### 语言精度与完整性

选题结论必须写出主体、关系、动作、条件和后果。不要只写“提升立意、增强共鸣、加强画面、表达高级”。把压缩词解压成一句完整的话：谁在什么处境下，因为哪件事，对谁做出什么选择，作品因此改变什么。

一段只完成一个判断，但要同时交代必要的依据、边界、例子或动作。复杂判断可以写长，不得用同义词和抽象名词堆出长度。删掉一句后，若事实、因果、取舍和下一步都不受影响，就删掉。

## 选题主持流程

### 第一步：接住现有种子

先提取已经存在的有效材料，不替用户补全：

- 明说或暗示的人物、关系与对象。
- 真实经历、生活细节、说过的话和反复出现的记忆。
- 创作者与材料的关系、独有入口、长期母题和可能自我辩护的位置。
- 用户最想保护的情绪、判断或作品气质。
- 已经锁定的歌手、旋律、用途、平台、委约条件和时间限制。
- 用户明确排斥的方向，以及排斥背后的原因。

指出哪一粒种子有生命力。保留用户的事实、动作和原话；不要把猜测写成用户原意，不要把口语整理成漂亮空话。

### 第二步：找到决定方向的缺口

只找最会改变作品身份的一至三个缺口。不要发送固定问卷：

1. 歌者：是谁在唱；他的年龄阶段、性别经验、地域、家庭、职业、教育、生活阅历、性格防御、语言环境和声音条件，哪些会真实改变这首歌。
2. 对象：唱给谁，或希望谁在旁听时被击中。
3. 关系：两个人、个人与群体、个人与故乡、职业、时代或自我之间是什么关系。
4. 处境：事情发生在什么时刻，什么已经改变，什么还来不及改变。
5. 核心需要：主人公想得到、保住、承认、告别、反抗或证明什么。
6. 主题判断：作品对这段生活究竟发现了什么，而不只是有什么情绪。
7. 用途：独立发行、影视、舞台、广告、教学、组织活动、比赛或私人纪念。
8. 听众：谁最可能把这首歌当成自己的话，他们在什么场景会听、唱或分享。
9. 新意：与同题作品相比，新在哪里；是关系新、材料新、角度新，还是用途与形式的组合新。
10. 材料：目前有哪些真实细节，哪些关键部分只能靠猜。
11. 入口：当前是先题后词、先曲填词、既有伴奏写 topline、委约命题、标题先行还是故事先行。
12. 运动：主人公从什么状态出发，什么使他失衡，最终关系、认识或行动发生了什么变化。
13. 情绪动力：人物怎样解释触发事件，它威胁什么需要或身份，又怎样进入身体、注意、防御和关系动作。
14. 中心问题：作品真正追问什么，人物目前相信什么，哪个事实正在反驳他，什么必须确认、什么不能提前解释完。
15. 作者位置：创作者凭什么接近材料，允许什么事实纠正自己，这次相对于长期母题新增了什么。

一次只问一个最能改变方向的问题。提问前先完成对标研究和能够由专业判断完成的部分，在内部比较不同路线并淘汰普通答案。对外先讲透当前证据足以支持的优先级；如果一个事实会在两条强分支之间改写人物关系，必须把分支和改判条件讲出来，而不是假装主方向已经确定。只有对标歌词而没有用户自己的故事材料时，默认不给单一路线，也不给任何人物故事排暂列第一：至少交付两条由不同人物事实触发的强分支，说明各自会如何改变主歌材料、副歌问题、桥段或结尾；当前优先级只能落在先保留哪种写法能力、先验证哪类事实，不能落在“替对方找理由”“对方早已告别”“人物还在等待”等未经证明的故事结论上。有效触发条件必须是人物关系、已经发生或没有发生的动作、时间节点、双方知道的信息、现实责任、歌手身份或作品用途；“想写得更克制、更狠、更成熟、更现代”只改变气质，不能单独生成一条分支。材料尚未成立时，把方向标为创作假设，并说明哪条新事实会证明或推翻它；不要让用户从空白开始替管理员想答案。

人物资料只收集会改变说话资格、语言质地、情绪分寸、生活材料和演唱可信度的部分。年龄要落到人生阶段、责任和时间感；家庭要落到权力、亲疏、亏欠、秘密和表达习惯；职业要落到观察、词汇、身体经验和风险。具体方法见人物身份 reference。

### 第三步：确认创作入口与约束

先判断作品从哪里开始生长：没有音乐的自由选题、已有旋律、已有伴奏或节拍、已有核心句、已有故事、明确歌手，还是一份外部简报。不同入口拥有不同自由度。

按入口分别处理：

- **无曲选题**：先确定人物、关系、处境、主题和用途，再让歌词结构与后续音乐共同生长。自由度最高，也最容易因为没有限制而写散。
- **依曲定题**：先听出旋律的情绪运动、重音、段落功能、呼吸长度、高潮位置和可容纳的信息量，再筛选与音乐相容的题材。不能把一份已经完成的文字命题硬压进旋律。
- **已有伴奏或节拍写 topline**：先判断律动、速度、音色、段落循环、能量曲线和声线空间，再用少量哼唱、节奏词或标题句测试人物口吻。此时题目必须经得起节奏与声音验证，不能只在纸面成立。
- **委约或征集命题**：先拆简报，再寻找既完成任务又能让人物真实开口的命题。委约提供边界，不提供作品灵魂。
- **标题、故事或人物先行**：检查这个起点是否真能支撑一首歌。好标题未必有内容，好故事未必适合歌唱，鲜明人物也未必在此刻有开口必要。

已有旋律时，不能先按文字喜好决定题材，再把歌词塞进去。先调用谱曲能力判断音乐的稳定与不稳定、明暗、速度、能量、段落反差、地域或时代气质，再决定哪些人物和情绪与它相容。具体音节、重音和逐句填配交给写词阶段。

面对委约、比赛、征歌、影视、品牌、行业或教学任务，必须把简报拆成八层，不能只抄关键词：

1. **硬条件**：时长、结构、语言、歌手、平台、交付格式、截止时间、版权和审核要求。
2. **核心任务**：这首歌必须让谁理解、记住、感到或做什么；只能保留一项最高优先级。
3. **偏好**：参考作品、音乐类型、气质、时代感和委托方喜欢的方向；偏好可协商，不等于硬条件。
4. **禁区**：事实、措辞、价值立场、品牌承诺、人物形象和文化使用中不能触碰的边界。
5. **隐含对象**：表面说给谁听，实际由谁审批、使用、演唱、转发和承担风险。
6. **矛盾要求**：例如既要庄重又要年轻、既要地方特色又要全国理解、既要品牌露出又不能像广告；必须指出冲突并提出取舍办法。
7. **调查对象**：哪些人、地方、行业、故事、产品事实或文化材料必须亲自核实，不能靠通用知识补写。
8. **交付与权利**：修改轮次、署名、独家范围、素材授权、使用期限、改编权和未来复用限制。

拆完后，用一句话说清简报真正要解决的唯一问题。若硬条件与核心任务互相冲突，先向用户说明，不进入选题包装。

### 第四步：校准立意、发声范围与公共连接

先用普通话写出这首歌对一段生活的判断。不要只写“关于爱、成长、乡愁、家国或时代”。判断必须落到人物、关系变化或价值冲突，并指出由哪组事实推出。

只有“悲伤、愤怒、治愈、释怀”等标签时，先读[情绪动力与心理运动](../../references/laohu-lyric-topic/15-情绪动力与心理运动.md)。拆出事件评价、核心需要、身体、行动、防御和语言动作。没有这条因果链，立意就是作者贴给人物的结论。

形成初步立意后，补出中心问题、人物当前答案、反证事实和未决部分。立意写作品已经看见什么；中心问题保留人物仍未解决的拉扯。两者不能互相替代。

再判断作品替谁发声。确认声音属于当事人、关系位置、群体，还是公共共同体；确认材料能否承担这个范围，歌者是否有资格这样说。范围没有高低，选择最真实、最必要、最能保留差异、最适合用途的一层。

内部判断发声范围时，先比较三个不同纵深的候选，不把同一句话换成不同修辞后直接交给用户：

- **私人方向**：保留一个人的具体对象、秘密和不可替换细节，检验私密经验是否已经触及共同关系。
- **关系或群体方向**：指出哪些人共享相似位置、代价和需要，补足共同语言、共同记忆与内部差异。
- **公共或普遍方向**：说明这段经验怎样进入公共责任、历史记忆或人类共同困境，并核验事实、伦理与发声资格。

比较三条路时，分别写出依据、机会、材料缺口、代表性风险和传播机制，再淘汰普通方案。若同一缺失事实会让不同路线各自成立，公开“事实条件 → 对应路线 → 整歌后果”的分支，而不是把它们伪装成平级偏好；若当前材料已经明显支持一条，则只公开主推荐和会推翻它的新证据。不要默认选择范围最大的版本。具体方法见[立意层级与公共共鸣](../../references/laohu-lyric-topic/14-立意层级与公共共鸣.md)。

### 第五步：建立可生长的作品重心

创意回答这首歌为什么只能这样写。它至少要在关系、材料、观察位置或判断上作出不可替换的选择；只换意象、语气和形式，仍然是旧题。

把用户的方向整理成一句可以被检验的命题：

```text
这是一首由【歌者身份】唱给【对象/旁听者】的【用途与类型】歌曲；
它写【具体处境中的关系变化】，不是泛写【宽泛题材】；
主人公表面在【可见行动】，实际想【内在需要】；
作品从【独特角度或材料】切入，让【目标听众】在【使用场景】里感到/理解【预期结果】。
```

这句话只用于内部守方向。写不清时，退回关系、处境和主题，不要继续润色。

命题形成后，用局部试验检查四个锚点：能返回的副歌核心句，能持续变义的核心意象，只保留关键转折的故事核，能标记重心的工作标题。缺哪一项都可以，但不要为填表硬造；它们只负责检验题目能否长成可唱作品。

锚点不是漂亮附件，要分别通过检验：

- **中心句**：由这个人物在这个时刻说是否可信；删掉修饰后是否仍有关系和判断；如果属于副歌核心句，是否完成一个明确的语言动作，是否有冲突、声音重心和三次回归的意义变化；是否适合被唱、被记住、被别人借来表达自己。详细检查调用写词 Skill 及其 `副歌核心句与传播记忆.md`。
- **核心意象**：是否来自人物生活和关系，而不是从“高级意象库”或现代物件清单里抽取；它是否有私人来处、具体物性、关系动作和前后变化；它怎样改变人物行为，并在不同段落被重新看见而不只是反复点名。没有这四项，只能列为待调查材料，不能写成主歌建议。
- **故事核**：是否包含人物、愿望、阻力、关键动作和变化；删去背景后，仍能用两三句话说清发生了什么；是否适合在歌曲时长内呈现，而不依赖大段说明。
- **工作标题**：是否标记作品真正重心；听过歌曲后会不会获得比初见时更多的意思；是否与同题作品过度重合；若标题很好但换到另一首歌仍成立，说明归属还不够。

局部试写一次只验证一个问题，例如人物口吻或副歌返回。一次同时更换人物、视角、意象和语气，无法判断命题因何成立或失败。

### 第六步：检查运动与展开

选题不能只有静止的感受。写清主人公起点、触发事件、正在失去或争取的东西，以及结尾新增的认识、决定或关系变化。变化可以很小，但核心句每次返回都必须获得新上下文。

动笔前选定主要展开机制：

- **时间推进**：从事发前、当下到余波，适合有明确事件和不可逆变化的题目。
- **空间推进**：人物经过不同地点，每个地点揭开同一关系的一层，不得退化成景点清单。
- **动作推进**：围绕收拾、等待、归还、寻找、告别等连续动作，让心理变化附着在可见行为上。
- **关系揭示**：先让听众误判两人的关系，再通过细节逐步看清亏欠、权力、秘密或真正对象。
- **认识翻转**：事实未必改变，但人物对同一件事的理解发生变化；转变必须由前文材料引起，不能桥段处突然顿悟。
- **对象转换**：表面唱给某个人，后来听出也在唱给过去的自己、家庭或一代人；转换必须有铺垫，不能靠结尾拔高。
- **并置累积**：不同人物或片段共同证明一个中心，适合群体和公共题材；各片段要有递进，不是案例罗列。
- **回环变义**：同一句或同一意象多次返回，意义从期待、怀疑走到承认或决定；每次返回前必须新增事实或关系压力。

只选一项主机制，必要时加一项辅助机制。若题目只能靠增加意象、地点或道理撑满篇幅，退回重找展开动力。

### 第六步补充：分析句、命题句与副歌核心句不能混为一谈

选题阶段可以说明一首歌要写什么，但不能把说明句直接冒充副歌核心。三者的责任不同：

```text
分析句：把原作或材料的事实、关系和因果讲明白，允许展开。
命题句：规定新歌要写的冲突和结局，必须能指导整首歌。
副歌核心句：由人物在副歌里说出口，完成质问、承认、宣告、请求或反转，并且值得被重复和记住。
```

判断副歌核心句，不能只看它是否“有深意”或“像金句”。必须同时回答：谁对谁说；人物当下要对方做什么或承认什么；前文哪两组具体事实把这句话逼出来；句中哪一个词承担冲突和声音重心；第一次、第二次和最后一次唱到它时，听众为什么会听出不同的重量。

若一句话需要管理员解释一遍，用户才知道它在说“对方已经不爱了”“对方把我留作退路”还是“我当时听错了”，它最多是分析草稿，不是核心句。先把关系拆成普通话，再交给写词 Skill 做可唱、可记、可复唱的压缩。不要在选题报告里用引号、加粗或标题排版，替一句尚未审过的说明句制造金句身份。

副歌核心句的下限是第一耳听懂，上限是听懂以后还会刺一下。它通常至少具备一项真正的语言动作：预期反转、公开认账、关系判词、直接质问、无法回避的承认、可被听众借用的愿望。只是把主题换成一句更抽象的话，或把“我很痛”换成“你改变了我”，都不算核心句。没有冲突、没有对象、没有后果的句子，不承担副歌。

选题 Skill 负责确定核心问题和语言动作，写词 Skill 负责形成并淘汰正式候选。选题阶段可以给最多两句局部试验用于比较，但必须标明是在验证什么，不能顺手交付完整副歌或把管理员概括写成作品定论。

此处只锁定发展方向和适合的展开机制，不提前完成全部段落。需要通过局部段落验证时，调用写词 Skill；验证后仍由本 Skill 判断题目是否成立。

### 第七步：给出方向，不替用户偷做决定

每次比较方向时至少说明：

- 当前作品相对于同题作品唯一值得继续追的发现是什么。
- 这条路最强的作品机会是什么。
- 它需要什么真实材料才能成立。
- 它最容易滑向哪种套话或旧作品。
- 它适合怎样的歌手、听众和使用场景。
- 为什么推荐或不推荐，主动放弃了什么，什么证据会推翻当前判断。

如果路线尚未拥有私人材料，必须把具体物件、场景和人物经历写成“待调查问题”，不能写成作品事实；也不能用“共同生活在替他作证”“人还停在两个人的时间里”“关系往前推一层”这类作者自造的抽象比喻代替普通话。先说清谁在什么时刻发现了什么、因此做了什么，再决定是否需要修辞。

用户最终决定作品方向。管理员负责把差异和代价看清，不把“都可以”当作专业意见，也不因为自己有推荐就替用户锁定。

### 第七步补充：全景发散必须改变现实规则

用户要求从一个都市情感对标向古典、神话、历史、职业或其他流派发散时，至少比较以下几种距离：

```text
近距：保留当代关系和生活规则，只换人物事实或冲突焦点。
中距：保留母问题，换时代、制度、职业、空间或叙述位置，使人物的权力、知识和代价发生变化。
远距：把母问题放进古典叙事、神话母题、民歌传统、戏剧对白或公共关系中，重新决定谁有资格说、谁先知道、谁承担后果。
反向：不再站在被留下的人一边，改写成离开者、旁观者、共同责任者或曾经误判的人来承担主题。
```

这不是素材清单。每条路线都要具体说明：人物是谁；现实规则怎么变；主歌用哪两组材料推进；副歌要完成哪种语言动作；结尾新增什么认识或决定；听众从哪里进入；为什么值得承担它增加的文化和理解成本。把手机换成书信、把出租屋换成长亭、把分手换成神话人物的离别，如果人物关系、权力和行动没有变化，仍是换景，不是发散。

分析前先在内部检查至少五个发散轴：人物、时代或制度、冲突对象、语言传统、传播场景。对外不展示未经淘汰的知识树，只给三条真正不同的路线和一条明确推荐。若只有对标、没有新人物事实，推荐只能落在“最值得寻找哪类材料”上，不能替用户宣布一个新故事已经成立。

## 歌词常见的题材内容

以下分类只定位生活领域。用户选定题材后，读取对应 reference，继续拆人物关系、关系阶段、关键时刻、现实代价、材料来源和套话风险。不得停在题材名上创作。

一首歌可以跨题材，但只能有一个主关系。不要把宏大词并列成内容。

### 爱情题材

爱情题材先定两个人、关系节点和关键选择。初见、热恋、错过、背叛、分手、重逢、婚姻和陪伴都只是入口；“甜蜜、痛苦、遗憾”不能构成选题。

### 亲情题材

亲情题材先定关系方向和照护位置。力量来自习以为常的小事突然被看见；不要用“伟大、无私、温暖”代替人物做过的事。

### 友情题材

友情题材先定共同经历、关系压力和说话对象。没有这三项，就会退化成祝酒词和口号。

### 乡情题材

乡情题材先定故乡对人物的实际作用：归属、童年、亲人、方言、迁徙还是身份来源。不要罗列地名和风景；写清离开后人物在哪里被改变，又何时认出自己仍属于那里。

### 励志豪情

励志题材必须有具体阻力、付出和选择。“坚持、梦想、未来、相信自己”不能代替行动。让听众看见人物怎样站起来，不要命令听众振作。

### 山水风情

山水题材先定谁看见、为何看见，以及景物唤醒了哪段关系和生命经验。不要孤立描绘山水。

### 民俗风情

民俗题材先定谁生活在其中、习俗怎样组织关系、人物如何理解它。核实当地事实和文化边界；不要把服饰、方言、歌舞排成符号展览。

### 爱国热情

爱国题材必须由具体的人、处境和行动承载。地名、山河、旗帜和赞美词不能代替感情。

### 世故人情

世故人情题材必须从人物代价和关系中推出认识。先写人生格言，再配景，判为无效。

### 时代豪情

时代题材先写宏观变化怎样进入一个人的日常、身体、家庭和命运，再决定是否扩大到群体。新闻议题和口号不能代替人的感受。

### 怀旧题材

怀旧题材先定今天的人重新看见了什么：当时不懂什么，如今失去什么，记忆为何此刻回来。不要自动美化过去。

### 公益题材

公益题材先核事实、受助者尊严和传播目的。不要消费苦难，不把善意写成自我感动，不把复杂问题压成一句号召。

### 环保题材

环保题材必须有可核验对象和责任链。不要写“地球哭了、天空不蓝、保护家园”这类没有行动主体的套话。

### 动物题材

动物题材先定动物是故事主体、关系对象还是隐喻载体。拟人和象征必须建立在可观察习性或具体关系上；只把人类故事换一层可爱外壳，不算动物题材。

题材库只负责提醒。继续寻找尚未被准确歌唱的人群、关系、职业、技术变化和心理处境。

## 歌词选材的原则

### 写人们爱听爱唱爱传的内容

寻找许多人共同经历、却很少被准确说出的关系。共性不是让人人都能套用；用一个具体人的真经验，击中许多人共同拥有的位置。

### 写社会生活中最需要的内容

把“社会需要”落到谁需要、为何此刻需要，以及歌曲提供陪伴、命名、纪念、凝聚还是行动。热门事件不自动构成好选题。

### 写音乐市场最受欢迎的内容

研究听众、平台、演出和委约方的现实需求。市场判断必须有当下数据、案例或调查；旧渠道经验只能提供方法，不能替代事实。

### 写自己最熟悉、感悟最深的内容

优先写亲历、长期观察和真正理解的生活。陌生题材先调查、访谈、核实材料；不得用想象中的行业、地域和人群代替真实生活。

四条原则共同校准：作者感受提供真实，听众需要提供连接，市场和用途提供落点，歌曲特性提供形式。任何一条单独统治，选题都会失衡。

## 歌词选材的方法

### 做感受生活的有心人

从工作、家庭、路途、谈话、冲突和时代变化中记录触动人的瞬间。记录“谁做了什么，以及这个动作为何此刻变得重要”，不要只记物件。

当用户没有明确题目时，不凭空列“爱情、成长、梦想”让他挑。沿五类入口生成候选：

1. **人**：最近谁让他心里留下了东西；这个人与谁的关系正在变化。
2. **事**：哪件已经发生、正在发生或始终没有发生的事，让生活前后不同。
3. **物与地点**：哪个物件或地方保存了关系证据；它被谁使用、留下、归还、丢失或重新看见。
4. **一句话与一个动作**：哪句话后来才听懂，哪个小动作比表态更诚实。
5. **反常与未完成**：什么本该发生却没有发生，什么已经结束却仍在人的习惯里继续。

每个入口都继续追到“人物—关系—处境—欲望—阻力—变化”，只得到漂亮画面时不算形成选题。灵感候选优先吸收用户的生活和可靠材料；材料稀少时，主动补代表作、可靠个案和外部观察，形成标明依据与假设的内部探索路线，淘汰后再公开主推荐。路线不能冒充已经核实的现实人物命题。

入口不是最终答案。每次从入口开始，先记录高频方向，再通过代表作比较、用户材料、可靠个案或明确的虚构前提，提出几种能够容纳现有材料的解释。先比较哪一种解释覆盖的证据更多、偷加的故事更少、能让整首歌发生更有价值的变化，再寻找真正值得继续追的反常、未完成、责任变化或人物需要。没有真实材料时，仍要形成经过对标校准的内部候选并公开当前优先级，但必须标明哪些是文本事实、人物可能的解释、管理员推论和创作假设；不得把生活清单冒充洞察，也不得把一种顺滑推论冒充人物已经发生的故事。

### 建立材料可信度

选题依赖的材料分四级：亲历并留有具体记忆；当事人可靠讲述；针对具体个案或生活领域的可靠报道、田野调查和多方证据；作者基于题材、职业、对标或模型常识作出的创作假设。前两级可以承担现实人物核心，第三级可以建立环境与事实边界，第四级可以生成路线候选和虚构设定，但必须标注、验证并由用户选择，不能冒充真实经历。对标作品中的事实属于原作，不得换名后写成新人物的既有经历。

陌生题材先列调查问题，不先列修辞：人物每天真实做什么，哪些词他们会用或不会用，关系中的代价由谁承担，外行最容易误解什么，什么细节一旦写错会让当事人出戏。调查完成后只保留会改变人物、关系和主题的材料，不把资料搜集量当成作品深度。

### 写歌词与歌曲擅长表现的内容

歌曲善于集中抒情、反复咏唱、放大一句心里话，也能用有限情节建立处境。过多人物、复杂背景、连续反转和必须靠说明才能懂的论题，更适合先换媒介或大幅收窄。判断标准不是题材高低，而是它能否在有限时长中被声音直接接住。

### 从生活中发掘新意

旧题材可以写，新意不必靠离奇。先隔离第一反应，再依次检查：关系是否有别人忽略的一面，材料是否来自真实而少见的生活，观察位置是否改变，时代条件是否让旧问题产生了新后果，人物是否因此做出不同的选择。删除新物件、新技术、新地名和新风格后，关系判断仍必须成立；否则只是换皮。新鲜不是陌生名词，陌生化是让熟悉生活中被自动忽略的关系重新显形。

### 选好反映生活的角度

同一生活可以正面写、侧面写，也可以用“一滴水反映太阳”。先找最能显出主题的那个人、那个时刻、那个动作或那个旁观位置。角度越准确，作品越不需要面面俱到；角度越空，越容易靠概念补篇幅。

## 六条分类轴：不要把不同问题混成一种类型

一首歌可以同时是“爱情题材 + 双人对唱 + 第二人称 + 新词体 + 抒情歌词 + 影视插曲”。下面六条轴分别解决不同选择，不能只勾一个标签就结束。

需要选择具体形式时，读取[类型体式与演唱形式](../../references/laohu-lyric-topic/09-类型体式与演唱形式.md)。本节只辨认分类轴；reference 比较人物关系、信息分配、听觉效果和创作难度。

### 1. 以演唱形式划分

- **独唱歌词**：一位歌者承担完整视角和情绪，适合个人独白、叙事或鲜明人物声音。
- **对唱歌词**：两位歌者形成问答、呼应、错位或冲突；必须让双方各有欲望与信息，不能把同一段话机械分行。
- **重唱歌词**：两人以上各自承担声部和人物关系，歌词要给独立声部、交叠与合唱留下位置。
- **表演唱歌词**：歌唱与动作、角色、情节结合，选题要有可表演的现场关系和行为。
- **歌舞曲歌词**：歌唱与舞蹈共同完成表达，内容、节奏和动作想象要相互支持。
- **吉他弹唱歌词**：强调个人表达、节奏清楚和自弹自唱的亲近感，常适合民谣式叙事与倾诉。
- **组合、小组唱与小合唱歌词**：需要考虑成员分工、群体形象、领唱与呼应，不是多人齐读独唱稿。
- **齐唱歌词**：多人同唱同一旋律，适合集体认同、共同记忆与易于统一表达的内容。
- **大合唱歌词**：面向大型群体、声部与舞台，内容需要足够的公共性、层次和气势，同时避免空喊。

### 2. 以演唱对象划分

- **男声演唱歌词**、**女声演唱歌词**、**童声演唱歌词**、**男女混声演唱歌词**，用于确认实际演唱者和声音组合。
- 不根据性别预设“男性只能阳刚、女性只能柔美”。真正决定表达的是歌手的音域、音色、年龄、经历、角色、表演能力和作品定位。
- 童声必须继续细分年龄、认知和语言能力；成人替儿童演唱，也不能用成人视角冒充儿童。

### 3. 以视角人称划分

- **第一人称视角歌词**：歌者是代言者，以“我/我们”承担经历，亲近直接，但必须明确这个“我”是谁。
- **第二人称视角歌词**：歌者是交流者，面对“你/你们”倾诉、询问、劝告、祝福或对抗，天然带有关系和现场感。
- **第三人称视角歌词**：歌者是旁观者，讲述“他/她/他们”的故事，适合拉开距离、塑造人物或形成民间叙事。

视角不是代词选择。先问歌者站在哪里、知道什么、为什么有资格说、希望对象如何回应。不得在没有设计的情况下让“我、你、他”来回漂移。

### 4. 以写作体式划分

- **民歌体歌词**：吸收民歌的句式、衬词、复沓、地域语言与口头传唱特征；必须理解具体地域和生活来源，不能只贴民族符号。
- **古诗体歌词**：借鉴传统诗词的凝练、意境、音韵和典雅语言；要能被歌唱与听懂，不能把仿古词藻堆成伪古文。
- **自由体歌词**：句式与段落较自由，但仍受旋律、节奏、重复和可唱性约束，自由不等于散乱。
- **散文体歌词**：接近日常叙述和散文语言，容纳较自然的语气与长短句；仍需有声音中心和音乐组织可能。
- **新词体歌词**：以当代口语、现代生活和较灵活形式表达，重视新鲜语感、时代经验与个体声音，不把网络热词当成时代感本身。

### 5. 以艺术特点划分

- **抒情歌词**：以集中表达感情为主，情绪要有对象、原因和变化。
- **叙事歌词**：用有限故事承载关系与情绪，不能把完整小说压缩成事件清单。
- **乡土歌词**：来自乡村、土地、地方劳动和生活经验，重在真实关系与地方语言，不把乡土写成供城市想象的布景。
- **军营民谣**：从军人真实生活与情感出发，用适合其演唱场景的形式表达战友、家国、责任、离别和柔情，避免口号代替生活。
- **校园歌词**：写特定成长阶段的友谊、学习、初恋、身份变化与共同记忆，语言和处境要属于当代学生。
- **诙谐歌词**：以人物误会、生活反差、语言机锋和自我暴露产生幽默；笑点要服务人物与主题，不靠贬低群体。

### 6. 以歌词用途划分

- **电影歌词**、**电视剧歌词**：服务人物、剧情、主题与视听节奏，同时应争取脱离剧情后仍能独立成立。
- **唱片歌词**：原意是面向歌手录制和发行的作品；今天应理解为独立单曲、专辑或艺人项目，核心是歌手定位与长期作品资产。
- **广告歌词**：在严格时长内传达品牌或产品的关键利益与记忆点，必须准确、凝练、可识别，不把说明书押韵。
- **教材歌词**：服务学习、认知、审美和年龄发展，内容必须准确、适龄、可教可唱。
- **舞台剧歌词**：必须由人物在特定戏剧情境中唱出，承担行动、冲突、转折或人物揭示，不能成为剧情暂停后的主题说明。

今天还应补充短视频、流媒体、游戏、动画、虚拟 IP、现场演出、音乐综艺、品牌内容、私人定制和社群共创等使用场景。新增用途时仍然追问：谁委托、谁使用、在哪听见、需要完成什么、时长与权利边界是什么。

## 不同类型歌词的选题要点

这些类型会同时改变题材选择、语言期待、歌手能力和使用目的。此处只负责选题校准，具体写法交给写词 Skill。

### 通俗歌词

内容趋近现代生活和平民日常，常面向流行音乐听众，强调新颖、自然、不落俗套。选题时把握三点：

- **语言力求通俗时尚**：寻找当代人真实使用又适合歌唱的语言；时尚不是堆热词，而是听得出人物生活在今天。
- **内容贴近生活潮流**：优先捕捉当下人的关系、工作、迁徙、娱乐和压力，不用冠冕堂皇的大道理覆盖个人心声。
- **感情务必真挚浓烈**：爱情、友谊、亲情和乡情可以反复写，但必须来自具体人物的真处境，不能只提高情绪词强度。

### 艺术歌词

常为美声、民族唱法、音乐会或声乐学习而作，重视诗意、内涵、情绪起伏、民族语言和声乐表现空间。选题需要有值得反复咀嚼的精神内容与意境，同时必须一听能进入，不能用华丽赞美词冒充艺术性。

### 影视歌词

- **影视剧歌词**：先读剧本、大纲、人物小传和导演意图，分清主题歌、人物歌、插曲与片尾歌各自任务。主题歌可以概括或抬升全剧，插曲可以从侧面丰富人物、转换情绪或推动剧情。
- **电视晚会歌词**：完成晚会主题，同时找到离开这台晚会仍然成立的人生关系与公共感受。不得困在活动口号和一次性事件里。

两类作品都要为具体视听任务服务，也要争取脱离原场景后仍有独立生命。

### 行业歌词

包括校歌、司歌、厂歌、院歌、行业歌、社团歌、社区歌和城市、园区、景区歌曲。必须满足委托目的，写出组织的真实特点、历史、地域、职业使命和共同精神；又要从具体单位中提炼普遍的人与价值，不能把名称、口号、成绩和业务范围排成歌词。

### 广告歌词

根据品牌、产品、传播时长和受众量体裁衣。选题先锁定唯一核心诉求：听众要记住品牌、产品利益、使用感受还是品牌态度。时长越短，选择越要集中；必须核验广告主张，不能为了押韵虚构效果。

### 儿童歌词

寓教于乐、富有童趣。先细分年龄、认知、语言、动作能力、演唱者和使用场景；两岁幼儿、低年级儿童与青春前期孩子不是同一受众。材料从儿童真实生活、游戏、提问和观察中来，站到孩子的眼睛里看世界，不用成人训话配几只小动物冒充童心。

### 摇滚歌词

适合直面现实困惑、个人处境、社会关系和价值冲突，以直接、坦率、强烈的自我声音表达。选题必须有真实要反抗、追问或争取的对象；愤怒和宣泄只是能量，不是主题，最后仍要落到人物为何不能继续沉默。

## 受众：不是人口标签，而是共同处境

需要建立具体听众、聆听时刻、分享动作或歌手适配判断时，读取[受众场景与歌手适配](../../references/laohu-lyric-topic/08-受众场景与歌手适配.md)。

了解受众，是为了知道这首歌替谁说出什么、会在什么时刻被需要，不是为了迎合一张刻板画像。

### 不同音乐受众群的划分依据

可以从年龄、地域、职业、文化程度与经济状况开始划分，但今天还必须观察：

- 人生阶段与家庭角色。
- 城市层级、迁徙经历与文化归属。
- 日常工作和压力来源。
- 听歌平台、设备、付费方式与发现路径。
- 独处、通勤、KTV、短视频、演出、仪式或亲子等使用场景。
- 共同记忆、语言习惯、审美参照和不愿被怎样描述。
- 谁是听众、谁是演唱者、谁是付款者或委托者；三者可能不是同一人。

### 不同类型受众群的观察入口

- **都市青少年受众群**：关注身份形成、同伴关系、流行变化、独立愿望、学业与初入社会的压力。原有“都市引领全国潮流”的结论受媒介时代影响，今天必须重新调查平台社群、城市与下沉市场之间的传播关系。
- **中年老年受众群**：关注家庭责任、身体变化、旧日记忆、代际关系、退休与重新寻找生活位置。不能默认他们只爱怀旧或不接受新音乐，应区分成长年代、教育、地域、技术使用和真实场景。
- **城镇乡村受众群**：关注地域生活、劳动方式、家庭网络、迁徙与城乡经验。城乡不是审美高低之分，网络也已改变旧有传播顺序；必须研究具体地区，而不是用“朴实、乡土”笼统代替。
- **漂泊打工受众群**：关注离乡、异地劳动、身份落差、住房、收入、爱情、亲情、尊严和回家。真正的共鸣来自他们认得出的工作细节、生活语言与现实矛盾，不能只写泛化乡愁和逆袭口号。
- **部队官兵受众群**：关注纪律与个体、职责与柔情、战友、家庭、退役记忆和具体演唱场景。必须以真实资料为基础，区分队列齐唱、舞台艺术歌曲、个人弹唱等用途，不把军人写成只会说口号的符号。
- **少年儿童受众群**：按年龄和发展阶段继续细分，并同时研究家长、教师、学校或平台的使用要求。儿童既是听众，也可能是演唱者；选择内容时要兼顾趣味、认知、动作、重复、准确性和长期影响。

这些只是观察入口，不是今天完整的固定市场。遇到新的职业、少数文化社群、驾车通勤者、游戏玩家、虚拟 IP 粉丝、银发学习者等人群，应重新调查其生活和需求，不把人强塞进旧分类。

### 受众命中检验

不要只写“面向年轻人”或“适合大众”。至少回答：

```text
他们共同经历什么
→ 哪个时刻最需要这首歌
→ 哪一句生活事实会让他们认出自己
→ 他们愿意自己唱、旁听、分享还是只在特定场景使用
→ 作品若换给另一群人，哪些内容会立刻失真
```

如果换一个年龄、职业、地域仍完全成立，说明受众画像可能只是标签，作品尚未真正进入他们的生活。

## 为歌手度身定做选题

有明确歌手时，选题不是给通用歌词贴上一个名字，而要先摸清这个人能把什么唱成自己的。

### 必须了解

- 唱法、音域、音色、咬字、节奏与现场能力。
- 既有作品、常用题材、表演风格和公众认知。
- 年龄、成长地区、经历、性格、兴趣与真实生活材料。
- 本人想延续什么、突破什么，哪些身份不愿再被消费。
- 目标听众、发布场景、合作方和作品用途。
- 独唱、对唱、重唱、表演唱、快歌、慢歌等基本形式。

### 延续与突破

为歌手选题要把握原有定位与创新之间的度：

- 延续的内容必须放大歌手真正拥有的优势，不能只复制旧作标签。
- 突破必须有声线、经历、表演能力或市场变化的依据，不能为了“反差”让歌手扮演不可信的人。
- 题材、视角和语言要属于歌者。完成命题后反问：这首歌像不像他会说的话，他为什么愿意唱，听众为什么相信由他唱。

禁止用性别、年龄、籍贯或外表直接推导人格和题材。它们是需要核对的条件，不是命运。真正的量身定做来自这个具体的人，而不是对某类人的成见。

## 用途与市场：先确定作品怎样被使用

面对外部简报、比赛、影视、品牌、组织或高成本项目时，读取[用途市场与委约简报](../../references/laohu-lyric-topic/10-用途市场与委约简报.md)；涉及作品寿命、竞争和投入取舍时同时读取[新意时效与投入判断](../../references/laohu-lyric-topic/12-新意时效与投入判断.md)。

歌词是一种会被演唱、传播和使用的文化作品。市场不是创作的敌人，但市场信息也不能代替创作判断。

旧有渠道包括音像、影视、电视节目、报刊、图书、广播、征歌、教材、演出、广告、企业音乐、网络和手机。今天处理任务时，不照搬旧渠道规模与旧消费结论，而把它们还原为四个必须核实的问题：

1. **发布载体**：流媒体、短视频、影视游戏、现场、综艺、教育产品、品牌媒介还是私人场景。
2. **使用者**：歌手、导演、品牌、学校、组织、创作者本人还是普通听众。
3. **完成任务**：独立欣赏、塑造艺人、服务剧情、教学、凝聚组织、品牌记忆、活动仪式或社交传播。
4. **现实限制**：时长、旋律、审核、预算、版权、交付规格、演唱难度与发布时间。

原有市场分类仍可作为用途清单，但需要翻译到今天的载体：

- **音像市场**：转为独立单曲、专辑、实体收藏与流媒体发行。
- **影视片市场**：扩展到电影、剧集、纪录片、动画、短剧和游戏中的主题歌、人物歌与插曲。
- **电视、MTV 节目市场**：扩展到综艺、晚会、音乐现场、音乐视频和平台节目。
- **报刊市场**：不再作为主要演唱渠道，可对应歌词刊载、专题策划、媒体共创与作品评论场景。
- **图书市场**：对应歌词集、曲谱、教材、IP 出版和跨媒介内容。
- **广播电台**：扩展到广播、播客、直播和音频平台中的节目歌曲与定制内容。
- **征歌比赛**：对应公开征集、赛事、城市与活动主题创作；先核对规则、权利归属和真实使用机会。
- **教材市场**：对应学校、幼儿教育、课程、考级和知识内容，准确、适龄与可教可唱是硬条件。
- **演出市场**：对应演唱会、音乐节、舞台、剧场、仪式和线下活动，必须从现场功能反推作品。
- **广告节目**：对应品牌广告、短视频、音频标识和商业内容，先锁定传播任务与可验证主张。
- **企业音乐市场**：对应企业、学校、医院、协会、社区、城市、园区与组织文化歌曲。
- **网络、手机市场**：今天已分化为流媒体、短视频、社交平台、游戏、虚拟 IP 与移动端互动场景，不能再视为单一渠道。

选择主攻方向时，结合作者和团队的生活资源、专业能力、合作网络、长期兴趣与真实机会。因地制宜、扬长避短是减少盲目投入，不是永远只写熟悉的一类；决定进入陌生市场时，先补调查、合作与试验能力。

任何“最受欢迎、市场很大、竞争较小、容易传播”的判断，都要使用当下可核验的信息。没有数据时标明为假设，并设计最低成本的验证方式，如访谈目标听众、分析近年代表作、查看平台使用场景或用局部样例测试反应。

### 区分单首机会与长期主攻方向

分开判断单首机会和长期方向。好题未必值得长期经营，长期方向里的每个题也未必值得写。

- **单首机会**看这一次：人物和材料是否成熟，现实窗口是否存在，歌手与用途是否匹配，当前投入是否值得。
- **长期主攻**看连续性：是否有稳定生活来源、持续观察能力、合作网络、审美兴趣、可积累的听众和足够多互不重复的命题。

遇到一次优质委约，可以接下但不改写长期定位；遇到长期喜欢却材料不足的方向，可以建立调查和练习计划，但不急着把第一首习作当代表作。

### 判断作品寿命

- **即时型**：依赖事件、热点、活动、发布时间或平台语境。优势是此刻必要，风险是窗口过去便失去解释力。
- **周期型**：在毕业、春节、婚礼、纪念日、赛事、城市节庆等时刻反复被需要。必须找到每次周期都会重新发生的真实关系。
- **常青型**：依赖长期存在的人性、关系与生活处境。常青不等于抽象，反而需要精确到能让不同时代的人认出自己。

寿命不是越长越好。一次现场任务可以只服务那个时刻；但必须知道作品为何会过期，并让投入、版权与复用预期与寿命相配。

### 判断投入与复用价值

高成本选题在进入完整写作前，至少核对：关键材料能否取得，事实与文化风险是否可控，歌手和使用方是否明确，音乐制作条件是否匹配，成功后能否用于其他演唱、发行、现场或内容场景，失败后研究与资产是否仍可复用。

投入不是只看钱，也包括采访、田野、授权、作曲、录音、沟通轮次和错过其他项目的机会成本。无法提高成功概率的精雕细琢不算必要投入；会决定人物真实性、任务兑现或长期资产的工作不能为了快而省略。

## 新意审查：不重复别人，也不重复自己

好创意的新颖、巧妙和独特，必须能指出具体差异。按以下顺序审查：

1. **关系新**：是否写了同题材中少见却真实的人物关系或权力位置。
2. **处境新**：是否抓住旧关系在当下生活中的新条件、新代价和新选择。
3. **材料新**：是否有只能来自这段生活的动作、话语、职业细节和共同记忆。
4. **角度新**：是否换了真正改变意义的观察者、时间点或叙述位置。
5. **形式新**：对唱、群唱、影视人物歌、互动场景等形式是否与内容互相需要。
6. **判断新**：作品是否提出了对这段生活更准确的理解，而不是只更换包装。

需要对标时，搜索同题材、同歌手、同受众、同用途的代表作。记录它们已经占据的核心关系、记忆句、意象领域和情绪结论，也拆解段落功能、修辞动作、句式组织、押韵、重复与高潮，再决定本作保留什么方法、改造什么组合、避开什么表达、补充什么发现。公共技法可以迁移；不得复刻原作的具体词句、独特意象组合、逐行句法与语义推进、韵脚地图、人物细节组合和可识别旋律。

以下变化不算新意：

- 把常见句子换成生僻词。
- 把地点、季节、物件换掉，人物关系没有变化。
- 为了反常而反常，生活逻辑不成立。
- 混合多个热门题材，却没有主线。
- 使用网络热词、方言或古风词便宣称形成风格。

## 选题成立性审查

形成候选命题后，逐项给出证据，不凭感觉打分：

### 1. 生活真实性

人物行为、关系和材料是否来自亲历、可靠讲述或充分调查？关键部分是否只能靠类型化想象补全？

### 2. 情感必要性

主人公为什么非在此刻唱不可？如果把情绪标签删掉，是否仍能从事件评价、核心需要、身体与行动、防御和关系后果中看见压力？情绪是人物被事实逼出的变化，还是作者预先选择的气氛？

### 3. 中心问题与主题价值

作品真正追问什么？人物当前相信什么，哪个事实正在反驳他？作品对这段生活已经发现了什么，又必须保留什么未决部分？它是在命名一个真实经验，还是把已有常识再说一遍？

### 4. 立意深度与公共连接

立意是否由具体事实、关系和代价推出？目标听众会通过哪一种共同处境、关系机制、身份记忆、价值冲突或使用场景认出自己？如果扩大了发声范围，作品是否有足够材料和资格承担，而不是在结尾添加宏大结论？

### 5. 歌曲适配

内容能否在有限篇幅中集中表达，是否存在可反复咏唱的情感中心？还是必须靠大量背景说明才能理解？

### 6. 歌手可信度

由这个人唱是否可信、可发挥、有意愿？歌者身份与视角是否错位？

### 7. 受众连接

目标听众能认出哪一处自己的生活？作品满足的是陪伴、表达、纪念、娱乐、凝聚还是行动需要？

### 8. 用途兑现

它能否完成影视、广告、舞台、教材、独立发行或委约的实际任务？脱离委约语境后是否需要独立成立？

### 9. 同题差异

差异落在关系、材料、角度或判断中的哪一项？如果只能说“更高级、更感人、更有画面”，判为差异尚未形成。

### 10. 材料充足度

现有素材能否支撑人物和主题？还缺哪一条事实、记忆、访谈或作品研究？

### 11. 反高频生成是否完成

是否记录了第一反应，完成三角对标与全层拆解，找到具体异常或可检验的创作假设，并形成了因果不同而非表面不同的候选？推荐是否说明借鉴来源、迁移动作和相似性风险，而不是先得到答案再补理由？未完成时可以继续提供研究和路线选择，但不能把探索路线判为正式命题。

### 12. 专业作品校准

主对标、同题异写作品和同技法异题作品分别说明了什么？成熟歌词创作者或歌词编辑最可能否决本命题的哪一处？本作继承了哪些关系、结构、修辞与声音方法，又在哪些具体表达组合上形成了独立作品？

审查后给出明确状态：

- **成立，可进入写词**：核心关系、主题、歌者、受众、用途和关键材料已经清楚。
- **方向有价值，仍需补一处**：指出唯一最关键的缺口，并继续引导，不先写完整歌词。
- **暂不建议写**：说明问题在题目本身、材料不足、身份错位、用途冲突还是同题无差异，并给出可救活的方向。

不要用总分掩盖致命缺口。歌手视角颠倒、事实不成立、材料完全缺失或用途无法兑现时，即使其他项目很强，也不能判为可写。

高成本、陌生题材或外部委约还要安排验证角色。不同人只验证自己真正知道的部分：

| 验证者 | 只让他验证什么 | 不能让他替代什么 |
| --- | --- | --- |
| 当事人或生活原型 | 行为、语言、处境和关系是否真实 | 文学价值与市场结论 |
| 歌手 | 这是不是他能相信、能开口、能发挥的歌 | 所有目标听众的反应 |
| 作曲者 | 命题是否有旋律、段落和重复发展的空间 | 题材真实性 |
| 制作人、导演或项目主创 | 作品是否适合整体声音、角色和项目位置 | 当事人的生活经验 |
| 委托方 | 核心任务、硬条件、禁区和交付是否兑现 | 公众是否一定喜欢 |
| 目标听众 | 能否识别自己的处境，是否愿意听、唱、分享或使用 | 创作者的全部专业判断 |
| 领域专业者或文化持有者 | 事实、术语、伦理、地域与文化表达是否准确 | 作品是否必须按其个人审美写 |
| 成熟歌词创作者或歌词编辑 | 选题艺术重量、同题差异、语言生长空间和歌曲适配 | 生活事实、群体代表资格和市场必然结果 |

验证前先写明问题，提供可以比较的候选，记录对方指出的具体位置和原因。只问“你觉得怎么样”，通常只能得到礼貌偏好。出现冲突反馈时，先判断双方验证的是否是同一件事，再由选题主持人按作品目的裁决；不得把任何一人的“喜欢”当成整首作品已经成立。

## 与用户的沟通方式

本节只规定选题阶段必须完成的专业交流动作。回复的人格、自然中文、解释深度、不同意见、模糊需求引导和发送前冷读，统一读取 `../laohu-natural-dialogue/SKILL.md`；不得在本文件另建一套通用沟通风格，也不得把下列流程原样写成报告交给用户。

选题阶段按“接住、命名、淘汰、押定、验证、收束”推进。每轮完成五件事：

1. 用自己的话说清目前真正成立的种子。
2. 指出这份材料中最值得保护、但用户可能还没有看见的关系或事实。
3. 明确淘汰最容易想到的方向，说明它会把作品写成什么旧歌。
4. 押定一个主方向，讲清它怎样改变主歌、副歌、结尾和听众记忆；存在强备选时才给一个对照。
5. 只把作品归属、真实经历或不可替代的审美决定交还用户，并说明什么新事实会改变当前推荐。

路线标题使用朴素标签，不提前表演歌词。例如优先写“按两个人的习惯过日子”“被对方改变以后”“这段关系没有说清”，不要写成带翻案、拟人、抽象债务或拼接比喻的金句。路线正文可以分析中心句可能承担什么功能，但局部试写必须另行标注，并交给歌词语言闸门验证。

不要发送调查表，也不要只说“补充受众、风格、情绪”。先完成判断，再提一个会改变方向的问题。例如：唱给离开的人，现有材料足以支撑一封没有回应的信；替同类经历者发声，还缺共同处境与共同语言。先推荐保留私人对象，再问用户是否确实要改成群体声音。

当用户只说“直接写、随便写、快一点”，而核心关系仍不清时，不交付完整歌词。可以给两句试探、一个局部场景或两种命题对照，帮助他感受差异；样例必须说明正在验证什么，不扩写成成品。

这条准入门不因用户催促、授权“先随便写”、承诺之后再改或要求“不要问”而失效。选题 Skill 负责拦截完整成品，沟通 Skill 负责把拦截说成人能接受的推进：先承认用户想尽快看到作品，再给局部验证和明确推荐，只把会改变作品身份的一个决定交给用户。没有人物、关系、处境和用途等关键基础时，任何完整歌词都属于模型替用户编造，不能当作探索稿交付。

用户已经提供足够信息时，不机械盘问。直接整理命题、指出判断依据和剩余风险，交给用户确认。

命题层以后采用渐进式创作讨论，不再把“选题”和“写词”理解成完全隔离的两间房。可以从工作歌名、副歌核心句、副歌完整试写、主歌场景、预副歌转折、桥段证据、结尾句、曲式或临时旋律中的任何一个入口继续；每次调用对应 Skill 产出与当前变量同等大小的真实候选，再把结果放回总线和其他乐段检查。选择`副歌核心句`入口时先停在一至两行，选择`副歌完整试写`入口时才写完整乐段，两者不得因属于同一副歌而自动合并。讨论形成的硬锚、软锚、淘汰句、段落职务、连接关系和副歌变体必须持续更新到[作品总线与跨阶段交接](../../references/laohu-lyric-topic/16-作品总线与跨阶段交接.md)规定的《歌词雏形板》，不能只存在于上一轮聊天解释里。

每轮讨论的最小成果不是“我们接下来围绕什么写”，而是：当前裁决、对应局部产物、保留或淘汰的证据、对其他乐段造成的变化和下一项最受影响的开放问题。用户提出的新句、新画面或新结构先视为候选，不机械服从也不推迟处理；先检查它是否让整首歌更准确，再决定成为硬锚、软锚或淘汰项。

## 阶段交付

用户确认方向后，先输出《作品总线卡》，再输出一份简洁但信息完整的《歌词创作命题》；持续创作还要在讨论中逐步形成《歌词雏形板》。总线卡不能被一句“核心主题”替代；命题是对总线的人物、材料和歌词任务展开；雏形板负责保存已经通过局部创作验证、能够直接交给完整初稿继承的结果。至少包含以下内容：

```markdown
## 歌词创作命题

- 一句话命题：
- 创作者与材料的关系、独有入口和可能偏见：
- 创作者动机、人物开口原因与作品现实任务：
- 题材与主关系：
- 歌者身份：
- 演唱对象、旁听者与知识边界：
- 目标听众与使用场景：
- 发生时刻、演唱时刻与使用时刻：
- 具体处境：
- 主人公的表层行动与内在需要：
- 触发事件、事件评价、矛盾需要、防御与主语言动作：
- 风险、代价与变化方向：
- 主要展开机制：
- 核心主题判断：
- 中心问题、人物当前答案、反证事实与保留的未决部分：
- 主要为谁发声：
- 发声范围与选择理由：
- 具体经验连接共同经验的路径：
- 公共意义与听众可参与的位置：
- 发声资格、代表性边界与拔高风险：
- 预期共鸣与传播机制：
- 听众的主心理功能与可观察使用动作：
- 独特角度与关键材料：
- 副歌核心句或中心句候选：
- 核心句的语言动作、具体依据与记忆重心：
- 核心句第一次、第二次和最后一次回归的意义变化：
- 核心意象与故事核：
- 暂定工作标题：
- 用途、类型与演唱形式：
- 创作入口与硬性约束：
- 预期寿命、投入与复用判断：
- 视角与大致语气：
- 必须保留：
- 明确排除：
- 尚未锁定但不妨碍写作：
- 尚需谁验证、验证什么：
- 专业作品校准结论与仍存在的审美分歧：
- 进入写词阶段最需要解决的问题：
```

《作品总线卡》至少包含：核心不可替代变化、主矛盾、主动目标、现实阻力、关键证据、信息与高潮顺序、不可逆选择、核心意象、语言动作、工作歌名承诺、声音承诺、视觉与传播承诺、主动舍弃、最大风险。字段按任务删减，但不能删掉会约束下游选择的因果。没有这些内容，不得声称已经完成选题交接。

字段按任务删减，不为了填满模板虚构信息。区分用户已经确认的决定、管理员判断和暂定假设；未确认内容不得伪装成锁定结果。

具体作品已经正式立项时，按顶层规则更新 `作品/<工作名>/创作日志.md`。普通讨论和候选默认留在聊天中，不擅自落盘。

交接给任何下游 Skill 前，确认对方不必重新猜测作品总线：谁在唱、唱给谁、什么事实打破什么秩序、人物要完成什么、阻力是什么、哪项选择不可逆、哪些材料真实、哪些方向禁止改变。交接文件必须附上该阶段要实现总线的方式和失配回流条件。结构、韵律、炼句、旋律、命名、视觉和传播由各自阶段完成，但不得改写总线而不回选题。

## 禁止事项

- 禁止把一个题材名称、一种情绪或几个意象当成完整选题。
- 禁止用情绪标签代替事件评价、核心需要、身体与行动、防御和关系后果。
- 禁止把立意写成唯一正确答案，提前消灭人物仍需面对的矛盾和听众参与空间。
- 禁止在关系、处境、歌者或用途会改变作品身份时直接生成完整歌词。
- 禁止用“大众、年轻人、女性、中老年”等人口标签代替受众研究。
- 禁止把旧唱片、彩铃、报刊和城乡传播经验当成今天仍然成立的市场事实。
- 禁止根据性别、年龄、籍贯和外表给歌手套固定性格与表达方式。
- 禁止用宏大概念、社会热点、组织口号和产品资料直接拼成歌词方向。
- 禁止把个人、群体、国家和世界排成作品质量等级，或默认发声范围越大越高级。
- 禁止用“替所有人发声”掩盖材料不足、群体内部差异和创作者没有代表资格。
- 禁止在私人故事结尾追加时代、家国或人类宣言，冒充立意升维。
- 禁止把立意深度、公共性和传播结果混成一个判断；传播预测必须说明具体连接与使用机制。
- 禁止为了市场迎合热点，也禁止以“真情实感”为由完全忽略听众与用途。
- 禁止把多个分类轴混成互斥选项；题材、形式、视角、体式、艺术特点与用途可以组合。
- 禁止把换词、换景、堆热词、仿古或故意猎奇误判为新意。
- 禁止用“有共鸣、有画面、有传播性、很高级”作结论而不指出具体关系、材料和机制。
- 禁止实质性复刻对标作品的具体词句、独特人物与意象组合、逐行语义推进、韵脚地图、记忆句和可识别旋律；不得以“改了几个字”替代独立创作。
- 禁止只对标最知名或最流行的作品，不区分市场结果、专业价值、历史影响和当前任务适配。
- 禁止把 Skill 边界理解成能力隔离；可以为验证选题试写局部内容，但不得在方向未确认时借试写偷渡完整成品。
- 禁止为了保留局部漂亮句、核心意象或工作标题，反过来牺牲人物真实性和命题方向。
- 禁止未经授权把用户明确锁定的强冲突、极端行动、高压现场、竞争解释、传奇性或结尾危险等级降级为安全结论。
- 禁止用“更写实、更克制、更高级、更有容量”掩盖换题；字面实现不成立时只能改实现，不得删除它承担的价值对撞、人物主动性、代价和余震。

## 交付前自审

提交命题前，先通过作品总线门：

1. 能否用普通话说清听众从开头到结尾经历的唯一核心变化，而不是列出几个并列主题？
2. 主歌、副歌、桥段、结尾、歌名、声音、视觉和传播各自怎样服务这次变化？
3. 哪个事实或动作负责把变化从“解释”变成“发生”？
4. 下游若提出另一条主矛盾，是否明确回流选题，而不是默默换题？
5. 删除气质词、宏大词和标题后，总线是否仍由人物、动作、对象、时间和代价成立？

再反向检查：

1. 这首歌写的是一个具体关系与处境，还是只写题材名称？
2. 用户原始材料中最有生命力的东西是否被保住，还是被通用方向覆盖？
3. 谁唱、唱给谁、谁旁听，三者是否清楚且视角不颠倒？
4. 受众是否有共同生活和使用场景，而不只是年龄或职业标签？
5. 推荐方向的优势、代价和材料要求是否说清？
6. 新意能否落到关系、处境、材料、角度、形式或判断？
7. 市场判断是否有当下证据；没有证据的内容是否标成假设？
8. 有没有把写词阶段的问题提前写成空泛答案？
9. 用户是否亲自确认了不可替代的决定？
10. 交给写词 Skill 后，对方是否还需要猜作品究竟是什么？
11. 人物身份是否具体到会改变他的观察、词汇、情绪分寸和说话资格，而不是一组人口标签？
12. 是否说明他在什么时刻会唱、会哼、会分享或会需要这首歌？
13. 若有强冲突，是否完成不可降级资产对照：现场、权力、动作、价值对撞、代价、悬念和传播画面没有被削弱？
14. 若采用写实、传奇或神话契约，核实标准是否与契约一致；没有用考据把戏剧改平，也没有用戏剧性掩盖因果空洞？
13. 选题是否存在起点、触发、风险和变化，核心句每次返回能否获得新含义？
14. 读取的 reference 是否都与当前缺口直接相关，还是把资料数量误当成判断质量？
15. 创作者想写、人物要唱与作品要完成的任务是否被分清，还是把外部目的塞进人物嘴里？
16. 创作入口、委约硬条件和既有音乐是否已经改变了选题判断，而不只是写在备注里？
17. 工作标题、中心句、核心意象和故事核是否经过各自检验，而不是因为一句漂亮便被锁定？
18. 是否区分单首机会与长期主攻，说明作品寿命、投入和复用预期？
19. 外部验证是否找对了人、问对了问题，并由主持人处理冲突，而不是做喜好投票？
20. 立意是否是一条由事实和关系推出的判断，而不是题材词、情绪词或正确价值词？
21. 是否把发声范围误当质量等级，未经比较便把作品推向群体、国家、世界或人类？
22. 一个具体人物的经验通过哪种关系机制连接共同经验，能否逐步说清？
23. 如果作品代表某个群体，是否核验了共同经历、内部差异、语言和发声资格？
24. 公共意义能否回指前文具体事实，还是只在结尾突然拔高？
25. 传播判断是否说明听众为什么会记住、借用、演唱、分享或反复使用，而不是把“有共鸣”当作证据？
26. 情绪是否能够从触发事实推导到人物评价、身体、行动、防御和关系后果，而不是一组气氛词？
27. 中心问题、人物当前答案、反证事实和未决部分是否清楚，还是人物只在证明作者结论？
28. 创作者是否拥有真实材料入口并允许事实纠正自己，还是只因题材流行便宣称有表达资格？
29. 听众需要是否落到状态变化、对象和使用动作，而不是“陪伴、治愈、共鸣”等功能标签？
30. 是否经过长期、当代与反向样本校准，并让真正熟悉歌词创作的人指出最可能写成陈词的位置？
31. 输入只有对标、没有新人物事实时，是否把“我更看好某个故事”误当成担当？若出现，删除故事排序，只推荐可迁移方法和优先验证的事实。
32. 是否把`习惯还没收到消息`、`解释系统还没坏掉`一类抽象拟人当成锋利？若出现，恢复具体人物、动作、对象和结果。

发现任何一项不成立，先回到对应环节继续讨论，不用一份形式完整的命题掩盖真实缺口。
