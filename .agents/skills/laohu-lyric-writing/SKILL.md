# 老胡歌词写作 Skill

歌词的第一任务不是把故事交代完整，而是让一个人不得不唱出一件关系中的事。故事可以在歌里发生，但必须服从这声开口；画面可以进入歌里，但必须把情绪变得可感。没有旋律时，先写出能被自然朗读、拍读和试唱的文字假设，不把纸面规则冒充成成曲结果。

## 交付契约与必经入口

起笔前先区分本轮交付的是分析引用、纯歌词，还是带演唱控制的生成包。任何作为作品展示的纯歌词，包括完整初稿和局部试写，都读取[歌词稿格式与乐段标签](../../references/laohu-lyric-writing/歌词稿格式与乐段标签.md)，按实际段落输出；用户另定载体时遵守该载体要求。讨论中引用一句歌词不因此强加乐段。生成包转谱曲负责人，不能用纯歌词格式删掉已授权控制。

发送前检查即将发送的最终正文，而非较早底稿：纯歌词按格式 reference 执行机械检查，语言按[改稿与交付验收](../../references/laohu-lyric-writing/改稿与交付验收.md)检查当前变更与整稿承接。所需阅读有截断就补读相关完整小节；只列文件名不算应用。无工具时逐项人工检查并如实说明，不把格式合规说成艺术质量通过。读取、候选取舍或检查没有完成时先补执行，不能靠“探索稿”豁免交付格式。

## 一、写词箴言：先立诗学公理，再读执行细则

下面六句是创作的最高层，不是禁词表，也不是逐句打勾的模板：

```text
情不空喊，景自成情。
叙事为情设骨，事实因心而现。
一字只领一意，数句共成深意。
借来的境，须换成此人的命。
能唱为骨，段落为势，语言为魂。
言不说尽，意不走失。
```

它们的执行含义如下：

- **情不空喊，景自成情**：不要先宣布“我很痛苦”，也不要先堆风月；先确定人物的关系压力，再让一个物件、动作、声音或礼俗显出它。抽象情绪词可以用，但必须有来处和明确职务。
- **叙事为情设骨，事实因心而现**：事件只有在改变关系、判断、责任、距离或代价时才进入歌词。允许叙事，禁止把时间线逐项报告一遍。
- **一字只领一意，数句共成深意**：一个字或词在当前句只承担一个主要情绪、关系或声音职务；深度来自句间回声、比喻属性、文化经验和未说死的部分，不来自事后给一个字追加多层解释。
- **借来的境，须换成此人的命**：学习古典意象、礼俗和对标技法时，保留它们的公共经验，换成当前人物真正承担的关系和代价。
- **能唱为骨，段落为势，语言为魂**：先保证句子有人声、段落有运动，再让字词完成文化重量、潜台词、回环和声音记忆。
- **言不说尽，意不走失**：留白省略的是听众能够依据承重词和关系补回的原因、责任或结局，不是删掉主谓宾后逼作者解释。

公理与细则的优先级：

```text
公理决定作品往哪里生长
→ 四层硬骨决定什么必须成立
→ 条件机制决定不同材料怎样落地
→ 声音规则决定怎样被唱见
→ 反向验收负责拦截已经出现的错误
```

细则不能把公理改成相反方向。若“更押韵、更古雅、更完整、更像画面”会让人物关系变薄，保留关系并回到上层重写。

歌词创新不以所有人都能接受为目标，也不以生僻词、怪意象和故意难懂为证明。正式创作前必须指出本作哪一项写法不能被同题歌曲替换：它可以是人物站在少见的责任位置、对常见关系作出不同判断、拒绝一个通常会被写成和解的答案、让同一句在回归时变成相反责任，或建立只属于这个歌者的句法与声音动作。第一遍能听懂只要求听众知道谁在说、在做什么、主要压力来自哪里；不要求听众立即同意人物，也不要求把冲突解释成安全结论。

改稿时把可唱、自然、清楚当作实现门，不当作磨平棱角的理由。一个不规则句长、突然停顿、刺人的判断、未回答的问题或不讨喜的人物立场若有事实、关系和声音支撑，先修咬字、句架和上下文，不自动改成对称、圆满和普遍正确。反过来，含混、生造和故意怪异若删掉后作品没有损失，不因“创新”获得豁免。

## 二、四层不是四份清单

四层从作品目的走到实际字句，是相互约束的能力，不是审美权重递减的四档。先修会使作品失真的断点，不等于语言只能在最后润色；材料、措辞、修辞和声音应在起笔时共同生成，也可以反向揭示更准确的关系与结构：

```text
灵魂：为什么非唱不可
筋骨：这一声怎样经过段落而改变
血肉：什么人、物、动作和文化经验承住它
表皮：什么字、句法、韵脚和气口让它成为歌
```

四层不是“全曲一套、乐段另起一套”，而是每一层先规定全曲共同目标，再向不同乐段延伸。主 Skill 必须直接保存这些高频生成判断；reference 只保存理论来源、标签歧义、扩展类型和案例，不能承接决定正文能否生成的核心规则。

乐段判断使用两个相乘的维度，不能把它们混成一张标签表：

```text
形式功能：Intro / Verse或Strophe / Refrain或Hook / Pre-chorus / Chorus / Post-chorus / Bridge / Link / Interlude / Solo / Breakdown或Drop / Outro
×
表达方式：演唱 / Rap / 念白 / 吟诵 / 齐唱或呼应 / 对白 / Ad-lib或Vocalise / 纯器乐
```

形式功能回答这一段在整首歌里做什么，表达方式回答它怎样被人声或音乐实现。`Rap Verse`继承主歌职务再接受 Rap 的 flow、重音和押韵要求；`Spoken Intro`继承前奏职务再接受念白语气；`Chant Post-chorus`继承后副歌职务再强化群体记忆；`Instrumental Bridge`仍承担桥段的对比与回流，但写词 Skill 只登记无词和交接，不虚构歌词。Hook 若只是歌节内的一句固定回环，按 Refrain 处理；若形成独立反复模块，按实际 Chorus、Post-chorus 或 hip-hop Hook section 处理。真实歌曲存在混合与模糊段落，标签只提供加权倾向，不是非黑即白的定义。

### 灵魂：先立一条关系命题

只写一条内部关系母句：

```text
谁在什么压力下，对谁承认、质问、让步、拒绝或承担什么，代价是什么。
```

它不是剧情梗概，也不是“思念、战争、爱情”这类标签。比如“我宁愿你负我，也不愿把你的生死交给一封无年月的信”是取舍命题；它不能原样放进歌词，必须继续压成可以咏唱的关系语言。

灵魂门先确定表达目的、歌者或声音身份、对象、材料边界与保护项。人物选择主导时再锁定主压力、选择和相应代价；陪伴、庆祝、吟唱或律动不强加不可逆后果。完整时间线、背景年表和场景清单留在创作档案，不直接成为歌词行位。

关系母句之后必须锁定歌者的立场与价值次序，不能只锁定第一人称代词。歌者可以是一个具体人物，也可以是边界明确的共同体；两者都要写清此刻最想得到什么、愿意为哪项选择承担代价、接受什么结果、拒绝拿什么充当替代、知道和看见什么，以及宏观世界中的哪件事会因此进入注意。外界身份与歌者的内心重心分开判断：一个人可以确实立功、被视为英雄，同时仍只是天地或时代中的一个具体的人；歌词不能因为外界身份成立，便自动围绕功名、评价和庆典组织。家庭、国家、战争和众生等背景只有经过歌者当下的见闻与取舍，才有资格进入第一人称歌词；作者或观众知道的全局不能借角色之口直接说明。

关系母句确定后，必须建立一份最小“关系事实账”：歌者与对象分别知道什么、选择了什么、误解了什么、仍不知道什么；哪些责怪、怀疑、请求、拒绝或原谅已经由材料建立，哪些只是作者为了增加戏剧性临时想到。歌词中的强关系词都要能追溯到这份账。疑问句同样会引入前提；问号不能把未经材料支持的怨恨、背叛或误解变成安全的留白。没有事实、人物认知或明确创作假设支持时，删除该关系冲突，回到已经成立的共同选择、失去和代价。

关系母句进入筋骨时，须转成各段的具体体验，按下文筋骨分支选择表达路径。写副歌前记录裸歌词应建立的中心感受和可回归表达；采用直接抒情时再说明对谁完成什么关系动作。主歌记录进入处境与出口感受，桥段记录选定的对比及回流。情绪名称不能替代这些选择，但不强迫每个乐段直接告白或改变判断。

#### 灵魂向不同乐段延伸

- **Intro / Cold open**：只让听众先撞见一个异常关系、声音、称谓或世界状态，决定“为何继续听”；不承担完整背景说明。无词前奏只登记它需要预示或遮蔽什么。
- **Verse / Strophe**：给全曲命题一个可以进入的处境，使压力被看见、听见、经历或逐步理解；可以叙事、白描和观察，不必完成最终关系动作。推进路线增加事实、认识、距离或代价；稳定路线验证感知丰富与持续收益，不以不变自动否决。
- **Refrain / Hook line**：把歌节中最值得反复的一项关系、判断、称谓或问题压成固定回环；它可以是歌节的一部分，不必拥有独立副歌的完整高潮。
- **Pre-chorus / Climb / Ramp**：把主歌尚可游移的感受变成不得不面对的压力，使副歌成为目的地；它不是第二主歌，也不必每首歌都有。
- **Chorus / 独立 Hook section**：建立本作可重复的感情、立场、感知或声音中心；直陈、景语与叙事按筋骨分支验收，不强制逐句命名情绪。
- **Post-chorus**：保存或放大副歌之后仍未消散的称谓、问题、答案、声音或高潮；可以提供收束，也可以成为副歌之后真正的能量到达，但不另立无关命题。
- **Bridge / Middle eight**：以本作需要的认识、感知距离或声音对比准备回归；纯音乐桥段不索取人物新决定，也不能只换新内容。
- **Link / Turnaround / Transition**：只负责保持、转移或重新导向已经存在的压力；没有独立灵魂命题。
- **Interlude / Solo / Instrumental break**：让歌词暂时退场，使某项旋律、声音、距离或未说完处得到空间；除非另有文字，不新增歌词命题。
- **Breakdown / Drop / Dance break**：暂停、抽空、释放或重置能量与身体感；若有文字，只承接已建立的口号、命令、称谓或碎片，不自动成为新叙事段。
- **Outro / Coda / Tag**：让人物的选择或中心声音在歌曲停止后仍留下后果；不再开启新的核心矛盾。

Rap、念白、吟诵、对白、齐唱和 Ad-lib 在灵魂层不获得独立命题，只改变谁能说、对谁说、距离多近以及共同体是否加入。若表达方式一换，人物立场和中心关系也跟着换掉，说明它不是修饰方式，而是新增了需要上层确认的歌者或对象。

### 筋骨：让段落改变同一件事的听法

默认运动是：

```text
主歌显形，预副歌收窄，副歌命情，桥段换命，尾声留痕。
```

这不是固定曲式。每段先确定听众在这里要获得什么，再选择相应的表达方式；材料有来源只证明可以用，句义成立只证明能读懂，两者都不能替代段落作用。关系作品应区分相邻感情，例如不愿忘记、希望重逢、怕被遗忘不能都用“放不下”代替。生成时指向裸歌词里哪一处称呼、句法、感知或声音使该感情被听见，不以作者给意象补出的寓意作为结果；陪伴、舞曲等改查安定、参与或持续，不强加关系选择。

副歌回归先选择变义、保持、累积或回接。下列仅为关系变义路线示例，不要求安定或仪式性重复采用：

```text
第一次：人物原来的愿望或自欺
第二次：新证据造成的防御或恐惧
最后一次：人物亲手承担的决定和代价
```

核心句若已获用户认可，默认锁定其表面文字；改变的是前文交给它的听法、对象、责任和停顿。要改核心句，必须说明新句增加了什么且得到明确授权。

采用关系闭合路线时，前两次副歌若反复留下同一个问句、否认、愿望或未完成判断，必须把它记入最后副歌的待处理项。最后副歌应当回答它、明确拒绝回答，或用人物的新决定改变它的含义；不得丢下原来的问题，另起一个漂亮意象或静态判断冒充变义。最后副歌所谓“新责任”，必须能还原为人物此刻承认、决定或继续做什么，不能只靠一个名词短语表示升华。

#### 筋骨向不同乐段延伸

- **Intro / Cold open**：建立第一个边界与期待，再交给首个核心乐段；可以取自主歌、副歌或独立材料，也可以直接 Chorus-first。前奏长短和能量主要由谱曲决定，写词只判断是否需要文字、文字交出什么、何处停止。
- **Verse / Strophe**：让听众先经历一项此人会注意的处境。可以用细节、感知、叙事、对白或直抒，但要由取景、语气与先后关系使听众产生具体感受；事实流水、物件清单或每个动作附一句寓意都不够。出口留下副歌可以承接的感受或认识，不抢先解释全歌结论。Strophe 可复用音乐，多段主歌不必同景；新材料应改变回归的来处，稳定路线则验证持续收益。
- **Refrain / Hook line**：作为 head refrain、tail refrain 或歌节内部固定句，随变化歌词反复获得新意义；若它已经形成独立完整模块，重新判断为 Chorus 或 Hook section，不能只凭“重复”命名。
- **Pre-chorus**：在核心循环内部把当前感受推到下一句；可用追问、承认的迟延、对象逼近、句法悬置或复沓聚焦，声音可共同承担牵引。必须说清接下来的副歌怎样完成或回应它；仅缩短句子、加重形容词、补背景或说“情绪升高”不算牵引。不需要时不添加，也不要求所有歌曲暗藏一个文字预副歌。
- **Chorus**：集中成听众愿意反复借用的感受、立场、呼唤、感知或声音中心。关系抒情先明确这一声是在舍不得什么、向谁求什么或接受不了什么，再比较人物直接开口与诗性实现；材料和比喻必须让这个中心更可感，而非逐句另开解谜。自问、叙事、景语、第三人称和含蓄表达都可成立，不以“我／你”、情绪词、高音或问号作资格。用裸稿确认中心感受与可记句架，而非靠点评才知道它在怀念还是悔恨；无音乐时不预支感染力。副歌可前置、延迟或与 Post-chorus 共担高潮，回归可变义也可稳定累积。
- **Post-chorus**：保留或放大前段已经建立的声音与感受，可缩为称呼、关键词、呼应或无词动机，也可成为实际高潮。新增长篇解释会使已经到达的感受退回说明；需要新命题时重新检查结构。它是否不同于间奏，要由实际回声、收束或高潮作用证明。
- **Bridge / Middle eight**：在核心循环之外改变此前的距离、观察、感情或声音，使回归被重新经历；可用自我推翻、向另一对象开口、当下与回忆对照，也可用纯声音对比。新增人物或事件只能作为触发，不能代替歌者如何受其影响。只在主歌与副歌之间反复牵引时，检查是否更像 Pre-chorus 或混合段。
- **Link / Turnaround / Transition**：短距离连接两个较大模块，保持、清空或重新导向动势；不能要求它完成一个独立段落弧线。
- **Interlude / Solo / Instrumental break**：中断或替代一段人声陈述，可借用 Verse、Chorus、Bridge 或新材料；写词结构卡只记录它替代什么、让什么暂停、回来后哪一句获得新空间。
- **Breakdown / Drop / Dance break**：按能量和质地完成抽空—蓄势—到达、释放或身体性重复；它首先是音乐结构，歌词若存在，只登记其在该能量轨迹中的位置。
- **Outro / Coda / Tag**：回收、缩短、重复、渐隐或停止已建立的字与声音，让听众带着同一感受离开。可以只留一个动作或尾词，不用总结道理，也不为凑歌名重新制造难解比喻；需要停留的作品不强制新结论。

段落边界与名称采用原型判断：重复歌词、旋律音区、和声、质地、位置、完整度和前后功能都只是加权证据。多个证据冲突时允许标记`Verse–Chorus blend`、`Bridge/Post-chorus blend`等混合角色，再说明本轮写词主要按哪项职务生成；不得为了标签整齐强行切段。

### 血肉：让情绪有可感的来处

材料进入歌词前先回答：人物为什么此刻看见或听见它；它改变了什么关系判断；它有什么准确物性、动作、声音或礼俗属性；删掉它损失的是情绪还是剧情完整。

材料不以“剧本是否已经写过”为唯一准入。歌词可以主动营造天气、光影、声响、器物和超现实景象，借它们的物性寄托人物难以直说的情绪。比较整段构思以前，每项意象先写清：它替歌者寄托哪一种具体感受；哪项物性与这份感受相通；歌者为何在此刻偏偏注意它；它在正文中属于字面景物、被情绪改变的主观感受、比喻象征，还是正在解释剧情原理的实际动作；它怎样在段内改变人物与对象的距离、判断或责任。前三类不必预先成为剧情事实，但必须让听众第一次就能辨认其身份，并由当前歌者与乐段赋予不可随意替换的意义；一旦意象开始说明法术、伤亡、因果或人物实际做了什么，就必须服从作品事实与动作逻辑。

凡候选会让听众把某项内容当成字面发生的场景事实，起笔前都必须建立一份最小“共享场景模型”，不能只在受伤、死亡等高压场面临时补账。模型至少包括：当前时间层及事件阶段；人物与关键物的位置、移动和接触；什么已经发生、正在发生、仍可能发生或已经不可能发生；谁能凭什么看见、听见、触到或知道；动作与结果之间需要哪些因果条件；用户最新修正、作品记录、旧稿和创作假设的优先级。候选中的动作、距离、声源、感知、身体状态、场景切换和因果结果都必须能从同一模型推出。推不出时先补事实或改为明确的主观感受、比喻和超现实表达；不得让押韵、反差、留白、类型常识或稿外解释替缺失事实取得资格。

共享场景模型随用户修正和正文推进同步更新。新事实与旧稿冲突时，先修作品记录再生成；回忆、倒叙、梦境和时间跳切必须由正文或已确认结构提供第一遍可辨认的边界。某项身体、天气、器物或声音材料若承担剧情证据，就服从相应的物理、世界设定与人物认知；若只承担抒情转译，则必须让听众听得出它是歌者的感受，并说明它为何偏偏属于此刻、此人、此段。这样既不拿写实逻辑误杀诗性，也不拿诗性掩盖字面事实矛盾。

画面不是连续分镜。一个画面可以只有一句，例如“我走在雨中”；后面完全可以转入抒情。画面是导火索，不是证据链。多个物件可以同时进入，但它们必须属于同一关系压力，并在回归时改变用途、位置、动作、对象、责任、距离或判断。

同一用意下不要只接受第一个具体物件。先比较真正可行的材料方向：私人小物是否确实属于人物生活，人物动作是否比物件更能显出关系，公共意象是否拥有足够文化经验和声音记忆。比较它们与命题是否相称、关系是否真实、能否承重、能否让更多听众进入、能否与其他材料共同推进，以及进入中文歌唱后有没有声音潜力。最后再做替换损失测试；稀有、细小和“只属于这个人”都不能自动判胜，常见和宏大也不能自动判俗。

抽象词、文化重量词和日常词都不是自动的好坏：`一生、余生、红尘、苍凉、沉痛、无言、思念`可以保留，只要它们在当前句有清楚的主要职务，并由关系或具体属性托住。禁止的不是某个词，而是用宽词代替尚未写清的内容，或用近义词把多种情绪糊成一个模糊状态。

#### 血肉向不同乐段延伸

- **Intro / Cold open**：优先一个可立即辨认的声音、称谓、关系碎片、异常动作或场景切口；可以无词。不得为了“交代清楚”塞入人物履历和世界观。
- **Verse / Strophe**：最有资格承载新歌词、场景、有限事实、动作、人物距离和叙事推进。材料可以公共、私人、宏观或微观，但必须形成情绪入口和段内变化，不能只是事实清单。
- **Refrain / Hook line**：使用能够经受多次重复和上下文改义的短关系句、称谓、问题、动作或意象；第一次就把含义封死的说明句缺少回旋空间。
- **Pre-chorus**：尽量复用主歌已经建立的材料，减少新人物、新地点和新事实；优先条件、让步、否定、接近的称谓、身体压力或尚未完成的问题。
- **Chorus**：优先公共情绪经验、承重关系词和零至两项已经建立的剧情锚点；允许宽词，因为主歌已经给它来处，但不能用宽词替代关系判断。
- **Post-chorus**：优先一个承重短句、称谓、问答、vocables、vocal chop 或已经建立的意象；若需要一整段新事实才能成立，它更像另一个核心段或桥段。
- **Bridge / Middle eight**：只引入足以使旧判断失效的新证据、称谓、事实或近处动作；新材料必须改变最后回归，不能只增加世界信息。
- **Link / Transition**：通常不增加核心事实；可使用短连接词、回声、Ad-lib、呼吸、空拍或前段残片。
- **Interlude / Solo / Instrumental break**：默认无歌词材料；若保留 Vocalise、采样或短句，只记录其声音身份与前后回声，不把它扩写成一段正文。
- **Breakdown / Drop / Dance break**：可使用身体指令、群体口号、碎片 hook、拟声、采样和高辨识度短词；抒情歌曲也可以完全无词，让失语本身承担关系压力。
- **Outro / Coda / Tag**：优先回收旧物、旧声、旧句或旧动作的新状态；新增材料必须证明它比已有回声更能留下后果。

表达方式会改变材料容量，但不改变乐段责任：Rap 能承载更高信息密度与内部押韵，不等于可以塞入全部剧情；念白可以保留更自然的句法和停顿，不等于可以写成解说词；对白允许多个说话者，不等于可以省略人物锚点；齐唱把私人句转成共同体声音时，必须先确认作品是否允许这项关系扩张。

### 表皮：让字句同时有语义、人声和回声

炼字不等于日常化，也不等于古雅化。判断词语时同时看它让人物以什么角度观察、以什么身份开口、让听者产生什么联想，以及它在句法、节奏和声音中完成什么。正常中文是语义关系可成立，不是搭配必须高频；准确但平直的释义可以帮助诊断，不能自动替换有身份、潜台词、修辞或声音记忆的原句。

重要新写，以及任何涉及语言风格、炼字、润色或表达退化的修改，起笔前读取 [表皮与语言声音](../../references/laohu-lyric-writing/04-表皮与语言声音.md) 的语言底稿与生成方法；本轮已经完整读过且未变化时复用。触发不以“已经有用户确认的核心句”为前提。原稿、用户指明的风格、实际材料和体裁都可建立底稿；尚未确认的选择标为暂定。涉及留白、双关或寓意时再读 [留白与修辞机制](../../references/laohu-lyric-writing/留白与修辞机制.md)，不以沟通层的白话标准代替歌词语体。

生成时先保护原稿已有的表达作用，再把同一材料从适用的观察位置、语域、词义、句法或声音方式中做真正不同的尝试。新写在最影响作品身份的关键意群比较至少两种实际文字实现；重要改稿比较原句、最小修复与另一种有依据的实现。内部保留胜出句、最强落选句及具体取舍，已有明确胜者就停止，不为每行凑候选，也不把过程表塞进正文。比较必须改变观察、关系或声音作用；仅换物件、反义词、语序或韵脚不能冒充不同构思。若优势只剩熟悉、整齐、容易解释，就回人物感受与材料重选；有实际陪伴、参与或声音收益的重复可以胜出，无音乐时不预支试听证明。记录哪一个词或句法改变了什么听法、哪项原有收益会损失，据此选择。生成与比较的具体步骤以该 reference 为权威。

全曲同声保护说话者、事实、立场与本歌已建立的语言范围，不把所有句子固定为同一种语气、词汇等级、观察角度和修辞。一位歌者可以转述体面话、用生活词顶回去，再露出私人迟疑；古雅与浅白、长句与短句、直说与隐语都按当地职务选择。变化必须能从正文或当前设计中接住；不为了多样性硬加语域，也不为了统一把有效差异抹掉。

每个记忆意群先还原为当前乐段允许的人声来源和实际职务，再压缩成歌词。副歌、桥段决定句和直接对白要能恢复谁对谁完成什么关系动作；主歌中的景语、感知、动作或必要事实，则要能恢复谁为何注意它、它怎样让关系压力显形。不是每一句都必须直接开口，但每一句都必须服务本段的局部四层；如果只能由作者解释“这个词代表很多情绪”，那是意义没有写出来。

本项目把歌词区别于分行散文和剧情概述的综合特征称为**歌性**。炼字是形成歌性的过程，凝练是语言结果，音律是声音结果；三者都不能单独代替歌性。歌性至少要求：整首歌存在可听见的关系主线；当前乐段按自己的职务使这条主线显形、收窄、命名、改写或留下余波；句架、重音、气口和韵脚形成可重复的声音秩序；保留下来的字同时承担语义、语气或节奏职务。主歌不因没有句句直抒而失去歌性，副歌也不能靠主歌式铺陈回避开口。押到同一韵而句架松散、重音落在虚词、段落职务没有推进，仍判为没有歌性。

词类不设配额。名词和动词通常交出人物、对象、动作与可感材料；能愿动词、副词、连词、助词、形容词和叠词可以交出可能、意愿、否定、转折、时间、范围、状态与节奏。生成候选后按`04-表皮与语言声音.md`圈出句法主干和全部修饰成分：每个成分必须改变一项彼此不重复的关系、时间、范围、立场或声音职务；两个以上条件、时间、范围或能愿成分连续落在同一主干前时，必须做累积负荷检查。删去某词后语义、语气和节奏均无损就删除；删后关系消失或人物立场改变则保留。不得把“多用名词动词”执行成机械清除虚词，也不得让语法垫料把承重动作推迟到句尾。

#### 表皮向不同乐段延伸

- **Intro / Cold open**：可以稀疏、悬空、无固定韵、念白、采样或一句高辨识度关系碎片；第一声必须建立声口，不能像作品说明。
- **Verse / Strophe**：允许较松的韵脚、较完整的句法、长短句和叙事性语流；若复用旋律，检查自然词组、重音位置、时值容量和发音负荷，不要求字数视觉对齐。
- **Refrain / Hook line**：句架、重音、句尾和发音轮廓应足以稳定回归；短不等于好，必须有可重复的声音动作和上下文变义空间。
- **Pre-chorus**：可通过句组缩短或拉长、复沓加密、韵脚聚合、休止、跨行和称谓逼近制造前进感；这些是候选手段，不是所有预副歌的固定音律。
- **Chorus**：记忆单元、重音、开放元音、句尾力量与复沓位置通常更稳定；允许长短句交错、破韵和延迟 hook，只要声音中心与情绪到达清楚。
- **Post-chorus**：发音记忆和群体可重复性优先，可用短句、vocables、chant、vocal chop、拖腔或节奏型；有完整歌词时仍需语义自然。
- **Bridge / Middle eight**：可改变句法长度、韵脚密度、语气、音区假设和说唱比例以制造对比，但全曲共同声口、人物身份与承重词体系不能一起消失。
- **Link / Transition**：语言最少化；一个尾词、吸气、残句、Ad-lib 或无词都可以，不能为排版完整强补句子。
- **Interlude / Solo / Instrumental break**：纯器乐时不设计歌词表皮；Vocalise 只检查发音、音色和情绪方向，语义可以为空。
- **Breakdown / Drop / Dance break**：优先节拍对齐、切分、重复、口号、呼应和身体性发音；是否需要密集文字取决于表达方式与编曲，不自动等于 Rap。
- **Outro / Coda / Tag**：可稀疏、残句、复沓、叠唱、渐隐或突然停止；最后一个实词、元音和停顿必须服务余波。

表达方式的表皮修饰规则：

- **Rap**：先服从 beat、flow、重音、切分、韵位和换气，再判断行长；内部韵、多音节韵和跨小节句法必须服务语义与人物姿态。Rap 是实现方式，不自动获得更高信息容量，也不要求每行同字数。
- **念白 / Spoken word / Recitative**：优先真实语序、语义重音、呼吸和潜台词；可以弱化押韵，不能退化成作者解说。
- **齐唱 / Chant / Call-and-response**：优先第一次可辨认、群体发音、领答关系和稳定重复；私人独白变成众声前先核对歌者范围。
- **对白 / Duet exchange**：每次换人必须有声部、称谓、句法或音乐位置锚定；双方可以使用不同语气，但不能像两首互不相干的歌。
- **Ad-lib / Vocalise / Vocal chop**：主要承担音色、呼吸、情绪与记忆，不强求完整语义；若它开始交出新事实或决定，重新归类为有词乐段。
- **纯器乐**：写词 Skill 只登记`无词`、它替代或连接什么以及歌词从何处回来；旋律、和声、音色和能量实现交给谱曲 Skill。

## 表达路径与探索权限

先继承选题已确认的表达目的，再选择段落职务。人物选择作品沿关系、事实、选择与代价推进；安定陪伴可通过可预期的回环维持安全感，律动通过拍点、切分、呼应与释放组织参与，幽默通过期待与偏转形成会意。各段仍须有作用，但作用可以是稳定、累积或声音持续，不必每次增加信息。

以下关系动作、改判和回归变义方法用于相应职务，不要求所有作品配置桥段、三次回归或不可逆结尾。无旋律时，拍读只验证文字节奏假设，不能宣称真实可唱。用户要求局部或完整探索时，交付实际样稿并注明未决结构；只要不替换锁定身份、事实和用户决定，普通字词、画面与结构候选由作者先试，不逐项索要批准。

## 三、正式生成顺序

### 生成前：只装配歌词输入

读取作品的`创作日志.md`和`歌词创作台.md`。日志负责状态、决定、保护项和回流；创作台只提供已确认的四层输入。创作档案可以帮助追溯，不直接作为歌词生成材料。

输入包必须只有：

```text
歌者 / 对象 / 关系母句
歌者的价值次序：此刻最想得到什么 / 承担什么 / 接受什么 / 拒绝拿什么替代
说话坐标：固定歌者 / 主要对象 / 旁人与引语来源 / 允许改变对象的条件
视角边界：歌者知道和看见什么 / 背景为何会被歌者注意 / 只属于作者或观众的全局
关系事实账 / 真正未知项 / 禁止补写的关系冲突
共享场景模型：时间层与事件阶段 / 人物和物件的位置、移动与接触 / 感知与知识来源 / 因果条件 / 事实优先级 / 明确的主观与超现实边界
意象职务账：所寄之情 / 关键物性 / 歌者为何注意 / 字面景物、主观感受、比喻象征或剧情动作 / 段内怎样变义
本轮体验与验证假设；人物路径追加主压力 / 选择 / 相应代价
零至三组确有必要的意象或声音回环
各乐段唯一职务
已经确认的段落构思（若有）：从什么可感起点进入 / 采用什么组织方法 / 中途怎样改变听法 / 把什么新认识交给下一段
副歌回归的变义、保持、累积或回接依据
桥段所选对比与回流；认知路线另记旧判断、新认知和选择
听众不补就无法进入的最少事实
本轮保护项、淘汰项和声音假设
不可替代写法：本作拒绝哪项同题惯例 / 哪一项关系、句法、回归或声音决定必须保留 / 谁可能因此拒绝
```

不要从完整故事的先后顺序起笔。正确顺序是：

```text
关系母句
→ 段落职务与出口认识
→ 乐段局部四层门
→ 比较整段构思与组织方法
→ 选定材料及段内运动
→ 句间回声和留白
→ 声音句架
→ 少量事实回声
```

整稿准备锁定时，检查实际采用的全曲结构：先检查每个乐段是否已经在同一张《乐段责任图》中得到具体的进入状态、唯一情感任务、离开状态、相邻交接和对下一次核心回归的新听法。局部四层卡负责把这项既定责任落实为当前段落的材料与声音，不能到写这一段时才替它发明核心感情。责任图缺格或只有宽泛作用时，以当前段落试写验证相邻依赖，明确未决项；锁定前补齐。漂亮局部可以带来可验证的结构发现，但不能自行升级为用户决定。

这道门不要求在曲式阶段预先选定景物、动作、韵脚和句长。全曲先记录当前选定的段落体验；人物路线说明这一段多承受什么，其他路线说明感知或声音如何持续与回接；逐段创作再比较“用什么可感材料和声音把它唱出来”。若局部材料迫使情感任务改变，先修改整张责任图并复核相邻段落，不能只在当前候选说明里补一条新解释。

每个乐段起笔前，按筋骨分支与 `02-筋骨与结构运动.md` 填写局部四层卡，依所选路径记录具体体验、实现和交接。涉及关系判断的内容须有关系事实账支持。外部记录、心理直陈、景语和关系宣告都不天然合格或错误。

生成前必须分开记录：`故事发生了什么 / 作者希望听众知道什么 / 当前乐段要让听众经历什么变化`。第三项必须根据乐段改写成可执行职务，不能停在`铺垫、抒情、爆发、升华`。主歌可以让听众先经历一处带立场的场景、一次感知变化或一项有限事实，不必立刻让歌者直接对对象开口；副歌须形成所选的情绪或声音中心；桥段按本作职务产生对比、转换、抽空、释放或新判断，不强制剧情揭示。任何只说明事件先后和人物结果的目标句都不能直接入词；它可以由合适乐段的场景、叙事、动作或改判证据逐渐显出，也可以完全留在后台，不能一律禁止，更不能原样分行。

局部四层确定后，再做与乐段相称的**中性旁白测试**。主歌不因能够改写成第三人称就失败；要检查它是否仍有作品独有的观察位置、材料运动和情绪入口，删掉这些以后，下一段是否会失去新的来处。副歌检查改成中性说明后损失了什么感情和声音中心；桥段检查失去所选的对比后，回归是否受损。纯音乐实现留给声音验证。失败时回到本段局部灵魂或材料，不依靠对偶、押韵、古风词和第一人称代词补救。

新写整段或因上层问题重写整段时，乐段职务清楚以后仍不得直接写句子。先在内部提出二至三个**整段构思**，每个构思都要用普通话说明：从哪一项感知、关系动作或判断起笔；整段主要采用情景交融、顺承递进、对照并置、回忆倒叙、问答呼应、回旋复沓、叙事推进或其他什么组织方法；同一项材料怎样在段内改变；结尾让歌者或听众比开头多明白什么；它怎样把这项新认识交给下一乐段。候选差异必须发生在观察角度、组织方法、段内运动或出口认识上，不能只是把风换成雨、把手换成影子或换一组近义词。

先比较整段构思，再选择胜出者：开头能否自然走到结尾，是否需要临时补剧情，语言与声音怎样让听众经历筋骨分支指定的本段作用。对最关键或已被用户否决的乐段，用实际段落候选验证，不只比较一个有出处的物件或一句好词；既检验第一次能感到什么，也检验最想重复哪一处声音。若只能证明材料照应、句义成立或主题一致，回到本段表达方式重新试写；不得把同样的句子换个标签就放行，也不把废弃副歌自动塞进主歌。已成立的字词、语体与声音可保留，失败的组织须改变。`改稿与交付验收.md`只验证正文是否实现了选择，不替作者补出正文没有的感情。

宏观背景、公共事件或旁人评价进入某个乐段前，再问一次：它在本段承担的是场景坐标、压力来源、必要事实、关系对照还是改判证据；删掉以后，当前乐段与下一段具体损失什么。主歌允许先写众人也能看见的世界，但必须由取景、次序、距离、感官或段尾转折使它成为本歌的情绪入口；副歌中的宏观词通常只保留已经被前文建立的承重锚点；桥段若用新事实承担改判，该事实必须改变旧判断；纯声音或感知对比不需要补造事实。回答不出局部职务，材料留在剧本后台。不得因为一个中性旁白也能看见`天地、众生、胜负、未来、牺牲`便自动删除，也不得因为它们概括主题方便便自动放行。

说话坐标必须在正文前固定：`我、你、他、她、他们`分别指谁，歌者正在对谁唱，旁人的话由谁转述，直接引语由谁说。相邻两个记忆意群若更换演唱对象、叙述对象或引语来源，必须有称谓、动作、句法或音乐位置提供第一遍即可听见的锚点；只能依靠故事梗概和作者解释分辨时，视为对象漂移，退回关系母句。直接引语会新增人物当时说过什么，必须来自用户事实、可靠材料或已确认创作假设；仅因“这句话很感人、人物可能会说”不得进入正式初稿。

扩写已经锁定的核心句时，先写清本段的开口任务，再给每个新增记忆意群写一句关系职务：它怎样继续、加深、反转或回响同一个关系动作，又改变对象、愿望、责任、代价或听法中的哪一项。当前采用直接抒情路线时，新增意群若仅解释原因、回放经过或概括主题，应检查是否偏离中心；主动选择的叙事、景语或评论按自身体验验收。移段须重新证明目标段落需要它，否则重写，不以事实正确或换标签放行。新增行也不能只为补成四句、续上同一韵、完成对偶或在末句留下问题；这些声音和修辞选择没有资格反过来制造新的爱恨、误解、责怪或求原谅。

关系职务与语言实现共同试写，不把功能说明直接分行充当歌词。按表皮节先建立本歌的语言底稿；已有用户确认的核心句、主歌或收束句时，把它们作为优先语言证据，不能只凭题材标签、“古风”惯例或当轮新意象另起一套说法。再从已确认文字提取：人物是在宣告、呼告、请求、质问还是解释；句子靠主句落锤，还是靠条件、因果和转折推进；承重名词与动词的密度、古雅与浅白的比例、人物身份与命运尺度、主要重音和句尾力量分别怎样。新增意群必须与这些已确认文字连读，保持同一人物、本歌允许的语体范围和与当前段落相称的语势；若从高压宣告退成`若……就……`、`不能……便……`一类完整说明，或把关系压力解释成“我接下来会怎样做”，即使意义正确，也判为功能说明泄露进正文。确需从宣告转为低声请求、从宏观尺度转为私人细节时，前文、关系或音乐必须给出可听见的转变理由。

曲式已经确定有两次以上副歌回归，且用户要求“创作副歌、补全副歌或继续写副歌”时，交付单位默认是整组副歌，不是其中一次。先同时写出每次回归的开口任务和新听法，再在同一轮交付全部副歌正文；共同核心句按已锁定文字保留，变化部分必须能够互相比较。只有用户明确要求单段试写、某次回归仍缺上游事实，或本轮只评审一个指定副歌时，才允许只交一段，并说明它不能代表整组已经完成。不得把单段写得完整，便把其余回归默认为以后再补。

### 生成中：先写能证明主线的句子

每一行主要承担以下一种职务即可：

```text
关系发声 / 抒情转译 / 抒情回声 / 声音记忆 / 必要事实
```

一个段落不必每行都直接说关系，但整首歌必须听得见关系。事实行只有在听众不补就无法进入、且能改变下一句的关系或声音时才保留。

修辞不是装饰名词，而是动作。使用前先写清四件事：它作用于哪项材料、哪一句、哪次回归或哪个声音位置；希望听众因此先听见、补回或重新理解什么；当前人物、语体、段落和声音为什么支持它；重复、解释或省略到什么程度会遮住人物和关系。四项说不清时，不以技法名称代替创作。

具体动作包括：

- 复沓不能先按“意思相近”判为赘余。先把紧邻前文能够承接的时间、画面、对象、动作和结果逐项展开，再让相同或相近句架分别领取其中一项；共享句架负责形成节奏，承接对象或感官的变化负责推进意义。省略对象时，听众必须能从前文直接补回主要指向；允许留下余味，不允许不知道动词落在什么上。两句若实际仍指向同一对象和同一结果，后一只换词解释前一，才删除。固定 Hook、称谓呼号、齐唱和跨乐段回归按各自的重复职务判断，不用相邻短句的语义递进标准误删。
- 对偶让相同句架承受不同结果。
- 比喻迁移来源物的一项准确属性，例如“思念如刀”由刀提供切割和疼痛。
- 化用公共表达、俗语、典故或自然规律时，先迁移其中的因果与关系结构，再决定是否保留句架。逐项映射“谁付出什么代价、谁采取什么行动、什么因此继续或失去”；只有关键词替换而人物责任、结果和后续场景没有改变，判为套句。通过映射的候选还必须由本作自己的画面、动作或后果继续证明，不能只靠听众认出原表达成立。关系映射只证明它有创作资格，不自动证明表达已经独立；若仍保留原表达可识别的完整句架并只替换一个关键词，必须同时生成一项脱离原句架的表达比较，只有作品明确需要化用、收益大于来源遮蔽时才保留。
- 反差先建立公共预期，再用一个实词或动词改写它。
- 条件、让步、问句和否认可以把结论留在未完成处，但必须先有关系来源。写问句前回答：歌者为什么此刻要问、他是否知道答案、哪项事实支持可能的答案、这次发问是在求证、拒绝接受、请求还是质问。反问可以明知答案，但必须让听众听见人物正在反抗或请求什么；若问句唯一作用是押韵、收尾或制造痛感，删除问句，不让修辞替故事新增冲突。

如果修辞只能靠作者说明才能成立，回到血肉层，不做华丽化补丁。

## 四、按实际乐段组装四层

前面的四层分支是生成权威。写某一乐段时，不再读取一张与四层并列的“乐段总表”，而是纵向抽取该乐段在四层中的四项要求，再叠加表达方式：

```text
本段灵魂偏转
→ 本段筋骨运动
→ 本段血肉容量
→ 本段表皮声音
→ Rap / 念白 / 齐唱 / 对白 / Vocalise / 纯器乐等实现修饰
```

把结果写成局部四层卡：

```text
形式角色与表达方式：例如 Verse × Rap、Intro × Spoken、Bridge × Instrumental
灵魂职务：中心关系在本段只推进到哪里
筋骨运动：从什么进入 → 怎样变化 → 交给下一段什么
血肉选择：主要触点 / 必要事实 / 明确省略 / 是否无词
表皮声音：语气 / 句架 / flow或旋律词组 / 重音 / 气口 / 韵脚与复沓假设
越位边界：虽属于故事，但不应由本段完成的内容
混合角色：若标签有歧义，当前按哪项主职务生成，保留哪项次职务
```

新写主歌或同一主歌连续两次在不同局部失败时，按`03-血肉与材料抒情.md`比较整段构思，不继续逐句换物件、补转折或增加禁令。多段主歌的关系、信息与同旋律对应按`02-筋骨与结构运动.md`检查。其他乐段同理：先回到对应层的偏转，不用相邻乐段的标准补救。

纯器乐段仍填写灵魂与筋骨，因为它必须知道为何出现、替代什么、如何回到歌词；血肉标记承重声音或主题材料，表皮的旋律、和声、配器、音色和能量由谱曲 Skill 接管。写词 Skill 不因结构表需要一格文字便强行增加歌词。

## 五、声音规则：诗性原则之后的硬骨

声音规则不能被文学公理替代，也不能反过来支配意义。正式作词前分开记录“段落功能卡”和“声音卡”，但分开记录不等于先写完整语义、再给它套节奏。两张卡完成后、真正落字以前，必须再做一次语义—声音对位：本段每一项承重时间、画面、对象、动作或结果由哪个词组领取；平行、复沓、长短变化或停顿分别让哪两项意义形成并列、递进、遮断或落空；省略的成分从哪里补回。找不到这种对应时，声音形式只是装饰；对应关系成立时，不得仅因两个短句语义相近便提前删去其中一个。

### 段落功能卡

```text
前段交来什么感受 → 本段结束要让听众经历什么具体变化或持续 → 哪种句法、语气、材料与声音实现它 → 裸稿中哪一意群证明已经发生 → 相邻段落承接什么而不重复什么 → 允许省略与禁止前台化的事实
```

“前几句显影、后面转关系、末句收判断”属于意义组织的可选方案，不是押韵规律。

功能卡以筋骨分支的表达任务裁决，不只填`抒情、爆发、升华、表达悲痛`。对当前候选，先不看作者说明，读者实际能认出哪种感受、最想重复哪一意群，再与预定职务核对。把候选放到相邻段落只是诊断：若解释其作用时仍只有“有画面、有情绪”，说明未分清表达职务；不要求每句只有一个可能位置，实际音乐可以使同句承担不同作用。句义或感情中心不清时先重写，不靠移段掩盖。

### 声音卡

有已锁定核心句时，先从核心句建立全曲声音基准：保护说话者、对象及用户确认的表达作用，记录主要语气、语体范围、句法力量、承重词密度、命运尺度与可重复的声音动作。逐项区分必须保持的特征与可随局部变化的特征，不把所有观测指标都固定。各乐段声音卡说明怎样承接基准、在哪里因人物距离、段落职务或音乐条件发生可辨变化。若主歌、预副歌、桥段分别采用互不相干的句法和语体，只能靠主题相同证明它们属于一首歌，先重做全曲声音基准，不继续逐段凑韵。

```text
语体与主要语气 → 句法推进方式 → 句法主干与修饰负荷 → 承重词与尺度 → 句数 → 句长走势 → 主要重音 → 气口候选 → 主韵/邻韵 → 主要落韵句 → 发音风险 → 有意不押句
```

- **句数**是结构容量。四句、八句、十六句说的是歌词句或音乐句数量，不是字数。
- **句长**由语义密度、旋律时值、重音和情绪决定。长短句可以交错，也可以局部相近；不能为排版整齐削平内容。
- **重音**是听众首先听见的字词，必须落在关系转折、承重词或声音记忆上。
- **气口**是自然词组、意义重音和换气的组织。可以没有、一个或多个；只放在自然停顿处，不切开主谓、动宾和固定搭配。正文用普通半角空格标记候选气口，不用竖线。
- **韵脚**是句尾的听觉回环。先确定段落主韵、可接受邻韵、落韵句和有意不押处，再在自然语义中选择句尾实词。语气词可以在句中出现，但不作为主要段落韵脚。
- **发音路径**检查承重字与相邻音节的声母、韵腹和韵尾怎样衔接，尤其关注句尾、长音、音高峰值和快速密集处。韵辙相同或相近只说明听觉回环可能成立，不代表口腔动作相同，也不代表旋律中同样好唱；无旋律时只标风险，最终交给真实旋律与试唱。

主歌可以较松，副歌通常需要更稳定的声音中心，预副歌可用韵脚聚合或休止制造前进感；这些是声音选择，不是段落功能的定义。宁可保留准确的非押实词，也不以硬凑韵改变人物关系、语义角色或词语搭配。无旋律时只标记文字侧假设，最终交给朗读、拍读、试唱和成曲验证。

“稳定的声音中心”不等于每行字数相同。先写自然语义单位和主要重音，再选择整齐、长短交错、逐步伸长或逐步缩短的句长走势。连续三行以上同时出现相同字数和相同气口时，必须做一次对称来源检查：相同句架是否承受平行而递进的意义，或是否已有重复旋律、节奏动机、仪式性宣告等声音理由。两项都没有，视为视觉对齐替代了声音设计；保留自然语义，另做一版长短变化的拍读比较。整齐句不是禁用项，只有无来源的整齐才退回重写。

核心句阶段即使只交一至两行，也必须先做最小声音验证：逐句标出字数或句长走势、自然词组、主要重音和句尾实词，再连续拍读三遍。只有尾字同韵，或排版看起来整齐，不能视为已经形成音律结构；拍读时重音漂移、自然词组被切开、后一句能量无故下落，就回到关系动作与句架重写，不继续补韵。核心句扩成完整副歌后，重新检查新增行的关系来源和整段句长走势；前两行已经成立，不代表后续行可以复制其字数、停顿和韵脚。

扩写锁定核心句时再做一次“换歌测试”：遮住剧情，只连读核心句与新增句；若语气从人物宣告变成作者说明，词语从高密度承重词变成中性过程词，或时代、身份与情绪尺度像换了一首歌，推翻新增句。正常中文、事实正确和段落职务成立，都不能替代这项语言连续性。

## 六、改稿顺序与反向审稿

任何准备交给用户评审的歌词文字，包括核心句、单段试写、替换句、副歌变体和完整初稿，都先按`改稿与交付验收.md`执行“候选展示准入”。生成与验收必须分成两次阅读：第一次允许作者知道自己想表达什么；第二次只看裸歌词、已确认的相邻乐段和全曲声音基准，不读取候选说明。不能交出准入证据的候选留在内部返工，不以“先给用户看看”跳过。

候选完成后遮住所有解释，只读歌词。按以下顺序审，不允许用低层润色掩盖高层问题：

```text
灵魂 → 筋骨 → 血肉 → 表皮 → 声音验证
```

### 灵魂门

是否只有一条主要关系压力？歌者为何此刻非唱不可？谁在唱、唱给谁、最想要什么、什么无法替代它是否清楚？背景材料是否都来自歌者能够看见、知道并会在意的部分？结尾是否兑现本作的收束、循环或开放方式？以不可逆选择为核心时，代价是否仍被保留？如果只是题材、时间线、外界评价或情绪标签，或者拿第一人称代词包着作者的全知说明，回到灵魂层。

### 筋骨门

按筋骨分支与段落功能卡检查本段听后结果及裸稿证据，保留当前表达路径的例外。人物抒情副歌需要可辨的中心感受与可回归句架；不能只凭材料照应、完整语法或比喻解释放行，也不能以不用第一人称而否决。逐段检查前段交来什么、本段怎样改变或维持、后段怎样承接；关系变义设计只换地点、消息或主语不算完成，稳定与声音路线另验。人物开口无准备地变成作者说明，回到表达方式重写。

### 血肉门

每个材料是否有歌者的情绪来处和准确物性？它属于景物、主观感受、比喻象征还是剧情动作，正文能否辨认？物件回环是否变义？抽象词是否有主要职务？删掉一行后损失的是关系和声音，还是仅仅剧情完整？后一种删掉。

### 表皮与声音门

每句主语、动词、对象是否自然；语体是否统一而不僵硬；句尾是否由实词落地；长短句、重音、气口、主韵和邻韵是否分别成立；是否存在为了古雅、对偶、整齐或押韵而生造的搭配。

必须做十二项反向测试：

1. **梗概测试**：改写成“谁在何时做了什么”，若几乎不损失情绪，只损失顺序，说明仍是剧情分行。
2. **时间删除测试**：删去后来、临走、收到、有人说等时间连接词后，若只剩顺序断裂，说明没有完成抒情转译。
3. **触点关闭测试**：删去物件或比喻后，若只剩“我很痛苦”的空判断，说明触点没有把情绪唱出来。
4. **关系方向测试**：逐个圈出爱、恨、怨、怪、等、原谅、亏欠、背叛等强关系词，写清谁对谁或对什么产生它，以及哪项材料赋予人物这种认知。对象一换，人物关系就会改变；无法追溯的词和问句退回灵魂层。
5. **对称来源测试**：连续三行以上同字数、同气口或同句法时，遮住排版朗读；若听不出意义递进、重复动机或刻意宣告，只看得见整齐，说明字数正在替代声音与情绪。回到自然语义单位，比较一版长短变化后再决定。
6. **说话坐标测试**：逐个标出所有人称代词、称谓和直接引语的指向，再只读歌词、不读梗概。若相邻意群中听不出谁在对谁说、引语由谁发出，或一个`你`可能被听成爱人、知情者和旁观者中的不同人物，退回关系母句与对象锚点，不用解释补足。
7. **全曲同声测试**：遮住乐段标签，连读主歌、预副歌、核心句和桥段。若各段虽围绕同一主题，却在主要语气、句法力量、词语密度、时代尺度或节奏动作上像不同歌者、不同歌曲，回到全曲声音基准；不能用字数统计、局部押韵或“段落功能不同”放行。
8. **重韵动机测试**：逐段圈出所有句尾字。同一个字再次落韵时，说明它第二次改变了什么对象、距离、责任、含义或情绪压力；若只重复原判断，或只是因为该字容易押韵，判为无意重韵。不要把正文中所有同字一律删除，有意 hook、复沓和回环按实际声音收益保留。
9. **同旋律对应测试**：两段主歌或其他复用旋律的歌词，逐位置比较句数、自然词组节奏、主要重音、发音负荷和情绪力度。对应位置要求词组边界、时值容量与演唱难度相容，不要求裸字数相等；若无法落入同一旋律职务，必须调整歌词或明确采用旋律变体。无音乐材料时标记为待验证，不以视觉字数相近冒充已经可唱。
10. **发音路径测试**：圈出句尾、长音候选、音高峰值候选和快速密集处，逐字标记声母、韵腹、韵尾及与前后音节的口腔动作。若只因同属一辙便认定顺口，或只因出现闭合、阻塞便认定难唱，均退回声音卡；结合速度、时值、音高和演唱方式判断。没有旋律或试唱时，只记录风险，不作可唱性定论。
11. **修饰负荷测试**：先只读主语、能愿判断、主要动词、对象和结果，再逐个放回条件、时间、范围、程度、否定和方式成分。若两个以上修饰成分连续挤在同一动作之前，却没有分别改变关系、时间、范围、立场或声音，或使主干迟迟不能出现，删除、换成更准确的承重词或调整语序；若删后人物选择、转折、时态或节奏动作改变，保留。对照句还要检查能愿词是否处在同一判断尺度，例如可能与可能、意愿与意愿；有意跨尺度必须由人物变化或段落职务证明。
12. **安全化对照测试**：把最可能引起分歧的关系判断、句法、留白或结尾改成同题作品最常见的说法，再与原稿裸读。常规版若只是更圆、更整齐，却让人物责任、不可逆代价、回归变义或声音身份消失，撤销安全化修改；原稿若只剩难懂和突兀、说不出它保护了什么，则创新没有成立，回到灵魂或声音卡重写。

准备替换的句子回到表皮节的原句—最小修复—差异实现比较：先具体指出失效位置与已有表达作用，再检查新句的收益和损失。仅因“不够古、不够高级、不够整齐”而装饰，或仅因“不够常见、不够顺滑”而日常化，都不能放行；没有净收益时保留原句。真实语义、事实或声音硬伤仍须修正，不以风格名义护住错误。

## 六点五、作词工艺委派：本 Skill 是协调者，语言级工艺交给 `lw-*`

本 Skill 持有作词域的**灵魂与筋骨判断权**：关系母句、歌者立场、段落职务、乐段运动、四层门与反向审稿都由它裁决，产出锁定正文与《乐段责任图》。但**语言层面某些需要专门语音学、韵学或体裁工艺的执行**，本项目挂了一个作词工艺库 `.agents/skills/laohu-lyric-writing/skills/lw-*`（改编自 jtydhr88/lyric-writing-skills，见 README）。它们是**执行件不是入口**：用户永远从本 Skill 进入，本 Skill 遇到下列缺口时才点名调用对应工艺卡，取回结果后仍由本 Skill 裁决是否采用。

| 本 Skill 遇到的缺口 | 委派给 |
| --- | --- |
| 普通话字数、平仄、十三辙、顿 | `lw-mandarin` |

| 粤语协音与九声（另一套硬约束，写作顺序反转） | `lw-cantonese` |

| 押韵类型学、韵式、意外度、故意不押 | `lw-rhyme` |
| 行长怎么数、段落功能、hook 放哪、平衡与不平衡 | `lw-structure` |
| 意象、具体名词、object writing、抽象名词黑名单 | `lw-imagery` |

三条边界防串权：
1. **结构分层**——一行「多长」怎么数归 `lw-structure`／各语言层；但「用这个长度做什么段落、hook 放哪」的裁决仍是本 Skill 的筋骨权，工艺卡只给数与法，不定段落职务。
2. **意图不越选题**——`lw-song-intent` 只提供词侧类型与意图清单，作品的关系母句、立意、受众与作品总线由 `laohu-lyric-topic` 唯一裁决；两者冲突以 `laohu-lyric-topic` 为准。
3. **审计归监督**——`lw-ai-tell-audit` 只提供作词侧 AI 味检查条目，能不能交稿、跨领域质量红线由 `laohu-quality-supervisor` 统一裁决，本 Skill 与工艺卡都不自立第二套质量权威。

工艺卡各自开头「四层能力总纲」写明了它独门守着哪一层、以及它不持有的判断权，调用时以那份声明为界。

## 七、阶段边界与参考入口

- 核心句阶段只交一至两行核心单位，不自动扩写整首。
- 初稿阶段交可评审的完整歌词，不交分行故事；状态为“歌词初稿待用户确认”。
- 用户未整体认可前，不进入精修、谱曲、正式命名或发布。
- 上层不成立时不改字；局部反馈若暴露同根问题，先更新唯一责任规则，再回到当前作品。

歌词进入谱曲时，交付锁定正文、各段职务、关键重音、候选气口、韵脚听觉位置、核心句每次回归的新责任、不可改动的事实与关系，以及仍待真实旋律验证的声音假设。写词只说明哪些语言事实必须被音乐听见，不替谱曲决定旋律、和声、配器和演唱方案。

按需要读取：

- `01-灵魂与作品重心.md`：关系母句、作品重心与对标反推。
- `02-筋骨与结构运动.md`：段落运动、副歌回归、桥段和容量。
- `03-血肉与材料抒情.md`：对应物、文化材料、留白和抽象词。
- `04-表皮与语言声音.md`：语体、炼字、句法、声音、韵脚和气口。
- `留白与修辞机制.md`：承重词、未封口处和修辞如何落成具体句子。
- `对标案例-抒情散文式咏唱.md`：从完整作品反推可迁移机制，不摘词库。
- `改稿与交付验收.md`：任何用户可见歌词候选的展示准入、反向审稿与交付门槛。
- `歌词稿格式与乐段标签.md`：作品歌词交付必读，调用条件与检查见本文件交付契约；不以用户是否提到格式为触发条件。
